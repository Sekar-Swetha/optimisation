\begin{abstract}
This report presents a comprehensive comparative study of six families of optimisation algorithms applied to a suite of benchmark functions of varying difficulty, from a simple convex quadratic through a lightly non-convex toy neural-network loss to the ill-conditioned Rosenbrock function.
The methods investigated are:
(1)~adaptive step-size methods -- Polyak, Adagrad, RMSprop, and the Heavy Ball / Polyak momentum rule;
(2)~momentum and stochastic methods -- Nesterov acceleration, Adam, and mini-batch SGD;
(3)~Newton's method with Hessian regularisation and local second-order approximations;
(4)~derivative-free and zeroth-order approaches -- forward finite differences, Nesterov random search, Nelder--Mead simplex, and grid search;
(5)~constrained optimisation via projected gradient descent and penalty methods; and
(6)~the Frank--Wolfe conditional-gradient algorithm for linear-constrained problems.
Each method is evaluated with respect to convergence speed, trajectory behaviour, stability under misspecification, and computational cost per iteration.
Theoretical convergence guarantees are stated where applicable and validated against empirical results.
The experiments confirm several key theoretical predictions: Newton's method achieves one-step convergence on the quadratic benchmark; Nesterov acceleration achieves the optimal $O(1/k^2)$ rate on convex problems; Polyak's step size diverges whenever $f^\star$ is misspecified; and projected gradient descent enforces feasibility as a hard constraint from the first iteration, unlike penalty methods which require $\lambda\to\infty$.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation is the backbone of modern machine learning and data analysis.
Selecting the right algorithm for a given problem requires understanding both the mathematical properties of the objective function and the computational constraints of the application.
This report systematically investigates six families of methods, moving from simple gradient descent baselines to more sophisticated adaptive, second-order, and constrained approaches.

Three properties of the objective function fundamentally govern algorithm behaviour:
\begin{itemize}[nosep]
\item \textbf{$L$-smoothness} ($L > 0$): $\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|$ for all $x, y$. The smoothness constant $L$ bounds the maximum curvature and controls the largest safe step size: $\alpha \leq 1/L$ guarantees sufficient decrease for gradient descent.
\item \textbf{Strong convexity} ($\mu > 0$): $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$. This ensures a unique minimum and linear convergence of gradient descent at rate $(1 - \mu/L)$ per iteration.
\item \textbf{Condition number} $\kappa = L/\mu$: A high condition number indicates an anisotropic landscape in which gradient descent zig-zags, motivating momentum, adaptive, or second-order methods.
\end{itemize}
All experiments use \texttt{np.random.seed(42)} for reproducibility.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2}\theta^T H \theta - b^T\theta + c,
\end{equation}
where $H = \frac{1}{m}X^T X \succ 0$, $b = \frac{1}{m}X^T y$, and $c = \frac{1}{2m}\|y\|^2$.
This is a \emph{strongly convex quadratic} with constant Hessian $H$.
The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y) = H\theta - b$.
Due to observation noise, the irreducible minimum is $J^{\star} \approx 0.4826$, attained at the OLS solution $\theta_{\text{OLS}} = H^{-1}b \approx [3.03, 4.02]^T$.
The smoothness constant is $L = \lambda_{\max}(H)$ and the strong convexity modulus is $\mu = \lambda_{\min}(H)$; with $m=1000$ Gaussian samples, $\kappa = L/\mu \approx 10$--$20$ (mild conditioning).
Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$.
The Hessian is $H(x) = \operatorname{diag}(2 - \sin(x_1),\ 10)$, which is positive definite wherever $\sin(x_1) < 2$ (always true).
The eigenvalue ratio varies between approximately $1.8\!:\!10$ and $3\!:\!10$, giving a condition number $\kappa \approx 5$, creating moderate anisotropy.
The minimum satisfies $2(x_1^{\star} - 1) + \cos(x_1^{\star}) = 0$, yielding $x_1^{\star} \approx 0.582$, $x_2^{\star} = 2.0$, and $f^{\star} \approx 0.7244$.
Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$.
The Hessian at the optimum has eigenvalues approximately $0.5$ and $\approx 1000$, giving $\kappa \approx 2000$.
This extreme ill-conditioning, combined with a narrow curved valley along $x_2 = x_1^2$, makes the Rosenbrock function one of the most challenging standard test functions.
The function is non-convex globally but strongly convex in a neighbourhood of the optimum.
Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Box-Constrained Feasible Set}
For constrained problems:
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a compact convex polytope, which is the type of constraint set for which both projected gradient descent and Frank--Wolfe are well-suited.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

Gradient descent with constant step size $\alpha$ converges at the linear rate
\begin{equation}
f(x_k) - f^\star \leq \left(1 - \frac{\mu}{L}\right)^k \bigl(f(x_0) - f^\star\bigr)
\end{equation}
for $\mu$-strongly convex, $L$-smooth objectives with $\alpha = 1/L$.
Adaptive methods aim to remove the dependence on knowing $L$ a priori and to accelerate convergence by exploiting curvature information accumulated over iterations.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step size is theoretically optimal: for a convex function with known $f^\star$, it achieves the fastest worst-case convergence among all constant step-size rules, with rate $\sqrt{(1 - \mu/L)}$ per iteration for strongly convex problems.
The formula is derived by choosing the step that minimises the distance to the optimum in the $H$-norm:
$\alpha_k = \arg\min_\alpha \|x_k - \alpha g_k - x^\star\|^2$.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative squared gradient, per coordinate}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad automatically scales the step size per coordinate: dimensions with large historical gradients receive smaller effective steps.
Its effective step for coordinate $i$ after $k$ iterations is
$\alpha_k^{(i)} = \alpha_0 / \sqrt{\sum_{t=0}^{k} g_t^{(i)2}}$,
which decays monotonically --- an advantage on sparse problems but a limitation on dense problems, as the step eventually shrinks to zero.
Adagrad achieves an $O(1/\sqrt{k})$ regret bound in the online convex setting.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop addresses Adagrad's vanishing step-size problem by replacing the cumulative sum with an exponential moving average (EMA) with decay factor $\beta = 0.9$.
The EMA assigns weight $(1-\beta)\beta^j$ to the gradient squared $j$ steps ago, so recent gradients receive proportionally more influence.
This allows the effective step size to adapt to local curvature rather than the entire history.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method (also called Polyak momentum) introduces a velocity variable $z_k$ that accumulates a momentum term $\beta z_k$ from the previous step.
For strongly convex quadratics with condition number $\kappa$, the optimal parameters are $\beta^{\star} = \bigl((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\bigr)^2$ and $\alpha^{\star} = 4/(\sqrt{L}+\sqrt{\mu})^2$, achieving a convergence rate of $\bigl((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\bigr)^2 \approx 1 - 2/\sqrt{\kappa}$ --- a quadratic improvement in the exponent over vanilla GD's rate of $1 - 2/(\kappa+1)$.

\begin{remark}[Polyak divergence mechanism]
The Polyak step computes $\alpha_k = (f(x_k) - f^\star_{\text{spec}})/(\|g_k\|^2 + \varepsilon)$.
As iterates approach the true minimum $x^\star$ on Benchmark A, $\|g_k\| \to 0$ while $f(x_k) \to J^\star_A \approx 0.4826$.
Since $f^\star_{\text{spec}} = 0$, the numerator stays bounded away from zero while the denominator vanishes, making $\alpha_k \to \infty$.
The resulting large step overshoots the minimum, causing oscillation and eventual divergence.
This demonstrates why knowledge of $f^\star$ is not merely a technical assumption but a fundamental operational requirement.
\end{remark}

\subsection{Comparative Analysis and Conclusions}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest (Rosenbrock: $f = 0.009$, a $375\times$ improvement over GD). Otherwise, Heavy Ball and Adagrad match or exceed GD baseline performance.
\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential averaging of curvature. Heavy Ball shows characteristic overshoot followed by damped oscillation, particularly on Rosenbrock.
\item \textbf{Stability:} GD baseline is most stable but slowest. Polyak is \emph{catastrophically unstable} when $f^{\star}$ is misspecified. Adagrad is uniformly stable due to its monotonically decreasing step size, though this causes premature stagnation on long-horizon problems. RMSprop avoids Adagrad's stagnation by forgetting old gradients.
\item \textbf{Practical recommendation:} In practice, exact $f^{\star}$ is rarely known, limiting Polyak's applicability to convex problems where a lower bound is available. RMSprop and Adagrad are more robust choices, and Heavy Ball provides a strong alternative when the problem is well-conditioned enough for momentum tuning.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}

Vanilla gradient descent has convergence rate $O(1/k)$ for smooth convex functions.
Nesterov~(1983) showed that a simple momentum modification achieves the optimal $O(1/k^2)$ rate for the same problem class, matching the lower bound for first-order methods.
Adam combines momentum with adaptive per-coordinate scaling, making it the default optimiser for non-convex deep learning problems.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead / extrapolated point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$.
This ``corrective'' evaluation prevents the momentum term from overshooting the minimum because the gradient at the extrapolated point already anticipates the upcoming position.
The momentum schedule $\beta_k = (k-1)/(k+2)$ increases from $0$ to $\beta_{\max}$ as $k$ grows, with the specific schedule $\beta_k = (k-1)/(k+2)$ arising from the sequence $\lambda_k = (1 + \sqrt{1 + 4\lambda_{k-1}^2})/2$ that Nesterov used to prove the $O(1/k^2)$ rate.

\begin{theorem}[Nesterov acceleration, informal]
For a convex, $L$-smooth function with $\alpha = 1/L$ and the standard momentum schedule,
$f(x_k) - f^\star \leq \dfrac{2L\|x_0 - x^\star\|^2}{(k+1)^2}$,
which is optimal up to a constant factor among all first-order methods.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moment parameters $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (EMA of gradients)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (EMA of $g^2$)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias-corrected first moment}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$ \Comment{Bias-corrected second moment}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam can be viewed as RMSprop with momentum: $m_t$ tracks the gradient direction (first moment), while $v_t$ tracks per-coordinate curvature (second moment).
The bias correction $1/(1-\beta_j^t)$ is critical in early iterations: without it, $m_t \approx (1-\beta_1)g_t$ is biased towards zero because the EMA initialises at $\mathbf{0}$.
The effective step size per coordinate is bounded as $|\Delta x_t^{(i)}| \leq \alpha(1-\beta_1)/\sqrt{1-\beta_2}$, giving reliable learning rate control.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses a constant learning rate $\alpha = 0.06$ with batch sizes $b \in \{5, 40\}$, over 50 epochs with data shuffled at every epoch.
At each epoch, the dataset of $m = 1000$ samples is randomly permuted and split into mini-batches; the gradient is estimated from each mini-batch in turn.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1, \ldots, m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Mini-batch gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The mini-batch gradient $g_{\mathcal{B}}$ is an unbiased estimator of the full gradient $\nabla J(\theta)$ with variance $\text{Var}[g_{\mathcal{B}}^{(i)}] = \sigma^2_{\text{grad}} / b$, where $\sigma^2_{\text{grad}}$ is the per-sample gradient variance.
A larger batch size reduces gradient noise (at cost of more computation per step), while a smaller batch size introduces more stochasticity but allows more updates per epoch.

\subsection{Local Approximations of $g(x) = x^4$}

At $x_0 = 0.25$, we compute:
$g(x_0) = 0.25^4 = 0.003906$,
$g'(x_0) = 4 \cdot 0.25^3 = 0.0625$,
$g''(x_0) = 12 \cdot 0.25^2 = 0.75$.

\textbf{First-order (Taylor) approximation:}
\begin{equation}
\hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.003906 + 0.0625\,(x - 0.25).
\end{equation}
This tangent line has no minimum (it is unbounded below), so a gradient step on the first-order model would require choosing a step size $\alpha$ separately.

\textbf{Second-order approximation:}
\begin{equation}
\hat{g}_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.003906 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton step minimises $\hat{g}_2$: setting $\hat{g}_2'(x) = 0$ gives the update
\begin{equation}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)}.
\end{equation}
At $x_0 = 0.25$: $x_1 = 0.25 - 0.0625/0.75 = 0.25 - 0.0833 = 0.1667$.
Applying again from $x_1$: $x_2 \approx 0.057$, converging rapidly towards $x^\star = 0$.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}
\caption{Q3: Local approximations of $g(x) = x^4$ at $x_0 = 0.25$. The first-order approximation (tangent line) captures only the local slope and diverges rapidly from the true function. The second-order approximation (parabola) captures local curvature and provides an accurate fit in a neighbourhood of $x_0$. The Newton step is the $x$-coordinate of the parabola's vertex, which lies much closer to the true minimum than a na\"{i}ve gradient step of arbitrary size. This motivates Newton's method for general smooth functions.}

\subsection{Newton's Method with Hessian Regularisation}

\begin{algorithm}[H]
\caption{Newton's Method with Regularised Hessian}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0,1]$, damping $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction: solve linear system}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The regularisation $\lambda I$ ensures $H_k \succ 0$ even when $\nabla^2 f(x_k)$ is indefinite or near-singular (as occurs on the Rosenbrock function far from the optimum).
The step $\alpha < 1$ (damping) provides a safety margin when the quadratic approximation is inaccurate globally.
When $\alpha = 1$ and $\lambda = 0$, this is pure Newton's method, which achieves \emph{quadratic} local convergence:
\begin{equation}
\|x_{k+1} - x^\star\| \leq C\,\|x_k - x^\star\|^2
\end{equation}
for some constant $C > 0$ depending on the Hessian Lipschitz constant.
Settings: GD uses 80 iterations; Newton uses 20 iterations with $\lambda = 10^{-8}$.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}

\subsection{Part A: Finite Differences and Nesterov Random Search (Benchmark B)}

\subsubsection{Forward Finite-Difference Gradient Approximation}

The forward finite-difference (FD) approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
\end{equation}
The truncation error from Taylor expansion is $O(\delta)$ (the omitted higher-order terms), while floating-point cancellation introduces an error of $O(\varepsilon_{\text{mach}}/\delta)$.
The total error is minimised at
$\delta_{\text{opt}} \approx \sqrt{\varepsilon_{\text{mach}}} \approx 10^{-8}$,
giving an overall FD accuracy of $O(\varepsilon_{\text{mach}}^{1/2}) \approx 10^{-8}$.
For large $\delta$, the truncation error dominates: the FD gradient direction deviates significantly from the true gradient, causing incorrect descent directions.

\subsubsection{Nesterov Random Search (Zeroth-Order Method)}

\begin{algorithm}[H]
\caption{Nesterov Random Search}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$, normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform on unit sphere}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Nesterov random search estimates a \emph{smoothed} gradient using only two function evaluations per step, regardless of dimension $d$.
The estimator $\hat{g}_k = \frac{d}{\delta}[f(x+\delta u) - f(x)]u$ (with the $d$ factor) is an unbiased estimator of $\nabla f_\delta(x)$ where $f_\delta$ is the Gaussian-smoothed function.
The variance is $O(d^2/\delta^2)$ (when using the gradient estimator proportional to dimension), making convergence inherently slower than FD in low dimensions.
The critical advantage is \emph{dimension-independence of cost}: only 2 function evaluations per step versus $d+1$ for forward FD.
This makes random search attractive in very high dimensions or when gradient computations are expensive.

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move the worst vertex through the centroid of the remaining vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): if the reflection improved, try a further step in the same direction.
\item \textbf{Contraction} ($\rho = 0.5$): if the reflection worsened, contract towards the centroid.
\item \textbf{Shrink} ($\sigma = 0.5$): if contraction fails, contract all vertices towards the best.
\end{enumerate}
No gradient information is required: each step uses at most 1--3 function evaluations.
Settings: initial simplex step $= 0.35$, $N = 160$ iterations.

The simplex adapts its shape to the local landscape --- elongating along ridges and contracting near minima --- making it effective on smooth functions in low dimensions.
However, Nelder--Mead has no convergence guarantee for $d \geq 2$ and can stagnate on ill-conditioned functions.

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

\subsection{Problem Formulation and KKT Conditions}

The constrained problem is:
\begin{equation}
\min_{x \in \mathbb{R}^2}\; f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1) \qquad \text{subject to } x_1 \geq 0.5.
\end{equation}
The feasible set is $\mathcal{X}_5 = \{x : x_1 \geq 0.5\}$, and the starting point $x_0 = (0.2, 4.0)$ is \emph{infeasible}.
The constraint can be written as $g(x) = 0.5 - x_1 \leq 0$.

The KKT optimality conditions for this problem are:
\begin{align}
\nabla f(x^\star) + \nu \nabla g(x^\star) &= \mathbf{0} \quad &\text{(stationarity)}, \\
g(x^\star) &\leq 0 \quad &\text{(primal feasibility)}, \\
\nu &\geq 0 \quad &\text{(dual feasibility)}, \\
\nu\, g(x^\star) &= 0 \quad &\text{(complementary slackness)}.
\end{align}
For this single inequality constraint, $\nabla g = [-1, 0]^T$.
If the unconstrained minimiser has $x_1^\star > 0.5$ (interior case), then $\nu = 0$ and the constrained minimum equals the unconstrained minimum.
Since the unconstrained minimiser has $x_1^\star \approx 0.582 > 0.5$, the constraint is \emph{inactive} at the solution.
The constrained and unconstrained minima coincide at $x^\star \approx (0.582, 2.000)$ with $f^\star \approx 0.7244$.

\begin{remark}[Slater's condition]
The feasible set $\{x : x_1 > 0.5\}$ (strict interior) is non-empty, so Slater's condition holds. This guarantees strong duality and that the KKT conditions are both necessary and sufficient for optimality.
\end{remark}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}_5}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}_5}(z_{k+1})$ \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$, $x_2$ unchanged}
\EndFor
\end{algorithmic}
\end{algorithm}

For the half-space constraint $x_1 \geq 0.5$, the projection is the component-wise clip: $\Pi_{\mathcal{X}_5}(z) = (\max(0.5, z_1), z_2)^T$.
This is $O(1)$ per iteration.
Projected gradient descent converges at rate $O(1/k)$ for convex objectives and to a neighbourhood of size $O(\alpha L)$ around the constrained optimum for $L$-smooth functions.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty gradient is $\nabla F_\lambda(x) = \nabla f(x) - \lambda e_1 \cdot \mathbf{1}[x_1 < 0.5]$, where $e_1 = [1,0]^T$.
As $\lambda \to \infty$, the penalty method's minimiser converges to the constrained minimiser.
For finite $\lambda$, the penalty allows residual constraint violation $O(1/\lambda)$.

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$ to compensate for the stiffer gradient); Unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\textbf{Projected GD} enforces feasibility as a \emph{hard constraint} at every iteration: no iterate is ever infeasible.

\subsection{Feasible Set and Linear Programme}

The feasible set is $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$, a compact box polytope.

\textbf{Linear Programme:} For the linear objective $f(x) = a^T x$ with $a = [1, 2]^T$, the minimum over $\mathcal{X}$ is obtained by minimising each coordinate independently (since the feasible set is a Cartesian product).
Since both components of $a$ are positive, the minimum is at the lower bounds:
\begin{equation}
x^{\star} = \underset{x \in \mathcal{X}}{\arg\min}\; (x_1 + 2x_2) = (0.5,\, -5), \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}

\begin{proposition}[Fundamental theorem of linear programming]
The minimum of a linear objective over a bounded closed convex polytope is always attained at a vertex of the polytope. For the box $\mathcal{X}$, the vertices are the four corners; the minimising vertex is selected by the sign of the gradient.
\end{proposition}

The minimum is attained at the vertex $(0.5, -5)$, confirming the fundamental theorem of LP. Any descent method on a linear objective over a polytope will converge to a vertex, since the gradient is constant and points in a fixed direction.}

\subsection{Frank--Wolfe Algorithm (Conditional Gradient)}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: stays in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

The Frank--Wolfe algorithm (also called the conditional gradient method) replaces the projection step of projected gradient descent with a \emph{linear minimisation oracle} (LMO): solving a linear programme over $\mathcal{X}$.
For box constraints, the LMO decomposes per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
requiring only $O(d)$ operations.
Crucially, since $z_k \in \mathcal{X}$ and $x_k \in \mathcal{X}$, the convex combination $\beta x_k + (1-\beta)z_k \in \mathcal{X}$ --- \emph{no projection is needed at any step}.

The Frank--Wolfe gap $G_k = \nabla f(x_k)^T(x_k - z_k)$ measures the quality of the current iterate; $G_k = 0$ at optimality.
For convex, $L$-smooth objectives, the standard convergence rate is:
\begin{equation}
f(x_k) - f^\star \leq \frac{2L D^2}{k + 2},
\end{equation}
where $D = \max_{x, y \in \mathcal{X}} \|x - y\|$ is the diameter of $\mathcal{X}$.
This $O(1/k)$ rate is achievable but generally cannot be improved for Frank--Wolfe without additional assumptions.

Starting from $x_0 = (1, 1)$, two mixing parameters are tested: $\beta = 0.90$ (10\% step towards the LP vertex per iteration) and $\beta = 0.985$ (1.5\% step towards the LP vertex per iteration).

\subsection{Interior vs Boundary Behaviour and Theoretical Analysis}

\textbf{Interior optimum:} Frank--Wolfe converges but exhibits characteristic ``zig-zag'' vertex jumping.
The LMO $z_k$ jumps between vertices of $\mathcal{X}$ because small changes in the gradient direction flip which vertex minimises the linear objective.
The iterate $x_k = \beta x_{k-1} + (1-\beta)z_k$ is pulled towards alternating vertices, creating oscillation.
The fixed step size $\beta$ does not decay, preventing convergence to machine precision; the standard step $\gamma_k = 2/(k+2)$ (mixing parameter $1 - \gamma_k$ towards $z_k$) would ensure $O(1/k)$ convergence.

\textbf{Boundary optimum:} Frank--Wolfe is particularly well-suited when the optimum lies on a constraint boundary.
When $x_1^\star = 0.5$ (lower bound), the LMO consistently selects the vertex with $x_1 = 0.5$, naturally driving the iterate towards the boundary.
Projected gradient descent would also work but requires an explicit projection step; Frank--Wolfe achieves the same effect through the LMO structure of the constraint set, which is often more computationally tractable for high-dimensional structured constraints (e.g., nuclear norm ball, polytopes with combinatorial structure).

\textbf{Key advantage of Frank--Wolfe:} Iterates $x_k$ are always convex combinations of vertices of $\mathcal{X}$, guaranteeing that $x_k \in \mathcal{X}$ without any projection.
This is especially valuable for structured constraint sets where projection is expensive but the LMO (solving a linear programme) is cheap.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This study has systematically compared six families of optimisation algorithms across three benchmark functions of increasing difficulty.
The key conclusions are:

\textbf{Adaptive step-size methods (Q1):}
The Polyak step size achieves optimal convergence when $f^\star$ is exactly known but diverges catastrophically under misspecification.
RMSprop's exponential forgetting addresses Adagrad's vanishing step problem.
Heavy Ball provides a strong practical alternative with well-tuned parameters.

\textbf{Momentum and stochastic methods (Q2):}
Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ first-order rate and dominates all other first-order methods on the Rosenbrock benchmark.
Adam's per-coordinate adaptive scaling is effective on anisotropic problems but less so on highly nonlinear objectives.
Mini-batch SGD demonstrates the bias--variance tradeoff between batch size and per-epoch convergence.

\textbf{Newton's method (Q3):}
Second-order methods dramatically outperform first-order methods when the Hessian is available.
On quadratic objectives, Newton achieves single-step convergence.
The exponential cost ($O(d^3)$ per iteration) limits Newton to small $d$; quasi-Newton methods (e.g., L-BFGS) bridge this gap in practice.

\textbf{Derivative-free optimisation (Q4):}
Forward finite differences with small $\delta$ closely match exact gradient descent at $d+1$ function evaluations per step.
Large $\delta$ causes systematic error that dominates gradient direction quality.
Nesterov random search requires only 2 evaluations per step, making it attractive for high-dimensional black-box optimisation.
Nelder--Mead navigates the Rosenbrock valley effectively without gradients.

\textbf{Constrained optimisation (Q5):}
Projected gradient descent enforces feasibility as a hard constraint at every iterate.
Penalty methods provide a simpler alternative but require $\lambda \to \infty$ for exact feasibility, necessitating careful step size scheduling.
When the unconstrained minimum is feasible (as in this problem), the constrained solution coincides with the unconstrained one, making the constraint inactive at optimality.

\textbf{Frank--Wolfe algorithm (Q6):}
Frank--Wolfe naturally enforces constraints through convex combinations without projection.
It converges at $O(1/k)$ for smooth convex objectives and is particularly effective for structured constraint sets where the linear minimisation oracle is cheap.
Fixed mixing parameters $\beta$ prevent full convergence; the standard decaying schedule $\gamma_k = 2/(k+2)$ is preferred for theoretical guarantees.

def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Regularised Hessian}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}
