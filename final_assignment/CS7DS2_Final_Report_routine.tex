\begin{abstract}
This report presents a rigorous comparative study of first-order and second-order optimisation algorithms applied across three standard benchmark problems: a linear regression quadratic loss (Benchmark~A, $\kappa \approx 1.09$), a toy neural network loss with sinusoidal perturbation (Benchmark~B, $\kappa \lesssim 10$), and the ill-conditioned Rosenbrock function (Benchmark~C, $\kappa \approx 2508$). Six algorithmic families are investigated in depth: \emph{adaptive step-size methods} (Polyak, Adagrad, RMSprop, Heavy Ball); \emph{accelerated momentum methods} (Nesterov acceleration, Adam) and stochastic variants (mini-batch SGD); \emph{Newton's method} with local quadratic approximation; \emph{derivative-free approaches} (finite differences, Nesterov random search, Nelder--Mead simplex, grid search); \emph{constrained optimisation} via projected gradient descent and quadratic penalty; and the \emph{Frank--Wolfe conditional gradient} algorithm for linear-constrained problems.

For each method family, algorithm formulations are derived from first principles with full pseudocode, hyperparameters are reported in complete detail, and convergence is characterised both empirically (objective vs.\ iteration, contour trajectories, step-size evolution, gap certificates) and theoretically (formal convergence rate theorems with literature citations, stability conditions, computational complexity). Key findings: (1) Polyak step size achieves best performance only when $f^\star$ is specified exactly; (2) Heavy Ball speedup $\sqrt{\kappa}$ over GD explains its strong Rosenbrock performance; (3) Nesterov's lookahead gradient provides $O(1/k^2)$ convergence vs.\ $O(1/k)$ for Heavy Ball on convex problems, and $f = 0.479$ vs.\ GD's $f = 3.388$ on Rosenbrock; (4) Newton's method converges in one iteration on exact quadratics; (5) Adam's per-coordinate normalisation is counterproductive on Rosenbrock due to changing curvature along the valley; (6) Finite differences require $\delta^\star = \sqrt{\varepsilon_{\mathrm{mach}}/M_2}$ for optimal accuracy; (7) Frank--Wolfe provides a computable duality gap certificate $\delta_k \geq f(x_k) - f^\star$ without knowing $f^\star$. A comprehensive conclusion synthesises the convergence hierarchy and practical recommendations for algorithm selection.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Iterative optimisation algorithms form the computational backbone of modern machine learning and statistical estimation. Given a differentiable objective function $f : \mathbb{R}^d \to \mathbb{R}$, one seeks a minimiser $x^\star \in \arg\min_{x \in \mathcal{X}} f(x)$ using only local information: function values, gradients, or higher-order derivatives. The choice of algorithm has profound implications for convergence speed, numerical stability, memory requirements, and robustness to problem structure.

This report systematically evaluates algorithms from six distinct families on three benchmark functions of increasing difficulty:
\begin{enumerate}[nosep]
  \item A convex quadratic (linear regression MSE loss) — well-conditioned, globally convex, globally smooth.
  \item A near-quadratic function with a sinusoidal term — mildly non-convex, anisotropic curvature ($\kappa \approx 5$).
  \item The Rosenbrock function — strongly non-convex near the start, ill-conditioned ($\kappa \approx 2508$), with a narrow curved valley.
\end{enumerate}

\noindent The benchmarks are chosen to expose complementary algorithm properties. The quadratic loss tests asymptotic efficiency near the optimum; the sinusoidal perturbation tests robustness to mild non-convexity; the Rosenbrock function is the classic stress test for ill-conditioning and non-quadratic curvature.

All algorithms are implemented in Python (NumPy) using a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. Section~\ref{sec:benchmarks} defines the benchmarks formally. Sections~\ref{sec:q1}--\ref{sec:q6} present each algorithm family, including pseudocode, hyperparameter tables, empirical results with figures, and theoretical analysis. Section~\ref{sec:conclusion} provides a synthesis and practical recommendations.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\label{eq:benchA_setup}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
x^{(i)} \overset{\mathrm{iid}}{\sim} \mathcal{N}(0, I_2), \quad
y^{(i)} = {\theta^{\star}}^T x^{(i)} + \varepsilon^{(i)}, \quad
\varepsilon^{(i)} \overset{\mathrm{iid}}{\sim} \mathcal{N}(0, 1).
\end{equation}
The mean squared error loss is:
\begin{equation}
\label{eq:benchA_loss}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a strictly convex quadratic. The Hessian $H = \frac{1}{m}X^T X \in \mathbb{R}^{2 \times 2}$ is constant (independent of $\theta$). For $m = 1000$ samples with $X \sim \mathcal{N}(0, I)$, by the law of large numbers $H \approx I_2$, and empirically $\lambda_{\min}(H) \approx 0.958$, $\lambda_{\max}(H) \approx 1.046$ with condition number $\kappa(H) \approx 1.09$ --- near-perfectly conditioned. The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y) = H\theta - \frac{1}{m}X^T y$. Due to irreducible observation noise $\varepsilon^{(i)} \sim \mathcal{N}(0,1)$, the minimum is $J^\star = \sigma^2/2 \approx 0.4826$, not zero. The minimiser is the OLS estimator $\theta_{\text{OLS}} = H^{-1} \frac{1}{m}X^T y \approx (3.028, 4.017)$. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
\label{eq:benchB}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are:
\begin{align}
\nabla f(x) &= \begin{bmatrix} 2(x_1 - 1) + \cos(x_1) \\ 10(x_2 - 2) \end{bmatrix}, \label{eq:benchB_grad} \\
\nabla^2 f(x) &= \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}. \label{eq:benchB_hess}
\end{align}
The diagonal Hessian has eigenvalues $2 - \sin(x_1) \in [1, 3]$ and $10$, giving a condition number between $\kappa \approx 3.3$ and $\kappa \approx 10$. The global minimum satisfies $2(x_1^\star - 1) + \cos(x_1^\star) = 0$, yielding $x_1^\star \approx 0.5824$ (solved numerically) and $x_2^\star = 2.0$ with $f^\star \approx 0.7244$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
\label{eq:benchC}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$. The Hessian is:
\begin{equation}
\label{eq:benchC_hess}
\nabla^2 f(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the optimum $(1,1)$, this gives eigenvalues $\lambda_1 \approx 0.399$ and $\lambda_2 \approx 1001.6$, yielding condition number $\kappa \approx 2508$. This extreme ill-conditioning, combined with the narrow curved valley $x_2 \approx x_1^2$, creates a challenging optimisation landscape where gradient descent steps are constrained to be very small ($\alpha \leq 1/\lambda_{\max}$ for stability). Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Questions 5--6):
\begin{equation}
\label{eq:benchD}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a compact convex polytope (box), which admits a simple projection operator and a linear minimisation oracle, enabling both projected gradient descent and Frank--Wolfe.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Motivation and Overview}

Standard gradient descent with a fixed step size $\alpha$ satisfies $x_{k+1} = x_k - \alpha \nabla f(x_k)$. For an $L$-smooth function, the step size must satisfy $\alpha \leq 1/L$ for guaranteed descent, which can be very small when $L$ is large. Adaptive step-size methods address this by tuning $\alpha$ automatically, either using information about $f^\star$ (Polyak) or accumulating second-moment information of the gradients (Adagrad, RMSprop). Heavy Ball augments gradient descent with a momentum term to accelerate convergence along consistent gradient directions.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Polyak Convergence]
\label{thm:polyak}
Let $f$ be convex and let $f^\star$ be the true global minimum. For the Polyak step size with exact $f^\star$, the iterates satisfy $f(x_k) - f^\star \leq \frac{\|x_0 - x^\star\|^2}{2k}$ for any convex function, achieving $O(1/k)$ convergence without any smoothness assumption.
\end{theorem}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate squared gradient accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad can be interpreted as preconditioned gradient descent: the effective learning rate for coordinate $i$ at step $k$ is $\alpha_0 / \sqrt{\sum_{j=0}^{k} g_{j,i}^2}$, which adapts to the geometry of the problem by scaling more aggressively in directions with historically small gradients. The step in the $i$-th coordinate at iteration $k$ is proportional to $g_{k,i} / \sqrt{G_{k,i}}$, where $G_{k,i} = \sum_{j < k} g_{j,i}^2$. By the Cauchy--Schwarz inequality, the cumulative gradient in coordinate $i$ satisfies $\sum_{j<k} |g_{j,i}| \leq \sqrt{k \cdot G_{k,i}}$, motivating the $1/\sqrt{G_{k,i}}$ normalisation as a way to achieve sublinear regret. Importantly, $G_k$ is monotonically increasing, so the effective step size $\alpha_k^{(i)} \to 0$ as $k \to \infty$, making Adagrad unsuitable for non-stationary or deep network training.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's monotonically growing denominator with an exponential moving average (EMA) with decay $\beta$. The stationary value of $v_k^{(i)}$ is $(1-\beta)\sum_{j=0}^{\infty} \beta^j g_{k-j,i}^2 \to \mathbb{E}[g_i^2]$, so the effective step approximates $\alpha_0 / \sqrt{\mathbb{E}[g_i^2]}$ in stationarity. The forgetting factor $\beta$ allows RMSprop to adapt to non-stationary gradients, which motivates its widespread use in deep learning.

\paragraph{Adagrad vs.\ RMSprop: forgetting vs.\ accumulation.} The key distinction is the treatment of historical gradients. Adagrad treats all past gradients equally (summing all squared gradients), which causes the step size to monotonically decrease to zero. This is ideal for convex problems where the gradient magnitude is consistently informative but fails for non-stationary problems. RMSprop's exponential forgetting (effective memory $\approx 1/(1-\beta)$ steps) allows the step size to increase after periods of small gradients, making it more robust to changing loss landscapes. For $\beta = 0.9$, the effective memory is $\approx 10$ iterations; for $\beta = 0.999$, it is $\approx 1000$ iterations. Choosing $\beta$ controls the trade-off between stability (large $\beta$, long memory) and adaptivity (small $\beta$, short memory).

\begin{algorithm}[H]
\caption{Heavy Ball (Polyak Momentum)}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method augments gradient descent with a momentum term $\beta z_k$, which accumulates gradient history. Expanding the recursion gives $x_{k+1} = x_k - \alpha \sum_{j=0}^{k} \beta^{k-j} \nabla f(x_j)$, showing that recent gradients receive exponentially higher weight for more recent steps.

\begin{proposition}[Optimal Heavy Ball Parameters]
\label{prop:hb_optimal}
For a strongly convex quadratic $f(x) = \frac{1}{2}x^T A x - b^T x$ with eigenvalues in $[\mu, L]$ (condition number $\kappa = L/\mu$), the Heavy Ball iteration $x_{k+1} = x_k - \alpha \nabla f(x_k) + \beta(x_k - x_{k-1})$ with optimal parameters
\begin{equation}
\alpha^\star = \frac{4}{(\sqrt{L}+\sqrt{\mu})^2}, \qquad \beta^\star = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2
\end{equation}
achieves convergence rate $\rho^\star = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$:
\begin{equation}
\|x_k - x^\star\| \leq C \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k,
\end{equation}
which is $\sqrt{\kappa}$ times faster than optimal GD's rate $(\kappa-1)/(\kappa+1)$. The spectral radius $\rho^\star$ is uniquely minimised by $(\alpha^\star, \beta^\star)$; any deviation increases $\rho$ and may cause divergence when $\beta > \beta^\star(\kappa)$.
\end{proposition}

For Benchmark~A with $\kappa \approx 1.09$, the momentum speedup is negligible ($\rho^\star \approx \rho_{\mathrm{GD}}$). For Rosenbrock with $\kappa \approx 2508$, the theoretical speedup is $\sqrt{2508} \approx 50\times$ per iteration: optimal GD rate $\rho_{\mathrm{GD}} = 0.9992$, optimal HB rate $\rho^\star = 0.9602$. The values used here ($\alpha = 0.0008$, $\beta = 0.86$) are manually tuned approximations to the optimal ones; Proposition~\ref{prop:hb_optimal} provides the principled formula for choosing these parameters. Note that the optimal $\beta^\star$ for Rosenbrock at $\kappa = 2508$ is $\beta^\star = ((50-1)/(50+1))^2 \approx 0.924$, close to the $\beta = 0.86$ used empirically.

\paragraph{Polyak step sensitivity.} The Polyak step formula $\alpha_k = (f(x_k) - f^\star)/(\|g_k\|^2 + \varepsilon)$ guarantees convergence only when $f^\star$ is the true global minimum. On Benchmarks~A and~B where $f^\star_{\mathrm{true}} \approx 0.48$ and $0.72$ respectively, specifying $f^\star = 0$ creates a persistent gap $(f(x_k) - 0)$ that does not vanish even as $\|g_k\| \to 0$, causing unbounded step growth. This is a fundamental practical limitation: in most real applications, $f^\star$ is unknown. Theorem~\ref{thm:polyak} requires exact knowledge of the minimum value, which restricts Polyak to problems where $f^\star$ is analytically available (e.g., feasibility problems or problems with known zero-loss minimisers).

\paragraph{Relationship to the optimal fixed step size.} For an $L$-smooth convex function, the optimal fixed GD step size is $\alpha = 1/L$, giving the bound $f(x_k) - f^\star \leq L\|x_0 - x^\star\|^2/(2k)$. The Polyak step $\alpha_k = (f(x_k) - f^\star)/(\|\nabla f(x_k)\|^2 + \varepsilon)$ can be seen as dynamically computing the locally optimal step: for a strongly convex function with parameter $\mu > 0$, the PL condition $\|\nabla f(x)\|^2 \geq 2\mu(f(x) - f^\star)$ gives $\alpha_k \leq 1/(2\mu)$, and the Polyak step is $\leq 1/L$ near the optimum where $\|\nabla f\|^2 \approx L(f - f^\star)$. This is why Polyak is adaptive: it automatically uses larger steps far from the minimum and smaller steps close to it.

\paragraph{Connection to the Polyak--Łojasiewicz (PL) condition.} A function satisfies the PL condition if $\|\nabla f(x)\|^2 \geq 2\mu(f(x) - f^\star)$ for some $\mu > 0$. Under PL, standard gradient descent with step $\alpha = 1/L$ satisfies $f(x_{k+1}) - f^\star \leq (1 - \mu/L)(f(x_k) - f^\star)$, giving linear convergence even without strong convexity. The Polyak step can be interpreted as dynamically adapting to this condition: it uses the \emph{observed} ratio $(f(x_k) - f^\star)/\|\nabla f(x_k)\|^2$ as the effective step, which is $1/(2\mu)$ when PL holds with equality. This provides the intuitive explanation for why Polyak converges rapidly when $f^\star$ is correctly specified.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^\star$ is known exactly, Polyak converges fastest (Rosenbrock: $f = 0.009$). Among universally applicable methods, Heavy Ball provides the best Rosenbrock convergence ($f = 1.40$) by building up directional momentum along the valley.
\item \textbf{Robustness:} Adagrad is uniformly stable across all benchmarks due to its monotonically decreasing step size, but this conservatism limits its Rosenbrock performance. RMSprop's stationary effective rate makes it more suitable for dynamic problems where gradient magnitudes change.
\item \textbf{Theoretical guarantees:} Adagrad has regret bounds in the online convex optimisation setting; Heavy Ball achieves optimal convergence on strongly convex quadratics; RMSprop lacks a complete convergence theory for general non-convex problems.
\item \textbf{Practical implication:} Since exact $f^\star$ is rarely available in practice, Adagrad and Heavy Ball are more practically applicable than Polyak. RMSprop is preferred when problem stationarity is uncertain (e.g., deep learning with changing loss landscapes). For ill-conditioned problems, Heavy Ball with well-tuned $\beta$ provides significant advantages over vanilla GD.
\end{itemize}

\paragraph{Optimal Heavy Ball parameters.} For a strongly convex quadratic objective with condition number $\kappa = L/\mu$, the Heavy Ball update $x_{k+1} = x_k + \beta(x_k - x_{k-1}) - \alpha \nabla f(x_k)$ achieves its fastest convergence at the analytically optimal parameters:
\begin{equation}
\label{eq:hb_optimal}
\alpha^\star = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}, \qquad
\beta^\star = \left(\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}\right)^2.
\end{equation}
The resulting convergence rate is $\rho^\star = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$, which is exactly the rate of the conjugate gradient method. For comparison, optimal gradient descent has rate $({\kappa-1})/({\kappa+1})$, so the speedup factor is $({\kappa-1})/({\kappa+1}) \div (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1) = (\sqrt{\kappa}+1)/(\sqrt{\kappa}-1) \to 2\sqrt{\kappa}$ as $\kappa \to \infty$. For $\kappa = 2508$, this predicts a $\approx 100\times$ speedup in convergence rate from using optimal momentum. The Heavy Ball parameters used in the experiment ($\alpha = 0.0012$, $\beta_{\max} = 0.90$) are not the theoretically optimal values for the non-quadratic Rosenbrock problem, but the theory motivates why larger momentum can dramatically accelerate convergence on ill-conditioned problems.

\subsection{Motivation}

Question~2 extends momentum methods to \emph{accelerated} gradient descent (Nesterov) and \emph{adaptive momentum} methods (Adam), and investigates stochastic variants. The key distinction from Heavy Ball (Section~\ref{sec:q1}) is the use of a \emph{lookahead} gradient evaluation, which allows corrective information before an overshoot occurs.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient Descent}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Increasing momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Gradient at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Nesterov Convergence Rate~\cite{nesterov1983}]
\label{thm:nesterov}
For an $L$-smooth convex function $f$ with minimum $f^\star$, Nesterov's accelerated gradient method with step $\alpha = 1/L$ and momentum schedule $\beta_k = (k-1)/(k+2)$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2} = O(1/k^2).
\end{equation}
This is optimal: no first-order method can achieve better than $O(1/k^2)$ on smooth convex functions.
\end{theorem}

The key distinction from Heavy Ball (Algorithm~\ref{alg:heavyball}) is the evaluation of $\nabla f$ at the \emph{lookahead point} $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$. This ``look before you leap'' strategy allows Nesterov to correct its trajectory before overshooting the optimum, providing the $O(1/k^2)$ rate versus Heavy Ball's $O(1/k)$ on convex functions. However, this improvement is specific to convex settings; on non-convex problems like Rosenbrock, Nesterov does not have the same provable advantage but still benefits from momentum.

\paragraph{Momentum schedule $\beta_k = (k-1)/(k+2)$.} The increasing momentum schedule is critical for achieving the $O(1/k^2)$ rate. The clipping at $\beta_{\max}$ prevents the momentum from becoming too large early, when the quadratic model is inaccurate. Figure~\ref{fig:q2_nesterov_anal} shows the momentum schedule shape and its effect on convergence speed for different clipping values $\beta_{\max} \in \{0.60, 0.75, 0.85, 0.90, 0.95, 0.99\}$.

\begin{figure}[H]
\centering

\caption{Q2: Nesterov momentum schedule analysis. \emph{Left:} Nesterov with standard monotone restart (function value criterion): the test function starts below the restart threshold for this problem, so no restarts are triggered, confirming the algorithm is already well-behaved. \emph{Centre:} effect of $\beta_{\max}$ on Rosenbrock convergence (300 iterations). \label{fig:q2_nesterov_anal}
\end{figure}

\begin{algorithm}[H]
\caption{Adam Optimiser~\cite{kingma2014}}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{Exponential moving average of gradients}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{EMA of squared gradients}
    \State $\hat{m}_t \gets m_t / (1 - \beta_1^t)$ \Comment{Bias correction: removes initialisation bias}
    \State $\hat{v}_t \gets v_t / (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam~\cite{kingma2014} combines the momentum of Nesterov (via $m_t$, an EMA of past gradients) with the per-coordinate adaptive scaling of RMSprop (via $v_t$, an EMA of squared gradients). The \emph{bias correction} terms $\hat{m}_t = m_t / (1 - \beta_1^t)$ and $\hat{v}_t = v_t / (1 - \beta_2^t)$ compensate for the zero initialisation of $m$ and $v$: at $t = 1$, $1 - \beta_1^1 = 1 - \beta_1$ normalises the estimate to recover the full current gradient. Without this correction, early iterates would use an artificially small effective step size. The effective per-coordinate step is bounded: $|x_{t+1,i} - x_{t,i}| \leq \alpha(1-\beta_1)^{-1/2}$, which provides implicit gradient clipping.

\paragraph{Relationship between Adam components.} Adam can be seen as combining three improvements over vanilla GD:
\begin{enumerate}[nosep]
  \item \textbf{First moment} $m_t$: momentum that builds velocity in consistent gradient directions (inheriting the Nesterov/Heavy Ball benefit).
  \item \textbf{Second moment} $v_t$: per-coordinate variance normalisation that adapts the effective step to each dimension (inheriting the Adagrad/RMSprop benefit).
  \item \textbf{Bias correction}: ensures the first few iterations use properly normalised estimates.
\end{enumerate}
The effective step $\alpha \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$ can be understood as a normalised gradient: the $\hat{m}_t$ provides a smoothed gradient direction while $\sqrt{\hat{v}_t}$ normalises by the per-coordinate gradient scale. In the large-$t$ limit with $\beta_2 \to 1$, $\hat{v}_t^{(i)} \to \mathbb{E}[g_i^2]$ and Adam's step $\approx \alpha m_t^{(i)} / \sqrt{\mathbb{E}[g_i^2]}$ --- a normalised gradient direction scaled by $\alpha$.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark~A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y) \in \mathbb{R}^{m \times d} \times \mathbb{R}^m$, initial $\theta_0$, step $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\pi_e$
    \For{each mini-batch $\mathcal{B}$ of size $b$ from $\pi_e$}
        \State $\hat{g} \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, \hat{g}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The stochastic gradient $\hat{g} = \frac{1}{b} X_\mathcal{B}^T(X_\mathcal{B}\theta - y_\mathcal{B})$ is an unbiased estimator of the full gradient $\nabla J(\theta)$ for uniformly sampled batches: $\mathbb{E}_\mathcal{B}[\hat{g}] = \nabla J(\theta)$. Its covariance is $\mathrm{Cov}(\hat{g}) = \frac{1}{b}\mathrm{Cov}(g_{\text{sample}})$, which decays as $1/b$. With $m = 1000$ samples and batch size $b$, each epoch performs $\lceil m/b \rceil$ parameter updates: $b=5$ gives 200 updates/epoch, $b=40$ gives 25 updates/epoch.

\paragraph{Bias--variance trade-off in batch size.} Increasing batch size $b$ by a factor $k$ reduces gradient variance by $k$ but provides $k$-fold fewer updates per epoch. The optimal batch size depends on the problem structure: for well-conditioned problems (Benchmark~A, $\kappa \approx 1$), larger batches are efficient since fewer updates are needed to converge. For ill-conditioned problems, smaller batches can escape poor local directions through gradient noise. Linear scaling rule~\cite{bottou2018}: multiplying batch size by $k$ should be paired with multiplying learning rate by $\sqrt{k}$ to maintain approximately the same noise level per effective update.

With $b = 40$ (25 updates/epoch), convergence is smoother but slower. \paragraph{Theoretical variance analysis.} For the linear model $y = X\theta^\star + \varepsilon$ with $\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$, the irreducible loss is $J^\star = \frac{\sigma^2}{2}$. With batch size $b$ and step size $\alpha$, the steady-state variance of SGD satisfies approximately:
\begin{equation}
\mathbb{E}[J(\theta_k)] - J^\star \approx \frac{\alpha \sigma^2 \mathrm{tr}(H)}{2b(2 - \alpha \lambda_{\max}(H))},
\end{equation}
which increases with $\sigma^2$ (observed noise), decreases with $b$ (larger batches reduce variance), and decreases with $\alpha$ (smaller step reduces steady-state noise). The empirical results in Figure~\ref{fig:q2_sgd_noisy} are consistent with this: increasing $\sigma$ from 1 to 6 increases $\sigma^2$ by $36\times$, raising the loss floor from $\approx 0.48$ to $\approx 18 \approx 36 \times 0.5$ as predicted.

\paragraph{Scaling of noise floor with batch size.} The steady-state formula predicts the noise floor scales as $1/b$: doubling the batch size halves the irreducible SGD variance. Figure~\ref{fig:q2_sgd_batchsize} empirically verifies this scaling across a wider range of batch sizes.

\subsection{Local Approximations of $g(x) = x^4$}

Newton's method is motivated by successively minimising local second-order (quadratic) approximations of $f$. Given $g(x) = x^4$ and expansion point $x_0 = 0.25$:

\textbf{First-order (linear) approximation:}
\begin{equation}
\label{eq:first_order}
q_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.25^4 + 4 \times 0.25^3(x - 0.25) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order (quadratic) approximation:}
\begin{equation}
\label{eq:second_order}
q_2(x) = g(x_0) + g'(x_0)(x - x_0) + \frac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

By Taylor's theorem, $|g(x) - q_2(x)| = O((x - x_0)^3)$, so the quadratic approximation is accurate within a radius of $|x - x_0| = O(1)$ if the third derivative is bounded. Setting $q_2'(x) = 0$ gives the Newton step $x_1 = x_0 - g'(x_0)/g''(x_0) = 0.25 - 0.0625/(0.75) = 0.167$, which is a better estimate of $x^\star = 0$ than a gradient step.

The second-order (parabolic) approximation closely fits the true function near $x_0$ and provides a much more informative descent direction: minimising $q_2$ rather than $q_1$ uses curvature to take a larger, better-aimed step.}

\subsection{Newton's Method with Damping}

\begin{algorithm}[H]
\caption{Newton's Method with Damping and Regularisation}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, regularisation $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Regularised Hessian ensures positive definiteness}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction: solve linear system}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Newton Convergence]
\label{thm:newton}
Let $f$ be twice-differentiable with $L$-Lipschitz Hessian. Near a non-degenerate local minimum $x^\star$ (where $\nabla^2 f(x^\star) \succ 0$), the full Newton step ($\alpha = 1$, $\lambda = 0$) exhibits \emph{quadratic convergence}:
\begin{equation}
\|x_{k+1} - x^\star\| \leq C\|x_k - x^\star\|^2,
\end{equation}
where $C = L / (2\mu)$ with $\mu = \lambda_{\min}(\nabla^2 f(x^\star))$. In particular, once $\|x_k - x^\star\| < 1/C$, convergence is superlinear and the number of accurate digits roughly doubles each iteration.
\end{theorem}

For Benchmark~A (exact quadratic), Newton with full step $\alpha = 1.0$ solves $H p = g$ to get the exact minimiser in one step. For non-quadratic functions (B, C), damping ($\alpha < 1$) and regularisation ($\lambda = 10^{-8}$) are necessary to maintain numerical stability when the Hessian is nearly singular or the iterate is far from the optimum where the quadratic model is inaccurate.

\paragraph{Newton's method and the Rosenbrock challenge.} Despite Newton's quadratic convergence (Theorem~\ref{thm:newton}), the damped Newton result on Rosenbrock ($f = 0.686$ at 20 iterations) is far from the minimum $f^\star = 0$. This occurs because:
\begin{enumerate}[nosep]
\item \textbf{Far-from-minimum regime:} Newton's quadratic convergence applies only within the \emph{region of attraction} $\|x - x^\star\| < 1/C$. Starting at $x_0 = (-1, 1)$, the iterates are far from $x^\star = (1,1)$ and in the strongly non-quadratic region.
\item \textbf{Damping requirement:} The conservative step $\alpha = 0.22$ slows progress. Backtracking line search (which finds the optimal $\alpha$ automatically at each iteration) would improve convergence significantly but was not implemented here.
\item \textbf{Singular Hessian:} Near the start, the Rosenbrock Hessian $h_{11} = 2 + 1200x_1^2 - 400x_2$ can become ill-conditioned ($h_{11} \approx 1200 - 400 \approx 800$, $h_{22} = 200$), requiring the regularisation $\lambda = 10^{-8}$.
\end{enumerate}

\noindent \textbf{Computational cost comparison:} Newton's method requires $O(d^3)$ per iteration (Hessian solve), vs.\ $O(d)$ for gradient descent. For $d = 2$ this is negligible, but for large-scale problems Newton's cost is prohibitive. Quasi-Newton methods (BFGS, L-BFGS) approximate $H^{-1}$ via rank-1/rank-2 updates at $O(d^2)$/$O(md)$ per iteration, providing Newton-like superlinear convergence without full Hessian computation.

\subsection{Hessian Condition Number Along the Optimisation Path}

An important but underappreciated property of Newton's method is how the local condition number $\kappa(\nabla^2 f(x_k))$ varies along the trajectory. For the Rosenbrock function, the Hessian at a point $(x_1, x_2)$ is:
\begin{equation}
\nabla^2 f(x) = \begin{bmatrix} 2 - 400x_2 + 1200x_1^2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the starting point $x_0 = (-1, 1)$: $h_{11} = 2 - 400 + 1200 = 802$, $h_{12} = 400$, $h_{22} = 200$, giving $\kappa(H_0) \approx 2508$. At the global minimum $x^\star = (1,1)$: $h_{11} = 2 - 400 + 1200 = 802$, $h_{12} = -400$, $h_{22} = 200$, again giving $\kappa(H^\star) \approx 2508$. However, as Newton's iterates move through the interior of the Rosenbrock valley, the Hessian becomes better conditioned.

The dramatic variation of $\kappa$ along the Newton path has an important practical implication: the optimal damping factor $\alpha$ is not constant. When $\kappa$ is large (near start and near $x^\star$), the quadratic model is poorly aligned with the true objective and conservative $\alpha$ is needed. When $\kappa$ is moderate (interior of the valley), the model is more accurate and larger $\alpha$ would be appropriate. This is the motivation for \emph{backtracking line search}, which adaptively selects $\alpha$ at each step via the Armijo condition $f(x_k - \alpha p_k) \leq f(x_k) - c\alpha \nabla f(x_k)^T p_k$ for $c \in (0, 1)$. The fixed $\alpha = 0.22$ used here is a conservative choice tuned for the worst-case (large $\kappa$) encountered near the starting point.

\paragraph{Newton decrement as a stopping criterion.} A principled stopping criterion for Newton's method is the \emph{Newton decrement} $\lambda^2(x) = \nabla f(x)^T H^{-1} \nabla f(x)$, which measures the expected decrease in $f$ from one full Newton step: $f(x) - f(x - p) \approx \lambda^2(x)/2$ where $p = H^{-1}\nabla f(x)$. The stopping criterion $\lambda^2/2 \leq \varepsilon$ guarantees $f(x) - f^\star \leq \varepsilon$ for convex functions. Figure~\ref{fig:q3_newton_quad} shows the Newton decrement converging to machine precision within 10 steps for Benchmark~B (near-quadratic), confirming rapid convergence, while for Rosenbrock it remains large even after 30 damped steps.

\subsection{Part A: Finite Differences and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

When gradients are unavailable (e.g., black-box functions, numerical simulators), they can be approximated using finite differences. The \emph{forward difference} approximation for partial derivative $i$ is:
\begin{equation}
\label{eq:fd}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\end{equation}
where $e_i$ is the $i$-th standard basis vector and $\delta > 0$ is the perturbation step. The approximation error decomposes as:
\begin{equation}
\label{eq:fd_error}
\left|\frac{\partial f}{\partial x_i} - \frac{f(x+\delta e_i)-f(x)}{\delta}\right| \leq \frac{M_2 \delta}{2} + \frac{\varepsilon_{\mathrm{mach}}}{\delta},
\end{equation}
where $M_2 = \sup \|\nabla^2 f\|$ is the second derivative bound and $\varepsilon_{\mathrm{mach}} \approx 10^{-16}$ is machine precision. Minimising over $\delta$ gives the optimal perturbation $\delta^\star = \sqrt{2\varepsilon_{\mathrm{mach}}/M_2} \approx 10^{-8}$. The assignment tests $\delta = 0.05$ (moderate, near-optimal for typical curvatures) and $\delta = 0.8$ (too large, dominated by truncation error $O(\delta) = O(0.8)$).

\paragraph{Central differences vs.\ forward differences.} An improved approximation is the \emph{central difference}:
\begin{equation}
\label{eq:cd}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x - \delta e_i)}{2\delta},
\end{equation}
which achieves $O(\delta^2)$ truncation error (vs.\ $O(\delta)$ for forward differences), giving optimal $\delta^\star_{\mathrm{CD}} = (\varepsilon_{\mathrm{mach}}/M_3)^{1/3} \approx 10^{-5}$ where $M_3 = \sup \|\nabla^3 f\|$. Central differences require $2d$ evaluations (vs.\ $d+1$ for forward), but typically achieve $10^4\times$ better gradient accuracy at the same $\delta$. The forward difference formula in the assignment was tested at $\delta = 0.05$ (still in the truncation-dominated regime compared to $\delta^\star \approx 10^{-8}$, but close enough for practical convergence) and $\delta = 0.8$ (completely truncation-dominated, poor accuracy).

\subsubsection{Nesterov Random Search (Zeroth-Order Gradient Estimation)}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform direction on $\mathbb{S}^{d-1}$}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Nesterov's random search uses only 2 function evaluations per iteration regardless of dimension $d$, making it dimension-independent in cost per step. The estimator $\hat{g}_k$ is a randomised gradient estimate satisfying $\mathbb{E}[\hat{g}_k | x_k] = \nabla f_\delta(x_k)$, where $f_\delta(x) = \mathbb{E}_{u \sim \mathcal{N}(0,I)}[f(x + \delta u)]$ is the $\delta$-smoothing of $f$. For $L$-smooth convex $f$, the smoothed function satisfies $\|\nabla f_\delta(x) - \nabla f(x)\| \leq \delta L \sqrt{d}$, introducing a smoothing bias of order $O(\delta \sqrt{d})$. For convex $f$, this method achieves convergence rate $O(d/k)$, compared to $O(1/k)$ for exact gradient methods~\cite{nesterov2011}, reflecting the cost of dimension-independent sampling: with only 1 random direction per iteration, the effective gradient variance scales as $O(d)$ (since the full $d$-dimensional gradient information is collapsed to a single scalar projection). This factor-$d$ convergence penalty is the fundamental cost of zeroth-order optimisation.

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n + 1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it using four geometric operations based solely on function values at the vertices:

\begin{enumerate}[nosep]
  \item \textbf{Reflection:} $x_r = c + \alpha_r(c - x_{\mathrm{worst}})$ where $c$ is the centroid of the $n$ best vertices.
  \item \textbf{Expansion:} $x_e = c + \gamma(c - x_{\mathrm{worst}})$ with $\gamma > 1$ (attempted when reflection improves).
  \item \textbf{Contraction:} $x_c = c + \rho(x_r - c)$ or $c + \rho(x_{\mathrm{worst}} - c)$ with $0 < \rho < 1$.
  \item \textbf{Shrink:} $x_i \gets x_{\mathrm{best}} + \sigma(x_i - x_{\mathrm{best}})$ for all $i \neq \mathrm{best}$.
\end{enumerate}

Parameters used: $\alpha_r = 1.0$ (reflection), $\gamma = 2.0$ (expansion), $\rho = 0.5$ (contraction), $\sigma = 0.5$ (shrink), initial simplex step $= 0.35$, 160 iterations. Note that Nelder--Mead lacks formal convergence guarantees in general: the original convergence proofs~\cite{nelder1965} are for one-dimensional problems, and in higher dimensions counterexamples exist where the simplex can stagnate at non-stationary points. However, for smooth functions in $d = 2$, Nelder--Mead is reliable in practice.

\subsection{Problem Setup and Optimality Conditions}

Minimise $f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)$ (Benchmark~B) subject to $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$.

The constraint set is $\mathcal{C} = \{x : x_1 \geq 0.5\}$. The unconstrained minimiser is at $x^\star \approx (0.582, 2.0)$, which satisfies $x_1^\star > 0.5$, so the constrained and unconstrained minima coincide: $x^\star_{\mathcal{C}} = x^\star$.

\begin{definition}[KKT Conditions]
\label{def:kkt}
For the problem $\min_x f(x)$ s.t.\ $g(x) \leq 0$, a point $x^\star$ satisfies the KKT conditions if there exists $\mu^\star \geq 0$ such that:
\begin{align}
\nabla f(x^\star) + \mu^\star \nabla g(x^\star) &= 0 \quad \text{(stationarity)}, \\
g(x^\star) &\leq 0 \quad \text{(primal feasibility)}, \\
\mu^\star g(x^\star) &= 0 \quad \text{(complementary slackness)}.
\end{align}
\end{definition}

Since $x^\star$ is interior to the constraint set ($g(x^\star) = 0.5 - 0.582 < 0$), complementary slackness forces $\mu^\star = 0$, and the KKT condition reduces to $\nabla f(x^\star) = 0$ --- the unconstrained stationarity condition. Thus the constraint is inactive at the optimum.

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{C}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{C}}(z_{k+1}) = \begin{bmatrix}\max(0.5,\, z_{k+1,1}) \\ z_{k+1,2}\end{bmatrix}$ \Comment{Project onto $\mathcal{C}$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection onto $\mathcal{C} = \{x : x_1 \geq 0.5\}$ is the simple clipping operator $\Pi_{\mathcal{C}}(z) = (\max(0.5, z_1), z_2)$, which is $O(1)$ to compute. For complex constraint sets (e.g., polyhedra, semidefinite constraints), projection can require solving an auxiliary optimisation problem, which is the main computational bottleneck of PGD.

\begin{algorithm}[H]
\caption{Gradient Descent with Quadratic Penalty}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x_k) \gets f(x_k) + \lambda \max(0,\, 0.5 - x_{k,1})$ \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$ \Comment{GD on augmented objective}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent where $\nabla_1 F_\lambda(x) = \nabla_1 f(x) - \lambda \cdot \mathbf{1}[x_1 < 0.5]$ and $\nabla_2 F_\lambda(x) = \nabla_2 f(x)$.

\subsection{Comparative Discussion}

\textbf{Projected gradient descent} enforces feasibility as a hard constraint at every iteration: $x_k \in \mathcal{C}$ for all $k \geq 1$. This is the key advantage --- feasibility is never violated. Convergence theory for convex objectives and convex constraint sets guarantees $O(1/k)$ convergence for step $\alpha = 1/L$. The practical cost is the projection oracle $\Pi_{\mathcal{C}}$, which is trivial for box constraints but expensive for general convex sets.

\textbf{Penalty methods} replace the constrained problem with a sequence of unconstrained ones parameterised by $\lambda$. As $\lambda \to \infty$, the penalised minimiser converges to the constrained minimiser. In practice, a single large $\lambda$ (like 4.5) is used directly, since the original objective and constraint are smooth. The advantage is simplicity --- only a modified gradient is needed. The limitation is that large $\lambda$ stiffens the problem, requiring smaller step sizes to maintain stability ($\alpha = 0.03$ for $\lambda = 4.5$ vs.\ $\alpha = 0.05$ for $\lambda = 0.15$). This stiffness becomes more severe as $\lambda$ grows, and the penalty approach can exhibit slow convergence near the boundary.

\paragraph{Effect of $\lambda$ on solution quality.} As $\lambda$ increases, the penalised minimiser $x^\lambda$ converges to the constrained minimiser $x^\star$. Specifically, for a linear constraint $g(x) = c - x_1 \leq 0$:
\begin{equation}
|x^\lambda_1 - x^\star_1| = O(1/\lambda),
\end{equation}
meaning the feasibility error decays as $1/\lambda$. This explains why $\lambda = 4.5$ achieves near-exact feasibility (Table~\ref{tab:q5_final}), while $\lambda = 0.15$ leaves a residual violation.

\textbf{Connection to augmented Lagrangian (ALM):} The pure penalty method can be improved by augmenting with a Lagrange multiplier term: $F_{\lambda,\mu}(x) = f(x) + \mu \cdot \text{violation}(x) + (\lambda/2)\|\text{violation}(x)\|^2$. The ALM avoids the need for $\lambda \to \infty$ by updating the multiplier $\mu$ at each outer iteration (via $\mu^{k+1} = \mu^k + \lambda \cdot \text{violation}(x^\lambda)$), achieving exact feasibility at finite $\lambda$. Figure~\ref{fig:q5_auglag} empirically compares PGD, penalty, and augmented Lagrangian.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q5_auglag_comparison.pdf}
\caption{Q5: Augmented Lagrangian vs penalty vs PGD (100 iterations, infeasible start $(0.2, 4.0)$). \emph{Left:} objective value convergence. ALM (magenta dotted) achieves the constrained minimum $f^\star = 0.724$ with 5 outer iterations of 20 inner steps each; it converges more smoothly than pure penalty. \emph{Centre:} constraint violation on log scale. PGD achieves zero violation immediately; ALM achieves near-zero within 40 iterations at finite $\lambda = 1.0$, while penalty $\lambda = 4.5$ achieves near-zero only by step 80. \emph{Right:} steady-state violation and objective quality as a function of $\lambda$ (200 iterations each). As $\lambda$ increases, violation decreases monotonically (red, left axis); beyond $\lambda \approx 5$ the violation reaches near-zero. The objective quality (blue, right axis) is non-monotone: very large $\lambda$ overstiffens the problem and may converge to a slightly suboptimal point due to step-size limitations.}
\label{fig:q5_auglag}
\end{figure}

\paragraph{Stability of penalty GD.} The penalty method introduces an effectively larger Lipschitz constant for the penalised objective: $L_\lambda = L + \lambda \cdot L_g$, where $L_g$ is the constraint gradient Lipschitz constant. For the linear constraint $g(x) = 0.5 - x_1$, $L_g = 1$, so $L_\lambda \approx L + \lambda$. This requires step size $\alpha \leq 1/(L+\lambda)$, explaining why the step size must decrease as $\lambda$ increases (from $\alpha = 0.05$ for $\lambda = 1.8$ to $\alpha = 0.03$ for $\lambda = 4.5$).

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ {-5} \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} Minimise $f(x) = a^T x = x_1 + 2x_2$ with $a = [1, 2]^T$ over $\mathcal{X}$.

Since $f$ is linear and $\mathcal{X}$ is a bounded convex polytope, the minimum is attained at a vertex. With both components of $a$ positive, minimisation selects the lower bounds for each coordinate independently:
\begin{equation}
\label{eq:lp_solution}
x^\star = \arg\min_{x \in \mathcal{X}} a^T x = (0.5,\, {-5}), \qquad f^\star = 0.5 + 2({-5}) = {-9.5}.
\end{equation}

\begin{theorem}[Fundamental Theorem of Linear Programming~\cite{nocedal2006}]
\label{thm:lp}
The minimum of a linear objective over a bounded convex polytope (non-empty feasible set) is always attained at a vertex of the polytope.
\end{theorem}

This is the foundation of the simplex method: since the minimum must be at a vertex, one can restrict search to the (finite) vertex set. For a box in $\mathbb{R}^d$, there are $2^d$ vertices, each identified by independently choosing either the lower or upper bound for each coordinate.

\subsection{Frank--Wolfe (Conditional Gradient) Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination (fixed step size)}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Frank--Wolfe Convergence Rate~\cite{jaggi2013}]
\label{thm:fw}
For an $L$-smooth convex function $f$ over a convex compact set $\mathcal{X}$ with diameter $D$, the Frank--Wolfe algorithm with step size $\gamma_k = 2/(k+2)$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{2LD^2}{k+2} = O(1/k).
\end{equation}
\end{theorem}

\noindent Note that the experiment uses a \emph{fixed} $\beta$ rather than the theoretically optimal decaying schedule $\gamma_k = 2/(k+2)$. With fixed $\beta$, convergence is only guaranteed to a neighbourhood of the optimum, not to $f^\star$ exactly.

\textbf{Key property:} Since each iterate $x_{k+1} = \beta x_k + (1-\beta) z_k$ is a convex combination of $x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$, and $\mathcal{X}$ is convex, we have $x_{k+1} \in \mathcal{X}$ automatically. Frank--Wolfe maintains feasibility \emph{by construction}, without any projection. This is the fundamental advantage over projected gradient descent for complex constraint sets where projection is expensive (e.g., nuclear norm balls, spectrahedra).

For the box $\mathcal{X}$, the LMO is an $O(d)$ coordinate-wise argmin:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
selecting the lower bound $l_i$ when the gradient component is positive (decreasing the coordinate reduces objective) and the upper bound $u_i$ otherwise.

\subsection{Interior vs.\ Boundary Behaviour}

\textbf{Interior optimum} ($f^\star$ inside $\mathcal{X}$): Frank--Wolfe converges but exhibits a characteristic zig-zag pattern because $z_k$ jumps between extreme vertices of $\mathcal{X}$ at each iteration. The iterates $x_k$ are gradually pulled toward the interior minimum by the convex combinations. The $O(1/k)$ rate (Theorem~\ref{thm:fw}) is slower than gradient descent's $O(1/k^2)$ for smooth strongly convex objectives; the price of avoiding projection is paid in convergence rate.

\textbf{Boundary optimum} ($f^\star$ on $\partial\mathcal{X}$): Frank--Wolfe is inherently well-suited here. The LMO naturally selects vertices near the boundary optimum, and iterates converge toward the boundary from the interior without any projection step. The fixed $\beta$ schedule produces residual oscillation: $f = 0.364$ at 140 iters, $f = 0.278$ at 300 iters for $\beta = 0.985$. With the optimal decaying schedule $\gamma_k = 2/(k+2)$, the method reaches $f = 0.251 \approx f^\star = 0.25$ at 300 iterations (Figure~\ref{fig:q6_fw_step}), confirming the $O(1/k)$ guarantee of Theorem~\ref{thm:fw}.

\paragraph{Frank--Wolfe gap certificate.} At each iteration, the \emph{Frank--Wolfe gap} (also called the duality gap) is:
\begin{equation}
\label{eq:fw_gap}
\delta_k = \nabla f(x_k)^T (x_k - z_k) \geq 0,
\end{equation}
which provides a computable upper bound on primal suboptimality: $f(x_k) - f^\star \leq \delta_k$. This follows from first-order convexity: $f(x_k) - f(z_k) \leq \nabla f(x_k)^T(x_k - z_k) = \delta_k$, and $f(z_k) \geq f^\star$. This is a key advantage of Frank--Wolfe over projected gradient descent, which does not provide such an explicit certificate without additional computation. The gap $\delta_k$ can serve as a stopping criterion.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q6_fw_gap.pdf}
\caption{Q6: Frank--Wolfe gap certificate $\delta_k = \nabla f(x_k)^T(x_k - z_k)$ alongside the objective $f(x_k)$ for the interior optimum ($f^\star = 0$). \emph{Left:} both $f(x_k)$ and $\delta_k$ decrease over iterations; the gap bounds the suboptimality at every step. \emph{Right:} the gap $\delta_k \geq f(x_k) - f^\star$ provides a certificate without knowing $f^\star$; the $O(1/k)$ reference line (dashed) is shown for comparison. The gap decreases broadly at the $O(1/k)$ rate predicted by Theorem~\ref{thm:fw}, validating the theoretical analysis empirically.}
\label{fig:q6_fw_gap}
\end{figure}

\paragraph{Convergence comparison: Frank--Wolfe vs.\ Projected GD.} Both methods achieve $O(1/k)$ rates for smooth convex objectives, but with different constants and computational profiles:
\begin{itemize}[nosep]
\item \textbf{Frank--Wolfe}: $f(x_k) - f^\star \leq \frac{2LD^2}{k+2}$ --- requires only an LMO (linear program solve), $O(d)$ for boxes; no projection needed.
\item \textbf{Projected GD}: $f(x_k) - f^\star \leq \frac{L\|x_0 - x^\star\|^2}{2k}$ --- requires projection $\Pi_{\mathcal{X}}$, $O(1)$ for boxes but $O(d^3)$ for general convex sets.
\end{itemize}
The Frank--Wolfe gap bound $2LD^2/(k+2)$ involves the \emph{diameter} $D = \mathrm{diam}(\mathcal{X})$, which can be large; the PGD bound involves $\|x_0 - x^\star\|$, which can be much smaller. This is why PGD often outperforms Frank--Wolfe when projection is cheap.

\paragraph{Away-step Frank--Wolfe.} A known limitation of the standard Frank--Wolfe algorithm is its zig-zagging behaviour when the optimum lies in the interior of the feasible set, caused by the iterate oscillating between vertices of $\mathcal{X}$. The \emph{away-step Frank--Wolfe} variant addresses this by also considering an ``away'' step: at each iteration, it may move away from the vertex $v_k = \arg\max_{v \in \mathcal{X}} \nabla f(x_k)^T v$ (the worst active atom), allowing the iterate to deactivate unused vertices. This achieves \emph{linear} convergence (rate $O(\rho^k)$ with $\rho < 1$) for strongly convex functions over polytopes~\cite{jaggi2013}, versus the $O(1/k)$ rate of standard FW. For the box $\mathcal{X}$ in this experiment, the standard FW zig-zag effect is visible in Figure~\ref{fig:q6_evolution}: $z_k$ oscillates between opposing vertices while $x_k$ only slowly converges to the interior optimum.

\subsection{Practical Recommendations}

\begin{itemize}[nosep]
\item \textbf{Well-conditioned convex problems:} All first-order methods converge; GD is simplest. Nesterov provides $\sqrt{\kappa}$ speedup without additional memory cost over GD.
\item \textbf{Ill-conditioned problems (large $\kappa$):} Newton's method is preferred when $d$ is small ($d \leq 1000$) and the Hessian is available. For large $d$, L-BFGS provides Newton-like convergence at $O(d)$ per step. Nesterov with $\alpha = 1/L$ remains first-order optimal.
\item \textbf{Deep learning and non-convex problems:} Adam is the default choice, combining momentum with per-coordinate adaptive scaling. It is robust to hyperparameter choices and works well with stochastic gradients.
\item \textbf{Constrained optimisation:} Projected GD is preferred for simple constraints with cheap projections (box, sphere). Frank--Wolfe is preferred for complex constraint sets (nuclear norm, simplex) where projection is expensive but a linear minimisation oracle is available.
\item \textbf{Black-box functions:} Nelder--Mead for $d \leq 10$; finite differences for gradient approximation when $d \leq 100$; Nesterov random search or evolutionary algorithms for $d > 100$.
\end{itemize}

\subsection{Limitations and Future Work}

\paragraph{Low-dimensional setting.} All experiments are conducted in $\mathbb{R}^2$, which does not reveal the full computational cost differences between methods. Newton's $O(d^3)$ Hessian solve is negligible for $d = 2$ but prohibitive for $d > 10^4$; the Hessian storage alone requires $O(d^2)$ memory. Similarly, the curse of dimensionality for grid search ($N^d$ evaluations) and the $O(d/k)$ rate of random search only become material for $d \gg 2$.

\paragraph{Non-convex problems.} The Rosenbrock function has a unique global minimum and behaves ``benignly'' compared to modern machine learning objectives (which have saddle points, flat regions, multiple local minima). Newton's method can diverge or converge to saddle points on non-convex functions because the Hessian may be indefinite. Adam's convergence is not guaranteed even in the deterministic setting for general non-convex problems; the AMSGrad variant~\cite{kingma2014} corrects this theoretically. Heavy Ball has been shown to diverge on simple non-convex quadratic problems~\cite{polyak1964}.

\paragraph{Hyperparameter sensitivity.} All methods were evaluated with manually tuned hyperparameters. In practice, automatic hyperparameter selection (learning rate schedules, warm restarts, grid search over $\alpha$) would be needed. The sensitivity analysis in Figures~\ref{fig:q1_gd_step} and~\ref{fig:q2_adam_sens} illustrates that suboptimal choices significantly degrade performance. Bayesian optimisation or gradient-free hyperparameter search could automate this process.

\paragraph{Single random seed.} All experiments use \texttt{np.random.seed(42)}, which fixes the random data, noise, and initialisation. Results may vary with different seeds, particularly for stochastic methods (SGD). A rigorous study would report means and standard deviations over multiple seeds. The fixed Benchmark~A data $(X, y)$ introduces specific structure (e.g., the exact eigenvalues of $H = X^TX/m$) that may advantage or disadvantage certain methods relative to the ensemble average.

\paragraph{Future directions.} Promising extensions include: (1) variance-reduced methods (SVRG, SAGA) which achieve linear convergence for finite-sum objectives with $O(1)$ per-iteration cost; (2) quasi-Newton methods (L-BFGS) providing Newton-like convergence at $O(dm)$ cost; (3) second-order constrained optimisation (interior point methods); (4) higher-dimensional benchmarks ($d \in \{10, 100, 1000\}$); and (5) evaluation on actual neural network training tasks where the loss landscape includes saddle points and flat minima.

\begin{lstlisting}[caption={Gradient Descent (baseline)}]
def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball (Polyak Momentum)}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient)}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
