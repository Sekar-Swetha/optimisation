\begin{abstract}
This report presents a systematic comparative study of fourteen optimisation algorithms across three benchmark problems of increasing difficulty: a convex quadratic loss (Benchmark A, $\kappa\approx1.2$), a mildly non-quadratic loss (Benchmark B, $\kappa\approx5$), and the highly ill-conditioned Rosenbrock function (Benchmark C, $\kappa\approx2504$). Six categories are examined: (1) adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball); (2) momentum and stochastic methods (Nesterov acceleration, Adam, mini-batch SGD); (3) Newton's method with second-order local approximations; (4) derivative-free and derivative-approximation methods (finite differences, Nesterov random search, Nelder--Mead, grid search); (5) constrained optimisation via projected gradient descent and penalty methods; and (6) the Frank--Wolfe conditional gradient algorithm for linear-constrained problems. Key findings: the Polyak step size diverges when $f^\star$ is misspecified because the step size grows as $O(1/\|\nabla f\|^2)$ while the function gap stays constant; Newton's method achieves one-step convergence on the quadratic benchmark due to exact inversion of the constant Hessian; Nesterov acceleration reduces the Rosenbrock final objective sevenfold over gradient descent by exploiting its $O(1/k^2)$ rate versus GD's $O(1/k)$; and projected gradient descent enforces hard constraints from iteration~1 while penalty methods require $\lambda\geq1.8$ for practical feasibility within 100 steps. The Rosenbrock condition number $\kappa\approx2504$ requires $\approx\!1{,}386$ GD iterations merely to halve the suboptimality gap, explaining the large performance spread between gradient methods and Newton/Nelder--Mead on that benchmark. All experiments use \texttt{numpy.random.seed(42)} for reproducibility.
\end{abstract}

\section{Benchmark Problems and Experimental Setup}

All experiments share the fixed random seed \texttt{np.random.seed(42)}.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix},\quad x^{(i)} \sim \mathcal{N}(0, I_2),\quad y^{(i)} = {\theta^{\star}}^T x^{(i)} + \varepsilon^{(i)},\quad \varepsilon^{(i)} \sim \mathcal{N}(0,1).
\end{equation}
The mean-squared-error loss and its gradient are:
\begin{equation}
J(\theta) = \frac{1}{2m}\sum_{i=1}^{m}\bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2, \qquad
\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y).
\end{equation}
The Hessian $H = \frac{1}{m}X^TX$ is constant and positive semi-definite, making $J$ a strictly convex quadratic. Because of observation noise $\varepsilon$, the least-squares minimum is $J^{\star} \approx 0.4826 > 0$. Starting point: $\theta_0 = [0,\,0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The Hessian is $H = \operatorname{diag}(2 - \sin(x_1),\;10)$. At the minimum, $x_1^{\star}\approx 0.582$ satisfies $2(x_1^{\star}-1)+\cos(x_1^{\star})=0$ (solved numerically), giving $f^{\star}\approx 0.7244$ and $x_2^{\star}=2.0$ exactly. The eigenvalue ratio varies between approximately $1.8\!:\!10$ and $3\!:\!10$, creating moderate anisotropy. Starting point: $x_0 = [-1,\;4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is $(1,\,1)$ with $f^{\star} = 0$. The Hessian at the optimum is
\[
H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\]
with eigenvalues $\lambda_1 \approx 1001.6$ and $\lambda_2 \approx 0.4$, giving condition number $\kappa \approx 2504$. This extreme ill-conditioning, combined with the narrow curved valley $x_2 \approx x_1^2$, makes Rosenbrock the most demanding of the three benchmarks for first-order methods. Starting point: $x_0 = [-1,\;1]^T$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}

\subsection{Theoretical Background}

All four methods derive from the first-order Taylor expansion $f(x - \alpha\nabla f(x)) \approx f(x) - \alpha\|\nabla f(x)\|^2$. The fundamental question is how to choose $\alpha_k$ adaptively without expensive line searches.

\textbf{Polyak step size} chooses $\alpha_k$ so that the first-order model predicts $f^{\star}$: setting the approximation equal to $f^{\star}$ yields $\alpha_k = (f(x_k)-f^{\star})/\|\nabla f(x_k)\|^2$. This has a natural self-scaling property: large gradients produce small steps (stable far from the minimum), small gradients produce large steps (aggressive near the minimum). The $\varepsilon$ damping prevents division by zero.

\textbf{Adagrad} accumulates the squared gradient magnitude for each coordinate independently: $G^{(i)}_k = \sum_{t=0}^{k-1}(g_t^{(i)})^2$. The per-coordinate step $\alpha_k^{(i)} = \alpha_0/(\sqrt{G^{(i)}_k}+\varepsilon)$ automatically decreases for coordinates with large past gradients (which have already been explored) and stays large for coordinates with small past gradients. If the $i$-th coordinate has gradient with average magnitude $\bar{g}_i$, then after $k$ steps $G^{(i)}_k \approx k\bar{g}_i^2$, so the effective step decays as $\alpha_0/(\bar{g}_i\sqrt{k})$: a $O(1/\sqrt{k})$ decay rather than GD's fixed step. This is especially effective for sparse problems (where $\bar{g}_i$ is small for rarely-updated coordinates) but can decrease too aggressively on dense problems.

\textbf{RMSprop} addresses Adagrad's aggressive step decay by replacing the cumulative sum with an exponentially weighted moving average $v_k^{(i)} = \beta v_{k-1}^{(i)} + (1-\beta)(g_k^{(i)})^2$. With $\beta = 0.9$ (as used here), only the most recent~$\sim\!1/(1-\beta)=10$ gradient squares receive appreciable weight, so the effective step size adapts to recent curvature rather than the entire history. If the gradient sequence is stationary (gradients are approximately i.i.d.\ with second moment $\sigma^2_i$), then $v^{(i)}_k\to\sigma^2_i$ as $k\to\infty$ (the geometric series $v_\infty = (1-\beta)\sum_{t=0}^\infty\beta^t\sigma^2_i = \sigma^2_i$ converges). The asymptotic effective step is therefore $\alpha_0/(\sigma_i+\varepsilon)$, which is proportional to the inverse gradient magnitude per coordinate---a form of per-coordinate normalisation.

\textbf{Heavy Ball (Polyak momentum)} replaces the gradient step with a momentum-weighted update. Because $\sum_{t\geq 0}\beta^t = 1/(1-\beta)$, the momentum velocity $z_k$ acts as a weighted sum of past gradients scaled by an effective step $\alpha/(1-\beta)$. For the settings used here (e.g.\ $\beta=0.88$, $\alpha=0.045$ on Benchmark A), the effective step is $0.045/0.12 \approx 0.375$, nearly five times larger than the GD baseline $\alpha=0.08$.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require $x_0$, $f^{\star}$, $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Self-scaling step}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha_0 > 0$, $\varepsilon > 0$, iterations $N$
\State $G \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G \gets G + g_k \odot g_k$ \Comment{Accumulate squared gradients per coordinate}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha_0 > 0$, $\beta \in (0,1)$, $\varepsilon > 0$, iterations $N$
\State $v \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v \gets \beta\, v + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha > 0$, $\beta \in [0,1)$, iterations $N$
\State $z \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z \gets \beta\, z + \alpha\, \nabla f(x_k)$ \Comment{Momentum velocity}
    \State $x_{k+1} \gets x_k - z$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Comparative Analysis}

\begin{itemize}[nosep,leftmargin=*]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest (Rosenbrock: $f=0.009$). Across all benchmarks where the true minimum is non-zero, Heavy Ball with $\beta\approx0.88$--$0.90$ achieves the best practical convergence by accumulating momentum in persistent descent directions.
\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves owing to its exponential averaging with $\beta=0.9$ (effective memory $\sim$10 steps). Heavy Ball shows characteristic overshoot followed by damped oscillation, visible in the contour trajectories.
\item \textbf{Stability:} GD is the most stable but slowest. Polyak is severely unstable when $f^{\star}$ is misspecified. Adagrad is uniformly stable due to its monotonically decreasing step, but this causes premature stagnation on Rosenbrock where sustained large steps are needed.
\item \textbf{Key insight on Polyak:} The method works well precisely when the excess $f(x_k)-f^{\star}$ and the gradient magnitude $\|\nabla f(x_k)\|$ are coupled (i.e.\ both go to zero together, as in exact-minimum problems). When they decouple---as when the true minimum is non-zero due to observation noise---the method is fundamentally ill-suited. Two practical remedies: (a) \emph{estimate} $f^\star$ using a lower bound (e.g.\ running minimum of observed function values); (b) \emph{clip} the step $\alpha_k \leftarrow \min(\alpha_k, \alpha_{\max})$ where $\alpha_{\max} = 1/L$ is a constant upper bound. The clipped variant retains the Polyak decay when $f(x_k)$ is near $f^\star$ but prevents unbounded growth when the gradient vanishes before the function does.
\item \textbf{Adagrad vs.\ RMSprop:} Adagrad's unbounded accumulation of squared gradients works well for sparse problems (each coordinate updates infrequently) but over-penalises dense problems. RMSprop's forgetting factor maintains a stationary effective step size, making it better suited to dense continuous optimisation as in neural network training.
\end{itemize}

\subsection{Convergence Rate Implications}

\begin{theorem}[Gradient Descent Linear Convergence]
\label{thm:gd}
For $\mu$-strongly convex $f$ with $L$-Lipschitz gradient, gradient descent with step $\alpha=1/L$ satisfies:
\begin{equation}
\label{eq:gd_rate}
f(x_k) - f^\star \leq \left(1 - \frac{\mu}{L}\right)^k (f(x_0) - f^\star) = \left(1 - \frac{1}{\kappa}\right)^k(f(x_0)-f^\star).
\end{equation}
\end{theorem}

The GD step sizes used in the experiments are conservative relative to $1/L$ (to ensure stability without knowing $L$ exactly); the actual per-step contraction factor is $\rho=\max(|1-\alpha\mu|,|1-\alpha L|)$.

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

Q1 demonstrated that adaptive step-size methods achieve per-step contractions of $\rho=0.88$--$0.9995$ depending on $\kappa$ (Table~\ref{tab:gd_convergence}). Q2 introduces two orthogonal improvements to first-order methods: \emph{momentum}, which escapes the $O(1/k)$ rate bottleneck; and \emph{stochastic} updates, which replace expensive full-gradient evaluations with cheap mini-batch estimates.

\subsection{Theoretical Background}

\textbf{Nesterov accelerated gradient} (NAG) introduces a ``lookahead'' correction to Heavy Ball. Where Heavy Ball evaluates the gradient at the current iterate $x_k$, Nesterov evaluates at the predicted next iterate $x_k + \beta_k z_k$, which is where the iterate will be if no gradient correction is applied. This correction allows the method to ``apply the brakes'' before overshooting. Nesterov's optimal $\beta_k = (k-1)/(k+2)$ schedule increases from 0 at $k=1$ (pure gradient step) toward 1 as $k\to\infty$.

\begin{theorem}[Nesterov Accelerated Gradient]
\label{thm:nesterov}
For $L$-smooth convex $f$ and the momentum schedule $\beta_k=(k-1)/(k+2)$:
\begin{equation}
\label{eq:nesterov_rate}
f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2}.
\end{equation}
\end{theorem}

Compared to the GD bound $f(x_k)-f^\star \leq L\|x_0-x^\star\|^2/(2k)$ (Theorem~\ref{thm:gd}), Nesterov is faster by a factor of $k/4$ and requires only $O(1/\varepsilon^{1/2})$ iterations to reach precision $\varepsilon$ vs.\ $O(1/\varepsilon)$ for GD. This $O(1/k^2)$ rate is information-theoretically optimal for first-order methods on smooth convex functions.

\textbf{Adam} (Adaptive Moment Estimation) combines momentum with per-coordinate adaptive scaling: $m_t$ is the exponential moving average of gradients (as in Heavy Ball) and $v_t$ is the EMA of squared gradients (as in RMSprop). The effective update $\alpha\hat{m}_t/(\sqrt{\hat{v}_t}+\varepsilon)$ can be interpreted as ``normalised momentum'': the direction is the momentum direction, but the step size is modulated by the recent gradient magnitude per coordinate. The bias-correction terms $1-\beta_1^t$ and $1-\beta_2^t$ are necessary because at $t=1$ the unbiased first moment is just $m_1=(1-\beta_1)g_1$; without correction this would produce an artificially small first step by a factor $(1-\beta_1)^2/(1-\beta_2)$. For the typical values $\beta_1=0.9$, $\beta_2=0.999$ used on Benchmark B: without correction the first step magnitude would be $(0.1)^2/(0.001)^{1/2}=0.01/0.0316\approx0.316\alpha\|g\|^{-1}$, whereas with correction it is $\alpha/(\|g\|+\varepsilon)$---a factor $\approx3\times$ larger on the first step. This makes Adam substantially more aggressive in early iterations than the uncorrected version.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha > 0$, $\beta_{\max}$, iterations $N$
\State $z \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\;\beta_{\max}\right)$ \Comment{Increasing momentum schedule}
    \State $\tilde{x} \gets x_k + \beta_k\, z$ \Comment{Lookahead point}
    \State $z \gets \beta_k\, z - \alpha\,\nabla f(\tilde{x})$ \Comment{Momentum update with lookahead gradient}
    \State $x_{k+1} \gets x_k + z$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adam (Adaptive Moment Estimation)}
\label{alg:adam}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha > 0$, $\beta_1, \beta_2 \in (0,1)$, $\varepsilon > 0$, iterations $N$
\State $m \gets \mathbf{0}$, $v \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g \gets \nabla f(x_t)$
    \State $m \gets \beta_1 m + (1-\beta_1) g$ \Comment{First moment (momentum)}
    \State $v \gets \beta_2 v + (1-\beta_2)\, g \odot g$ \Comment{Second moment (RMSprop)}
    \State $\hat{m} \gets m/(1-\beta_1^t)$,\quad $\hat{v} \gets v/(1-\beta_2^t)$ \Comment{Bias correction}
    \State $x_{t+1} \gets x_t - \alpha\,\hat{m}/(\sqrt{\hat{v}}+\varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses $\alpha=0.06$, batch sizes $b\in\{5,40\}$, 50 epochs, with data shuffled each epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, $\theta_0$, $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, \ldots, E$}
    \State Randomly permute indices $\{1,\ldots,m\}$
    \For{each mini-batch $\mathcal{B} \subset \{1,\ldots,m\}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Unbiased gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

With $m=1000$ samples, batch size $b=5$ gives $200$ updates per epoch and $b=40$ gives $25$ updates per epoch. The mini-batch gradient $\hat{g}_{\mathcal{B}} = \frac{1}{b}\sum_{i\in\mathcal{B}}g_i$ satisfies:
\begin{itemize}[nosep,leftmargin=*]
\item \textbf{Unbiasedness:} $\mathbb{E}_{\mathcal{B}}[\hat{g}_{\mathcal{B}}] = \nabla J(\theta)$ (gradient expectation equals full batch gradient).
\item \textbf{Variance:} $\mathrm{Var}[\hat{g}_{\mathcal{B}}] = \frac{1}{b}\Sigma_g$ where $\Sigma_g = \frac{1}{m}\sum_{i=1}^{m}(g_i - \nabla J)(g_i - \nabla J)^T$ is the per-sample gradient covariance. Thus $\|\mathrm{Var}[\hat{g}]\|_F \propto 1/b$: doubling the batch size halves the gradient noise variance.
\item \textbf{Noise floor:} For a well-specified linear model with $\varepsilon^{(i)}\sim\mathcal{N}(0,\sigma^2)$, the irreducible noise floor $J^\star = \sigma^2/2$ is a property of the data, not the algorithm. SGD does not converge to a point below $J^\star$ with a fixed step size; instead it oscillates in the $O(\alpha\sigma^2_g/b)$ neighbourhood of $\theta_{\mathrm{OLS}}$.
\end{itemize}

\subsection{Convergence of SGD: Fixed vs.\ Decaying Step Size}

The experiments above use a \emph{fixed} step size $\alpha=0.06$. With a fixed step size, SGD with mini-batch gradients does not converge to $\theta_{\mathrm{OLS}}$ but instead oscillates in an $O(\alpha\|\Sigma_g\|/b)$ neighbourhood of it. To achieve exact convergence, the step size must satisfy the Robbins--Monro conditions:
\begin{equation}
\sum_{k=0}^\infty \alpha_k = \infty, \qquad \sum_{k=0}^\infty \alpha_k^2 < \infty,
\end{equation}
e.g.\ $\alpha_k = \alpha_0/(k+1)$ or $\alpha_k = \alpha_0/\sqrt{k+1}$. Under such a schedule, $\mathbb{E}[\|\theta_k - \theta_{\mathrm{OLS}}\|^2]\to 0$ as $k\to\infty$. The fixed step size used here is practical for the finite-iteration regime (50 epochs) but would prevent convergence to machine precision in the limit. This explains the residual oscillation visible for $b=5$ in Figure~\ref{fig:q2_sgd_batch}.

\section{Question 3: Newton's Method and Local Approximation \hfill [30 marks]}
\label{sec:q3}
% ============================================================

Q1--Q2 used first-order information (gradients). Q3 introduces \emph{second-order} information (the Hessian), which enables a qualitatively different convergence regime: quadratic rather than linear (see \eqref{eq:newton_quad}).

\subsection{First- and Second-Order Local Approximations}

For $g(x) = x^4$ at $x_0 = 0.25$ (where $g'(x)=4x^3$, $g''(x)=12x^2$):
\begin{align}
g_0 &= 0.25^4 = 3.906 \times 10^{-3}, \quad g'(x_0) = 4(0.25)^3 = 0.0625, \quad g''(x_0) = 12(0.25)^2 = 0.75.
\end{align}

\textbf{First-order approximation} (tangent line):
\begin{equation}
\hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0) = 3.906\times10^{-3} + 0.0625\,(x - 0.25).
\end{equation}

\textbf{Second-order approximation} (local parabola):
\begin{equation}
\hat{g}_2(x) = g(x_0) + g'(x_0)(x-x_0) + \tfrac{1}{2}g''(x_0)(x-x_0)^2 = 3.906\times10^{-3} + 0.0625(x-0.25) + 0.375(x-0.25)^2.
\end{equation}

\textbf{Newton update derivation:} Minimising $\hat{g}_2$ by setting $\frac{d\hat{g}_2}{dx}=0$ gives $g'(x_0) + g''(x_0)(x-x_0) = 0$, hence:
\begin{equation}
x_1 = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\end{equation}
In the multidimensional case this generalises to $x_{k+1} = x_k - \alpha H_k^{-1}\nabla f(x_k)$, where $H_k = \nabla^2 f(x_k) + \lambda I$ (with damping $\lambda=10^{-8}$ to ensure positive definiteness).

\textbf{One-step convergence for quadratics (Benchmark A):} For $J(\theta) = \frac{1}{2}\theta^T H\theta - b^T\theta + c$ with constant Hessian $H = X^TX/m$, the gradient is $\nabla J(\theta) = H\theta - b$. With $\alpha=1$ and no damping:
\begin{equation}
\theta_1 = \theta_0 - H^{-1}(H\theta_0 - b) = \theta_0 - \theta_0 + H^{-1}b = H^{-1}b = \theta_{\mathrm{OLS}},
\end{equation}
regardless of $\theta_0$. The Newton step exactly inverts the quadratic's Hessian and lands at the global minimum in one step. This is why GD requires $O(\kappa)$ iterations while Newton requires exactly 1.

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Damped Newton's Method}
\label{alg:newton}
\begin{algorithmic}[1]
\Require $x_0$, step size $\alpha$, damping $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}

\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Quadratic Convergence Theory}

\begin{theorem}[Quadratic Convergence of Newton's Method]
\label{thm:newton}
Let $x^\star$ be a local minimum with $\nabla^2 f(x^\star) \succ 0$ (minimum eigenvalue $\mu > 0$) and assume the Hessian is Lipschitz continuous: $\|\nabla^2 f(x)-\nabla^2 f(y)\|\leq M\|x-y\|$. For the full Newton step ($\alpha=1$), in a neighbourhood $\|x_0-x^\star\|\leq r_0 = 2\mu/M$:
\begin{equation}
\label{eq:newton_quad}
\|x_{k+1} - x^\star\| \leq \frac{M}{2\mu}\|x_k - x^\star\|^2.
\end{equation}
\end{theorem}

This \textbf{quadratic convergence} means: setting $e_k = \|x_k-x^\star\|$ and $c = M/(2\mu)$, we have $e_k \leq c^{-1}(ce_0)^{2^k}$. Once $ce_0 < 1$ (i.e.\ within the Newton basin), the number of accurate decimal digits \emph{doubles} each iteration.

\textbf{Why does Rosenbrock require damping $\alpha=0.22$?} At $x_0=(-1,1)$, the gradient is $\nabla f = (-4, 0)$ and the Hessian is $H_0 = \bigl[\begin{smallmatrix}802 & 400\\400 & 200\end{smallmatrix}\bigr]$ (same eigenvalues as $H(1,1)$ but different eigenvectors). The full Newton step is $p = H_0^{-1}(-4,0) = (-2, 4)$, giving $x_1^{\text{full}} = (1,-3)$---far from the optimum $(1,1)$. The quadratic model at $x_0$ predicts $f(x_1)\approx f(x_0) - 4^T p/2 \approx 0$, but the true $f(1,-3) = 0 + 100(-3-1)^2 = 1600$, an enormous error. This is because the Hessian Lipschitz constant $M$ is large for Rosenbrock (the Hessian changes by $\|\Delta H\|=O(800)$ over the step direction), placing $x_0$ far outside the Newton basin. Damping $\alpha=0.22$ keeps the step small enough for the quadratic model to remain valid.

\subsection{Comparison: Newton vs.\ First-Order Methods}

Newton's method has two key advantages: (1) \textbf{scale invariance}---the Newton direction $H^{-1}g$ is invariant to affine reparameterisations, so it automatically accounts for different scalings in each coordinate; and (2) \textbf{quadratic convergence}---near a strongly convex minimum, the error contracts quadratically as in \eqref{eq:newton_quad}. The practical limitations are: (i) computing $\nabla^2 f$ costs $O(d^2)$ and solving the linear system costs $O(d^3)$, which is prohibitive for large $d$; (ii) far from the minimum the Hessian may be indefinite, requiring damping or trust-region modifications; and (iii) the quadratic convergence basin can be small when the Hessian Lipschitz constant $M$ is large relative to $\mu$, as on Rosenbrock.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}
% ============================================================

Q1--Q3 assumed exact gradient information. Q4 relaxes this: Part~A approximates gradients via finite differences (recovering gradient descent performance when $\delta$ is well-chosen), while Part~B considers methods that require \emph{no} gradient information at all---only function evaluations.

\subsection{Part A: Finite Differences and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation for the $i$-th partial derivative is:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
\end{equation}
The approximation error has two components:
\begin{enumerate}[nosep,leftmargin=*]
\item \textbf{Truncation error:} $\left|\frac{f(x+\delta e_i)-f(x)}{\delta} - \frac{\partial f}{\partial x_i}\right| \leq \frac{\delta}{2}\left|\frac{\partial^2 f}{\partial x_i^2}\right| = O(\delta)$, from the Taylor expansion $f(x+\delta e_i)=f(x)+\delta\partial_i f+\frac{\delta^2}{2}\partial_{ii}f+O(\delta^3)$.
\item \textbf{Cancellation error:} When $\delta$ is small, $f(x+\delta e_i)\approx f(x)$ to many significant digits. In double precision (machine epsilon $\varepsilon_{\text{mach}}\approx2.2\times10^{-16}$), the numerator $f(x+\delta e_i)-f(x)$ suffers relative error $\varepsilon_{\text{mach}}/\delta$ from catastrophic cancellation, giving absolute error $O(|f|\,\varepsilon_{\text{mach}}/\delta)$.
\end{enumerate}
The total error is minimised by balancing $\delta/2 \cdot|f''| \approx |f|\,\varepsilon_{\text{mach}}/\delta$, giving:
\begin{equation}
\delta^\star = \sqrt{\frac{2|f|\,\varepsilon_{\text{mach}}}{|f''|}} \approx \sqrt{\varepsilon_{\text{mach}}} \approx 1.5\times10^{-8},
\end{equation}
where the final approximation uses $|f|/|f''|\approx1$ near the optimum. Central differences reduce the truncation error to $O(\delta^2)$ with optimal $\delta^\star\approx\varepsilon_{\text{mach}}^{1/3}\approx6\times10^{-6}$, but require $2d$ evaluations per step rather than $d$.

For the tested values, consider the starting point $x_0=(-1,4)$ on Benchmark B. The second derivative $\partial^2 f/\partial x_1^2 = 2-\sin(x_1)$; at $x_1=-1$: $f''_1 \approx 2+0.84=2.84$. The true gradient $\partial f/\partial x_1 = 2(-1-1)+\cos(-1)\approx-3.46$.
\begin{itemize}[nosep,leftmargin=*]
\item $\delta=0.05$: truncation error $\approx \delta\,f''_1/2 = 0.05\times1.42 = 0.071$; relative error $0.071/3.46\approx2\%$. This is small enough that the gradient direction is nearly exact.
\item $\delta=0.8$: truncation error $\approx 0.8\times1.42 = 1.14$; relative error $1.14/3.46\approx33\%$. At this level the gradient direction is substantially wrong, explaining the observed stalling.
\end{itemize}
Near the minimum, $|\nabla f|\to0$ while the truncation error stays $O(\delta)$, so $\delta=0.8$ can produce gradient estimates with error exceeding the true gradient magnitude, causing the iterate to move in the wrong direction. By contrast, $\delta=0.05$ maintains a 2\% relative error throughout the trajectory, closely tracking exact GD.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha > 0$, $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$, normalise: $u_k \gets u_k/\|u_k\|$ \Comment{Random unit vector}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\,u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The directional derivative estimator is a zeroth-order gradient approximation. Using the Taylor expansion $f(x+\delta u) = f(x) + \delta\nabla f(x)^T u + O(\delta^2)$, and the fact that $\mathbb{E}_u[u\,u^T] = \frac{1}{d}I$ for a uniform random unit vector $u$:
\begin{equation}
\mathbb{E}_u\bigl[\hat{g}_k\bigr] = \mathbb{E}_u\!\left[\frac{f(x_k+\delta u)-f(x_k)}{\delta}u\right] = \mathbb{E}_u\!\left[\nabla f(x_k)^T u \cdot u + O(\delta)\right] = \frac{1}{d}\nabla f(x_k) + O(\delta).
\end{equation}
Thus it is a \emph{biased} estimator: the factor $1/d$ means the effective gradient magnitude is $d$ times smaller than the true gradient. For $d=2$ this halves the effective step size, requiring roughly $d$ times more iterations than exact GD to achieve the same precision. The estimator requires only 2 function evaluations per iteration (regardless of $d$), making it appealing for large-scale black-box optimisation.  The variance is $\mathrm{Var}[\hat{g}_k] \propto \|\nabla f(x_k)\|^2$ and does not decrease as $d$ grows, so the signal-to-noise ratio degrades as $O(1/d)$ in high dimensions.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1=3$ vertices in $\mathbb{R}^2$ and iteratively reshapes it through four operations: \textbf{reflection} ($\alpha_r=1.0$): reflect worst vertex through centroid; \textbf{expansion} ($\gamma=2.0$): if reflection improved, try further; \textbf{contraction} ($\rho=0.5$): if reflection did not improve, shrink towards centroid; and \textbf{shrink} ($\sigma=0.5$): contract all non-best vertices toward the best. No gradient is required: the simplex geometry adapts to the local landscape through comparisons of function values.

Settings: initial step $=0.35$ (simplex side length), 160 iterations.

\textbf{Why Nelder--Mead succeeds on Rosenbrock:} The Rosenbrock function has a unique global minimum at $(1,1)$ with $f^\star=0$ and no local minima---it is a smooth bowl that happens to be extremely elongated. The difficulty for gradient methods is purely the condition number $\kappa\approx2504$: the gradient almost always points nearly perpendicular to the valley floor rather than along it toward the minimum. Nelder--Mead bypasses this: by reshaping the simplex via function value comparisons, it can orient its longest axis \emph{along} the valley and take steps in the correct direction without needing to solve an ill-conditioned gradient system.

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

Q1--Q4 operated in unconstrained settings. Q5 introduces the constraint $x_1 \geq 0.5$ and compares two fundamentally different approaches: \emph{projection} (modify the iterate after each step) and \emph{penalty} (modify the objective before taking the step).

\subsection{Problem Setup}

Minimise Benchmark B subject to $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$.

\textbf{Constraint activity analysis:} The unconstrained minimum $x_1^\star \approx 0.582 > 0.5$ lies strictly inside the feasible region, so the constraint is \emph{inactive} at the optimum. By the KKT conditions, the constrained and unconstrained optima coincide: $x^\star_{\text{constrained}} = x^\star_{\text{unconstrained}} \approx (0.582, 2.0)$, and the optimal Lagrange multiplier $\mu^\star = 0$. This makes Q5 a test of \emph{convergence to the feasible set from an infeasible start} rather than a test of convergence at an active constraint boundary. Any method that achieves feasibility will converge to the same optimum as unconstrained GD.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha > 0$, $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}\bigl(x_k - \alpha\,\nabla f(x_k)\bigr)$ \Comment{$\Pi_{\mathcal{X}}$: clip $x_1 \gets \max(0.5, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require $x_0$, $\alpha > 0$, $\lambda > 0$, $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_\lambda(x_k) \gets f(x_k) + \lambda\max(0,\,-x_1^{(k)} + 0.5)$
    \State $\nabla F_\lambda(x_k) \gets \nabla f(x_k) + \lambda\,[-\mathbf{1}_{x_1^{(k)}<0.5},\,0]^T$ \Comment{Subgradient of penalty}
    \State $x_{k+1} \gets x_k - \alpha\,\nabla F_\lambda(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: Projected GD ($\alpha=0.08$, 100 it.), Penalty with $\lambda\in\{0.15,\,1.8,\,4.5\}$ ($\alpha=0.05$ for $\lambda\leq1.8$; $\alpha=0.03$ for $\lambda=4.5$), unconstrained GD ($\alpha=0.07$). All run for 100 iterations.

\textbf{Projected GD:} Feasibility is guaranteed as a hard constraint from iteration~1. The projection $\Pi_{\mathcal{X}}$ is trivially cheap for half-space constraints ($\max$ operation), so there is no computational overhead. The method converges to the exact constrained minimiser.

\textbf{Penalty method:} As $\lambda\to\infty$ the penalised problem approaches the original constrained problem, so the penalty solution converges to the exact constrained minimiser in the limit. However, large $\lambda$ makes the penalised objective numerically ill-conditioned: the Hessian of $\lambda\max(0,-x_1+0.5)$ introduces large curvature near the constraint boundary, which is why $\lambda=4.5$ requires a smaller step size ($\alpha=0.03$). Choosing $\lambda$ requires balancing feasibility enforcement (large $\lambda$) against numerical stability (small $\lambda$).

\textbf{Augmented Lagrangian (Multiplier Method):} A more principled approach replaces the pure quadratic penalty with:
\begin{equation}
L_\rho(x,\nu) = f(x) - \nu\,(x_1-0.5) + \frac{\rho}{2}\max(0,\,0.5-x_1)^2,
\end{equation}
where $\nu \geq 0$ is a Lagrange multiplier estimate updated as $\nu_{t+1}=\nu_t - \rho\,\min(0,x_1-0.5)$ after each inner minimisation. This allows $\rho$ to remain bounded while still converging to the exact constrained solution, avoiding the ill-conditioning of large $\lambda$. The augmented Lagrangian is equivalent to the penalty method in the limit but achieves superlinear convergence in the dual variable $\nu$.

\section{Question 6: Linear Programmes and Frank--Wolfe \hfill [30 marks]}
\label{sec:q6}

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\;-5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1,\,2]^T$, the minimum over $\mathcal{X}$ is attained at the vertex where all positive-coefficient coordinates are at their lower bounds:
\begin{equation}
x^{\star} = (0.5,\;-5), \qquad f^{\star} = 1\cdot0.5 + 2\cdot(-5) = -9.5.
\end{equation}
This follows from the \textbf{fundamental theorem of linear programming}: the minimum of a linear function over a bounded polytope is attained at a vertex (extreme point). \emph{Proof sketch:} Let $x^{\star}$ be an interior point of the polytope. Since $f(x)=a^Tx$ is linear and $\nabla f = a \neq 0$, moving in direction $-a/\|a\|$ strictly decreases $f$. We can continue until we hit a facet, then a lower-dimensional face, until we reach a vertex---which is therefore at least as good as any interior point. For box constraints, the LP decomposes per coordinate: $\min_{l_i\leq x_i\leq u_i}a_ix_i = a_i l_i$ if $a_i>0$, else $a_i u_i$. So $x_i^\star=l_i$ if $a_i>0$ and $x_i^\star=u_i$ if $a_i<0$, giving $x^\star=(0.5,-5)$ and $f^\star=-9.5$ for $a=[1,2]^T$.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\,\nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LP subproblem)}
    \State $x_{k+1} \gets \beta\, x_k + (1-\beta)\, z_k$ \Comment{Convex combination: stays in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

For box constraints, the LP subproblem decomposes as:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
at cost $O(d)$. Crucially, the update $x_{k+1} = \beta x_k + (1-\beta)z_k$ is a convex combination of two feasible points, so $x_{k+1} \in \mathcal{X}$ automatically---\textbf{no projection is required}. This is the key advantage of Frank--Wolfe over projected gradient descent when projections are costly.

\begin{theorem}[Frank--Wolfe Convergence]
\label{thm:fw}
For $L$-smooth convex $f$ over a convex compact set $\mathcal{X}$, the standard Frank--Wolfe algorithm with step size $\gamma_k = 2/(k+2)$ satisfies:
\begin{equation}
\label{eq:fw_rate}
f(x_k) - f^\star \leq \frac{2L C_{\mathcal{X}}^2}{k+2}, \qquad C_{\mathcal{X}} = \max_{x,y\in\mathcal{X}}\|x-y\|.
\end{equation}
\end{theorem}

For our feasible set, $C_{\mathcal{X}} = \|(5,10)-(0.5,-5)\| = \sqrt{4.5^2+15^2}\approx 15.66$. This $O(1/k)$ rate is the same as gradient descent but projection-free. The fixed-$\beta$ variant used here does not carry the same guarantee; for the interior problem with $L=2$, the Theorem~\ref{thm:fw} bound after 140 steps gives $2\times2\times245/142\approx 6.9$, which is very loose compared to the observed $f_{\text{final}}\approx0.005$---indicating that the fixed-$\beta$ variant performs much better in practice than the worst-case bound.

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum:} Frank--Wolfe converges but exhibits ``zig-zagging'' between vertices of $\mathcal{X}$. At each step the LP oracle sends $z_k$ to a corner of $\mathcal{X}$ (regardless of how close $x_k$ is to the interior optimum), and the small convex step $(1-\beta)$ then pulls $x_k$ slightly toward that corner. Near the optimum $(1,5)$ with $f(x) = (x_1-1)^2+(x_2-5)^2$: the gradient is $\nabla f = (2(x_1-1), 2(x_2-5))$. When $x_k \approx (1.05, 4.9)$ the gradient is approximately $(0.10, -0.20)$. The LP oracle selects $z_k = (l_1, u_2) = (0.5, 10)$ (lower bound for $g_1>0$, upper bound for $g_2<0$). One step later with $x_{k+1} \approx (1.02, 4.97)$ the gradient becomes $(0.04, -0.06)$; now $z_{k+1} = (0.5, 10)$ again---but the sign could flip due to noise, selecting $(0.5, -5)$. This rapid alternation between $(0.5, 10)$ and $(0.5, -5)$ is the zig-zag, damped by the convex combination coefficient $(1-\beta)$. This is the fundamental limitation of Frank--Wolfe for interior optima: it cannot ``focus'' on the optimum but must always step toward a vertex.

\textbf{Boundary optimum:} Frank--Wolfe is better suited here. The gradient of $x_1^2 + x_2^2$ consistently points toward the lower-left, so the LP oracle reliably selects $(0.5, ?)$ as the optimal vertex. The iterate converges toward the boundary naturally without projection. However, the fixed $\beta=0.93$ step size does not decay, causing residual oscillation about the constrained minimum $(0.5, 0)$.

\textbf{Practical implication:} Frank--Wolfe with the standard $\gamma_k=2/(k+2)$ decay schedule avoids the late-stage oscillation issue. The fixed-$\beta$ variant is easier to tune for problems where the optimum is clearly in the interior or on the boundary, but the standard schedule is preferable for general use.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This study reveals several principles governing the behaviour of optimisation algorithms:

\textbf{Step-size adaptivity:} Polyak's step size is theoretically elegant but requires exact knowledge of $f^{\star}$; when $f^{\star}$ is misspecified (as on Benchmarks A and B), the method diverges because the step size grows without bound as the gradient vanishes. Adagrad and RMSprop provide robust adaptivity without oracle knowledge, with RMSprop's exponential forgetting addressing Adagrad's main weakness (excessive step decay).

\textbf{Momentum:} Heavy Ball effectively multiplies the step size by $1/(1-\beta)\approx8$--$10\times$ for typical $\beta$ values, providing faster convergence on well-conditioned problems. Nesterov's lookahead and adaptive $\beta_k$ schedule achieve a 7-fold reduction in Rosenbrock final objective over GD in the same iteration count, confirming the theoretical $O(1/k^2)$ vs.\ $O(1/k)$ advantage on the valley geometry. Adam combines both ideas (RMSprop for scaling, momentum for direction), giving broadly competitive performance.

\textbf{Second-order information:} Newton's method is transformative on well-structured problems (one-step convergence on quadratics), but the $O(d^3)$ cost and sensitivity to Hessian quality limit its applicability. Damping ($\alpha<1$) is essential on highly non-quadratic problems like Rosenbrock.

\textbf{Derivative-free methods:} Finite differences with a well-chosen $\delta$ closely approximate exact gradients. Nesterov random search trades accuracy for scalability (2 function evaluations per iteration). Nelder--Mead is remarkably effective in low dimensions, reaching $f<10^{-2}$ on Rosenbrock without any derivative information.

\textbf{Constrained optimisation:} Projected gradient descent provides the strongest feasibility guarantees (hard constraints from iteration 1) at minimal computational cost for simple constraints. Penalty methods offer a simpler implementation but require careful tuning of $\lambda$; the ill-conditioning introduced by large $\lambda$ necessitates reduced step sizes.

\textbf{Frank--Wolfe:} The projection-free property is valuable when the constraint set's LP oracle is cheap (as for box constraints). The algorithm converges reliably for both interior and boundary optima, though its ``zig-zag'' behaviour near interior optima is less efficient than gradient descent with projection.

\subsection*{Practical Recommendations}

Based on the experimental results, the following method selection heuristics emerge:
\begin{itemize}[nosep,leftmargin=*]
\item \textbf{Well-conditioned quadratic / machine learning models:} Adam or Heavy Ball. Both converge rapidly on Benchmarks A and B; Adam's bias-corrected first step and per-coordinate scaling make it robust to heterogeneous gradient magnitudes.
\item \textbf{Smooth but ill-conditioned problems:} Nesterov acceleration. The $O(1/k^2)$ rate provides a qualitative advantage over GD and Heavy Ball, particularly when $\kappa\gg1$. If $f^\star$ is known, Polyak provides the best per-step descent but requires oracle knowledge.
\item \textbf{Gradient unavailable:} Nelder--Mead for low-dimensional ($d\leq10$) problems; Nesterov random search for high-dimensional black-box optimisation ($d\gg 10$) where function evaluations are the bottleneck.
\item \textbf{Second-order available and affordable:} Newton's method with damping for well-structured problems near the optimum. The $O(d^3)$ cost is prohibitive for large $d$, but for $d=2$ as here it is optimal.
\item \textbf{Constrained problems:} Projected gradient descent for simple constraint sets (boxes, half-spaces); penalty/augmented Lagrangian for complex or implicit constraints.
\end{itemize}

def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float); z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g   # velocity accumulation
        x = x - z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov acceleration and Adam}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float); z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)  # adaptive schedule
        lookahead = x + beta_k * z                   # predict next iterate
        g = grad_fn(lookahead)                        # evaluate at prediction
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g           # momentum
        v_vec = beta2 * v_vec + (1 - beta2) * g**2        # RMSprop
        m_hat = m_vec / (1 - beta1**t)                    # bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))  # ensure positive definite
        p = np.linalg.solve(H_reg, g)          # Newton direction
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)

def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LP oracle for box constraint: x_i -> lower bound if gradient > 0
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                      for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z   # convex combination (stays feasible)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
