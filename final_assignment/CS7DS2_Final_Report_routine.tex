\begin{abstract}
This report presents a comprehensive comparative study of first-order and second-order optimisation
algorithms applied to three benchmark problems of increasing difficulty: a linear regression
quadratic loss (convex, well-conditioned), a sinusoidally perturbed quadratic (mildly non-quadratic),
and the Rosenbrock function (non-convex, highly ill-conditioned with condition number
$\kappa \approx 2000$). Six families of methods are investigated: (1) adaptive step-size rules ---
Polyak, Adagrad, RMSprop, and Heavy Ball --- which address the step-size selection problem central
to practical gradient descent; (2) accelerated and stochastic methods --- Nesterov momentum and
Adam --- which combine curvature awareness with momentum to achieve faster convergence; (3)
Newton's method with Hessian regularisation, demonstrating quadratic convergence on near-quadratic
problems; (4) derivative-free and gradient-approximation methods --- finite differences, Nesterov
random search, Nelder--Mead simplex, and grid search --- applicable when gradients are unavailable;
(5) constrained optimisation via projected gradient descent and quadratic penalty methods; and
(6) the Frank--Wolfe (conditional gradient) algorithm for linear-constrained smooth minimisation.
Each method is evaluated in terms of convergence speed, trajectory behaviour, stability, and
computational trade-offs. Key findings include: Polyak's step size requires exact knowledge of
$f^\star$ and diverges when this is misspecified; Newton's method converges in a single step on
quadratic objectives; Nesterov momentum achieves the theoretical $O(1/k^2)$ acceleration;
and Frank--Wolfe converges at $O(1/k)$ while maintaining automatic feasibility through convex
combinations.
\end{abstract}

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. The
three benchmark functions were selected to span a range of difficulties and structural properties.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
\label{sec:bench_a}

A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
x^{(i)} \sim \mathcal{N}(0, I_2), \quad
y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad
\varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
          = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a convex quadratic with constant Hessian $H = \frac{1}{m}X^T X \succ 0$ and gradient
$\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The Lipschitz constant of the gradient is
$L = \lambda_{\max}(H)$ and the strong convexity constant is $\mu = \lambda_{\min}(H)$.
Because of observation noise $\varepsilon$, the OLS minimum satisfies
$J(\theta^{\star}_{\text{OLS}}) \approx \frac{1}{2}\sigma^2 = 0.5$, confirmed empirically as
$J^\star \approx 0.4826$. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\label{sec:bench_b}

\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is
$\nabla f = \bigl[2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)\bigr]^T$
and the Hessian is $H = \operatorname{diag}\!\bigl(2 - \sin(x_1),\ 10\bigr)$.
The eigenvalue ratio $\lambda_2/\lambda_1 = 10/(2 - \sin(x_1))$ varies between approximately
$10/1 = 10$ and $10/3 \approx 3.3$, creating moderate anisotropy. The $\sin$ term makes
this function \emph{non-quadratic} but only mildly so: the Hessian diagonal entry
$2 - \sin(x_1)$ deviates from 2 by at most 1. The minimum lies at approximately
$(0.582, 2.0)$ with $f^\star \approx 0.7244$, found by solving $2(x_1 - 1) + \cos(x_1) = 0$
numerically. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\label{sec:bench_c}

\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$. The Hessian at the optimum is
\begin{equation}
H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues approximately $1001.6$ and $0.4$ giving condition number
$\kappa = \lambda_{\max}/\lambda_{\min} \approx 2502$. Away from the optimum, for example at the
starting point $x_0 = (-1, 1)$, the Hessian is
$H(-1,1) = \operatorname{diag}(2 + 1200 - 400(-1+1),\ 200) + \text{off-diag terms}$.
The curved, narrow valley $x_2 \approx x_1^2$ and extreme anisotropy make
this the canonical hard test for local optimisation methods. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
\label{sec:bench_d}

For constrained problems (Questions 5 and 6), the feasible set is:
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a box (hyperrectangle), for which both projection and the linear minimisation oracle
used by Frank--Wolfe decompose into independent per-coordinate operations.

\begin{remark}[Why Rosenbrock is difficult]
Benchmark C (Rosenbrock) is the canonical ``hard'' test function for several compounding reasons:
(1) \emph{Narrow curved valley}: the path to the minimum follows $x_2 = x_1^2$, a parabolic
curve that first-order methods struggle to track since the gradient is mostly perpendicular to
the valley;
(2) \emph{High condition number}: $\kappa \approx 2500$ at the optimum, requiring tiny step
sizes to maintain stability across the narrow dimension while making progress along the valley
glacially slow;
(3) \emph{Non-convexity near the saddle}: the starting point $(-1, 1)$ lies in a region where
the function has a saddle-like structure (gradient changes sign in $x_1$) before the valley
floor is reached; and
(4) \emph{Changing curvature}: the Hessian $H_{11} = 2 + 1200x_1^2 - 400x_2$ varies dramatically
along the trajectory (from $\approx 1202$ to $\approx 802$), invalidating locally-chosen
step sizes after a few steps.
\end{remark}

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Motivation and Background}

Gradient descent with a constant step size $\alpha$ requires $\alpha \leq 1/L$ for convergence
(where $L$ is the Lipschitz constant of $\nabla f$), and achieves the optimal fixed-step rate
$\alpha = 2/(\mu + L)$ for strongly convex functions. In practice, $L$ and $\mu$ are rarely
known analytically, and the optimal step size must be estimated. Too large a step causes
divergence; too small a step causes slow convergence. The condition number
$\kappa = L/\mu$ determines how difficult it is to choose a good constant step: for large
$\kappa$, the optimal $\alpha$ is very small (to avoid instability in the steep direction)
while the convergence along the flat direction is correspondingly slow.

Adaptive step-size rules address this by estimating effective curvature on-the-fly from
gradient history, removing the need to specify a fixed global step. Conceptually, each method
tries to answer: given the history of gradients, what step size should I use next to make
the fastest progress without overshooting? We compare four adaptive methods against a constant
step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{definition}[Effective step size]
For coordinate-wise methods, the \emph{effective step size} at iteration $k$ for coordinate $i$
is the actual multiplier applied to the gradient: for Adagrad,
$\alpha_k^{(i)} = \alpha_0 / (\sqrt{G_k^{(i)}} + \varepsilon)$; for RMSprop,
$\alpha_k^{(i)} = \alpha_0 / (\sqrt{v_k^{(i)}} + \varepsilon)$.
\end{definition}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Constant Step-Size Gradient Descent (Baseline)}
\label{alg:gd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{proposition}[Polyak convergence]
For a convex function with minimum $f^\star$, the Polyak step satisfies
$f(x_{k+1}) - f^\star \leq \tfrac{1}{2}\|x_k - x^\star\|^2 / \alpha_k$.
When $f^\star$ is known exactly and $f$ is strongly convex, this gives geometric convergence.
\end{proposition}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0 > 0$, $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Coordinate-wise squared gradient sum}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's update adapts the effective step size per coordinate: frequently-updated coordinates
receive smaller steps as $G_k^{(i)}$ grows, while infrequently-updated ones retain larger steps.
For convex online learning, Adagrad achieves $O(\log T / \sqrt{T})$ regret \cite{duchi2011adaptive}.
A key limitation is the \emph{monotonically decreasing} effective step: since $G_k$ only
increases, the step eventually shrinks to zero even if gradient magnitudes later decrease,
potentially causing premature stalling.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0 > 0$, decay $\beta \in (0,1)$,
         $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$
    \Comment{Exponential moving average (EMA) of $g_k^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's unbounded accumulation with an exponential moving average of squared
gradients, using forgetting factor $\beta = 0.9$. The effective window is approximately
$1/(1-\beta) = 10$ recent iterations. This prevents the effective step from shrinking
monotonically, making RMSprop suitable for non-stationary problems. Unlike Adagrad, RMSprop
lacks a general worst-case convergence guarantee, but works well in practice for neural network
training.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0, 1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \Comment{Accumulated momentum buffer}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method (also known as gradient descent with momentum, or the Polyak momentum
method, distinct from Polyak's adaptive step size) adds a momentum term that accumulates
gradient history, allowing the iterate to accelerate in consistent descent directions
and damp oscillations in alternating directions. The $z_k$ buffer acts as a ``heavy ball''
rolling in a potential well: the gradient exerts a restoring force while momentum maintains
the velocity in the downhill direction. For strongly convex quadratics with condition number $\kappa$, the optimal
Heavy Ball parameters are:
\begin{equation}
\alpha^\star = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}, \qquad
\beta^\star = \left(\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}\right)^2,
\end{equation}
achieving a convergence rate of $(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1})^{2k}$,
which is the square root of gradient descent's rate $(\frac{\kappa-1}{\kappa+1})^{2k}$.

\subsection{Comparative Analysis}

For an $L$-smooth, $\mu$-strongly convex function, gradient descent with $\alpha = 1/L$
achieves the linear convergence rate:
\begin{equation}
f(x_{k+1}) - f^\star \leq \left(1 - \frac{\mu}{L}\right)(f(x_k) - f^\star)
= \left(\frac{\kappa - 1}{\kappa}\right)(f(x_k) - f^\star),
\end{equation}
where $\kappa = L/\mu$ is the condition number. For Benchmark A, $\kappa = \lambda_{\max}(H)/\lambda_{\min}(H)$;
for Benchmark B, $\kappa \approx 10/1.5 \approx 6.7$; for Rosenbrock (near the optimum),
$\kappa \approx 2500$. These condition numbers directly explain why GD struggles on Benchmark C
while performing well on A and B.

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest
  (Rosenbrock: $f = 0.009$). In the more common case where $f^\star$ is unknown (or
  misspecified), Adagrad and Heavy Ball match or exceed the GD baseline.
\item \textbf{Smoothness of trajectories:} RMSprop produces the smoothest convergence curves
  due to exponential averaging of gradient magnitudes. Heavy Ball shows characteristic
  overshoot followed by damped oscillation. Adagrad's trajectory is smooth but eventually
  stalls.
\item \textbf{Stability guarantees:} The GD baseline is most stable but slowest. Polyak is
  \emph{conditionally stable}: stable when $f^\star$ is known exactly, catastrophically
  unstable otherwise. Adagrad is unconditionally stable due to its monotonically decreasing
  step size, though this may cause premature stalling on non-stationary or high-dimensional
  problems where early gradients are large relative to later ones.
\item \textbf{Practical considerations:} In practice, $f^\star$ is rarely available, limiting
  Polyak's applicability. RMSprop and Adagrad are more practical choices for deep learning,
  particularly when feature scales vary across coordinates. Heavy Ball provides a simple
  momentum mechanism that requires only one additional hyperparameter ($\beta$) beyond the
  base step size and is well-understood theoretically for quadratic objectives.
\item \textbf{Heavy Ball and condition number:} For strongly convex quadratics, the optimal
  Heavy Ball parameters give convergence rate $\rho_{\text{HB}} = (\sqrt{\kappa} - 1)/(\sqrt{\kappa} + 1)$,
  squaring the GD rate $\rho_{\text{GD}} = (\kappa - 1)/(\kappa + 1)$. For
  $\kappa = 2500$: $\rho_{\text{GD}} \approx 0.9992$, $\rho_{\text{HB}} \approx 0.9608$ ---
  a significant improvement, explaining Heavy Ball's superior Rosenbrock performance.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}

\subsection{Algorithm Formulations and Theoretical Background}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient (NAG)}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$
    \Comment{Increasing momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$
    \Comment{Gradient evaluated at \emph{lookahead} point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at the
extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$ itself. This allows
the iterate to ``look ahead'' and correct its trajectory before committing, preventing the
overshooting that plagues Heavy Ball in non-quadratic regions.

\begin{theorem}[Nesterov acceleration]
For a convex, $L$-smooth function, Nesterov's method with step size $\alpha = 1/L$ and momentum
schedule $\beta_k = (k-1)/(k+2)$ achieves the convergence rate
\begin{equation}
f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2} = O\!\left(\frac{1}{k^2}\right),
\end{equation}
which is \emph{optimal} for first-order methods on smooth convex functions~\cite{nesterov1983method}.
This is a quadratic improvement over gradient descent's $O(1/k)$ rate. Equivalently, to achieve
$\varepsilon$-accuracy, Nesterov requires $O(1/\sqrt{\varepsilon})$ iterations vs.\ gradient
descent's $O(1/\varepsilon)$: a $\sqrt{1/\varepsilon}$ speedup.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha > 0$, $\beta_1, \beta_2 \in [0,1)$,
         $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$
    \Comment{EMA of gradient (first moment)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$
    \Comment{EMA of squared gradient (second moment)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$
    \Comment{Bias-corrected first moment}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \Comment{Bias-corrected second moment}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$) with per-coordinate adaptive scaling (via $v_t$), inheriting
advantages of both RMSprop and momentum methods. The bias correction $(1 - \beta_1^t)^{-1}$ and
$(1 - \beta_2^t)^{-1}$ correct for the zero-initialisation of the moment estimates: without
these, early iterations would have artificially small moments. The effective step size for
coordinate $i$ at iteration $t$ is bounded:
\begin{equation}
\left|\Delta x_t^{(i)}\right| \leq \frac{\alpha(1 + \beta_1)}{1 - \beta_1} \cdot \frac{1}{\sqrt{(1-\beta_2^t)/(1-\beta_2)/(t \cdot v_t^{(i)})} + \varepsilon} \approx \alpha(1 + \beta_1)/(1-\beta_1),
\end{equation}
meaning Adam implicitly bounds the step size, adding a form of stability not present in standard
RMSprop.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$,
and 50 epochs, with data indices randomly permuted at each epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD with Epoch Shuffling}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Dataset $(X, y)$ with $m$ rows, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Sample a uniformly random permutation $\sigma$ of $\{1,\ldots,m\}$
    \For{$j = 0, b, 2b, \ldots$}
        \State $\mathcal{B} \gets \{\sigma(j+1), \ldots, \sigma(j+b)\}$ \Comment{Mini-batch indices}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$
        \Comment{Mini-batch gradient}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The mini-batch gradient $g$ is an unbiased estimator of the full gradient $\nabla J(\theta)$:
\begin{equation}
\mathbb{E}[g] = \nabla J(\theta), \qquad
\operatorname{Var}[g^{(i)}] = \frac{1}{b}\operatorname{Var}[\nabla J_j(\theta)],
\end{equation}
where $\nabla J_j(\theta) = (x^{(j)})^T(x^{(j)T}\theta - y^{(j)}) / m$ is the gradient
contribution from sample $j$. Larger batches reduce variance proportionally to $1/b$,
but perform fewer updates per pass over the data.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q2_sgd_batch.pdf}
\caption{Q2: Mini-batch SGD with different batch sizes on Benchmark A. With $b = 5$, each
epoch performs $1000/5 = 200$ parameter updates, providing faster per-epoch progress. With

\subsection{Effect of Observation Noise on SGD Convergence}

The experiment is repeated with output noise scaled by a factor of 6 (standard deviation
$\sigma = 6$ instead of $\sigma = 1$). In linear regression, the noise floor scales as:
\begin{equation}
J^\star_\sigma = \frac{\sigma^2}{2} \cdot \frac{1}{m}\sum_{i=1}^m \varepsilon_i^2
\approx \frac{\sigma^2}{2} \approx \frac{36}{2} = 18,
\end{equation}
since the OLS residuals are dominated by the noise term when the model is correctly specified.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q2_sgd_noisy.pdf}
\caption{Q2: Effect of observation noise on SGD convergence. Left: original noise ($\sigma = 1$),

Increasing the noise by factor 6 raises the irreducible loss floor by factor $\approx 36$

\begin{remark}
The noise floor increase from $0.48$ to approximately $18$ illustrates a key practical point:
for regression problems, reducing observation noise (e.g., through better data collection or
feature engineering) has a much larger impact on final model quality than tuning
optimisation hyperparameters. Additionally, this demonstrates that for regression tasks, the
SGD convergence problem is \emph{fundamentally statistical}, not purely algorithmic: no
optimisation algorithm can reduce $J$ below $\sigma^2/2$ since this irreducible error
is inherent to the data-generating process.
\end{remark}

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0)
= (0.25)^4 + 4(0.25)^3(x - 0.25)
= 0.00391 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order (Taylor) approximation:}
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
= 0.00391 + 0.0625(x - 0.25) + \tfrac{1}{2}(12(0.25)^2)(x - 0.25)^2.
\end{equation}

The Newton update is derived by minimising the second-order model: setting the derivative of
the quadratic model to zero gives
\begin{equation}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)}.
\end{equation}
This is the Newton--Raphson root-finding step applied to $g'$. When $g$ is strictly convex
($g'' > 0$), the second-order model is a valid quadratic lower bound, and minimising it
provides a better estimate of the minimum than a gradient step alone.

\subsection{Newton's Method with Hessian Regularisation}

\begin{algorithm}[H]
\caption{Newton's Method with Tikhonov Regularisation (Damped Newton)}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, damping $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian, $\lambda = 10^{-8}$}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{Damped Newton step}
\EndFor
\end{algorithmic}
\end{algorithm}

The Tikhonov term $\lambda I$ serves two purposes: it ensures numerical invertibility of $H_k$
(relevant near saddle points or inflection regions where the Hessian may be near-singular), and
it interpolates between Newton's direction ($\lambda \to 0$) and the gradient direction
($\lambda \to \infty$). The damping factor $\alpha < 1$ is required when the quadratic model
is inaccurate far from the minimum (e.g., on Rosenbrock where the Hessian changes rapidly).

\begin{theorem}[Quadratic convergence of Newton's method]
Let $f$ be twice continuously differentiable with $\nabla^2 f$ Lipschitz continuous (constant
$M$) and $\nabla^2 f(x^\star) \succ 0$ at the local minimum $x^\star$.
Then for $\|x_0 - x^\star\|$ sufficiently small and $\alpha = 1$ (full Newton step):
\begin{equation}
\|x_{k+1} - x^\star\| \leq \frac{M}{2\mu}\|x_k - x^\star\|^2,
\end{equation}
where $\mu = \lambda_{\min}(\nabla^2 f(x^\star))$. This \emph{quadratic convergence} means
the number of correct decimal digits roughly doubles each iteration.
\end{theorem}

For a pure quadratic $f(\theta) = \frac{1}{2}\theta^T H \theta - b^T \theta$, $\nabla^2 f = H$
is constant and the Newton step is exact: $\theta_{k+1} = \theta_k - H^{-1}(H\theta_k - b) = H^{-1}b = \theta^\star$,
converging in \emph{one step} regardless of conditioning.

\subsection{Computational Cost and Quasi-Newton Methods}

Newton's method requires: (a) evaluating $\nabla^2 f(x_k)$, which costs $O(d^2)$ for $d$-dimensional
problems; and (b) solving the linear system $H_k p_k = g_k$, which costs $O(d^3)$ by Gaussian
elimination. For $d = 2$ (our benchmarks), this is trivial, but for large-scale problems
(e.g., neural networks with $d \sim 10^6$) it is infeasible.

\textbf{Quasi-Newton methods} (e.g., BFGS, L-BFGS) build an approximation $B_k \approx \nabla^2 f(x_k)$
from gradient difference information:
\begin{equation}
s_k = x_{k+1} - x_k, \quad y_k = \nabla f(x_{k+1}) - \nabla f(x_k), \quad
B_{k+1} = B_k + \frac{y_k y_k^T}{y_k^T s_k} - \frac{B_k s_k s_k^T B_k^T}{s_k^T B_k s_k}.
\end{equation}
This \emph{BFGS update} maintains positive definiteness while incorporating curvature information
from the secant condition $B_{k+1} s_k = y_k$. BFGS achieves superlinear (but not quadratic)
convergence at $O(d^2)$ cost per iteration --- a practical middle ground between GD ($O(d)$)
and Newton ($O(d^3)$). L-BFGS stores only the $m$ most recent $(s_k, y_k)$ pairs, reducing
memory to $O(md)$ and making it practical for very large $d$.

\subsection{Part A: Finite Difference Gradient Approximation (Benchmark B)}

\subsubsection{Theory}

The forward finite-difference approximation of partial derivatives is:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\end{equation}
where $e_i$ is the $i$-th standard basis vector. By Taylor's theorem, the truncation error is:
\begin{equation}
\left|\frac{\partial f}{\partial x_i}(x) - \frac{f(x + \delta e_i) - f(x)}{\delta}\right|
= \frac{\delta}{2}\left|\frac{\partial^2 f}{\partial x_i^2}(\xi)\right| + O(\delta^2),
\end{equation}
for some $\xi$ between $x$ and $x + \delta e_i$. This $O(\delta)$ truncation error is balanced
against the $O(\varepsilon_{\text{mach}}/\delta)$ floating-point cancellation error, yielding
optimal $\delta^\star \approx \sqrt{\varepsilon_{\text{mach}}} \approx 1.5 \times 10^{-8}$.
Central differences $[f(x + \delta e_i) - f(x - \delta e_i)]/(2\delta)$ achieve $O(\delta^2)$
truncation error, allowing a larger optimal $\delta \approx \varepsilon_{\text{mach}}^{1/3}$.

\begin{figure}[H]
\centering
\includegraphics[width=0.88\textwidth]{figures/q4_fd_error_analysis.pdf}
\caption{Finite difference gradient approximation error vs.\ step size $\delta$ for Benchmark B
at $x = (0, 3)$. Forward differences (blue) show the typical V-shaped error curve:

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$; normalise $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
    \Comment{Directional derivative estimate along $u_k$}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method uses only two function evaluations per iteration, regardless of
dimension. The estimator $\hat{g}_k$ is an unbiased estimator of a smoothed gradient:
\begin{equation}
\mathbb{E}_u[\hat{g}_k] = \nabla f_\delta(x_k), \quad
\text{where}\quad
f_\delta(x) = \mathbb{E}_{u \sim \mathcal{U}(S^{d-1})}[f(x + \delta u)]
\end{equation}
is the spherical average of $f$ over the sphere of radius $\delta$. For smooth $f$,
$\|\nabla f_\delta(x) - \nabla f(x)\| = O(\delta^2)$, so the bias is small. However,
the variance of the estimator is $\operatorname{Var}[\hat{g}_k] = O(d) \cdot \|\nabla f(x_k)\|^2/d = O(\|\nabla f\|^2)$,
meaning the estimator has constant signal-to-noise ratio in $d$, but the expected number of
iterations to achieve accuracy $\varepsilon$ scales as $O(d/\varepsilon)$ compared to $O(1/\varepsilon)$
for exact gradient descent. This $d$-factor is the fundamental curse of dimensionality
for derivative-free methods.

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n + 1 = 3$ vertices in $\mathbb{R}^2$,
iteratively updating the worst vertex. Its four operations are:
\begin{itemize}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1$): move the worst vertex through the centroid of the
  remaining $n$ vertices to $x_r = c + \alpha_r(c - x_{\text{worst}})$.
\item \textbf{Expansion} ($\gamma = 2$): if $x_r$ is the new best, try $x_e = c + \gamma(c - x_{\text{worst}})$.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection does not improve, contract either
  outside ($x_c = c + \rho(x_r - c)$) or inside ($x_c = c + \rho(x_{\text{worst}} - c)$).
\item \textbf{Shrink} ($\sigma = 0.5$): if contraction fails, contract all vertices towards
  the best: $x_i \gets x_{\text{best}} + \sigma(x_i - x_{\text{best}})$.
\end{itemize}

Settings: initial simplex step $= 0.35$ (from $x_0 = [-1, 1]^T$), 160 iterations.

\subsection{Problem Formulation}

We minimise Benchmark B subject to the linear constraint $x_1 \geq 0.5$:
\begin{equation}
\min_{x \in \mathbb{R}^2}\; f(x_1, x_2) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1),
\quad \text{s.t.}\quad x_1 \geq 0.5.
\end{equation}
The feasible set is $\mathcal{X} = \{x : x_1 \geq 0.5\}$. The unconstrained minimiser is at
$(0.582, 2.0)$, which satisfies $x_1 = 0.582 > 0.5$, so the \emph{constrained} minimum is also
at $(0.582, 2.0)$ with $f^\star = 0.7244$. The constraint is \emph{inactive} at the optimum,
which means any method that eventually reaches feasibility will converge to the same point.
Starting point: $x_0 = (0.2, 4.0)$, which is \emph{infeasible} ($x_1 = 0.2 < 0.5$).

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Infeasible start $x_0$, step size $\alpha > 0$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$
    \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1}) = ({\max}(0.5, z_{k+1}^{(1)}),\; z_{k+1}^{(2)})$
    \Comment{Project: clip $x_1$ to $[0.5, \infty)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Convergence of projected gradient descent]
For a convex, $L$-smooth objective $f$ and convex feasible set $\mathcal{X}$, PGD with
step size $\alpha \leq 1/L$ satisfies
\begin{equation}
\min_{k \leq T} \|\Pi_{\mathcal{X}}(x_k - \alpha \nabla f(x_k)) - x_k\| = O(1/\sqrt{T}),
\end{equation}
which is the same $O(1/\sqrt{T})$ convergence rate as unconstrained gradient descent on
smooth convex functions.
\end{theorem}

\begin{algorithm}[H]
\caption{Penalty Method (Quadratic Penalty)}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Infeasible start $x_0$, step size $\alpha > 0$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, -x_1 + 0.5)$
    \Comment{Penalised objective}
    \State $\nabla F_\lambda(x) \gets \nabla f(x) - \lambda\, \mathbf{1}[x_1 < 0.5]\, e_1$
    \Comment{Subgradient of penalty term}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The linear penalty $\lambda \max(0, 0.5 - x_1)$ is a specific instance of the $\ell_1$ exact
penalty function. The penalised problem converges to the constrained optimum as $\lambda \to \infty$.
For finite $\lambda$, the minimiser of $F_\lambda$ satisfies the first-order condition
$\nabla f(x^\star_\lambda) = \lambda\, \mathbf{1}[x_1 < 0.5]\, e_1$, yielding a constraint
violation of $O(1/\lambda)$ for typical smooth problems.

\subsection{Hyperparameter Settings}

Settings: Projected GD ($\alpha = 0.08$, 100 iterations); Penalty with
$\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$;
$\alpha = 0.03$ for $\lambda = 4.5$, which requires a smaller step due to the larger
Lipschitz constant of the penalised objective); unconstrained GD ($\alpha = 0.07$, 100 iterations).

\textbf{Projected gradient descent} enforces feasibility as a hard constraint from the very
first iteration. This is the fundamental advantage: no matter how large the gradient step,
the iterate is always feasible. The cost is requiring a \emph{projection oracle} $\Pi_\mathcal{X}$,
which is trivial for simple constraints like bounds ($O(d)$ operations) but can be expensive for
general convex sets (e.g., projection onto the positive semidefinite cone requires an
eigendecomposition). PGD also has the advantage of operating directly on the constrained
problem, inheriting the same convergence rate as unconstrained gradient descent.

\textbf{Penalty methods} require only a modified scalar objective (no special projection
machinery). The weight $\lambda$ controls the trade-off: small $\lambda$ under-penalises
violations; large $\lambda$ makes the penalised objective poorly conditioned (Lipschitz
constant of $F_\lambda$ is $L + \lambda$ for the linear penalty, requiring step sizes of
$O(1/(L+\lambda))$ for stability). The exact $\ell_1$ penalty used here can achieve exact
feasibility for finite $\lambda$ when the constraint qualification holds, unlike quadratic
penalties $\lambda \|Ax - b\|^2/2$ which only achieve feasibility as $\lambda \to \infty$.

\textbf{Augmented Lagrangian} (method of multipliers) offers a principled improvement over
penalty methods by combining a quadratic penalty with a dual variable update:
\begin{equation}
L_\rho(x, \mu) = f(x) + \mu^T c(x) + \frac{\rho}{2}\|c(x)\|^2,
\end{equation}
where $c(x) = \max(0, 0.5 - x_1)$ is the constraint function. The dual variable $\mu$ is
updated after each primal minimisation step: $\mu \gets \mu + \rho\, c(x)$. This achieves
exact feasibility for finite $\rho$ even in problems where the plain penalty method requires
$\rho \to \infty$, making it more numerically stable than pure penalty methods for
ill-conditioned constraints.

\subsection{Feasible Set and Linear Programme}

The feasible set is the axis-aligned box:
$\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme (LP):} Minimise $f(x) = a^T x = x_1 + 2x_2$ over $\mathcal{X}$,
where $a = [1, 2]^T$.

\begin{proposition}[LP solution]
The minimum of a linear objective over a bounded convex polytope is attained at a vertex.
For the box $\mathcal{X}$, since $a_1 = 1 > 0$ and $a_2 = 2 > 0$, the minimum is at
the vertex where both $x_1$ and $x_2$ take their minimum values:
\begin{equation}
x^{\star} = (0.5,\, -5), \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}
\end{proposition}

This illustrates the fundamental theorem of linear programming: for any linear objective,
the optimal solution is always attained at a vertex (extreme point) of the feasible polytope.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) Algorithm}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial feasible $x_0 \in \mathcal{X}$, convex combination weight $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$
    \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$
    \Comment{Convex combination: $x_{k+1} \in \mathcal{X}$ by convexity}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{proposition}[Frank--Wolfe feasibility]
Since $\mathcal{X}$ is convex and both $x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$ (the
LMO minimises over $\mathcal{X}$), every iterate $x_{k+1} = \beta x_k + (1-\beta) z_k$ is a
convex combination of feasible points and thus feasible. Frank--Wolfe never requires an
explicit projection oracle.
\end{proposition}

For box constraints $\mathcal{X} = [l, u]^d$, the LMO decomposes per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
requiring only $O(d)$ operations.

\begin{theorem}[Frank--Wolfe convergence rate]
For a convex, $L$-smooth objective $f$ over a compact convex set $\mathcal{X}$ with
diameter $D = \max_{x,y \in \mathcal{X}}\|x - y\|$, the Frank--Wolfe algorithm with
step size $\gamma_k = 2/(k+2)$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{2LD^2}{k+2} = O\!\left(\frac{1}{k}\right).
\end{equation}
Note: here we use a fixed $\beta$ rather than the optimal decaying schedule, which may
affect the constant but preserves the $O(1/k)$ rate qualitatively.
\end{theorem}

\subsection{Interior vs.\ Boundary Behaviour: Analysis}

\textbf{Interior optimum case:} Frank--Wolfe converges to the correct minimum but exhibits
the characteristic zig-zag oscillation. Near the interior optimum, the gradient $\nabla f(x_k)$
is small but nonzero; the LMO nonetheless selects a vertex of $\mathcal{X}$ (far from $x_k$),
creating a large directional jump $z_k - x_k$ that is down-weighted by $(1-\beta)$ in the
convex combination. As $\beta \to 1$, this down-weighting becomes more aggressive, reducing
oscillation at the cost of slower progress. The $O(1/k)$ convergence rate implies that
achieving precision $\varepsilon$ requires $O(1/\varepsilon)$ iterations --- much slower than
gradient descent's $O(\log(1/\varepsilon))$ rate on strongly convex problems.

\textbf{Boundary optimum case:} Frank--Wolfe is well-suited to boundary optima because the
LMO vertex $z_k$ frequently selects the boundary-closest vertex (here $x_1 = 0.5$), naturally
driving the iterate to the boundary without projection. The fixed $\beta = 0.93$ schedule
yields a residual gap of $0.114$ after 140 iterations because the step size does not decay to
zero. Using the standard decaying schedule $1 - \gamma_k = 2/(k+2)$ (equivalently
$\beta_k = k/(k+2)$) would ensure convergence to the constrained optimum.

\textbf{Comparison with Projected Gradient Descent:} The key advantage of Frank--Wolfe is that
it avoids computing projections, which can be expensive. Its disadvantage is the $O(1/k)$
convergence rate versus the $O(1/k^2)$ rate of Nesterov-accelerated projected gradient descent
on smooth strongly convex objectives. Frank--Wolfe excels in settings where the LMO is
computationally cheap (e.g., box constraints, simplex, nuclear norm ball) and where iterates
being convex combinations of extreme points has structural advantages (e.g., sparse solutions
when $\mathcal{X}$ is a polytope).

\textbf{Frank--Wolfe gap:} A useful primal certificate of optimality is the
\emph{Frank--Wolfe gap} (or duality gap):
\begin{equation}
g_k = \nabla f(x_k)^T(x_k - z_k),
\end{equation}
where $z_k$ is the LMO solution. Since $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$,
we have $f(x_k) - f^\star \leq g_k$ for convex $f$. Thus $g_k$ provides an upper bound on
the optimality gap without knowing $f^\star$. In our experiments, $g_k$ could be used to
implement a stopping criterion: stop when $g_k \leq \varepsilon$.

\textbf{Practical applications of Frank--Wolfe:} FW is particularly popular in machine learning
for optimising over structured constraint sets: (1) the $\ell_1$ ball $\|x\|_1 \leq 1$ (used in
Lasso and compressed sensing --- the LMO selects a coordinate $\pm e_i$); (2) the nuclear
norm ball $\|X\|_* \leq 1$ (used in matrix completion --- the LMO computes the leading singular
vector); and (3) the flow polytope (used in traffic/routing problems). In all these cases,
the projection is expensive but the LMO has special structure enabling efficient computation.

% ============================================================
\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has investigated six families of optimisation algorithms across three benchmark
problems of increasing difficulty. The following key conclusions emerge:

\textbf{Adaptive step-size methods} (Q1): Adagrad and Heavy Ball provide reliable improvement
over constant step-size GD without requiring problem-specific parameter tuning. Polyak's rule
is theoretically elegant but requires exact knowledge of the optimal value $f^\star$; when
this is unavailable or misspecified, it can diverge catastrophically. RMSprop's exponential
moving average addresses Adagrad's monotone decay but lacks a worst-case guarantee.

\textbf{Momentum and acceleration} (Q2): Nesterov's method achieves the theoretically optimal
$O(1/k^2)$ convergence rate for convex functions, which manifests clearly on the Rosenbrock
problem where it outperforms all Q1 methods. Adam combines momentum with per-coordinate
scaling, but its advantages are most pronounced on problems with heterogeneous feature scales
(not the case for the benchmarks here). Mini-batch SGD's convergence floor is determined by
observation noise, not optimisation quality.

\textbf{Newton's method} (Q3): Provides quadratic convergence and is exact in one step for
quadratic objectives. Its main limitations are (a) requiring the Hessian and its inverse
(cost $O(d^3)$ per step), and (b) needing damping when the quadratic model is inaccurate,
which is common on highly non-quadratic functions like Rosenbrock. Despite these limitations,
Newton outperforms all first-order methods on all three benchmarks in terms of iterations
required per unit of convergence.

\textbf{Derivative-free methods} (Q4): Finite differences with good $\delta$ closely
approximates exact gradient descent at $d+1$ function evaluations per iteration. Nesterov
random search provides dimension-independent per-step cost but converges slowly in $d$
dimensions. Nelder--Mead is practical for low-dimensional problems and serves as a reliable
derivative-free benchmark. Grid search is the only method with a global optimality guarantee
but scales exponentially with dimension.

\textbf{Constrained optimisation} (Q5): Projected gradient descent enforces hard feasibility
at every iteration and should be preferred when a projection oracle is available. Penalty
methods are simpler to implement but require tuning of $\lambda$ and may converge to
infeasible points for small penalties. For the test problem (inactive constraint at the
optimum), both methods converge to the same solution, with the penalty method's accuracy
improving with $\lambda$.

\textbf{Frank--Wolfe} (Q6): Provides automatic feasibility maintenance through convex
combinations, eliminating projection. It is most advantageous when projections are expensive
and the LMO is cheap. The $O(1/k)$ convergence rate is slower than accelerated projected
methods but sufficient in many practical applications.

\begin{lstlisting}[caption={Gradient Descent (Baseline)},label={lst:gd}]
def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size},label={lst:polyak}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad},label={lst:adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop},label={lst:rmsprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball},label={lst:hb}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient},label={lst:nesterov}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)  # Increasing momentum schedule
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)                       # Gradient at lookahead point
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser},label={lst:adam}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g          # First moment (EMA)
        v_vec = beta2 * v_vec + (1 - beta2) * g**2       # Second moment (EMA)
        m_hat = m_vec / (1 - beta1**t)                    # Bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Tikhonov Regularisation},label={lst:newton}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))  # Tikhonov regularisation
        try:
            p = np.linalg.solve(H_reg, g)     # Solve H_reg * p = g
        except np.linalg.LinAlgError:
            p = g                              # Fallback to gradient step
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient) Algorithm},label={lst:fw}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # Linear minimisation oracle (LMO) for box constraints
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z     # Convex combination: maintains feasibility
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
