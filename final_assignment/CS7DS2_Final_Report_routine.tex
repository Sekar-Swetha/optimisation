\begin{abstract}
This report presents a comprehensive comparative study of six categories of optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark A), a toy neural network loss with sinusoidal perturbation (Benchmark B), and the ill-conditioned Rosenbrock function (Benchmark C).
The methods investigated are: (i) adaptive step-size rules --- Polyak, Adagrad, RMSprop, and Heavy Ball; (ii) momentum and stochastic methods --- Nesterov acceleration, Adam, and mini-batch SGD; (iii) Newton's method exploiting second-order information; (iv) derivative-free approaches --- forward finite differences, Nesterov random search, Nelder--Mead, and grid search; (v) constrained optimisation via projected gradient descent and quadratic penalty methods; and (vi) the Frank--Wolfe algorithm for linear-constrained problems.
Key findings include: (1) the Polyak step requires exact knowledge of $f^{\star}$ and diverges catastrophically when misspecified (as observed on Benchmarks A and B); (2) Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ first-order rate and outperforms all other first-order methods by 7$\times$ on the Rosenbrock function ($\kappa \approx 2508$), while Adam underperforms Nesterov due to its diagonal preconditioning ignoring the off-diagonal Hessian coupling; (3) Newton's method converges in a single step on the quadratic benchmark (the Newton step equals the OLS estimator in closed form), with quadratic convergence near smooth non-quadratic minima; (4) the inactive constraint insight for Q5 --- the unconstrained minimiser $x^{\star}_1 \approx 0.582 > 0.5$ means the KKT multiplier $\mu = 0$ and the constrained and unconstrained problems share the same solution; and (5) the Frank--Wolfe algorithm handles box constraints via convex combinations without projection at $O(1/k)$, with the decaying step $\gamma_k = 2/(k+2)$ outperforming fixed-$\beta$ strategies. Each method is evaluated in terms of convergence speed, trajectory behaviour, stability, and computational cost, with analysis grounded in formal convergence theory.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation lies at the heart of modern machine learning and data analysis. Training a model reduces to minimising a loss function, and the choice of optimisation algorithm has profound effects on convergence speed, solution quality, and computational cost. This report investigates a broad spectrum of algorithms, ranging from simple gradient descent with adaptive step sizes to derivative-free and constrained methods, applied to three benchmark problems of varying difficulty.

The six questions in this assignment correspond to six major algorithmic paradigms:

\begin{enumerate}[nosep]
  \item \textbf{Adaptive step-size methods} (Section~\ref{sec:q1}): Methods that replace the fixed learning rate with a step-size rule that responds to gradient history --- Polyak, Adagrad, RMSprop, and Heavy Ball.
  \item \textbf{Momentum and stochastic methods} (Section~\ref{sec:q2}): Nesterov accelerated gradient and Adam, which combine momentum with adaptive scaling; mini-batch SGD studying the effect of batch size and noise.
  \item \textbf{Newton's method} (Section~\ref{sec:q3}): Second-order methods that exploit the Hessian to take curvature-informed steps, compared against gradient descent.
  \item \textbf{Derivative-free optimisation} (Section~\ref{sec:q4}): Finite-difference gradient approximation, Nesterov random search, Nelder--Mead simplex, and grid search --- all requiring only function evaluations.
  \item \textbf{Constrained optimisation} (Section~\ref{sec:q5}): Projected gradient descent and penalty methods for handling inequality constraints.
  \item \textbf{Frank--Wolfe algorithm} (Section~\ref{sec:q6}): A projection-free algorithm for linearly constrained optimisation, illustrated on box-constrained problems.
\end{enumerate}

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. Section~\ref{sec:benchmarks} defines the benchmark problems used throughout.

\textbf{Notation:} Throughout this report, $f : \mathbb{R}^n \to \mathbb{R}$ denotes the objective function; $x^{\star}$ the global minimiser; $f^{\star} = f(x^{\star})$ the global minimum value; $\nabla f(x)$ the gradient; $H(x) = \nabla^2 f(x)$ the Hessian; $L$ the Lipschitz constant of $\nabla f$ (so $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$); $\mu > 0$ the strong convexity modulus (so $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$); and $\kappa = L/\mu$ the condition number. We use $\odot$ for element-wise (Hadamard) product, $\|\cdot\|$ for the Euclidean norm, and $O(\cdot)$ for big-O notation as the iteration count $k \to \infty$.

\textbf{Information-order hierarchy:} The methods in this report form a strict hierarchy by the type of oracle (function/gradient/Hessian) they require, with provably better convergence at each higher level. \emph{Zeroth-order} methods (Q4: grid search, Nelder--Mead, Nesterov random search, finite differences) use only function evaluations; their best achievable rate for $L$-smooth convex problems is $O(n/k)$, the factor of $n$ reflecting the cost of recovering gradient information from scalar evaluations. \emph{First-order} methods (Q1--Q2, Q5--Q6: GD, Nesterov, Adam, projected GD, Frank--Wolfe) use gradients; Nesterov's $O(1/k^2)$ rate is information-theoretically optimal for this oracle class \cite{nesterov2018}. \emph{Second-order} methods (Q3: Newton) additionally use the Hessian and achieve \emph{quadratic} local convergence --- a qualitative improvement that renders convergence rate comparisons meaningless near the optimum (any small neighbourhood is escaped in a constant number of steps). The price increases monotonically: zeroth-order requires $O(n)$ function evaluations per gradient estimate; first-order requires $O(n)$ arithmetic per gradient; second-order requires $O(n^2)$ memory and $O(n^3)$ arithmetic per Hessian solve. For $n = 2$, all three tiers have negligible per-step cost, so convergence rate alone determines competitiveness --- explaining why Newton dominates in Q3. For $n = 10^6$, only zeroth- or first-order methods are viable.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated from a linear model:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0,I_2), \quad y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
\label{eq:loss_A}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
The gradient and Hessian are:
\begin{equation}
\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y), \qquad H = \nabla^2 J = \frac{1}{m}X^T X.
\end{equation}
This is a strictly convex quadratic with constant Hessian. With the fixed seed (\texttt{np.random.seed(42)}), the Hessian eigenvalues are approximately $\lambda_1 \approx 0.9247$ and $\lambda_2 \approx 1.0325$, giving a condition number $\kappa(H) \approx 1.12$ --- nearly perfectly conditioned. Since $X \in \mathbb{R}^{m \times 2}$ with $m = 1000$ i.i.d.\ rows from $\mathcal{N}(0,I_2)$, by the law of large numbers $H = X^TX/m \to I_2$ as $m\to\infty$, so $\kappa(H) \to 1$: the near-unit condition number is expected for large $m$ with standardised features.

The minimiser is the ordinary least-squares (OLS) estimator $\hat{\theta} = (X^TX)^{-1}X^Ty \approx [3.028,\, 4.017]^T$, close to $\theta^{\star} = [3,4]^T$ due to the large sample size ($\hat\theta \to \theta^{\star}$ as $m\to\infty$ by consistency). The irreducible noise floor is $J^{\star} = J(\hat\theta) \approx 0.4826$; since the model is correctly specified with $\varepsilon^{(i)} \sim \mathcal{N}(0,1)$, the expected noise floor is $\mathbb{E}[J(\hat\theta)] = \sigma^2(m - 2)/(2m) \approx \sigma^2/2 = 0.5$ for large $m$, consistent with the observed value. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
\label{eq:loss_B}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are:
\begin{equation}
\nabla f = \begin{bmatrix} 2(x_1 - 1) + \cos(x_1) \\ 10(x_2 - 2) \end{bmatrix}, \qquad H(x) = \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}.
\end{equation}
Since the Hessian is diagonal and $x_2$-independent, $x_2^{\star} = 2$ exactly. The $x_1$-component satisfies $2(x_1-1) + \cos(x_1) = 0$, giving $x_1^{\star} \approx 0.5824$ numerically. The minimum function value is $f^{\star} \approx 0.7244$.

The Hessian eigenvalues vary with position: $\lambda_1 = H_{11}(x_1) = 2 - \sin(x_1)$ and $\lambda_2 = H_{22} = 10$. Near the starting point $x_0 = [-1, 4]^T$: $H_{11}(-1) = 2 - \sin(-1) \approx 2.841$, giving $\kappa = 10/2.841 \approx 3.52$. Near the optimum $x_1^{\star} \approx 0.582$: $H_{11}(0.582) = 2 - \sin(0.582) \approx 2 - 0.549 = 1.451$, giving $\kappa = 10/1.451 \approx 6.89$. The condition number \emph{worsens} along the trajectory (from 3.52 to 6.89), consistent with the sinusoidal term creating more challenging curvature near the minimum. The sinusoidal term is the smallest eigenvalue: $H_{11}(x_1) \in [1, 3]$ for all $x_1$ since $|\sin(x_1)| \leq 1$, so the function remains strictly convex throughout ($\lambda_{\min} \geq 1 > 0$), making this a challenging but globally tractable problem. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
\label{eq:loss_C}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian is:
\begin{equation}
H(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the optimum $(1,1)$: $H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}$. The eigenvalues satisfy $\lambda^2 - 1002\lambda + (802 \times 200 - 400^2) = \lambda^2 - 1002\lambda + 400 = 0$, giving $\lambda = (1002 \pm \sqrt{1002^2 - 1600})/2 = (1002 \pm \sqrt{1002404})/2$. Numerically: $\lambda_{\min} \approx 0.40$ and $\lambda_{\max} \approx 1001.6$, giving condition number $\kappa \approx 2508$. This extreme ill-conditioning has direct consequences for first-order methods: GD requires $O(\kappa)$ iterations per decade of convergence, meaning approximately 2508 iterations to reduce $f - f^{\star}$ by a factor of 10 with an optimal step size $\alpha = 2/(\lambda_{\min} + \lambda_{\max})$. The curved valley $x_2 = x_1^2$ means the Hessian is far from this diagonal structure away from the optimum: $H_{12} = -400x_1$ is large and negative for $x_1 < 0$, creating a strong coupling between coordinates that gradient descent cannot exploit. Starting point: $x_0 = [-1, 1]^T$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations. Let $f : \mathbb{R}^n \to \mathbb{R}$ be the objective, $g_k = \nabla f(x_k)$ the gradient at iteration $k$, and $\odot$ denote element-wise multiplication.

\begin{algorithm}[H]
\caption{Polyak Step Size \cite{polyak1969}}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Optimal step to $f^{\star}$ in one dimension}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step is theoretically optimal for subgradient methods when $f^{\star}$ is known. The step $\alpha_k = (f(x_k) - f^{\star})/\|g_k\|^2$ uniquely solves the 1D problem $\min_\alpha \|x_k - \alpha g_k - x^{\star}\|^2$: expanding, the distance from the projected point to $x^{\star}$ is $\|x_k - x^{\star}\|^2 - 2\alpha g_k^T(x_k - x^{\star}) + \alpha^2\|g_k\|^2$, minimised at $\alpha^{\star} = g_k^T(x_k - x^{\star})/\|g_k\|^2$. By the subgradient inequality, $f^{\star} \geq f(x_k) + g_k^T(x^{\star} - x_k)$, giving $g_k^T(x_k - x^{\star}) \geq f(x_k) - f^{\star}$; substituting yields the Polyak formula \cite{polyak1969}. For strongly convex $f$ with $f^{\star}$ known exactly, Polyak's rule achieves convergence at the optimal rate.

\begin{algorithm}[H]
\caption{Adagrad \cite{duchi2011}}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0 > 0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^n$ \Comment{Cumulative squared-gradient accumulator}
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate squared-gradient accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$ \Comment{Coordinate-adaptive step}
\EndFor
\end{algorithmic}
\end{algorithm}

The effective per-coordinate learning rate $\alpha_0/\sqrt{(G_k)_i + \varepsilon}$ decays monotonically. Adagrad was designed for sparse gradients and has a theoretical $O(\sqrt{T})$ total regret bound \cite{duchi2011}:
\begin{equation}
R_T = \sum_{k=1}^T [f(x_k) - f(x^{\star})] \leq \frac{1}{2\alpha_0}\sum_{i=1}^n \sqrt{(G_T)_i} \cdot (x_{0,i} - x^{\star}_i)^2,
\end{equation}
where $(G_T)_i = \sum_{k=1}^T g_{k,i}^2$ is the cumulative squared gradient for coordinate $i$. The key insight: the per-coordinate bound $\sqrt{(G_T)_i}$ adapts to the gradient magnitude in each direction --- coordinates with small total gradient (sparse features, small curvature) receive less penalty than high-gradient coordinates. By Cauchy-Schwarz, $\sum_i \sqrt{(G_T)_i} \leq \sqrt{n \sum_i (G_T)_i} \leq \sqrt{n T g_{\max}^2}$, giving $R_T \leq O(\|x_0 - x^{\star}\|\sqrt{nT}/2\alpha_0)$ and $R_T/T = O(1/\sqrt{T})$ average regret. For strongly convex problems, the rate improves to $O(\log T/T)$. The monotonic decay is a feature for sparse settings (coordinate $i$ that appears infrequently retains its effective rate) but a limitation for dense, stationary settings where the step eventually vanishes even when the gradient hasn't converged.

\begin{algorithm}[H]
\caption{RMSprop \cite{tieleman2012}}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0} \in \mathbb{R}^n$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces the cumulative accumulator of Adagrad with an exponentially weighted moving average, controlled by $\beta$. This forgetting mechanism prevents the learning rate from decaying to zero and allows adaptation to changing gradient scales. The exponential moving average $v_k = \beta v_{k-1} + (1-\beta)g_{k-1}^2 = (1-\beta)\sum_{j=0}^{k-1}\beta^{k-1-j}g_j^2$ has an effective window of $1/(1-\beta)$ steps: gradients older than $1/(1-\beta)$ iterations are down-weighted by $e^{-1}$ or more. With $\beta = 0.9$, the effective window is $1/(1-0.9) = 10$ iterations; with $\beta = 0.99$, it is 100 iterations. This means RMSprop adapts to recent gradient scale changes within its window, unlike Adagrad which accumulates the entire history. Concretely, at step $k$: $v_k^{(i)} \approx \bar{g}_i^2$ where $\bar{g}_i^2$ is the exponential moving average of $g_i^2$ over the last $1/(1-\beta)$ steps, giving $\alpha_{\text{eff}} \approx \alpha_0 / \bar{g}_i$ --- a dynamic step that adjusts to the local gradient scale rather than its global maximum.

The diagonal preconditioning $\text{diag}(1/\sqrt{v_k})$ can be viewed as a diagonal approximation to the inverse Fisher information matrix, connecting RMSprop to the \emph{natural gradient} --- a full-matrix preconditioner that accounts for the geometry of the loss landscape. The diagonal approximation is computationally efficient ($O(n)$ vs $O(n^3)$ for the full Fisher) but loses information about cross-coordinate correlations, which is why methods like Newton (Section~\ref{sec:q3}) that use the full Hessian outperform RMSprop on well-conditioned problems.

\begin{algorithm}[H]
\caption{Heavy Ball (Polyak Momentum) \cite{polyak1964}}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^n$ \Comment{Velocity vector}
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Accumulate gradient momentum}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

For a quadratic objective with eigenvalues $\mu \leq \lambda \leq L$, the Heavy Ball method with optimal parameters $\alpha^{\star} = 4/(\sqrt{L} + \sqrt{\mu})^2$ and $\beta^{\star} = \left((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\right)^2$ achieves linear convergence with rate $(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$, which is strictly better than gradient descent's rate $(\kappa-1)/(\kappa+1)$ for ill-conditioned problems \cite{polyak1964}. These optimal parameters are the same as those of Nesterov on quadratics, confirming that both methods achieve the optimal first-order convergence rate on this function class.

\begin{remark}
Despite achieving the optimal quadratic rate, Heavy Ball has \emph{no convergence guarantee for general non-quadratic objectives}: the method can diverge or cycle on smooth non-convex functions. In contrast, Nesterov's method (Section~\ref{sec:q2}) achieves the optimal $O(1/k^2)$ rate for \emph{all} convex $L$-smooth functions via its lookahead gradient mechanism. The practical implication is that Heavy Ball requires careful hyperparameter tuning (especially $\beta$) on non-quadratic problems, whereas Nesterov with the prescribed $\beta_k$ schedule is provably safe.
\end{remark}

\textbf{Why Adagrad outperforms GD on Benchmark C:} GD must fix $\alpha = 0.0012$ to satisfy the global stability condition $\alpha < 2/L$ throughout the trajectory. At the starting point $(-1,1)$, the Hessian eigenvalues are $\lambda_{\min} \approx 0.40$ and $\lambda_{\max} \approx 1002$ (the full condition number $\kappa \approx 2508$ is realised there), giving stability limit $2/L \approx 0.002$; the choice $\alpha = 0.0012$ is only 60\% of this limit, a conservative but necessary constraint. Adagrad's effective step size adapts: at step $k=1$, after the first gradient $g_0 = [-4, 0]^T$ is accumulated ($G_1 = [16, 0]^T$), the effective step in $x_1$ is $\alpha_0/\sqrt{G_{1,1}} = 0.45/4 = 0.1125$, far larger than GD's $0.0012$. After 1--2 steps, when large gradients appear ($\|g_1\| \approx 205$), the effective step drops to $\approx 0.003$, but this is still 2.5$\times$ GD's step. The key mechanism: Adagrad's self-tuning allows larger steps when gradient magnitudes are moderate (early iterations near $x_0$) and automatically reduces them when large curvatures are encountered, achieving per-step progress that a fixed-$\alpha$ GD cannot match without risking instability.

\subsection{Comparative Analysis and Theoretical Perspective}

\begin{theorem}[Polyak Convergence {\cite{polyak1969}}]
If $f$ is convex, $L$-smooth, and $f^{\star}$ is known exactly, the Polyak step-size rule satisfies
\[
f(x_{k+1}) - f^{\star} \leq \left(1 - \frac{\mu}{L}\right)(f(x_k) - f^{\star})
\]
for strongly convex $f$ with modulus $\mu$. When $f^{\star}$ is misspecified as $\tilde{f}^{\star} < f^{\star}$, the step size $\alpha_k \to \infty$ as $\|g_k\| \to 0$, causing divergence.
\end{theorem}

On Benchmark C (Rosenbrock), Polyak achieves the best result because $f^{\star} = 0$ is exactly known. Among the remaining methods, Heavy Ball is the most consistently strong performer on the ill-conditioned Benchmark C.}

\textbf{Why does Heavy Ball outperform Adagrad on Rosenbrock?} This key finding warrants theoretical explanation. At the starting point $x_0 = (-1, 1)$, the Rosenbrock gradient is $\nabla f(-1,1) = [-4, 0]^T$ --- relatively modest. However, as the iterate descends towards the valley floor $x_2 = x_1^2$, the transverse gradient component (orthogonal to the valley) is large due to the steep curvature ($100(x_2 - x_1^2)$ term). The transverse gradients, encountered in early iterations, accumulate in Adagrad's squared-gradient sum $G_k$, permanently shrinking the effective step in \emph{all} directions --- including along the valley floor where large steps are needed. Heavy Ball, by contrast, accumulates velocity \emph{in the consistent valley-floor direction} without any shrinkage mechanism. The momentum vector $z_k$ aligns with the long-run descent direction (along the valley), providing the large steps needed for meaningful progress despite the extreme condition number ($\kappa \approx 2508$). This illustrates a general principle: \emph{monotone step-decay methods can stagnate on ill-conditioned landscapes where sustained velocity in a specific direction is needed}.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient \cite{nesterov1983}}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Momentum schedule: $\beta_k \to 1$ as $k\to\infty$}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point (gradient evaluated ahead of current iterate)}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Update velocity at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The critical distinction from Heavy Ball is the \emph{lookahead evaluation}: the gradient is computed at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This allows Nesterov momentum to ``look ahead'' and correct its trajectory before overshooting, providing a stabilising feedback mechanism that Heavy Ball lacks. The schedule $\beta_k = (k-1)/(k+2)$ is the theoretically motivated choice achieving the optimal $O(1/k^2)$ convergence rate \cite{nesterov1983}.

\textbf{Why the $\beta_k$ schedule gives $O(1/k^2)$:} The schedule $\beta_k = (k-1)/(k+2)$ arises from the recursion $t_{k+1} = \frac{1 + \sqrt{1 + 4t_k^2}}{2}$ (where $t_0 = 1$), which satisfies $t_k \geq (k+1)/2$. The convergence proof uses a Lyapunov (energy) function $\Phi_k = t_k^2(f(x_k) - f^{\star}) + \frac{1}{2\alpha}\|z_k\|^2$, where $z_k$ tracks the accumulated "optimistic" position. The key identity in the proof is $\Phi_{k+1} \leq \Phi_k$, i.e., the energy is non-increasing. Since $t_k^2 \geq (k+1)^2/4$ and $\Phi_0$ is finite, it follows that $f(x_k) - f^{\star} \leq \Phi_k / t_k^2 \leq \Phi_0 / t_k^2 \leq 4\Phi_0 / (k+1)^2 = O(1/k^2)$. The increasing $\beta_k$ schedule is necessary: if $\beta_k$ were fixed, the energy function $\Phi_k$ would not satisfy the non-increasing property. As $k \to \infty$, $\beta_k \to 1$ (maximum inertia), meaning the method builds up velocity in the descent direction optimally. In early iterations, $\beta_k$ is small, giving cautious, GD-like steps; as $k$ grows, momentum increases, building velocity. The cap $\beta_{\max}$ prevents numerical instabilities for non-convex objectives where the quadratic model breaks down.

\begin{theorem}[Nesterov Optimal Rate {\cite{nesterov1983}}]
For convex, $L$-smooth $f$, Nesterov's accelerated gradient with $\alpha = 1/L$ satisfies
\[
f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2}.
\]
This $O(1/k^2)$ rate is optimal for first-order methods --- it matches the lower bound proved by Nesterov, whereas gradient descent achieves only $O(1/k)$.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser \cite{kingma2014}}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in [0,1)$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean) estimate}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (variance) estimate}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction: removes initialisation bias}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$ \Comment{Preconditioned momentum step}
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$, inheriting from Heavy Ball, Section~\ref{sec:q1}) with per-coordinate adaptive scaling (via $v_t$, inheriting from RMSprop, Section~\ref{sec:q1}). The bias correction terms $(1-\beta_1^t)$ and $(1-\beta_2^t)$ are essential in early iterations: without them, $m_t$ and $v_t$ are biased towards zero since they start at zero. Quantitatively, at $t=1$: $m_1 = (1-\beta_1)g_1$, $v_1 = (1-\beta_2)g_1^2$. Without bias correction, the effective step size would be $\alpha/\sqrt{v_1} = \alpha/({\sqrt{1-\beta_2}}\cdot|g_1|)$; with $\beta_2 = 0.999$, this gives $\alpha/\sqrt{0.001} \approx 31.6\alpha$ --- an inflated step 31$\times$ larger than intended. The bias correction divides by $(1-\beta_2^1) = 0.001$ to recover the correct scaling, ensuring $\hat{v}_1 = g_1^2$ (unbiased at $t=1$). The effective learning rate in Adam's update can be written as:
\begin{equation}
\alpha_t^{(i)} = \alpha \cdot \frac{\sqrt{1-\beta_2^t}}{1-\beta_1^t} \cdot \frac{1}{\sqrt{\hat{v}_{t,i}} + \varepsilon} \approx \frac{\alpha}{\sqrt{\hat{v}_{t,i}} + \varepsilon},
\end{equation}
which is approximately in $[\varepsilon^{-1}\alpha_{\min}, \alpha_{\max}]$ for bounded gradients. Adam achieves $O(T^{-1/4})$ convergence in the non-convex stochastic case, which is the optimal rate for the non-convex stochastic setting \cite{kingma2014}. To put this in perspective: to find an $\varepsilon$-approximate stationary point ($\|\nabla f\| \leq \varepsilon$) requires $O(\varepsilon^{-4})$ iterations for Adam, compared to $O(\varepsilon^{-2})$ for SGD and $O(\varepsilon^{-3/2})$ for variance-reduced methods (SVRG, SARAH). For the strongly convex setting, Nesterov achieves $O(1/k^2)$ (error decays as $1/k^2$), while Adam's theoretical rate is $O(\sqrt{T} / T) = O(1/\sqrt{T})$ per coordinate --- four times slower as an exponent. Concretely: to reduce the sub-optimality by factor 10, Nesterov requires $\sqrt{10}\approx 3.2\times$ more iterations; Adam requires $10\times$ more. This 10:3.2 ratio explains the observed gap: after 150 iterations, Nesterov achieves $f=0.479$ while Adam achieves $f=1.578$.

In the deterministic setting, Adam does not have a formal convergence guarantee for non-convex problems: Reddi et al.\ (2018) \cite{reddi2018} constructed a simple convex online learning problem where Adam fails to converge, demonstrating that the non-monotone update of $v_t$ can prevent the algorithm from learning fast enough in unfavourable coordinate directions. They proposed AMSGrad, which replaces $\hat{v}_t$ with $\bar{v}_t = \max(\bar{v}_{t-1}, \hat{v}_t)$ (monotone maximisation), ensuring the effective learning rate never increases. AMSGrad restores the $O(\sqrt{T})$ regret guarantee with a theoretical proof. For the experiments in this assignment (deterministic, non-convex Rosenbrock), Adam's empirical non-convergence is consistent with this theoretical limitation: the oscillatory gradients along the valley cause $v_t$ to fluctuate, corrupting the adaptive step calibration.

Adam's diagonal preconditioning ignores this correlation and may even hinder it by scaling $x_1$ and $x_2$ updates independently. This explains the 3.3$\times$ performance gap ($f = 0.479$ vs $f = 1.578$) between Nesterov and Adam on Benchmark C.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs ($E = 50$), with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD \cite{robbins1951}}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\pi$
    \For{each mini-batch $\mathcal{B} = \{\pi(ib+1), \ldots, \pi((i+1)b)\}$, $i = 0,1,\ldots$}
        \State $\hat{g} \gets \dfrac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, \hat{g}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The stochastic gradient is an unbiased estimate of the full gradient: $\mathbb{E}[\hat{g}] = \nabla J(\theta)$. For a quadratic loss with observation noise $\sigma^2$, the mini-batch gradient covariance decomposes as:
\begin{equation}
\mathrm{Cov}[\hat{g}] = \frac{1}{b}\left(\frac{\sigma^2}{m} X^TX\right) + \underbrace{0}_{\text{full-batch term}},
\end{equation}
so the gradient variance scales as $\Sigma/b$ where $\Sigma = \frac{\sigma^2}{m}X^TX$ is determined by the data and noise. For Benchmark A with the fixed seed, $\Sigma \approx \mathrm{diag}(0.925, 1.032)$; doubling the batch from $b=5$ to $b=40$ reduces per-step gradient variance by factor 8, from $\Sigma/5 \approx \mathrm{diag}(0.185, 0.206)$ to $\Sigma/40 \approx \mathrm{diag}(0.023, 0.026)$.

\textbf{Linear scaling rule:} To match the convergence quality of batch size $b$ with learning rate $\alpha$, batch size $kb$ should use learning rate $k\alpha$ (keeping the noise floor $\propto \alpha/b$ constant). Concretely: $b=5, \alpha=0.06$ and $b=40, \alpha=0.48$ have identical noise floors of $\approx \alpha\sigma^2/(2\mu b) \approx 0.006/(2 \times 0.925 \times 5) = 0.00065$. This rule, introduced by Goyal et al.\ (2017) for large-scale distributed training, allows $k$ parallel workers each processing batch $b$ to simulate a single worker with batch $kb$ and rate $k\alpha$, recovering full-batch convergence speed at $k$-fold wall-clock speedup. The rule breaks down for very large $k$ (typically $k \gtrsim \sqrt{\kappa \ln(1/\varepsilon)}$) because the \emph{critical batch size} --- the batch size above which variance reduction yields diminishing returns --- is bounded: for the SGD convergence bound (Theorem below), the noise floor $\alpha\sigma^2/(2\mu b)$ cannot be eliminated by increasing $b$ alone; decaying $\alpha \to 0$ is also required for exact convergence.

The key trade-off: smaller $b$ means more frequent updates per epoch but higher gradient variance; larger $b$ means fewer, higher-quality updates per epoch. With $m=1000$ samples: $b=5$ performs 200 updates/epoch and $b=40$ performs 25 updates/epoch, an 8:1 ratio explaining the faster per-epoch loss reduction observed for $b=5$ in Figure~\ref{fig:q2_sgd_batch}.

When $\mathrm{Var}_{\text{obs}} = \sigma^2$ dominates, increasing $b$ does not meaningfully reduce variance, explaining the convergence to the same floor for both batch sizes under high noise.
\end{remark}

\begin{theorem}[SGD Convergence \cite{robbins1951}]
For a $\mu$-strongly convex, $L$-smooth objective and mini-batch stochastic gradients with variance $\sigma^2_{\text{sg}}/b$, SGD with constant step size $\alpha \leq 1/(2L)$ satisfies:
\[
\mathbb{E}[J(\theta_k)] - J^{\star} \leq \left(1 - \mu\alpha\right)^k \bigl(J(\theta_0) - J^{\star}\bigr) + \frac{\alpha \sigma^2_{\text{sg}}}{2\mu b}.
\]
The second term is an irreducible \emph{noise floor} $\propto \alpha/b$: it can be reduced by decreasing $\alpha$ or increasing $b$, but not eliminated with a constant step size. This floor explains why SGD converges to a neighbourhood of $J^{\star}$ rather than to $J^{\star}$ itself, with size proportional to $\sigma^2/b$. Reaching exact convergence requires a decaying step schedule (e.g., $\alpha_k = c/(k + k_0)$), but this slows the initial convergence.
\end{theorem}

\subsection{Local Taylor Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} at $x_0 = 0.25$: using $g(0.25) = 0.0039$, $g'(0.25) = 4(0.25)^3 = 0.0625$:
\begin{equation}
\label{eq:first_order}
g_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order approximation}: using additionally $g''(0.25) = 12(0.25)^2 = 0.75$:
\begin{equation}
\label{eq:second_order}
g_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises $g_2$ with respect to $x$, yielding the stationary condition $g'(x_0) + g''(x_0)(x_{k+1} - x_k) = 0$, i.e.:
\begin{equation}
\label{eq:newton_1d}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)}.
\end{equation}
For $g(x) = x^4$ at $x_0 = 0.25$: $x_1 = 0.25 - 0.0625/0.75 = 0.25 - 0.0833 = 0.1667$. The true minimum of $g$ is $x^{\star} = 0$, so the Newton step gives $|x_1 - x^{\star}| = 0.1667$, compared to $|x_0 - x^{\star}| = 0.25$ --- a $1.5\times$ reduction. The second Newton iterate gives $x_2 = x_1 - g'(x_1)/g''(x_1) = 0.1667 - 4(0.1667)^3/(12(0.1667)^2) = 0.1667 - 0.1667/3 = 0.1111$, reducing the error by another $1.5\times$. This reveals \emph{linear} convergence (ratio $2/3$ per step: $x_{k+1} = x_k - x_k/3 = (2/3)x_k$, so $x_k = (2/3)^k x_0 \to 0$), confirming that Newton is not quadratically convergent on $g(x) = x^4$. The reason is that the quadratic convergence theorem requires $g''(x^{\star}) \neq 0$; here $g''(0) = 12 \times 0^2 = 0$, so the quadratic model is degenerate at the minimiser and Newton's step merely reduces the iterate by a constant factor rather than squaring the error. In the multivariate setting this becomes $x_{k+1} = x_k - H_k^{-1} \nabla f(x_k)$, where $H_k = \nabla^2 f(x_k)$ is the Hessian. The Newton direction $p_k = -H_k^{-1}\nabla f(x_k)$ can be interpreted as a \emph{preconditioned gradient}: it applies the inverse Hessian as a preconditioning matrix that normalises the gradient by the local curvature, transforming the problem into one with an identity Hessian (perfectly conditioned) in the local coordinate system $\tilde{x} = H_k^{1/2}x$. This is why Newton's method converges in one step on quadratics (constant Hessian $\Rightarrow$ exact preconditioning everywhere) and achieves quadratic convergence on smooth non-quadratic functions (Hessian varies slowly $\Rightarrow$ preconditioning remains accurate).

\subsection{Newton's Method with Hessian Damping}

\begin{algorithm}[H]
\caption{Newton's Method with Hessian Regularisation}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0,1]$, damping $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation ensures $H_k \succ 0$}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (descent direction when $H_k \succ 0$)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{Damped Newton step ($\alpha=1$: full Newton)}
\EndFor
\end{algorithmic}
\end{algorithm}

The damping $\lambda = 10^{-8}$ ensures $H_k$ is positive definite even when the Hessian is indefinite (which can occur for the Rosenbrock function far from the optimum). The step $\alpha < 1$ is necessary when the quadratic model is a poor approximation, e.g., in regions of high curvature variation. Computational cost per iteration: $O(n^2)$ for gradient/Hessian evaluation and $O(n^3)$ for the linear system solve $H_k p_k = g_k$ (using Cholesky decomposition for symmetric positive definite $H_k$).

\textbf{Note on step sizes:} Benchmark A uses $\alpha = 1.0$ for Newton because the quadratic structure means the full Newton step is exact. Benchmark B uses $\alpha = 0.85$ due to the sinusoidal non-quadratic term. Benchmark C requires $\alpha = 0.22$ because the Rosenbrock Hessian changes rapidly; full Newton steps ($\alpha=1$) overshoot in this case.

\textbf{Modified Cholesky factorisation:} The Newton direction requires solving $H_k p_k = g_k$ where $H_k = \nabla^2 f(x_k) + \lambda I$. For a symmetric positive definite matrix, the Cholesky factorisation $H_k = LL^T$ (where $L$ is lower triangular) enables the solve in two triangular substitutions at $O(n^2/2)$ cost for $n \times n$ $H_k$, versus $O(n^3/3)$ for LU decomposition. The Tikhonov regularisation $\lambda = 10^{-8}$ ensures $H_k \succ 0$ throughout: if $\lambda_{\min}(H_k) < \lambda$, the regularised matrix $H_k + \lambda I$ has $\lambda_{\min} \geq \lambda > 0$, guaranteeing the Cholesky factorisation exists and the Newton direction $p_k = -(H_k+\lambda I)^{-1}g_k$ is a descent direction. For Benchmark C, the Rosenbrock Hessian is positive definite everywhere along the trajectory (eigenvalue bounds: $\lambda_{\min}(H) \geq 200 - \sqrt{200^2 + 400^2 x_1^2}$, which can be negative for large $|x_1|$), so the regularisation is a safety net rather than a correction. In practice, a more principled approach is the Gill--Murray--Wright modified Cholesky, which finds the smallest $\lambda$ needed at each step via an incomplete Cholesky factorisation attempt.

\textbf{GD stability analysis:} The GD step sizes (0.08, 0.06, 0.001) must satisfy $\alpha < 2/L$ for convergence, where $L = \lambda_{\max}(H)$. For Benchmark A: $L \approx 1.033$, so the stability condition gives $\alpha < 1.936$; the choice $\alpha = 0.08$ is highly conservative ($4\%$ of the limit) but safe. For Benchmark B: $L = \max(H_{22}, H_{11}^{\max}) = \max(10, 3) = 10$, giving stability condition $\alpha < 0.2$; $\alpha = 0.06$ is $30\%$ of the limit. For Benchmark C: the Lipschitz constant of $\nabla f$ is $L = \sup_x \lambda_{\max}(H(x))$, which is $O(\|x\|^2)$ far from the origin and effectively unbounded globally. Near the starting point $(-1,1)$: $H_{11} = 2 + 1200(1) - 400(1) = 802$, giving $L \approx 802$ and stability condition $\alpha < 0.0025$; the choice $\alpha = 0.001$ (GD) satisfies this, while the Nesterov step $\alpha = 0.0007$ is even more conservative. The very small steps required by the Rosenbrock Lipschitz constant directly explain the slow GD convergence observed on Benchmark C.

\begin{theorem}[Newton Quadratic Convergence \cite{nocedal2006}]
In a neighbourhood of a strict local minimiser $x^{\star}$ where $\nabla^2 f(x^{\star}) \succ 0$ and $\nabla^2 f$ is Lipschitz continuous, the full Newton step ($\alpha=1$) satisfies:
\[
\|x_{k+1} - x^{\star}\| \leq C\|x_k - x^{\star}\|^2
\]
for some constant $C > 0$ depending on $L$ (Hessian Lipschitz constant) and $\mu$ (strong convexity). This \emph{quadratic convergence} means the number of correct decimal digits roughly doubles at each iteration, compared to the linear convergence of gradient descent.
\end{theorem}

For Benchmark A, the Hessian is constant ($L=0$), so even one step achieves machine precision. The exact calculation confirms this: starting from $\theta_0$, the Newton step gives:
\begin{equation}
\theta_1 = \theta_0 - H^{-1}\nabla J(\theta_0) = \theta_0 - \bigl(\tfrac{1}{m}X^TX\bigr)^{-1}\!\cdot\tfrac{1}{m}X^T(X\theta_0 - y) = (X^TX)^{-1}X^Ty = \hat\theta_{\text{OLS}},
\end{equation}
so $\theta_1$ equals the OLS minimiser exactly, independent of $\theta_0$. This is why Newton achieves the minimum in one step on any quadratic objective: the Newton step solves the local quadratic model exactly, and for a quadratic the model is the global function. For Benchmarks B and C, damping ($\alpha < 1$) reduces convergence to super-linear but is necessary for global convergence.

\textbf{Computational cost comparison:} Each Newton iteration costs $O(n^3)$ for the Hessian solve (here $n=2$, so $O(8)$), plus $O(n^2)$ for Hessian evaluation. Each GD iteration costs $O(n)$ for the gradient. The key comparison is: Newton uses 20 iterations vs GD's 80 iterations, achieving 5$\times$ better results on Rosenbrock with only $0.25\times$ the iteration count. In $n=2$ dimensions, Newton's higher per-iteration cost is negligible.

\textbf{Quasi-Newton and L-BFGS:} For $n \gg 1$, forming and inverting the full Hessian is prohibitive: $O(n^2)$ memory to store $H$ and $O(n^3)$ per solve. The \emph{Limited-memory BFGS (L-BFGS)} algorithm \cite{nocedal2006} addresses this by maintaining only the last $m$ curvature pairs
\[
(s_i,\, y_i) = (x_{i+1} - x_i,\; \nabla f(x_{i+1}) - \nabla f(x_i)), \quad i = k-m,\ldots,k-1,
\]
and applying a two-loop recursion to compute $H_k^{-1}g_k$ in $O(mn)$ time without explicitly forming $H_k^{-1}$. With $m = 5$--$20$, L-BFGS achieves \emph{superlinear convergence} in practice (faster than linear convergence of GD, but slower than quadratic convergence of Newton). The BFGS update satisfies the secant condition $H_{k+1}s_k = y_k$, ensuring the approximate Hessian interpolates the true curvature in the most recent direction. L-BFGS is the standard workhorse for large-scale smooth optimisation ($n = 10^4$--$10^7$), sitting between the extremes of GD ($O(n)$ per step, no curvature) and Newton ($O(n^3)$ per step, exact curvature).

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Forward Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with a function-value ratio:
\begin{equation}
\label{eq:fd}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \qquad e_i \in \mathbb{R}^n \text{ the $i$-th unit vector.}
\end{equation}
The approximation error has two competing sources:
\begin{itemize}[nosep]
  \item \textbf{Truncation error:} $O(\delta)$ from ignoring higher-order Taylor terms. For Benchmark B, with $\|H\| \approx 10$, the leading error term is approximately $\tfrac{1}{2}\delta\|H\| = 5\delta$.
  \item \textbf{Floating-point roundoff:} $O(\varepsilon_{\text{machine}}/\delta)$ since function values are computed to precision $\varepsilon_{\text{machine}} \approx 10^{-16}$.
\end{itemize}
The total error $E(\delta) \approx c_1 \delta + c_2/\delta$ is minimised at $\delta^{\star} = \sqrt{c_2/c_1} \approx \sqrt{\varepsilon_{\text{machine}}} \approx 10^{-8}$. The assignment tests $\delta = 0.05$ (mild overestimate but acceptable) and $\delta = 0.8$ (gross overestimate causing severe truncation error).

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order) \cite{nesterov2017}}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_n)$; normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform direction on sphere}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The estimator $\hat{g}_k$ is a biased gradient estimator: $\mathbb{E}[\hat{g}_k] = \nabla f_\delta(x_k)$ where $f_\delta$ is a Gaussian-smoothed version of $f$. For small $\delta$, $\nabla f_\delta \approx \nabla f$. The key advantage is \emph{dimension independence}: exactly 2 function evaluations per iteration regardless of the number of parameters $n$, compared to $n+1$ for forward FD. The cost is high variance: the random direction $u_k$ is an inefficient estimator of the gradient with variance $\propto n$.

\begin{theorem}[Zeroth-Order Convergence Rate \cite{nesterov2017}]
For an $L$-smooth convex function $f$ minimised via Nesterov random search with appropriately tuned step size, after $k$ iterations:
\[
\mathbb{E}[f(x_k)] - f^{\star} = O\!\left(\frac{nL\|x_0 - x^{\star}\|^2}{k}\right).
\]
The factor of $n$ compared to gradient descent's $O(L\|x_0-x^{\star}\|^2/k)$ rate directly quantifies the cost of gradient information loss: to achieve the same precision as GD in $k$ iterations, random search requires $nk$ iterations, or equivalently $2nk$ function evaluations vs $(n+1)k$ for coordinate-wise FD.
\end{theorem}

\textbf{Variance analysis:} For uniform $u$ on the unit sphere in $\mathbb{R}^n$, the expected squared norm of the directional derivative estimator satisfies (for small $\delta$):
\begin{equation}
\mathbb{E}_u\!\left[\|\hat{g}_k\|^2\right] = \mathbb{E}_u\!\left[\frac{(f(x+\delta u) - f(x))^2}{\delta^2}\,uu^T\right] \approx \frac{\|\nabla f(x)\|^2}{n} \cdot n \cdot n = n\|\nabla f(x)\|^2,
\end{equation}
where the factor arises because $\mathbb{E}_u[(\nabla f^T u)^2 uu^T] = \frac{1}{n}\|\nabla f\|^2 I_n$ and $\|\hat{g}\|^2 = (\nabla f^T u)^2$. The variance grows \emph{linearly with $n$}: in a 1000-dimensional problem, the estimator has 1000$\times$ higher second moment than in 1D, severely degrading the signal-to-noise ratio for high-dimensional optimisation.

\textbf{Comparison to related zeroth-order methods:}
\begin{itemize}[nosep]
  \item \textbf{Coordinate-wise FD (Kiefer-Wolfowitz):} Uses $n$ coordinate perturbations, giving $O(n)$ FE/iter and producing a full gradient estimate with $O(\delta^2)$ bias (central differences) or $O(\delta)$ bias (forward differences). Equivalent to the FD gradient descent in Part A.
  \item \textbf{SPSA (Simultaneous Perturbation Stochastic Approximation):} Uses a random $\pm 1$ Rademacher perturbation $\Delta_k \in \{-1,+1\}^n$, estimating $\hat{g}_k = \frac{f(x+\delta\Delta_k)-f(x-\delta\Delta_k)}{2\delta}\Delta_k^{-1}$ (element-wise). This achieves 2 FE/iter regardless of $n$, like Nesterov RS, with similar variance $\propto n$. SPSA is designed for \emph{stochastic} objectives where even the function value is noisy.
  \item \textbf{Evolution Strategies (ES):} Maintains a population of $\lambda$ candidates $f(x + \sigma\epsilon_i)$ for $\epsilon_i \sim \mathcal{N}(0,I)$. The gradient estimator $\hat{g} = \frac{1}{\lambda\sigma}\sum_i f(x+\sigma\epsilon_i)\epsilon_i$ reduces variance by $\lambda$ via averaging, at the cost of $2\lambda$ FE/iter. Used in reinforcement learning (where $n$ can be millions and gradients are unavailable) with $\lambda \approx 1000$ parallel workers.
\end{itemize}
The key message is that \emph{all 2-FE-per-iteration zeroth-order methods pay a $\Theta(n)$ factor in convergence rate}: this is an information-theoretic lower bound, not an algorithmic deficiency. Compare this to the mini-batch SGD variance reduction in Section~\ref{sec:q2}: while both methods average stochastic estimates (gradient samples vs function evaluations), mini-batch SGD can reduce variance by increasing batch size $b$, while Nesterov RS cannot reduce its $\Theta(n)$ variance factor without extra FE per step. When $n$ is small (as in this $n=2$ experiment), the 2-FE/iter advantage can outweigh the slower per-step progress, but for $n \geq 100$, first-order methods become strongly preferable whenever gradient information is available.

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm \cite{nelder1965} maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively reshapes it through four operations applied in order of preference:
\begin{enumerate}[nosep]
  \item \textbf{Reflection} ($\alpha_r = 1.0$): Move the worst vertex $x_h$ through the centroid $\bar{x}$ of the remaining vertices: $x_r = \bar{x} + 1.0(\bar{x} - x_h)$.
  \item \textbf{Expansion} ($\gamma = 2.0$): If reflection improved, try $x_e = \bar{x} + 2.0(\bar{x} - x_h)$.
  \item \textbf{Contraction} ($\rho = 0.5$): If reflection worsened, contract towards centroid.
  \item \textbf{Shrink} ($\sigma = 0.5$): If contraction also worsens, contract all vertices towards the best.
\end{enumerate}
Settings: initial simplex step $= 0.35$, 160 iterations. No gradient information is required.

\textbf{Key insight:} The choice of derivative-free method depends critically on the problem dimension and available budget. For $d = 2$, Nelder--Mead is the most effective derivative-free method as it exploits the simplex geometry. For large $d$, Nesterov random search is preferable despite its slow per-step convergence because its $O(2)$ FE/iter cost is dimension-independent. Grid search is the only method that provably finds the global optimum to within resolution, but its $O(N^d)$ cost is prohibitive for $d \geq 4$.

\textbf{Theoretical limitations of Nelder--Mead:} Despite excellent practical performance, Nelder--Mead has no general convergence guarantee: McKinnon (1998) constructed a 2D example of a smooth, strongly convex function where Nelder--Mead converges to a non-stationary point. The issue is that the simplex can collapse into a lower-dimensional object (degenerate simplex), after which it cannot recover. In practice, the restart strategy (re-initialise the simplex when volume falls below a threshold) mitigates this, and Nelder--Mead performs well on smooth $d \leq 10$ problems. For the Rosenbrock function with its narrow curved valley, the simplex's adaptive reshaping (elongation along the valley) is particularly effective. The convergence rate is super-linear in practice but $O(1/k)$ in the worst case for smooth convex functions \cite{nocedal2006}.

\textbf{Simplex geometry and the initial step size:} The initial simplex is generated by starting at $x_0 = (-1, -1)$ and adding vertices at $x_0 + s e_i$ for $i = 1, 2$ (where $s = 0.35$ and $e_i$ are unit vectors). The initial simplex volume is $V_0 = \tfrac{1}{2}|s|^2 = 0.0613$, comparable to the scale of the Rosenbrock valley (which has transverse width $\approx 0.1$--$0.3$ near the starting point). A too-small simplex would fail to sense the curvature anisotropy and would make tiny steps; a too-large simplex would straddle the valley and require many shrink operations to localise. The choice $s = 0.35$ is well-balanced: large enough to sense the valley floor direction, small enough to avoid the high-curvature walls. As the simplex approaches the minimum, the shrink operations contract its volume geometrically, with the theoretical volume decay $V_k = (1/2)^{N_s} V_0$ where $N_s$ is the number of shrink operations --- this accounts for the step-wise pattern in the convergence curve (Figure~\ref{fig:q4_nm}).

\textbf{Curse of dimensionality comparison:} Grid search with $N=55$ points per dimension and $d=2$ requires $55^2 = 3025$ function evaluations, achieving resolution $\approx 0.073$. In $d=10$ dimensions with the same resolution, $55^{10} \approx 2.5 \times 10^{17}$ evaluations would be needed --- computationally infeasible. Nelder--Mead scales as $O(d)$ evaluations per step (for a $d+1$-vertex simplex) and is practical up to $d \approx 10$--$20$ in practice. Nesterov random search uses exactly 2 evaluations per step regardless of $d$, making it the most scalable derivative-free method for high-dimensional problems, at the cost of the $n$-factor penalty in convergence rate.

\subsection{Problem Setup}

Minimise Benchmark B~\eqref{eq:loss_B} subject to the inequality constraint $x_1 \geq 0.5$, starting from the \emph{infeasible} initial point $x_0 = (0.2, 4.0)^T$:
\begin{equation}
\label{eq:constrained_problem}
\min_{x \in \mathbb{R}^2} f(x_1, x_2) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1) \qquad \text{subject to } x_1 \geq 0.5.
\end{equation}

\textbf{Important structural observation:} The unconstrained minimiser of $f$ is $x^{\star} = (0.5824, 2.0)^T$ with $f^{\star} \approx 0.7244$. Since $x^{\star}_1 = 0.5824 > 0.5$, the constraint $x_1 \geq 0.5$ is \emph{inactive} at the unconstrained optimum. Consequently, the constrained and unconstrained problems share the same optimal solution:
\begin{equation}
\label{eq:inactive_constraint}
x^{\star}_{\text{constrained}} = x^{\star}_{\text{unconstrained}} = (0.5824,\; 2.0)^T, \qquad f^{\star}_{\text{constrained}} = f^{\star}_{\text{unconstrained}} \approx 0.7244.
\end{equation}
The challenge of this problem is therefore not in finding a constrained solution that differs from the unconstrained one, but in correctly handling the \emph{infeasible starting point} $x_0 = (0.2, 4.0)$ and ensuring feasibility throughout the trajectory.

\textbf{KKT Conditions:} At the optimal solution $(0.5824, 2.0)$, the KKT stationarity conditions for \eqref{eq:constrained_problem} are:
\begin{equation}
\nabla f(x^{\star}) - \mu \begin{bmatrix}1\\0\end{bmatrix} = 0, \quad \mu \geq 0, \quad \mu(x^{\star}_1 - 0.5) = 0.
\end{equation}
Since the constraint is inactive ($x^{\star}_1 = 0.5824 > 0.5$), complementary slackness gives $\mu = 0$, and the stationarity condition reduces to $\nabla f(x^{\star}) = 0$ --- the unconstrained optimality condition. This confirms that the constrained optimum is interior to the feasible set.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step (may leave feasible set)}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project back: $x_1 \leftarrow \max(0.5,\, x_1)$ (trivial for half-space)}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Quadratic Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\State Define penalised objective: $F_{\lambda}(x) = f(x) + \lambda \max(0,\, -x_1 + 0.5)$
\For{$k = 0, 1, \ldots, N-1$}
    \State Compute $\nabla F_{\lambda}(x_k)$: $\partial_{x_1}F_\lambda = \partial_{x_1}f(x_k) - \lambda\, \mathbf{1}[x_{1,k} < 0.5]$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$ to maintain stability), unconstrained GD ($\alpha = 0.07$). All methods run for 100 iterations.

\textbf{Quantitative first-step analysis for projected GD:} At $x_0 = (0.2, 4.0)$, the gradient is $\nabla f(x_0) = [2(0.2-1)+\cos(0.2),\, 10(4-2)] = [-0.62,\, 20.0]^T$. The gradient step gives $z_1 = (0.2 - 0.08\times(-0.62),\, 4.0 - 0.08\times 20) = (0.2496,\, 2.4)$. Since $z_{1,1} = 0.2496 < 0.5$, the projection clips: $x_1 = (0.5,\, 2.4)$. At $x_1$, the gradient is $[-0.12,\, 4.0]$, and the unconstrained step gives $z_2 = (0.5 + 0.08\times0.12,\, 2.4 - 0.32) = (0.510, 2.08)$; since $0.510 > 0.5$, the projection is \emph{inactive}. Thus the constraint boundary is active only at iteration 1, and all subsequent iterates lie strictly inside the feasible set --- consistent with the inactive constraint at the optimum.

\textbf{Projected GD} (see Algorithm~\ref{alg:pgd}) enforces feasibility as a \emph{hard constraint} at every iteration. This is its fundamental advantage: feasibility is guaranteed regardless of the step size or penalty weight. The projection onto a half-space $\{x : x_1 \geq 0.5\}$ is trivially $\Pi(z) = (\max(0.5, z_1), z_2)$ in $O(1)$ cost. For a $\mu$-strongly convex, $L$-smooth objective, projected gradient descent on a convex set converges at the same linear rate as unconstrained gradient descent (Section~\ref{sec:q1}): $f(x_k) - f^{\star} \leq (1 - \mu/L)^k (f(x_0) - f^{\star})$ \cite{nocedal2006}. The projection step does not worsen the convergence rate; it merely restricts the iterates to the feasible set. For Benchmark B with $\mu = \lambda_{\min}(H) \approx 1.45$ and $L = \lambda_{\max}(H) = 10$, the projected GD convergence rate is $(1 - 1.45/10)^k = (0.855)^k$, requiring approximately $\ln(1/\varepsilon)/\ln(1/0.855) \approx 15.6\ln(1/\varepsilon)$ iterations for $\varepsilon$-accuracy --- consistent with the rapid convergence observed in Figure~\ref{fig:q5_fval}.

\textbf{Penalty methods} trade exact feasibility for simplicity: only gradient evaluations of the augmented objective $F_\lambda$ are needed. The penalty weight $\lambda$ controls the trade-off between optimality and feasibility. As $\lambda \to \infty$, the penalised solution $x^{\star}(\lambda)$ converges to the constrained solution $x^{\star}$, but the penalised objective $F_\lambda$ becomes increasingly ill-conditioned with condition number $\kappa(F_\lambda) \approx \max(\kappa(f), \lambda/\mu)$, requiring smaller step sizes to maintain stability. This is the fundamental limitation of the pure penalty approach: the conditioning worsens exactly when the constraint needs to be most strongly enforced.

An improvement is the \emph{augmented Lagrangian} (or method of multipliers) method, which adds both a penalty term and a dual variable (Lagrange multiplier) $\hat\mu$:
\begin{equation}
\mathcal{L}_\lambda(x, \hat\mu) = f(x) + \hat\mu \max(0, -x_1 + 0.5) + \frac{\lambda}{2}\max(0, -x_1 + 0.5)^2.
\end{equation}
The dual update rule $\hat\mu_{j+1} = \max(0, \hat\mu_j - \lambda(x_{1,j} - 0.5))$ shifts the penalty centre towards the constraint boundary, achieving exact feasibility without requiring $\lambda \to \infty$. Concretely, for fixed (moderate) $\lambda$, the augmented Lagrangian method converges to exact feasibility via the dual update, whereas the pure penalty method needs $\lambda \to \infty$ for exact feasibility but suffers from the conditioning bound $\kappa(F_\lambda) \lesssim \lambda/\mu$. This is the key advantage of augmented Lagrangian: it achieves $\lambda$-independent conditioning while still enforcing feasibility exactly in the limit.

In this experiment, the constraint is inactive at the solution, so even $\lambda = 0.15$ eventually reaches the correct objective value --- the penalty gradient drives the iterate towards feasibility, but the inactive constraint means the optimal solution is not on the boundary and the penalty weight has little effect on the final objective value once feasibility is achieved.

\textbf{Penalty parameter selection:} In practice, a good choice balances feasibility enforcement and conditioning. A rule of thumb is to set $\lambda$ such that the penalty term $\lambda|v(x_0)|$ (where $v(x) = \max(0, 0.5 - x_1)$ is the violation) is of the same order as $\|\nabla f(x_0)\|$: at $x_0 = (0.2, 4.0)$, the violation $|v(x_0)| = 0.3$ and $\|\nabla f(x_0)\| = \sqrt{(-0.62)^2 + (20)^2} \approx 20$, suggesting $\lambda \approx 20/0.3 \approx 66$. The experimental values $\lambda \in \{0.15, 1.8, 4.5\}$ are all well below this, which explains why even $\lambda = 4.5$ does not enforce feasibility very aggressively. An increasing penalty schedule $\lambda_j = \rho^j \lambda_0$ (geometric growth with $\rho > 1$) is the standard strategy for the penalty method, avoiding the need to choose $\lambda$ precisely.

\section{Question 6: Linear Programmes and Frank--Wolfe Algorithm \hfill [30 marks]}

\subsection{Feasible Set and Linear Programme}

The feasible set is the box $\mathcal{X}$ defined in~\eqref{eq:feasible_set}: $\mathcal{X} = [0.5, 5] \times [-5, 10]$.

\textbf{Linear Programme:} Minimise $f(x) = a^T x = x_1 + 2x_2$ over $\mathcal{X}$ (where $a = [1, 2]^T$). Since both components of $a$ are positive, the linear objective decreases in both coordinate directions, and the minimum is attained at the lower bound in each dimension:
\begin{equation}
\label{eq:lp_solution}
x^{\star} = \begin{bmatrix} 0.5 \\ -5 \end{bmatrix}, \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}
This exemplifies the \textbf{Fundamental Theorem of Linear Programming}: the minimum of a linear objective over a bounded polytope is always attained at a vertex (extreme point). \emph{Proof sketch:} For any interior or edge point $x \in \mathcal{X}$, there exists a feasible direction $d \neq 0$ such that $a^Td \leq 0$ (i.e., moving along $d$ does not increase the objective). Following $d$ until the boundary gives a point with objective value $\leq a^Tx$, so the minimum cannot be in the interior. By induction on faces, the minimum is attained on a face of dimension 0 --- a vertex. For the box $\mathcal{X}$, the vertices are $(0.5,-5)$, $(5,-5)$, $(0.5,10)$, $(5,10)$, and evaluating $f = x_1 + 2x_2$ at each: $f(0.5,-5)=-9.5$, $f(5,-5)=-5$, $f(0.5,10)=20.5$, $f(5,10)=25$. The minimum is at $(0.5,-5)$ with $f^{\star} = -9.5$.

\textbf{LP duality:} The dual LP for $\min_{x \in \mathcal{X}} a^T x$ (which is $\min a^Tx$ s.t.\ $l \leq x \leq u$) has dual variables $\lambda \geq 0$ (for $x \geq l$) and $\nu \geq 0$ (for $x \leq u$), with dual problem $\max_{(\lambda,\nu) \geq 0} l^T\lambda - u^T\nu$ s.t.\ $\lambda - \nu = a$. At the primal optimum $x^{\star} = (0.5, -5)$: dual variables $\lambda_i = a_i > 0$ (constraint $x_i \geq l_i$ is active at lower bound, so $\lambda_i > 0$) and $\nu_i = 0$ (constraint $x_i \leq u_i$ is inactive). Strong duality confirms $f^{\star} = l^T\lambda = 0.5 \times 1 + (-5) \times 2 = -9.5$. In the Frank--Wolfe context, the LP subproblem $\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$ is exactly this LP with $a = \nabla f(x_k)$, whose optimal solution is always a vertex by the fundamental theorem. This is why the LMO~\eqref{eq:fw_lmo} always returns a corner of the box.

\textbf{Comparison with Simplex method:} The Simplex algorithm for LP moves along edges of the polytope from vertex to vertex, always improving the objective. For the $2 \times 2$ box in this experiment, the Simplex method solves the LP in at most 4 vertex evaluations ($\leq 2$ pivots), versus the 180 iterations used by Frank--Wolfe. This demonstrates that for pure LP, specialised methods are far superior. Frank--Wolfe is valuable when $f$ is \emph{non-linear} (as in the interior and boundary optimum experiments in this question) --- using the LP subproblem as a linearisation oracle for a convex objective, rather than as the true problem.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) \cite{frank1956}}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination (stays in $\mathcal{X}$)}
\EndFor
\end{algorithmic}
\end{algorithm}

For box constraints, the LMO decouples by coordinate:
\begin{equation}
\label{eq:fw_lmo}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
This requires $O(d)$ operations per iteration with no projection oracle. Since $x_{k+1}$ is a convex combination of $x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$ (vertices lie in $\mathcal{X}$), feasibility is maintained automatically: $x_{k+1} \in \mathcal{X}$ for all $k$. The formula~\eqref{eq:fw_lmo} follows immediately from: $\arg\min_{x \in [l_i, u_i]} g_i x$ equals $l_i$ if $g_i > 0$ (objective decreases towards lower bound) and $u_i$ if $g_i \leq 0$ (objective decreases towards upper bound).

For this feasible set, the box diameter is $D = \|(5-0.5, 10-(-5))\| = \|(4.5, 15)\| = \sqrt{4.5^2 + 15^2} \approx 15.66$.

\begin{theorem}[Frank--Wolfe Convergence \cite{frank1956}]
For convex, $L$-smooth $f$ minimised over a compact convex set $\mathcal{X}$ with diameter $D = \max_{x,y \in \mathcal{X}} \|x - y\|$, the Frank--Wolfe algorithm with step size $\gamma_k = 2/(k+2)$ satisfies:
\[
f(x_k) - f^{\star} \leq \frac{2LD^2}{k+2} = O\!\left(\frac{1}{k}\right).
\]
For the interior optimum problem with $L = 2$ (since $\nabla^2 f = 2I$, $L = \lambda_{\max}(2I) = 2$) and $D^2 = 4.5^2 + 15^2 = 245.25$, this gives the bound $2LD^2/(k+2) = 981.0/(k+2)$, predicting $f(x_{180}) - f^{\star} \lesssim 5.39$. The actual value $f \approx 0.005$ is far better (3 orders of magnitude) because the bound is extremely loose: the diameter $D \approx 15.66$ corresponds to traversing the entire box, whereas the iterates stay within a small neighbourhood of $(1,5)$ after the first few iterations. This rate is worse than the $O(1/k^2)$ achievable by projected gradient descent with Nesterov acceleration, the price for avoiding projection.
\end{theorem}

The \textbf{Frank--Wolfe gap} $g_k = \nabla f(x_k)^T (x_k - z_k) \geq 0$ measures the sub-optimality and serves as a stopping criterion: $g_k = 0 \Rightarrow x_k$ is optimal. Non-negativity follows from convexity: $f^{\star} \geq f(x_k) + \nabla f(x_k)^T(x^{\star} - x_k) \geq f(x_k) - \nabla f(x_k)^T(x_k - x^{\star}) \geq f(x_k) - g_k$ (since $z_k = \arg\min_{z\in\mathcal{X}}\nabla f(x_k)^T z \leq \nabla f(x_k)^T x^{\star}$, so $\nabla f(x_k)^T x_k - g_k = \nabla f(x_k)^T z_k \leq \nabla f(x_k)^T x^{\star}$). In the implementation, $\beta$ is fixed (rather than using the optimal $\gamma_k = 2/(k+2)$), which modifies the effective step size and may sacrifice the $O(1/k)$ convergence guarantee.

\subsection{Frank--Wolfe Gap Analysis}

The \textbf{Frank--Wolfe gap} $g_k = \nabla f(x_k)^T(x_k - z_k)$ is a computable upper bound on the primal sub-optimality: $g_k \geq f(x_k) - f^{\star}$ for convex $f$. It serves as both a convergence certificate and a stopping criterion (set $g_k \leq \varepsilon$ for $\varepsilon$-optimality). The proof is clean: by convexity, $f(x^{\star}) \geq f(x_k) + \nabla f(x_k)^T(x^{\star} - x_k)$, so $f(x_k) - f^{\star} \leq \nabla f(x_k)^T(x_k - x^{\star})$. Since $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z \leq \nabla f(x_k)^T x^{\star}$, we have $\nabla f(x_k)^T(x_k - z_k) \geq \nabla f(x_k)^T(x_k - x^{\star}) \geq f(x_k) - f^{\star} \geq 0$. The FW gap also has a \emph{dual interpretation}: it equals the maximum improvement achievable in one FW step over all feasible directions, making it the tightest computable upper bound on sub-optimality available without extra computational cost.

\subsection{Interior vs Boundary Behaviour and Theoretical Implications}

\textbf{Interior optimum:} Frank--Wolfe converges but exhibits a characteristic ``zig-zag'' pattern as $z_k$ alternates between extreme vertices of $\mathcal{X}$. The convex combination gradually averages these jumps, but the oscillation never fully disappears with a fixed $\beta$. As shown in Figure~\ref{fig:q6_fw_gap}, the standard decaying schedule $\gamma_k = 2/(k+2)$ provides both the $O(1/k)$ convergence guarantee and smoother behaviour, outperforming fixed $\beta$ strategies. The fundamental limitation is that Frank--Wolfe is inherently a \emph{first-order method} with the $O(1/k)$ rate it cannot exceed without second-order information.

\textbf{Boundary optimum:} Frank--Wolfe is particularly well-suited to boundary optima: the LMO naturally selects the vertex closest to the constrained solution, and the iterate drifts towards the boundary without explicit projection. However, the fixed $\beta$ schedule causes a characteristic failure mode near the boundary. For $f(x) = x_1^2 + x_2^2$ with $\nabla f = [2x_1, 2x_2]$, the LMO selects $z_k = (0.5, -5)$ whenever $x_{1,k} > 0$ and $x_{2,k} > 0$. The update $x_{k+1} = 0.93\,x_k + 0.07\,z_k$ drives $x_2 \to -5$ geometrically. Once $x_2$ turns negative, the LMO switches to $z_k = (0.5, 10)$ (since $\nabla_{x_2} f = 2x_2 < 0$), pulling $x_2$ back towards positive. This creates sustained oscillation near $x_2 = 0$ --- the optimal coordinate. The final position $(0.500, -0.337)$ is the asymptotic fixed point of this oscillation, not the true optimum $(0.5, 0)$. The decaying step $\gamma_k = 2/(k+2) \to 0$ would eliminate this oscillation by making each move progressively smaller, allowing the iterates to converge to the true boundary optimum rather than cycling around it.

\textbf{Comparison with Projected Gradient:} Projected gradient descent can achieve $O(1/k^2)$ (with Nesterov) on this problem at the cost of computing the projection $\Pi_{\mathcal{X}}(z) = (\text{clip}(z_1, 0.5, 5), \text{clip}(z_2, -5, 10))$ (O(1) for boxes). Frank--Wolfe becomes advantageous when the constraint set is complex (e.g., nuclear norm ball, flow polytope, spectrahedron) where the LP subproblem is efficiently solvable but projection is expensive or intractable. For the simple box constraint in this experiment, projected gradient is strictly preferable due to its faster convergence rate.

\textbf{Away-steps Frank--Wolfe:} The standard FW update $x_{k+1} = (1-\gamma_k)x_k + \gamma_k z_k$ moves \emph{towards} the LP vertex $z_k$. A limitation is that this convex combination can only ``approach'' a new extreme point but cannot move away from a vertex that was previously visited --- causing the zig-zag behaviour observed for interior optima. The \emph{away-steps Frank--Wolfe} variant \cite{frank1956} introduces an additional away step:
\begin{equation}
v_k = \arg\max_{v \in \mathcal{S}_k} \nabla f(x_k)^T v,
\end{equation}
where $\mathcal{S}_k$ is the active set (vertices used in the convex combination representing $x_k$). The method then chooses between the standard towards-step (with $\gamma_k^{\max} = 1$) and the away-step (with $\gamma_k^{\max} = \alpha_k/(1-\alpha_k)$ where $\alpha_k$ is the weight on $v_k$), selecting whichever gives a larger FW gap decrease. Away-steps FW achieves \emph{linear convergence} (rate $O(\rho^k)$ for $\rho < 1$, where $\rho = 1 - 2\delta\mu_f/(L D^2)$ depends on the pyramidal width $\delta$ of the constraint set) on strongly convex objectives, rather than the $O(1/k)$ sublinear rate of standard FW --- a qualitative improvement that comes at the cost of maintaining the active set representation of $x_k$.

A related variant is the \emph{pairwise FW} step, which combines a towards-step (towards $z_k$) and an away-step (from $v_k$) simultaneously: $x_{k+1} = x_k + \gamma_k(z_k - v_k)$. This keeps the iterate as a sparse convex combination by transferring weight from $v_k$ to $z_k$ directly, reducing the active set size more aggressively than the standard FW update. For the box constraint $\mathcal{X}$ in this experiment, the active set is at most 4 vertices (the box has 4 extreme points), so the overhead of maintaining $\mathcal{S}_k$ is negligible. In higher-dimensional or more complex polytopes (e.g., the Birkhoff polytope for doubly stochastic matrices, with $n^2$ extreme points for the set of $n \times n$ permutation matrices), maintaining the active set becomes expensive, and the away-step/pairwise variants require careful bookkeeping. The fundamental trade-off remains: away-steps FW achieves linear convergence at the cost of active set management, while standard FW is simpler but fundamentally limited to $O(1/k)$.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has conducted a systematic comparative study of optimisation algorithms across six paradigms and three benchmark problems of increasing difficulty.

\subsection*{Summary of Key Findings}

\textbf{Adaptive step-size methods (Q1):} The Polyak step provides optimal convergence when $f^{\star}$ is known exactly, but catastrophically diverges when $f^{\star}$ is misspecified (a fundamental practical limitation). Adagrad's monotonically decaying step makes it stable but can cause premature slowdown. RMSprop's exponential moving average of gradient squares avoids Adagrad's vanishing step issue. Heavy Ball, while lacking Nesterov's theoretical guarantees, provides substantial acceleration on ill-conditioned problems through momentum.

\textbf{Momentum and stochastic methods (Q2):} Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ first-order convergence rate, outperforming all other first-order methods on the Rosenbrock benchmark by a factor of 7$\times$ over GD. Adam combines the benefits of momentum and adaptive scaling but underperforms Nesterov on strongly non-quadratic problems. Mini-batch SGD demonstrates the batch-size trade-off: smaller batches provide more frequent but noisier updates, with the relative advantage diminishing under high observation noise.

\textbf{Newton's method (Q3):} Second-order methods are fundamentally superior on well-conditioned problems: Newton solves the quadratic benchmark (Benchmark A) in a single iteration. On the Rosenbrock function ($\kappa \approx 2508$), damped Newton achieves a 5.4$\times$ improvement over GD in 25\% of the iterations. The $O(n^3)$ cost of the Hessian solve limits applicability in high dimensions, but for small $n$, Newton's method has no competitor.

\textbf{Derivative-free methods (Q4):} Forward finite differences with an appropriate step ($\delta = 0.05$) closely approximate exact gradient descent; a poor step ($\delta = 0.8$) degrades gradient quality significantly. Nesterov random search is dimension-independent in FE cost but converges slowly due to single-direction gradient projection. Nelder--Mead effectively navigates the Rosenbrock valley without gradients, while grid search guarantees global optimum discovery at the prohibitive cost of $O(N^d)$ evaluations.

\textbf{Constrained optimisation (Q5):} Projected gradient descent enforces feasibility as a hard constraint from iteration 1, making it the most reliable method. For this problem, the inequality constraint $x_1 \geq 0.5$ is inactive at the optimal solution ($x^{\star}_1 \approx 0.582 > 0.5$), so the constrained and unconstrained optima coincide. Penalty methods enforce feasibility approximately, with feasibility quality increasing with penalty weight $\lambda$ at the cost of conditioning.

\textbf{Frank--Wolfe (Q6):} The Frank--Wolfe algorithm avoids projection by solving a linear subproblem, maintaining feasibility through convex combinations. It converges at $O(1/k)$, slower than projected gradient with Nesterov acceleration, but is preferred when the constraint set (e.g., nuclear norm ball, flow polytope) admits efficient LP solves but expensive projections. The algorithm naturally progresses towards boundary optima and exhibits characteristic vertex-oscillation near interior optima. The theoretically motivated decaying step $\gamma_k = 2/(k+2)$ outperforms fixed $\beta$ strategies in both gap decay and final objective value (Figure~\ref{fig:q6_fw_gap}).

\subsection*{Unifying Principles}

Across all six questions, the experiments confirm four fundamental principles of optimisation:

\begin{enumerate}[nosep]
  \item \textbf{Curvature is everything:} Methods that exploit or adapt to curvature --- Newton (explicit Hessian), Adam/RMSprop (diagonal curvature adaptation), Nesterov (momentum) --- consistently outperform plain gradient descent on ill-conditioned problems. The condition number $\kappa$ is the single most important predictor of relative method performance: on Benchmark C ($\kappa \approx 2508$), the gap between best and worst method spans 3 orders of magnitude.
  \item \textbf{Prior knowledge has value but fragility:} The Polyak step demonstrates that prior knowledge ($f^{\star}$) enables optimal convergence but makes the method brittle. When knowledge is imperfect, the method fails catastrophically. This trade-off between oracle power and robustness is a recurring theme: zeroth-order methods sacrifice gradient information for deployability; penalty methods use an approximate feasibility oracle; Polyak uses an approximate optimality oracle. All three fail in characteristic ways when the oracle is wrong.
  \item \textbf{Feasibility vs optimality:} Constrained optimisation introduces a genuine tension between reaching the optimal solution and maintaining feasibility. Projected gradient resolves this by treating feasibility as paramount (hard constraint); penalty methods resolve it approximately, trading feasibility for algorithmic simplicity. The Frank--Wolfe algorithm sidesteps both by embedding feasibility into the algorithmic structure via convex combinations, but at the cost of a slower $O(1/k)$ convergence rate.
  \item \textbf{The information-order hierarchy is strict:} Each additional oracle type unlocks a strictly better convergence regime. Zeroth-order methods achieve $O(n/k)$; first-order methods achieve $O(1/k^2)$ (Nesterov-optimal); second-order methods achieve quadratic local convergence. The experimental hierarchy Newton $>$ Nesterov $>$ Adam $\approx$ Heavy Ball $>$ Adagrad $\approx$ GD $>$ FD GD $>$ Nesterov random search exactly mirrors the theoretical information-order hierarchy on the most discriminating benchmark (Rosenbrock).
\end{enumerate}

The experimental results align well with theoretical predictions: second-order methods are most effective when the cost of Hessian computation is affordable; Nesterov acceleration provides optimal first-order guarantees; and the Polyak step exemplifies the practical fragility of methods requiring prior knowledge of the optimal value. The Rosenbrock function, with its condition number of $\kappa \approx 2508$, serves as a stringent discriminator separating methods by their ability to handle ill-conditioning.

\subsection*{Limitations and Extensions}

Several limitations of this study are worth noting. First, all benchmarks are low-dimensional ($n = 2$), which may overstate the performance of methods whose per-iteration cost grows with $n$ (Newton: $O(n^3)$) and understate the advantage of truly dimension-free methods (Nesterov random search). Second, all problems are either convex or near-convex; the relative advantages of Nesterov and Newton may differ significantly on highly non-convex loss landscapes (e.g., deep neural networks with saddle points). Third, the comparison of first-order methods depends on hyperparameter tuning, which was done manually; practical methods use adaptive hyperparameter search (e.g., grid search over $\alpha$, $\beta$), and relative rankings may change.

Natural extensions include:
\begin{itemize}[nosep]
  \item \textbf{Higher-dimensional benchmarks} ($n = 10^3$--$10^6$): L-BFGS (quasi-Newton with $m=5$--$20$ curvature pairs) would become the dominant method as it achieves Newton-like convergence at $O(mn)$ cost per step. Coordinate descent (cyclic or random) would also become competitive since it can exploit sparsity and avoids full-gradient computation.
  \item \textbf{Line search:} Replacing fixed step sizes with Armijo-backtracking or Wolfe-condition line search would eliminate the manual step size selection and enable larger steps when curvature permits. The Wolfe conditions $f(x_k + \alpha p_k) \leq f(x_k) + c_1 \alpha \nabla f(x_k)^T p_k$ (sufficient decrease) and $\nabla f(x_k + \alpha p_k)^T p_k \geq c_2 \nabla f(x_k)^T p_k$ (curvature condition, $c_1 < c_2$) ensure that the step provides adequate decrease while maintaining gradient progress. Line search is standard in L-BFGS and quasi-Newton methods but adds $O(\log(1/\alpha_{\min}))$ function evaluations per step.
  \item \textbf{Non-convex objectives:} For functions with multiple local minima (deep networks, max-cut), global optimisation methods become relevant: simulated annealing (random walk with temperature-controlled acceptance), basin hopping (random restarts from local minima), or branch-and-bound (exact methods for small mixed-integer problems). None of the methods in this report guarantee global optimality for non-convex problems.
  \item \textbf{Variance reduction for SGD:} SVRG (Stochastic Variance Reduced Gradient) and SARAH (Stochastic Recursive Gradient) eliminate the noise floor limitation of constant-step SGD by periodically computing the full gradient and using it to correct the stochastic gradient. SVRG achieves linear convergence $O(\rho^k)$ for $\mu$-strongly convex problems at a cost of one full gradient computation per epoch, reducing the effective variance by a factor of $b/m$ compared to mini-batch SGD. For Benchmark A with $m = 1000$ and $b = 40$, SVRG's effective gradient variance would be $O(1/1000)$ per epoch versus SGD's $O(1/40)$ per step --- a 25$\times$ improvement with the same per-epoch compute budget.
\end{itemize}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Hessian Regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
