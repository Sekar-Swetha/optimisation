\begin{abstract}
This report presents a comprehensive comparative study of six categories of optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark A), a toy neural network loss with sinusoidal perturbation (Benchmark B), and the ill-conditioned Rosenbrock function (Benchmark C).
The methods investigated are: (i) adaptive step-size rules --- Polyak, Adagrad, RMSprop, and Heavy Ball; (ii) momentum and stochastic methods --- Nesterov acceleration, Adam, and mini-batch SGD; (iii) Newton's method exploiting second-order information; (iv) derivative-free approaches --- forward finite differences, Nesterov random search, Nelder--Mead, and grid search; (v) constrained optimisation via projected gradient descent and quadratic penalty methods; and (vi) the Frank--Wolfe algorithm for linear-constrained problems.
Key findings include: the Polyak step is highly sensitive to the accuracy of the optimal value estimate and diverges catastrophically when this is unknown; Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ rate and outperforms all first-order methods on Rosenbrock; Newton's method converges in a single step on the quadratic benchmark, demonstrating its $O(1/k)$-per-iteration superiority for well-conditioned problems; and the Frank--Wolfe algorithm naturally handles box constraints without projection, though at an $O(1/k)$ convergence rate. Each method is evaluated in terms of convergence speed, trajectory behaviour, stability, and computational trade-offs, with analysis grounded in the theoretical properties of each algorithm.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation lies at the heart of modern machine learning and data analysis. Training a model reduces to minimising a loss function, and the choice of optimisation algorithm has profound effects on convergence speed, solution quality, and computational cost. This report investigates a broad spectrum of algorithms, ranging from simple gradient descent with adaptive step sizes to derivative-free and constrained methods, applied to three benchmark problems of varying difficulty.

The six questions in this assignment correspond to six major algorithmic paradigms:

\begin{enumerate}[nosep]
  \item \textbf{Adaptive step-size methods} (Section~\ref{sec:q1}): Methods that replace the fixed learning rate with a step-size rule that responds to gradient history --- Polyak, Adagrad, RMSprop, and Heavy Ball.
  \item \textbf{Momentum and stochastic methods} (Section~\ref{sec:q2}): Nesterov accelerated gradient and Adam, which combine momentum with adaptive scaling; mini-batch SGD studying the effect of batch size and noise.
  \item \textbf{Newton's method} (Section~\ref{sec:q3}): Second-order methods that exploit the Hessian to take curvature-informed steps, compared against gradient descent.
  \item \textbf{Derivative-free optimisation} (Section~\ref{sec:q4}): Finite-difference gradient approximation, Nesterov random search, Nelder--Mead simplex, and grid search --- all requiring only function evaluations.
  \item \textbf{Constrained optimisation} (Section~\ref{sec:q5}): Projected gradient descent and penalty methods for handling inequality constraints.
  \item \textbf{Frank--Wolfe algorithm} (Section~\ref{sec:q6}): A projection-free algorithm for linearly constrained optimisation, illustrated on box-constrained problems.
\end{enumerate}

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. Section~\ref{sec:benchmarks} defines the benchmark problems used throughout.

\textbf{Notation:} Throughout this report, $f : \mathbb{R}^n \to \mathbb{R}$ denotes the objective function; $x^{\star}$ the global minimiser; $f^{\star} = f(x^{\star})$ the global minimum value; $\nabla f(x)$ the gradient; $H(x) = \nabla^2 f(x)$ the Hessian; $L$ the Lipschitz constant of $\nabla f$ (so $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$); $\mu > 0$ the strong convexity modulus (so $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$); and $\kappa = L/\mu$ the condition number. We use $\odot$ for element-wise (Hadamard) product, $\|\cdot\|$ for the Euclidean norm, and $O(\cdot)$ for big-O notation as the iteration count $k \to \infty$.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated from a linear model:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0,I_2), \quad y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
\label{eq:loss_A}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
The gradient and Hessian are:
\begin{equation}
\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y), \qquad H = \nabla^2 J = \frac{1}{m}X^T X.
\end{equation}
This is a strictly convex quadratic with constant Hessian. With the fixed seed (\texttt{np.random.seed(42)}), the Hessian eigenvalues are approximately $\lambda_1 \approx 0.9247$ and $\lambda_2 \approx 1.0325$, giving a condition number $\kappa(H) \approx 1.12$ --- nearly perfectly conditioned. Since $X \in \mathbb{R}^{m \times 2}$ with $m = 1000$ i.i.d.\ rows from $\mathcal{N}(0,I_2)$, by the law of large numbers $H = X^TX/m \to I_2$ as $m\to\infty$, so $\kappa(H) \to 1$: the near-unit condition number is expected for large $m$ with standardised features.

The minimiser is the ordinary least-squares (OLS) estimator $\hat{\theta} = (X^TX)^{-1}X^Ty \approx [3.028,\, 4.017]^T$, close to $\theta^{\star} = [3,4]^T$ due to the large sample size ($\hat\theta \to \theta^{\star}$ as $m\to\infty$ by consistency). The irreducible noise floor is $J^{\star} = J(\hat\theta) \approx 0.4826$; since the model is correctly specified with $\varepsilon^{(i)} \sim \mathcal{N}(0,1)$, the expected noise floor is $\mathbb{E}[J(\hat\theta)] = \sigma^2(m - 2)/(2m) \approx \sigma^2/2 = 0.5$ for large $m$, consistent with the observed value. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
\label{eq:loss_B}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are:
\begin{equation}
\nabla f = \begin{bmatrix} 2(x_1 - 1) + \cos(x_1) \\ 10(x_2 - 2) \end{bmatrix}, \qquad H(x) = \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}.
\end{equation}
Since the Hessian is diagonal and $x_2$-independent, $x_2^{\star} = 2$ exactly. The $x_1$-component satisfies $2(x_1-1) + \cos(x_1) = 0$, giving $x_1^{\star} \approx 0.5824$ numerically. The minimum function value is $f^{\star} \approx 0.7244$.

The Hessian eigenvalues vary with position: near the starting point $x_0 = [-1, 4]^T$, the condition number $\kappa \approx 3.5$; near the optimum, $\kappa \approx 6.9$. The sinusoidal term introduces mild non-convexity (the Hessian entry $H_{11} = 2 - \sin(x_1)$ can range from $1$ to $3$, staying positive throughout the region of interest), making this a challenging but tractable problem. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
\label{eq:loss_C}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian is:
\begin{equation}
H(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the optimum $(1,1)$: $H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}$. The eigenvalues satisfy $\lambda^2 - 1002\lambda + (802 \times 200 - 400^2) = \lambda^2 - 1002\lambda + 400 = 0$, giving $\lambda = (1002 \pm \sqrt{1002^2 - 1600})/2 = (1002 \pm \sqrt{1002404})/2$. Numerically: $\lambda_{\min} \approx 0.40$ and $\lambda_{\max} \approx 1001.6$, giving condition number $\kappa \approx 2508$. This extreme ill-conditioning has direct consequences for first-order methods: GD requires $O(\kappa)$ iterations per decade of convergence, meaning approximately 2508 iterations to reduce $f - f^{\star}$ by a factor of 10 with an optimal step size $\alpha = 2/(\lambda_{\min} + \lambda_{\max})$. The curved valley $x_2 = x_1^2$ means the Hessian is far from this diagonal structure away from the optimum: $H_{12} = -400x_1$ is large and negative for $x_1 < 0$, creating a strong coupling between coordinates that gradient descent cannot exploit. Starting point: $x_0 = [-1, 1]^T$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations. Let $f : \mathbb{R}^n \to \mathbb{R}$ be the objective, $g_k = \nabla f(x_k)$ the gradient at iteration $k$, and $\odot$ denote element-wise multiplication.

\begin{algorithm}[H]
\caption{Polyak Step Size \cite{polyak1969}}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Optimal step to $f^{\star}$ in one dimension}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step is theoretically optimal for subgradient methods when $f^{\star}$ is known. The step $\alpha_k = (f(x_k) - f^{\star})/\|g_k\|^2$ uniquely solves the 1D problem $\min_\alpha \|x_k - \alpha g_k - x^{\star}\|^2$: expanding, the distance from the projected point to $x^{\star}$ is $\|x_k - x^{\star}\|^2 - 2\alpha g_k^T(x_k - x^{\star}) + \alpha^2\|g_k\|^2$, minimised at $\alpha^{\star} = g_k^T(x_k - x^{\star})/\|g_k\|^2$. By the subgradient inequality, $f^{\star} \geq f(x_k) + g_k^T(x^{\star} - x_k)$, giving $g_k^T(x_k - x^{\star}) \geq f(x_k) - f^{\star}$; substituting yields the Polyak formula \cite{polyak1969}. For strongly convex $f$ with $f^{\star}$ known exactly, Polyak's rule achieves convergence at the optimal rate.

\begin{algorithm}[H]
\caption{Adagrad \cite{duchi2011}}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0 > 0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^n$ \Comment{Cumulative squared-gradient accumulator}
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate squared-gradient accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$ \Comment{Coordinate-adaptive step}
\EndFor
\end{algorithmic}
\end{algorithm}

The effective per-coordinate learning rate $\alpha_0/\sqrt{(G_k)_i + \varepsilon}$ decays monotonically. Adagrad was designed for sparse gradients and has a theoretical $O(\sqrt{T}/T)$ convergence guarantee for convex problems in terms of regret \cite{duchi2011}. The monotonic decay is a feature for sparse settings but a limitation for dense, stationary settings where the step eventually vanishes.

\begin{algorithm}[H]
\caption{RMSprop \cite{tieleman2012}}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0} \in \mathbb{R}^n$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces the cumulative accumulator of Adagrad with an exponentially weighted moving average, controlled by $\beta$. This forgetting mechanism prevents the learning rate from decaying to zero and allows adaptation to changing gradient scales.

\begin{algorithm}[H]
\caption{Heavy Ball (Polyak Momentum) \cite{polyak1964}}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^n$ \Comment{Velocity vector}
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Accumulate gradient momentum}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

For a quadratic objective with eigenvalues $\mu \leq \lambda \leq L$, the Heavy Ball method with optimal parameters $\alpha^{\star} = 4/(\sqrt{L} + \sqrt{\mu})^2$ and $\beta^{\star} = \left((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\right)^2$ achieves linear convergence with rate $(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$, which is strictly better than gradient descent's rate $(\kappa-1)/(\kappa+1)$ for ill-conditioned problems \cite{polyak1964}. These optimal parameters are the same as those of Nesterov on quadratics, confirming that both methods achieve the optimal first-order convergence rate on this function class.

\begin{remark}
Despite achieving the optimal quadratic rate, Heavy Ball has \emph{no convergence guarantee for general non-quadratic objectives}: the method can diverge or cycle on smooth non-convex functions. In contrast, Nesterov's method (Section~\ref{sec:q2}) achieves the optimal $O(1/k^2)$ rate for \emph{all} convex $L$-smooth functions via its lookahead gradient mechanism. The practical implication is that Heavy Ball requires careful hyperparameter tuning (especially $\beta$) on non-quadratic problems, whereas Nesterov with the prescribed $\beta_k$ schedule is provably safe.
\end{remark}

\subsection{Comparative Analysis and Theoretical Perspective}

\begin{theorem}[Polyak Convergence {\cite{polyak1969}}]
If $f$ is convex, $L$-smooth, and $f^{\star}$ is known exactly, the Polyak step-size rule satisfies
\[
f(x_{k+1}) - f^{\star} \leq \left(1 - \frac{\mu}{L}\right)(f(x_k) - f^{\star})
\]
for strongly convex $f$ with modulus $\mu$. When $f^{\star}$ is misspecified as $\tilde{f}^{\star} < f^{\star}$, the step size $\alpha_k \to \infty$ as $\|g_k\| \to 0$, causing divergence.
\end{theorem}

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q1_method_comparison.pdf}
\caption{Q1: Summary of final objective values after 120 iterations, all methods across all three benchmarks. The red dashed line marks $f^{\star}$ for each benchmark. On Benchmarks A and B, Polyak diverges (bar values truncated; true values 2.72 and 24.07 respectively). On Benchmark C (Rosenbrock), Polyak achieves the best result because $f^{\star} = 0$ is exactly known. Among the remaining methods, Heavy Ball is the most consistently strong performer on the ill-conditioned Benchmark C.}
\label{fig:q1_comparison}
\end{figure}

\textbf{Why does Heavy Ball outperform Adagrad on Rosenbrock?} This key finding warrants theoretical explanation. Adagrad's monotonically decreasing step is detrimental on Rosenbrock: the large gradients encountered near the starting point ($\|\nabla f(x_0)\| \approx 400$) cause the accumulator $G_k$ to grow rapidly, permanently shrinking the effective step far below what is needed to traverse the valley floor. Heavy Ball, by contrast, accumulates velocity \emph{in the consistent valley-floor direction} without any shrinkage mechanism. The momentum vector $z_k$ grows directionally along the valley, providing the large steps needed for meaningful progress despite the extreme condition number ($\kappa \approx 2508$). This illustrates a general principle: \emph{monotone step-decay methods can stagnate on ill-conditioned landscapes where sustained velocity is needed}.

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest (Rosenbrock: $f = 0.009$). Otherwise, Heavy Ball is the strongest performer on Benchmark C.
\item \textbf{Stability:} GD is most stable but slowest. Polyak is \emph{unstable} when $f^{\star}$ is misspecified. Adagrad is uniformly stable due to its monotonically decreasing step, though this may cause premature stagnation on ill-conditioned problems.
\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential averaging of gradient history. Heavy Ball introduces mild oscillation when $\beta$ is large, visible on Benchmark B.
\item \textbf{Practical guidance:} In practice, exact $f^{\star}$ is rarely available, limiting Polyak's applicability to specific problem classes (e.g., feasibility problems). For ill-conditioned optimisation without sparsity structure, Heavy Ball with well-tuned $\alpha$ and $\beta$ is the recommended choice among the Q1 methods. Note that Heavy Ball's optimal rate $\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k$ matches Nesterov's \emph{optimal first-order rate} on quadratics, but Heavy Ball does not achieve this rate on general non-quadratic functions unlike Nesterov's method.
\end{itemize}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient \cite{nesterov1983}}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Momentum schedule: $\beta_k \to 1$ as $k\to\infty$}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point (gradient evaluated ahead of current iterate)}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Update velocity at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The critical distinction from Heavy Ball is the \emph{lookahead evaluation}: the gradient is computed at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This allows Nesterov momentum to ``look ahead'' and correct its trajectory before overshooting, providing a stabilising feedback mechanism that Heavy Ball lacks. The schedule $\beta_k = (k-1)/(k+2)$ is the theoretically motivated choice achieving the optimal $O(1/k^2)$ convergence rate \cite{nesterov1983}.

\textbf{Motivation for the $\beta_k$ schedule:} The schedule $\beta_k = (k-1)/(k+2)$ arises from the recursion $t_{k+1} = \frac{1 + \sqrt{1 + 4t_k^2}}{2}$ (where $t_0 = 1$) that appears in the convergence proof. As $k \to \infty$, $\beta_k \to 1$, meaning the momentum fraction approaches 1 (maximum inertia). In early iterations, $\beta_k$ is small, giving cautious, GD-like steps; as $k$ grows, momentum increases, building velocity in the descent direction. The cap $\beta_{\max}$ prevents numerical instabilities for non-convex objectives. The key theoretical insight is that this \emph{increasing} momentum schedule allows the method to "build up speed" optimally while maintaining a sufficient decrease condition each step.

\begin{theorem}[Nesterov Optimal Rate {\cite{nesterov1983}}]
For convex, $L$-smooth $f$, Nesterov's accelerated gradient with $\alpha = 1/L$ satisfies
\[
f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2}.
\]
This $O(1/k^2)$ rate is optimal for first-order methods --- it matches the lower bound proved by Nesterov, whereas gradient descent achieves only $O(1/k)$.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser \cite{kingma2014}}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in [0,1)$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean) estimate}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (variance) estimate}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction: removes initialisation bias}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$ \Comment{Preconditioned momentum step}
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$, inheriting from Heavy Ball) with per-coordinate adaptive scaling (via $v_t$, inheriting from RMSprop). The bias correction terms $(1-\beta_1^t)$ and $(1-\beta_2^t)$ are essential in early iterations: without them, $m_t$ and $v_t$ are biased towards zero since they start at zero. The effective learning rate in Adam's update can be written as:
\begin{equation}
\alpha_t^{(i)} = \alpha \cdot \frac{\sqrt{1-\beta_2^t}}{1-\beta_1^t} \cdot \frac{1}{\sqrt{\hat{v}_{t,i}} + \varepsilon} \approx \frac{\alpha}{\sqrt{\hat{v}_{t,i}} + \varepsilon},
\end{equation}
which is approximately in $[\varepsilon^{-1}\alpha_{\min}, \alpha_{\max}]$ for bounded gradients. Adam achieves $O(T^{-1/4})$ convergence in the non-convex stochastic case, which is the optimal rate for the non-convex stochastic setting \cite{kingma2014}. In the deterministic setting, Adam does not have a formal convergence guarantee for non-convex problems: Reddi et al.\ (2018) constructed a simple convex online learning problem where Adam fails to converge, and proposed AMSGrad ($\hat{v}_t$ replaced by $\max(\hat{v}_{t-1}, \hat{v}_t)$) as a fix with convergence guarantees. For the experiments in this assignment (deterministic, non-convex Rosenbrock), Adam's empirical non-convergence is consistent with this theoretical limitation.

Adam's diagonal preconditioning ignores this correlation and may even hinder it by scaling $x_1$ and $x_2$ updates independently. Nesterov's isotropic momentum, by contrast, accumulates velocity in the joint direction of descent along the valley, correctly capturing the correlated structure. This explains the 3.3$\times$ performance gap ($f = 0.479$ vs $f = 1.578$) between Nesterov and Adam on Benchmark C.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs ($E = 50$), with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD \cite{robbins1951}}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\pi$
    \For{each mini-batch $\mathcal{B} = \{\pi(ib+1), \ldots, \pi((i+1)b)\}$, $i = 0,1,\ldots$}
        \State $\hat{g} \gets \dfrac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, \hat{g}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The stochastic gradient is an unbiased estimate of the full gradient: $\mathbb{E}[\hat{g}] = \nabla J(\theta)$. For a quadratic loss with observation noise $\sigma^2$, the mini-batch gradient covariance decomposes as:
\begin{equation}
\mathrm{Cov}[\hat{g}] = \frac{1}{b}\left(\frac{\sigma^2}{m} X^TX\right) + \underbrace{0}_{\text{full-batch term}},
\end{equation}
so the gradient variance scales as $\Sigma/b$ where $\Sigma = \frac{\sigma^2}{m}X^TX$ is determined by the data and noise. Doubling the batch size halves the gradient variance, halving the number of iterations required for the same convergence --- the \emph{linear scaling rule}: to match the convergence of batch size $b$ with learning rate $\alpha$, batch size $kb$ should use learning rate $k\alpha$. This fundamental rule (exploited in distributed training where $k$ parallel workers allow a $k$-fold increase in effective batch size) breaks down for very large $k$ due to the boundary effects on the noise floor. The key trade-off: smaller $b$ means more frequent updates per epoch but higher gradient variance; larger $b$ means fewer, higher-quality updates per epoch.

\centering
\includegraphics[width=0.85\textwidth]{figures/q2_sgd_batch.pdf}
\caption{Q2: Mini-batch SGD with different batch sizes (per-epoch loss). With $b = 5$, each epoch performs $1000/5 = 200$ parameter updates, enabling fast per-epoch convergence but with higher gradient variance. With $b = 40$, each epoch has only $1000/40 = 25$ updates, resulting in smoother but slower per-epoch progress. The smaller batch reaches lower loss faster in terms of epochs due to the 8$\times$ more frequent updates, but exhibits greater oscillation near the minimum as each mini-batch gradient deviates more from the true gradient.}

\begin{remark}
The mini-batch gradient variance decomposes as $\mathrm{Var}[\hat{g}] = \mathrm{Var}_{\text{obs}}/b + \mathrm{Var}_{\text{model}}/b$. When $\mathrm{Var}_{\text{obs}} = \sigma^2$ dominates, increasing $b$ does not meaningfully reduce variance, explaining the convergence to the same floor for both batch sizes under high noise.
\end{remark}

\begin{theorem}[SGD Convergence \cite{robbins1951}]
For a $\mu$-strongly convex, $L$-smooth objective and mini-batch stochastic gradients with variance $\sigma^2_{\text{sg}}/b$, SGD with constant step size $\alpha \leq 1/(2L)$ satisfies:
\[
\mathbb{E}[J(\theta_k)] - J^{\star} \leq \left(1 - \mu\alpha\right)^k \bigl(J(\theta_0) - J^{\star}\bigr) + \frac{\alpha \sigma^2_{\text{sg}}}{2\mu b}.
\]
The second term is an irreducible \emph{noise floor} $\propto \alpha/b$: it can be reduced by decreasing $\alpha$ or increasing $b$, but not eliminated with a constant step size. This floor explains why SGD converges to a neighbourhood of $J^{\star}$ rather than to $J^{\star}$ itself, with size proportional to $\sigma^2/b$. Reaching exact convergence requires a decaying step schedule (e.g., $\alpha_k = c/(k + k_0)$), but this slows the initial convergence.
\end{theorem}

\subsection{Local Taylor Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} at $x_0 = 0.25$: using $g(0.25) = 0.0039$, $g'(0.25) = 4(0.25)^3 = 0.0625$:
\begin{equation}
\label{eq:first_order}
g_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order approximation}: using additionally $g''(0.25) = 12(0.25)^2 = 0.75$:
\begin{equation}
\label{eq:second_order}
g_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises $g_2$ with respect to $x$, yielding the stationary condition $g'(x_0) + g''(x_0)(x_{k+1} - x_k) = 0$, i.e.:
\begin{equation}
\label{eq:newton_1d}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)}.
\end{equation}
In the multivariate setting this becomes $x_{k+1} = x_k - H_k^{-1} \nabla f(x_k)$, where $H_k = \nabla^2 f(x_k)$ is the Hessian. The Newton direction $p_k = -H_k^{-1}\nabla f(x_k)$ can be interpreted as a \emph{preconditioned gradient}: it applies the inverse Hessian as a preconditioning matrix that normalises the gradient by the local curvature, transforming the problem into one with an identity Hessian (perfectly conditioned) in the local coordinate system $\tilde{x} = H_k^{1/2}x$. This is why Newton's method converges in one step on quadratics (constant Hessian $\Rightarrow$ exact preconditioning everywhere) and achieves quadratic convergence on smooth non-quadratic functions (Hessian varies slowly $\Rightarrow$ preconditioning remains accurate).

\subsection{Newton's Method with Hessian Damping}

\begin{algorithm}[H]
\caption{Newton's Method with Hessian Regularisation}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0,1]$, damping $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation ensures $H_k \succ 0$}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (descent direction when $H_k \succ 0$)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{Damped Newton step ($\alpha=1$: full Newton)}
\EndFor
\end{algorithmic}
\end{algorithm}

The damping $\lambda = 10^{-8}$ ensures $H_k$ is positive definite even when the Hessian is indefinite (which can occur for the Rosenbrock function far from the optimum). The step $\alpha < 1$ is necessary when the quadratic model is a poor approximation, e.g., in regions of high curvature variation. Computational cost per iteration: $O(n^2)$ for gradient/Hessian evaluation and $O(n^3)$ for the linear system solve $H_k p_k = g_k$ (using Cholesky decomposition for symmetric positive definite $H_k$).

\begin{theorem}[Newton Quadratic Convergence \cite{nocedal2006}]
In a neighbourhood of a strict local minimiser $x^{\star}$ where $\nabla^2 f(x^{\star}) \succ 0$ and $\nabla^2 f$ is Lipschitz continuous, the full Newton step ($\alpha=1$) satisfies:
\[
\|x_{k+1} - x^{\star}\| \leq C\|x_k - x^{\star}\|^2
\]
for some constant $C > 0$ depending on $L$ (Hessian Lipschitz constant) and $\mu$ (strong convexity). This \emph{quadratic convergence} means the number of correct decimal digits roughly doubles at each iteration, compared to the linear convergence of gradient descent.
\end{theorem}

For Benchmark A, the Hessian is constant ($L=0$), so even one step achieves machine precision. For Benchmarks B and C, damping ($\alpha < 1$) reduces convergence to super-linear but is necessary for global convergence.

\textbf{Computational cost comparison:} Each Newton iteration costs $O(n^3)$ for the Hessian solve (here $n=2$, so $O(8)$), plus $O(n^2)$ for Hessian evaluation. Each GD iteration costs $O(n)$ for the gradient. The key comparison is: Newton uses 20 iterations vs GD's 80 iterations, achieving 5$\times$ better results on Rosenbrock with only $0.25\times$ the iteration count. In $n=2$ dimensions, Newton's higher per-iteration cost is negligible.

\textbf{Quasi-Newton and L-BFGS:} For $n \gg 1$, forming and inverting the full Hessian is prohibitive: $O(n^2)$ memory to store $H$ and $O(n^3)$ per solve. The \emph{Limited-memory BFGS (L-BFGS)} algorithm \cite{nocedal2006} addresses this by maintaining only the last $m$ curvature pairs
\[
(s_i,\, y_i) = (x_{i+1} - x_i,\; \nabla f(x_{i+1}) - \nabla f(x_i)), \quad i = k-m,\ldots,k-1,
\]
and applying a two-loop recursion to compute $H_k^{-1}g_k$ in $O(mn)$ time without explicitly forming $H_k^{-1}$. With $m = 5$--$20$, L-BFGS achieves \emph{superlinear convergence} in practice (faster than linear convergence of GD, but slower than quadratic convergence of Newton). The BFGS update satisfies the secant condition $H_{k+1}s_k = y_k$, ensuring the approximate Hessian interpolates the true curvature in the most recent direction. L-BFGS is the standard workhorse for large-scale smooth optimisation ($n = 10^4$--$10^7$), sitting between the extremes of GD ($O(n)$ per step, no curvature) and Newton ($O(n^3)$ per step, exact curvature).

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}
% ============================================================

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Forward Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with a function-value ratio:
\begin{equation}
\label{eq:fd}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \qquad e_i \in \mathbb{R}^n \text{ the $i$-th unit vector.}
\end{equation}
The approximation error has two competing sources:
\begin{itemize}[nosep]
  \item \textbf{Truncation error:} $O(\delta)$ from ignoring higher-order Taylor terms. For Benchmark B, with $\|H\| \approx 10$, the leading error term is approximately $\tfrac{1}{2}\delta\|H\| = 5\delta$.
  \item \textbf{Floating-point roundoff:} $O(\varepsilon_{\text{machine}}/\delta)$ since function values are computed to precision $\varepsilon_{\text{machine}} \approx 10^{-16}$.
\end{itemize}
The total error $E(\delta) \approx c_1 \delta + c_2/\delta$ is minimised at $\delta^{\star} = \sqrt{c_2/c_1} \approx \sqrt{\varepsilon_{\text{machine}}} \approx 10^{-8}$. The assignment tests $\delta = 0.05$ (mild overestimate but acceptable) and $\delta = 0.8$ (gross overestimate causing severe truncation error).

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order) \cite{nesterov2017}}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_n)$; normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform direction on sphere}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The estimator $\hat{g}_k$ is a biased gradient estimator: $\mathbb{E}[\hat{g}_k] = \nabla f_\delta(x_k)$ where $f_\delta$ is a Gaussian-smoothed version of $f$. For small $\delta$, $\nabla f_\delta \approx \nabla f$. The key advantage is \emph{dimension independence}: exactly 2 function evaluations per iteration regardless of the number of parameters $n$, compared to $n+1$ for forward FD. The cost is high variance: the random direction $u_k$ is an inefficient estimator of the gradient with variance $\propto n$.

\begin{theorem}[Zeroth-Order Convergence Rate \cite{nesterov2017}]
For an $L$-smooth convex function $f$ minimised via Nesterov random search with appropriately tuned step size, after $k$ iterations:
\[
\mathbb{E}[f(x_k)] - f^{\star} = O\!\left(\frac{nL\|x_0 - x^{\star}\|^2}{k}\right).
\]
The factor of $n$ compared to gradient descent's $O(L\|x_0-x^{\star}\|^2/k)$ rate directly quantifies the cost of gradient information loss: to achieve the same precision as GD in $k$ iterations, random search requires $nk$ iterations, or equivalently $2nk$ function evaluations vs $(n+1)k$ for coordinate-wise FD.
\end{theorem}

\textbf{Variance analysis:} For uniform $u$ on the unit sphere in $\mathbb{R}^n$, the expected squared norm of the directional derivative estimator satisfies (for small $\delta$):
\begin{equation}
\mathbb{E}_u\!\left[\|\hat{g}_k\|^2\right] = \mathbb{E}_u\!\left[\frac{(f(x+\delta u) - f(x))^2}{\delta^2}\,uu^T\right] \approx \frac{\|\nabla f(x)\|^2}{n} \cdot n \cdot n = n\|\nabla f(x)\|^2,
\end{equation}
where the factor arises because $\mathbb{E}_u[(\nabla f^T u)^2 uu^T] = \frac{1}{n}\|\nabla f\|^2 I_n$ and $\|\hat{g}\|^2 = (\nabla f^T u)^2$. The variance grows \emph{linearly with $n$}: in a 1000-dimensional problem, the estimator has 1000$\times$ higher second moment than in 1D, severely degrading the signal-to-noise ratio for high-dimensional optimisation.

\textbf{Comparison to related zeroth-order methods:}
\begin{itemize}[nosep]
  \item \textbf{Coordinate-wise FD (Kiefer-Wolfowitz):} Uses $n$ coordinate perturbations, giving $O(n)$ FE/iter and producing a full gradient estimate with $O(\delta^2)$ bias (central differences) or $O(\delta)$ bias (forward differences). Equivalent to the FD gradient descent in Part A.
  \item \textbf{SPSA (Simultaneous Perturbation Stochastic Approximation):} Uses a random $\pm 1$ Rademacher perturbation $\Delta_k \in \{-1,+1\}^n$, estimating $\hat{g}_k = \frac{f(x+\delta\Delta_k)-f(x-\delta\Delta_k)}{2\delta}\Delta_k^{-1}$ (element-wise). This achieves 2 FE/iter regardless of $n$, like Nesterov RS, with similar variance $\propto n$. SPSA is designed for \emph{stochastic} objectives where even the function value is noisy.
  \item \textbf{Evolution Strategies (ES):} Maintains a population of $\lambda$ candidates $f(x + \sigma\epsilon_i)$ for $\epsilon_i \sim \mathcal{N}(0,I)$. The gradient estimator $\hat{g} = \frac{1}{\lambda\sigma}\sum_i f(x+\sigma\epsilon_i)\epsilon_i$ reduces variance by $\lambda$ via averaging, at the cost of $2\lambda$ FE/iter. Used in reinforcement learning (where $n$ can be millions and gradients are unavailable) with $\lambda \approx 1000$ parallel workers.
\end{itemize}
The key message is that \emph{all 2-FE-per-iteration zeroth-order methods pay a $\Theta(n)$ factor in convergence rate}: this is an information-theoretic lower bound, not an algorithmic deficiency. When $n$ is small (as in this $n=2$ experiment), the 2-FE/iter advantage can outweigh the slower per-step progress, but for $n \geq 100$, first-order methods become strongly preferable whenever gradient information is available.

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm \cite{nelder1965} maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively reshapes it through four operations applied in order of preference:
\begin{enumerate}[nosep]
  \item \textbf{Reflection} ($\alpha_r = 1.0$): Move the worst vertex $x_h$ through the centroid $\bar{x}$ of the remaining vertices: $x_r = \bar{x} + 1.0(\bar{x} - x_h)$.
  \item \textbf{Expansion} ($\gamma = 2.0$): If reflection improved, try $x_e = \bar{x} + 2.0(\bar{x} - x_h)$.
  \item \textbf{Contraction} ($\rho = 0.5$): If reflection worsened, contract towards centroid.
  \item \textbf{Shrink} ($\sigma = 0.5$): If contraction also worsens, contract all vertices towards the best.
\end{enumerate}
Settings: initial simplex step $= 0.35$, 160 iterations. No gradient information is required.

\textbf{Key insight:} The choice of derivative-free method depends critically on the problem dimension and available budget. For $d = 2$, Nelder--Mead is the most effective derivative-free method as it exploits the simplex geometry. For large $d$, Nesterov random search is preferable despite its slow per-step convergence because its $O(2)$ FE/iter cost is dimension-independent. Grid search is the only method that provably finds the global optimum to within resolution, but its $O(N^d)$ cost is prohibitive for $d \geq 4$.

\textbf{Theoretical limitations of Nelder--Mead:} Despite excellent practical performance, Nelder--Mead has no general convergence guarantee: McKinnon (1998) constructed a 2D example of a smooth, strongly convex function where Nelder--Mead converges to a non-stationary point. The issue is that the simplex can collapse into a lower-dimensional object (degenerate simplex), after which it cannot recover. In practice, the restart strategy (re-initialise the simplex when volume falls below a threshold) mitigates this, and Nelder--Mead performs well on smooth $d \leq 10$ problems. For the Rosenbrock function with its narrow curved valley, the simplex's adaptive reshaping (elongation along the valley) is particularly effective. The convergence rate is super-linear in practice but $O(1/k)$ in the worst case for smooth convex functions \cite{nocedal2006}.

\textbf{Comparison of finite difference step sizes:} At the starting point $x_0 = (-1, 4)$, the true gradient $\nabla f(x_0) \approx [g_1, g_2]$ with $g_1 = 2(-2) + \cos(-1) \approx -3.46$ and $g_2 = 10(4-2) = 20$. The forward FD approximation with $\delta = 0.05$ has truncation error $\tfrac{1}{2}\delta \cdot H_{11} \approx 0.5 \times 0.05 \times 2.84 \approx 0.07$ for the $x_1$ component --- a relative error of $\approx 2\%$, explaining the close agreement with exact GD. With $\delta = 0.8$, the truncation error is $\approx 1.14$, a relative error of $\approx 33\%$, completely corrupting the gradient direction and causing the observed divergence from the exact GD trajectory. This quantitatively confirms the importance of choosing $\delta \ll \|\nabla f\|/\|H\|$, i.e., the step should be much smaller than the ratio of gradient magnitude to curvature. An even better approach is \emph{central differences}: $[f(x + \delta e_i) - f(x - \delta e_i)]/(2\delta)$, which achieves $O(\delta^2)$ truncation error with the same $2$ function evaluations per coordinate --- squaring the accuracy for no additional cost.

\subsection{Problem Setup}

Minimise Benchmark B~\eqref{eq:loss_B} subject to the inequality constraint $x_1 \geq 0.5$, starting from the \emph{infeasible} initial point $x_0 = (0.2, 4.0)^T$:
\begin{equation}
\label{eq:constrained_problem}
\min_{x \in \mathbb{R}^2} f(x_1, x_2) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1) \qquad \text{subject to } x_1 \geq 0.5.
\end{equation}

\textbf{Important structural observation:} The unconstrained minimiser of $f$ is $x^{\star} = (0.5824, 2.0)^T$ with $f^{\star} \approx 0.7244$. Since $x^{\star}_1 = 0.5824 > 0.5$, the constraint $x_1 \geq 0.5$ is \emph{inactive} at the unconstrained optimum. Consequently, the constrained and unconstrained problems share the same optimal solution:
\begin{equation}
\label{eq:inactive_constraint}
x^{\star}_{\text{constrained}} = x^{\star}_{\text{unconstrained}} = (0.5824,\; 2.0)^T, \qquad f^{\star}_{\text{constrained}} = f^{\star}_{\text{unconstrained}} \approx 0.7244.
\end{equation}
The challenge of this problem is therefore not in finding a constrained solution that differs from the unconstrained one, but in correctly handling the \emph{infeasible starting point} $x_0 = (0.2, 4.0)$ and ensuring feasibility throughout the trajectory.

\textbf{KKT Conditions:} At the optimal solution $(0.5824, 2.0)$, the KKT stationarity conditions for \eqref{eq:constrained_problem} are:
\begin{equation}
\nabla f(x^{\star}) - \mu \begin{bmatrix}1\\0\end{bmatrix} = 0, \quad \mu \geq 0, \quad \mu(x^{\star}_1 - 0.5) = 0.
\end{equation}
Since the constraint is inactive ($x^{\star}_1 = 0.5824 > 0.5$), complementary slackness gives $\mu = 0$, and the stationarity condition reduces to $\nabla f(x^{\star}) = 0$ --- the unconstrained optimality condition. This confirms that the constrained optimum is interior to the feasible set.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step (may leave feasible set)}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project back: $x_1 \leftarrow \max(0.5,\, x_1)$ (trivial for half-space)}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Quadratic Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\State Define penalised objective: $F_{\lambda}(x) = f(x) + \lambda \max(0,\, -x_1 + 0.5)$
\For{$k = 0, 1, \ldots, N-1$}
    \State Compute $\nabla F_{\lambda}(x_k)$: $\partial_{x_1}F_\lambda = \partial_{x_1}f(x_k) - \lambda\, \mathbf{1}[x_{1,k} < 0.5]$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$ to maintain stability), unconstrained GD ($\alpha = 0.07$). All methods run for 100 iterations.

\textbf{Projected GD} enforces feasibility as a \emph{hard constraint} at every iteration. This is its fundamental advantage: feasibility is guaranteed regardless of the step size or penalty weight. The projection onto a half-space $\{x : x_1 \geq 0.5\}$ is trivially $\Pi(z) = (\max(0.5, z_1), z_2)$ in $O(1)$ cost. For a $\mu$-strongly convex, $L$-smooth objective, projected gradient descent on a convex set converges at the same linear rate as unconstrained gradient descent: $f(x_k) - f^{\star} \leq (1 - \mu/L)^k (f(x_0) - f^{\star})$ \cite{nocedal2006}. The projection step does not worsen the convergence rate; it merely restricts the iterates to the feasible set.

\textbf{Penalty methods} trade exact feasibility for simplicity: only gradient evaluations of the augmented objective $F_\lambda$ are needed. The penalty weight $\lambda$ controls the trade-off between optimality and feasibility. As $\lambda \to \infty$, the penalised solution $x^{\star}(\lambda)$ converges to the constrained solution $x^{\star}$, but the penalised objective $F_\lambda$ becomes increasingly ill-conditioned with condition number $\kappa(F_\lambda) \approx \max(\kappa(f), \lambda/\mu)$, requiring smaller step sizes to maintain stability. This is the fundamental limitation of the pure penalty approach: the conditioning worsens exactly when the constraint needs to be most strongly enforced.

An improvement is the \emph{augmented Lagrangian} (or method of multipliers) method, which adds both a penalty term and a dual variable (Lagrange multiplier) $\hat\mu$:
\begin{equation}
\mathcal{L}_\lambda(x, \hat\mu) = f(x) + \hat\mu \max(0, -x_1 + 0.5) + \frac{\lambda}{2}\max(0, -x_1 + 0.5)^2.
\end{equation}
The dual update rule $\hat\mu_{j+1} = \max(0, \hat\mu_j - \lambda(x_{1,j} - 0.5))$ shifts the penalty centre towards the constraint boundary, achieving exact feasibility without requiring $\lambda \to \infty$. Concretely, for fixed (moderate) $\lambda$, the augmented Lagrangian method converges to exact feasibility via the dual update, whereas the pure penalty method needs $\lambda \to \infty$ for exact feasibility but suffers from the conditioning bound $\kappa(F_\lambda) \lesssim \lambda/\mu$. This is the key advantage of augmented Lagrangian: it achieves $\lambda$-independent conditioning while still enforcing feasibility exactly in the limit.

In this experiment, the constraint is inactive at the solution, so even $\lambda = 0.15$ eventually reaches the correct objective value --- the penalty gradient drives the iterate towards feasibility, but the inactive constraint means the optimal solution is not on the boundary and the penalty weight has little effect on the final objective value once feasibility is achieved.

\textbf{Penalty parameter selection:} In practice, a good choice balances feasibility enforcement and conditioning. A rule of thumb is to set $\lambda$ such that the penalty term $\lambda|v(x_0)|$ (where $v(x) = \max(0, 0.5 - x_1)$ is the violation) is of the same order as $\|\nabla f(x_0)\|$: at $x_0 = (0.2, 4.0)$, the violation $|v(x_0)| = 0.3$ and $\|\nabla f(x_0)\| = \sqrt{(-0.62)^2 + (20)^2} \approx 20$, suggesting $\lambda \approx 20/0.3 \approx 66$. The experimental values $\lambda \in \{0.15, 1.8, 4.5\}$ are all well below this, which explains why even $\lambda = 4.5$ does not enforce feasibility very aggressively. An increasing penalty schedule $\lambda_j = \rho^j \lambda_0$ (geometric growth with $\rho > 1$) is the standard strategy for the penalty method, avoiding the need to choose $\lambda$ precisely.

\subsection{Feasible Set and Linear Programme}

The feasible set is the box $\mathcal{X}$ defined in~\eqref{eq:feasible_set}: $\mathcal{X} = [0.5, 5] \times [-5, 10]$.

\textbf{Linear Programme:} Minimise $f(x) = a^T x = x_1 + 2x_2$ over $\mathcal{X}$ (where $a = [1, 2]^T$). Since both components of $a$ are positive, the linear objective decreases in both coordinate directions, and the minimum is attained at the lower bound in each dimension:
\begin{equation}
\label{eq:lp_solution}
x^{\star} = \begin{bmatrix} 0.5 \\ -5 \end{bmatrix}, \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}
This exemplifies the \textbf{Fundamental Theorem of Linear Programming}: the minimum of a linear objective over a bounded polytope is always attained at a vertex (extreme point). \emph{Proof sketch:} For any interior or edge point $x \in \mathcal{X}$, there exists a feasible direction $d \neq 0$ such that $a^Td \leq 0$ (i.e., moving along $d$ does not increase the objective). Following $d$ until the boundary gives a point with objective value $\leq a^Tx$, so the minimum cannot be in the interior. By induction on faces, the minimum is attained on a face of dimension 0 --- a vertex. For the box $\mathcal{X}$, the vertices are $(0.5,-5)$, $(5,-5)$, $(0.5,10)$, $(5,10)$, and evaluating $f = x_1 + 2x_2$ at each: $f(0.5,-5)=-9.5$, $f(5,-5)=-5$, $f(0.5,10)=20.5$, $f(5,10)=25$. The minimum is at $(0.5,-5)$ with $f^{\star} = -9.5$.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) \cite{frank1956}}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination (stays in $\mathcal{X}$)}
\EndFor
\end{algorithmic}
\end{algorithm}

For box constraints, the LMO decouples by coordinate:
\begin{equation}
\label{eq:fw_lmo}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
This requires $O(d)$ operations per iteration with no projection oracle. Since $x_{k+1}$ is a convex combination of $x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$ (vertices lie in $\mathcal{X}$), feasibility is maintained automatically: $x_{k+1} \in \mathcal{X}$ for all $k$. The formula~\eqref{eq:fw_lmo} follows immediately from: $\arg\min_{x \in [l_i, u_i]} g_i x$ equals $l_i$ if $g_i > 0$ (objective decreases towards lower bound) and $u_i$ if $g_i \leq 0$ (objective decreases towards upper bound).

For this feasible set, the box diameter is $D = \|(5-0.5, 10-(-5))\| = \|(4.5, 15)\| = \sqrt{4.5^2 + 15^2} \approx 15.66$.

\begin{theorem}[Frank--Wolfe Convergence \cite{frank1956}]
For convex, $L$-smooth $f$ minimised over a compact convex set $\mathcal{X}$ with diameter $D = \max_{x,y \in \mathcal{X}} \|x - y\|$, the Frank--Wolfe algorithm with step size $\gamma_k = 2/(k+2)$ satisfies:
\[
f(x_k) - f^{\star} \leq \frac{2LD^2}{k+2} = O\!\left(\frac{1}{k}\right).
\]
For the interior optimum problem with $L = 2$ and $D \approx 15.66$, this gives the bound $f(x_k) - f^{\star} \leq 490.5/(k+2)$, predicting $f(x_{180}) - f^{\star} \lesssim 2.7$. The actual value $f \approx 0.005$ is far better because the bound is loose (the diameter $D$ over-estimates the effective problem size). This rate is worse than the $O(1/k^2)$ achievable by projected gradient descent with Nesterov acceleration, the price for avoiding projection.
\end{theorem}

The \textbf{Frank--Wolfe gap} $g_k = \nabla f(x_k)^T (x_k - z_k) \geq 0$ measures the sub-optimality and serves as a stopping criterion: $g_k = 0 \Rightarrow x_k$ is optimal. Non-negativity follows from convexity: $f^{\star} \geq f(x_k) + \nabla f(x_k)^T(x^{\star} - x_k) \geq f(x_k) - \nabla f(x_k)^T(x_k - x^{\star}) \geq f(x_k) - g_k$ (since $z_k = \arg\min_{z\in\mathcal{X}}\nabla f(x_k)^T z \leq \nabla f(x_k)^T x^{\star}$, so $\nabla f(x_k)^T x_k - g_k = \nabla f(x_k)^T z_k \leq \nabla f(x_k)^T x^{\star}$). In the implementation, $\beta$ is fixed (rather than using the optimal $\gamma_k = 2/(k+2)$), which modifies the effective step size and may sacrifice the $O(1/k)$ convergence guarantee.

\subsection{Interior vs Boundary Behaviour and Theoretical Implications}

\textbf{Interior optimum:} Frank--Wolfe converges but exhibits a characteristic ``zig-zag'' pattern as $z_k$ alternates between extreme vertices of $\mathcal{X}$. The convex combination gradually averages these jumps, but the oscillation never fully disappears with a fixed $\beta$. As shown in Figure~\ref{fig:q6_fw_gap}, the standard decaying schedule $\gamma_k = 2/(k+2)$ provides both the $O(1/k)$ convergence guarantee and smoother behaviour, outperforming fixed $\beta$ strategies. The fundamental limitation is that Frank--Wolfe is inherently a \emph{first-order method} with the $O(1/k)$ rate it cannot exceed without second-order information.

\textbf{Boundary optimum:} Frank--Wolfe is particularly well-suited to boundary optima: the LMO naturally selects the vertex closest to the constrained solution, and the iterate drifts towards the boundary without explicit projection. However, the $O(1/k)$ rate means that achieving high accuracy requires many iterations. In Table~\ref{tab:q6_final}, the boundary case achieves $f = 0.364$ vs $f^{\star} = 0.25$ after 140 iterations --- a 46\% sub-optimality gap, reflecting the slow convergence near the boundary with a fixed $\beta$ schedule.

\textbf{Comparison with Projected Gradient:} Projected gradient descent can achieve $O(1/k^2)$ (with Nesterov) on this problem at the cost of computing the projection $\Pi_{\mathcal{X}}(z) = (\text{clip}(z_1, 0.5, 5), \text{clip}(z_2, -5, 10))$ (O(1) for boxes). Frank--Wolfe becomes advantageous when the constraint set is complex (e.g., nuclear norm ball, flow polytope, spectrahedron) where the LP subproblem is efficiently solvable but projection is expensive or intractable. For the simple box constraint in this experiment, projected gradient is strictly preferable due to its faster convergence rate.

\textbf{Away-steps Frank--Wolfe:} The standard FW update $x_{k+1} = (1-\gamma_k)x_k + \gamma_k z_k$ moves \emph{towards} the LP vertex $z_k$. A limitation is that this convex combination can only ``approach'' a new extreme point but cannot move away from a vertex that was previously visited --- causing the zig-zag behaviour observed for interior optima. The \emph{away-steps Frank--Wolfe} variant \cite{frank1956} introduces an additional away step:
\begin{equation}
v_k = \arg\max_{v \in \mathcal{S}_k} \nabla f(x_k)^T v,
\end{equation}
where $\mathcal{S}_k$ is the active set (vertices used in the convex combination representing $x_k$). The method then chooses between the standard towards-step (with $\gamma_k^{\max} = 1$) and the away-step (with $\gamma_k^{\max} = \alpha_k/(1-\alpha_k)$ where $\alpha_k$ is the weight on $v_k$), selecting whichever gives a larger FW gap decrease. Away-steps FW achieves \emph{linear convergence} (rate $O(\rho^k)$ for $\rho < 1$) on strongly convex objectives, rather than the $O(1/k)$ sublinear rate of standard FW --- a qualitative improvement that comes at the cost of maintaining the active set representation of $x_k$.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has conducted a systematic comparative study of optimisation algorithms across six paradigms and three benchmark problems of increasing difficulty.

\subsection*{Summary of Key Findings}

\textbf{Adaptive step-size methods (Q1):} The Polyak step provides optimal convergence when $f^{\star}$ is known exactly, but catastrophically diverges when $f^{\star}$ is misspecified (a fundamental practical limitation). Adagrad's monotonically decaying step makes it stable but can cause premature slowdown. RMSprop's exponential moving average of gradient squares avoids Adagrad's vanishing step issue. Heavy Ball, while lacking Nesterov's theoretical guarantees, provides substantial acceleration on ill-conditioned problems through momentum.

\textbf{Momentum and stochastic methods (Q2):} Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ first-order convergence rate, outperforming all other first-order methods on the Rosenbrock benchmark by a factor of 7$\times$ over GD. Adam combines the benefits of momentum and adaptive scaling but underperforms Nesterov on strongly non-quadratic problems. Mini-batch SGD demonstrates the batch-size trade-off: smaller batches provide more frequent but noisier updates, with the relative advantage diminishing under high observation noise.

\textbf{Newton's method (Q3):} Second-order methods are fundamentally superior on well-conditioned problems: Newton solves the quadratic benchmark (Benchmark A) in a single iteration. On the Rosenbrock function ($\kappa \approx 2508$), damped Newton achieves a 5.4$\times$ improvement over GD in 25\% of the iterations. The $O(n^3)$ cost of the Hessian solve limits applicability in high dimensions, but for small $n$, Newton's method has no competitor.

\textbf{Derivative-free methods (Q4):} Forward finite differences with an appropriate step ($\delta = 0.05$) closely approximate exact gradient descent; a poor step ($\delta = 0.8$) degrades gradient quality significantly. Nesterov random search is dimension-independent in FE cost but converges slowly due to single-direction gradient projection. Nelder--Mead effectively navigates the Rosenbrock valley without gradients, while grid search guarantees global optimum discovery at the prohibitive cost of $O(N^d)$ evaluations.

\textbf{Constrained optimisation (Q5):} Projected gradient descent enforces feasibility as a hard constraint from iteration 1, making it the most reliable method. For this problem, the inequality constraint $x_1 \geq 0.5$ is inactive at the optimal solution ($x^{\star}_1 \approx 0.582 > 0.5$), so the constrained and unconstrained optima coincide. Penalty methods enforce feasibility approximately, with feasibility quality increasing with penalty weight $\lambda$ at the cost of conditioning.

\textbf{Frank--Wolfe (Q6):} The Frank--Wolfe algorithm avoids projection by solving a linear subproblem, maintaining feasibility through convex combinations. It converges at $O(1/k)$, slower than projected gradient with Nesterov acceleration, but is preferred when the constraint set (e.g., nuclear norm ball, flow polytope) admits efficient LP solves but expensive projections. The algorithm naturally progresses towards boundary optima and exhibits characteristic vertex-oscillation near interior optima. The theoretically motivated decaying step $\gamma_k = 2/(k+2)$ outperforms fixed $\beta$ strategies in both gap decay and final objective value (Figure~\ref{fig:q6_fw_gap}).

\subsection*{Overall Ranking by Benchmark}

\begin{itemize}[nosep]
  \item \textbf{Benchmark A} (well-conditioned quadratic, $\kappa \approx 1.12$): Newton $\gg$ all first-order methods (single-step convergence). Among first-order methods: all converge to the noise floor $J^{\star} \approx 0.4826$ within 80--120 iterations with no significant differences.
  \item \textbf{Benchmark B} (mildly non-quadratic, $\kappa \approx 3.5$--$6.9$): Newton $>$ Nesterov $\approx$ Adam $\approx$ Adagrad $\approx$ Heavy Ball $\approx$ GD. All methods converge to $f^{\star} \approx 0.7244$; differences are in convergence speed, not final quality.
  \item \textbf{Benchmark C} (Rosenbrock, $\kappa \approx 2508$): Newton ($\alpha=0.22$) $>$ Polyak ($f^{\star}=0$ exact) $>$ Nesterov $>$ Heavy Ball $>$ Adam $>$ Adagrad $>$ GD $\approx$ RMSprop. Curvature exploitation and momentum are essential for meaningful progress on this ill-conditioned problem.
\end{itemize}

\subsection*{Unifying Principles}

Across all six questions, the experiments confirm three fundamental principles of optimisation:

\begin{enumerate}[nosep]
  \item \textbf{Curvature is everything:} Methods that exploit or adapt to curvature --- Newton (explicit Hessian), Adam/RMSprop (diagonal curvature adaptation), Nesterov (momentum) --- consistently outperform plain gradient descent on ill-conditioned problems. The condition number $\kappa$ is the single most important predictor of relative method performance.
  \item \textbf{Prior knowledge has value but fragility:} The Polyak step demonstrates that prior knowledge ($f^{\star}$) enables optimal convergence but makes the method brittle. When knowledge is imperfect, the method fails catastrophically. This trade-off between oracle power and robustness is a recurring theme.
  \item \textbf{Feasibility vs optimality:} Constrained optimisation introduces a genuine tension between reaching the optimal solution and maintaining feasibility. Projected gradient resolves this by treating feasibility as paramount (hard constraint); penalty methods resolve it approximately, trading feasibility for algorithmic simplicity. The Frank--Wolfe algorithm sidesteps both by embedding feasibility into the algorithmic structure via convex combinations.
\end{enumerate}

The experimental results align well with theoretical predictions: second-order methods are most effective when the cost of Hessian computation is affordable; Nesterov acceleration provides optimal first-order guarantees; and the Polyak step exemplifies the practical fragility of methods requiring prior knowledge of the optimal value. The Rosenbrock function, with its condition number of $\kappa \approx 2508$, serves as a stringent discriminator separating methods by their ability to handle ill-conditioning.

\subsection*{Limitations and Extensions}

Several limitations of this study are worth noting. First, all benchmarks are low-dimensional ($n = 2$), which may overstate the performance of methods whose per-iteration cost grows with $n$ (Newton: $O(n^3)$) and understate the advantage of truly dimension-free methods (Nesterov random search). Second, all problems are either convex or near-convex; the relative advantages of Nesterov and Newton may differ significantly on highly non-convex loss landscapes (e.g., deep neural networks with saddle points). Third, the comparison of first-order methods depends on hyperparameter tuning, which was done manually; practical methods use adaptive hyperparameter search (e.g., grid search over $\alpha$, $\beta$), and relative rankings may change.

Natural extensions include: (i) testing on higher-dimensional benchmarks ($n = 10^3$--$10^6$) where L-BFGS and coordinate descent become competitive; (ii) incorporating line search (Wolfe conditions, Armijo backtracking) to remove the need for manual step size selection; (iii) studying non-convex objectives with multiple local minima, where global methods (simulated annealing, genetic algorithms) would be relevant; and (iv) investigating variance reduction techniques for SGD (SVRG, SARAH) that achieve linear convergence without the noise floor limitation of constant-step SGD.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Hessian Regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
