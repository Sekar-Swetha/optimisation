\begin{abstract}
This report presents a comprehensive comparative study of first-order and second-order optimisation algorithms applied to three benchmark problems of increasing difficulty: a linear regression quadratic loss (Benchmark A), a toy neural network loss with sinusoidal perturbation (Benchmark B), and the ill-conditioned Rosenbrock function (Benchmark C). Six categories of methods are investigated: (1) adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball); (2) momentum-based and stochastic methods (Nesterov acceleration, Adam, mini-batch SGD); (3) Newton's method with local quadratic approximations; (4) derivative-free and derivative-approximation approaches (finite differences, Nesterov random search, Nelder--Mead, grid search); (5) constrained optimisation via projected gradient descent and penalty methods; and (6) the Frank--Wolfe algorithm for box-constrained problems.

Key findings include: the Polyak step size diverges catastrophically when $f^{\star}$ is misspecified but achieves the best Rosenbrock convergence ($f = 0.009$) when $f^{\star}$ is exact; Nesterov acceleration achieves near-optimal $O(1/k^2)$ convergence and outperforms Adam on Rosenbrock ($f = 0.479$ vs $f = 1.578$); Newton's method solves the quadratic benchmark in a single iteration and reduces Rosenbrock loss by $5\times$ compared to gradient descent in only 20 iterations; Nelder--Mead navigates the Rosenbrock valley gradient-free while grid search suffers exponential scaling; projected gradient descent enforces feasibility as a hard constraint from the first iteration, while penalty methods with insufficient weight $\lambda = 0.15$ fail to enforce it; and Frank--Wolfe converges without projection for the boundary-constrained case. Each method is analysed in terms of convergence rate, sensitivity to problem conditioning, and practical trade-offs.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation lies at the heart of modern machine learning and data analysis: training a neural network, fitting a regression model, and solving a control problem all reduce to minimising some loss function. The choice of optimisation algorithm profoundly affects both the quality and efficiency of the solution, and different algorithms exhibit vastly different behaviour depending on the structure of the objective.

This report addresses six fundamental categories of optimisation methods studied in CS7DS2, evaluated on a common set of benchmark problems of increasing difficulty. The key questions are:
\begin{enumerate}[nosep]
\item How do adaptive step-size rules mitigate the need to hand-tune the learning rate?
\item When does momentum genuinely accelerate convergence, and what are the conditions for this acceleration to be theoretically justified?
\item How does second-order curvature information improve convergence, and at what cost?
\item How accurately can derivative-free and finite-difference methods approximate gradient information?
\item How do projected gradient descent and penalty methods differ in their approach to feasibility?
\item What is the Frank--Wolfe algorithm's distinct advantage over projected gradient for box-constrained problems?
\end{enumerate}

Throughout, the analysis connects empirical results to the theoretical convergence guarantees of each method, and highlights how problem structure (convexity, smoothness, condition number) determines which algorithm is best suited to a given task. All experiments use \texttt{np.random.seed(42)} for reproducibility.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated as
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
            = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a \emph{strongly convex quadratic}. Its Hessian $H = X^T X / m$ is constant with eigenvalues $\lambda_{\min}(H) \approx 0.96$ and $\lambda_{\max}(H) \approx 1.04$ (since $X$ has i.i.d.\ $\mathcal{N}(0,1)$ rows), giving condition number $\kappa \approx 1.08$. The gradient is $\nabla J(\theta) = X^T(X\theta - y)/m$. Because of observation noise, the minimum loss is $J^{\star} \approx 0.4826$, not zero. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is
\begin{equation}
  H(x) = \begin{pmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{pmatrix}.
\end{equation}
The eigenvalue ratio varies between approximately $1\text{:}5$ and $3\text{:}10$, giving a modest condition number of about 5--6. Setting $\nabla f = 0$ yields $x_2 = 2$ and $2(x_1 - 1) + \cos(x_1) = 0$; numerically this gives $x_1 \approx 0.582$. The global minimum is at $(0.582, 2.0)$ with $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian at the optimum is
\begin{equation}
  H(1,1) = \begin{pmatrix} 802 & -400 \\ -400 & 200 \end{pmatrix},
\end{equation}
with eigenvalues approximately $0.5$ and $1000$, giving condition number $\kappa \approx 2000$. This extreme ill-conditioning, combined with the narrow curved valley along $x_2 = x_1^2$, makes Rosenbrock one of the most challenging standard test functions: gradient methods waste most steps bouncing across the steep transverse direction rather than progressing along the valley. Starting point: $x_0 = [-1, 1]^T$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

For gradient descent $x_{k+1} = x_k - \alpha_k \nabla f(x_k)$ applied to an $L$-smooth, $\mu$-strongly convex function, the optimal fixed step size is $\alpha^{\star} = 2/(L + \mu)$, achieving convergence rate
\begin{equation}
  \|x_k - x^{\star}\|^2 \leq \left(\frac{\kappa - 1}{\kappa + 1}\right)^{2k} \|x_0 - x^{\star}\|^2, \quad \kappa = L/\mu.
\end{equation}
When $\kappa$ is large (as in Rosenbrock), the factor $(\kappa-1)/(\kappa+1) \approx 1$, and convergence is extremely slow. Adaptive step-size methods attempt to overcome this by automatically adjusting $\alpha_k$ based on gradient history, effectively estimating or compensating for curvature without computing the Hessian.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Optimal Polyak step}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step minimises the distance to $x^{\star}$ in a single step for quadratics and guarantees convergence for convex $f$ when $f^{\star}$ is exactly known: $f(x_{k+1}) - f^{\star} \leq \frac{1}{2}\|x_k - x^{\star}\|^2 / (k+1)$. The critical requirement is knowledge of $f^{\star}$; any misspecification causes pathological behaviour.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad applies large steps to infrequently updated coordinates and small steps to frequently updated ones. Its cumulative regret bound is $O(\sqrt{T})$ in the online convex setting. However, the monotonically growing denominator $\sqrt{G_k}$ means the effective step size decays to zero, which can stall convergence on non-convex or long-running optimisation tasks.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{EMA of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's cumulative sum with an exponential moving average (EMA) controlled by $\beta$. This ``forgetting'' prevents the step size from decaying to zero, keeping the effective rate responsive to recent gradient magnitudes. With $\beta = 0.9$, the effective window is approximately $1/(1-\beta) = 10$ iterations.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method adds a momentum term that accumulates past gradients. For a quadratic $f$ with eigenvalues in $[\mu, L]$, the optimal Heavy Ball parameters $\alpha^{\star} = 4/(\sqrt{L}+\sqrt{\mu})^2$ and $\beta^{\star} = \bigl((\sqrt{L}-\sqrt{\mu})/(\sqrt{L}+\sqrt{\mu})\bigr)^2$ achieve the optimal convergence rate $((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1))^k$ --- the same rate as Nesterov, and dramatically better than GD's $(\kappa-1)/(\kappa+1)$.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest (Rosenbrock: $f = 0.009$, a $374\times$ improvement over GD). When $f^{\star}$ is misspecified, Polyak diverges catastrophically. Adagrad and Heavy Ball reliably match or exceed GD across all benchmarks.

\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential gradient averaging ($\beta = 0.9$). Heavy Ball shows characteristic overshoot-then-converge behaviour from its momentum term, with oscillation amplitude controlled by $\beta$.

\item \textbf{Stability:} GD baseline is most stable but slowest. Polyak is \emph{critically sensitive} to $f^{\star}$ specification. Adagrad is uniformly stable due to its monotonically decreasing step, though this may cause premature stagnation on long optimisation runs.

\item \textbf{Condition number sensitivity:} On Benchmark A ($\kappa \approx 1.08$), all methods converge comparably fast. On Benchmark C ($\kappa \approx 2000$), the gap widens dramatically: Heavy Ball's momentum partially compensates for the ill-conditioning by building consistent momentum along the valley, while plain GD stagnates.

\item \textbf{Practical recommendation:} In practice, $f^{\star}$ is rarely known, limiting Polyak to special applications (e.g., convex optimisation with known optimal value). RMSprop and Heavy Ball are more robust choices for general non-convex problems.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}

For a convex $L$-smooth function, gradient descent achieves $O(1/k)$ convergence: $f(x_k) - f^{\star} \leq O(L\|x_0 - x^{\star}\|^2/k)$. Nesterov (1983) showed that this rate is \emph{optimal} among first-order methods for this function class, and that a simple momentum modification achieves the optimal $O(1/k^2)$ rate:
\begin{equation}
  f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2}.
\end{equation}
This is a strict improvement over GD's $O(1/k)$ bound and matches the fundamental information-theoretic lower bound for first-order methods on smooth convex problems.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead: gradient evaluated ahead of current point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The critical distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This ``corrective'' step allows Nesterov to adjust its trajectory before overshooting. The schedule $\beta_k = (k-1)/(k+2)$ increases momentum gradually from 0 towards 1, matching the sequence $t_k = (1 + \sqrt{1 + 4t_{k-1}^2})/2$ used in FISTA and related methods.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (uncentred variance)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines first-order momentum (via $m_t$, an EMA of past gradients) with per-coordinate adaptive scaling (via $v_t$, an EMA of squared gradients), inheriting advantages of both RMSprop and momentum methods. The bias correction terms $(1 - \beta_1^t)^{-1}$ and $(1-\beta_2^t)^{-1}$ are crucial during early iterations when $m_t$ and $v_t$ are initialised at zero and would otherwise under-estimate the true moments. At large $t$, these corrections converge to 1. The effective per-coordinate step size is $\alpha \|\hat{m}_t\| / \sqrt{\hat{v}_t + \varepsilon} \approx \alpha \text{sign}(g_t)$ for large $t$, which bounds the update magnitude to approximately $\alpha$ per coordinate.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices
    \For{each mini-batch $\mathcal{B} \subseteq \{1,\ldots,m\}$ of size $b$}
        \State $\hat{g} \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, \hat{g}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

Each mini-batch gradient $\hat{g}$ is an unbiased estimate of $\nabla J(\theta)$: $\mathbb{E}[\hat{g}] = \nabla J(\theta)$. Its variance is $\text{Var}[\hat{g}_i] \propto \sigma^2_{\text{noise}} / b$, decreasing with batch size.

\subsection{Nesterov vs Heavy Ball: A Theoretical Comparison}

Both Heavy Ball and Nesterov accumulate momentum, but their convergence properties differ fundamentally. On a quadratic $f$ with condition number $\kappa$:
\begin{itemize}[nosep]
\item \textbf{Heavy Ball} with optimal parameters converges at rate $\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k$ (polynomial improvement over GD but not proven for non-quadratics).
\item \textbf{Nesterov} with $\alpha = 1/L$ and $\beta_k = (k-1)/(k+2)$ achieves the information-theoretically optimal $O(1/k^2)$ rate for convex smooth $f$, without requiring knowledge of $\mu$.
\end{itemize}
This theoretical advantage explains Nesterov's superior performance on Rosenbrock in Table~\ref{tab:q2_final}: its lookahead step provides a provably better descent direction, particularly along the slowly-varying valley floor direction.

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) = 0.25^4 + 4 \cdot 0.25^3\,(x - 0.25) = 0.0039 + 0.0625(x - 0.25).
\end{equation}
This linear model captures only the local slope, providing the direction of steepest descent but ignoring curvature entirely. Minimising a linear model yields no finite solution, which is precisely why gradient descent requires a step-size to be useful.

\textbf{Second-order approximation:}
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}
where $g''(x_0) = 12 \times 0.25^2 = 0.75$. The Newton update minimises the second-order model exactly: setting the derivative of the quadratic to zero gives
\begin{equation}
  x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)} = x_k - \frac{4x_k^3}{12x_k^2} = x_k - \frac{x_k}{3} = \frac{2}{3}x_k.
\end{equation}
Starting from $x_0 = 0.25$: $x_1 = 0.167$, $x_2 = 0.111$, \ldots, converging geometrically to zero. For general $x^p$, Newton converges quadratically once $|x_k|$ is small.

\subsection{Newton's Method for Multidimensional Problems}

\begin{algorithm}[H]
\caption{Newton's Method with Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, Hessian damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation for numerical stability}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Newton direction $p_k = H_k^{-1} g_k$ solves the linear system arising from minimising the local quadratic model $f(x_k) + g_k^T(x - x_k) + \frac{1}{2}(x-x_k)^T H_k (x-x_k)$. The damping term $\lambda I$ (with $\lambda = 10^{-8}$) regularises the Hessian to handle near-singularity and ensures positive definiteness. The step $\alpha < 1$ (damped Newton) is used when the Rosenbrock Hessian varies too rapidly for the full Newton step to be accurate globally.

\begin{theorem}[Quadratic Convergence of Newton's Method]
Let $f$ be twice continuously differentiable, $\nabla^2 f$ Lipschitz continuous with constant $L_H$, and $\nabla^2 f(x^{\star})$ positive definite with minimum eigenvalue $\sigma > 0$. Then there exists a neighbourhood of $x^{\star}$ in which Newton's method with $\alpha = 1$ satisfies:
\begin{equation}
  \|x_{k+1} - x^{\star}\| \leq \frac{L_H}{2\sigma}\, \|x_k - x^{\star}\|^2.
\end{equation}
\end{theorem}
Once the iterates enter this neighbourhood, errors are squared at each step, leading to extremely rapid convergence (1 decimal place of accuracy becomes 2, then 4, then 8, \ldots).

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping $\lambda = 10^{-8}$.

\subsection{Computational Trade-Offs}

Newton's method requires forming and inverting the $d \times d$ Hessian at each step, costing $O(d^2)$ to form and $O(d^3)$ to invert (or $O(d^2)$ using sparse structure). For $d = 2$, this is negligible. For large-scale problems ($d = 10^6$ as in neural networks), exact Newton is infeasible. \emph{Quasi-Newton methods} (BFGS, L-BFGS) approximate $H_k^{-1}$ from gradient differences, achieving super-linear convergence with $O(d^2)$ or $O(md)$ memory cost, bridging the gap between GD and Newton in practice.

\subsection{Part A: Finite Difference Approximation and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with a one-sided difference:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \quad i = 1, \ldots, d.
\end{equation}
For a twice-differentiable $f$, the Taylor expansion gives the approximation error:
\begin{equation}
  \left|\frac{\partial f}{\partial x_i}(x) - \frac{f(x + \delta e_i) - f(x)}{\delta}\right| \leq \frac{\delta}{2}\left|\frac{\partial^2 f}{\partial x_i^2}(x)\right| + O(\delta^2).
\end{equation}
This is the \emph{truncation error}, which grows with $\delta$. Simultaneously, finite-precision arithmetic introduces \emph{round-off error} proportional to $\varepsilon_{\text{mach}}/\delta \approx 2.2 \times 10^{-16}/\delta$. Balancing these two sources gives the optimal step size $\delta^{\star} \sim \sqrt{\varepsilon_{\text{mach}}} \approx 1.5 \times 10^{-8}$. The assignment uses $\delta = 0.05$ (good, near-exact gradient) and $\delta = 0.8$ (poor, significant truncation error).

For $\delta = 0.8$ on Benchmark B with $|\partial^2 f/\partial x_1^2| = |2 - \sin(x_1)| \leq 3$, the truncation error per coordinate is approximately $0.8/2 \times 3 = 1.2$ --- a large fraction of the gradient itself near the minimum ($\|\nabla f\| \approx 1$), explaining the observed poor convergence.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order Method)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha = 0.025$, perturbation $\delta = 0.08$, iterations $N = 220$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Stochastic directional gradient}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method uses only \emph{two} function evaluations per iteration regardless of dimension. The gradient estimate $\hat{g}_k$ is an unbiased directional derivative along a random direction: $\mathbb{E}[u_k \hat{g}_k^T] = \nabla f(x_k) + O(\delta^2)$. However, projecting the full gradient onto a single random direction introduces high variance, slowing convergence by a factor of $O(d)$ compared to using the full gradient.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four geometric operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): Move the worst vertex through the centroid of the remaining vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): If reflection improved, try a further step in the same direction.
\item \textbf{Contraction} ($\rho = 0.5$): If reflection worsened, contract toward the centroid.
\item \textbf{Shrink} ($\sigma = 0.5$): If contraction also failed, shrink all vertices toward the best.
\end{enumerate}
No gradient information is required. The simplex adapts its shape to the local landscape, becoming elongated in shallow directions and contracted in steep ones. Settings: initial simplex step $= 0.35$, iterations $= 160$.

\subsection{Problem Setup and Optimality Conditions}

Minimise Benchmark B subject to $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$:
\begin{equation}
  \min_{x \in \mathbb{R}^2} f(x) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1) \quad \text{subject to} \quad x_1 \geq 0.5.
\end{equation}
Since the unconstrained minimum is at $x_1 \approx 0.582 > 0.5$, the constraint is \emph{inactive} at the solution: the constrained and unconstrained minima coincide. The KKT conditions are:
\begin{equation}
  \nabla f(x^{\star}) - \mu^{\star} e_1 = 0, \quad \mu^{\star}(x_1^{\star} - 0.5) = 0, \quad \mu^{\star} \geq 0,
\end{equation}
where $e_1 = [1, 0]^T$. Since $x_1^{\star} = 0.582 > 0.5$, complementary slackness gives $\mu^{\star} = 0$, and the KKT conditions reduce to $\nabla f(x^{\star}) = 0$, confirming the constrained optimum coincides with the unconstrained one.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha = 0.08$, iterations $N = 100$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project: $(x_1)_{k+1} \leftarrow \max(0.5,\, (z_1)_{k+1})$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method (Exact Penalty with $\ell_1$ Term)}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N = 100$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x_k) \gets f(x_k) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $\nabla F_{\lambda}(x_k) \gets \nabla f(x_k) + \lambda \cdot [-\mathbf{1}_{x_1 < 0.5},\, 0]^T$ \Comment{Subgradient}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty $\lambda \max(0, 0.5 - x_1)$ is an exact penalty function: for $\lambda > \mu^{\star}$ (the optimal Lagrange multiplier), the unconstrained minimiser of $F_{\lambda}$ coincides exactly with the constrained minimiser. Since $\mu^{\star} = 0$ here (inactive constraint), any $\lambda > 0$ is theoretically sufficient. In practice, the gradient discontinuity at $x_1 = 0.5$ and the finite step size require careful tuning.

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\textbf{Projected GD} enforces feasibility at every iteration via the projection operator $\Pi_{\mathcal{X}}(z) = (\max(0.5, z_1), z_2)$. The projection onto a half-space requires only a single max operation, making it computationally trivial here. For more complex constraint sets (e.g., an $\ell_2$ ball, a polytope, or a positive semidefinite cone), the projection can be expensive or require specialised algorithms (Dykstra's algorithm, Euclidean distance transforms), which can limit projected GD's practicality.

\textbf{Penalty methods} trade hard feasibility for algorithmic simplicity: only a modified objective gradient is needed. The penalty weight $\lambda$ must exceed the true Lagrange multiplier $\mu^{\star}$ for the penalty minimiser to be feasible. As $\lambda \to \infty$, the penalty minimiser converges to the constrained minimiser, but large $\lambda$ creates a very ill-conditioned augmented objective, requiring proportionally smaller step sizes. The \textbf{augmented Lagrangian method} (multiplier method) avoids this ill-conditioning by maintaining an explicit multiplier estimate $\hat{\mu}$: $F(\x, \hat{\mu}) = f(x) + \hat{\mu} \max(0, 0.5 - x_1) + \frac{\rho}{2}\max(0, 0.5 - x_1)^2$, achieving faster convergence with a fixed (moderate) $\rho$.

\subsection{Feasible Set and Linear Programme}

The feasible set is the box $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1, 2]^T$, the minimum over $\mathcal{X}$ is obtained by minimising each coordinate independently (due to the separable, box structure):
\begin{equation}
  x^{\star} = (0.5,\, -5), \qquad f^{\star} = 1 \times 0.5 + 2 \times (-5) = -9.5.
\end{equation}
This is the lower-left corner of the box. This illustrates the \textbf{fundamental theorem of linear programming}: the optimum of a linear objective over a bounded polytope is always attained at a vertex. The LP can be solved exactly in $O(d)$ for box constraints by independently checking the sign of each component of $a$.

Since both components of $a$ are positive, the objective increases as we move right and up, so the minimum is at the lower-left vertex $(0.5, -5)$, where $f = -9.5$. Any interior point yields a strictly higher objective value.}

\end{figure}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: $\beta$ is the \emph{retention} parameter}
\EndFor
\end{algorithmic}
\end{algorithm}

For box constraints, the LMO decomposes per coordinate with cost $O(d)$:
\begin{equation}
  (z_k)_i = \begin{cases} \ell_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
where $\ell_i, u_i$ are the lower/upper bounds. Each iterate is a convex combination of $x_0$ and vertices of $\mathcal{X}$, guaranteeing $x_k \in \mathcal{X}$ without any projection. The mixing parameter $\beta \in (0, 1)$ controls the step size: $(1 - \beta)$ is the fraction moved towards $z_k$.

\begin{proposition}[Frank--Wolfe Convergence]
For a convex $L$-smooth $f$, Frank--Wolfe with step size $\gamma_k = 2/(k+2)$ (equivalently, $\beta_k = k/(k+2)$) satisfies:
\begin{equation}
  f(x_k) - f^{\star} \leq \frac{2LC^2}{k+2},
\end{equation}
where $C = \text{diam}(\mathcal{X})$. This is an $O(1/k)$ rate --- slower than projected GD's $O(1/k^2)$ or linear rate for strongly convex $f$, but achieved without any projection.
\end{proposition}

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum:} FW converges to the interior but with the characteristic zig-zag pattern. The general $O(1/k)$ convergence rate is visible: improvements slow steadily. Smaller $\beta$ (larger steps towards $z_k$) can make initial progress faster but introduces more oscillation near the optimum, which explains the seemingly counterintuitive result that $\beta = 0.985$ achieves a better final value despite taking smaller steps.

\textbf{Boundary optimum:} FW is naturally suited to boundary optima because the LMO consistently selects the vertex at $x_1 = 0.5$ once the gradient $\partial f/\partial x_1 > 0$ (which holds as long as $x_1 < 0$ --- but the constraint is $x_1 \geq 0.5$, so this holds throughout the trajectory from $x_0 = (3,3)$). The residual gap $f = 0.364$ vs $f^{\star} = 0.25$ after 140 iterations reflects the $O(1/k)$ rate with the fixed-$\beta$ schedule.

\textbf{FW vs projected GD comparison:}
\begin{itemize}[nosep]
\item \textbf{Projection cost:} Projected GD requires a projection oracle at each step. For box constraints (as here), this is $O(d)$ and trivial. For general convex sets (semidefinite, nuclear norm, probability simplex), projection can be expensive ($O(d^2)$ or $O(d \log d)$), making FW's $O(d)$ LMO preferable.
\item \textbf{Convergence rate:} Projected GD achieves $O(1/k^2)$ for convex $L$-smooth $f$ with optimal step sizes, faster than FW's $O(1/k)$. However, for sparse problems (e.g., $\ell_1$ constrained), FW produces sparse iterates (convex combinations of vertices), which is highly desirable.
\item \textbf{Practical choice:} FW is preferred when the LMO is cheaper than the projection and sparse iterates are desired (e.g., LASSO, matrix completion). Projected GD is preferred for simple constraint sets where projection is cheap and the convergence rate matters more.
\end{itemize}

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has systematically evaluated six categories of optimisation algorithms across three benchmarks of increasing difficulty. The central findings are:

\textbf{Adaptive step-size methods (Q1):} The Polyak step achieves the fastest convergence when $f^{\star}$ is exactly known, but fails catastrophically when $f^{\star}$ is misspecified. Among robust methods, Heavy Ball offers the best Rosenbrock performance ($f = 1.40$) by accumulating momentum along the valley direction. Adagrad is uniformly stable across all benchmarks. RMSprop's exponential forgetting provides smoother step-size evolution than Adagrad but slightly lower accuracy.

\textbf{Momentum and stochastic methods (Q2):} Nesterov acceleration achieves $O(1/k^2)$ convergence, dramatically outperforming GD on Rosenbrock ($f = 0.479$ vs $3.388$). Adam's per-coordinate scaling is beneficial for anisotropic problems but cannot match Nesterov's directional acceleration on ill-conditioned landscapes. Mini-batch SGD converges faster per epoch with smaller batches due to more frequent updates, and the irreducible noise floor scales as $\sigma^2$.

\textbf{Newton's method (Q3):} Newton solves the quadratic benchmark exactly in one step and provides a $5.4\times$ improvement over GD on Rosenbrock in 20 iterations vs 80. Quadratic convergence near the solution is orders of magnitude faster than gradient descent's linear rate. The key limitation is the $O(d^3)$ Hessian inversion cost, making Newton infeasible for high-dimensional problems without quasi-Newton approximations.

\textbf{Derivative-free methods (Q4):} Small finite-difference steps ($\delta = 0.05$) approximate gradients faithfully, while large steps ($\delta = 0.8$) corrupt gradient direction. Nesterov random search demonstrates that gradient-free progress is possible with only two function evaluations per step, albeit slowly ($O(1/k)$ with $O(d)$ factor overhead). Nelder--Mead effectively navigates the Rosenbrock valley without any gradient information in low dimensions.

\textbf{Constrained optimisation (Q5):} Projected GD enforces feasibility as a hard constraint from iteration 1 at zero computational overhead for the half-space constraint $x_1 \geq 0.5$. Penalty methods with sufficiently large $\lambda \geq 1.8$ achieve near-identical final accuracy but with softer feasibility enforcement. The penalty weight determines convergence speed to the feasible set; too small a $\lambda$ results in persistent violation.

\textbf{Frank--Wolfe (Q6):} FW naturally handles box-constrained problems without projection, making it efficient when the LMO is cheaper than the projection. The $O(1/k)$ convergence rate is slower than projected GD's $O(1/k^2)$, but the projection-free property and sparse iterates make FW highly practical in large-scale sparse learning. For interior optima, conservative mixing ($\beta = 0.985$) reduces oscillation and achieves better final accuracy than aggressive mixing ($\beta = 0.90$).

Overall, the choice of optimisation algorithm should be driven by problem structure: the condition number, available gradient information, constraint geometry, and dimensionality. No single algorithm dominates across all settings, and understanding the theoretical guarantees of each method is essential for making informed choices in practice.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
