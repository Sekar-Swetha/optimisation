\begin{abstract}
This report presents a systematic comparative study of twelve optimisation algorithms applied to three standard benchmark problems: a linear regression quadratic loss (Benchmark~A), a toy neural network loss with sinusoidal perturbation (Benchmark~B), and the ill-conditioned Rosenbrock function (Benchmark~C). Six categories of methods are examined: (1)~adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball), demonstrating the critical sensitivity of Polyak's rule to the accuracy of the specified optimal value; (2)~momentum-based and stochastic methods (Nesterov acceleration, Adam, mini-batch SGD), showing that Nesterov achieves the best Rosenbrock convergence ($f=0.479$ vs.\ GD's $f=3.388$); (3)~Newton's method with Hessian damping, achieving single-step convergence on the quadratic loss; (4)~derivative-free approaches (finite differences, Nesterov random search, Nelder--Mead, grid search) compared by gradient fidelity and scalability; (5)~constrained optimisation via projected gradient descent and quadratic penalty methods, showing that projection enforces feasibility exactly from iteration~1; and (6)~the Frank--Wolfe conditional gradient algorithm for linear-constrained problems, illustrating its natural handling of boundary optima. Each method is analysed with respect to convergence speed, trajectory behaviour, theoretical convergence guarantees, and computational trade-offs.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Gradient-based optimisation is the cornerstone of modern machine learning and data analysis. The choice of optimisation algorithm critically determines convergence speed, solution accuracy, and computational cost. This report investigates a spectrum of algorithms, from classical gradient descent to second-order Newton methods and derivative-free strategies, unified by application to three carefully chosen benchmark problems of increasing difficulty.

The benchmarks span the key challenges encountered in practice: Benchmark~A (quadratic loss) is strongly convex with a closed-form solution; Benchmark~B (toy neural network) introduces mild non-linearity via a sinusoidal term; Benchmark~C (Rosenbrock) is a canonical ill-conditioned test function with condition number $\kappa \approx 2504$ at the optimum. This progression allows each method's strengths and limitations to be revealed clearly.

Throughout this report, the following standard definitions apply. A differentiable function $f$ is \emph{$L$-smooth} if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ for all $x, y$ (equivalently, $\nabla^2 f \preceq LI$). It is \emph{$\mu$-strongly convex} if $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$ for all $x, y$ (equivalently, $\nabla^2 f \succeq \mu I$). The \emph{condition number} $\kappa = L/\mu$ determines the convergence rate of gradient-based methods.

All experiments use \texttt{numpy} with fixed seed \texttt{np.random.seed(42)} for full reproducibility. The complete implementation is provided in \texttt{CS7DS2\_Final\_Code\_25336453.py} and reproduced in Appendix~\ref{app:code}.

\section{Benchmark Problems and Experimental Setup}

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d=2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = {\theta^{\star}}^T x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a \emph{strongly convex} quadratic. The Hessian $H = \frac{1}{m}X^TX$ is constant, positive definite, and its eigenvalues $0 < \lambda_{\min}(H) \leq \lambda_{\max}(H)$ determine the smoothness constant ($L = \lambda_{\max}(H)$) and the strong convexity modulus ($\mu = \lambda_{\min}(H)$). For the generated dataset (seed 42, $m=1000$), $\lambda_{\max}(H) \approx 1.033$ and $\lambda_{\min}(H) \approx 0.925$, giving $\kappa(H) \approx 1.12$ — an \emph{extremely} well-conditioned problem. The optimal step size for gradient descent is $\alpha^* = 2/(\mu + L) \approx 1.02$; the conservative $\alpha = 0.08$ is used across all Q1 experiments to ensure stability across all methods on all benchmarks simultaneously. Due to observation noise, the minimum loss is $J^{\star} \approx 0.4826 \approx \sigma^2_{\mathrm{noise}}/2$ (the irreducible noise floor). Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\label{eq:bench_B}
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is
\begin{equation}
H(x) = \begin{pmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{pmatrix}.
\end{equation}
Since $\sin(x_1) \in [-1,1]$, the $(1,1)$ eigenvalue of $H$ ranges in $[1, 3]$, giving a condition number $\kappa(x) = 10/(2-\sin(x_1))$ between $10/3 \approx 3.3$ and $10$. Along the optimisation trajectory from $x_0=(-1,4)$ to $x^*=(0.582, 2)$: at the start $\kappa \approx 10/2.84 \approx 3.5$; at the minimum $\kappa \approx 10/1.45 \approx 6.9$. The function is non-quadratic due to the $\sin$ term, but remains strongly convex on any bounded domain. Setting $\nabla f = 0$ requires $2(x_1^*-1)+\cos(x_1^*)=0$ (transcendental equation, solved by bisection) and $x_2^*=2$; the solution is $x_1^* \approx 0.5824$, giving the minimum at $(0.5824,\,2.0)$ with $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\label{eq:rosenbrock}
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian at the optimum is
\begin{equation}
H(1,1) = \begin{pmatrix} 802 & -400 \\ -400 & 200 \end{pmatrix},
\end{equation}
with eigenvalues approximately $0.4$ and $1001.6$, yielding condition number $\kappa \approx 2504$. This extreme ill-conditioning, combined with the narrow curved valley along $x_2 = x_1^2$, makes Rosenbrock one of the most challenging standard test functions for first-order methods. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Questions~5--6):
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a convex polytope (box), enabling efficient projection ($O(d)$ per step) and efficient linear minimisation ($O(d)$ per Frank--Wolfe oracle).

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

For a function $f$ with $L$-Lipschitz gradient and strong convexity modulus $\mu$, vanilla gradient descent with constant step $\alpha \leq 1/L$ satisfies:
\begin{equation}
f(x_k) - f^{\star} \leq \left(1 - \mu/L\right)^k \bigl(f(x_0) - f^{\star}\bigr),
\end{equation}
i.e., \emph{linear convergence} with rate $1 - 1/\kappa$. Adaptive methods aim to improve upon this by exploiting per-coordinate curvature information or using knowledge of $f^{\star}$.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Adaptive step based on sub-optimality gap}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step size is theoretically motivated: for a convex $L$-smooth function with known $f^{\star}$, it is optimal in the sense that it minimises the worst-case distance to the optimum. Specifically, for convex $f$ and exact $f^{\star}$, the Polyak step satisfies $\|x_{k+1} - x^{\star}\|^2 \leq \|x_k - x^{\star}\|^2 - (f(x_k)-f^{\star})^2/\|g_k\|^2$, yielding sublinear convergence. For strongly convex functions with exact $f^{\star}$, the rate improves to linear.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative squared gradient (per-coordinate)}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's effective step $\alpha_0/\sqrt{G_k^{(i)}}$ for coordinate $i$ is large initially (when $G_k^{(i)}$ is small) and decays monotonically. This is beneficial for sparse gradients but causes the rate to vanish for dense, non-stationary problems.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's cumulative sum with an exponential moving average (decay $\beta = 0.9$), so recent gradients dominate and the effective step size remains bounded away from zero.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

Heavy Ball adds a momentum term that accumulates gradient history, allowing it to build speed in consistent descent directions. For a quadratic $f$ with eigenvalues in $[\mu, L]$, the optimal momentum $\beta^* = \bigl((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\bigr)^2$ and step $\alpha^* = 4/(\sqrt{L}+\sqrt{\mu})^2$ give a convergence rate of $\bigl((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\bigr)^2$ per iteration — the same as the optimal first-order rate. This is a significant improvement over GD's rate $(\kappa-1)/(\kappa+1)$ for large $\kappa$: for $\kappa = 100$, GD's rate is $\approx 0.98$ while Heavy Ball achieves $\approx 0.82$ per step. However, Heavy Ball does \emph{not} provably achieve this rate on non-quadratic functions and can oscillate on general convex problems.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest (Rosenbrock: $f = 0.024$ after 120 iterations). Otherwise, Heavy Ball ($f=1.40$) and Adagrad ($f=0.4826$) match or exceed GD on their respective best benchmarks. These first-order methods are compared with the momentum and Newton methods from Questions~2 and~3 in the cross-question comparison of Figure~\ref{fig:combined_rosenbrock}.

\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential averaging; its effective step size adapts to recent curvature without vanishing or exploding. Heavy Ball shows characteristic overshoot followed by damped oscillation — more pronounced as $\beta \to 1$.

\item \textbf{Stability:} GD baseline is most stable but slowest. Polyak is \emph{unstable} when $f^{\star}$ is misspecified (Benchmarks~A and~B). Adagrad is uniformly stable due to its monotonically decreasing step size. The step-size plots (Figures~\ref{fig:q1_stepsize_A}--\ref{fig:q1_stepsize_C}) visually confirm the divergent Polyak step and the contrasting smooth RMSprop behaviour.

\item \textbf{Coordinate adaptation:} Adagrad and RMSprop provide per-coordinate step sizes, which is advantageous when curvature varies greatly across dimensions. On Benchmark~B ($\kappa \in [3.5, 6.9]$), the per-coordinate scaling of Adagrad/RMSprop allows the $x_2$ direction (eigenvalue~10) to use a smaller effective step than the $x_1$ direction (eigenvalue~$\approx$1.5). Heavy Ball and Polyak apply a scalar step to all coordinates simultaneously.

\item \textbf{Practical recommendation:} In practice, exact $f^{\star}$ is rarely known, limiting Polyak's applicability. RMSprop is preferred when the loss landscape is non-stationary (e.g., during neural network training). Adagrad suits sparse gradient settings such as NLP word embeddings. Heavy Ball is a strong choice for dense, well-conditioned problems.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}

Classical gradient descent achieves an $O(1/k)$ rate for convex functions: $f(x_k) - f^{\star} \leq L\|x_0-x^{\star}\|^2/(2k)$. Nesterov's seminal 1983 result showed that this rate can be improved to $O(1/k^2)$ for smooth convex functions:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2},
\end{equation}
which is \emph{optimal} in the sense that no first-order method can guarantee a better rate on all $L$-smooth convex functions (this is the lower bound due to Nesterov, 1983). This acceleration is achieved by evaluating the gradient at a \emph{lookahead} (extrapolated) point rather than the current iterate. For strongly convex functions, Nesterov momentum achieves a linear rate of $(1 - \sqrt{1/\kappa})^k$, compared to GD's $(1 - 1/\kappa)^k$ — an exponential improvement in $\kappa$.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Increasing momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead (extrapolated) point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Update momentum}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This allows Nesterov momentum to ``correct'' its trajectory before overshooting. The schedule $\beta_k = (k-1)/(k+2)$ (truncated at $\beta_{\max}$) increases momentum gradually from $0$ toward~$1$, which is precisely what is needed to achieve the $O(1/k^2)$ rate. Using a fixed momentum $\beta$ (as in Heavy Ball) breaks the theoretical guarantee, which is why Nesterov must use this specific increasing schedule.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean) estimate}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (variance) estimate}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction for initialisation}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$, an exponential moving average of past gradients) with per-coordinate adaptive scaling (via $v_t$, an exponential moving average of squared gradients). The bias correction terms $1-\beta_1^t$ and $1-\beta_2^t$ correct for the zero initialisation of $m_0$ and $v_0$, preventing the early iterates from being biased towards zero. Adam can be viewed as RMSprop with momentum and bias correction.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, and runs for 50 epochs with data shuffled at each epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1,\ldots,m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The mini-batch gradient $g_{\mathcal{B}}$ is an \emph{unbiased} estimate of the full gradient $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. Its variance is $\mathrm{Var}[g_{\mathcal{B}}] = \sigma_g^2/b$ where $\sigma_g^2$ is the per-sample gradient variance. For large batches, $g_{\mathcal{B}} \approx \nabla J$ and SGD approximates GD. For small batches, high gradient variance introduces noise that acts as implicit regularisation but prevents convergence below a noise floor. The optimal batch size trades off variance (favouring large $b$) against computation time per epoch (favouring small $b$): in theory, for a fixed number of gradient evaluations, both large and small batches give similar final accuracy, but the \emph{wall-clock} time varies by hardware parallelism.

\subsection{Local Approximations of $g(x) = x^4$}
\label{sec:q3_approx}

Around $x_0 = 0.25$, with $g'(x) = 4x^3$ and $g''(x) = 12x^2$:

\textbf{First-order (Taylor) approximation:}
\begin{equation}
g^{(1)}(x) = g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order approximation:}
\begin{equation}
g^{(2)}(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises $g^{(2)}$: setting $(g^{(2)})'(x) = 0$ gives $x_{k+1} = x_k - g'(x_k)/g''(x_k) = 0.25 - 0.0625/0.75 = 0.1\overline{6}$. This corresponds to stepping to the stationary point of the local quadratic model, which is why Newton's method achieves \emph{quadratic} local convergence: $|x_{k+1} - x^{\star}| = O(|x_k - x^{\star}|^2)$.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}
\caption{Q3: Local approximations of $g(x) = x^4$ at $x_0 = 0.25$. The first-order approximation (tangent line) captures only the local slope and deviates rapidly. The second-order approximation (parabola) fits well in a neighbourhood of $x_0$ and provides a much better estimate of the function's minimum — motivating Newton's method, which steps to the minimum of this quadratic model. The radius of accuracy of the second-order approximation is approximately $|g^{(3)}(x_0)|/(6 g''(x_0)) = 24 \cdot 0.25 / (6 \cdot 0.75) \approx 1.33$ units.}

\subsection{Newton's Method}
\label{sec:q3_newton}

\begin{algorithm}[H]
\caption{Newton's Method with Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Newton direction $p_k = H_k^{-1} g_k$ transforms the gradient into a curvature-normalised descent direction. Hessian damping ($\lambda = 10^{-8}$) ensures positive definiteness when the Hessian is ill-conditioned or indefinite. For strongly convex $f$, pure Newton ($\alpha=1$) achieves \emph{quadratic convergence} in the local regime: there exists $\delta > 0$ such that for $\|x_0 - x^{\star}\| < \delta$,
\begin{equation}
\|x_{k+1} - x^{\star}\| \leq C\|x_k - x^{\star}\|^2,
\end{equation}
for some constant $C > 0$ depending on Lipschitz properties of the Hessian.

Hyperparameter settings: GD runs for 80 iterations; Newton runs for 20 iterations with damping $\lambda = 10^{-8}$.

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \qquad i = 1, \ldots, d.
\end{equation}
By Taylor expansion, the truncation error is $O(\delta)$ (due to neglected higher-order terms), while numerical cancellation introduces an error of order $O(\varepsilon_{\mathrm{mach}}/\delta)$ where $\varepsilon_{\mathrm{mach}} \approx 10^{-16}$. The total error is minimised at the \emph{optimal} step size:
\begin{equation}
\delta^* = \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}.
\end{equation}
In double precision, $\delta = 0.05$ (good) incurs $O(0.05)$ truncation error; $\delta = 0.8$ (poor) incurs $O(0.8)$ truncation error — the gradient direction can deviate substantially from the true gradient. Each evaluation requires $d+1 = 3$ function evaluations for $d=2$ dimensions.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order Method)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{U}(\mathbb{S}^{d-1})$ (uniform on unit sphere)
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Stochastic directional derivative}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

In the implementation, $u_k$ is sampled from $\mathcal{N}(0,I)$ and then normalised to lie on $\mathbb{S}^{d-1}$. For Gaussian (unnormalised) $u_k$, $\mathbb{E}[(\nabla f(x_k) \cdot u_k) u_k] = \nabla f(x_k)$, so the estimator is approximately unbiased. The normalisation introduces a small bias but controls the estimator's scale. This zeroth-order method requires only \textbf{2 function evaluations per iteration} regardless of dimension $d$ — a major advantage when gradient computation is expensive or unavailable. The trade-off is higher estimator variance: $\mathrm{Var}[\hat{g}_k] \approx O(d) \|\nabla f\|^2$ (the directional projection discards $d-1$ gradient components), requiring more iterations by a factor of $O(d)$ compared to full-gradient descent. With $d=2$ in this experiment, the disadvantage is modest.

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move worst vertex through centroid of remaining vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection improves upon the best, try going further.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection worsens, try a point between the centroid and worst vertex.
\item \textbf{Shrink} ($\sigma = 0.5$): if contraction also fails, contract all vertices toward the best.
\end{enumerate}
No gradient information is required — only function values. The simplex adapts its shape to the local landscape, elongating in descent directions and contracting near optima. Settings: initial simplex step $= 0.35$, iterations $= 160$.

\begin{remark}
The key trade-off is between gradient quality and function evaluation cost. Exact gradients require either analytical expressions (not always available) or $O(d)$ function evaluations via finite differences. Zeroth-order methods use only $O(1)$ evaluations per step but require more iterations to converge. For Nesterov random search, the convergence rate in terms of function evaluations is $O(d/\sqrt{T})$ for nonsmooth functions and $O(d/T)$ for smooth ones — exactly a factor of $d$ slower than gradient-based methods. This ``dimension curse'' makes zeroth-order methods impractical for $d \gg 10$ but valuable when gradients are unavailable (e.g., simulation-based optimisation, black-box tuning).
\end{remark}

\subsection{Problem Setup and KKT Conditions}

Minimise Benchmark~B subject to the constraint $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$:
\begin{equation}
\min_{x \in \mathbb{R}^2} f(x) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1) \quad \text{s.t.} \quad x_1 \geq 0.5.
\label{eq:q5_problem}
\end{equation}

The unconstrained minimum of $f$ is at $x_1^* \approx 0.582 > 0.5$, so it lies in the \emph{feasible} region. The constrained optimum therefore coincides with the unconstrained optimum: $x^* = (0.582, 2.0)$ with $f^* \approx 0.7244$. The first-order necessary (KKT) conditions for this inequality-constrained problem are:
\begin{equation}
\nabla f(x^*) - \mu^* \begin{pmatrix}1\\0\end{pmatrix} = 0, \quad \mu^*(x_1^* - 0.5) = 0, \quad \mu^* \geq 0,
\end{equation}
where $\mu^*$ is the KKT multiplier for the constraint $x_1 \geq 0.5$. Since $x_1^* = 0.582 > 0.5$, complementary slackness requires $\mu^* = 0$, and the condition reduces to $\nabla f(x^*) = 0$. The constraint is \emph{inactive} at the optimum, which is why both projected GD and penalty methods can converge to the same point as unconstrained GD.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

For the half-space $\mathcal{X} = \{x : x_1 \geq 0.5\}$, the projection is trivial: $\Pi_{\mathcal{X}}(z) = (\max(0.5, z_1), z_2)^T$. For convex $f$ and convex $\mathcal{X}$, projected GD converges to the constrained optimum at rate $O(1/k)$ for general convex $f$, and linearly for strongly convex $f$.

\begin{algorithm}[H]
\caption{Quadratic Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Exact penalty (non-smooth)}
    \State Compute $\nabla F_\lambda(x_k)$: $\;\partial F_\lambda/\partial x_1 = \partial f/\partial x_1 - \lambda\,\mathbf{1}[x_1 < 0.5]$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$, since larger $\lambda$ induces steeper gradients); Unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\textbf{Projected GD} enforces feasibility at every iteration as a hard constraint. \textbf{Penalty methods} convert the constrained problem to an unconstrained one. They require only gradient computation of the penalised objective, avoiding the projection oracle. However, feasibility is enforced only asymptotically as $\lambda \to \infty$, and larger $\lambda$ makes the penalised problem increasingly ill-conditioned (the penalty ``cliff'' near the constraint boundary creates a gradient discontinuity), requiring smaller step sizes and more iterations. An \emph{augmented Lagrangian} (method of multipliers) approach avoids this issue: it introduces a dual variable $\mu$ updated by $\mu_{k+1} \leftarrow \mu_k + \rho \max(0, 0.5 - x_1^{(k)})$ and solves a moderately penalised subproblem at each outer iteration. This achieves exact feasibility without driving $\lambda \to \infty$, at the cost of an outer dual update loop.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1, 2]^T$, the minimum over the box $\mathcal{X}$ is obtained by minimising each coordinate independently, since the objective decomposes:
\begin{equation}
\min_{x \in \mathcal{X}} (x_1 + 2x_2) = \min_{0.5 \leq x_1 \leq 5} x_1 + \min_{-5 \leq x_2 \leq 10} 2x_2 = 0.5 + 2(-5) = -9.5.
\end{equation}
The optimum is at $x^{\star} = (0.5, -5)$, with $f^{\star} = -9.5$. This illustrates the \emph{fundamental theorem of linear programming}: the optimum of a linear objective over a bounded polytope is always attained at a vertex (extreme point) of the feasible set.

The minimum is at the lower-left vertex $(0.5, -5)$, where both coordinates are at their lower bounds, consistent with both components of $a$ being positive. This vertex-optimality is exploited by the Frank--Wolfe algorithm's linear minimisation oracle.}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: $x_{k+1} \in \mathcal{X}$ by convexity}
\EndFor
\end{algorithmic}
\end{algorithm}

For a box $\mathcal{X}$, the LMO decomposes per coordinate in $O(d)$ operations:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
This requires no projection oracle. Since each iterate $x_{k+1} = \beta x_k + (1-\beta) z_k$ is a convex combination of feasible points, all iterates remain feasible automatically.

The Frank--Wolfe gap $G_k = \nabla f(x_k)^T(x_k - z_k) \geq 0$ serves as a certificate of near-optimality at every iteration without knowing $f^{\star}$: $G_k = 0$ iff $x_k$ satisfies the first-order optimality condition (since $z_k$ minimises the linear approximation over $\mathcal{X}$). For $L$-smooth convex $f$, the standard Frank--Wolfe analysis (with step-size schedule $\gamma_k = 2/(k+2)$) gives:
\begin{equation}
f(x_k) - f^{\star} \leq G_k \leq \frac{2L \cdot \mathrm{diam}(\mathcal{X})^2}{k+2},
\end{equation}
i.e., an $O(1/k)$ convergence rate. For the box $\mathcal{X}$, $\mathrm{diam}(\mathcal{X})^2 = (5-0.5)^2 + (10-(-5))^2 = 20.25 + 225 = 245.25$, so the bound becomes $f(x_k) - f^{\star} \leq 490.5 L/(k+2)$. This is slower than projected gradient descent's linear convergence for strongly convex objectives, but Frank--Wolfe does not require a projection oracle — a critical advantage when $\mathcal{X}$ is a nuclear norm ball, a spectrahedron, or another set where LP oracles are cheaper than projections.

The fixed $\beta$ schedule used here is equivalent to a fixed step size $\gamma = 1-\beta$ toward the LP vertex, which does not achieve the $O(1/k)$ rate. For the theoretical guarantee, the step schedule $\gamma_k = 2/(k+2) \to 0$ is required.

\subsection{Frank--Wolfe Gap Analysis}

The Frank--Wolfe gap $G_k = \nabla f(x_k)^T(x_k - z_k)$ provides a computable certificate of near-optimality at every iteration: since $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$, we have $\nabla f(x_k)^T(x_k - z_k) \geq \nabla f(x_k)^T(x_k - x^{\star})$, and for convex $f$:
\begin{equation}
f(x_k) - f^{\star} \leq \nabla f(x_k)^T(x_k - x^{\star}) \leq G_k.
\end{equation}
The gap thus upper bounds the sub-optimality at each iteration without knowing $f^{\star}$.

\subsection{Interior vs.\ Boundary Behaviour}

\textbf{Interior optimum:} Frank--Wolfe exhibits characteristic ``zig-zag'' oscillation because the LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$ at each step (the gradient changes sign between iterations as the iterate oscillates around the optimum). The convex combination iterates average these jumps toward the interior optimum. The $O(1/k)$ convergence is slow compared to projected gradient descent, which achieves linear convergence (exponential rate) for strongly convex functions. The relative advantage of Frank--Wolfe lies in the absence of a projection oracle, not in convergence speed.

\textbf{Boundary optimum:} Frank--Wolfe performs well for boundary optima because the LP oracle consistently selects the feasible extreme point in the descent direction, naturally driving iterates toward the constraint boundary without projection. For $f = x_1^2 + x_2^2$ with gradient $\nabla_1 f = 2x_1 > 0$ (as $x_1 \geq 0.5$), the oracle consistently selects $z_1 = 0.5$, driving $x_1$ monotonically to its lower bound. However, the fixed-$\beta$ schedule leaves a residual gap of $0.364 - 0.25 = 0.114$ after 140 iterations. Using the diminishing schedule $\gamma_k = 2/(k+2)$ (i.e., $\beta_k = k/(k+2) \to 1$) achieves the theoretical $O(1/k)$ convergence rate.

A key structural advantage of Frank--Wolfe over projected gradient descent (Section~\ref{sec:q5}) is its \emph{projection-free} nature: the only feasibility-enforcing operation is a linear minimisation. For constraints like the nuclear norm ball (used in matrix completion), LP oracles require $O(n^2)$ operations (leading singular vectors) while projection requires $O(n^3)$ (full SVD), making Frank--Wolfe the preferred approach at scale.

\textbf{Key conclusions:}

\begin{enumerate}[nosep]
\item \textbf{Problem structure determines best method.} For quadratic problems (Benchmark~A, $\kappa \approx 1.12$), Newton's method solves in one step, and even GD converges in a handful of iterations due to the tiny $\kappa-1 \approx 0.12$. The theoretical GD rate per step is $(1-1/\kappa)/(1+1/\kappa) \approx 0.055$, meaning loss halves roughly every 13 iterations. For ill-conditioned problems (Benchmark~C, $\kappa \approx 2504$), GD's theoretical rate $(1-1/2504)^k$ requires over 1700 iterations to reduce error by a factor of 2 — practically useless without acceleration. Nesterov momentum dominates among first-order methods here; Polyak (with correct $f^*$) achieves the best absolute result.

\item \textbf{Adaptivity helps but requires care.} Adagrad and RMSprop reduce sensitivity to learning rate tuning and handle heterogeneous curvature, but Adagrad's vanishing step size and RMSprop's lack of convergence guarantees are genuine limitations. Adam combines both adaptive scaling and momentum, performing well in practice despite lacking theoretical guarantees in the general non-convex case.

\item \textbf{Second-order information has transformative value.} Newton's method achieves quadratic convergence — solving Benchmark~A \emph{exactly} in one step (quadratic loss has constant Hessian, so one Newton step is exact regardless of starting point), and reducing Rosenbrock from $f=3.73$ (GD, 80 iters) to $f=0.69$ in just 20 iterations. The $O(d^3)$ cost of computing and solving the Newton system is the barrier to its use in large-scale machine learning: for $d = 10^6$ parameters, the Newton system would require $10^{18}$ operations — infeasible. Quasi-Newton methods (e.g., L-BFGS) approximate the Hessian at $O(d \cdot m)$ cost where $m \ll d$, bridging first and second order methods.

\item \textbf{Gradient-free methods sacrifice convergence for generality.} Finite differences with small $\delta$ closely match true GD but scale poorly in dimension ($O(d)$ function evaluations per step). Random search requires only $O(1)$ evaluations but has high gradient variance and slow convergence. Nelder--Mead is reliable for low-dimensional problems ($d \leq 5$) without gradient information.

\item \textbf{Constrained methods trade feasibility guarantees for computational cost.} Projected GD enforces feasibility exactly at every iteration but requires a projection oracle. Penalty methods are simpler to implement but enforce feasibility only approximately, with larger penalty coefficients causing ill-conditioning. Frank--Wolfe avoids projection entirely and is naturally suited to constrained problems where LP oracles are cheap.

\item \textbf{Practical recommendations.} For large-scale machine learning with stochastic gradients: Adam or RMSprop. For well-conditioned smooth problems: Nesterov or Heavy Ball. For small-scale problems with exact gradients: Newton with line search. For derivative-free problems in low dimension: Nelder--Mead. For constrained optimisation with cheap projection: projected GD.
\end{enumerate}

def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
