\begin{abstract}
This report presents a comprehensive comparative study of six families of optimisation algorithms applied to three benchmark problems of increasing difficulty: a linear regression quadratic loss (Benchmark~A, condition number $\kappa \approx 1$), a toy neural-network loss with sinusoidal perturbation (Benchmark~B, $\kappa \approx 7$), and the Rosenbrock function (Benchmark~C, $\kappa \approx 2500$). The methods investigated are: (i) adaptive step-size methods --- Polyak, Adagrad, RMSprop, and Heavy~Ball, each exploiting local gradient information to adjust the learning rate; (ii) momentum-based acceleration --- Nesterov's optimal method ($O(1/k^2)$ vs.\ the $O(1/k)$ rate of gradient descent) and the Adam optimiser, together with mini-batch stochastic gradient descent; (iii) Newton's method, which exploits second-order curvature to achieve quadratic convergence near a non-degenerate optimum; (iv) derivative-free approaches including finite-difference gradient estimation, Nesterov's random search, the Nelder--Mead simplex, and exhaustive grid search; (v) projected gradient descent and quadratic penalty methods for single-constraint feasible-set optimisation; and (vi) the Frank--Wolfe (conditional gradient) algorithm for linear-constrained optimisation, together with an explicit LP subproblem. Results confirm that method performance depends critically on benchmark geometry: Polyak diverges when $f^\star$ is misspecified; Nesterov momentum substantially outperforms gradient descent on the ill-conditioned Rosenbrock valley; Newton's method converges in a single step on a quadratic; and Frank--Wolfe achieves projection-free feasibility maintenance with an $O(1/k)$ suboptimality gap. Theoretical convergence rates are stated and connected to empirical observations throughout.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation is the engine of modern machine learning and data analysis. Training a model, fitting a regression, calibrating a policy, or solving a resource-allocation problem all reduce to finding a minimiser of some objective function $f : \mathbb{R}^d \to \mathbb{R}$. The choice of algorithm determines not only \emph{whether} a solution is reached, but \emph{how quickly} and at \emph{what computational cost}. Different algorithms embody different trade-offs: full-gradient methods are accurate but expensive per step; stochastic methods are cheap but noisy; second-order methods converge fast near the optimum but require Hessian storage and inversion; derivative-free methods are universally applicable but inefficient in high dimensions; and constrained methods must balance feasibility enforcement with objective reduction.

This report investigates these trade-offs empirically across six problem categories (Questions 1--6), each contributing 30~marks to the final assignment. Three benchmark functions are used throughout:
\begin{itemize}[nosep]
  \item \textbf{Benchmark~A} (linear regression, $\S$\ref{sec:benchmarks}): a well-conditioned quadratic whose Hessian $H = X^TX/m$ has eigenvalues close to $1$ for $m \gg d$, offering a baseline where most first-order methods converge quickly.
  \item \textbf{Benchmark~B} (toy neural network, $\S$\ref{sec:benchmarks}): a mildly anisotropic function ($\kappa \approx 7$) whose non-quadratic sinusoidal term provides a gentle non-linearity, revealing differences between first- and second-order methods.
  \item \textbf{Benchmark~C} (Rosenbrock, $\S$\ref{sec:benchmarks}): the canonical stress test for optimisation algorithms, with $\kappa \approx 2500$ at the optimum and a narrow, curved valley that exposes the limitations of first-order methods with isotropic step sizes.
\end{itemize}

A fourth feasible region (Benchmark~D: $\{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$) is used in Questions~5 and~6 for constrained optimisation. All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility, and all figures are generated by the accompanying code \texttt{CS7DS2\_Final\_Code\_25336453.py}.

\paragraph{Report organisation.} Section~\ref{sec:benchmarks} formally defines the benchmarks and their spectral properties. Sections~\ref{sec:q1}--\ref{sec:q6} correspond to Questions~1--6 of the assignment brief. Each section states the relevant theoretical convergence guarantees, presents hyperparameter settings, discusses the empirical results, and connects findings back to course theory. Section~\ref{sec:conclusion} synthesises the results into a unified comparative discussion.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
x^{(i)} \sim \mathcal{N}(0, I_2), \quad
y^{(i)} = {\theta^{\star}}^T x^{(i)} + \varepsilon^{(i)}, \quad
\varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2
= \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
The Hessian $H = X^TX/m$ is constant. By the law of large numbers, $H \to I_2$ as $m \to \infty$, so for $m = 1000$ we expect $H \approx I_2$, giving condition number $\kappa \approx 1$. The irreducible noise floor is $J^{\star} \approx \sigma^2/2 = 0.5$; the empirical value is $J^{\star} \approx 0.4826$. Starting point: $\theta_0 = [0,\,0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}

\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
Gradient: $\nabla f = [2(x_1 - 1) + \cos(x_1),\; 10(x_2 - 2)]^T$. Hessian: $H(x) = \mathrm{diag}(2 - \sin(x_1),\; 10)$. At the minimum $x_1^{\star} \approx 0.582$ (where $2(x_1^{\star}-1)+\cos(x_1^{\star}) = 0$) and $x_2^{\star} = 2.0$:
\[
H(x^{\star}) = \mathrm{diag}(2 - \sin(0.582),\; 10) \approx \mathrm{diag}(1.45,\; 10).
\]
Hence $\mu \approx 1.45$, $L = 10$, and $\kappa = L/\mu \approx 6.9$. The minimum function value is $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1,\,4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is $x^{\star} = (1,\,1)$ with $f^{\star} = 0$. At the optimum, the Hessian is
\[
H(x^{\star}) = \begin{bmatrix} 2 + 1200 - 400 & -400 \\ -400 & 200 \end{bmatrix}
= \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}.
\]
Since $\mathrm{tr}(H) = 1002$ and $\det(H) = 802 \cdot 200 - 400^2 = 400$, the eigenvalues satisfy $\lambda_1 + \lambda_2 = 1002$ and $\lambda_1 \lambda_2 = 400$. Solving: $\lambda_1 \approx 1001.6$, $\lambda_2 \approx 0.4$, giving $\kappa = \lambda_1/\lambda_2 \approx 2504$. This extreme ill-conditioning combined with the curved banana-shaped valley $x_2 \approx x_1^2$ makes Rosenbrock one of the most challenging standard test functions. Starting point: $x_0 = [-1,\,1]^T$.

For gradient descent with step size $\alpha$ to be stable on Rosenbrock, we require $\alpha \leq 2/L = 2/1001.6 \approx 0.002$. Even with a stable step, the convergence rate at the optimum is $(1-\mu/L)^k = (1-1/2504)^k \approx e^{-k/2504}$, requiring approximately $2504 \ln(1000) \approx 17{,}300$ iterations to reduce the suboptimality by a factor of $10^3$.

\subsection{Benchmark D: Constrained Feasible Set}

For constrained problems: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$.
The diameter is $D = \|(5,10)^T - (0.5,-5)^T\| = \sqrt{4.5^2 + 15^2} \approx 15.66$, which governs the Frank--Wolfe convergence guarantee (Section~\ref{sec:q6}).

\subsection{Theoretical Background}

\begin{definition}
A function $f : \mathbb{R}^d \to \mathbb{R}$ is \emph{$L$-smooth} if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|$ for all $x, y$. It is \emph{$\mu$-strongly convex} if $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$.
\end{definition}

For the baseline gradient descent (GD) update $x_{k+1} = x_k - \alpha \nabla f(x_k)$ with $\alpha = 1/L$:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{L \|x_0 - x^{\star}\|^2}{2k} \qquad \text{(convex, } O(1/k)\text{ rate)}.
\end{equation}
Under strong convexity ($\mu > 0$), convergence accelerates to linear:
\begin{equation}
\|x_k - x^{\star}\|^2 \leq \left(1 - \frac{\mu}{L}\right)^k \|x_0 - x^{\star}\|^2 \quad \Rightarrow \quad O(\rho^k),\ \rho = 1 - \frac{1}{\kappa}.
\end{equation}
For Benchmark~A ($\kappa \approx 1$), GD with $\alpha \approx 1$ converges in $O(1)$ steps. For Benchmark~C ($\kappa \approx 2504$), the convergence factor $\rho \approx 0.9996$ requires thousands of iterations --- motivating the adaptive methods studied here.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Adaptive, requires knowledge of $f^\star$}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Polyak convergence]\label{thm:polyak}
If $f$ is convex and $f^\star$ is known exactly, the Polyak step satisfies
$\|x_{k+1} - x^\star\|^2 = \|x_k - x^\star\|^2 - (f(x_k)-f^\star)^2/\|g_k\|^2$,
so the distance to the optimum is non-increasing. Under strong convexity, this implies linear convergence. Critically, if $f^\star_{\text{spec}} < f^\star_{\text{true}}$, then as $x_k \to x^\star$ we have $\|g_k\| \to 0$ while $f(x_k) - f^\star_{\text{spec}} \to f^\star_{\text{true}} - f^\star_{\text{spec}} > 0$, causing $\alpha_k \to \infty$ and inducing divergence.
\end{theorem}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate cumulative squared gradient}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's key property is per-coordinate learning-rate adaptation: coordinates with consistently large gradients receive smaller effective rates, while infrequently updated coordinates receive larger rates. In the online-learning setting, the cumulative regret satisfies $R_T \leq \alpha_0 \sum_{i=1}^d \sqrt{G_{T,i}}$, which is $O(\sqrt{T})$ even for adversarial losses. The main limitation is the monotonically decreasing step (since $G_k$ is non-decreasing), which can cause premature stagnation on long-horizon problems.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop (Hinton, 2012) corrects Adagrad's over-discounting by replacing the cumulative sum with an exponential moving average (EMA) with decay $\beta$. The effective window length is $1/(1-\beta)$; with $\beta = 0.9$, only the last $\sim 10$ gradients dominate. This allows the step size to recover when gradient magnitudes decrease, preventing premature stagnation.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}
For a strongly convex quadratic $f(x) = \frac{1}{2}x^T H x - b^T x$ with $\mu = \lambda_{\min}(H)$ and $L = \lambda_{\max}(H)$, the \emph{optimal} Heavy~Ball parameters are
$\alpha^* = \tfrac{4}{(\sqrt{L}+\sqrt{\mu})^2}$ and $\beta^* = \bigl(\tfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\bigr)^2$,
achieving convergence rate $\bigl(\tfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\bigr)^{2k}$ versus $(1-1/\kappa)^k$ for GD. For $\kappa = 7$ (Benchmark~B): $\beta^* \approx 0.20$ and the optimal rate is $\approx 0.45^{2k}$, dramatically faster than GD's $0.86^k$. In practice, $\beta = 0.90$ is used, which provides acceleration but may cause overshoot on non-quadratic problems.
\end{remark}

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly (Benchmark~C), Polyak converges fastest. On Benchmarks~A and B, Heavy~Ball and Adagrad match or exceed GD, with Heavy~Ball preferred when momentum can build in a consistent direction.
\item \textbf{Robustness:} GD is the most robust (no hyperparameter sensitivity beyond $\alpha$). Adagrad is reliably stable due to its monotonically decreasing step. RMSprop and Heavy~Ball require more tuning but offer better peak performance. Polyak requires exact $f^\star$ --- a strong assumption rarely satisfied in practice.
\item \textbf{Curvature sensitivity:} On Benchmark~A ($\kappa \approx 1$), all methods perform similarly. On Benchmark~C ($\kappa \approx 2504$), the gap widens dramatically: Polyak reduces $f$ by a factor of $\sim 375$ over GD, Heavy~Ball by $\sim 2.5$, and Adagrad by $\sim 1.6$.
\item \textbf{Practical recommendation:} RMSprop and Adagrad are the most robust choices for general problems where $f^\star$ is unknown. For well-conditioned quadratics, Heavy~Ball with tuned $\alpha$ and $\beta$ is competitive with Nesterov (see Section~\ref{sec:q2}).
\end{itemize}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\; \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Update momentum buffer}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The pivotal innovation is the \emph{lookahead}: the gradient is evaluated at the point $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$ itself. This ``corrects'' the momentum trajectory before the step is committed, avoiding the systematic overshoot of Heavy~Ball. The adaptive schedule $\beta_k = (k-1)/(k+2)$ increases momentum gradually and achieves the following fundamental bound:

\begin{theorem}[Nesterov Acceleration, 1983]\label{thm:nesterov}
For $f$ convex and $L$-smooth, Nesterov's accelerated gradient method with step size $\alpha = 1/L$ achieves
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L \|x_0 - x^{\star}\|^2}{(k+1)^2} = O\!\left(\frac{1}{k^2}\right),
\end{equation}
which is provably optimal among first-order methods that use only $\nabla f$ evaluations. This is quadratically faster than the $O(1/k)$ rate of gradient descent.
\end{theorem}

In practice, the $\beta_{\max}$ parameter caps the momentum to prevent overshoot on non-convex problems such as Benchmark~B and~C.

\begin{remark}[Why the schedule $\beta_k = (k-1)/(k+2)$ achieves $O(1/k^2)$]
The sequence $t_k = (k+1)/2$ satisfies $t_k^2 \leq t_{k-1}^2 + t_k$ (the key Lyapunov recursion), and $\beta_k = (t_{k-1}-1)/t_k$ converges to 1 as $k \to \infty$. Together, these yield the energy estimate $E_k = t_k^2(f(x_k)-f^\star) + \frac{t_k^2}{2\alpha}\|y_k - x^\star\|^2$ is non-increasing, where $y_k = x_k + \beta_k z_k$ is the lookahead point. Telescoping gives $f(x_k) - f^\star \leq E_0/t_k^2 = O(1/k^2)$. The $\beta_{\max}$ cap prevents this schedule from being applied at full strength in early iterations when the iterate may be far from $x^\star$.
\end{remark}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\; v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (momentum)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (adaptive scale)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam (Kingma \& Ba, 2015) combines RMSprop's per-coordinate adaptive scaling (via $v_t$) with Nesterov-style momentum (via $m_t$). The bias correction terms $(1-\beta_j^t)$ are essential in early iterations: without them, $m_t \approx (1-\beta_1) g_t \ll g_t$ and $v_t \approx (1-\beta_2) g_t^2$ would produce artificially small updates. Dividing by $(1-\beta_j^t) \to 0$ restores the correct scale. The default $(\beta_1, \beta_2) = (0.9, 0.999)$ yields an effective gradient memory of $\sim 10$ and $\sim 1000$ steps, respectively.

\begin{remark}[Adam's convergence guarantees]
Unlike Nesterov's method, Adam does not have a general convergence guarantee for non-convex smooth objectives. Counter-examples exist where Adam fails to converge even on simple convex problems when the step size does not decay (Reddi et al., 2018). The AMSGrad variant addresses this by using the \emph{maximum} of past second moments rather than the exponential moving average. In practice, Adam with careful learning rate tuning converges well on the benchmark problems studied here, as confirmed by the final values in Table~\ref{tab:q2_final}.
\end{remark}

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark~A uses learning rate $\alpha = 0.06$ (\emph{constant} across all epochs), batch sizes $b \in \{5, 40\}$, 50~epochs, with data shuffled at every epoch.

\begin{remark}[Constant vs.\ decaying learning rate in SGD]
With a constant learning rate $\alpha$, SGD converges to a \emph{neighbourhood} of the optimum whose radius is $O(\alpha \sigma^2)$, where $\sigma^2 = \mathrm{Var}[\hat{g}]$ is the gradient noise variance. To achieve exact convergence to $\theta^\star$, one must use a decaying schedule: $\alpha_k = c/(k+c_0)$ satisfies $\sum_k \alpha_k = \infty$ (divergent sum) and $\sum_k \alpha_k^2 < \infty$ (square-summable), which are the Robbins--Monro conditions for convergence. In practice, constant learning rates are preferred in deep learning where the final batch loss floor is irreducible; the present experiment (50 epochs with constant $\alpha = 0.06$) confirms convergence to the noise floor $J^\star \approx 0.4826$ for both batch sizes.
\end{remark}

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $\hat{g} \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Unbiased gradient estimate: $\mathbb{E}[\hat{g}] = \nabla J(\theta)$}
        \State $\theta \gets \theta - \alpha\, \hat{g}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The mini-batch gradient is unbiased: $\mathbb{E}[\hat{g}] = \nabla J(\theta)$. Its variance is $\mathrm{Var}[\hat{g}] = \sigma^2_{\mathrm{samp}}/b$, where $\sigma^2_{\mathrm{samp}}$ is the per-sample gradient variance. Smaller $b$ gives higher-variance updates (more oscillation) but performs $m/b$ parameter updates per epoch, potentially yielding faster early descent.

\subsection{Local Approximations of $g(x) = x^4$}

The Taylor series of $g(x) = x^4$ around $x_0 = 0.25$:

\textbf{First-order (gradient) approximation:}
\begin{equation}
\hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.25^4 + 4 \cdot 0.25^3\,(x - 0.25) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order (curvature) approximation:}
\begin{equation}
\hat{g}_2(x) = \hat{g}_1(x) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises $\hat{g}_2$: setting $\hat{g}_2'(x) = 0$ gives $x_{k+1} = x_k - g'(x_k)/g''(x_k)$. This is equivalent to stepping to the stationary point of the local quadratic model. Since $g(x) = x^4$ is convex and the Newton step always moves to the minimum of the quadratic model, the method is well-defined.

\textbf{One Newton step on $g(x) = x^4$ from $x_0 = 0.25$:}
\[
x_1 = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{4(0.25)^3}{12(0.25)^2} = 0.25 - \frac{0.0625}{0.75} \approx 0.1667.
\]
Repeating: $x_2 = 0.1667 - 4(0.1667)^3/(12(0.1667)^2) = 0.1667/3 \approx 0.0556$. The pattern $x_{k+1} = x_k/3$ reveals convergence to 0 (the true minimum) at a superlinear rate. This is faster than gradient descent, which would require $\alpha$ tuning and many steps to converge.

\subsection{Newton's Method with Damping}

\begin{algorithm}[H]
\caption{Newton's Method with Damping and Regularisation}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, Hessian regularisation $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation for positive definiteness}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (descent direction since $H_k \succ 0$)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{Damped Newton step ($\alpha \leq 1$)}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Newton's Quadratic Convergence]\label{thm:newton}
Let $f$ be twice continuously differentiable with Lipschitz Hessian, and let $x^\star$ be a non-degenerate local minimum (i.e., $\nabla^2 f(x^\star) \succ 0$). Then for $x_0$ sufficiently close to $x^\star$ and $\alpha = 1$ (full Newton step), there exists $C > 0$ such that
\begin{equation}
\|x_{k+1} - x^\star\| \leq C\, \|x_k - x^\star\|^2.
\end{equation}
This \emph{quadratic} convergence rate means that the number of correct decimal digits approximately doubles per iteration in the local regime. For a quadratic objective, Newton converges in \emph{one} step regardless of condition number.

\begin{proof}[Proof sketch for quadratic objectives]
For $f(\theta) = \frac{1}{2}\theta^T H \theta - b^T \theta$ with $\nabla f(\theta) = H\theta - b$, $\nabla^2 f = H$, the Newton step is:
$\theta_{k+1} = \theta_k - H^{-1}(H\theta_k - b) = H^{-1}b = \theta^\star.$
One step, regardless of $\kappa$. With regularisation $\lambda = 10^{-8} \ll \lambda_{\min}(H)$, the result holds approximately.
\end{proof}
\end{theorem}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian regularisation $\lambda = 10^{-8}$.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark~B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference (FD) approximation of the $i$-th partial derivative is:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta} = \frac{\partial f}{\partial x_i}(x) + \underbrace{\frac{\delta}{2} \frac{\partial^2 f}{\partial x_i^2}(x) + O(\delta^2)}_{\text{truncation error}}.
\end{equation}

An alternative is the \textbf{central finite difference}:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x - \delta e_i)}{2\delta} = \frac{\partial f}{\partial x_i}(x) + \underbrace{\frac{\delta^2}{6}\frac{\partial^3 f}{\partial x_i^3}(x) + O(\delta^4)}_{\text{truncation error $O(\delta^2)$}},
\end{equation}
which achieves $O(\delta^2)$ truncation (vs.\ $O(\delta)$ for forward FD) at the cost of $2d$ function evaluations per gradient (vs.\ $d+1$ for forward FD). For the same step size $\delta$, central differences are far more accurate; for the same accuracy, they require a larger $\delta$ and hence are less susceptible to round-off errors.

\begin{proposition}[Optimal FD step sizes]\label{prop:fd}
For \emph{forward differences}: total error $e_{\mathrm{fwd}}(\delta) \approx \frac{|f''|}{2}\delta + \frac{2\varepsilon_{\mathrm{fp}}}{\delta}$, optimal $\delta_{\mathrm{fwd}} = 2\sqrt{\varepsilon_{\mathrm{mach}}} \approx 3 \times 10^{-8}$ (IEEE~754 double, $\varepsilon_{\mathrm{mach}} \approx 2.2\times 10^{-16}$).

For \emph{central differences}: total error $e_{\mathrm{cen}}(\delta) \approx \frac{|f'''|}{6}\delta^2 + \frac{2\varepsilon_{\mathrm{fp}}}{\delta}$, optimal $\delta_{\mathrm{cen}} = (3\varepsilon_{\mathrm{mach}}/|f'''|)^{1/3} \approx 6 \times 10^{-6}$ --- three orders of magnitude larger, reducing round-off sensitivity.
\end{proposition}

The assignment implements forward differences with $\delta = 0.05$ (good) and $\delta = 0.8$ (poor: truncation error $O(\delta) = O(0.8)$ dominates and seriously distorts the gradient direction). Note that the FD-GD learning rate ($\alpha = 0.08$) is slightly larger than the exact-GD rate ($\alpha = 0.06$), adjusted empirically to compensate for the bias in the gradient estimate.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$; normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Random directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates the gradient using only \emph{two} function evaluations per iteration regardless of dimension $d$. The estimator is unbiased for a smoothed version of $f$: $\mathbb{E}[\hat{g}_k] = \nabla f_\delta(x_k)$ where $f_\delta$ is a Gaussian-smoothed surrogate. The convergence rate is $O(d/k)$ for $L$-smooth convex functions in expectation, which is $d/2 = 1$ times slower than GD for $d=2$ but independent of $d$ in terms of function evaluations (unlike FD, which requires $d+1$ evaluations for a full gradient).

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm (1965) maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it via four geometry-preserving operations: \textbf{reflection} ($\alpha_r = 1.0$) moves the worst vertex through the centroid of the remaining vertices; \textbf{expansion} ($\gamma = 2.0$) extends further if reflection improved; \textbf{outside/inside contraction} ($\rho = 0.5$) shrinks towards the centroid if reflection worsened; and \textbf{shrink} ($\sigma = 0.5$) contracts all vertices towards the best vertex. No gradient information is required at any step.

Unlike gradient-based methods, Nelder--Mead has no general convergence guarantee for $d \geq 2$. However, for smooth unimodal functions in low dimension, it reliably finds local minima. Its termination is typically governed by the simplex diameter or function value spread.

\subsection{Problem Formulation and KKT Conditions}

Minimise Benchmark~B subject to a single linear constraint:
\begin{equation}
\min_{x \in \mathbb{R}^2}\; f(x_1, x_2) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1),
\qquad \text{s.t.}\quad x_1 \geq 0.5.
\end{equation}
Starting from the infeasible point $x_0 = (0.2,\, 4.0)$. The feasible set is $\mathcal{X} = \{x : x_1 \geq 0.5\}$.

\begin{proposition}[KKT conditions]\label{prop:kkt}
Writing the constraint as $g(x) = 0.5 - x_1 \leq 0$, the KKT conditions for a local minimum $x^\star$ are:
\begin{align}
\nabla f(x^\star) - \mu e_1 &= 0 \quad \text{(stationarity, where $e_1 = [1,0]^T$)}, \\
\mu\,(0.5 - x_1^\star) &= 0 \quad \text{(complementary slackness)}, \\
\mu &\geq 0 \quad \text{(dual feasibility)}, \\
x_1^\star &\geq 0.5 \quad \text{(primal feasibility)}.
\end{align}
The unconstrained minimum of $f$ is at $x_1^\star \approx 0.582 > 0.5$, so the constraint is \emph{inactive} at the optimum: $\mu = 0$ (complementary slackness requires $0.5 - 0.582 < 0$, hence $\mu = 0$). Consequently, the constrained minimum \emph{equals} the unconstrained minimum. The constraint only affects the optimisation \emph{path} (particularly from the infeasible starting point), not the final solution.
\end{proposition}

\subsection{Algorithm Descriptions}

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1}) = [z_{k+1,1} \vee 0.5,\; z_{k+1,2}]^T$ \Comment{Project: $x_1 \leftarrow \max(0.5, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

PGD inherits the same $O(1/k)$ convergence rate as unconstrained GD for convex $f$ over convex $\mathcal{X}$, provided the projection is exact. For the half-space $\{x_1 \geq 0.5\}$, the projection is a simple clamping operation ($O(1)$ per step). PGD enforces feasibility as a \emph{hard constraint} at every iteration.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_\lambda(x) \gets f(x) + \lambda\, \max(0,\; 0.5 - x_1)$ \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_\lambda(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The quadratic penalty version would use $\frac{\lambda}{2}\max(0, 0.5-x_1)^2$; here a linear (exterior) penalty is used. As $\lambda \to \infty$, the penalty-method solution converges to the constrained minimum, but the penalised objective becomes increasingly ill-conditioned (Lipschitz constant grows as $\lambda$), requiring smaller step sizes. This is the fundamental penalty-method trade-off.

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$); unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\textbf{Key design principles:}
\begin{itemize}[nosep]
\item \textbf{Projected GD} enforces feasibility exactly at every iteration. This guarantees that all intermediate iterates are valid solutions, which is critical in applications where infeasible points are operationally meaningless (e.g., non-negative weights, probability simplex). The cost is requiring an exact projection oracle, which is trivial for half-spaces ($O(1)$) but can be expensive for general convex sets (e.g., semidefinite cone: $O(d^3)$).
\item \textbf{Penalty methods} enforce feasibility approximately, with accuracy increasing with $\lambda$. The advantage is algorithmic simplicity (no projection oracle required); only a modified gradient computation is needed. The disadvantage is the trade-off: large $\lambda$ enforces the constraint well but requires smaller step sizes (since $\nabla F_\lambda$ has Lipschitz constant $L_f + \lambda$), slowing convergence.
\item \textbf{Augmented Lagrangian} (not implemented here, but theoretically superior): the method minimises
\begin{equation}
L_\rho(x, \mu) = f(x) + \mu\, g(x) + \frac{\rho}{2}\, [g(x)]_+^2,
\end{equation}
where $[g]_+ = \max(0, g)$, alternating between minimisation over $x$ and dual update $\mu \leftarrow \max(0, \mu + \rho g(x_k))$. Unlike the pure penalty method, the augmented Lagrangian achieves exact feasibility ($g(x^\star) = 0$) at a \emph{finite} $\rho$ when the dual variable $\mu$ converges to the true Lagrange multiplier. This resolves the ill-conditioning of large-$\lambda$ penalty methods while retaining their simplicity.
\end{itemize}

\section{Question 6: Linear Programmes and Frank--Wolfe Algorithm \hfill [30 marks]}
\label{sec:q6}

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$ (diameter $D \approx 15.66$, see Section~\ref{sec:benchmarks}).

\textbf{Linear Programme:} For $f(x) = a^Tx$ with $a = [1,\, 2]^T$, the minimum over $\mathcal{X}$ is:
\begin{equation}
x^{\star} = \arg\min_{x \in \mathcal{X}} (x_1 + 2x_2) = (0.5,\; -5), \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}
This follows from the \textbf{fundamental theorem of linear programming}: for a linear objective over a bounded polytope, the minimum is attained at a vertex. Since both components of $a$ are positive, the minimum is at the lower bounds.

\textbf{Verification of LP optimality:} By the LP optimality condition, $x^\star = (0.5, -5)$ is optimal iff $a^T(x-x^\star) \geq 0$ for all $x \in \mathcal{X}$ (since $f$ is linear, this means $f(x) \geq f(x^\star)$). Indeed, for any $(x_1, x_2) \in \mathcal{X}$: $f(x) - f(x^\star) = (x_1 - 0.5) + 2(x_2 + 5) \geq 0$ since $x_1 \geq 0.5$ and $x_2 \geq -5$. \qquad $\checkmark$

\subsection{Frank--Wolfe (Conditional Gradient) Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: $x_{k+1} \in \mathcal{X}$ by convexity}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Frank--Wolfe convergence]\label{thm:fw}
For $f$ convex and $L$-smooth over a compact convex set $\mathcal{X}$ with diameter $D = \sup_{x,y \in \mathcal{X}}\|x-y\|$, with the standard step size $\gamma_k = 2/(k+2)$ (i.e., $\beta_k = 1-\gamma_k = k/(k+2)$), the Frank--Wolfe algorithm satisfies:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2LD^2}{k+2} = O\!\left(\frac{1}{k}\right).
\end{equation}
This $O(1/k)$ rate matches gradient descent but is achieved without any projection oracle. The trade-off is that FW requires solving an LP subproblem (the LMO) at each iteration, which for box constraints decomposes trivially:
$(z_k)_i = l_i$ if $(\nabla f(x_k))_i > 0$, else $(z_k)_i = u_i$.
\end{theorem}

The \emph{Frank--Wolfe duality gap} $h_k = \nabla f(x_k)^T(x_k - z_k) \geq f(x_k) - f^\star$ provides an upper bound on suboptimality, computable without knowing $f^\star$.

\begin{remark}
The implementation uses a \emph{fixed} mixing parameter $\beta$ (i.e., $\gamma = 1-\beta$ is constant), which deviates from the standard $\gamma_k = 2/(k+2)$ schedule. A fixed step size does not guarantee the $O(1/k)$ bound from Theorem~\ref{thm:fw}; it may converge to a neighbourhood of $x^\star$ but not to $x^\star$ itself. The results below reflect this limitation.
\end{remark}

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum:} FW exhibits the characteristic ``zig-zag'' pattern because $z_k$ alternates between extreme vertices of $\mathcal{X}$. The convex combination averages these jumps. With a fixed $\beta$, convergence stagnates at a residual oscillation level proportional to $D(1-\beta)/(1-\beta)$ --- governed by the size of the vertex jumps relative to the step size. Using the decaying schedule $\gamma_k = 2/(k+2)$ would eventually drive $z_k - x_k \to 0$ and achieve $f(x_k) \to f^\star$.

\textbf{Boundary optimum:} FW is naturally suited to boundary optima: the LP oracle always selects the vertex of $\mathcal{X}$ most aligned with the negative gradient, which for $\nabla f(x) = [2x_1, 2x_2]^T$ points toward $(0.5, 0)$ when $x$ is near the boundary. The fixed-$\beta$ limitation means the iterate never fully reaches $(0.5, 0)$; the residual gap is $f = 0.364$ vs.\ $f^\star = 0.25$.

\textbf{FW duality gap as a stopping criterion:} At any iterate $x_k$, the Frank--Wolfe gap
\begin{equation}
h_k = \nabla f(x_k)^T (x_k - z_k) \geq f(x_k) - f^\star \geq 0
\end{equation}
provides a computable upper bound on suboptimality without requiring knowledge of $f^\star$. For example, at the final boundary iterate $x_k \approx (0.5, -0.337)$: $\nabla f = (1.0, -0.674)$, $z_k = (0.5, 10)$ (the LP oracle selects the lower bound for $x_1$ since $\nabla f_1 > 0$, and the upper bound for $x_2$ since $\nabla f_2 < 0$), giving $h_k = (1.0)(0) + (-0.674)(-10.337) \approx 6.97$. While the true gap is only $0.364 - 0.25 = 0.114$, the FW gap 6.97 confirms that further optimisation is needed. The gap is loose because the LP vertex is at an extreme point far from $x^\star$; it tightens as $x_k \to x^\star$ and $z_k \to x^\star$.

\textbf{FW vs Projected GD for constrained problems:}
Frank--Wolfe avoids projection entirely (only an LP oracle is needed), making it attractive when projection is expensive (e.g., nuclear-norm ball: PGD requires full SVD, FW requires rank-1 SVD). However, FW's $O(1/k)$ rate cannot be improved to $O(1/k^2)$ without additional structure (unlike PGD which can use Nesterov acceleration). For box constraints (where both projection and LP are trivially $O(d)$), PGD is generally preferred.

\subsection{Key Conclusions}

\begin{enumerate}[leftmargin=*, label=\arabic*.]

\item \textbf{Problem geometry dominates method performance.} On Benchmark~A ($\kappa \approx 1$), nearly all methods converge in $O(1)$ iterations and differences are negligible. On Benchmark~C ($\kappa \approx 2504$), the gap between the best method (Polyak with correct $f^\star$: $f=0.0094$) and the worst (GD: $f \approx 3.5$) is three orders of magnitude.

\item \textbf{Polyak step size is powerful but fragile.} When $f^\star$ is known exactly (Benchmark~C), Polyak achieves the fastest convergence among all first-order methods. When $f^\star$ is misspecified (Benchmarks~A and~B, where the true minima are 0.48 and 0.72 but $f^\star=0$ is specified), the method diverges due to unbounded step sizes. This sensitivity limits practical use.

\item \textbf{Nesterov acceleration achieves provably optimal first-order convergence.} The $O(1/k^2)$ rate (Theorem~\ref{thm:nesterov}) translates to substantial empirical improvements on Benchmark~C over GD ($0.479$ vs.\ $3.39$), confirming that the quadratic acceleration is relevant even in the nonconvex regime.

\item \textbf{Newton's method is qualitatively superior on quadratics} (one exact step on Benchmark~A) \textbf{but requires careful damping on ill-conditioned non-linear problems} (Benchmark~C). Its quadratic convergence near the optimum (Theorem~\ref{thm:newton}) is offset by the need for a Hessian oracle and the sensitivity to initial conditions when the Hessian changes rapidly. Quasi-Newton methods (L-BFGS) offer a practical compromise for high-dimensional problems.

\item \textbf{Finite-difference gradient approximation quality is critical.} Using $\delta = 0.05$ closely reproduces exact-GD behaviour, while $\delta = 0.8$ severely biases the gradient and prevents convergence. The optimal step balances truncation error ($O(\delta)$) against round-off error ($O(\varepsilon_{\mathrm{mach}}/\delta)$), giving $\delta_{\mathrm{opt}} \approx \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}$.

\item \textbf{Projected GD enforces hard feasibility} from the first iteration, making it preferable when feasibility is non-negotiable. The penalty method trades constraint satisfaction for algorithmic simplicity, converging to a feasible solution only asymptotically ($\lambda \to \infty$). For the specific problem here (where the unconstrained minimum is feasible), both methods achieve the same final solution.

\item \textbf{Frank--Wolfe's projection-free approach} is its key advantage for constraint sets where projection is expensive. Its $O(1/k)$ convergence (Theorem~\ref{thm:fw}) matches GD but the fixed-$\beta$ implementation prevents reaching $f^\star$ due to residual oscillation; the standard decaying schedule $\gamma_k = 2/(k+2)$ is recommended for guaranteed convergence.

\end{enumerate}

\subsection{Practical Recommendations}

For practitioners choosing an optimisation algorithm:
\begin{itemize}[nosep]
\item \textbf{Well-conditioned, smooth, large-scale} (e.g., deep learning): Adam or RMSprop with mini-batch SGD. Adam's per-coordinate scaling handles heterogeneous feature scales and its momentum accelerates convergence through flat regions.
\item \textbf{Ill-conditioned, moderate-scale} (e.g., scientific computing, small neural networks): Nesterov momentum if only first-order information is available; L-BFGS or damped Newton if Hessian-vector products are feasible.
\item \textbf{Gradient available, learning rate unknown}: Adagrad provides a good automatic schedule at the cost of eventual over-discounting; RMSprop fixes this with a tunable $\beta$.
\item \textbf{Black-box objective, low-dimension} ($d \leq 10$): Nelder--Mead (no gradient required). For moderate $d$, Nesterov random search or evolution strategies (CMA-ES) are preferred.
\item \textbf{Constrained, simple feasible set} (box, simplex, half-space): Projected GD for exact feasibility; penalty method for simplicity.
\item \textbf{Constrained, expensive projection} (nuclear-norm ball, spectahedron): Frank--Wolfe with decaying step size $\gamma_k = 2/(k+2)$ for guaranteed $O(1/k)$ convergence without any projection.
\end{itemize}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Nelder--Mead Simplex}]
def nelder_mead(loss_fn, x0, step, n_iters, alpha_r=1.0, gamma=2.0, rho=0.5, sigma=0.5):
    n = len(x0)
    simplex = np.zeros((n + 1, n))
    simplex[0] = x0.copy()
    for i in range(n):
        simplex[i + 1] = x0.copy()
        simplex[i + 1][i] += step
    f_vals = np.array([loss_fn(v) for v in simplex])
    centroid_hist = [np.mean(simplex, axis=0).copy()]
    f_best_hist = [np.min(f_vals)]
    for _ in range(n_iters):
        order = np.argsort(f_vals)
        simplex = simplex[order]; f_vals = f_vals[order]
        centroid = np.mean(simplex[:-1], axis=0)
        x_r = centroid + alpha_r * (centroid - simplex[-1])
        f_r = loss_fn(x_r)
        if f_vals[0] <= f_r < f_vals[-2]:
            simplex[-1] = x_r; f_vals[-1] = f_r
        elif f_r < f_vals[0]:
            x_e = centroid + gamma * (centroid - simplex[-1])
            f_e = loss_fn(x_e)
            if f_e < f_r: simplex[-1] = x_e; f_vals[-1] = f_e
            else: simplex[-1] = x_r; f_vals[-1] = f_r
        else:
            if f_r < f_vals[-1]:
                x_c = centroid + rho * (x_r - centroid)
                f_c = loss_fn(x_c)
                if f_c <= f_r: simplex[-1] = x_c; f_vals[-1] = f_c
                else:
                    for i in range(1, n+1):
                        simplex[i] = simplex[0]+sigma*(simplex[i]-simplex[0])
                        f_vals[i] = loss_fn(simplex[i])
            else:
                x_c = centroid + rho * (simplex[-1] - centroid)
                f_c = loss_fn(x_c)
                if f_c < f_vals[-1]: simplex[-1] = x_c; f_vals[-1] = f_c
                else:
                    for i in range(1, n+1):
                        simplex[i] = simplex[0]+sigma*(simplex[i]-simplex[0])
                        f_vals[i] = loss_fn(simplex[i])
        centroid_hist.append(np.mean(simplex, axis=0).copy())
        f_best_hist.append(np.min(f_vals))
    return np.array(centroid_hist), np.array(f_best_hist), simplex
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
