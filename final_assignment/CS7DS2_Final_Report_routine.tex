\begin{abstract}
This report presents a rigorous comparative study of optimisation algorithms applied across three standard benchmark problems: a convex quadratic linear-regression loss (Benchmark~A), a mildly nonlinear toy neural-network loss with a sinusoidal perturbation (Benchmark~B), and the highly non-convex, ill-conditioned Rosenbrock function (Benchmark~C). Six categories of methods are investigated systematically: (1) adaptive step-size methods—Polyak, Adagrad, RMSprop, and Heavy Ball; (2) momentum and stochastic methods—Nesterov acceleration, Adam, and mini-batch SGD; (3) Newton's method with first- and second-order local approximations; (4) derivative-free approaches—finite-difference gradient descent, Nesterov random search, Nelder–Mead simplex, and grid search; (5) constrained optimisation via projected gradient descent and penalty methods; and (6) the Frank–Wolfe conditional gradient algorithm for linear-constrained problems. Each method is evaluated with respect to convergence speed, trajectory behaviour, stability, and computational cost. Key findings include: the Polyak step size is highly effective when $f^{\star}$ is known exactly but diverges when it is misspecified; Nesterov acceleration achieves demonstrably superior convergence on the ill-conditioned Rosenbrock function; Newton's method exhibits near-quadratic convergence on smooth benchmarks while requiring aggressive damping on nonlinear landscapes; and the Frank–Wolfe algorithm naturally enforces box constraints without explicit projection but converges at an $O(1/k)$ rate regardless of optimum location.
\end{abstract}

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. The three benchmark functions are chosen to probe qualitatively different difficulty regimes.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and two parameters is generated as:
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
  \label{eq:benchA_data}
\end{equation}
The mean-squared-error loss is:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
            = \frac{1}{2} \theta^T H \theta - b^T \theta + c,
  \label{eq:benchA_loss}
\end{equation}
where $H = \frac{1}{m}X^T X$ is the empirical Hessian (a constant positive semi-definite matrix), $b = \frac{1}{m}X^T y$, and $c = \frac{1}{2m}\|y\|^2$. The gradient is $\nabla J(\theta) = H\theta - b = \frac{1}{m}X^T(X\theta - y)$.

Since $H$ is constant, Benchmark~A is a \emph{strongly convex quadratic}: it has a unique global minimiser $\theta^{\star}_{\mathrm{OLS}} = H^{-1}b$ attainable in closed form. With $m=1000$ i.i.d. standard normal rows, the empirical Hessian $H = \frac{1}{m}X^TX$ has eigenvalues $\lambda_1 \approx 0.925$, $\lambda_2 \approx 1.033$, giving a very low condition number $\kappa(H) \approx 1.12$. This near-perfect conditioning means any reasonable first-order method converges quickly — Benchmark~A primarily tests numerical correctness rather than convergence speed. Due to observation noise, the minimum loss is $J^{\star} \approx 0.4826 \neq 0$. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Quadratic Loss}

\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
  \label{eq:benchB}
\end{equation}
The gradient is $\nabla f = \bigl[2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)\bigr]^T$ and the Hessian is $H(x) = \operatorname{diag}\bigl(2 - \sin(x_1),\ 10\bigr)$. The Hessian is positive definite for all $x_1 \in (-\pi, \pi)$ since $2 - \sin(x_1) > 0$ throughout. The local curvature ratio $10 / (2 - \sin(x_1))$ varies between approximately $10/3 \approx 3.3$ and $10/1 = 10$, creating mild but non-trivial anisotropy.

Setting $\nabla f = 0$ gives $x_2^{\star} = 2$ and the transcendental equation $2(x_1 - 1) + \cos(x_1) = 0$, solved numerically to yield $x_1^{\star} \approx 0.582$. Thus the minimiser is approximately $(0.582, 2.0)$ with $f^{\star} = (0.582-1)^2 + 0 + \sin(0.582) \approx 0.175 + 0.549 = 0.7244$. The Hessian eigenvalues at the starting point $x_0 = [-1, 4]^T$ are $\approx [2.84, 10]$ (ratio $\approx 3.5:1$), and at the minimiser $\approx [1.45, 10]$ (ratio $\approx 6.9:1$). This moderate anisotropy challenges step-size selection but is far less severe than Rosenbrock. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
  \label{eq:benchC}
\end{equation}
The global minimum is $f^{\star} = 0$ at $(1, 1)$. The Hessian is:
\begin{equation}
  H(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the minimiser $(1,1)$: $H = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}$, with eigenvalues $\lambda_1 \approx 0.399$ and $\lambda_2 \approx 1001.6$, giving condition number $\kappa \approx 2508$. Away from the minimum, the condition number is even larger. This extreme ill-conditioning (factor $\sim 2000\times$ worse than Benchmark~A), combined with the narrow curved valley $x_2 \approx x_1^2$ along which the function value changes very slowly, makes Rosenbrock the most challenging of the three benchmarks and the primary discriminator between methods. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}

For constrained problems: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$ — a closed, bounded (compact) convex polytope.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

For an $L$-smooth function ($\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$), gradient descent with step size $\alpha = 1/L$ satisfies the \emph{descent lemma}: $f(x_{k+1}) \leq f(x_k) - \frac{1}{2L}\|\nabla f(x_k)\|^2$. The four adaptive methods below attempt to automate or improve upon the fixed-step choice.

\begin{theorem}[Polyak Convergence — Known $f^{\star}$]\label{thm:polyak}
If $f$ is convex and $L$-smooth, the Polyak step $\alpha_k = (f(x_k) - f^{\star})/(\|\nabla f(x_k)\|^2 + \varepsilon)$ satisfies
$f(x_{k+1}) - f^{\star} \leq f(x_k) - f^{\star}$
with equality only at the minimiser, and the method converges to $x^{\star}$ provided $f^{\star}$ is specified exactly.
\end{theorem}

When $f^{\star}$ is \emph{misspecified} (set to 0 when the true minimum is $f^{\star}_{\mathrm{true}} > 0$), as $x_k$ approaches $x^{\star}$: the numerator $f(x_k) - 0 \to f^{\star}_{\mathrm{true}} > 0$ while the denominator $\|\nabla f(x_k)\|^2 + \varepsilon \to \varepsilon$. Thus $\alpha_k \to f^{\star}_{\mathrm{true}}/\varepsilon$, which can be enormous ($\approx 0.4826/10^{-4} = 4826$ for Benchmark~A), causing the iterates to overshoot wildly and diverge.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative squared-gradient sum (per coordinate)}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's effective per-coordinate step size $\alpha_0/(\sqrt{G_k^{(i)}} + \varepsilon)$ decays monotonically because $G_k^{(i)}$ is non-decreasing. Coordinates with historically large gradients receive smaller steps, automatically performing coordinate-wise normalisation. The drawback is that the cumulative sum grows without bound, causing the effective learning rate to vanish even when the problem is not yet solved.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's cumulative sum with an exponential moving average controlled by $\beta = 0.9$. The effective step size $v_k^{(i)}$ tracks the recent gradient magnitude, preventing the unbounded decay seen in Adagrad. This makes RMSprop better suited to non-stationary objectives.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method accumulates a velocity $z_k$ that builds momentum in the consistent descent direction. For a strongly convex quadratic with curvature ratio $L/\mu$, the optimal Heavy Ball parameters achieve the convergence rate $\left(\frac{\sqrt{L}-\sqrt{\mu}}{\sqrt{L}+\sqrt{\mu}}\right)^2$ per iteration—a significant improvement over gradient descent's $\left(\frac{L-\mu}{L+\mu}\right)^2$ rate. However, theoretical guarantees are limited to quadratics; on general non-convex problems, oscillations or divergence can occur.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Benchmark A — well-conditioned ($\kappa \approx 1.12$):} All well-behaved methods converge quickly. Adagrad, GD, and Heavy Ball all reach $f = 0.4826$ within 120 iterations. RMSprop slightly overshoots ($f = 0.5064$). Polyak diverges due to misspecified $f^{\star}$. On such a well-conditioned problem, the choice of method matters little — the condition number of 1.12 means gradient descent already has a near-optimal convergence rate.
\item \textbf{Benchmark B — moderate anisotropy ($\kappa \approx 3.5$ at start):} Methods that converge in A also converge in B. The moderate curvature ratio still allows gradient descent to work well. Polyak reaches 0.9819 (above $f^{\star} = 0.7244$), failing to converge to the true minimum due to $f^{\star}$ misspecification, but without the catastrophic divergence seen on A.
\item \textbf{Benchmark C — extreme ill-conditioning ($\kappa \approx 2508$):} This is the discriminating benchmark. Ranking: Polyak ($f=0.0239$) $\gg$ Heavy Ball ($1.40$) $\succ$ Adagrad ($2.20$) $\succ$ RMSprop ($3.12$) $\approx$ GD ($3.51$). Momentum (Heavy Ball) is the key differentiator among the methods that do not require $f^{\star}$.
\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential gradient averaging. Heavy Ball exhibits characteristic overshoot visible as a slight bump before convergence.
\item \textbf{Practical implication:} $f^{\star}$ is almost never known exactly in practice, limiting Polyak's applicability to the rare case of problems with analytically known minima (e.g., regularised regression with known regularisation). As noted in the course lectures (Week~3b), in machine learning applications $f^{\star} = 0$ is sometimes a reasonable approximation but can cause ``noisy'' behaviour near the actual noise floor. For practical use on ill-conditioned problems, Heavy Ball (momentum) offers the best alternative among the Q1 methods.
\item \textbf{Heavy Ball interpretation (course Week~4a):} Since $z_{k+1} = \sum_{j=0}^{k} \beta^{k-j} \alpha \nabla f(x_j)$, the velocity is a weighted average of all past gradients with exponential forgetting. The effective step size is approximately $\alpha/(1-\beta)$: with $\beta = 0.88$ this gives an effective scale of $\alpha/0.12 \approx 8.3\alpha$ on Benchmark~A, explaining why momentum allows larger effective progress per step without instability.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}

\subsection{Theoretical Background}

\begin{theorem}[Nesterov Optimal Convergence Rate]\label{thm:nesterov}
For an $L$-smooth, $\mu$-strongly convex function $f$, Nesterov's accelerated gradient method achieves
\[
  f(x_k) - f^{\star} \leq \frac{L\|x_0 - x^{\star}\|^2}{2} \cdot \left(1 - \sqrt{\mu/L}\right)^k,
\]
matching the lower bound for first-order methods. In the convex (non-strongly convex) case, the rate is $O(1/k^2)$ vs $O(1/k)$ for gradient descent.
\end{theorem}

The improvement from $O(1/k)$ to $O(1/k^2)$ is achieved by evaluating the gradient at the \emph{lookahead point} $x_k + \beta_k z_k$ rather than at $x_k$, allowing the algorithm to partially correct its trajectory before overshooting.

A key insight from the course (Week~4b): when $\alpha \approx 0$, the Nesterov lookahead step $\tilde{x}_k = x_k + \beta_k z_k$ approximates where the next iterate will be. By evaluating $\nabla f$ at this predicted point, Nesterov effectively corrects the descent direction \emph{before} overshooting, unlike Heavy Ball which computes the gradient at the current (soon-to-be-vacated) point. This ``look before you leap'' strategy underlies Nesterov's superior theoretical convergence rate.

Adam~(Kingma \& Ba, 2015) combines first-moment momentum (as in Heavy Ball) with per-coordinate second-moment scaling (as in RMSprop), additionally applying bias correction to avoid initialisation artefacts. Adam's update can be written as:
\[
  x_{t+1} = x_t - \alpha \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \varepsilon}
\]
where $\hat{m}_t = m_t/(1-\beta_1^t)$ and $\hat{v}_t = v_t/(1-\beta_2^t)$ are bias-corrected first and second moment estimates. When $\hat{v}_t$ is large in a coordinate (high recent gradient magnitude), the effective step in that coordinate is small; when $\hat{v}_t$ is small, the effective step approaches $\alpha$.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Schedule: $\beta_k \to (k-1)/(k+2) \to 1$ as $k\to\infty$}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Velocity update at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (momentum direction)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (adaptive scale)}
    \State $\hat{m}_t \gets m_t / (1 - \beta_1^t)$, \quad $\hat{v}_t \gets v_t / (1 - \beta_2^t)$ \Comment{Bias correction}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{align}
  g(x) &\approx g(x_0) + g'(x_0)(x - x_0) \nonumber \\
       &= (0.25)^4 + 4(0.25)^3(x - 0.25) \nonumber \\
       &= 0.00391 + 0.0625\,(x - 0.25).
  \label{eq:first_order}
\end{align}

\textbf{Second-order (quadratic) approximation:}
\begin{align}
  g(x) &\approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 \nonumber \\
       &= 0.00391 + 0.0625\,(x - 0.25) + \tfrac{1}{2}(12 \cdot 0.25^2)(x - 0.25)^2 \nonumber \\
       &= 0.00391 + 0.0625\,(x - 0.25) + 0.375\,(x - 0.25)^2.
  \label{eq:second_order}
\end{align}

Minimising~\eqref{eq:second_order} with respect to $x$ yields $\hat{x} = x_0 - g'(x_0)/g''(x_0)$, the \textbf{Newton update} for 1D:
\begin{equation}
  x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)}.
  \label{eq:newton_1d}
\end{equation}
For $g(x) = x^4$ at $x_0 = 0.25$: $x_1 = 0.25 - 4(0.25)^3 / (12(0.25)^2) = 0.25 - 0.25/3 \approx 0.167$. Continuing, $|x_k|$ decreases super-linearly towards 0, reflecting the quadratic convergence of Newton's method.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}
\caption{Q3: Local approximations of $g(x) = x^4$ at $x_0 = 0.25$. The first-order approximation (tangent line, blue dashed) captures the local slope but deviates rapidly from the true function and has no minimum — a gradient descent step along this line would proceed indefinitely. The second-order approximation (red dot-dash parabola) captures local curvature and forms a proper bowl with minimum at $\hat{x} = x_0 - g'/g'' \approx 0.167$. Newton's method steps directly to this minimum, combining curvature information to make a more informed update than gradient descent. The key insight is that for a quadratic function, Newton's method finds the exact minimum in a single step, while gradient descent requires many iterations.}
\label{fig:q3_approx}
\end{figure}

\subsection{Newton's Method}

Extending~\eqref{eq:newton_1d} to multiple dimensions, Newton's method solves the linear system $H_k p_k = \nabla f(x_k)$ for the Newton direction $p_k = H_k^{-1} \nabla f(x_k)$, then steps $x_{k+1} = x_k - \alpha p_k$. With a damping factor $\lambda I$ added to $H_k$ (Tikhonov regularisation), the system becomes $(H_k + \lambda I)p_k = \nabla f(x_k)$, ensuring positive definiteness.

\begin{algorithm}[H]
\caption{Newton's Method with Tikhonov Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Regularised Hessian, $\lambda = 10^{-8}$}
    \State Solve $H_k p_k = g_k$ for $p_k$ \Comment{Newton direction: $p_k \approx H_k^{-1} g_k$}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{proposition}[Local Quadratic Convergence]
Near a local minimiser $x^{\star}$ with $\nabla^2 f(x^{\star}) \succ 0$, pure Newton's method ($\alpha = 1$) satisfies
\[
  \|x_{k+1} - x^{\star}\| \leq C \|x_k - x^{\star}\|^2
\]
for some constant $C > 0$, meaning the number of correct decimal digits roughly doubles per iteration.
\end{proposition}

For step sizes $\alpha < 1$ (damped Newton), the local quadratic convergence is preserved but the constant changes. The damping is necessary on Rosenbrock because the Hessian changes rapidly along the trajectory, and full Newton steps ($\alpha = 1$) would overshoot the narrow valley.

\begin{remark}[Newton, Adagrad, and Descent Directions]
As noted in the course (Week~6a), both Newton's method and Adagrad modify the gradient descent direction using second-order information: Newton replaces $\nabla f$ with $H^{-1}\nabla f$ (full inverse Hessian, requiring $O(d^3)$ work), while Adagrad approximates the inverse Hessian with a diagonal matrix $\mathrm{diag}(\sqrt{G})^{-1}$ (only $O(d)$ work). Newton is exact but expensive; Adagrad is a cheap diagonal approximation. This hierarchy — exact Newton $\succ$ quasi-Newton (BFGS) $\succ$ Adagrad diagonal $\succ$ GD (identity) — represents the fundamental trade-off between curvature information and computational cost.
\end{remark}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite-Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
  \label{eq:fd}
\end{equation}
The total error in~\eqref{eq:fd} is the sum of two competing terms:
\begin{equation}
  \mathrm{error}(\delta) \approx \underbrace{\frac{|f''(x)|}{2}\, \delta}_{\text{truncation: } O(\delta)} + \underbrace{\frac{2\varepsilon_{\mathrm{mach}}\, |f(x)|}{\delta}}_{\text{round-off: } O(\varepsilon_{\mathrm{mach}}/\delta)}.
\end{equation}
Minimising over $\delta$ gives $\delta^{\star} = 2\sqrt{\varepsilon_{\mathrm{mach}}\, |f|/|f''|} \approx \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}$ for double precision. The assignment tests two non-optimal values: $\delta = 0.05$ (truncation error $\sim 0.05$, moderate) and $\delta = 0.8$ (truncation error $\sim 0.8$, severe). Note that $d + 1 = 3$ function evaluations are required per gradient estimate in $\mathbb{R}^2$, making the per-iteration cost comparable to exact gradient computation when $d$ is small.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Randomised directional derivative}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Nesterov random search estimates a single directional derivative $\langle \nabla f(x_k), u_k \rangle$ along a random unit vector $u_k$. Since $\mathbb{E}[(\langle\nabla f, u\rangle) u] = \frac{1}{d}\nabla f$ for uniformly random $u$, the method is an unbiased gradient estimator (up to $O(\delta)$ bias), scaled by $1/d$. The key advantage is that only \textbf{two function evaluations} are needed per iteration regardless of dimension $d$, making it dimension-free in per-iteration cost. The convergence rate is $O(d/k)$ for smooth convex objectives—a factor $d$ worse than gradient descent.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four geometric operations: \textbf{reflection} ($\alpha_r = 1.0$, moving the worst vertex through the centroid of the remaining vertices), \textbf{expansion} ($\gamma = 2.0$, extending the reflection if it improves upon all vertices), \textbf{outside contraction} ($\rho = 0.5$, contracting between centroid and reflected point), and \textbf{inside contraction} or \textbf{shrink} ($\sigma = 0.5$, contracting all vertices towards the best). No gradient information is used. Initial simplex step: 0.35.

\subsection{Problem Setup}

The task is to minimise Benchmark~B, $f(x_1, x_2) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1)$, subject to the constraint $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$. The constraint $x_1 \geq 0.5$ defines a half-plane; since the unconstrained minimiser $x^{\star} \approx (0.582, 2.0)$ satisfies $x_1^{\star} \approx 0.582 > 0.5$, the constraint is inactive at the true constrained optimum — the constrained and unconstrained optima coincide, meaning any method that enforces feasibility should converge to the same solution.

\subsection{Projected Gradient Descent}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{C}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{C}}(z)$ \Comment{Project: $x_1 \gets \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection onto $\{x : x_1 \geq 0.5\}$ is simply $\Pi_{\mathcal{C}}(z)_1 = \max(0.5, z_1)$, $\Pi_{\mathcal{C}}(z)_2 = z_2$. This is a closed-form $O(1)$ operation. Projected GD is equivalent to running unconstrained GD and clipping the $x_1$ component at each step. Since the constraint is inactive at the optimum, once the iterate enters the feasible region it behaves identically to unconstrained GD.

\subsection{Penalty Method}

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, -x_1 + 0.5)$ \Comment{Penalised objective}
    \State Compute gradient: $\nabla_1 F_\lambda = \nabla_1 f - \lambda \cdot \mathbf{1}[x_1 < 0.5]$, $\nabla_2 F_\lambda = \nabla_2 f$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty term $\lambda \max(0, -x_1 + 0.5)$ adds a linear ``slope'' towards the feasible region when $x_1 < 0.5$. As $\lambda \to \infty$, the penalised minimiser $\to$ the true constrained minimiser. The penalty gradient is discontinuous at $x_1 = 0.5$ (kink), which can cause oscillation if the trajectory crosses the constraint boundary repeatedly. Larger $\lambda$ pushes more aggressively towards feasibility but also stiffens the gradient landscape, requiring a smaller step size for numerical stability.

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), Unconstrained GD ($\alpha = 0.07$). All: 100 iterations.

\section{Question 6: Linear Programmes and Frank--Wolfe Algorithm \hfill [30 marks]}
\label{sec:q6}
% ============================================================

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$ — a bounded, closed, convex polytope with four vertices.

\textbf{Linear Programme:} minimise $f(x) = a^T x$, $a = [1, 2]^T$, over $\mathcal{X}$.

Since $f$ is linear and $\mathcal{X}$ is a compact convex polytope, the \emph{Fundamental Theorem of Linear Programming} guarantees that the optimum is attained at a vertex of $\mathcal{X}$. The four vertices are $(0.5, -5)$, $(5, -5)$, $(0.5, 10)$, and $(5, 10)$. Evaluating $f$ at each:
\begin{align*}
  f(0.5, -5) &= 0.5 - 10 = -9.5, \quad &f(5, -5) &= 5 - 10 = -5, \\
  f(0.5, 10) &= 0.5 + 20 = 20.5, \quad &f(5, 10) &= 5 + 20 = 25.
\end{align*}
The minimum is $f^{\star} = -9.5$ at $x^{\star} = (0.5, -5)$. Alternatively, since both components of $a$ are positive, each coordinate independently achieves its minimum at its lower bound.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q6_lp.pdf}
\caption{Q6-I: Feasible region (blue box) and contours of the linear objective $f(x) = x_1 + 2x_2$. The contour lines are parallel (as required for a linear objective), and the minimum is attained at the lower-left corner $(0.5, -5)$, where $f^{\star} = -9.5$. This confirms the Fundamental Theorem: the optimum of a linear objective over a convex polytope is at a vertex. For the Frank--Wolfe linear minimisation oracle, this vertex-seeking property is exploited at each iteration.}
\label{fig:q6_lp}
\end{figure}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination, $x_{k+1} \in \mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

The key advantage of Frank--Wolfe is that \textbf{iterates remain in $\mathcal{X}$ automatically}: since $x_k, z_k \in \mathcal{X}$ and $\mathcal{X}$ is convex, $\beta x_k + (1-\beta)z_k \in \mathcal{X}$ for $\beta \in [0,1]$. No projection oracle is needed — the LMO for a box constraint decomposes per coordinate:
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
requiring $O(d)$ work. For smooth convex objectives over compact sets, the \emph{Frank--Wolfe duality gap}:
\begin{equation}
  g_k = \nabla f(x_k)^T(x_k - z_k) \geq 0
  \label{eq:fw_gap}
\end{equation}
is a computable upper bound on $f(x_k) - f^{\star}$ (via the first-order condition $f(z) \geq f(x_k) + \nabla f(x_k)^T(z - x_k)$ for convex $f$). When $g_k = 0$, the iterate $x_k$ is a first-order optimal point. The convergence rate is $g_k \leq O(LD^2/k)$ where $L$ is the Lipschitz constant of $\nabla f$ and $D = \max_{x,y \in \mathcal{X}}\|x - y\|$ is the diameter of $\mathcal{X}$. The course (Week~10a) motivates Frank--Wolfe as arising from the observation that the minimum of a linear function over a polytope always lies at a vertex — so the LP subproblem can be solved by inspection for box constraints.

\subsection{Interior Optimum: $f(x) = (x_1-1)^2 + (x_2-5)^2$}

The unconstrained minimiser $(1, 5) \in \mathcal{X}$ (since $0.5 \leq 1 \leq 5$ and $-5 \leq 5 \leq 10$). Tested with $\beta \in \{0.90, 0.985\}$ from $x_0 = (1,1)$, 180 iterations.

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum:} Frank--Wolfe exhibits a characteristic ``zig-zag'' pattern (visible in Figure~\ref{fig:q6_fw_contour}): the LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$ at each iteration, and the convex combination gradually averages them towards the interior minimiser. The convergence rate is $O(1/k)$ for smooth convex objectives. Smaller values of $(1-\beta)$ (i.e., larger $\beta$) lead to smoother but slower convergence initially, yet better final accuracy due to reduced oscillation.

\textbf{Boundary optimum:} Frank--Wolfe is particularly well-suited to boundary optima. Since the LMO always selects vertices that minimise the linear approximation, and the constrained optimum lies near the boundary, the LP consistently selects vertices in the correct boundary region. The iterate converges towards the boundary without explicit projection. The residual gap ($f = 0.364$ vs $f^{\star} = 0.25$ at iteration 140) is due to the fixed $\beta$ not decaying—using the standard $\gamma_k = 2/(k+2)$ line-search schedule would achieve $O(1/k)$ convergence to $f^{\star}$.

A fundamental limitation of Frank--Wolfe compared to projected gradient descent is its $O(1/k)$ rate (vs $O(L\|x_0-x^{\star}\|^2/(2k))$ for projected GD), but its projection-free nature and vertex-sparsity of iterates make it preferred for structured feasible sets (e.g., nuclear norm ball, flow polytopes) where projection is expensive.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This study provides a systematic empirical and theoretical comparison of 12 optimisation methods across three qualitatively different benchmark functions.

\textbf{Adaptive step-size methods (Q1):} The Polyak step achieves the fastest convergence when $f^{\star}$ is exactly known (Rosenbrock: $f = 0.024$ in 120 iterations, vs GD's $f = 3.51$) but fails when $f^{\star}$ is misspecified — diverging on Benchmark~A ($f = 4.77$) and failing to reach the minimum on Benchmark~B ($f = 0.982$ vs $f^{\star} = 0.724$). Benchmark~A has $\kappa \approx 1.12$ (nearly isotropic), making it easy for all methods; Benchmark~C with $\kappa \approx 2508$ is the key discriminator. Among non-Polyak methods, Heavy Ball (momentum) is the best choice on ill-conditioned problems.

\textbf{Momentum and stochastic methods (Q2):} Nesterov acceleration is the standout performer on Rosenbrock ($f = 0.479$ vs GD's $3.388$ in 150 iterations), confirming the theoretical $O(1/k^2)$ improvement over GD's $O(1/k)$ on smooth convex objectives. Adam offers a practical combination of momentum and adaptive scaling but does not match Nesterov on severely ill-conditioned problems. For mini-batch SGD, smaller batch sizes converge faster per epoch but with higher variance; high data noise obscures the batch-size effect by raising the irreducible loss floor.

\textbf{Newton's method (Q3):} Newton's method demonstrates the power of second-order information: it converges in a single step on the quadratic benchmark (Benchmark~A) and in $\sim$5 steps on the near-quadratic Benchmark~B. The necessary heavy damping ($\alpha = 0.22$) on the Rosenbrock function limits its per-step progress, but it still reaches $f = 0.686$ in 20 iterations vs GD's $3.73$ in 80 iterations.

\textbf{Derivative-free methods (Q4):} Finite-difference GD with $\delta = 0.05$ reaches $f = 0.728$ on Benchmark~B vs exact GD's $f = 0.724$ — less than 1\% accuracy loss. Poor $\delta = 0.8$ reaches only $f = 1.640$, confirming that truncation error dominates at large stencil. Nelder--Mead achieves the remarkable result of locating the Rosenbrock minimum exactly ($f \approx 0$, $x \approx (1,1)$) in 160 iterations without any gradient information. Grid search finds $f = 0.00156$ at $(1.037, 1.074)$ — within $\|x-x^{\star}\|_2 \approx 0.083$ of the true minimum.

\textbf{Constrained optimisation (Q5):} Projected gradient descent immediately enforces feasibility as a hard constraint and is the recommended method when a cheap projection exists. Penalty methods provide a simpler but softer alternative: sufficiently large $\lambda$ achieves feasibility but requires reduced step sizes. The penalty weight must be tuned carefully to balance constraint satisfaction against convergence speed.

\textbf{Frank--Wolfe (Q6):} Frank--Wolfe naturally respects constraints via projection-free convex combinations, achieving $O(1/k)$ convergence. It is better suited to boundary optima (where the LP vertex closely approximates the constrained minimiser) and to structured constraint sets where projection is expensive but LP subproblems are tractable.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):

        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):

    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]

        z = beta * z + alpha * g
        x = x - z

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
