\begin{abstract}
This report presents a comprehensive comparative study of 14 first-order, second-order, and derivative-free optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss with condition number $\kappa \approx 1.12$ (Benchmark~A), a toy neural network loss with position-varying condition number $\kappa \in [3.5, 6.9]$ (Benchmark~B), and the Rosenbrock function with $\kappa \approx 2508$ (Benchmark~C). Six families of methods are investigated: (1)~adaptive step-size methods including Polyak, Adagrad, RMSprop, and Heavy Ball; (2)~momentum-based acceleration via Nesterov's $O(1/k^2)$ method and Adam; (3)~Newton's method with Tikhonov-regularised Hessian; (4)~derivative-free approaches including finite differences, Nesterov random search, Nelder--Mead, and grid search; (5)~constrained optimisation via projected gradient descent and penalty methods with KKT analysis; and (6)~the Frank--Wolfe conditional gradient algorithm. Each method is implemented from scratch in Python and evaluated on convergence speed, trajectory behaviour, and computational complexity. Key findings: the Polyak step diverges when $f^{\star}$ is misspecified ($f = 24.07$ vs.\ true $0.72$ on Benchmark~B); Nesterov achieves $f = 0.479$ on Rosenbrock (best first-order result); Newton converges in one step on the quadratic; and Nelder--Mead achieves $f = 0.27$ on Rosenbrock without gradients, outperforming GD's $f = 3.73$.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation lies at the heart of modern machine learning and data analysis. The choice of algorithm and its hyperparameters profoundly affects both convergence speed and solution quality. This report investigates a broad spectrum of optimisation methods from the CS7DS2 curriculum, providing both theoretical analysis and empirical evidence across three benchmark functions of increasing difficulty.

The three benchmarks cover representative problem classes: Benchmark~A is a smooth, strongly convex quadratic (linear regression) with condition number $\kappa \approx 1.12$, ideal for illustrating convergence rates and the irreducible noise floor; Benchmark~B introduces mild non-convexity through a sinusoidal perturbation with position-varying condition number $\kappa \in [3.5, 6.9]$; and Benchmark~C (Rosenbrock) is the canonical ill-conditioned, non-convex benchmark with a narrow curved valley whose condition number $\kappa \approx 2508$ represents the most demanding test case.

\textbf{Notation.} We use $f : \mathbb{R}^d \to \mathbb{R}$ for the objective function, $\nabla f$ for the gradient, $\nabla^2 f$ for the Hessian, $x^{\star}$ for the minimiser, and $f^{\star} = f(x^{\star})$ for the optimal value. The symbol $\odot$ denotes elementwise (Hadamard) multiplication. We write $\kappa = L/\mu$ for the condition number of the Hessian, where $L$ and $\mu$ are the Lipschitz constant and strong convexity parameter respectively. The superscript $(i)$ denotes the $i$-th coordinate of a vector.

All algorithms are implemented in Python using only \texttt{NumPy}, with a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. The complete source code is provided in \texttt{CS7DS2\_Final\_Code\_25336453.py}; key implementations are reproduced in Appendix~\ref{app:code}.

\textbf{Organisation.} The report proceeds through six method families in increasing sophistication:

\begin{enumerate}[nosep,label=\textbf{Q\arabic*.}]
\item \textbf{Adaptive step sizes} (Polyak, Adagrad, RMSprop, Heavy Ball): replace the fixed learning rate with data-driven estimates of the local curvature scale.
\item \textbf{Momentum and stochastic methods} (Nesterov, Adam, mini-batch SGD): exploit gradient history to achieve acceleration ($O(1/k^2)$ vs.\ $O(1/k)$) and handle stochastic oracles.
\item \textbf{Newton's method}: use explicit Hessian information to achieve quadratic (superlinear) local convergence; bridges to second-order quasi-Newton methods.
\item \textbf{Derivative-free methods} (finite differences, Nesterov random search, Nelder--Mead, grid search): operate with only function values, trading gradient efficiency for applicability to black-box objectives.
\item \textbf{Constrained optimisation} (projected GD, penalty methods): enforce feasibility constraints via hard projection or soft penalties; analysis through KKT conditions and complementary slackness.
\item \textbf{Linear programmes and Frank--Wolfe}: the conditional gradient algorithm connects LP theory (vertex optimality, LMO oracle) to constrained smooth optimisation, yielding projection-free methods with sparse iterate structure.
\end{enumerate}

Each section follows the structure: (1) algorithm formulation with theoretical guarantees, (2) hyperparameter choices and stability analysis, (3) empirical convergence results with figures, and (4) discussion connecting theory to observed behaviour.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = {\theta^{\star}}^T x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The mean squared error loss is:
\begin{equation}
J(\theta) = \frac{1}{2m} \|X\theta - y\|^2 = \frac{1}{2m}\sum_{i=1}^{m}\!\left({\theta}^T x^{(i)} - y^{(i)}\right)^2,
\end{equation}
with gradient $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$ and constant Hessian $H_A = \frac{1}{m}X^T X$.

\textbf{Spectral properties.} The eigenvalues of $H_A$ are $\mu = 0.9247$ and $L = 1.0325$, giving condition number $\kappa(H_A) = L/\mu \approx 1.117$. This near-unity condition number makes Benchmark~A an ideal testbed for first-order methods: the landscape is isotropic and any gradient direction is nearly optimal. Starting point: $\theta_0 = [0,\, 0]^T$. Due to observation noise $\varepsilon^{(i)} \sim \mathcal{N}(0,1)$, the OLS minimiser is $\hat{\theta} = [3.028,\, 4.017]^T$ (not exactly $\theta^{\star}$), and the noise floor is $J^{\star} \approx 0.4826$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
\label{eq:loss_B}
f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are:
\begin{align}
\nabla f(x) &= \bigl[2(x_1 - 1) + \cos(x_1),\; 10(x_2 - 2)\bigr]^T, \\
H_B(x) &= \operatorname{diag}\!\bigl(2 - \sin(x_1),\; 10\bigr).
\end{align}
The sinusoidal term introduces position-dependent curvature in the $x_1$ direction. At the starting point $x_0 = [-1,\, 4]^T$: $H_B = \operatorname{diag}(2.841,\, 10)$, condition number $\kappa \approx 3.52$. At the minimum $x^{\star} \approx (0.5824,\, 2.0)$: $H_B = \operatorname{diag}(1.450,\, 10)$, condition number $\kappa \approx 6.90$. The minimum satisfies the stationarity condition $2(x_1^{\star} - 1) + \cos(x_1^{\star}) = 0$ (no closed form), giving $f^{\star} \approx 0.7244$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
\label{eq:loss_C}
f(x) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The gradient and Hessian are:
\begin{align}
\nabla f(x) &= \bigl[-2(1 - x_1) - 400x_1(x_2 - x_1^2),\; 200(x_2 - x_1^2)\bigr]^T, \\
H_C(x) &= \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{align}
The global minimum is at $(1,\, 1)$ with $f^{\star} = 0$. At the optimum, $H_C(1,1) = \bigl[\begin{smallmatrix}802 & -400 \\ -400 & 200\end{smallmatrix}\bigr]$ has eigenvalues $\approx 0.399$ and $1001.6$, giving condition number $\kappa \approx 2508$. This extreme ill-conditioning, combined with the narrow curved valley along $x_2 = x_1^2$, makes the Rosenbrock function a severe test of curvature exploitation. Starting point: $x_0 = [-1,\, 1]^T$.

\subsection{Algorithm Formulations}
\label{subsec:q1_algs}

Four adaptive methods are compared against constant step-size GD across all benchmarks for 120 iterations. The GD update is $x_{k+1} = x_k - \alpha \nabla f(x_k)$. For an $L$-smooth, $\mu$-strongly convex function with $\alpha \leq 1/L$, GD converges at rate $\|x_k - x^{\star}\|^2 \leq (1 - \mu\alpha)^k \|x_0 - x^{\star}\|^2$, yielding the linear convergence factor $\rho = 1 - \mu/L = 1 - 1/\kappa$. The largest stable step size is $\alpha_{\max} = 2/(L + \mu)$ (optimal for linear convergence), and the tightest bound gives rate $\rho_{\min} = (\kappa - 1)/(\kappa + 1)$.

\begin{corollary}[Expected Reduction in 120 Iterations]
\label{cor:gd_120iters}
With optimal step $\alpha^{\star} = 2/(L + \mu)$, after $k = 120$ iterations GD reduces the initial error by a factor $\rho_{\min}^{120}$:
\[
\text{Bench.\ A}\,(\kappa = 1.117):\; \rho_A^{120} \approx (0.054)^{120} \approx 10^{-152} \quad (\text{converged to machine precision}),
\]
\[
\text{Bench.\ C}\,(\kappa = 2508):\; \rho_C^{120} \approx (0.9992)^{120} \approx 0.909 \quad (\text{only 9.1\% reduction}).
\]
This $10^{151}$-fold difference in error reduction explains the observed $\approx 1000$-fold gap in final function values between Benchmarks~A and C for gradient-based methods.
\end{corollary}

For the benchmarks: $\rho_A \approx 0.054$ ($\kappa = 1.117$), and for Rosenbrock $\rho_C \approx 0.9992$ ($\kappa \approx 2508$), explaining why GD barely progresses on Benchmark~C in 120 iterations. The corollary above quantifies this gap precisely: GD on Benchmark~A converges to machine precision while Benchmark~C loses only 9\% of its initial error.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value estimate $f^{\star}$, regulariser $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Adaptive step}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Polyak Step Convergence]
\label{thm:polyak}
For a convex function $f$ with unique minimiser $x^{\star}$ and $f^{\star} = f(x^{\star})$ known exactly, the Polyak step satisfies:
\[
\|x_{k+1} - x^{\star}\|^2 \leq \|x_k - x^{\star}\|^2 - \frac{(f(x_k) - f^{\star})^2}{\|g_k\|^2},
\]
guaranteeing monotone decrease in distance to $x^{\star}$. When $f^{\star}$ is misspecified (set too small), $\alpha_k = (f(x_k) - f^{\star}_{\text{spec}}) / (\|g_k\|^2 + \varepsilon) \to \infty$ as $\|g_k\| \to 0$ while $f(x_k) - f^{\star}_{\text{spec}} \to f^{\star}_{\text{true}} - f^{\star}_{\text{spec}} > 0$, causing divergence.
\end{theorem}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base rate $\alpha_0$, regulariser $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate squared gradient accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$ \Comment{Per-coordinate adaptive rate}
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's effective per-coordinate rate is $\alpha_k^{(i)} = \alpha_0 / (\sqrt{\sum_{j=0}^{k} g_j^{(i)2}} + \varepsilon)$, which decays monotonically. This can be interpreted as preconditioning by the diagonal of the accumulated Gram matrix $\sum_{j} g_j g_j^T$: coordinates with historically large gradient magnitudes receive smaller steps, mirroring the inverse Hessian scaling that Newton's method would apply. The preconditioner $\operatorname{diag}(\sqrt{G_k})$ is a computationally cheap approximation to $H^{-1/2}$.

\textbf{Online learning interpretation.} Adagrad was originally derived in the \emph{online learning} / regret minimisation framework. For a sequence of loss functions $f_1, f_2, \ldots, f_T$, Adagrad achieves regret bound $R_T \leq \frac{\|x_1 - x^{\star}\|_2^2}{2\alpha_0} + \alpha_0 \sum_{i=1}^d \sqrt{\sum_{t=1}^T g_t^{(i)2}}$. The second term is minimised per-coordinate by the adaptive denominator: coordinates with small total gradient have large effective steps, coordinates with large total gradient have small steps. For dense, non-sparse gradients (as in our fully observed benchmarks), all $\sum g_t^{(i)2}$ grow at $O(T)$, so the regret scales as $O(\sqrt{T})$ --- corresponding to an $O(1/\sqrt{T})$ average excess loss. Adagrad is well-suited for sparse gradients (where many coordinates are rarely updated) but can prematurely stall on dense problems due to the monotonic denominator growth.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, regulariser $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $\|g\|^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop addresses Adagrad's monotonic decay by replacing the full accumulation with an exponential moving average controlled by $\beta$. This allows the effective step size to recover if the gradient magnitudes decrease, making it suitable for non-stationary objectives. The parameter $\beta$ controls the effective window: $1/(1-\beta)$ steps contribute significantly, so $\beta = 0.9$ gives an effective window of $\approx 10$ recent steps. For $\beta = 0.9$, the effective step size at iteration $k$ is approximately $\alpha_0 / \sqrt{\bar{v}_k}$ where $\bar{v}_k \approx \mathbb{E}[g_k^2]$ is the recent gradient second moment.

\begin{algorithm}[H]
\caption{Polyak Momentum (Heavy Ball)}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Accumulated momentum}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

This is equivalent to $x_{k+1} = x_k - \alpha\,\nabla f(x_k) + \beta(x_k - x_{k-1})$: a gradient step augmented by a fraction of the previous displacement. For quadratics, the optimal parameters $\alpha^{\star} = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}$ and $\beta^{\star} = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2$ yield linear convergence at rate $\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}$, the same asymptotic rate as Nesterov.

\textbf{Key finding:} The Polyak step is optimal when $f^{\star}$ is known exactly (Rosenbrock), but catastrophically unstable otherwise. In practice, exact $f^{\star}$ is rarely available, limiting its direct applicability. Adagrad provides a robust, parameter-light alternative for well-conditioned problems; Heavy Ball offers the best balance on ill-conditioned problems when $f^{\star}$ is unknown.

\textbf{Connection to Polyak--{\L}ojasiewicz (PL) inequality.} GD achieves linear convergence under a weaker condition than strong convexity: the \emph{PL inequality} $\tfrac{1}{2}\|\nabla f(x)\|^2 \geq \mu\bigl(f(x) - f^{\star}\bigr)$ for all $x$. Under PL, GD with $\alpha \leq 1/L$ satisfies $f(x_k) - f^{\star} \leq (1 - 2\mu\alpha)^k\bigl(f(x_0) - f^{\star}\bigr)$, recovering the standard linear rate even on non-convex functions. Benchmark~A (quadratic) satisfies PL globally with $\mu = 0.925$; Benchmark~B satisfies it in a neighbourhood of $x^{\star}$ since the Hessian is positive definite there. This explains why all gradient methods converge linearly on Benchmarks~A and B despite the sinusoidal non-linearity in B. Benchmark~C (Rosenbrock) \emph{does not} satisfy PL globally due to its long, flat valley, where $\|\nabla f\| \approx 0$ but $f \gg 0$ --- this is precisely why gradient-only methods struggle there.

\begin{theorem}[Linear Convergence under PL Inequality]
\label{thm:pl}
Suppose $f$ satisfies the Polyak--\L{}ojasiewicz (PL) inequality with constant $\mu > 0$:
\[
\tfrac{1}{2}\|\nabla f(x)\|^2 \geq \mu\bigl(f(x) - f^{\star}\bigr) \quad \forall\, x.
\]
Then gradient descent with step $\alpha \leq 1/L$ achieves:
\[
f(x_k) - f^{\star} \leq (1 - 2\mu\alpha)^k \bigl(f(x_0) - f^{\star}\bigr).
\]
The PL condition is strictly weaker than strong convexity: every $\mu$-strongly convex function satisfies PL with the same $\mu$, but not conversely (functions with non-unique minimisers or non-convex geometries can still satisfy PL). The key implication is that all stationary points are global minima, enabling the same linear convergence rate as on strongly convex objectives.
\end{theorem}

\subsection{Comparative Analysis and Discussion}

\begin{itemize}[nosep]
\item \textbf{Polyak:} Theoretically optimal when $f^{\star}$ is known exactly. Its step $\alpha_k = (f(x_k) - f^{\star}) / \|\nabla f\|^2$ is a normalised residual that automatically scales to the remaining function value. On Benchmark~C it achieves $f = 0.0094$ in 120 iterations --- better than Nesterov at 150 iterations --- but requires the oracle $f^{\star}$.

\item \textbf{Adagrad:} Uniformly stable due to its monotonically decreasing effective rate. The accumulated denominator $\sum_j g_j^{(i)2}$ acts as a per-coordinate curvature estimate, giving large steps on flat directions and small steps on steep ones. This implicitly compensates for the anisotropic Hessian of Benchmark~C ($\kappa \approx 2508$), explaining why Adagrad ($f = 2.20$) outperforms plain GD ($f = 3.51$). The limitation: on dense problems, all denominators grow monotonically, causing the effective rate to decay to zero even in directions where more progress is possible.

\item \textbf{RMSprop:} The exponential moving average ($\beta = 0.9$, effective window $\approx 10$ iterations) allows the effective step to adapt to the \emph{recent} curvature rather than the entire history, avoiding Adagrad's premature stalling. However, on Rosenbrock the very small required base rate ($\alpha_0 = 0.0035$) dominates performance, limiting gains over GD.

\item \textbf{Heavy Ball:} Achieves the best GD-family result on Rosenbrock ($f = 1.40$ vs.\ GD's $3.51$). The momentum vector $z_k = \sum_{j=0}^{k} \beta^{k-j} \alpha g_j$ is an exponentially-weighted sum of past gradients. Along the Rosenbrock valley, gradients consistently point in the same direction, allowing $z_k$ to accumulate and produce larger effective steps. The optimal Heavy Ball parameters for a quadratic are $\beta^{\star} = ((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1))^2$; with $\kappa \approx 2508$ this gives $\beta^{\star} = ((50.08-1)/(50.08+1))^2 \approx 0.923$, consistent with the sensitivity figure (Figure~\ref{fig:q1_hb_sens}). The experiment uses $\beta = 0.86$, somewhat below the theoretical optimum, which improves stability on the non-quadratic Rosenbrock landscape where the Hessian changes rapidly along the valley.

\item \textbf{Stability vs.\ speed:} GD is most stable but slowest on ill-conditioned problems (convergence rate $\rho \approx 1 - 1/\kappa$). Adaptive methods trade some stability for speed by introducing hyperparameters. Polyak is the extreme case --- maximum speed when $f^{\star}$ is exact, catastrophic failure otherwise. Adagrad and Heavy Ball represent robust intermediate choices.
\end{itemize}

\subsection{Algorithm Formulations}
\label{subsec:q2_algs}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_1$, step size $\alpha$, maximum momentum $\beta_{\max}$, iterations $N$
\State $z_1 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\; \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Momentum update at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$. This ``correct-before-overshoot'' mechanism allows the gradient to predict the direction of future iterates, suppressing oscillation. The adaptive schedule $\beta_k = (k-1)/(k+2)$ is capped at $\beta_{\max}$ to prevent instability on non-convex functions.

\textbf{Intuition for the $O(1/k^2)$ rate.} The standard GD analysis yields $f(x_k) - f^{\star} \leq \frac{L\|x_0 - x^{\star}\|^2}{2k}$ for convex objectives, i.e.\ $O(1/k)$. The key insight is that GD with step $\alpha = 1/L$ satisfies the recursive bound $f(x_{k+1}) - f^{\star} \leq f(x_k) - f^{\star} - \frac{1}{2L}\|\nabla f(x_k)\|^2$, and summing over iterations wastes information about how close $x_k$ is to $x^{\star}$. Nesterov's method uses an \emph{estimate sequence} $\{\phi_k\}$: a sequence of simple functions satisfying (1) $\phi_k(x^{\star}) \leq f^{\star} + \delta_k$ for some $\delta_k \to 0$, and (2) $f(x_k) \leq \phi_k^{\star}$ (minimum of $\phi_k$). By maintaining these two properties simultaneously, the $O(1/k^2)$ rate follows because the quadratic lower bound on $f$ tightens at rate $O(1/k^2)$. The schedule $\beta_k = (k-1)/(k+2)$ is derived from the condition that the estimate sequence remains valid, and $\alpha \leq 1/L$ ensures sufficient decrease of the actual iterate.

\begin{theorem}[Nesterov Convergence Rate]
\label{thm:nesterov}
For a convex, $L$-smooth function $f$, Nesterov accelerated gradient with step $\alpha = 1/L$ and the schedule $\beta_k = (k-1)/(k+2)$ achieves:
\[
f(x_k) - f(x^{\star}) \leq \frac{2L\|x_1 - x^{\star}\|^2}{(k+1)^2} = O(1/k^2),
\]
which is optimal among first-order methods (matching the Nemirovski--Yudin lower bound on gradient oracle complexity for convex smooth functions). This is a quadratic speedup over GD's $O(L\|x_0-x^{\star}\|^2/k)$ rate. For strongly convex functions, Nesterov achieves the faster linear rate $O(\exp(-k\sqrt{\mu/L}))$, vs.\ GD's $O(\exp(-k\mu/L))$ --- a square-root improvement in the exponent. The Nemirovski--Yudin oracle complexity lower bound states that \emph{no} first-order method can achieve better than $\Omega(\exp(-k/\sqrt{\kappa}))$ on smooth strongly convex objectives using only gradient information; Nesterov's method matches this bound and is therefore \emph{optimal} in the oracle complexity sense.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_1$, learning rate $\alpha$, decay rates $\beta_1, \beta_2 \in (0,1)$, regulariser $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\; v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (uncentred variance)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias-corrected mean}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$ \Comment{Bias-corrected variance}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines first-moment (momentum) and second-moment (adaptive scaling) estimation. It can be viewed as RMSprop augmented with a momentum term: removing the bias correction and $m_t$ recovers RMSprop; removing $v_t$ recovers heavy-ball momentum. The bias correction $(1 - \beta_j^t)^{-1}$ is essential in early iterations: without it, $m_t$ and $v_t$ are biased towards zero because they are initialised at zero, producing artificially small effective numerators and denominators with an imbalance in early steps. As $t$ increases, the corrections converge to one and have negligible effect.

\begin{remark}
The effective per-coordinate step at iteration $t$ is $\alpha\,|\hat{m}_t^{(i)}|/(\sqrt{\hat{v}_t^{(i)}} + \varepsilon)$. Since $|\hat{m}_t^{(i)}| \leq \sqrt{\hat{v}_t^{(i)}}$ (by the Cauchy--Schwarz inequality in expectation), the effective step size is bounded by $\alpha / \varepsilon$. This provides implicit step-size normalisation, explaining Adam's robustness to learning rate scaling.
\end{remark}

\subsection{Why Nesterov Outperforms Adam on Rosenbrock}

\textbf{Adam's implicit Hessian approximation.} Adam's per-coordinate step $\alpha \hat{m}_t^{(i)} / (\sqrt{\hat{v}_t^{(i)}} + \varepsilon)$ can be interpreted as Newton's method with a diagonal Hessian approximation: $H_t^{-1} \approx \operatorname{diag}(1/\sqrt{\hat{v}_t})$. The second moment $\hat{v}_t^{(i)} \approx \mathbb{E}[g_t^{(i)2}]$ estimates the variance (and squared mean) of the gradient in direction $i$; $1/\sqrt{\mathbb{E}[g^{(i)2}]}$ is an approximation to $1/\sqrt{H_{ii}}$ (the inverse square root of the diagonal of the Hessian). This provides a \emph{diagonal preconditioner} that approximately compensates for heterogeneous curvature. For Benchmarks~A and B where the Hessian is nearly diagonal, this works well. For Rosenbrock, the dominant curvature is in an \emph{off-diagonal} direction (along the valley), so the diagonal approximation misses the key structure.

The performance gap between Nesterov ($f = 0.479$) and Adam ($f = 1.579$) on Benchmark~C merits theoretical explanation. Rosenbrock's primary challenge is the narrow, curved valley: progress requires large steps \emph{along} the valley floor direction and very small steps perpendicular to it. Nesterov handles this through accumulated momentum: once the momentum vector $z_k$ aligns with the valley, the gradient computed at the lookahead point $\tilde{x}_k = x_k + \beta_k z_k$ is directed more steeply along the valley, further amplifying the correct direction. Adam, by contrast, normalises each coordinate independently: $x_{t+1} = x_t - \alpha \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$. This normalisation removes the magnitude information from the gradient, preventing the momentum from building up to the large scale needed to traverse the valley efficiently. The per-coordinate scaling is beneficial in isotropic settings (Benchmarks~A and B) but counterproductive on the anisotropic Rosenbrock where the valley direction is \emph{not} aligned with any coordinate axis.

\subsection{Mini-Batch Stochastic Gradient Descent}
\label{subsec:q2_sgd}

Mini-batch SGD on Benchmark~A uses $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, and 50 epochs, with data shuffled at every epoch. One epoch corresponds to one pass through all $m = 1000$ data points, yielding $\lfloor m/b \rfloor$ parameter updates per epoch.

\textbf{Variance analysis.} The mini-batch gradient $g_\mathcal{B} = \frac{1}{b}\sum_{j \in \mathcal{B}} \nabla f_j(\theta)$ is an unbiased estimator of $\nabla J(\theta)$. Its variance per coordinate satisfies:
\begin{equation}
\mathrm{Var}\!\left[g_\mathcal{B}^{(i)}\right] = \frac{\sigma_i^2}{b}, \qquad \sigma_i^2 = \frac{1}{m}\sum_{j=1}^m \!\left[\nabla_i f_j(\theta) - \nabla_i J(\theta)\right]^2,
\end{equation}
where $\sigma_i^2$ is the per-sample gradient variance in direction $i$. Doubling the batch size halves the gradient variance. For $\mu$-strongly convex $J$ with Lipschitz constant $L$, the iterate satisfies:
\begin{equation}
\label{eq:sgd_bound}
\mathbb{E}\!\left[\|\theta_k - \theta^{\star}\|^2\right] \leq (1 - 2\mu\alpha)^k \|\theta_0 - \theta^{\star}\|^2 + \frac{\alpha \sigma^2}{2\mu b},
\end{equation}
where $\sigma^2 = \sum_i \sigma_i^2$. The first term decays geometrically; the second is the \emph{irreducible noise floor} $\propto \alpha / b$. Setting $\alpha \propto 1/\sqrt{k}$ (decaying schedule) achieves $O(1/\sqrt{k})$ convergence instead of the constant floor in~\eqref{eq:sgd_bound}. The floor explains why both batch sizes converge to approximately the same neighbourhood of $\theta^{\star}$ rather than to $\theta^{\star}$ itself.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g_{\mathcal{B}} \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$
        \State $\theta \gets \theta - \alpha\, g_{\mathcal{B}}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\textbf{Variance reduction (SVRG/SAG).} The irreducible noise floor $\alpha\sigma^2/(2\mu b)$ in~\eqref{eq:sgd_bound} can be eliminated by \emph{variance reduction} methods. SVRG (Stochastic Variance Reduced Gradient, Johnson \& Zhang 2013) periodically computes the full gradient $\nabla J(\tilde{\theta})$ at a snapshot $\tilde{\theta}$, then uses the corrected estimate:
\[
g_k^{\mathrm{SVRG}} = \nabla f_i(\theta_k) - \nabla f_i(\tilde{\theta}) + \nabla J(\tilde{\theta}),
\]
which has variance $O(\|\theta_k - \tilde{\theta}\|^2)$ --- small when $\theta_k$ is near $\tilde{\theta}$. SVRG achieves \emph{linear convergence} $O(\rho^k)$ at $O(d)$ per iteration (amortised), combining the best of GD (linear rate) and SGD (cheap iterations). This eliminates the noise floor from~\eqref{eq:sgd_bound} at the cost of periodic full-gradient passes.

\subsection{Local Taylor Approximations of $g(x) = x^4$}

The first- and second-order Taylor approximations of $g(x) = x^4$ at $x_0 = 0.25$ are:
\begin{align}
g_1(x) &= g(x_0) + g'(x_0)(x - x_0) \nonumber \\
 &= (0.25)^4 + 4(0.25)^3(x - 0.25) = 3.906 \times 10^{-3} + 0.0625\,(x - 0.25), \\[4pt]
g_2(x) &= g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 \nonumber \\
 &= 3.906 \times 10^{-3} + 0.0625\,(x - 0.25) + \tfrac{1}{2}(0.375)(x - 0.25)^2.
\end{align}
The Newton step minimises $g_2$ by moving to its stationary point:
\begin{equation}
x_{\mathrm{Newton}} = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{4(0.25)^3}{12(0.25)^2} = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\end{equation}
One can verify $g(0.1667) = 0.000772 \ll g(0.25) = 0.00391$, confirming the Newton step produces a large improvement relative to the gradient step.

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Damped Newton's Method}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, damping $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Regularised (positive-definite) Hessian}
    \State Solve $H_k\, p_k = g_k$ for the Newton direction $p_k$ \Comment{$p_k = H_k^{-1} g_k$}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Newton's direction $p_k = H_k^{-1} g_k$ is the minimiser of the local quadratic model $f(x_k) + g_k^T d + \frac{1}{2}d^T H_k d$. The damping $\lambda I$ ensures $H_k + \lambda I \succ 0$ even when the Hessian has small or negative eigenvalues (as occurs in non-convex regions of Rosenbrock). The step size $\alpha < 1$ further globalises convergence.

\begin{theorem}[Newton Quadratic Convergence]
\label{thm:newton}
For a twice-continuously-differentiable function $f$ with $\nabla^2 f(x^{\star}) \succ 0$ and $\alpha = 1$ (full Newton step), if $x_0$ is sufficiently close to $x^{\star}$ and $\nabla^2 f$ is Lipschitz continuous with constant $M$:
\[
\|x_{k+1} - x^{\star}\| \leq \frac{M}{2\sigma_{\min}(\nabla^2 f(x^{\star}))}\,\|x_k - x^{\star}\|^2,
\]
where $\sigma_{\min}$ denotes the smallest eigenvalue. This \emph{quadratic} (superlinear) convergence implies the number of correct decimal digits roughly doubles per iteration: $10^{-1} \to 10^{-2} \to 10^{-4} \to 10^{-8} \to \ldots$ For a quadratic objective, the Hessian is constant ($M = 0$) and Newton converges in a single step.
\end{theorem}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping $\lambda = 10^{-8}$.

\textbf{Note:} Newton on Benchmark~C does not reach the global minimum $(1,1)$ in 20 iterations: the final position $(0.183, 0.020)$ is still partway along the valley. The damped step ($\alpha = 0.22$) moves cautiously because the quadratic approximation is only locally valid: the Rosenbrock landscape deviates substantially from a quadratic over distances larger than the valley width (approximately $1/\sqrt{\kappa_{\max}} \approx 1/\sqrt{2508} \approx 0.02$). With more iterations or an adaptive line-search Newton, the method would converge to $(1,1)$ in $O(\log\log(1/\epsilon))$ iterations from the basin of attraction.

\textbf{Armijo backtracking line search.} In production Newton implementations, the step size $\alpha$ is chosen adaptively via the \emph{Armijo condition}: find $\alpha = \rho^j$ (for $j = 0, 1, 2, \ldots$) such that
\begin{equation}
f(x_k - \alpha p_k) \leq f(x_k) - c\,\alpha\,g_k^T p_k,
\end{equation}
where $c \in (0, 1)$ (typically $c = 10^{-4}$) and $\rho \in (0, 1)$ (typically $0.5$). Since $p_k = H_k^{-1}g_k$ is a descent direction ($g_k^T p_k = g_k^T H_k^{-1}g_k > 0$ when $H_k \succ 0$), the Armijo condition is always eventually satisfied, guaranteeing monotone decrease in $f$. Near the optimum (when the Newton step is unit and the quadratic approximation is accurate), $\alpha = 1$ satisfies the condition and the quadratic convergence rate activates. Replacing the fixed $\alpha = 0.22$ with backtracking would allow Newton to take larger steps when the landscape permits and smaller steps in the narrow valley, potentially reaching closer to $(1,1)$ in 20 iterations.

\subsection{Computational Cost Analysis}

Newton's method requires solving an $n \times n$ linear system at each iteration, costing $O(n^3)$ (LU factorisation) plus $O(n^2)$ for the Hessian evaluation. For $n = 2$ this is trivial, but the cost becomes prohibitive for large-scale problems (e.g.\ deep neural networks with $n = 10^8$ parameters). Several scalable alternatives exist:
\begin{itemize}[nosep]
\item \textbf{BFGS:} Maintains a dense $n \times n$ approximation to $H_k^{-1}$ using rank-2 updates $H_{k+1}^{-1} = H_k^{-1} + \frac{s_k s_k^T}{s_k^T y_k} - \frac{H_k^{-1}y_k y_k^T H_k^{-1}}{y_k^T H_k^{-1} y_k}$ where $s_k = x_{k+1} - x_k$ and $y_k = \nabla f_{k+1} - \nabla f_k$. The update is derived as the minimum-change rank-2 correction satisfying the \emph{secant condition} $H_{k+1}^{-1} y_k = s_k$, which ensures the approximation is consistent with the observed curvature along the step direction. The Wolfe conditions on the line search guarantee $s_k^T y_k > 0$ (curvature condition), maintaining positive definiteness. Cost $O(n^2)$/iter, superlinear convergence (between linear and quadratic), no Hessian evaluations needed.
\item \textbf{L-BFGS:} Limited-memory BFGS stores only the last $m \ll n$ curvature pairs $(s_k, y_k)$, reducing storage from $O(n^2)$ to $O(mn)$ and iteration cost to $O(mn)$. This is the standard solver for smooth large-scale problems in scientific computing (SciPy's \texttt{L-BFGS-B}, PyTorch's \texttt{torch.optim.LBFGS}).
\item \textbf{Diagonal approximations:} Adagrad and Adam use diagonal approximations $\operatorname{diag}(\sqrt{G_k})$ and $\operatorname{diag}(\sqrt{\hat{v}_t})$ as cheap surrogates for the square root of the inverse Hessian, connecting adaptive gradient methods conceptually to Newton's method. The key difference: these diagonals accumulate over the \emph{optimisation trajectory}, not at a fixed point, so they approximate average curvature rather than local curvature.
\item \textbf{Newton CG (Hessian-free):} For large $n$, avoids forming $H$ explicitly by solving $H_k p = g_k$ via conjugate gradients using only Hessian-vector products $H_k v = \nabla^2 f(x_k) v$, which costs $O(n)$ per Hessian-vector product via automatic differentiation. Achieves Newton's convergence without the $O(n^2)$ storage.
\end{itemize}

\textbf{Key findings:} Newton's method converges in 1 iteration on the quadratic (Benchmark~A), confirming the ``single-step minimiser'' property for constant Hessians. On Rosenbrock, Newton's damped step ($\alpha = 0.22$) achieves $5.4\times$ better final value than GD with $4\times$ fewer iterations, but must remain cautious because the quadratic approximation is accurate only within $\sim 0.02$ of each point (valley width $\approx 1/\sqrt{\kappa_{\max}}$). The Armijo backtracking condition provides an adaptive substitute for the fixed $\alpha$, enabling larger steps where the quadratic approximation is accurate and smaller steps in the curved valley. The BFGS rank-2 update provides superlinear convergence without Hessian evaluations: the ideal intermediate between first-order (linear convergence) and Newton (quadratic, but $O(n^3)$/iter).

\subsection{Part A: Derivative Approximation Methods (Benchmark B)}

\subsubsection{Forward Finite Difference Gradient}

The forward finite-difference approximation of the $i$-th partial derivative is:
\begin{equation}
\label{eq:fd}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\end{equation}
where $e_i$ is the $i$-th standard basis vector. The approximation error decomposes into:
\begin{itemize}[nosep]
\item \textbf{Truncation error:} $O(\delta)$ from the first-order Taylor expansion.
\item \textbf{Round-off error:} $O(\varepsilon_{\mathrm{mach}} / \delta)$ from finite-precision arithmetic.
\end{itemize}
The optimal $\delta$ that balances these is $\delta^{\star} = \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}$ for double precision. The experiments use $\delta = 0.05$ (good: truncation $O(0.05)$, round-off $O(10^{-14})$) and $\delta = 0.8$ (poor: truncation $O(0.8)$), both far from the optimal $\delta^{\star}$.

Each gradient evaluation at a $d$-dimensional point requires $d + 1$ function evaluations (one base evaluation at $x$ and one per coordinate direction), compared to $O(d)$ arithmetic operations for exact analytic gradients. For $d = 2$, this is 3 evaluations per step.

\textbf{Central differences} provide second-order accuracy $O(\delta^2)$ at the cost of $2d$ evaluations:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x - \delta e_i)}{2\delta}, \quad \text{error } O(\delta^2) \gg O(\delta).
\end{equation}
The optimal $\delta$ for central differences is $\delta^{\star}_c = \varepsilon_{\mathrm{mach}}^{1/3} \approx 10^{-5.3}$, roughly three orders of magnitude larger than for forward differences, making it more numerically stable in practice.

\subsubsection{Nesterov Random Search (Zeroth-Order)}

\begin{algorithm}[H]
\caption{Nesterov Random Search}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation scale $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform random direction on $\mathbb{S}^{d-1}$}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The directional estimate $\hat{g}_k$ approximates $(\nabla f(x_k)^T u_k) u_k$. Taking expectation over $u_k \sim \mathrm{Uniform}(\mathbb{S}^{d-1})$:
\[
\mathbb{E}_{u}[\hat{g}_k] \approx \mathbb{E}_u\bigl[(\nabla f^T u)\, u\bigr] = \frac{1}{d}\, \nabla f(x_k),
\]
since $\mathbb{E}[uu^T] = \frac{1}{d} I_d$ for uniform $u$ on the sphere. Thus $\hat{g}_k$ is an unbiased estimator of $\frac{1}{d}\nabla f$, and the effective step is $\alpha_{\mathrm{eff}} = \alpha \cdot d$. The \emph{critical advantage} is dimension-independence: only \textbf{2} function evaluations per iteration regardless of $d$, making it $d/2$ times cheaper than forward-difference GD. This makes it uniquely valuable for black-box optimisation (simulators, hardware-in-the-loop, adversarial attacks) where gradient computation is impossible or prohibitively expensive.

\textbf{Convergence rate.} Nesterov random search on a convex $L$-smooth function achieves:
\[
\mathbb{E}\bigl[f(x_k) - f^{\star}\bigr] = O\!\left(\frac{d\,L\,\|x_0 - x^{\star}\|^2}{k}\right),
\]
which is a factor $d$ worse than GD's $O(L\|x_0-x^{\star}\|^2/k)$ rate. This extra $d$ factor reflects the variance in the random direction: only $1/d$ of the true gradient is captured per step on average. For $d = 2$ (our benchmarks), this is only $2\times$ slower than GD per gradient call, but for large $d$ (e.g.\ $d = 1000$) it requires $1000\times$ more iterations to match GD's accuracy.

\subsection{Part B: Derivative-Free Methods on Benchmark C}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices $\{x^{(0)}, x^{(1)}, x^{(2)}\}$ (ordered by function value) and iteratively updates it through four operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): reflect the worst vertex $x^{(n)}$ through the centroid $\bar{x}$ of the remaining $n$ vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x^{(n)})$.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved beyond the best vertex, try further step $x_e = \bar{x} + \gamma(\bar{x} - x^{(n)})$.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection worsened, contract towards the centroid: $x_c = \bar{x} + \rho(x^{(n)} - \bar{x})$.
\item \textbf{Shrink} ($\sigma = 0.5$): replace all non-best vertices with $x^{(i)} \gets x^{(0)} + \sigma(x^{(i)} - x^{(0)})$ (entire simplex shrinks toward the best vertex).
\end{enumerate}
The algorithm requires no gradient or Hessian information: only function evaluations at simplex vertices. The simplex geometry naturally adapts to the local landscape through scaling and rotation.

\textbf{Why Nelder--Mead excels on Rosenbrock.} The key feature is the simplex's ability to \emph{rotate and elongate} relative to the problem structure. On the narrow curved valley of the Rosenbrock function, the simplex naturally elongates along the valley direction (the eigenvector of $H_C$ with smallest eigenvalue $\lambda_{\min} \approx 0.4$). Reflection moves the worst vertex (typically the one most off-valley) across the centroid of the other two, generating a new candidate aligned with the valley. This is equivalent to an approximate line search along the valley direction without needing to compute the gradient. In contrast, coordinate-descent and finite-difference GD must move in axis-aligned directions and are trapped by the narrow valley because the along-valley eigenvector of $H_C(1,1)$ is $(1, 2)/\sqrt{5}$, making an angle $\arctan(2) \approx 63^\circ$ from the $x_1$ axis --- far from both coordinate directions, so no single axis-aligned step can efficiently traverse it.

The theoretical limitation of Nelder--Mead is that it has no general convergence guarantee for $n > 1$: the simplex can degenerate (all vertices collinear), stagnate at non-stationary points, or cycle. In practice, a restart strategy (when the simplex becomes too small) mitigates this.

Settings: initial simplex step $= 0.35$, $N = 160$ iterations.

\textbf{Discussion:} Gradient-based methods are orders of magnitude faster when gradients are available. Zeroth-order methods should only be used when gradient computation is impossible (black-box simulators, hardware-in-the-loop, adversarial attacks on non-differentiable classifiers). Among gradient-free methods:
\begin{itemize}[nosep]
\item \textbf{Nelder--Mead} exploits function evaluations at all $n+1$ simplex vertices simultaneously, providing directional information in $O(n)$ evaluations per iteration. It performs well on smooth low-dimensional problems ($d \leq 10$) but lacks theoretical convergence guarantees and can stagnate on degenerate landscapes.
\item \textbf{Grid search} is the only method with global optimality guarantees (within grid resolution $\Delta x \approx 0.074$ here), but the $O(N^d)$ total cost is the curse of dimensionality: for $d = 10$ and $N = 55$ points per dimension, the grid would have $55^{10} \approx 2.5 \times 10^{17}$ points.
\item \textbf{Nesterov random search} scales to arbitrary dimension at 2 FE/iter cost, but converges very slowly ($O(1/\sqrt{k})$ or worse in practice) due to the single directional sample.
\end{itemize}

On Rosenbrock specifically, Nelder--Mead achieves $f \approx 0.27$ in 160 iterations vs.\ GD's $f = 3.73$ in 80 iterations, demonstrating that the simplex's geometric adaptability to the curved valley compensates for the lack of gradient information.

\textbf{Key findings:} The FD approximation error follows the theoretical two-regime curve: $O(\delta)$ truncation for large $\delta$ and $O(\varepsilon_{\mathrm{mach}}/\delta)$ round-off for small $\delta$, meeting at the optimal $\delta^{\star} \approx 10^{-8}$. The experimental $\delta = 0.8$ incurs $16\times$ more error than $\delta = 0.05$ (both truncation-dominated). Nesterov random search uses only 2 FE/iter regardless of dimension, making it uniquely scalable for black-box optimisation, but its convergence rate degrades by a factor $d$ vs.\ GD. Nelder--Mead achieves $f = 0.27$ on Rosenbrock without any gradient information, outperforming GD's $f = 3.73$: the simplex's ability to rotate and elongate along the valley is the geometric key. Grid search provides global guarantees at $O(N^d)$ cost --- the curse of dimensionality.

\subsection{Problem Setup and Optimality Conditions}

The constrained problem is:
\begin{equation}
\min_{x \in \mathbb{R}^2}\; f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1), \quad \text{subject to}\; g(x) = 0.5 - x_1 \leq 0.
\label{eq:q5_problem}
\end{equation}
The starting point $x_0 = (0.2, 4.0)$ is infeasible ($g(x_0) = 0.3 > 0$).

\textbf{KKT conditions.} The Lagrangian is $\mathcal{L}(x, \mu) = f(x) + \mu\,(0.5 - x_1)$. The KKT stationarity conditions for the constrained minimiser $x^{\star}$ are:
\begin{align}
&\nabla_x \mathcal{L}(x^{\star}, \mu) = \nabla f(x^{\star}) - \mu e_1 = 0 \quad \Rightarrow \quad 2(x_1^{\star}-1) + \cos(x_1^{\star}) = \mu, \\
&g(x^{\star}) = 0.5 - x_1^{\star} \leq 0 \quad \text{(primal feasibility)}, \\
&\mu \geq 0 \quad \text{(dual feasibility)}, \\
&\mu (0.5 - x_1^{\star}) = 0 \quad \text{(complementary slackness)}.
\end{align}
Since the unconstrained minimum is at $x^{\star}_{\text{unc}} \approx (0.5824, 2.0)$ with $x_1^{\star} = 0.5824 > 0.5$, the constraint is \emph{inactive} at the constrained minimum. By complementary slackness $\mu(0.5 - x_1^{\star}) = 0$ with $x_1^{\star} \neq 0.5$, we must have $\mu = 0$. Therefore $x^{\star} = x^{\star}_{\text{unc}} = (0.5824, 2.0)$.

\textbf{Sensitivity interpretation.} The KKT multiplier $\mu^{\star}$ has the sensitivity interpretation: $\partial f^{\star}/\partial b = \mu^{\star}$, where $b = 0.5$ is the constraint right-hand side. Since $\mu^{\star} = 0$ here, a small perturbation of the constraint bound (e.g.\ moving it to $0.5 + \varepsilon$) does \emph{not} change the optimal value: $f^{\star}(0.5 + \varepsilon) = f^{\star}(0.5) + O(\varepsilon^2)$ for small $\varepsilon > 0$. This confirms that the constraint is non-binding and the optimum is robustly interior to the feasible region.

\textbf{Active constraint scenario.} Had the constraint bound been $b = 0.7 > x_1^{\star} \approx 0.582$, the constraint would be active: $x^{\star} = (0.7, 2.0)$ with $\mu^{\star} = 2(0.7 - 1) + \cos(0.7) = -0.6 + 0.765 = 0.165 > 0$, giving $f^{\star} = (0.7-1)^2 + 0 + \sin(0.7) = 0.09 + 0.644 = 0.734 > f^{\star}_{\text{unc}}$. The KKT multiplier would quantify how much the optimum worsens per unit tightening of the constraint.

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{C}} : x_1 \gets \max(0.5, x_1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $x_{k+1} \gets \Pi_{\mathcal{C}}\!\left(x_k - \alpha\, \nabla f(x_k)\right)$ \Comment{Gradient step then project}
\EndFor
\end{algorithmic}
\end{algorithm}

PGD enforces feasibility as a \textbf{hard constraint}: the projection $\Pi_{\mathcal{C}}(x) = \max(0.5, x_1)$ is a valid proximity operator for $\mathcal{C} = \{x : x_1 \geq 0.5\}$. For this constraint, the projection costs $O(1)$.

\begin{theorem}[PGD Convergence]
\label{thm:pgd}
For an $L$-smooth convex function $f$ and a closed convex constraint set $\mathcal{C}$, Projected Gradient Descent with $\alpha \leq 1/L$ achieves:
\[
f(x_k) - f(x^{\star}) \leq \frac{\|x_0 - x^{\star}\|^2}{2\alpha k} = O(1/k).
\]
For $\mu$-strongly convex $f$, the rate improves to linear convergence: $f(x_k) - f^{\star} \leq (1 - \mu\alpha)^k(f(x_0) - f^{\star})$. The convergence rate matches unconstrained GD because the projection $\Pi_{\mathcal{C}}$ is non-expansive: $\|\Pi_{\mathcal{C}}(x) - \Pi_{\mathcal{C}}(y)\| \leq \|x - y\|$ for any $x, y$.
\end{theorem}

For Benchmark~B in Question 5 ($\mu \approx 1.45$, $L \approx 10$, $\alpha = 0.08$): PGD achieves linear rate $1 - 1.45 \times 0.08 = 0.884$ per step, reaching convergence within 100 iterations. The hard projection ensures that all intermediate iterates are feasible, making PGD suitable for safety-critical applications.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\State Define $F_\lambda(x) = f(x) + \lambda\, \max(0,\, 0.5 - x_1)$
\For{$k = 0, 1, \ldots, N-1$}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_\lambda(x_k)$ \Comment{GD on augmented objective}
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty gradient is: $\nabla F_\lambda = \nabla f + \lambda \nabla(\max(0, 0.5 - x_1)) = \nabla f - \lambda e_1\,\mathbf{1}[x_1 < 0.5]$. As $\lambda \to \infty$, the penalty solution approaches the constrained solution. The penalty $\max(0, \cdot)$ is non-smooth, meaning the gradient is discontinuous at the constraint boundary.

Settings: PGD ($\alpha = 0.08$); Penalty $\lambda = 0.15$ ($\alpha = 0.05$), $\lambda = 1.8$ ($\alpha = 0.05$), $\lambda = 4.5$ ($\alpha = 0.03$); Unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\textbf{Key trade-offs:}
\begin{itemize}[nosep]
\item \textbf{PGD} enforces hard feasibility at every step, making it the preferred method when feasibility is a safety requirement (e.g.\ power grid constraints, control bounds). Theoretically, PGD inherits the same convergence rate as unconstrained GD: $O(1/k)$ for convex and linear convergence for strongly convex objectives, since the projection $\Pi_{\mathcal{C}}$ is non-expansive. The limitation is the need for an efficient projection oracle; for general convex sets the projection can be as expensive as solving a quadratic programme.

\item \textbf{Penalty methods} require only the gradient of the augmented objective $F_\lambda = f + \lambda\,\phi$ (where $\phi(x) = \max(0, g(x))$ for inequality constraints), making them easy to implement with any existing solver. However, increasing $\lambda$ stiffens the objective: the condition number of $\nabla^2 F_\lambda$ grows with $\lambda$, requiring smaller step sizes. Specifically, the Lipschitz constant of $\nabla F_\lambda$ grows as $\lambda \to \infty$, so $\alpha \leq 1/L_\lambda$ forces increasingly small steps. The theoretical penalty update $\lambda_k \to \infty$ converges to the constrained solution but is numerically ill-conditioned.

\item \textbf{Augmented Lagrangian (Method of Multipliers)} combines penalty and Lagrangian duality to avoid the ill-conditioning of pure penalty methods:
\begin{equation}
\mathcal{L}_\rho(x, \mu) = f(x) + \mu\, (0.5 - x_1)_+ + \frac{\rho}{2}\|(0.5 - x_1)_+\|^2,
\end{equation}
with multiplier updates $\mu_{k+1} = \mu_k + \rho\, (0.5 - x_k)_+$. For a fixed $\rho$, the AL method achieves the same accuracy as the pure penalty with $\lambda \to \infty$, without requiring $\rho \to \infty$. This eliminates the step-size/conditioning trade-off and allows substantially faster convergence.

\textbf{Convergence rate of the Augmented Lagrangian.} For convex $f$ with $L$-Lipschitz gradient and a linear constraint $Ax = b$, the ADMM (Alternating Direction Method of Multipliers) variant achieves:
$\|Ax_k - b\| = O(1/k)$ and $f(x_k) - f^{\star} = O(1/k)$ with fixed $\rho > 0$. This contrasts favourably with pure penalty methods that require $\rho \to \infty$ (causing $L_{\rho} = L + \rho \|A^T A\|_2 \to \infty$). For strongly convex $f$, ADMM achieves linear convergence $O(\rho^k)$ for fixed $\rho$ chosen optimally. The AL can thus achieve the benefits of projection (exact constraint satisfaction in the limit) at $O(d)$ cost per iteration, bridging PGD and penalty methods.

\item \textbf{Why the constraint is inactive here:} The unconstrained minimum of Benchmark~B is at $x_1^{\star} \approx 0.582 > 0.5$. The constraint $x_1 \geq 0.5$ is therefore inactive at the solution (complementary slackness: $\mu = 0$). This explains why unconstrained GD, PGD, and large-$\lambda$ penalty methods all converge to the same point: they all find the same feasible minimum.
\end{itemize}

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$ (axis-aligned box / polytope with 4 vertices: $(0.5,-5)$, $(5,-5)$, $(5,10)$, $(0.5,10)$).

\textbf{Linear Programme (Task I).} Minimise $f(x) = x_1 + 2x_2 = a^T x$ with $a = [1, 2]^T$ over $\mathcal{X}$.

Since $f$ is linear over the convex polytope $\mathcal{X}$, the fundamental theorem of linear programming guarantees the minimum is attained at a \emph{vertex} (an extreme point). The KKT conditions for this LP are: $a = \mu_1 e_1 - \mu_2 e_1 + \mu_3 e_2 - \mu_4 e_2$ with complementary slackness, which is solved at the vertex where all active bound constraints align with the objective gradient direction. Since $a_1 = 1 > 0$ and $a_2 = 2 > 0$, both components should be minimised, giving the lower bounds:
\begin{equation}
x^{\star} = (0.5,\; -5), \qquad f^{\star} = 1 \cdot 0.5 + 2 \cdot (-5) = -9.5.
\end{equation}
The LP can be solved in $O(1)$ by inspection for box constraints: for each component $i$, set $x_i = l_i$ if $a_i > 0$ and $x_i = u_i$ if $a_i < 0$. This is precisely the LMO used in the Frank--Wolfe algorithm, establishing the direct connection between LP theory and the FW update.

\subsection{Frank--Wolfe (Conditional Gradient) Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe with Fixed Mixing Parameter}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial feasible $x_0 \in \mathcal{X}$, fixed mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{z \in \mathcal{X}}\;\nabla f(x_k)^T z$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1-\beta)\, z_k$ \Comment{Convex combination step toward LMO solution}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}
The standard Frank--Wolfe algorithm uses a decaying step $\gamma_k = 2/(k+2)$, yielding the $O(1/k)$ convergence guarantee. The implementation here uses a \textbf{fixed} mixing parameter $\beta$ (equivalently, fixed $\gamma = 1 - \beta$), which can converge faster initially but may oscillate near the optimum for interior solutions where $z_k$ jumps between vertices.
\end{remark}

For the box constraint $\mathcal{X}$, the LMO decomposes per coordinate: $(z_k)_i = l_i$ if $(\nabla f(x_k))_i > 0$, else $(z_k)_i = u_i$. This costs $O(d)$ per iteration and requires no projection oracle --- a key advantage over projected methods for complex constraint sets.

\begin{theorem}[Frank--Wolfe Convergence]
\label{thm:fw}
For a convex, $L$-smooth function $f$ over a compact convex set $\mathcal{X}$ with diameter $D = \max_{x,y \in \mathcal{X}}\|x-y\|$, the standard Frank--Wolfe with $\gamma_k = 2/(k+2)$ satisfies:
\[
f(x_k) - f(x^{\star}) \leq \frac{2LD^2}{k+2} = O(1/k).
\]
This rate is projection-free but cannot be improved to $O(1/k^2)$ in general (unlike projected gradient methods). For the box $\mathcal{X}$: $D = \sqrt{(5-0.5)^2 + (10-(-5))^2} \approx 15.66$. The convergence is limited by the diameter $D^2$ rather than the distance to the optimum $\|x_0 - x^{\star}\|^2$, which can be significantly smaller.
\end{theorem}

\subsection{Frank--Wolfe Duality Gap}

The \emph{Frank--Wolfe gap} (or primal-dual gap) at iterate $x_k$ is:
\begin{equation}
\label{eq:fw_gap}
g_k = \nabla f(x_k)^T (x_k - z_k) = \max_{z \in \mathcal{X}} \nabla f(x_k)^T (x_k - z),
\end{equation}
where $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$ is the LMO solution. For a convex function, this gap satisfies $f(x_k) - f^{\star} \leq g_k$: the gap provides a \emph{computable upper bound} on the optimality error without knowing $f^{\star}$.

\begin{proposition}
\label{prop:fw_gap}
For the standard FW with $\gamma_k = 2/(k+2)$, the FW gap satisfies $g_k \leq 4LD^2/(k+2) = O(1/k)$, matching the rate in Theorem~\ref{thm:fw} and providing a directly computable certificate.
\end{proposition}

The gap also serves as a \emph{termination criterion}: if $g_k \leq \varepsilon$, then $f(x_k) - f^{\star} \leq \varepsilon$ is certified. In the experiments: for the boundary case, $g_{140} = \nabla f(x_{140})^T(x_{140} - z_{140})$ would be a valid stopping criterion, computable without knowing $f^{\star} = 0.25$.

\subsection{Interior vs.\ Boundary Behaviour and Analysis}

\textbf{Interior optimum --- vertex chattering.} Near the interior minimum $(1, 5)$, the gradient $\nabla f(x_k) = 2(x_k - [1, 5]^T) \approx 0$ is small. The LMO $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$ selects $z^{(i)} = l_i$ if $(\nabla f(x_k))_i > 0$ and $z^{(i)} = u_i$ otherwise. When $\nabla f(x_k)$ is near zero, small sign changes in individual components cause $z_k$ to jump between box vertices --- this is the \emph{chattering} or \emph{zigzagging} phenomenon. Each step then moves the iterate towards a different vertex, preventing tight convergence. Away-step FW addresses this by adding a ``corrective'' step away from the active vertex: $x_{k+1} = x_k + \gamma_k(x_k - v_k)$ where $v_k = \arg\max_{v \in \mathcal{S}_k} \nabla f(x_k)^T v$ and $\mathcal{S}_k$ is the current active set. For strongly convex $f$ over a polytope, away-step FW achieves linear convergence $O(\rho^k)$ with $\rho = 1 - \mu/(L\kappa_f^2)$, where $\kappa_f$ is the pyramidal width of $\mathcal{X}$.

\textbf{Boundary optimum --- consistent vertex selection.} Frank--Wolfe excels here. At the boundary minimiser $x^{\star} = (0.5, 0)$, the gradient $\nabla f(x^{\star}) = 2x^{\star} = [1, 0]^T$. Since $(\nabla f)_1 = 1 > 0$, the LMO consistently selects $z_k = (0.5, -5)$ (the lower-left vertex), pointing towards the constraint boundary. As $x_k \to x^{\star}$, the LMO does not chatter because the gradient sign remains stable. After 140 iterations, the boundary method reaches $f = 0.364$ vs $f^{\star} = 0.25$ --- still above the true optimum because the fixed $\beta = 0.93$ step does not decay and the iterate remains a convex combination of $x_0$ and $(0.5, -5)$. Additional iterations would close this gap monotonically.

\textbf{Projection-free advantage and sparse approximation.} The key practical virtue of Frank--Wolfe is that it avoids projections. For the box constraint $\mathcal{X}$, projection is $O(d)$ and equivalent to the LMO; but for structured constraint sets the LMO is computationally much cheaper:
\begin{itemize}[nosep]
\item \textbf{$\ell_1$ ball} ($\|x\|_1 \leq r$): the LMO selects the atom $z = r\,\mathrm{sign}(-g_i) e_{\arg\max_i |g_i|}$ in $O(d)$, whereas projection requires $O(d \log d)$ sorting or $O(d)$ median finding. FW on the $\ell_1$ ball yields \emph{sparse iterates}: each $x_k$ is a convex combination of at most $k$ atoms (unit vectors), with sparsity $\leq k$. This is the Frank--Wolfe interpretation of \emph{basis pursuit} and LASSO.
\item \textbf{Nuclear norm ball} ($\|X\|_* \leq r$, $X \in \mathbb{R}^{m \times n}$): the LMO requires only the top singular vector pair ($O(mn)$ via power method), compared to $O(mn\min(m,n))$ for full SVD projection. This makes FW the standard algorithm for matrix completion and low-rank optimisation.
\item \textbf{Probability simplex} ($\sum_i x_i = 1$, $x_i \geq 0$): the LMO is $z = e_{\arg\min_i g_i}$ in $O(d)$, trivially identifying the best coordinate. This is the Frank--Wolfe interpretation of \emph{boosting}.
\end{itemize}

The sparse atom structure of FW iterates is a key advantage in memory-limited or interpretability-critical settings where dense solutions are undesirable.

\textbf{Key findings:} The LP Task~I (minimise $x_1 + 2x_2$) achieves its optimum at the lower-left vertex $(0.5, -5)$ with $f^{\star} = -9.5$, confirming LP vertex optimality. FW's LMO for this box constraint is the same as the LP oracle. For the interior Task~II, the fixed-$\beta$ FW oscillates because the gradient direction near $(1, 5)$ fluctuates, causing the LMO to jump vertices: $\beta = 0.985$ (smaller step) achieves better final value ($f = 0.0046$) than $\beta = 0.90$ ($f = 0.0089$). The standard decaying FW with $\gamma_k = 2/(k+2)$ provides the theoretical $O(1/k)$ guarantee. The FW duality gap $g_k = \nabla f^T(x_k - z_k) \geq f(x_k) - f^{\star}$ provides a computable certificate of optimality without knowing $f^{\star}$.

The comparison highlights the trade-offs between method classes:
\begin{itemize}[nosep]
\item \textbf{Information hierarchy:} Newton (uses $H$) $\gg$ Gradient methods (uses $\nabla f$) $\gg$ Zeroth-order (uses $f$). Each tier uses strictly more information and achieves strictly better performance on all three benchmarks. The \emph{oracle complexity lower bound} (Nemirovski--Yudin) states that any first-order method requires $\Omega(1/\sqrt{\varepsilon})$ gradient queries to reach $\varepsilon$-accuracy on $L$-smooth convex objectives --- Nesterov achieves this bound and Adam does not.

\item \textbf{Within first-order methods:} Acceleration (Nesterov) provides the largest gain by building consistent descent momentum along the Rosenbrock valley. The intuition: after $k$ steps, Nesterov's momentum accumulates $\approx k$ gradient directions, all pointing up-valley; their sum has magnitude $O(k)$ along the valley. GD at each step takes the current gradient only, with magnitude $O(1)$. Adam's per-coordinate normalisation explicitly divides out this magnitude, eliminating the accumulated momentum advantage.

\item \textbf{Polyak's special case:} With exact $f^{\star} = 0$, Polyak achieves results competitive with Newton on Rosenbrock ($f = 0.009$ vs.\ Newton's $f = 0.686$ in 20 iterations). This is because the Polyak step perfectly allocates the ``budget'' of remaining function value: at each step it takes a step proportional to $(f(x_k) - 0)/\|\nabla f\|^2$, automatically large when far from the minimum and small when close, without any curvature computation.

\item \textbf{Condition number governs method selection:} For $\kappa \approx 1.12$ (Benchmark~A), the convergence rate $\rho = (\kappa-1)/(\kappa+1) \approx 0.054$ per step means GD halves the error every $\log(2)/\log(1/0.054) \approx 0.23$ steps --- essentially one step. All methods are essentially equivalent. For $\kappa \approx 2508$ (Benchmark~C), $\rho = (2507/2509) \approx 0.9992$ means GD needs $\log(2)/\log(1/0.9992) \approx 869$ steps to halve the error. This explains the dramatic performance hierarchy on Benchmark~C. Nesterov's rate $\rho_N = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1) \approx 0.961$ needs only $\approx 17$ steps for the same improvement, a $\approx 50\times$ gain consistent with the $O(\kappa)$ vs.\ $O(\sqrt{\kappa})$ scaling (see also Figure~\ref{fig:cond_analysis}).
\end{itemize}

\section{Summary and Conclusions}
\label{sec:conclusion}
% ============================================================

This study implemented and evaluated 14 distinct optimisation algorithms across three benchmark functions spanning well-conditioned quadratic, mildly non-convex, and severely ill-conditioned ($\kappa \approx 2508$) landscapes. All algorithms were implemented from scratch in Python and verified against exact analytical solutions where available.

\subsection{Adaptive Step-Size Methods (Question 1)}
The Polyak step achieves theoretically optimal convergence when $f^{\star}$ is known exactly (Rosenbrock: $f = 0.009$ in 120 iterations), but fails catastrophically with misspecified $f^{\star}$ (diverging to $f = 24.07$ on Benchmark~B). This sensitivity fundamentally limits its applicability to settings where $f^{\star}$ is available (e.g.\ linear regression with known noise variance). Adagrad's per-coordinate diagonal preconditioning provides a computationally cheap approximation to the inverse Hessian, explaining its improved performance on ill-conditioned problems. Heavy Ball's momentum accumulation along consistent gradient directions achieves the best first-order result on Rosenbrock among methods without oracle $f^{\star}$ ($f = 1.40$ vs.\ GD's $3.51$).

\subsection{Momentum and Stochastic Methods (Question 2)}
Nesterov's accelerated gradient achieves the theoretically optimal $O(1/k^2)$ convergence rate (Theorem~\ref{thm:nesterov}), confirmed empirically on Benchmark~A, and is the best first-order method on Rosenbrock ($f = 0.479$ at 150 iterations). The key advantage over Adam on ill-conditioned problems is that Nesterov builds large-scale momentum in the valley-traversal direction, while Adam's per-coordinate normalisation suppresses this accumulation. In high-noise SGD settings, increasing label noise from $\sigma = 1$ to $\sigma = 6$ raises the convergence floor by $\approx 36\times$ (proportional to $\sigma^2$), and the batch-size effect is dominated by the irreducible noise variance.

\subsection{Newton's Method (Question 3)}
Newton's method demonstrates the decisive advantage of second-order information: single-iteration convergence on the quadratic Benchmark~A (exploiting the constant Hessian), and $5.4\times$ better final value on Rosenbrock with $4\times$ fewer iterations versus GD. The Tikhonov-regularised Hessian ($\lambda = 10^{-8}$) ensures positive definiteness throughout. The damped step ($\alpha = 0.22$ on Rosenbrock) is necessary because the quadratic approximation is accurate only within a neighbourhood of size $\approx 1/\sqrt{\kappa_{\max}} \approx 0.02$, smaller than the valley width. The connection to adaptive gradient methods is through diagonal Hessian approximations: Adagrad and Adam are cheap surrogates for Newton's inverse Hessian scaling.

\subsection{Derivative-Free Methods (Question 4)}
The forward finite-difference approximation introduces $O(\delta)$ truncation error; the experiment confirms that $\delta = 0.05$ provides high-fidelity gradients, while $\delta = 0.8$ introduces $\sim 16\times$ greater error. The optimal FD step $\delta^{\star} = \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}$ minimises the sum of truncation and round-off errors. Nesterov random search's key property is the $\mathbb{E}[uu^T] = I/d$ identity, making it an unbiased estimator of $\nabla f / d$ at 2 FE/iter. Nelder--Mead achieves $f \approx 0.27$ on Rosenbrock in 160 iterations by adapting its simplex geometry to the curved valley, outperforming GD ($f = 3.73$) without any gradient information. Grid search guarantees global coverage but is limited by the curse of dimensionality: $55^d$ evaluations required for $d$-dimensional problems.

\subsection{Constrained Optimisation (Question 5)}
The constraint $x_1 \geq 0.5$ is inactive at the unconstrained minimum ($x_1^{\star} \approx 0.582 > 0.5$), so all methods ultimately converge to the same point. This illustrates the KKT complementary slackness condition: at the constrained minimiser, $\mu = 0$ and the constraint is not active. Projected GD enforces hard feasibility from iteration 1 through $O(1)$ projection. The penalty parameter $\lambda$ controls the trade-off between constraint satisfaction and objective conditioning: $\lambda = 0.15$ is insufficient to eliminate violations within 100 iterations, while $\lambda = 4.5$ achieves zero violation in $\approx 10$ iterations but requires a reduced step size $\alpha = 0.03$.

\subsection{Frank--Wolfe Algorithm (Question 6)}
The Frank--Wolfe algorithm connects directly to the linear programme solved in Task~I: the LMO $\arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$ is identical to solving a linear programme with objective $\nabla f(x_k)^T z$. By Theorem~\ref{thm:fw}, convergence is $O(1/k)$ with the standard decaying step. The fixed-step variant used here converges but oscillates near interior optima (the LMO jumps between vertices as gradient direction fluctuates). Boundary optima are handled naturally since the LMO consistently points toward the same vertex, and indeed the boundary case achieves $f = 0.364$ vs.\ $f^{\star} = 0.25$ after 140 iterations, with continued convergence expected with more iterations.

\textbf{Recommendation hierarchy by scenario:}
\begin{itemize}[nosep]
\item \emph{Convex, well-conditioned} ($\kappa \leq 10$): Standard GD or Adagrad. The near-unity condition number means GD is already near-optimal; PL inequality guarantees linear convergence.
\item \emph{Convex, ill-conditioned} ($\kappa \gg 1$): Nesterov achieves the optimal $O(1/k^2)$ rate (Nemirovski--Yudin bound). Adam is more robust to hyperparameter tuning but has no worst-case rate guarantee and underperforms Nesterov when the ill-conditioning direction is not aligned with coordinate axes.
\item \emph{Hessians available, small $d$ ($\leq 1000$)}: Newton's method (or BFGS for medium scale). Quadratic convergence amortises the $O(d^3)$ Hessian cost in $O(\log\log(1/\varepsilon))$ iterations.
\item \emph{Large scale, smooth}: L-BFGS using $O(md)$ storage with $m \approx 10$--$20$ stored curvature pairs.
\item \emph{No gradients available, small $d$ ($\leq 10$)}: Nelder--Mead; the simplex adapts its geometry to the landscape.
\item \emph{No gradients available, large $d$}: Nesterov random search (2 FE/iter; scales independently of dimension).
\item \emph{Linearly/affinely-constrained, structured}: Frank--Wolfe. Especially powerful when the LMO is cheap (nuclear norm, $\ell_1$ ball, simplex); yields sparse iterates.
\item \emph{Bound-constrained, general}: Projected gradient descent with $O(1)$ projection for box constraints.
\item \emph{$f^{\star}$ known exactly}: Polyak step. Single hyperparameter, optimally adaptive, but brittle.
\end{itemize}

\textbf{Unifying principle: geometry determines algorithm.} The three benchmarks span three qualitatively different geometries: (A) isotropic quadratic bowl, (B) anisotropic bowl with mild non-linearity, (C) narrow curved valley. The performance hierarchy on (C) --- Newton $\gg$ Nesterov $\gg$ Adam $\gg$ GD --- directly reflects how well each method exploits curvature information: Newton uses the full Hessian to navigate the valley in any direction; Nesterov uses accumulated momentum to build up speed along the valley; Adam normalises out the curvature advantage; GD steps are throttled by the largest eigenvalue. The derivative-free champion on Rosenbrock, Nelder--Mead, succeeds precisely because its simplex can rotate to align with the valley direction without any gradient or curvature computation.

\begin{lstlisting}[caption={Gradient Descent}]
def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g   # z accumulates momentum
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z       # Evaluate gradient at lookahead
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)   # Bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Damped Newton's Method}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))   # Tikhonov regularisation
        try:
            p = np.linalg.solve(H_reg, g)       # Newton direction
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe with Fixed Mixing Parameter}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: solve min_{z in X} g^T z (box constraint decomposes per coord)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z  # Fixed-step convex combination
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
