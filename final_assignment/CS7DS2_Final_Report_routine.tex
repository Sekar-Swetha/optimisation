\begin{abstract}
This report presents a comprehensive comparative study of first-order and second-order optimisation
algorithms applied to four benchmark problems: a linear regression quadratic loss (Benchmark~A),
a sinusoidally perturbed quadratic loss inspired by neural network training (Benchmark~B), the
ill-conditioned Rosenbrock function (Benchmark~C), and a box-constrained feasible set
(Benchmark~D). Six categories of methods are investigated: (1)~adaptive step-size methods
(Polyak, Adagrad, RMSprop, Heavy~Ball); (2)~momentum-based methods (Nesterov acceleration, Adam)
with mini-batch stochastic gradient descent; (3)~Newton's method with local quadratic
approximations; (4)~derivative-free approaches (finite differences, Nesterov random search,
Nelder--Mead, grid search); (5)~constrained optimisation via projected gradient descent and
quadratic penalty methods; and (6)~the Frank--Wolfe conditional gradient algorithm for
linear-constrained problems. Each method is evaluated in terms of convergence speed, trajectory
behaviour, constraint satisfaction, and computational trade-offs. Key findings include:
(i)~the Polyak step size is highly sensitive to the accuracy of the optimal value estimate ---
diverging on Benchmarks~A and~B (where $f^{\star}=0$ is misspecified) but achieving the best
result on Rosenbrock ($f = 0.009$ vs $f = 3.51$ for GD) when $f^{\star}=0$ is exact;
(ii)~Nesterov acceleration achieves a $7\times$ improvement over GD on Rosenbrock ($f = 0.479$
vs $f = 3.39$ in 150 iterations), consistent with the theoretical $O(1/k^2)$ vs $O(1/k)$
advantage; (iii)~Newton's method converges in a single step on strictly quadratic losses and in
$\leq 5$ iterations on near-quadratic Benchmark~B, with quadratic local convergence rate
$\|x_{k+1}-x^{\star}\| \leq (M/2\mu)\|x_k-x^{\star}\|^2$; (iv)~Nelder--Mead achieves
$f < 10^{-5}$ on Rosenbrock in 160 iterations using only function evaluations, outperforming
all first-order methods tested; (v)~projected gradient descent enforces feasibility as a hard
constraint from iteration~1, while penalty methods require $\lambda \geq 1.8$ for reliable
constraint satisfaction; and (vi)~the Frank--Wolfe standard diminishing schedule
$\gamma_k = 2/(k+2)$ achieves $f = 0.0011$ vs $f = 0.0985$ for a fixed $\beta = 0.90$
schedule, validating the theoretical requirement for decaying step sizes.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation lies at the core of modern machine learning and data analysis. The choice of
optimisation algorithm --- and its hyperparameters --- profoundly affects both the quality of the
solution found and the computational cost of finding it. This report studies six broad families
of algorithms, ranging from classical gradient descent to modern adaptive methods and
gradient-free approaches, on four benchmark problems of varying structure and difficulty.

The four benchmark problems span a spectrum of problem structures
(Section~\ref{sec:benchmarks}): Benchmark~A is a perfectly conditioned quadratic (linear
regression loss); Benchmark~B introduces mild non-linearity through a sinusoidal perturbation
with condition number $\kappa \in [10/3, 10]$; Benchmark~C (the Rosenbrock function) is a
notoriously difficult non-convex function with a narrow curved valley and condition number
$\kappa \approx 2504$; and Benchmark~D is a box-constrained version of Benchmark~B used for
constrained optimisation (Questions~5--6).

The theoretical analysis throughout uses the following standard framework. A function
$f : \mathbb{R}^d \to \mathbb{R}$ is called:
\begin{itemize}[nosep]
\item \emph{$L$-smooth} if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ for all $x,y$
  (equivalently, $\nabla^2 f \preceq LI$);
\item \emph{$\mu$-strongly convex} if $f(y) \geq f(x) + \nabla f(x)^\top(y-x) + \frac{\mu}{2}\|y-x\|^2$
  (equivalently, $\nabla^2 f \succeq \mu I$);
\item with \emph{condition number} $\kappa = L/\mu$.
\end{itemize}
Under $L$-smoothness and $\mu$-strong convexity: GD with $\alpha = 2/(\mu+L)$ converges at rate
$O(\rho^k)$ with $\rho = (\kappa-1)/(\kappa+1)$; Nesterov acceleration achieves $O(\sqrt{\kappa} \log(1/\varepsilon))$
iterations --- a $\sqrt{\kappa}$-fold improvement. This hierarchy is
\emph{information-theoretically tight}: Nesterov (1983) proved a matching lower bound showing
that no first-order method (using only $f$ and $\nabla f$) can achieve $\varepsilon$-accuracy
in fewer than $\Omega(\sqrt{\kappa}\log(1/\varepsilon))$ gradient evaluations on smooth strongly
convex problems. GD's $O(\kappa\log(1/\varepsilon))$ rate is therefore provably suboptimal by
a $\sqrt{\kappa}$ factor, and Nesterov acceleration is the unique optimal first-order method
(see also Remark in Section~\ref{sec:q2}). For Benchmarks~A and~B, $\kappa \in [1, 10]$;
for Benchmark~C, $\kappa \approx 2504$, making the choice of algorithm critical.

All experiments use \texttt{numpy} with a fixed random seed (\texttt{np.random.seed(42)}) for
full reproducibility. The complete implementation is provided in
\texttt{CS7DS2\_Final\_Code\_25336453.py}; selected excerpts appear in
Appendix~\ref{app:code}.

\textbf{Report structure:}
Section~\ref{sec:q1} (Q1) studies adaptive step-size methods (Polyak, Adagrad, RMSprop,

Section~\ref{sec:q2} (Q2) analyses momentum acceleration (Nesterov, Adam) and mini-batch

Section~\ref{sec:q3} (Q3) examines Newton's method and the role of second-order curvature

Section~\ref{sec:q6} (Q6) investigates the Frank--Wolfe (conditional gradient) algorithm.
Sections~\ref{sec:comparison} and~\ref{sec:conclusion} provide a unified cross-method comparison
and recommendations.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
x^{(i)} \sim \mathcal{N}(0, I_2), \quad
y^{(i)} = {\theta^{\star}}^{\!\top} x^{(i)} + \varepsilon^{(i)}, \quad
\varepsilon^{(i)} \sim \mathcal{N}(0,1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^\top x^{(i)} - y^{(i)}\bigr)^2
           = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a strictly convex quadratic with constant Hessian $H = \frac{1}{m}X^\top X \succ 0$.
The gradient is $\nabla J(\theta) = \frac{1}{m}X^\top(X\theta - y)$.  Because of observation
noise, the infimum is $J^{\star} \approx 0.4826 \neq 0$. The OLS solution is
$\hat{\theta} = (X^\top X)^{-1} X^\top y \approx [3.028,\, 4.017]^\top$, which is close to but
not equal to $\theta^{\star}$ due to finite-sample noise. Starting point: $\theta_0 = [0,0]^\top$.

\subsection{Benchmark B: Sinusoidally Perturbed Quadratic}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^\top$ and the Hessian is
$H(x) = \operatorname{diag}(2 - \sin(x_1),\ 10)$.  The Hessian eigenvalues satisfy
$\lambda_1(x) = 2 - \sin(x_1) \in [1, 3]$ and $\lambda_2 = 10$, yielding a local condition
number in the range $\kappa(x) \in [10/3,\, 10]$.  The unique global minimum satisfies the
first-order condition $2(x_1^{\star}-1) + \cos(x_1^{\star}) = 0$, $x_2^{\star} = 2$; solving
numerically gives $x^{\star} \approx (0.582, 2.0)$ with $f^{\star} \approx 0.7244$.  Starting
point: $x_0 = [-1, 4]^\top$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian is:
\begin{equation}
\nabla^2 f(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At both the optimum $(1,1)$ and the starting point $(-1,1)$, the Hessian evaluates to
$\begin{bmatrix} 802 & \mp 400 \\ \mp 400 & 200 \end{bmatrix}$,
with $\det = 802 \times 200 - 400^2 = 400$ and $\operatorname{tr} = 1002$. Solving
$\lambda^2 - 1002\lambda + 400 = 0$ gives eigenvalues $\lambda_{\max} \approx 1001.6$ and
$\lambda_{\min} \approx 0.40$, yielding a condition number $\kappa \approx 2504$. This extreme
ill-conditioning, combined with a narrow curved valley along $x_2 = x_1^2$, makes the Rosenbrock
function one of the most challenging standard test functions for first-order methods.
Starting point: $x_0 = [-1, 1]^\top$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Questions~5--6):
\begin{equation}
\mathcal{X} = \bigl\{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\bigr\}.
\end{equation}
This is a box (hyperrectangle), which admits an efficient projection and a closed-form linear
minimisation oracle --- both critical properties exploited in Questions~5 and~6.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}

\subsection{Algorithm Formulations}
\label{ssec:q1_algs}

Four adaptive step-size methods are compared against a constant step-size gradient descent
baseline across all three benchmark functions for 120 iterations.

For reference, constant step-size gradient descent on a $\mu$-strongly convex, $L$-smooth
function (i.e., $\mu I \preceq \nabla^2 f \preceq LI$) with optimal step size
$\alpha^{\star} = 2/(\mu + L)$ converges at rate:
\begin{equation}
\label{eq:gd_rate}
f(x_k) - f^{\star} \leq \left(\frac{\kappa - 1}{\kappa + 1}\right)^{2k} \bigl(f(x_0) - f^{\star}\bigr),
\end{equation}
where $\kappa = L/\mu$ is the condition number. All adaptive methods below aim to improve
upon this rate by better exploiting the local geometry.

\subsubsection{Polyak Step Size}

The Polyak step size adapts the learning rate at each iteration to theoretically achieve the
fastest descent for a given function value gap. Given knowledge of the optimal value $f^{\star}$,
the update is:

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{proposition}[Polyak convergence]
For a convex function $f$ with known $f^{\star}$, the Polyak step satisfies
$\|x_{k+1} - x^{\star}\|^2 \leq \|x_k - x^{\star}\|^2 - \frac{(f(x_k)-f^{\star})^2}{\|g_k\|^2}$,
guaranteeing monotone decrease of the distance to the optimum.
\end{proposition}

\begin{remark}[The Polyak--\L{}ojasiewicz condition]
The Polyak step achieves linear convergence on a broader class of functions than strongly
convex ones via the \emph{Polyak--\L{}ojasiewicz (PL) condition}: $f$ satisfies PL with
constant $\mu > 0$ if $\|\nabla f(x)\|^2 \geq 2\mu(f(x) - f^{\star})$ for all $x$.  Every
$\mu$-strongly convex function satisfies PL with the same $\mu$, but PL permits multiple global
minimisers and non-unique $x^{\star}$.  Under PL and $L$-smoothness, substituting
$\alpha_k = (f(x_k)-f^{\star})/\|\nabla f(x_k)\|^2$ into the $L$-smooth descent lemma gives:
\[
  f(x_{k+1}) - f^{\star} \leq f(x_k) - f^{\star} - \frac{(f(x_k)-f^{\star})^2}{L\|\nabla f(x_k)\|^{-2}\|\nabla f(x_k)\|^2}
  \leq \left(1 - \frac{\mu}{L}\right)(f(x_k) - f^{\star}),
\]
using $\|\nabla f\|^2 \geq 2\mu(f-f^{\star})$ in the last step.  Thus the Polyak step
achieves the \emph{same} linear rate $\rho = 1 - \mu/L$ as optimal fixed-step GD on
strongly convex problems, without requiring knowledge of $L$ or $\mu$.  The Rosenbrock
function satisfies PL in a neighbourhood of its valley floor (where a single global minimum
$(1,1)$ exists and the gradient norm is bounded away from zero except at the minimum),
which explains why Polyak achieves rapid convergence ($f = 0.009$ in 120 iterations) despite
the non-convex global landscape.
\end{remark}

\noindent This guarantee relies critically on the accuracy of $f^{\star}$; the method fails in
two qualitatively different ways depending on the direction of misspecification:
\begin{itemize}[nosep]
\item \emph{Under-estimation} ($f^{\star}_{\text{spec}} < f^{\star}_{\text{true}}$, e.g.,
  $f^{\star} = 0$ when $f^{\star}_{\text{true}} \approx 0.48$): the numerator
  $f(x_k) - f^{\star}_{\text{spec}} \approx 0.48$ stays positive as $\|\nabla f\| \to 0$,
  so $\alpha_k = 0.48/\|\nabla f\|^2 \to \infty$, causing the iterate to diverge.
\item \emph{Over-estimation} ($f^{\star}_{\text{spec}} > f^{\star}_{\text{true}}$, e.g.,
  $f^{\star} = 2 > f^{\star}_{\text{true}} \approx 0.48$): once $f(x_k) < f^{\star}_{\text{spec}}$,
  the numerator $f(x_k) - 2 < 0$, giving $\alpha_k < 0$ --- the algorithm takes a gradient
  \emph{ascent} step and immediately diverges.
\end{itemize}
Both failure modes explain why Polyak diverges on Benchmarks~A and~B in Figure~\ref{fig:q1_fval_A}--\ref{fig:q1_fval_B}: the specified $f^{\star} = 0$ is below the true minima $\approx 0.48$ and $\approx 0.72$, triggering the under-estimation divergence. Conversely, when $f^{\star}$ is known exactly (Benchmark~C: $f^{\star} = 0$), the Polyak
proposition implies:
\begin{equation}
\|x_{k+1} - x^{\star}\|^2 \leq \|x_k - x^{\star}\|^2 \left(1 - \frac{(f(x_k)/\|x_k-x^{\star}\|)^2}{\|g_k\|^2/\|x_k-x^{\star}\|^2}\right),
\end{equation}
and by the gradient inequality for convex $f$:
$f(x_k) - f^{\star} \geq \langle g_k, x_k - x^{\star} \rangle \cdot (-1) \Rightarrow f(x_k) \leq \|g_k\|\|x_k - x^{\star}\|$,
so the factor in parentheses is at least $\frac{f(x_k)^2}{\|g_k\|^2\|x_k-x^{\star}\|^2} > 0$,
ensuring strict decrease. On the Rosenbrock function, the large gradient norms near the curved
valley mean $f(x_k)/\|g_k\| \gg 0$, giving large Polyak steps that advance quickly along the
valley --- explaining why Polyak achieves $f = 0.0094$ vs GD's $f = 3.51$ in 120 iterations.

\subsubsection{Adagrad}

Adagrad accumulates the squared gradient history per coordinate, automatically reducing the
effective step size for frequently-updated parameters:

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate cumulative squared gradient}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The effective learning rate $\alpha_k^{(i)} = \alpha_0 / (\sqrt{G_k^{(i)}} + \varepsilon)$ is
monotonically \emph{decreasing} in each coordinate, which can cause premature convergence on
non-stationary problems but guarantees stability in the stationary setting. Notably, Adagrad
implicitly performs coordinate-wise preconditioning: if coordinate $i$ consistently receives
large gradients, $G_k^{(i)}$ grows rapidly, reducing the effective step in that direction and
correcting for large curvature. This adaptive preconditioning is particularly beneficial when
the Hessian is ill-conditioned and its large-curvature directions align with the coordinate
axes.

\begin{remark}[Adagrad effective step-size decay rate]
To see why Adagrad's effective step decays monotonically, consider coordinate $i$ with
approximately constant gradient magnitude $|g_k^{(i)}| \approx c > 0$ over $k$ steps.
Then $G_k^{(i)} = \sum_{j=1}^{k}(g_j^{(i)})^2 \approx kc^2$, so
\[
  \alpha_k^{(i)} = \frac{\alpha_0}{\sqrt{G_k^{(i)}} + \varepsilon} \approx \frac{\alpha_0}{c\sqrt{k}},
  \quad k \gg 1.
\]
This $O(1/\sqrt{k})$ decay per coordinate is exactly the optimal schedule for non-smooth
convex problems (subgradient method): the cumulative regret over $k$ rounds is
$O(\alpha_0 c \sqrt{k})$, tight for this class. The \emph{per-coordinate} nature is the
key advantage: a coordinate $j$ with small gradient magnitude $c_j \ll c_i$ retains a
large effective step $\alpha_0/(c_j\sqrt{k})$ even while coordinate $i$ decays fast, automatically
balancing progress across heterogeneous curvature directions without any manual tuning.
This contrasts with a global $O(1/\sqrt{k})$ schedule that would uniformly slow all
coordinates regardless of their gradient scale.
\end{remark}

\begin{remark}[Adagrad as online mirror descent]
Adagrad admits a clean interpretation as \emph{online mirror descent} with a time-varying
Mahalanobis norm.  At step $k$, the Adagrad update
$x_{k+1} = x_k - \alpha_0 G_k^{-1/2} g_k$ (where $G_k = \operatorname{diag}(\sum_{j \leq k}g_j^2)$)
is equivalent to:
\[
  x_{k+1} = \arg\min_{x} \Bigl\{ g_k^\top x + \frac{1}{2\alpha_0}\|x - x_k\|_{G_k}^2 \Bigr\},
  \qquad \|v\|_{G_k}^2 = v^\top G_k v.
\]
This is mirror descent with the Bregman divergence induced by the convex potential
$\phi_k(x) = \frac{1}{2\alpha_0}\|x\|_{G_k}^2$, i.e.\ measuring progress in the
\emph{cumulative-gradient-weighted norm}.  The key theoretical consequence is that Adagrad
achieves the \emph{optimal online regret bound} $\sum_{k=1}^{T} (f(x_k) - f(x^{\star})) \leq
\frac{1}{2\alpha_0}\|x_0 - x^{\star}\|_{\text{diag}}^2 + \alpha_0 \sum_{i=1}^{d}\sqrt{\sum_{k=1}^{T}(g_k^{(i)})^2}$,
where the second term is $O(\sqrt{T})$ for each coordinate independently.  For coordinates
with small gradient variance, the second term grows slowly --- explaining the per-coordinate
benefit.  This mirror descent view also clarifies why the cumulative-average matrix $G_k/k$
approximates the Hessian diagonal: for quadratic $f$ with gradient $Hx$, $g_k^{(i)} \approx
H_{ii} x_k^{(i)}$ (if $H$ is diagonal), so $G_k^{(i)}/k \to H_{ii}^2 \|x\|^2/k$, and the
Adagrad step $\alpha_0/(G_k^{(i)})^{1/2}$ becomes approximately $\alpha_0/(H_{ii}\|x\|)$
--- a natural scaling by inverse gradient magnitude.
\end{remark}

\begin{remark}[Limitation: diagonal vs.\ full preconditioning]
Adagrad's coordinate-wise update implicitly approximates the Hessian by a diagonal matrix
$\hat{H}_k \approx \operatorname{diag}(G_k^{(1)}/k,\ldots,G_k^{(d)}/k)$, which equals the
true Hessian diagonal only when the Hessian eigenvectors are axis-aligned.  For the Rosenbrock
function at $x^{\star} = (1,1)$:
\[
  H = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
  \quad \text{eigenvectors approximately } (2,-1)/\sqrt{5}\text{ and }(1,2)/\sqrt{5},
\]
which are strongly off-axis (angle $\approx 27°$ from the coordinate axes).  The diagonal
approximation $\hat{H} = \operatorname{diag}(802, 200)$ ignores the off-diagonal coupling
$H_{12} = -400$; the effective condition number after Adagrad preconditioning is
$\kappa(\hat{H}^{-1/2} H \hat{H}^{-1/2}) = \lambda_{\max}/\lambda_{\min}$ of the
\emph{symmetrised preconditioned matrix}, which remains $O(\sqrt{\kappa})$ rather than $1$ (as
it would under the optimal Newton preconditioner $H^{-1/2}$).  This is why Adagrad ($f = 2.20$)
substantially underperforms Newton ($f = 0.686$) on Benchmark~C: diagonal preconditioning
reduces ill-conditioning but cannot eliminate it when curvature is off-diagonal.  Methods with
full-matrix adaptivity (natural gradient, L-BFGS) would achieve the $O(1)$ effective condition
number, but at $O(d^2)$ memory cost.
\end{remark}

\subsubsection{RMSprop}

RMSprop replaces Adagrad's cumulative sum with an exponential moving average (EMA) of squared
gradients, preventing the effective learning rate from decaying to zero. With decay $\beta = 0.9$,
the EMA has an effective \emph{window length} of $1/(1-\beta) = 10$ iterations: gradients from
more than $\sim 10$ steps ago contribute negligibly ($\beta^{10} = 0.9^{10} \approx 0.35$). This
means RMSprop adapts to the recent local curvature rather than all historical curvature, enabling
continued learning on non-stationary functions where Adagrad would stall.

The practical consequence is that RMSprop's effective step size $\alpha_0/\sqrt{v_k + \varepsilon}$
is approximately \emph{stationary} in the long run: once $v_k$ converges to its equilibrium
value (the local expected squared gradient magnitude), the step remains near $\alpha_0/\sqrt{\mathbb{E}[g^2]}$.
This is a feature on non-stationary problems (sustained learning rate) but a limitation on
stationary ones where Adagrad's monotone decay is necessary for fine convergence.
On the Rosenbrock function (Benchmark~C), the gradient magnitude \emph{decreases} as the
iterate approaches the minimum: $\|\nabla f(x_k)\| \sim O(\|x_k - x^{\star}\|)$ near $x^{\star}$.
RMSprop's EMA forgets the large early gradients within $\sim 10$ steps, so its effective step
$\alpha_0/\sqrt{v_k}$ can \emph{increase} as the iterate nears the minimum (since $v_k$
drops with the recent gradients), risking overshoot.  Adagrad's cumulative sum $G_k$ grows
monotonically, ensuring the step can only decrease --- providing a built-in stability guarantee
that the EMA cannot match.  This is why Adagrad ($\alpha_0 = 0.45$, $f = 2.20$) requires a
much larger base rate than RMSprop ($\alpha_0 = 0.0035$, $f = 3.12$) on Benchmark~C: the
large Adagrad base rate is ``safe'' because cumulative history prevents overshoot, while
RMSprop needs a small base rate to compensate for its volatile effective step.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsubsection{Heavy Ball (Polyak Momentum)}

The Heavy Ball method augments gradient descent with a momentum term that accumulates velocity
across iterations. The key intuition: in ill-conditioned problems, gradient descent zig-zags
across the narrow valley (gradients in the high-curvature direction cancel), while momentum
accumulates the consistent gradient components along the valley floor. Mathematically, the
velocity $z_k = \alpha \sum_{j=0}^{k} \beta^{k-j} \nabla f(x_j)$ is a discounted sum of
past gradients; consistent downhill directions accumulate while oscillating directions cancel
geometrically. This explains the $(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$ convergence rate: the
ratio improves from $\kappa$ to $\sqrt{\kappa}$ in the exponent.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

For a strongly convex quadratic $f$ with condition number $\kappa$, the optimal momentum
parameter and step size are $\beta^{\star} = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2$
and $\alpha^{\star} = \left(\frac{2}{\sqrt{\lambda_{\max}} + \sqrt{\lambda_{\min}}}\right)^2$,
yielding a convergence rate of $\rho = \frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1} < 1$, which
improves upon the $\frac{\kappa-1}{\kappa+1}$ rate of plain gradient descent.

\begin{remark}[Derivation of optimal Heavy Ball parameters]
For a quadratic objective, the Heavy Ball error $e_k = x_k - x^{\star}$ in coordinate $i$
satisfies a two-step recurrence with characteristic polynomial
$p(r) = r^2 - (1 + \beta - \alpha\lambda_i)r + \beta = 0$ (the product of roots is $\beta$ by
Vieta's formulae, and their sum is $1+\beta-\alpha\lambda_i$).  The spectral radius for
eigenvalue $\lambda_i$ is $\rho_i = \sqrt{\beta}$ when the discriminant is negative (complex
roots, product = $\beta$) and the larger real root otherwise.  The discriminant is
$\Delta_i = (1+\beta-\alpha\lambda_i)^2 - 4\beta$.  With the choice
$\alpha = 4/(\sqrt{\lambda_{\max}}+\sqrt{\lambda_{\min}})^2$ and
$\beta = \bigl((\sqrt{\lambda_{\max}}-\sqrt{\lambda_{\min}})/(\sqrt{\lambda_{\max}}+\sqrt{\lambda_{\min}})\bigr)^2$,
one can verify that $\Delta_i = 16(\lambda_{\min}-\lambda_i)(\lambda_{\max}-\lambda_i)/
(\sqrt{\lambda_{\max}}+\sqrt{\lambda_{\min}})^4 \leq 0$ for all
$\lambda_i \in [\lambda_{\min}, \lambda_{\max}]$, so roots are always complex with
$|r_{1,2}| = \sqrt{\beta}$.  The rate $\rho = \sqrt{\beta} =
(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$ is thus \emph{uniform} across all eigenvalues
simultaneously --- the elegant result of the minimax Chebyshev design.
\end{remark}

\begin{remark}[Scope of convergence guarantee: quadratics only]
A critical theoretical distinction between Heavy Ball and Nesterov (Section~\ref{sec:q2}) is
the \emph{scope} of their convergence guarantees.  The $\rho = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$
linear rate for Heavy Ball applies \emph{only to quadratic objectives} where the Hessian is
constant and the characteristic-polynomial analysis above is exact.  For general smooth strongly
convex functions with a varying Hessian, Heavy Ball is \emph{not} guaranteed to converge at
the accelerated rate and can even diverge on simple non-quadratic strongly convex problems
(counter-examples are known for one-dimensional functions of the form
$f(x) = \mu x^2/2 + g(x)$ where $g$ is smooth but oscillatory).  Nesterov acceleration, by
contrast, achieves $O(1/k^2)$ convergence for \emph{any} smooth convex function via the
Lyapunov energy argument that does not assume a fixed Hessian.  The lookahead evaluation at
$\tilde{x}_k = x_k + \beta_k z_k$ is precisely what enables this wider guarantee.  In
practice, Heavy Ball often achieves good convergence on non-quadratic problems (our experiment:
$f = 1.40$ vs $f = 3.51$ for plain GD on Rosenbrock, a substantial gain), but this is
problem-dependent and without the theoretical backing of the $(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$
rate in the non-quadratic setting.  For guaranteed acceleration on smooth convex functions,
Nesterov is the theoretically correct choice.
\end{remark}

\subsection{Comparative Analysis}
\label{ssec:q1_analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed on quadratic problems (A, B):} When $f^{\star}$ is accurately
  specified, Polyak is theoretically optimal for subgradient methods. On correctly configured
  methods, Adagrad and Heavy Ball match GD's final accuracy on Benchmarks~A and~B
  (Table~\ref{tab:q1_final}). For Benchmark~A the Hessian is approximately $H \approx I_2$, so
  $\kappa \approx 1$ and Eq.~\eqref{eq:gd_rate} predicts essentially geometric convergence to
  $J^{\star}$ in $O(1/\log(1/\varepsilon))$ steps, explaining why plain GD is highly competitive
  on this benchmark.

\item \textbf{Performance on ill-conditioned landscapes (C):} Polyak (with correct $f^{\star}$)
  converges fastest. Heavy Ball with $\beta = 0.86$ accumulates momentum in the valley direction
  and achieves $f = 1.40$ --- a $60\%$ improvement over GD's $f = 3.51$. With condition number
  $\kappa \approx 2504$, the GD rate from Eq.~\eqref{eq:gd_rate} is
  $(\kappa-1)/(\kappa+1) \approx 0.9992$ per iteration --- fewer than $0.08\%$ improvement per
  step in the worst direction, requiring $\gg 1000$ iterations to converge. Heavy Ball's
  accelerated rate $(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1) \approx 0.961$ is geometrically faster.
  Adagrad's coordinate-wise adaptation helps navigate the different curvatures in $x_1$/$x_2$.

\item \textbf{Stability and plateauing:} GD is the most stable but slowest. Polyak is unstable
  when $f^{\star}$ is misspecified. Adagrad is uniformly stable due to monotonically decreasing
  steps (Algorithm~\ref{alg:adagrad}). On Benchmark~C, Adagrad ($f = 2.20$) outperforms
  RMSprop ($f = 3.12$) despite RMSprop being generally considered more adaptive: on the
  Rosenbrock trajectory, the gradient magnitude decreases substantially as the iterate enters
  the valley from the initial steep descent. Adagrad's cumulative sum $G_k$ correctly reflects
  this history, giving a step size that decreases monotonically and remains compatible with
  descent throughout. RMSprop's exponential average (window $\approx 10$ iterations) reacts
  too quickly --- once the gradient magnitude drops, the effective step $\alpha_0/\sqrt{v_k}$
  grows abruptly (since $v_k$ forgets the large initial gradients), potentially overshooting
  and causing oscillation in the narrow valley. The required base rate ($\alpha_0 = 0.0035$
  for RMSprop vs $\alpha_0 = 0.45$ for Adagrad) reflects this: RMSprop needs a much smaller
  base rate to prevent instability, leaving less room for progress.

\item \textbf{Practical considerations:} In real machine learning applications, $f^{\star}$ is
  almost never known exactly, which severely limits the applicability of the Polyak step
  (Algorithm~\ref{alg:polyak}). RMSprop (Algorithm~\ref{alg:rmsprop}) and Adam
  (Section~\ref{sec:q2}) are preferred in practice due to their robustness to $f^{\star}$
  uncertainty combined with adaptive per-coordinate scaling.
\end{itemize}

\subsection{Algorithm Formulations}

\subsubsection{Nesterov Accelerated Gradient}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The fundamental distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at
the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$. This lookahead
step can be interpreted as evaluating the gradient at the point we expect to reach \emph{after}
applying the current momentum, allowing the method to ``look before it leaps'' and correct its
trajectory proactively rather than reactively. The adaptive schedule $\beta_k = (k-1)/(k+2)$
(capped at $\beta_{\max}$) has the theoretical property:

\begin{theorem}[Nesterov, 1983]
For a convex function $f$ with Lipschitz-continuous gradient (Lipschitz constant $L$), the
Nesterov accelerated gradient method with step size $\alpha \leq 1/L$ achieves:
\[
  f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2},
\]
which is optimal among first-order methods, in contrast to the $O(1/k)$ rate of
gradient descent.
\end{theorem}

\begin{remark}[Optimality of the $O(1/k^2)$ rate]
The $O(1/k^2)$ rate is \emph{information-theoretically optimal}: Nesterov also proved a
matching lower bound showing that no first-order method (using only values and gradients) can
achieve $f(x_k) - f^{\star} = o(L\|x_0 - x^{\star}\|^2 / k^2)$ for all smooth convex $f$.
This means gradient descent's $O(1/k)$ rate is not an accident of its design --- it is
provably suboptimal, and acceleration to $O(1/k^2)$ is the best achievable. The
specific schedule $\beta_k = (k-1)/(k+2)$ (equivalently, the momentum sequence
$\lambda_{k+1} = (1 + \sqrt{1 + 4\lambda_k^2})/2$ in Nesterov's original parameterisation)
is derived from a Lyapunov energy argument: the sequence
$E_k = \alpha(f(x_k) - f^{\star}) + \frac{1}{2}\|v_k - x^{\star}\|^2$ (where $v_k$ is
an auxiliary sequence) is shown to satisfy $E_{k+1} \leq (1 - \lambda_{k+1}^{-1}) E_k$,
yielding the $O(1/k^2)$ recursion. The intuition is that momentum ``builds up a credit'' by
taking slightly over-eager steps that would be suboptimal for a single gradient step, but
which yield a better sequence of iterates than myopic descent.
\end{remark}

\begin{remark}[Strongly convex case: linear rate with fixed momentum]
For $\mu$-strongly convex, $L$-smooth $f$, Nesterov achieves the optimal
\emph{linear} convergence rate by switching to a constant momentum parameter:
$\beta = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$ (the same as the optimal Heavy Ball parameter),
yielding:
\[
  f(x_k) - f^{\star} \leq \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^{2k}
  \cdot \frac{L + \mu}{2}\|x_0 - x^{\star}\|^2,
  \quad \text{requiring } O\!\left(\sqrt{\kappa}\log\frac{1}{\varepsilon}\right) \text{ iterations.}
\]
This is the same $\sqrt{\kappa}$ dependence as Heavy Ball on quadratics, but now guaranteed for
\emph{any} smooth $\mu$-strongly convex function (not just quadratics).  The distinction
from Heavy Ball (Remark in Section~\ref{sec:q1}) is critical: both achieve the same
$(\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$ rate, but Nesterov's guarantee holds under curvature
variation (changing Hessian), while Heavy Ball's is only proved for constant Hessian.  For
Benchmark~C, $\kappa \approx 2504$, so the optimal strongly-convex Nesterov rate is
$\rho_{\rm opt} = (\sqrt{2504}-1)/(\sqrt{2504}+1) = (50-1)/(50+1) \approx 0.961$, predicting
$O(0.961^{2k})$ convergence in function value.  The observed Nesterov performance ($f = 0.479$
after 150 iterations starting from $f(x_0) = 4.0$) is qualitatively consistent with this
despite Rosenbrock's non-global-convexity: the theory is locally applicable once the
iterate enters the strongly convex neighbourhood of $x^{\star}$.
\end{remark}

\subsubsection{Adam Optimiser}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First-moment (mean) estimate}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second-moment (variance) estimate}
    \State $\hat{m}_t \gets m_t / (1 - \beta_1^t)$ \Comment{Bias-corrected mean}
    \State $\hat{v}_t \gets v_t / (1 - \beta_2^t)$ \Comment{Bias-corrected variance}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam can be understood as combining momentum (via $m_t$, analogous to Heavy Ball) with
per-coordinate adaptive scaling (via $v_t$, analogous to RMSprop). The bias-correction terms
$(1 - \beta_j^t)$ are critical in early iterations where $m_t$ and $v_t$ are initialised at
zero and would otherwise underestimate the true first and second moments.

\begin{remark}[Adam second-moment staleness on non-stationary landscapes]
With $\beta_2 = 0.999$, the effective memory window of $v_t$ is $1/(1-\beta_2) = 1000$
iterations. In the $T = 150$-iteration experiment, $v_T$ therefore averages squared gradients
over essentially \emph{all} 150 iterations: $v_{150} \approx (1-\beta_2)\sum_{t=1}^{150}g_t^2$.
For the Rosenbrock function, the gradient magnitude decreases substantially as the iterate
descends from $x_0=(-1,1)$ to the valley floor --- early gradients can be $10\times$ larger
than late ones. The sum $\sum g_t^2$ is dominated by the large early-iteration values, making
$v_{150}$ overestimate the current curvature, which forces a small effective step size in the
final iterations. Nesterov, by contrast, uses a fixed step $\alpha = 0.0007$ throughout and
accumulates momentum along the valley floor: a simpler structure that is better adapted to
the consistently downhill direction, explaining its $3\times$ lower final objective
($0.479$ vs $1.578$) despite Adam's richer per-coordinate information.
\end{remark}

\begin{remark}[Adam: convergence gap and AMSGrad fix]
Unlike Nesterov's accelerated gradient (which enjoys an $O(1/k^2)$ convergence guarantee on
smooth convex objectives), Adam does not have a general convergence guarantee in the
full-batch deterministic setting. Its regret bounds apply to the online/stochastic setting.
On deterministic smooth objectives, Nesterov is theoretically preferred; Adam's per-coordinate
scaling is particularly beneficial for deep learning with sparse or heterogeneous gradients.
The bias-correction terms $(1-\beta_j^t)$ are essential at small $t$: without them, the
effective step size in iteration~1 would be $\alpha m_1/(v_1^{1/2}+\varepsilon)$, where
$m_1 = (1-\beta_1)g_1$ and $v_1 = (1-\beta_2)g_1^2$, giving an inflated step
$\alpha(1-\beta_1)^{1/2}/(1-\beta_2)^{1/2} \cdot g_1/|g_1|$ that may overshoot drastically.
The bias correction effectively implements a learning-rate warm-up: the true step in iteration~$t$
scales as $\alpha\sqrt{1-\beta_2^t}/(1-\beta_1^t)$, which starts near zero and grows to $\alpha$
as $t$ increases --- the same warm-up schedule commonly used in Transformer training.

Reddi et al.\ (2018) showed a specific counter-example where Adam with $\beta_2$ close to 1
fails to converge due to the EMA second moment being too smooth (a single large gradient is
``forgotten'' too quickly, causing the step to grow non-monotonically).  Their fix, AMSGrad,
replaces the EMA $v_t$ with a running maximum: $\hat{v}_t \gets \max(\hat{v}_{t-1}, v_t)$,
which ensures the effective denominator $\sqrt{\hat{v}_t}$ is non-decreasing in each
coordinate.  Under this modification, the effective learning rate $\alpha/\sqrt{\hat{v}_t}$
is non-increasing, giving AMSGrad a convergence guarantee of $O(1/\sqrt{T})$ regret --- the
same as Adagrad.  AMSGrad is more conservative than Adam in practice and does not always
improve empirical performance, but closes the theoretical gap.
\end{remark}

\subsection{Mini-Batch Stochastic Gradient Descent}
\label{ssec:q2_sgd}

Mini-batch SGD on Benchmark~A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$,
50 epochs, with data indices randomly permuted at the start of every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\pi \in S_{m}$
    \For{each mini-batch $\mathcal{B}$ of size $b$ from permuted data}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^\top(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

With $m = 1000$ samples, batch size $b = 5$ yields $\lceil 1000/5 \rceil = 200$ updates per
epoch, whereas $b = 40$ yields $\lceil 1000/40 \rceil = 25$ updates per epoch. After 50
epochs, $b = 5$ has therefore completed $50 \times 200 = 10{,}000$ gradient steps while
$b = 40$ has completed only $50 \times 25 = 1{,}250$ --- an $8$-fold difference in update
count. This explains the faster per-epoch convergence of the small batch: it performs more
parameter updates in the same number of passes over the data. The gradient
variance for a mini-batch of size $b$ is $\mathrm{Var}[\hat{g}] = \sigma_g^2/b$ where
$\sigma_g^2 = \frac{1}{m}\sum_{i=1}^{m}\|\nabla \ell_i(\theta) - \nabla J(\theta)\|^2$ is the
per-sample gradient variance. Smaller $b$ increases variance by factor $40/5 = 8$, which
manifests as the greater oscillation visible near convergence in Figure~\ref{fig:q2_sgd_batch}.

The irreducible noise floor of mini-batch SGD scales as $O(\sigma_g^2/b \cdot \alpha)$: even at
convergence, each update shifts the iterate by $O(\alpha \sigma_g / \sqrt{b})$, preventing
convergence to the exact minimiser at fixed $\alpha$. Decaying $\alpha_k \to 0$ eliminates
the floor but slows convergence. This motivates \emph{variance-reduction methods} (SVRG,
SAGA) which combine per-sample updates with periodic full-gradient corrections, achieving
the exact linear rate of full GD at the cost of 2--3$\times$ more computation per epoch ---
the ideal combination of stochastic efficiency and deterministic convergence.

The implementation uses \emph{random shuffling without replacement} (Algorithm~\ref{alg:sgd}):
the $m$ data indices are permuted once per epoch, then each mini-batch is drawn sequentially
from this permutation.  This is superior to \emph{sampling with replacement} (iid draws),
because in a single epoch every data point is seen exactly once, distributing the information
content of the dataset uniformly.  Theoretical analysis shows that without-replacement SGD
converges as $O(1/(n^{2/3}T))$ (where $T$ is the number of epochs) compared to
$O(\sigma/\sqrt{T})$ for with-replacement, a subtle but practical advantage on finite datasets.

\begin{remark}[Variance reduction: SVRG and SAGA]
The $O(\sigma_g^2/b)$ variance floor of mini-batch SGD prevents convergence to the exact
minimiser at a fixed learning rate.  \emph{Variance-reduction methods} eliminate this floor by
augmenting each stochastic gradient with a periodic full-gradient correction.  SVRG (Johnson
\& Zhang, 2013) computes a full gradient $\nabla J(\tilde{\theta})$ once per epoch and uses the
estimator
\[
  \tilde{g}_t = \nabla \ell_{i_t}(\theta_t) - \nabla \ell_{i_t}(\tilde{\theta}) + \nabla J(\tilde{\theta}),
\]
which is unbiased ($\mathbb{E}[\tilde{g}_t] = \nabla J(\theta_t)$) and has variance
$\mathrm{Var}[\tilde{g}_t] = O(\|\theta_t - \tilde{\theta}\|^2)$ --- vanishing as $\theta_t \to x^{\star}$.
This control-variate structure is sufficient to prove linear convergence for $\mu$-strongly
convex, $L$-smooth objectives:
\[
  \mathbb{E}[J(\theta_T) - J^{\star}] \leq \rho^T\,(J(\theta_0) - J^{\star}),
  \qquad \rho = 1 - \frac{\mu}{10L},
\]
using $O\!\bigl((m + \kappa)\log(1/\varepsilon)\bigr)$ total gradient evaluations (where
$\kappa = L/\mu$), compared to $O(m\kappa\log(1/\varepsilon))$ for full-batch GD --- a factor
$m/\kappa$ saving when the dataset is large.  SAGA (Defazio et al., 2014) achieves the same
rate without epoch-level synchronisation by maintaining a table of $m$ per-sample gradients
and sampling a random variance-reduction update at each step, but requires $O(md)$ memory.
Both methods represent the natural theoretical completion of the SGD narrative: they achieve
the exact linear convergence rate of full-batch GD while retaining the per-sample iteration
cost of SGD, at the price of 2--3$\times$ more function evaluations per effective update.
\end{remark}

A practically important consequence of the noise-floor analysis is the \emph{linear scaling
rule}: to maintain the same noise floor when increasing batch size by factor $k$ (replacing
$b$ with $kb$), the learning rate should scale proportionally $\alpha \to k\alpha$. Since the
noise floor $\propto \alpha \sigma_g^2/b$, multiplying both $\alpha$ and $b$ by $k$ keeps the
floor constant. This rule --- widely used in large-scale distributed training (a system with
$K$ GPUs uses $\alpha_{\text{base}} \times K$ as the initial learning rate) --- has a validity
limit: when $k\alpha > 2/L$, the GD update itself becomes unstable. In practice a
learning-rate \emph{warm-up} schedule (linearly ramping $\alpha$ from 0 to $k\alpha$ over the
first few epochs) regularises this instability and is standard in Transformer and ResNet
training.

\subsection{Local Approximations of $g(x) = x^4$}
\label{ssec:q3_approx}

At expansion point $x_0 = 0.25$, the function values and derivatives are:
$g(x_0) = 0.25^4 = 3.906 \times 10^{-3}$,
$g'(x_0) = 4 \times 0.25^3 = 0.0625$,
$g''(x_0) = 12 \times 0.25^2 = 0.75$.

\textbf{First-order (Taylor) approximation:}
\begin{equation}
g(x) \approx \hat{g}_1(x;x_0) = g(x_0) + g'(x_0)(x - x_0) = 3.906\times10^{-3} + 0.0625(x - 0.25).
\end{equation}
The minimum of this linear model is unbounded (occurs as $x \to -\infty$), so a gradient step
with step size $\alpha$ yields $x_1 = x_0 - \alpha\, g'(x_0) = 0.25 - 0.0625\alpha$, which
depends on the choice of $\alpha$.

\textbf{Second-order (Newton) approximation:}
\begin{equation}
g(x) \approx \hat{g}_2(x;x_0) = g(x_0) + g'(x_0)(x-x_0) + \tfrac{1}{2}g''(x_0)(x-x_0)^2
= 3.906\times10^{-3} + 0.0625(x-0.25) + 0.375(x-0.25)^2.
\end{equation}
Minimising this quadratic model over $x$ yields the Newton update:
\begin{equation}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)} = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\end{equation}
This is the key motivation for Newton's method: the quadratic model captures curvature
information and allows a single-step minimiser to be computed analytically, whereas the linear
model requires multiple gradient steps with a manually tuned step size. The Newton step at
$x_0 = 0.25$ gives $x_1 = 0.1667$, whereas the true minimum of $g(x) = x^4$ is $x^{\star} = 0$.
The error $|x_1 - x^{\star}| = 0.1667$ vs $|x_0 - x^{\star}| = 0.25$ illustrates that we are
not yet in the ``quadratic convergence basin'' --- the quadratic model only approximates the
quartic well near $x_0$. Applying Newton again from $x_1 = 0.1667$:
$x_2 = 0.1667 - g'(0.1667)/g''(0.1667) = 0.1667 - 4(0.1667)^3/(12(0.1667)^2) = 0.1667 - 0.1667/3 \approx 0.111$,
with $|x_2 - x^{\star}|/|x_1 - x^{\star}|^2 \approx 0.111/0.0278 \approx 4 = M/(2\mu)$,
consistent with Eq.~\eqref{eq:newton_quad_conv} for the quartic $g$ with $\mu = g''(0) \to 0$
(degenerate; convergence is super-linear but slower than quadratic at $x^{\star} = 0$).

\subsection{Newton's Method}
\label{ssec:q3_newton}

\begin{algorithm}[H]
\caption{Newton's Method with Regularised Hessian}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian for positive definiteness}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The regularisation $\lambda = 10^{-8}$ ensures positive definiteness and numerical stability
when the Hessian is nearly singular. Newton's method achieves quadratic convergence near a
non-degenerate local minimum where the Hessian is Lipschitz-continuous:
\begin{equation}
\label{eq:newton_quad_conv}
\|x_{k+1} - x^{\star}\| \leq \frac{M}{2\mu}\,\|x_k - x^{\star}\|^2,
\end{equation}
where $\mu = \lambda_{\min}(\nabla^2 f(x^{\star}))$ is the smallest Hessian eigenvalue at the
optimum and $M$ is the Lipschitz constant of $\nabla^2 f$. The key geometric insight is that
the Newton direction $p_k = H_k^{-1}\nabla f(x_k)$ accounts for the curvature in all directions
simultaneously, effectively ``normalising'' the gradient by the local shape of the objective,
whereas gradient descent only uses the gradient direction and must compensate through step-size
tuning. This contrasts with the linear convergence rate
$\|x_{k+1} - x^{\star}\| \leq \rho\,\|x_k - x^{\star}\|$ ($\rho < 1$) of gradient descent,
where $\rho = (1 - 2\alpha\mu L/(\mu+L)^2)$ depends on the condition number.

\begin{remark}[Kantorovich convergence basin]
The quadratic rate \eqref{eq:newton_quad_conv} applies only inside the \emph{Newton
convergence basin} $\{x : \|x - x^{\star}\| < r\}$ where the Kantorovich radius is
$r := 2\mu/M$.  Inside this ball the contraction factor $(M/2\mu)\|x_k-x^{\star}\| < 1$
so errors square per step; outside, convergence (if it occurs) is at most linear and requires
globalisation via line search or trust region.  For the Rosenbrock function,
$\mu = \lambda_{\min}(\nabla^2 f(x^{\star})) \approx 0.40$.  The Lipschitz constant $M$ of
$\nabla^2 f$ is dominated by the $1200 x_1^2$ term: $\|\partial H_{11}/\partial x_1\| = 2400$
near $x^{\star}=(1,1)$, giving $r \approx 2 \times 0.40/2400 \approx 3.3 \times 10^{-4}$.
The starting point satisfies $\|x_0 - x^{\star}\| = \|(-2,0)\| = 2$, roughly $6000\times r$
outside the basin.  After 20 damped Newton steps the iterate reaches $\approx(0.183, 0.020)$
at distance $\approx 1.27$ from $(1,1)$ --- still thousands of times outside the
quadratic-convergence basin.  Therefore \emph{all 20 iterations} in this experiment operated
in the global convergence phase with the damped step, consistent with $f = 0.686$ remaining far
from $f^{\star} = 0$.  Full quadratic convergence on the Rosenbrock function would require a
backtracking line search or many more iterations to enter the basin near $(1,1)$.
\end{remark}

Hyperparameter settings (Table~\ref{tab:q3_params}): GD runs for 80 iterations; Newton runs
for 20 iterations. The damped step $\alpha < 1$ is used on Benchmarks~B and~C because the
rapidly varying Hessian means the full Newton step ($\alpha = 1$) may overshoot, putting the
iterate outside the convergence basin of the quadratic model. On the quadratic Benchmark~A,
the full Newton step is used ($\alpha = 1.0$): since $f$ \emph{is} the quadratic model, no
approximation error exists and $\alpha = 1$ gives the exact minimiser.

The choice $\alpha = 0.22$ for Benchmark~C (Rosenbrock) can be understood via the
\emph{Armijo condition}: choose the largest $\alpha$ such that
$f(x_k - \alpha p_k) \leq f(x_k) - c_1 \alpha \nabla f(x_k)^\top p_k$
for some $c_1 \in (0,1)$. For Rosenbrock, the Newton direction $p_k = H_k^{-1}\nabla f(x_k)$
points into the narrow valley, but the full Newton step can jump across the valley; a damped
step $\alpha \approx 0.22$ stays within the region where the quadratic approximation is valid,
allowing reliable descent at each iteration despite the non-quadratic structure.

\subsection{Convergence Comparison}
\label{ssec:q3_convergence}

\begin{proposition}[Newton's method on quadratic objectives]
\label{prop:newton_quadratic}
Let $J(\theta) = \frac{1}{2}\theta^\top H\theta - b^\top\theta + c$ with $H \succ 0$ and
$b = X^\top y / m$. The gradient is $\nabla J(\theta) = H\theta - b$. The Newton step with
$\alpha = 1$ gives:
\begin{equation}
\theta_1 = \theta_0 - H^{-1}\nabla J(\theta_0) = \theta_0 - H^{-1}(H\theta_0 - b) = H^{-1}b = \hat{\theta}_{\mathrm{OLS}},
\end{equation}
which is the exact minimiser in \textbf{one} iteration, regardless of the starting point
$\theta_0$ and the condition number of $H$.
\end{proposition}

On Benchmark~C, Newton converges to $(0.183, 0.020)$ after 20 iterations
(Table~\ref{tab:q3_final}) --- which is still well short of the global minimum $(1, 1)$.
This illustrates a known limitation of Newton's method on non-convex functions: it finds a
region of rapid curvature reduction but does not guarantee reaching the global minimum without
sufficient iterations or a backtracking line search. The issue is that for the Rosenbrock
function, the Hessian at $(-1, 1)$ has eigenvalues $\lambda_{\min} \approx 0.40$, $\lambda_{\max}

region of the valley; with damping $\alpha = 0.22$, each Newton step moves only $\approx 22\%$
of the way along this direction. Backtracking Armijo line search or trust-region methods would
adaptively choose $\alpha$ to make faster progress.
\end{remark}

\subsection{Part A: Finite Differences and Nesterov Random Search (Benchmark B)}
\label{ssec:q4a}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with a secant:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\quad e_i \text{ the $i$-th canonical basis vector.}
\end{equation}
This requires $d + 1$ function evaluations per gradient estimate (one base evaluation plus one
perturbed evaluation per coordinate). The approximation error decomposes into two competing terms:
\begin{equation}
\left|\frac{f(x + \delta e_i) - f(x)}{\delta} - \frac{\partial f}{\partial x_i}(x)\right|
\leq \underbrace{\frac{\delta}{2}\left|\frac{\partial^2 f}{\partial x_i^2}(x)\right|}_{\text{truncation error }O(\delta)}
+ \underbrace{\frac{2\varepsilon_{\mathrm{mach}}}{\delta}}_{\text{rounding error }O(\varepsilon/\delta)}.
\end{equation}
The optimal $\delta$ minimises the sum of the two competing error terms. Setting the derivative
of the total error bound equal to zero:
$\frac{\partial^2 f/\partial x_i^2}{2} - \frac{2\varepsilon_{\mathrm{mach}}}{\delta^2} = 0$,
giving $\delta^{\star} = (4\varepsilon_{\mathrm{mach}} / |f''|)^{1/2} \sim \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}$
(assuming $|f''| = O(1)$). At this optimal $\delta$, both error terms are equal and the minimum
total error is $O(\varepsilon_{\mathrm{mach}}^{1/2}) \approx 10^{-8}$. For the central
difference approximation, $\delta^{\star} \sim \varepsilon_{\mathrm{mach}}^{1/3}$ due to the
$O(\delta^2)$ truncation error. In this experiment, $\delta = 0.05$ is $\sim 5 \times 10^6$
times larger than the forward-difference optimum but remains in the regime where truncation
($\sim 10^{-3}$) is acceptably small compared to gradient magnitudes ($\sim 10^{-1}$). The
poorly chosen $\delta = 0.8$ has truncation error $\approx 0.8/2 \times |f''| \approx 0.4$,
comparable to the gradient itself, causing visible degradation in Figure~\ref{fig:q4_fval_B}.

\begin{remark}[Bias propagation: how FD error affects GD convergence]
When GD uses the biased gradient estimate $\tilde{g}_k = \nabla f(x_k) + e_k$ with
constant bounded error $\|e_k\| \leq \varepsilon_g$, the iterate update becomes
$x_{k+1} = x_k - \alpha(\nabla f(x_k) + e_k)$.  For $\mu$-strongly convex $f$, applying
the triangle inequality to the contraction:
\[
  \|x_{k+1} - x^{\star}\| \leq (1 - \alpha\mu)\|x_k - x^{\star}\| + \alpha\varepsilon_g,
\]
so the iteration converges not to $x^{\star}$ but to a \emph{bias ball} of radius
$r^{\star} = \varepsilon_g / \mu$ (the fixed point of the right-hand side).  For $\delta = 0.05$
on Benchmark~B: the truncation error is $\varepsilon_g \approx \frac{\delta}{2}\max_i|f_{x_ix_i}|
\approx \frac{0.05}{2} \times 10 \approx 0.25$, while $\mu \approx 1$, giving
$r^{\star} \approx 0.25$.  The resulting terminal error in $f$ is
$f(x_{\infty}) - f^{\star} \approx \frac{\mu}{2}(r^{\star})^2 \approx 0.03$, which falls
within the observation noise floor of Benchmark~B ($J^{\star} \approx 0.48$) --- explaining
why good FD ($\delta = 0.05$) matches exact GD to visual accuracy in
Figure~\ref{fig:q4_fval_B}.  For $\delta = 0.8$, the ball radius grows to
$r^{\star} \approx 4/\mu \approx 4$, comparable to the function range itself, causing the
large terminal error visible for the poor FD case.  This analysis also quantifies the
\emph{optimal $\delta$ for a fixed step budget}: as $\delta$ decreases, $\varepsilon_g$ decreases
(smaller truncation error) but rounding error $2\varepsilon_{\rm mach}/\delta$ increases; the
bias ball radius is minimised at $\delta^{\star} \sim \sqrt{\varepsilon_{\rm mach}} \approx 10^{-8}$,
exactly the forward-difference optimum derived from the error balance.
\end{remark}

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates the directional derivative in a random direction $u_k$, using
only two function evaluations per iteration regardless of dimension. For smooth $f$:
\begin{equation}
\mathbb{E}_{u_k}[\hat{g}_k] = \frac{1}{d}\,\nabla f(x_k) + O(\delta^2),
\end{equation}
so the estimate is a scaled unbiased gradient direction (to leading order in $\delta$). The
scaling by $1/d$ means the effective step size per coordinate is $\alpha/d$ times smaller than
for exact GD, explaining why more iterations are needed in higher dimensions. For $d = 2$ this
penalty is modest, but for $d = 100$ the method requires $\sim 50\times$ more iterations than
FD GD. The cost is substantially higher variance than finite differences, requiring
more iterations to converge even for $d = 2$ (Algorithm~\ref{alg:nrs}).

\begin{remark}[Gaussian smoothing interpretation]
The expectation formula $\mathbb{E}[\hat{g}_k] = \frac{1}{d}\nabla f(x_k) + O(\delta^2)$
follows from interpreting $\hat{g}_k$ as a gradient of the \emph{Gaussian-smoothed} objective
$f_\delta(x) = \mathbb{E}_{u \sim \mathcal{U}(\mathbb{S}^{d-1})}[f(x + \delta u)]$, which
smooths $f$ over a sphere of radius $\delta$. One can show $\nabla f_\delta(x) = \frac{d}{\delta}\,\mathbb{E}_u[(f(x+\delta u)-f(x))\,u]$,
so $\hat{g}_k$ is an unbiased estimator of $\frac{1}{d}\nabla f_\delta(x_k)$, and
$\nabla f_\delta(x) = \nabla f(x) + O(\delta^2 / d)$ by Taylor expansion (the $O(\delta^2)$
smoothing bias). The variance of $\hat{g}_k$ is $\mathrm{Var}[\hat{g}_k] = O(\|\nabla f\|^2 / d)$
--- one factor of $1/d$ from the random projection and another from the sphere geometry ---
so the signal-to-noise ratio of the random search estimate is $O(1/\sqrt{d})$ relative to exact
GD, explaining the $O(d)$ iteration overhead. This smoothing viewpoint also explains why a
smaller $\delta$ reduces approximation error but increases variance in finite arithmetic.
\end{remark}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and
iteratively transforms it through four operations in order of preference:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move the worst vertex through the centroid of the
      remaining vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, try moving further.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection worsened, contract towards the
      centroid.
\item \textbf{Shrink} ($\sigma = 0.5$): contract all vertices towards the best vertex.
\end{enumerate}
No gradient information is required. Settings: initial simplex step $= 0.35$, iterations $= 160$.

\begin{remark}[Forward vs.\ central finite differences: optimal $\delta$ and error]
The total approximation error has different structure for the two FD formulas:
\begin{align*}
  \text{Forward:} &\quad \left|\frac{f(x+\delta e_i)-f(x)}{\delta} - \partial_i f\right|
    \leq \frac{|f''|}{2}\delta + \frac{2\varepsilon_{\rm mach}}{\delta},
  \quad \delta^{\star} = \sqrt{\frac{4\varepsilon_{\rm mach}}{|f''|}}\sim\sqrt{\varepsilon_{\rm mach}},
  \quad \varepsilon_{\rm total} \sim \varepsilon_{\rm mach}^{1/2};\\
  \text{Central:} &\quad \left|\frac{f(x+\delta e_i)-f(x-\delta e_i)}{2\delta} - \partial_i f\right|
    \leq \frac{|f'''|}{6}\delta^2 + \frac{\varepsilon_{\rm mach}}{\delta},
  \quad \delta^{\star} = \left(\frac{3\varepsilon_{\rm mach}}{|f'''|}\right)^{1/3}\sim\varepsilon_{\rm mach}^{1/3},
  \quad \varepsilon_{\rm total} \sim \varepsilon_{\rm mach}^{2/3}.
\end{align*}
For $\varepsilon_{\rm mach} \approx 10^{-16}$: forward achieves $\varepsilon_{\rm total}
\approx 10^{-8}$ while central achieves $\approx 10^{-10.7}$ --- an improvement of
$\sim 500\times$ in gradient approximation error per coordinate, at the cost of one extra
function evaluation per coordinate (central needs $2d$ vs.\ forward's $d+1$).  The central
formula uses $\delta^{\star} \approx (10^{-16})^{1/3} \approx 2 \times 10^{-6}$, whereas the
forward formula uses $\delta^{\star} \approx 10^{-8}$.  At the $\delta = 0.05$ used in this
experiment, both formulas are far from their $\varepsilon_{\rm mach}$-optimal $\delta$, operating
in the truncation-dominated regime where the forward error is $O(\delta) \approx 0.025$ per
component and the central error is $O(\delta^2) \approx 6 \times 10^{-4}$ --- already a
$40\times$ improvement for the central formula, explaining why central differences would give
significantly more accurate gradients at the same computational cost.
\end{remark}

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

\subsection{Problem Setup}
\label{ssec:q5_setup}

Minimise Benchmark~B subject to the constraint $x_1 \geq 0.5$, starting from the infeasible
point $x_0 = (0.2, 4.0)$. The feasible set is the half-space
$\mathcal{F} = \{x \in \mathbb{R}^2 : x_1 \geq 0.5\}$.

\begin{remark}[KKT Analysis]
The unconstrained minimum of Benchmark~B is at $x^{\star} \approx (0.582, 2.0)$, which satisfies
$x_1^{\star} = 0.582 > 0.5$. Therefore the constraint $x_1 \geq 0.5$ is \emph{inactive} at the
optimum: the constrained and unconstrained minima coincide. This can be verified via the
Karush--Kuhn--Tucker (KKT) conditions: at $x^{\star}$, the constrained minimum satisfies
$\nabla f(x^{\star}) + \mu(-e_1) = 0$ for some Lagrange multiplier $\mu \geq 0$, i.e.,
$\nabla f(x^{\star})_1 = \mu$. At $x^{\star} = (0.582, 2.0)$:
$\nabla f(x^{\star})_1 = 2(0.582 - 1) + \cos(0.582) \approx 2(-0.418) + 0.836 \approx 0$.
Since the unconstrained gradient is already zero in the $x_1$ direction, $\mu = 0$ and
complementary slackness $\mu(x_1^{\star} - 0.5) = 0$ is satisfied trivially. The constraint
does not affect the gradient at the optimum --- it is inactive.

The challenge is therefore one of \emph{constraint handling during the iterative process}:
both methods must ensure feasibility is maintained or recovered even though the starting point
$(0.2, 4.0)$ is infeasible. The dual variable $\mu$ could be non-zero during the transient
phase even though it vanishes at the optimum; penalty methods implicitly track this via the
penalty gradient $-\lambda e_1$ when $x_1 < 0.5$.

\begin{remark}[Slater's condition and strong duality]
The KKT conditions derived above are \emph{necessary} for optimality only under a
\emph{constraint qualification} (CQ).  The relevant CQ here is \emph{Slater's condition}:
there exists a strictly feasible point, i.e.\ $\hat{x}$ with $\hat{x}_1 > 0.5$.  Indeed,
$\hat{x} = (1.0, 2.0)$ satisfies $\hat{x}_1 = 1 > 0.5$, so Slater's condition holds.
Slater's condition implies two important consequences: (i)~\emph{strong duality} --- the
Lagrangian dual $d(\mu) = \min_{x} \{f(x) - \mu(x_1 - 0.5)\}$ achieves $d(\mu^{\star}) =
f(x^{\star})$ with zero duality gap; (ii)~the KKT conditions are also \emph{sufficient} for
global optimality (since $f$ is convex).  Specifically, $x^{\star} = (0.582, 2.0)$ and
$\mu^{\star} = 0$ satisfy KKT, and no other point can be optimal because any feasible
$x \neq x^{\star}$ satisfies $f(x) > f(x^{\star})$ by strict convexity of $f$ in the
feasible region.  Without a CQ (e.g., if the feasible region were
$\{x_1^2 \leq 0$, impossible\}), KKT conditions need not hold at a constrained minimum.
The linear constraint $x_1 \geq 0.5$ is always a linear CQ, so Slater's condition is
equivalent to feasibility of the interior, which clearly holds here.
\end{remark}

A key advantage of the \emph{augmented Lagrangian method} over plain penalty is this: the
dual variable update $\mu \leftarrow \mu + \lambda h(x_k)$ (where $h(x) = \max(0, 0.5-x_1)$)
performs gradient ascent on the Lagrangian dual $d(\mu) = \min_x \mathcal{L}_\lambda(x,\mu)$.
Since $d$ is concave, $\mu$ converges to the optimal KKT multiplier $\mu^{\star} = 0$ for a
fixed moderate $\lambda$, eliminating the need for $\lambda \to \infty$. In this problem,
since the constraint is inactive ($\mu^{\star} = 0$), the augmented Lagrangian reduces to the
plain penalty after a few dual updates --- but for active constraints the multiplier update
would provide substantial computational savings over increasing $\lambda$ to large values.
\end{remark}

\subsubsection{Projected Gradient Descent}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{F}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{F}}(z_{k+1})$ \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection onto the half-space $\{x_1 \geq 0.5\}$ is trivial: $\Pi_{\mathcal{F}}(z) =
(\max(0.5, z_1),\, z_2)^\top$. More generally, projection onto a convex set satisfies
$\|\Pi_{\mathcal{F}}(z) - x^{\star}\| \leq \|z - x^{\star}\|$ for any $x^{\star} \in \mathcal{F}$,
which is the \emph{non-expansiveness} property that ensures convergence of projected GD at rate $O(1/k)$
for convex $f$. Projected GD can be seen as a special case of the \emph{proximal gradient}
method: defining the indicator function $\iota_{\mathcal{F}}(x) = 0$ if $x \in \mathcal{F}$,
$+\infty$ otherwise, and the proximal operator
$\mathrm{prox}_{\alpha \iota_{\mathcal{F}}}(z) = \arg\min_{x}\{\iota_{\mathcal{F}}(x) + \frac{1}{2\alpha}\|x-z\|^2\} = \Pi_{\mathcal{F}}(z)$,
the projected GD update $x_{k+1} = \Pi_{\mathcal{F}}(x_k - \alpha\nabla f(x_k))$ is exactly
$\mathrm{prox}_{\alpha \iota_{\mathcal{F}}}(x_k - \alpha \nabla f(x_k))$. This proximal
framework generalises to regularised objectives via a unified algorithmic recipe: replace
the indicator $\iota_{\mathcal{F}}$ with any closed convex regulariser $r(x)$, and the
projected GD step becomes the \emph{proximal gradient} step
$x_{k+1} = \mathrm{prox}_{\alpha r}(x_k - \alpha\nabla f(x_k))$
where $\mathrm{prox}_{\alpha r}(z) = \arg\min_x\{r(x) + \frac{1}{2\alpha}\|x-z\|^2\}$.
The canonical example is the LASSO: $\min_x\{\frac{1}{2}\|Ax - b\|^2 + \lambda\|x\|_1\}$.
Here $f(x) = \frac{1}{2}\|Ax-b\|^2$ (gradient $A^\top(Ax-b)$, $L$-smooth with $L=\lambda_{\max}(A^\top A)$)
and $r(x) = \lambda\|x\|_1$ with proximal operator the \emph{soft-thresholding}:
\[
  \bigl(\mathrm{prox}_{\alpha\lambda\|\cdot\|_1}(z)\bigr)_i
  = \mathrm{sign}(z_i)\,\max(|z_i| - \alpha\lambda,\; 0),
  \quad i = 1, \ldots, d.
\]
This coordinate-wise shrinkage zeros out small components (enforcing sparsity) and shrinks
large ones by $\alpha\lambda$.  The proximal gradient algorithm applied to LASSO achieves
$O(1/k)$ convergence (convex case) or $O(\rho^k)$ with $\rho = 1 - \mu/L$ (strongly convex
case via LASSO's restricted strong convexity), providing the same convergence guarantee as
projected GD but for the broader class of composite (smooth $+$ non-smooth) objectives.
This framework --- smooth loss $+$ proximal-friendly regulariser --- unifies projected GD,
LASSO, group LASSO, nuclear norm minimisation, and all other ``prox-friendly'' formulations
into a single algorithmic paradigm.

\begin{proposition}[Projected GD convergence]
\label{prop:pgd_convergence}
Let $f$ be $L$-smooth and convex over a closed convex set $\mathcal{F}$.  The projected
gradient descent iterate $x_{k+1} = \Pi_{\mathcal{F}}(x_k - \alpha\nabla f(x_k))$ with
$\alpha = 1/L$ satisfies:
\begin{equation}
  f(x_k) - f^{\star} \leq \frac{\|x_0 - x^{\star}\|^2}{2\alpha k} = \frac{L\|x_0 - x^{\star}\|^2}{2k},
\end{equation}
i.e., $O(1/k)$ convergence.  If $f$ is additionally $\mu$-strongly convex over $\mathcal{F}$,
then $f(x_k) - f^{\star} \leq (1 - \mu\alpha)^k(f(x_0) - f^{\star})$, i.e., linear convergence
at rate $\rho = 1 - \mu/L$.
\end{proposition}

The proof follows from the Euclidean projection's \emph{non-expansiveness}
$\|\Pi_{\mathcal{F}}(u) - \Pi_{\mathcal{F}}(v)\| \leq \|u - v\|$ and the $L$-smooth descent
lemma.  For Benchmark~Q5 with $\alpha = 0.08 < 1/L = 1/10 = 0.1$ (using $L \approx 10$,
the maximum Hessian eigenvalue of Benchmark~B at $x_0$), the strongly-convex rate is
$\rho \leq 1 - \mu \times 0.08 \leq 1 - 1.0 \times 0.08 = 0.92$, predicting convergence
to machine precision in $\approx 100/\log(1/0.92) \approx 120$ iterations --- consistent
with convergence by iteration 100 observed in Figure~\ref{fig:q5_fval}.

\subsubsection{Quadratic Penalty Method}

\begin{algorithm}[H]
\caption{Quadratic Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $\nabla F_{\lambda}(x_k) \gets \nabla f(x_k) - \lambda\,\mathbf{1}[x_1 < 0.5]\,e_1$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

For the constraint $x_1 \geq 0.5$, the penalty gradient adds $-\lambda e_1$ when $x_1 < 0.5$
(pushing $x_1$ upwards) and is zero otherwise. As $\lambda \to \infty$, the penalty method
converges to the constrained solution, but larger $\lambda$ requires smaller step sizes to
maintain stability.

\begin{remark}[Ill-conditioning from large penalty weights]
In the infeasible region $x_1 < 0.5$, the penalised Hessian picks up an extra $\lambda$ in
the $(1,1)$ entry (the penalty gradient $-\lambda e_1$ contributes a constant force, so its
derivative in $x_1$ is $+\lambda$ once the subdifferential is taken across the boundary):
\[
  \nabla^2 F_\lambda(x)\big|_{x_1 < 0.5}
  = \operatorname{diag}(2 - \sin(x_1) + \lambda,\; 10).
\]
The condition number in the infeasible region becomes
$\kappa(F_\lambda) \approx (2 - \sin(x_1) + \lambda)/\min(2-\sin(x_1), 10)$.
For $\lambda = 0.15$: $\kappa \approx 1.65/1.0 = 1.65$; for $\lambda = 4.5$:
$\kappa \approx 5.5/2.0 = 2.75$ (eigenvalues $\approx 5.5$ and $2$); for $\lambda \to \infty$:
$\kappa \to \lambda/10 \to \infty$.  This $O(\lambda)$ ill-conditioning forces the step size to
satisfy $\alpha < 2/\lambda_{\max}(F_\lambda) \approx 2/(\lambda + 3)$, explaining the reduced
$\alpha = 0.03$ for $\lambda = 4.5$ compared to $\alpha = 0.08$ for unconstrained GD
(Table~\ref{tab:q5_params}).  The augmented Lagrangian method avoids this by performing dual
variable updates $\mu \leftarrow \mu + \rho h(x_k)$ at a \emph{fixed} moderate $\rho$, so the
penalised Hessian condition number remains $O(1)$ while the dual variable converges to the
true KKT multiplier.  In the present problem, $\mu^{\star} = 0$ (inactive constraint), so
the augmented Lagrangian reduces to the plain penalty after a few updates --- but for active
constraints with $\mu^{\star} > 0$ the multiplier update provides substantial computational
benefit by eliminating the $\lambda \to \infty$ requirement.
\end{remark}

\subsection{Comparative Discussion}
\label{ssec:q5_discussion}

\textbf{Projected Gradient Descent} enforces feasibility as a hard constraint at every iteration.
Its key advantage is that all iterates $x_k \in \mathcal{F}$, which is critical in settings where
infeasible points are physically meaningless or computationally problematic. For convex
$f$ and convex $\mathcal{F}$, projected GD converges at rate $O(1/k)$ (convex case) or
$O(\rho^k)$ (strongly convex case), matching plain GD up to constants. The cost is the need
for a projection oracle; here $\Pi_{\mathcal{F}}(z) = (\max(0.5, z_1), z_2)^\top$ is trivial
($O(1)$ operations), but for general convex sets such as the Lorentz cone or nuclear norm ball
the projection itself is a non-trivial second-order cone programme.

\textbf{Penalty methods} avoid explicit projection by modifying the objective. The penalty
weight $\lambda$ controls the trade-off: small $\lambda$ gives smoother landscapes and allows
larger step sizes but enforces the constraint weakly; large $\lambda$ enforces the constraint
tightly but introduces a stiff additive term requiring smaller step sizes (hence $\alpha = 0.03$
vs $\alpha = 0.05$ for $\lambda = 4.5$ vs $\lambda \leq 1.8$). In the limit $\lambda \to \infty$,
the sequence of penalty-method solutions converges to the constrained optimum. This motivates
the \emph{augmented Lagrangian method}: define
$\mathcal{L}_\lambda(x, \mu) = f(x) + \mu\,h(x) + \frac{\lambda}{2}\|h(x)\|^2$,
where $\mu$ is the Lagrange multiplier and $h(x) = \max(0, 0.5 - x_1)$ is the constraint
residual. By alternately minimising over $x$ and updating $\mu \leftarrow \mu + \lambda h(x)$,
the dual variable $\mu$ converges to the KKT multiplier at a fixed moderate $\lambda$, eliminating
the need for $\lambda \to \infty$ and avoiding the ill-conditioning that makes large-$\lambda$
penalty methods slow to optimise. In this problem, since the constraint is inactive ($\mu = 0$),
the augmented Lagrangian reduces to the plain objective with no advantage over penalty --- the
benefit manifests for active constraints (e.g., $x_0 = (0.2, 4.0)$ starting infeasible and the
constraint remaining active if the minimum were below $x_1 = 0.5$).

\textbf{Choice between methods:} Projected GD is preferred when (a) the projection is cheap
and (b) the iterates must remain feasible at all times. Penalty methods are preferred when
(a) implementing a projection oracle is difficult or (b) a soft constraint (feasibility ``on
average'') is acceptable. The Frank--Wolfe algorithm (Question~6) offers a third option that
avoids both projection and explicit penalty terms, at the cost of slower $O(1/k)$ convergence.

\subsection{Feasible Set and Linear Programme}
\label{ssec:q6_lp}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} Minimise $f(x) = a^\top x$ with $a = [1, 2]^\top$ over $\mathcal{X}$.
Since $f$ is linear and $\mathcal{X}$ is a bounded polytope (box), the minimum is attained at a
vertex. For a box, the minimising vertex is obtained by choosing the lower bound for each
coordinate where $a_i > 0$ and the upper bound where $a_i \leq 0$. Since $a_1 = 1 > 0$ and
$a_2 = 2 > 0$:
\begin{equation}
x^{\star}_{\mathrm{LP}} = (0.5,\, -5), \qquad f^{\star}_{\mathrm{LP}} = 1 \times 0.5 + 2 \times (-5) = -9.5.
\end{equation}
This illustrates the \emph{fundamental theorem of linear programming}: the minimum of a linear
objective over a bounded convex polytope is always attained at a vertex (extreme point). In
general, for a $d$-dimensional box, there are $2^d$ vertices to check, but for a box constraint
the LMO reduces to choosing per-coordinate bounds in $O(d)$ operations (coordinate-separable
structure). This efficiency is precisely what makes Frank--Wolfe practical on box constraints
and is why the LMO can be cheaper than the projection even in moderate dimensions.

\subsection{Frank--Wolfe (Conditional Gradient) Algorithm}
\label{ssec:q6_fw}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) with Fixed Mixing}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^\top x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Fixed convex combination}
\EndFor
\end{algorithmic}
\end{algorithm}

The key property of Frank--Wolfe is that iterates $x_{k+1} = \beta x_k + (1-\beta) z_k$ are
always convex combinations of feasible points ($x_k, z_k \in \mathcal{X}$), so $x_{k+1} \in \mathcal{X}$
by convexity of $\mathcal{X}$ --- \emph{without any projection step}. This is advantageous when
the projection onto $\mathcal{X}$ is expensive (e.g., the nuclear norm ball or spectrahedron) but
the linear minimisation oracle (LMO) is cheap.

For the box $\mathcal{X}$, the LMO decomposes per coordinate in $O(d)$ operations:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0. \end{cases}
\end{equation}

\begin{theorem}[Frank--Wolfe convergence rate, Frank \& Wolfe 1956]
\label{thm:frankwolfe}
For a smooth convex objective $f$ with $L$-Lipschitz gradient over a bounded convex set
$\mathcal{X}$ (diameter $D = \max_{x,y \in \mathcal{X}} \|x - y\|$), the standard Frank--Wolfe
algorithm with step sizes $\gamma_k = 2/(k+2)$ (equivalently $\beta_k = k/(k+2)$) achieves:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2LD^2}{k+2} = O(1/k).
\end{equation}
\end{theorem}

\begin{remark}[Proof sketch via one-step recursion]
Let $h_k = f(x_k) - f^{\star}$.  Two key facts: (i) since $z_k$ minimises $\nabla f(x_k)^\top z$
over $\mathcal{X}$ and $x^{\star} \in \mathcal{X}$, convexity of $f$ gives
$\nabla f(x_k)^\top(z_k - x_k) \leq \nabla f(x_k)^\top(x^{\star}-x_k) \leq -h_k$;
(ii) $\|z_k - x_k\| \leq D$ by definition of $D$.  Applying $L$-smoothness to
$x_{k+1} = (1-\gamma_k)x_k + \gamma_k z_k$:
\[
h_{k+1} \leq h_k + \gamma_k \nabla f(x_k)^\top(z_k-x_k) + \tfrac{L\gamma_k^2 D^2}{2}
\leq (1-\gamma_k)h_k + \tfrac{L\gamma_k^2 D^2}{2}.
\]
Inductively assuming $h_k \leq 2LD^2/(k+2)$ and setting $\gamma_k = 2/(k+2)$:
\[
h_{k+1} \leq \tfrac{k}{k+2}\cdot\tfrac{2LD^2}{k+2} + \tfrac{2LD^2}{(k+2)^2}
= \tfrac{2LD^2 k}{(k+2)^2} \leq \tfrac{2LD^2}{k+3},
\]
where the last step uses $k/(k+2)^2 \leq 1/(k+3)$, i.e., $k(k+3) \leq (k+2)^2$ (always true).
This completes the induction and shows that $\gamma_k = 2/(k+2)$ is \emph{precisely calibrated}
to the $O(1/k)$ recursion --- other fixed-step schedules do not achieve this rate.
\end{remark}

In this implementation a fixed $\beta$ is used instead of the diminishing schedule --- a heuristic
variant that can converge faster initially but does not provide the $O(1/k)$ guarantee and
introduces residual oscillation near the optimum. For the box $\mathcal{X}$ here,
$D = \|(5 - 0.5, 10 - (-5))\| = \|(4.5, 15)\| \approx 15.66$.

\subsection{Interior vs Boundary Behaviour}
\label{ssec:q6_analysis}

\textbf{Interior optimum:} Frank--Wolfe converges, but the $O(1/k)$ rate is slow relative to
gradient-based methods. Near the interior optimum, the gradient $\nabla f(x_k)$ is small and
changes direction frequently, causing the LMO vertex $z_k$ to jump between multiple vertices of
$\mathcal{X}$. The fixed $\beta$ schedule prevents the step size from decaying, introducing a
residual oscillation that limits precision. The standard diminishing schedule $\gamma_k = 2/(k+2)$
eliminates this issue.

\textbf{The Frank--Wolfe gap} provides a practical convergence certificate that does not require
knowledge of $f^{\star}$. At each iterate $x_k$, the FW gap is defined as:
\begin{equation}
g_k := \max_{z \in \mathcal{X}} \nabla f(x_k)^\top (x_k - z) = \nabla f(x_k)^\top(x_k - z_k),
\end{equation}
where $z_k$ is the LMO solution. Since $f$ is convex, $g_k \geq f(x_k) - f^{\star} \geq 0$,
so $g_k$ upper-bounds the optimality gap. The Frank--Wolfe convergence theorem implies
$g_k = O(1/k)$, providing a stopping criterion that is computable at each iteration without
knowing $f^{\star}$ --- a significant practical advantage over methods that require the
optimal value.  Moreover, $g_k = 0$ if and only if $x_k$ is a \emph{first-order stationary
point} of the constrained problem: $g_k = 0 \Leftrightarrow \min_{z \in \mathcal{X}}\nabla f(x_k)^\top z
= \nabla f(x_k)^\top x_k \Leftrightarrow \nabla f(x_k)^\top(z - x_k) \geq 0\ \forall z \in \mathcal{X}$,
which is the constrained first-order optimality condition (the analogue of $\nabla f = 0$
for unconstrained problems).  For convex $f$ this condition is also sufficient for global
optimality.  In code, computing $g_k$ requires only the gradient (already computed for the
gradient step) and the LMO solution (already computed for the iterate update), adding zero
overhead to the Frank--Wolfe iteration.

For the interior objective $f(x) = (x_1-1)^2 + (x_2-5)^2$, the mechanism behind the LMO
oscillation near $x^{\star} = (1,5)$ can be traced precisely: the gradient
$\nabla f(x_k) = 2(x_k - x^{\star})$ is small and its components can change sign when $x_k$
crosses $x^{\star}$ coordinate-wise.  The LMO then jumps discontinuously between boundary
vertices: $(z_k)_i = l_i$ if $(\nabla f)_i > 0$ else $u_i$, so $(z_k)_1$ alternates between
$0.5$ and $5$ whenever $(x_k)_1$ oscillates around $1$.  With fixed $\beta = 0.90$, each
such jump displaces $x_k$ by $(1-\beta)|z_k - x_k| \approx 0.10 \times 4.5 \approx 0.45$
in $x_1$ alone --- a substantial step relative to the sub-unit distance from $x^{\star}$.
The FW gap at such an iterate satisfies
$g_k = \nabla f(x_k)^\top(x_k - z_k) \approx 2(x_k-x^{\star})^\top(x_k-z_k) \approx 2\|x_k-x^{\star}\|
\cdot D$, which remains $O(1)$ despite $\|x_k - x^{\star}\|$ being small, because $\|x_k - z_k\| \approx D$
is large.  The standard schedule $\gamma_k = 2/(k+2)$ decays the step to zero, so each
LMO vertex switch contributes only $\gamma_k \cdot \|z_k - x_k\| \to 0$, resolving the
oscillation and achieving the $O(1/k)$ convergence guarantee.

\begin{remark}[Sparsity-inducing property and the away-step variant]
A key structural property of Frank--Wolfe is that iterates are \emph{sparse in the vertex
representation}.  The update $x_{k+1} = (1-\gamma_k)x_k + \gamma_k z_k$ shows $x_{k+1}$ is a
convex combination of $x_k$ and the LMO vertex $z_k$.  Unrolling the recursion from $x_0$:
$x_k \in \mathrm{conv}(\{x_0\} \cup \{z_j\}_{j < k})$, so after $k$ iterations the iterate
lies in the convex hull of at most $k+1$ points (the \emph{active set}).  For structured
constraint sets such as the $\ell_1$-ball $\|x\|_1 \leq r$ --- where LMO vertices are the
$2d$ scaled unit vectors $\pm r\,e_i$ --- this means $x_k$ has at most $k+1$ nonzero
coordinates: Frank--Wolfe \emph{automatically produces sparse solutions}, a highly desirable
property for feature selection, matrix completion, and compressed sensing problems where the
solution is known to be sparse.

However, the standard FW rate $O(1/k)$ is the same whether $f$ is convex \emph{or} strongly
convex, unlike projected GD which accelerates to $O(\rho^k)$ linear convergence for
$\mu$-strongly convex $f$.  The \emph{away-step Frank--Wolfe} closes this gap: at each step,
the algorithm selects either a \emph{towards step} (moving towards the LMO vertex $z_k$, as
in standard FW) or an \emph{away step} (moving away from the \emph{worst} active-set atom
$s_k = \arg\max_{s \in \mathcal{S}_k} \nabla f(x_k)^\top s$), choosing whichever gives more
descent.  For $\mu$-strongly convex $f$, away-step FW achieves:
\[
  f(x_k) - f^{\star} \leq \left(1 - \frac{\mu\,\delta(\mathcal{X})^2}{4L\,D^2}\right)^k (f(x_0) - f^{\star}),
\]
where $\delta(\mathcal{X})$ is the \emph{pyramidal width} of $\mathcal{X}$ (a geometric constant
measuring how ``spread out'' the vertices are).  The cost is maintaining and updating the
active-set $\mathcal{S}_k$, adding $O(|\mathcal{S}_k|)$ overhead per iteration, but the
method remains projection-free while recovering the linear convergence rate of projected GD.
\end{remark}

\textbf{Boundary optimum:} Frank--Wolfe is particularly well-suited here. The LMO consistently
selects the vertex closest to the unconstrained minimum (across the constraint boundary), pulling
the iterate towards $x^{\star}_{\mathrm{bnd}} = (0.5, 0)$. With 140 iterations and $\beta = 0.93$,
the boundary case has not fully converged ($f = 0.364$ vs $f^{\star} = 0.25$), suggesting more
iterations or a smaller $\beta$ are needed. The slow convergence ($f - f^{\star} = 0.114$
vs the $O(1/k)$ bound $2LD^2/(140+2) \approx 2 \times 2 \times 245/(142) \approx 6.9$) shows
the bound is loose in practice, as expected for a method-agnostic worst-case analysis.

\textbf{Comparison with projected GD (Q5):} Frank--Wolfe avoids projection entirely by
construction; projected GD always enforces feasibility but requires a projection oracle. For
constraints where projection is computationally cheap (box constraints here: $O(d)$ per step),
projected GD is preferable due to faster convergence. For constraints where projection is
expensive (e.g., the nuclear norm ball requires an SVD: $O(\min(m,n)^2\max(m,n))$) but the LMO
is cheap, Frank--Wolfe is the method of choice. This trade-off is central to modern optimisation
for matrix completion, semidefinite programming, and structured prediction.

  gradients alone cannot supply: $f(x_k) - f^{\star}$ quantifies how far the iterate is from
  optimal in function value, encoding implicit curvature information.  For $L$-smooth strongly
  convex $f$, the gradient-bound inequality $\|\nabla f(x)\|^2 \leq 2L(f(x)-f^{\star})$ implies
  $\alpha_k = (f-f^{\star})/\|\nabla f\|^2 \geq 1/(2L)$, guaranteeing the Polyak step is
  always at least as large as the standard GD step $1/(2L)$ --- the method automatically
  adjusts to the problem's smoothness without requiring knowledge of $L$.  On non-convex
  Rosenbrock, this self-calibration still works empirically: as $x_k$ approaches $x^{\star}$
  along the valley, $f(x_k) \to 0$ while $\|\nabla f\|$ decreases proportionally, keeping
  $\alpha_k$ at a useful scale throughout.  In this sense, knowing $f^{\star}$ is equivalent
  to possessing \emph{oracle access} to the remaining optimisation gap, a piece of information
  unavailable to pure gradient methods and explaining why Polyak outperforms every
  gradient-only method on Benchmark~C.

\begin{remark}[Convergence on non-convex landscapes: why theory and practice align]
All convergence rate guarantees in this report assume \emph{convexity} (at minimum, the PL
condition), yet Benchmark~C (the Rosenbrock function) is non-convex: it has a unique global
minimum at $(1,1)$ but the Hessian at general points is indefinite (negative eigenvalues exist
in regions around the curved valley).  Despite this, all first-order methods converge to the
global minimum empirically.  Three structural properties explain this alignment:

(i)~\textbf{No spurious local minima:} The Rosenbrock function has exactly one critical point
(the global minimum $(1,1)$) in $\mathbb{R}^2$ --- a classical result.  Any gradient descent
trajectory must converge to a critical point (by the descent lemma); with only one critical
point, convergence to the global minimum is guaranteed.

(ii)~\textbf{Saddle point escape:} The function does have saddle points in higher-dimensional
generalisations, but for $d=2$ the single critical point is a global minimum.  In general,
gradient descent avoids strict saddle points (where the Hessian has at least one negative
eigenvalue) with probability one from a random initialisation, due to the stable manifold
theorem; gradient noise in stochastic methods further accelerates saddle escape.

(iii)~\textbf{Coercivity:} The Rosenbrock function satisfies $f(x) \to \infty$ as
$\|x\| \to \infty$, so level sets $\{f \leq c\}$ are compact; combined with continuity,
this implies any converging trajectory must remain bounded and enter a compact region
containing the global minimum.

These structural properties mean that standard convergence theory --- applied with
$\mu = \lambda_{\min}(\nabla^2 f(x^{\star})) \approx 0.40$ and $L = \lambda_{\max}
\approx 1002$ near $x^{\star}$ --- qualitatively predicts the observed rates even outside
the convexity regime.
\end{remark}

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has investigated six families of optimisation algorithms on benchmark functions
covering a spectrum of difficulty. The main findings are summarised below.

\textbf{Adaptive step-size methods (Q1):} The Polyak step size achieves optimal convergence when
$f^{\star}$ is known exactly (Rosenbrock: $f = 0.009$) but diverges catastrophically when
$f^{\star}$ is misspecified. Adagrad and Heavy Ball are uniformly reliable alternatives. For
ill-conditioned landscapes, Heavy Ball's momentum accumulation provides a significant advantage
over constant step-size GD.

\textbf{Momentum and stochastic methods (Q2):} Nesterov acceleration outperforms all first-order
methods on the Rosenbrock function ($f = 0.479$, vs $f = 3.39$ for GD), validating the
theoretical $O(1/k^2)$ rate on challenging non-convex landscapes. Adam combines the benefits of
momentum and per-coordinate scaling, though its adaptive second moment can become stale when
curvature changes rapidly. In the stochastic setting, smaller batch sizes converge faster per
epoch at the cost of greater gradient noise.

\textbf{Newton's method (Q3):} Second-order information is transformative: Newton's method
converges in a single iteration on quadratic objectives (Proposition~\ref{prop:newton_quadratic})
and in a handful of iterations on near-quadratic functions. On the Rosenbrock function, even the
damped Newton step ($\alpha = 0.22$) achieves $f = 0.686$ in 20 iterations, compared to
$f = 3.73$ for GD in 80 iterations. The quadratic convergence rate
(Eq.~\ref{eq:newton_quad_conv}) explains this rapid improvement: once in the convergence
neighbourhood, the error squares with each iteration. The limitation is the $O(d^3)$ cost of
Hessian computation and inversion (via $\texttt{np.linalg.solve}$ in the implementation),
making Newton's method impractical for $d \gg 100$ without approximations (quasi-Newton, etc.).

\textbf{Derivative-free methods (Q4):} Finite-difference gradients with $\delta = 0.05$ closely
replicate exact GD at an additional cost of $d$ function evaluations per step. Large $\delta$
introduces truncation error that significantly degrades convergence. Nesterov random search
requires only 2 function evaluations per step but converges much more slowly due to the
single-direction gradient estimate. Notably, Nelder--Mead converges to $f < 10^{-5}$ on the
Rosenbrock function in just 160 iterations (Figure~\ref{fig:q4_dfree_comparison}), outperforming
all first-order methods tested; this reflects the simplex method's implicit curvature estimation
through simplex shape adaptation, even without gradient information.

\textbf{Constrained optimisation (Q5):} Projected gradient descent enforces feasibility as a
hard constraint from the very first iteration, while penalty methods trade exact feasibility for
simpler implementation. When the constraint is inactive at the optimum (as in this example), both
methods ultimately converge to the same solution, but projected GD does so while maintaining
feasibility throughout.

\textbf{Frank--Wolfe (Q6):} The Frank--Wolfe algorithm avoids explicit projection by replacing it
with a cheap linear minimisation oracle, maintaining feasibility automatically through convex
combinations. It achieves $O(1/k)$ convergence on convex smooth objectives
(Theorem~\ref{thm:frankwolfe}). The fixed-$\beta$ implementation exhibits significant residual
oscillation near the optimum: with $\beta = 0.90$ (10\% step towards LP vertex), the method
achieves $f = 0.0985$ after 200 iterations compared to $f = 0.0011$ for the standard diminishing
schedule $\gamma_k = 2/(k+2)$ (Figure~\ref{fig:q6_fw_step_comparison}). This directly validates
the importance of a decaying step size for fine convergence near the optimum.

The course has demonstrated that no single algorithm dominates across all problem types.
Understanding the mathematical structure of the objective --- its smoothness, convexity,
condition number, and constraint geometry --- is prerequisite to choosing the appropriate method.
The theoretical convergence rates ($O(1/k)$, $O(1/k^2)$, quadratic) provide principled guidance
that, as validated here, predicts empirical behaviour at least qualitatively even on non-convex
benchmarks.

\textbf{Outlook: quasi-Newton methods and beyond.} The experiments here are limited to $d = 2$;
practical machine learning operates in millions of parameters.  \emph{Quasi-Newton methods}
(most notably L-BFGS) bridge the gap between first-order ($O(d)$ per step) and Newton's
($O(d^3)$ per step) methods: they maintain a low-rank approximation of the inverse Hessian
built from the last $m$ gradient-difference pairs (typically $m \leq 20$), requiring $O(md)$
memory and $O(md)$ per-step arithmetic.  The BFGS update (the full-memory version from which
L-BFGS is derived) constructs a Hessian approximation $B_{k+1}$ satisfying the
\emph{secant equation} $B_{k+1} s_k = y_k$ (where $s_k = x_{k+1} - x_k$ and
$y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$) via the rank-2 update:
\begin{equation}
B_{k+1} = B_k - \frac{B_k s_k s_k^\top B_k}{s_k^\top B_k s_k} + \frac{y_k y_k^\top}{y_k^\top s_k}.
\end{equation}
This update preserves positive-definiteness (when $y_k^\top s_k > 0$, which holds under the
Wolfe line-search conditions) and satisfies the curvature information along the step direction
exactly.  Locally, L-BFGS achieves \emph{superlinear}
convergence --- faster than linear GD but without the quadratic guarantee of full Newton ---
making it the standard for smooth unconstrained problems up to $d \sim 10^6$
(\texttt{scipy.optimize.minimize(method=`L-BFGS-B')}).  For structured constraints, the
\emph{augmented Lagrangian method of multipliers} (ADMM) extends the penalty framework from
Question~5 to separable objectives by alternating between primal updates and dual variable
ascent, converging at $O(1/k)$ for general convex problems while preserving the problem's
separable structure.  These methods, together with the first- and second-order algorithms
studied here, form the complete toolkit needed to tackle the optimisation problems that arise
throughout modern data science.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Regularised Hessian}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
