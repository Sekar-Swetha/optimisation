\begin{abstract}
This report presents a comprehensive comparative study of optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark A, $\kappa \approx 1$), a toy neural network loss with sinusoidal perturbation (Benchmark B, $\kappa \approx 7$), and the Rosenbrock function (Benchmark C, $\kappa \approx 2000$). Six categories of methods are investigated: (1) adaptive step-size methods --- Polyak, Adagrad, RMSprop, and Heavy Ball; (2) momentum-based and stochastic methods --- Nesterov acceleration, Adam, and mini-batch SGD; (3) Newton's method with second-order local approximations; (4) derivative-free approaches --- finite differences, Nesterov random search, Nelder--Mead, and grid search; (5) constrained optimisation via projected gradient descent and penalty methods; and (6) the Frank--Wolfe conditional gradient algorithm for linear-constrained problems. Key numerical findings: Newton's method converges in one iteration on the quadratic benchmark and achieves $5.4\times$ better Rosenbrock accuracy than gradient descent in $4\times$ fewer iterations; Nesterov acceleration reduces the Rosenbrock objective from $3.39$ (GD) to $0.479$ in 150 iterations by exploiting the $O(\sqrt{\kappa})$ vs $O(\kappa)$ iteration advantage; projected gradient descent achieves zero constraint violation from iteration~1 while penalty methods with insufficient weight $\lambda$ leave residual violations; and the Polyak step size---optimal when $f^\star$ is known exactly (Rosenbrock: $f=0.009$)---diverges catastrophically when $f^\star$ is misspecified, reaching $f=24$ on the neural network benchmark. The Rosenbrock function ($\kappa \approx 2000$) consistently serves as the most discriminating benchmark, where algorithmic choice yields up to three orders of magnitude difference in final objective value.
\end{abstract}

\section{Introduction}

Optimisation is the mathematical foundation of modern machine learning and data analysis. Training a neural network, fitting a statistical model, or solving an inference problem all reduce to minimising an objective function, often subject to constraints. The choice of optimisation algorithm profoundly influences the speed, stability, and quality of the solution obtained.

This report investigates six families of gradient-based and derivative-free optimisation algorithms, each motivated by distinct theoretical principles. \textbf{Unified theoretical framework.} The six questions in this assignment are not isolated --- they each explore different strategies for overcoming the same fundamental challenge: optimising a possibly non-smooth, possibly constrained, possibly high-dimensional function with limited computational resources. The unifying principle is:
\begin{itemize}[nosep]
\item \textbf{Q1} (adaptive step-sizes): Overcome poor step-size tuning by exploiting gradient magnitude history. Polyak uses exact problem knowledge ($f^\star$); Adagrad and RMSprop use cumulative or exponential gradient history.
\item \textbf{Q2} (momentum/stochastic): Overcome slow GD convergence by accumulating directional information (Nesterov, Heavy Ball) or reducing per-step cost (SGD). Both approaches address the $O(\kappa)$ iteration bottleneck.
\item \textbf{Q3} (second-order): Eliminate $\kappa$-dependence entirely by exploiting Hessian information. Newton's $H^{-1}$ preconditioner makes the effective condition number $\kappa(H^{-1}H) = 1$ --- perfect conditioning.
\item \textbf{Q4} (derivative-free): Operate without any gradient information, approximating it via finite differences (adding $O(\delta)$ bias) or random projections (adding $O(d)$ slowdown factor).
\item \textbf{Q5} (constrained via hard/soft feasibility): Add feasibility requirements that interact with the condition number: projected GD maintains rate $O(1/k)$, penalty methods effectively increase $L$ by $\lambda$ but maintain $O(1/k)$ in the limit.
\item \textbf{Q6} (Frank--Wolfe): Decouple gradient steps from constraint enforcement by using a linear oracle, trading projection cost for a $O(1/k)$ convergence rate and a natural duality gap certificate.
\end{itemize}

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
The Hessian $H = \frac{1}{m}X^T X$ is constant and positive semi-definite. The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The smoothness constant equals the largest eigenvalue $L = \lambda_{\max}(H)$, and the strong convexity constant $\mu = \lambda_{\min}(H) > 0$ (almost surely for $m > 2$). Due to observation noise, the irreducible minimum is $J^{\star} \approx \sigma^2/2 \approx 0.4826$, not zero. Starting point: $\theta_0 = [0,\, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H(x) = \operatorname{diag}(2 - \sin(x_1),\ 10)$. Since $|\sin(x_1)| \leq 1$, the $x_1$-curvature lies in $[1, 3]$, giving a local condition number $\kappa \in [10/3, 10]$.

\textbf{Physical motivation of the sinusoidal term:} The quadratic base $(x_1-1)^2 + 5(x_2-2)^2$ represents a simple convex loss (e.g.\ mean squared error for a linear model). The $\sin(x_1)$ perturbation models the non-quadratic, non-convex nature of neural network losses arising from activation functions (e.g.\ sigmoid, $\tanh$, ReLU). The perturbation changes the effective curvature between $[1, 3]$ and can create local flat regions where $\frac{\partial^2 f}{\partial x_1^2} = 2 - \sin(x_1) \approx 1$ (when $\sin(x_1) \approx 1$). This makes Benchmark B more challenging than a pure quadratic while remaining tractable for all tested methods.

The minimum lies at approximately $(x_1^\star,\, x_2^\star) = (0.582,\, 2.000)$ with $f^\star \approx 0.7244$ (solving $2(x_1-1)+\cos(x_1)=0$ numerically). Starting point: $x_0 = [-1,\, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is $(1, 1)$ with $f^\star = 0$ \cite{rosenbrock1960}. The Hessian at $x^\star = (1,1)$ is:
\begin{equation}
\nabla^2 f(1,1) = \begin{bmatrix} 2 + 1200 - 400 & -400 \\ -400 & 200 \end{bmatrix} = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}.
\end{equation}
The eigenvalues are $\lambda_1 \approx 0.399$ and $\lambda_2 \approx 1001.6$, giving $\kappa(1,1) \approx 2508$. This extreme ill-conditioning, combined with the narrow curved valley along $x_2 = x_1^2$, makes the Rosenbrock function one of the most challenging standard test functions for first-order methods.

The valley structure means the gradient direction is \emph{nearly perpendicular} to the direction of steepest descent towards $x^\star$: along the valley floor (low curvature $\lambda_1 \approx 0.5$ direction), the gradient is small, while across the valley (high curvature $\lambda_2 \approx 1000$ direction), the gradient is large but points orthogonally to the desired progress. GD is therefore forced to take tiny steps to avoid crossing the valley, requiring $O(\kappa) \approx 2000$ iterations per unit progress. Starting point: $x_0 = [-1,\, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Questions 5 and 6):
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a compact convex polytope (axis-aligned box) with diameter $D = \|(5 - 0.5,\, 10 - (-5))\| = \sqrt{4.5^2 + 15^2} \approx 15.66$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

\begin{definition}[$L$-smoothness and $\mu$-strong convexity]
\label{def:smooth_sc}
A differentiable function $f: \mathbb{R}^d \to \mathbb{R}$ is:
\begin{itemize}[nosep]
\item \emph{$L$-smooth} if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ for all $x,y$ (equivalently, $\nabla^2 f \preceq LI$ when $f$ is twice differentiable);
\item \emph{$\mu$-strongly convex} if $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$ for all $x,y$ (equivalently, $\nabla^2 f \succeq \mu I$).
\end{itemize}
The condition number $\kappa = L/\mu \geq 1$ measures the curvature ratio; $\kappa = 1$ means the level sets are perfect spheres.
\end{definition}

For an $L$-smooth convex function, gradient descent with constant step $\alpha \leq 1/L$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{\|x_0 - x^\star\|^2}{2\alpha k}.
\end{equation}
For $\mu$-strongly convex functions, the rate improves to:
\begin{equation}
\|x_k - x^\star\|^2 \leq \left(1 - \frac{\mu}{L}\right)^k \|x_0 - x^\star\|^2,
\end{equation}
i.e.\ linear (geometric) convergence with rate $\rho = 1 - \mu/L = 1 - 1/\kappa$. The condition number $\kappa$ thus directly governs convergence speed --- the larger $\kappa$, the slower GD converges. Adaptive step-size methods aim to overcome this dependence by automatically scaling the learning rate to the local curvature.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Proportional to suboptimality}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step size minimises the distance to $x^\star$ at each iteration. For a convex $f$ with subgradient $g_k \in \partial f(x_k)$, the subgradient inequality gives $f(x^\star) \geq f(x_k) + g_k^T(x^\star - x_k)$, hence $g_k^T(x_k - x^\star) \geq f(x_k) - f^\star$. Then:
\begin{align}
\|x_{k+1} - x^\star\|^2 &= \|x_k - \alpha_k g_k - x^\star\|^2 \notag \\
&= \|x_k - x^\star\|^2 - 2\alpha_k g_k^T(x_k - x^\star) + \alpha_k^2\|g_k\|^2 \notag \\
&\leq \|x_k - x^\star\|^2 - 2\alpha_k(f(x_k) - f^\star) + \alpha_k^2\|g_k\|^2.
\end{align}
Minimising over $\alpha_k > 0$ gives the Polyak step $\alpha_k = (f(x_k) - f^\star)/\|g_k\|^2$, which makes the bound $\|x_{k+1} - x^\star\|^2 \leq \|x_k - x^\star\|^2 - (f(x_k) - f^\star)^2/\|g_k\|^2$ as tight as possible.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative sum of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad \cite{duchi2011} scales each coordinate's learning rate inversely by the root of its gradient history, effectively giving larger steps to rarely-updated parameters. For convex functions, Adagrad achieves a regret bound of $O(\sqrt{T})$ over $T$ rounds, implying convergence at $O(\log T/\sqrt{T})$. Its principal limitation is that the accumulated sum $G_k = \sum_{j\leq k} g_{j}^2$ grows without bound: at iteration $k$, the effective step size satisfies $({\rm eff.\ }\alpha)_k \leq \alpha_0/\sqrt{k \cdot \min_j g_{j,i}^2}$, which decays as $1/\sqrt{k} \to 0$. This prevents Adagrad from making progress in later iterations on stationary (non-diminishing) problems --- an issue that RMSprop resolves through exponential forgetting of old gradients.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop \cite{tieleman2012} addresses Adagrad's vanishing step problem by replacing the cumulative sum with an exponential moving average (decay $\beta = 0.9$). The effective second moment estimate $v_k \approx \mathbb{E}[g^2]$ remains bounded, preventing the step from collapsing. Formally, $v_k$ is a geometric series: $v_k = (1-\beta)\sum_{j=0}^{k-1}\beta^{k-1-j} g_j^2$, where recent gradients receive exponentially higher weight.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Momentum accumulation}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method adds a momentum term $\beta z_k$ to the gradient update \cite{polyak1987}. For a quadratic $f(x) = \frac{1}{2}x^T H x - b^T x$ with eigenvalues $\mu \leq \lambda_i \leq L$ (condition number $\kappa = L/\mu$), the optimal Heavy Ball parameters are:
\begin{equation}
\alpha^\star = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}, \qquad \beta^\star = \left(\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}\right)^2,
\end{equation}
yielding the convergence rate $\rho^\star = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$, which improves upon GD's rate $(1 - 1/\kappa) \approx 1 - 1/\kappa$ for large $\kappa$. The iteration count to achieve $\varepsilon$-accuracy scales as $O(\sqrt{\kappa} \log(1/\varepsilon))$ vs GD's $O(\kappa \log(1/\varepsilon))$ --- an asymptotic speedup of $\sqrt{\kappa}$.

For Benchmark C ($\kappa \approx 2000$), the theoretical speedup is $\sqrt{2000} \approx 44.7\times$, predicting Heavy Ball would need $\sim$44 times fewer iterations than GD. Empirically, Heavy Ball achieves $f = 1.40$ (Table~\ref{tab:q1_convergence_summary}) vs GD's $f = 3.39$ in the same 120 iterations on Rosenbrock, a $2.4\times$ improvement --- less than the theoretical $44\times$ because the Rosenbrock function is \emph{not} quadratic, so the optimal quadratic parameters do not apply, and the practical parameters $\alpha = 0.0008$, $\beta = 0.86$ are tuned conservatively for stability. Physically, the iterate behaves like a ball rolling in the objective landscape, accumulating speed in consistent descent directions and decelerating across oscillating directions.

\begin{remark}
\label{rem:hb_nonquadratic}
The optimal $O(\sqrt{\kappa})$ rate of Heavy Ball applies only to strongly convex \emph{quadratic} functions. For general non-quadratic objectives, Heavy Ball does not enjoy the same guarantees and can even diverge for poorly chosen $(\alpha, \beta)$. In contrast, Nesterov's acceleration (Section~\ref{sec:q2}) achieves $O(1/k^2)$ for \emph{any} smooth convex function, making it theoretically superior. Empirically, this is reflected in Table~\ref{tab:q1_final}: Heavy Ball achieves $f = 1.40$ on Rosenbrock vs Nesterov's $f = 0.479$ (Table~\ref{tab:q2_final}).
\end{remark}

\textbf{Condition number analysis:} The GD step size bounds confirm the relative condition numbers. Benchmark A requires $\alpha \leq 2/(\lambda_{\min} + \lambda_{\max})$; since $H = X^T X/m \approx I$ by the law of large numbers, $\kappa_A \approx 1$. \subsection{Analysis of Polyak Divergence}

The Polyak step size \cite{polyak1969} is derived under the assumption that $f^\star$ is known exactly. The divergence on Benchmarks A and B can be characterised precisely.

\begin{proposition}
\label{prop:polyak_diverge}
Let $f^\star_{\rm true}$ be the true minimum. If the Polyak step is run with specified $\tilde{f}^\star < f^\star_{\rm true}$, then as $\|g_k\| \to 0$ the step size satisfies
\[
\alpha_k = \frac{f(x_k) - \tilde{f}^\star}{\|g_k\|^2 + \varepsilon} \;\to\; \frac{f^\star_{\rm true} - \tilde{f}^\star}{\varepsilon} \quad \text{(a large constant)},
\]
causing the iterate to take a large step away from the minimum and re-enter a region of non-negligible gradient, resulting in sustained oscillations.
\end{proposition}

On Benchmark A, $f^\star_{\rm true} \approx 0.4826$ and $\tilde{f}^\star = 0$, giving $\alpha_k \approx 0.4826/\varepsilon = 4826$ near the minimum. On Benchmark C, $f^\star_{\rm true} = \tilde{f}^\star = 0$, so $\alpha_k = f(x_k)/(\|g_k\|^2 + \varepsilon)$ shrinks properly as the iterate converges.

\subsection{RMSprop Convergence Analysis}

RMSprop converges to $f = 0.5027$ on Benchmark A (above the noise floor $J^\star = 0.4826$). This systematic overestimation occurs because of a feedback loop near the minimum:

\begin{enumerate}[nosep]
\item Near $\theta_{\rm OLS}$, gradients are small: $\|g_k\| \approx \varepsilon_{\rm small}$.
\item The EMA $v_k = \beta v_{k-1} + (1-\beta)g_k^2 \approx \beta^{k-k_0} v_{k_0}$ retains memory of earlier large gradients from the descent phase ($k < k_0$), so $v_k$ remains elevated relative to the current small gradients.
\item The effective step $\alpha_{\rm eff} = \alpha_0 / \sqrt{v_k}$ is thus \emph{disproportionately large} relative to the current gradient magnitude.
\item The iterate overshoots, generating a slightly larger gradient, which keeps $v_k$ from decaying, sustaining the oscillation.
\end{enumerate}

This ``gradient scale mismatch'' is characteristic of RMSprop with a fixed $\beta = 0.9$ --- the $10$-step memory horizon (effective $\approx 1/(1-\beta) = 10$ steps) is too long for a tightly converging problem. Smaller $\alpha_0 = 0.22$ reduces this but cannot fully eliminate the oscillation. In contrast, Adagrad's cumulative sum $G_k = \sum_{j\leq k} g_j^2$ grows monotonically and the step always decays, preventing this overshoot mechanism.

Figure~\ref{fig:q1_adagrad_rmsprop} illustrates this fundamental difference: Adagrad's effective step size decays monotonically as $O(1/\sqrt{k})$ and eventually approaches zero (causing premature stagnation on long runs), while RMSprop's EMA-based step size stabilises at a level determined by the current gradient magnitude, maintaining adaptivity throughout optimisation.

\subsection{Theoretical Background: Accelerated Convergence}

Gradient descent achieves $O(1/k)$ convergence for smooth convex functions. Nesterov (1983) showed this is \emph{not} optimal --- an improved $O(1/k^2)$ rate is achievable by first-order methods, now known as Nesterov acceleration.

\begin{theorem}[Nesterov, 1983 \cite{nesterov1983}]
\label{thm:nesterov}
Let $f$ be convex and $L$-smooth. Nesterov's accelerated gradient method with step $\alpha = 1/L$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2}.
\end{equation}
This $O(1/k^2)$ rate is \emph{optimal} among all first-order methods (cannot be improved by any algorithm that uses only gradient queries).
\end{theorem}

The key insight of Nesterov's method is the \emph{lookahead}: the gradient is evaluated at a point $\tilde{x}_k$ that looks ahead in the direction of the current momentum, allowing the method to ``correct'' its trajectory before it overshoots.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Gradient at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The adaptive schedule $\beta_k = (k-1)/(k+2) \to 1$ gradually increases momentum to achieve the optimal rate. The update is equivalent to: $x_{k+1} = \tilde{x}_k - \alpha\nabla f(\tilde{x}_k) + \beta_k^2 z_{k-1}$, which differs from Heavy Ball only in evaluating the gradient at the \emph{lookahead} point rather than $x_k$.

\textbf{Nesterov vs Heavy Ball --- formal comparison:} Both can be written as $x_{k+1} = x_k + \beta_k(x_k - x_{k-1}) - \alpha \nabla f(y_k)$, where $y_k = x_k$ (Heavy Ball) or $y_k = x_k + \beta_k(x_k - x_{k-1})$ (Nesterov). The lookahead point $y_k$ allows Nesterov to evaluate the gradient at a more ``ahead'' position, producing a correction that dampens overshoot. This subtle difference has a profound consequence: Nesterov's $O(1/k^2)$ convergence is \emph{optimal} (by lower bounds on first-order methods), while Heavy Ball's rate on general convex functions is not guaranteed to be better than GD's $O(1/k)$, and on non-quadratic functions Heavy Ball can fail to converge (Remark~\ref{rem:hb_nonquadratic}).

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{EMA of gradient (1st moment)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{EMA of squared gradient (2nd moment)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction: compensates for zero initialisation}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam \cite{kingma2015} combines momentum (via $m_t \approx \mathbb{E}[g]$) with per-coordinate adaptive scaling (via $v_t \approx \mathbb{E}[g^2]$), combining the advantages of RMSprop and Nesterov momentum. The bias correction terms $1/(1-\beta^t)$ are critical in early iterations: without them, $m_1 = (1-\beta_1)g_1 \approx 0$ would give nearly zero effective gradient, stalling convergence.

Figure~\ref{fig:q2_adam_bias} illustrates the bias correction effect: the raw first moment $m_t$ severely underestimates the true gradient in the first $\sim 1/(1-\beta_1) = 10$ iterations, so the corrected $\hat{m}_t = m_t/(1-\beta_1^t)$ is essential for meaningful early updates. The correction factor $1/(1-\beta_1^t)$ decays from $1/(1-0.9) = 10$ at $t=1$ to $\approx 1$ at $t \gg 10$, making Adam equivalent to uncorrected updates once sufficient history is accumulated.

The bias-corrected estimate $\hat{m}_t = m_t/(1-\beta_1^t)$ (blue) closely tracks the true gradient from the first iteration. \textbf{Right:} The effective update magnitude with vs without bias correction, showing that uncorrected Adam would take much smaller steps in the first $\sim$10 iterations ($1/(1-\beta_1) = 10$ for $\beta_1 = 0.9$). The Nesterov implementation uses an adaptive momentum schedule $\beta_k = \min((k-1)/(k+2),\, \beta_{\max})$ that starts at 0 (pure gradient descent) and gradually increases to $\beta_{\max} = 0.90$--$0.92$, providing global convergence guarantees absent from fixed-momentum heavy ball. \subsection{Why Adam Underperforms Nesterov on Rosenbrock}

Table~\ref{tab:q2_final} shows Nesterov achieving $f = 0.479$ vs Adam's $f = 1.578$ on Rosenbrock. This gap arises from a fundamental structural difference:

\begin{itemize}[nosep]
\item \textbf{Nesterov} exploits the \emph{consistent descent direction} along the Rosenbrock valley floor. The momentum accumulates over iterations in the valley direction, producing increasingly large steps along the flat (low-curvature) dimension. The $O(1/k^2)$ rate (Theorem~\ref{thm:nesterov}) is achieved precisely by this momentum build-up.

\item \textbf{Adam} normalises each coordinate by $\sqrt{v_t} \approx \sqrt{\mathbb{E}[g^2]}$, making the effective step size approximately $\alpha / \sqrt{\mathbb{E}[g^2]}$ per coordinate. On Rosenbrock, the gradient magnitudes along and across the valley differ by orders of magnitude, and the $v_t$ normalisation \emph{equalises} these, inadvertently reducing Adam's effective step in the productive valley direction. This ``scale-invariance'' that makes Adam robust to poorly scaled problems here works against it.
\end{itemize}

To see this quantitatively: near the Rosenbrock valley floor at $x = (0.5, 0.25)$, the gradient is $\nabla f \approx (-1.0, -25.0)^T$. The effective Adam step in the $x_2$ direction is $\alpha \hat{m}_2/\sqrt{\hat{v}_2}$, where after burn-in $\hat{m}_2 \approx -25$ and $\hat{v}_2 \approx 625$, giving effective step $\approx 0.006 \times (-25)/25 = -0.006$. Nesterov, with accumulated momentum $z \approx -\alpha \nabla f / (1-\beta)$, takes a step $\approx -\alpha \nabla f_2 / (1-0.90) = -0.0007 \times (-25)/0.1 = 0.175$. This $\sim29\times$ larger effective step in the productive $x_2$ direction is why Nesterov makes faster progress along the valley floor.

This analysis illustrates a general principle: adaptive gradient methods trade directional exploitation (momentum) for per-coordinate robustness. When the landscape has a consistent low-curvature descent direction (as in Rosenbrock's valley floor), pure momentum methods outperform adaptive methods. When the landscape is poorly scaled or has vastly different curvatures per coordinate (as in deep network layers with heterogeneous feature scales), adaptive methods (Adam) typically outperform fixed-momentum methods \cite{bottou2018}.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices into batches $\mathcal{B}_1, \ldots, \mathcal{B}_{m/b}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\textbf{Bias-variance trade-off in mini-batch size:} The stochastic gradient satisfies $\mathbb{E}[g] = \nabla J(\theta)$ (unbiased) with variance $\operatorname{Var}[g] = \sigma^2_g/b$, where $\sigma^2_g$ is the per-sample gradient variance. Smaller $b$ gives more gradient updates per epoch ($m/b$ updates vs a single update for full-batch) but higher variance; larger $b$ reduces variance at the cost of fewer updates.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q2_sgd_batch.pdf}
\caption{Q2: Mini-batch SGD with different batch sizes. With $b = 5$, each epoch performs $1000/5 = 200$ gradient steps, enabling faster per-epoch convergence but higher oscillation near the minimum. With $b = 40$, only $1000/40 = 25$ steps per epoch produce smoother but slower progress. The smaller batch reaches lower loss faster (in epochs) due to more frequent updates, but the noise floor near convergence is higher for $b = 5$ than $b = 40$.}

\subsubsection{Per-Gradient-Evaluation Comparison: SGD vs Full-Batch GD}

The per-epoch comparison in Figure~\ref{fig:q2_sgd_batch} favours mini-batch SGD because each epoch performs $m/b$ gradient steps, so fewer epochs are needed to see many updates. However, this conflates the cost of an epoch: a full-batch GD step uses all $m$ samples, while an SGD mini-batch step uses only $b$ samples. A fair comparison normalises by the number of equivalent full-gradient evaluations:
\begin{equation}
\text{cost}(k\text{ mini-batch steps of size }b) \;=\; \frac{k \cdot b}{m}\;\text{ full-gradient equivalents}.
\end{equation}

This is consistent with the classical result that \emph{in the strongly convex setting} with fixed step size and no noise, full-batch GD converges at rate $(1 - \mu/L)^k$ per full-gradient evaluation, while mini-batch SGD with the same cost achieves the slower stochastic rate $O(1/k)$ due to gradient variance. The practical choice depends on whether gradient variance is the limiting factor (favour large $b$) or data throughput is the limiting factor (favour small $b$ with parallelism).

\subsection{SGD with Increased Observation Noise}

\textbf{Quantitative Nesterov vs Adam comparison:} On Rosenbrock, Nesterov achieves $f = 0.479$ and Adam $f = 1.578$ after 150 iterations. This corresponds to Nesterov reducing the objective by a factor of $3.39/0.479 \approx 7.1\times$ from GD's baseline, while Adam achieves only $3.39/1.578 \approx 2.1\times$ reduction. The theoretical $O(1/k^2)$ rate of Nesterov vs Adam's $O(1/\sqrt{k})$ or $O(1/k)$ rate (depending on the analysis) predicts Nesterov should have a $\sim(1/k^2)/(1/k) = 1/k$ advantage that grows with iteration count, consistent with the $\approx 3.3\times$ observed gap.

\textbf{Convergence theory for SGD:} For a $\mu$-strongly convex, $L$-smooth function, mini-batch SGD with learning rate $\alpha_k = c/(\mu k)$ achieves:
\begin{equation}
\mathbb{E}[f(\theta_k)] - f^\star \leq \frac{L c^2 \sigma^2_g}{2b\mu k},
\end{equation}
where $\sigma^2_g$ is the per-sample gradient variance and $b$ is the batch size. This $O(1/k)$ rate is optimal for stochastic first-order methods (vs $O(1/k^2)$ for deterministic Nesterov). The expected suboptimality scales as $\sigma^2_g/(b \cdot k)$, confirming that larger batches reduce variance (and thus the optimisation noise floor) proportional to $1/b$.

The experiment is repeated with output noise scaled by factor 6 ($\varepsilon^{(i)} \sim \mathcal{N}(0,36)$ vs $\mathcal{N}(0,1)$).

\subsection{Local Approximations of $g(x) = x^4$}

At $x_0 = 0.25$, we have $g(x_0) = 0.25^4 = 0.00390625$, $g'(x_0) = 4(0.25)^3 = 0.0625$, $g''(x_0) = 12(0.25)^2 = 0.75$.

\textbf{First-order (tangent) approximation:}
\begin{equation}
\hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.00391 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order (quadratic) approximation:}
\begin{equation}
\hat{g}_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.00391 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

By Taylor's theorem, the approximation errors are: $|g(x) - \hat{g}_1(x)| = O(|x-x_0|^2)$ and $|g(x) - \hat{g}_2(x)| = O(|x-x_0|^3)$. The Newton step minimises $\hat{g}_2$: setting $\hat{g}_2'(x) = 0$ gives $x_{\text{Newton}} = x_0 - g'(x_0)/g''(x_0) = 0.25 - 0.0625/0.75 = 0.1\overline{6}$, which is closer to the true minimum $x^\star = 0$ than the gradient step $x_0 - \alpha g'(x_0)$ for any fixed $\alpha$.

The parabola fits well in a neighbourhood of $x_0$, and its minimum (Newton step) provides a superior estimate of the function's minimum than any fixed-step gradient descent step. \subsection{Newton's Method and Quadratic Convergence}

\begin{algorithm}[H]
\caption{Newton's Method with Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Quadratic Convergence of Newton's Method]
\label{thm:newton_conv}
Suppose $f$ is twice continuously differentiable, $\nabla^2 f(x^\star) \succ 0$ with smallest eigenvalue $\mu > 0$, and $\nabla^2 f$ is $M$-Lipschitz. Then Newton's method with $\alpha = 1$ (undamped) satisfies, in a neighbourhood of $x^\star$:
\begin{equation}
\|x_{k+1} - x^\star\| \leq \frac{M}{2\mu}\|x_k - x^\star\|^2.
\end{equation}
This is \emph{quadratic convergence}: the number of correct digits roughly doubles at each iteration.
\end{theorem}

In contrast, gradient descent achieves only \emph{linear convergence}: $\|x_{k+1} - x^\star\| \leq (1 - \mu/L)\|x_k - x^\star\|$. The cost per Newton iteration is higher ($O(d^3)$ for Hessian inversion vs $O(d)$ for a gradient step), but the dramatic reduction in iteration count typically makes Newton superior when $d$ is small and the function is smooth.

\begin{corollary}[Iteration complexity comparison]
\label{cor:newton_gd_compare}
To reduce error to $\varepsilon = 10^{-6}$ from $\|x_0 - x^\star\| = 1$:
\begin{itemize}[nosep]
\item GD requires $k_{\rm GD} = \kappa \log(1/\varepsilon) / 2 \approx 6.9\kappa$ iterations (Benchmark B: $k \approx 48$).
\item Newton requires $k_{\rm Newton} = \log_2(\log(1/\varepsilon)) \approx 4$ iterations (because errors double-square: $10^{-1} \to 10^{-2} \to 10^{-4} \to 10^{-8}$).
\end{itemize}
For $\kappa = 7$ (Benchmark B), this is a $12\times$ iteration advantage for Newton. For $\kappa = 2000$ (Rosenbrock), GD would need $\sim 14000$ iterations vs Newton's $\sim 4$--$6$ --- a $2000\times$ advantage in iteration count.
\end{corollary}

The damping parameter $\lambda = 10^{-8}$ in \texttt{newtons\_method} regularises the Hessian $H_k + \lambda I$, ensuring positive definiteness when $H_k$ may be singular or nearly singular (as occurs on Rosenbrock where $H_{\rm Rosenbrock}$ can be very ill-conditioned). The step size $\alpha < 1$ provides a \emph{global convergence} safeguard: the pure Newton step ($\alpha = 1$) only has local convergence guarantees, while damping ($\alpha < 1$) trades convergence speed for a larger basin of attraction.

\subsection{Computational Trade-offs}

Newton's method requires computing and inverting the $d \times d$ Hessian at each iteration: $O(d^2)$ to evaluate $\nabla^2 f$ and $O(d^3)$ (or $O(d^2)$ using conjugate gradient) to solve the linear system. For $d = 2$ (as in these experiments), this is negligible --- Newton's entire 20-iteration run completes in microseconds. However, in high-dimensional settings ($d \sim 10^6$--$10^9$), full Newton is computationally prohibitive, motivating quasi-Newton methods (L-BFGS approximates $H^{-1}$ using $O(md)$ operations with $m \ll d$ history vectors) and second-order-free methods (Adam, Nesterov).

The Rosenbrock results demonstrate Newton's strength precisely where gradient methods struggle most: extreme ill-conditioning ($\kappa \approx 2000$). While GD achieves $f = 3.73$ in 80 iterations (barely leaving the starting valley), Newton reaches $f = 0.69$ in 20 iterations --- a $5.4\times$ improvement with $4\times$ fewer iterations. This remarkable efficiency gain is a direct consequence of Newton's iteration complexity being \emph{independent} of the condition number near the minimum: the quadratic convergence rate $\|x_{k+1} - x^\star\|^2 \leq C\|x_k - x^\star\|^4$ means the method does not ``feel'' ill-conditioning once it enters the quadratic convergence regime.

\begin{remark}[Quasi-Newton Methods]
When the Hessian $\nabla^2 f$ is expensive or unavailable, quasi-Newton methods (BFGS, L-BFGS) approximate $H_k \approx \nabla^2 f(x_k)$ using secant equations from gradient differences: $H_{k+1}(x_{k+1} - x_k) = \nabla f(x_{k+1}) - \nabla f(x_k)$. L-BFGS stores only the last $m$ pairs $(s_k, y_k) = (x_{k+1}-x_k, \nabla f_{k+1} - \nabla f_k)$, requiring $O(md)$ storage vs $O(d^2)$ for full BFGS. Quasi-Newton achieves \emph{superlinear} convergence (between linear and quadratic) and is the standard choice for medium-scale unconstrained optimisation ($10^2 \leq d \leq 10^5$) in scientific computing \cite{nocedal2006}.
\end{remark}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta} = \frac{\partial f}{\partial x_i}(x) + \frac{\delta}{2}\frac{\partial^2 f}{\partial x_i^2}(x) + O(\delta^2).
\label{eq:fd}
\end{equation}
The bias (truncation error) is $O(\delta)$; rounding errors add $O(\varepsilon_{\rm mach}/\delta)$ where $\varepsilon_{\rm mach} \approx 10^{-16}$. The optimal $\delta$ balances these: $\delta_{\rm opt} \sim \sqrt{\varepsilon_{\rm mach}} \approx 10^{-8}$. In practice, $\delta = 0.05$ gives small truncation error while remaining numerically well-conditioned, whereas $\delta = 0.8$ introduces large truncation error because the function curvature on Benchmark B is $O(1)$--$O(10)$, so the $O(\delta^2 \cdot f'')\approx O(0.64\cdot 10) = O(6.4)$ bias term is large relative to the gradient.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform on unit sphere}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\textbf{Theoretical properties:} For $u$ uniformly distributed on the unit sphere $\mathbb{S}^{d-1}$, the estimator satisfies:
\begin{equation}
\mathbb{E}\!\left[\frac{f(x+\delta u) - f(x)}{\delta}\, u\right] = \frac{1}{d}\nabla f(x) + O(\delta^2),
\end{equation}
i.e.\ it is a biased estimate of $\frac{1}{d}\nabla f(x)$, requiring an effective learning rate of $\alpha_{\rm eff} = d \cdot \alpha$ to match gradient descent. The noise variance scales as $O(\|\nabla f\|^2)$, and the convergence rate for smooth convex functions is $O(d/k)$ expected suboptimality --- a factor of $d$ worse than gradient descent's $O(1/k)$. For $d = 2$, this additional factor is manageable (empirically $\sim 2$--$3\times$ more iterations), but for $d = 100$ the method would require $100\times$ more iterations than exact GD for the same accuracy. Despite this, Nesterov random search requires only 2 function evaluations per step (regardless of $d$), making it compelling when function evaluations are cheap but gradients are unavailable.

Figure~\ref{fig:fd_error} plots the gradient approximation error $\|\hat{g}_\delta - \nabla f\|$ as a function of $\delta$ for Benchmark B at a fixed test point, demonstrating the classical U-shaped error curve. For very small $\delta$, rounding errors dominate; for large $\delta$, truncation error dominates; and the optimal $\delta \approx 10^{-8}$ balances both. The tested values $\delta = 0.05$ and $\delta = 0.8$ are both in the truncation-dominated regime, but $\delta = 0.05$ incurs a truncation error $\approx 6\times$ smaller than $\delta = 0.8$.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm \cite{nelder1965} maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four operations.
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): Move worst vertex $x_w$ through centroid $\bar{x}$ of remaining vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x_w)$.
\item \textbf{Expansion} ($\gamma = 2.0$): If reflection improved, try $x_e = \bar{x} + \gamma(\bar{x} - x_w)$.
\item \textbf{Contraction} ($\rho = 0.5$): If reflection worsened, try $x_c = \bar{x} + \rho(x_r - \bar{x})$ (outside) or $\bar{x} + \rho(x_w - \bar{x})$ (inside).
\item \textbf{Shrink} ($\sigma = 0.5$): If contraction fails, contract all vertices towards best: $x_i \gets x_1 + \sigma(x_i - x_1)$.
\end{enumerate}
No gradient information is required. Settings: initial simplex step $= 0.35$, 160 iterations.

\textbf{Theoretical properties and convergence analysis:} Nelder--Mead has no general convergence guarantee for $d \geq 2$ --- the simplex can degenerate (all vertices collinear) and the algorithm stalls. However, for smooth unimodal functions in low dimensions ($d \leq 5$), the algorithm performs well in practice. The operations adapt the simplex geometry to the local landscape:
\begin{itemize}[nosep]
\item \emph{Reflection + Expansion}: When reflection improves, the method is descending quickly --- expansion ($\gamma = 2.0$) amplifies this direction, providing acceleration analogous to momentum.
\item \emph{Contraction}: When reflection worsens, the simplex is on the wrong side of the centroid; contraction reduces the step toward a hopefully better region.
\item \emph{Shrink}: The nuclear option --- all vertices collapse toward the best. This costs $n$ evaluations and suggests the current simplex is completely misoriented.
\end{itemize}
On Rosenbrock, the curved valley forces many contraction steps as the simplex attempts to orient along the valley. The method succeeds because the valley is smooth and unimodal, so a well-oriented simplex can slide along it without degenerating.

\subsection{Problem Setup and KKT Conditions}

Minimise $f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)$ subject to $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$.

Rewriting as a standard minimisation problem: minimise $f(x)$ subject to $g(x) = 0.5 - x_1 \leq 0$. The KKT first-order optimality conditions \cite{boyd2004} are:
\begin{align}
\nabla f(x^\star) + \lambda^\star \nabla g(x^\star) &= 0 && \text{(stationarity)} \\
g(x^\star) &\leq 0 && \text{(primal feasibility)} \\
\lambda^\star &\geq 0 && \text{(dual feasibility)} \\
\lambda^\star g(x^\star) &= 0 && \text{(complementary slackness)}
\end{align}
where $\lambda^\star \geq 0$ is the Lagrange multiplier for the constraint.

\textbf{Case analysis:} If the unconstrained minimum $(0.582, 2.0)$ satisfies $x_1 \geq 0.5$, then $\lambda^\star = 0$ and the constraint is inactive. Indeed, $0.582 > 0.5$, so the constrained minimum \emph{coincides with the unconstrained minimum}: $x^\star = (0.582, 2.0)$, $f^\star \approx 0.7244$, $\lambda^\star = 0$.

\textbf{KKT verification at $x^\star = (0.582, 2.0)$:}
\begin{align*}
\text{Stationarity:} &\quad \nabla f(x^\star) + \lambda^\star \nabla g(x^\star) = \begin{bmatrix}2(0.582-1)+\cos(0.582) \\ 10(2-2)\end{bmatrix} + 0\cdot\begin{bmatrix}-1\\0\end{bmatrix} = \begin{bmatrix}0\\0\end{bmatrix} \checkmark \\
\text{Primal feasibility:} &\quad g(x^\star) = 0.5 - 0.582 = -0.082 \leq 0 \checkmark \\
\text{Dual feasibility:} &\quad \lambda^\star = 0 \geq 0 \checkmark \\
\text{Compl.\ slackness:} &\quad \lambda^\star g(x^\star) = 0 \cdot (-0.082) = 0 \checkmark
\end{align*}
All KKT conditions are satisfied, confirming $x^\star = (0.582, 2.0)$ is the globally optimal constrained solution (the problem is convex). The starting point $x_0 = (0.2, 4.0)$ violates primal feasibility ($0.5 - 0.2 = 0.3 > 0$), so every method must first move towards the feasible region.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project back: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

For the half-space constraint $x_1 \geq 0.5$, the projection is $\Pi_{\mathcal{X}}(z) = (\max(0.5, z_1), z_2)^T$, a simple component-wise clipping. The key property of a projection is \emph{non-expansiveness}: $\|\Pi_{\mathcal{X}}(a) - \Pi_{\mathcal{X}}(b)\| \leq \|a - b\|$ for all $a, b$, which ensures the projected iterate remains close to the constrained optimum.

\begin{proposition}[Projected GD Convergence \cite{boyd2004}]
Let $f$ be $L$-smooth and convex over a closed convex set $\mathcal{X}$, with $x^\star = \arg\min_{x \in \mathcal{X}} f(x)$. Projected GD with step $\alpha = 1/L$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{L\|x_0 - x^\star\|^2}{2k}.
\end{equation}
\end{proposition}
This is the same $O(1/k)$ rate as unconstrained GD, demonstrating that projection incurs no asymptotic convergence penalty for convex $f$ and convex constraints.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $\nabla F_{\lambda}(x) \gets \nabla f(x) - \lambda \mathbf{1}[x_1 < 0.5]\, e_1$ \Comment{Subdifferential}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty method solves the unconstrained problem $\min_x F_\lambda(x) = f(x) + \lambda\, \phi(g(x))$ where $\phi(t) = \max(0, t)$ is the hinge penalty. As $\lambda \to \infty$, the penalty solution converges to the constrained solution: $x^\star(\lambda) \to x^\star$ as $\lambda \to \infty$. In practice, large $\lambda$ creates a steep, nearly discontinuous gradient near the constraint boundary, requiring smaller step sizes for stability.

\textbf{Landscape effect of $\lambda$:} Figure~\ref{fig:q5_penalty_landscape} shows the penalised objective $F_\lambda(x) = f(x) + \lambda\max(0,\, 0.5-x_1)$ for $\lambda \in \{0.15, 1.8, 4.5\}$. For small $\lambda = 0.15$, the penalty adds only a gentle ridge at $x_1 = 0.5$, insufficient to prevent the gradient from pulling the iterate towards the unconstrained minimum at $x_1 = 0.582$ (which lies in the feasible region for this problem). For $\lambda = 4.5$, the steep penalty wall near $x_1 = 0.5$ strongly discourages infeasibility. Note that since the true unconstrained minimum $(0.582, 2.0)$ is feasible ($x_1 = 0.582 > 0.5$), all three $\lambda$ values converge to the same point with enough iterations --- the difference is only in how quickly they escape the initial infeasible region $x_1 = 0.2 < 0.5$.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} Minimise $f(x) = a^T x = x_1 + 2x_2$ over $\mathcal{X}$ (i.e.\ $a = [1, 2]^T$). Since $f$ is linear and $\mathcal{X}$ is a bounded convex polytope, the \emph{Fundamental Theorem of Linear Programming} guarantees that the minimum is attained at a vertex of $\mathcal{X}$. Since $a_1 = 1 > 0$ and $a_2 = 2 > 0$, each component is minimised at its lower bound:
\begin{equation}
x^\star = (0.5,\; -5), \qquad f^\star = 1\times 0.5 + 2\times(-5) = -9.5.
\end{equation}

\textbf{LP Duality:} The dual of this LP is: maximise $b^T y$ subject to $A^T y = a$, $y \geq 0$. For a box constraint written as $l \leq x \leq u$, introducing dual variables $\lambda \geq 0$ (for $x \geq l$) and $\mu \geq 0$ (for $x \leq u$), strong duality gives $f^\star = \lambda^T l - \mu^T u$. At the solution $(0.5, -5)$: both lower bounds are active, $\lambda = a = [1,2]^T$, $\mu = 0$, dual value $= 1\times 0.5 + 2\times(-5) = -9.5 = f^\star$ (strong duality holds). This confirms the LP is solved exactly at a vertex where the active constraints uniquely determine the solution.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{z \in \mathcal{X}}\, \nabla f(x_k)^T z$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination, stays in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Frank--Wolfe Convergence \cite{frank1956,jaggi2013}]
\label{thm:fw_conv}
Let $f$ be $L$-smooth and convex on a compact convex set $\mathcal{X}$ with diameter $D = \max_{x,y\in\mathcal{X}}\|x-y\|$. Frank--Wolfe with $\gamma_k = 2/(k+2)$ (standard decaying step) satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{2LD^2}{k+2}.
\end{equation}
\end{theorem}

The implementation here uses a fixed $\beta$ (rather than the decaying $\gamma_k = 1 - \beta = 2/(k+2)$ of the standard analysis), which trades the theoretical $O(1/k)$ guarantee for empirical stability. The key advantages over projected gradient methods are: (1) no projection is required --- iterates remain in $\mathcal{X}$ by convexity; (2) the LMO for box constraints decomposes coordinate-wise, requiring only $O(d)$ operations.

\textbf{LMO for box constraints:} The LP subproblem $\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$ decomposes per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
where $[l_i, u_i]$ are the coordinate bounds. This always returns a vertex of the box $\mathcal{X}$.

\textbf{Frank--Wolfe gap} as a convergence certificate: $h_k = \nabla f(x_k)^T(x_k - z_k) \geq f(x_k) - f^\star$ (by convexity). When $h_k \leq \varepsilon$, we have verified $\varepsilon$-optimality without knowing $f^\star$.

\subsection{Interior vs Boundary Behaviour: Theoretical Analysis}

\textbf{Interior optimum:} Frank--Wolfe converges but exhibits characteristic ``zig-zag.'' The LMO returns vertices of $\mathcal{X}$, which are far from the interior optimum, causing the convex combination to overshoot. The convergence rate is $O(1/k)$ (Theorem~\ref{thm:fw_conv}). Smaller step size ($\beta = 0.985$) reduces oscillation at the cost of slower initial descent, but achieves better final accuracy on the 180-iteration run.

\textbf{Boundary optimum:} Frank--Wolfe is naturally suited because the LMO consistently selects a vertex near the constrained optimum. The boundary case converges slower than the interior case in terms of absolute $f$ reduction because the residual gap $0.364 - 0.25 = 0.114$ requires the iterate to travel close to a vertex of $\mathcal{X}$, but the mixing parameter $\beta = 0.93$ limits the step size. Implementing the standard decaying schedule $\gamma_k = 2/(k+2)$ (equivalent to $\beta = 1 - 2/(k+2) = k/(k+2) \to 1$) would accelerate convergence in this case.

\textbf{Standard decaying step schedule:} The theoretical $O(1/k)$ guarantee of Theorem~\ref{thm:fw_conv} requires $\gamma_k = 2/(k+2)$, equivalent to $\beta_k = k/(k+2) \to 1$. The fixed $\beta$ used in the implementation converges faster initially (when $\beta < k/(k+2)$, i.e.\ the step is larger than the decaying schedule) but may oscillate at later stages when $\beta > k/(k+2)$ (the step is now larger than optimal). The boundary case ($\beta = 0.93$) has not converged to $f^\star = 0.25$ after 140 iterations, whereas the decaying schedule would guarantee convergence by Theorem~\ref{thm:fw_conv}. This illustrates the practical importance of using the theoretically motivated step-size schedule.

\textbf{Quantitative zig-zag analysis (interior optimum, $\beta = 0.90$):} Near the interior optimum $x^\star = (1, 5)$, the gradient $\nabla f(x_k) = 2(x_k - x^\star)$ points roughly away from $x^\star$. The LMO then selects the vertex $z_k$ that minimises $\nabla f(x_k)^T z$ over the box $\mathcal{X}$. For $x_k$ near $(1,5)$, the gradient components $(\nabla f_1, \nabla f_2)$ alternate sign as $x_k$ oscillates, causing the LMO to alternate between opposing vertices. Specifically, if $x_k > x^\star$, the LMO selects $z_k = (0.5, -5)$ (lower-left vertex), and the update $x_{k+1} = 0.90\, x_k + 0.10 \times (0.5, -5)$ pushes $x_k$ towards the lower-left --- overshooting through $x^\star$ to a point $x_{k+1} < x^\star$. Now the gradient flips and the LMO selects the upper-right vertex $(5, 10)$, creating the oscillation.

The oscillation amplitude at step $k$ satisfies approximately $\|x_k - x^\star\| \approx (0.90)^k \|x_0 - x^\star\| + (1 - \beta) D$ where $(1-\beta)D = 0.10 \times \|z - x^\star\|_{\rm max}$ is the irreducible floor from the LMO pulling towards a distant vertex. For the interior case with $x^\star = (1,5)$, the nearest vertex is $(0.5, -5)$ at distance $\sqrt{0.25 + 100} \approx 10.0$, so the irreducible oscillation is $0.10 \times 10.0 = 1.0$. This explains why $\beta = 0.985$ performs better: the irreducible floor is $0.015 \times 10.0 = 0.15$, giving $f \approx 0.15^2 = 0.0225$ vs $\beta = 0.90$'s floor of $f \approx 1.0^2 = 1.0$. The actual values ($f = 0.0046$ and $f = 0.0089$) are lower because the mixing from all previous iterates helps cancel oscillations, but the ordering is correctly predicted.

\textbf{Frank--Wolfe vs Projected GD:} Frank--Wolfe avoids projections, making it preferable when projections are expensive (e.g.\ nuclear norm ball, spectrahedron). Projected GD converges faster per iteration when projections are cheap (e.g.\ box constraints), because it can take gradient steps of size $1/L$ vs Frank--Wolfe's steps that are constrained to convex combinations with potentially distant vertices. Additionally, Frank--Wolfe provides a natural convergence certificate via the Frank--Wolfe gap $h_k = \nabla f(x_k)^T(x_k - z_k) \geq f(x_k) - f^\star$ --- this duality gap certifies optimality without knowing $f^\star$, an important practical advantage.

\subsection{Key Findings and Theoretical Connections}

\begin{enumerate}
\item \textbf{Condition number dominates convergence.} The Rosenbrock function ($\kappa \approx 2000$) is the most discriminating benchmark. For gradient descent, the convergence factor per iteration is $(1 - \mu/L) = (1 - 1/\kappa)$: on Benchmark A ($\kappa \approx 1$), each step removes virtually all error; on Benchmark C ($\kappa \approx 2000$), the factor is $0.9995$, requiring $k_{0.01} = \log(0.01)/\log(0.9995) \approx 9200$ steps to reach $1\%$ of initial error. Figure~\ref{fig:kappa} compares GD, Nesterov ($k_{0.01} \propto \sqrt{\kappa} \approx 44$ steps), and Heavy Ball, confirming that algorithmic choice matters exponentially as $\kappa$ grows. On Benchmarks A and B ($\kappa \approx 2$--$7$), all stable methods achieve essentially the same final accuracy because even GD converges quickly.

\item \textbf{Second-order methods are most efficient per iteration.} Newton's method solves Benchmark A exactly in one iteration and achieves $5.4\times$ better Rosenbrock accuracy in $4\times$ fewer iterations than GD. The quadratic convergence rate (Theorem~\ref{thm:newton_conv}) is exponentially faster than GD's linear rate. This advantage is decisive in low-dimensional problems where the $O(d^3)$ Hessian cost is acceptable.

\item \textbf{Nesterov acceleration bridges the gap.} Nesterov achieves the optimal $O(1/k^2)$ convergence rate (Theorem~\ref{thm:nesterov}) without requiring Hessian evaluations, reducing the Rosenbrock objective to $0.479$ vs GD's $3.388$ in the same 150 iterations. This demonstrates that the lookahead mechanism effectively compensates for ill-conditioning without second-order information.

\item \textbf{Adaptive methods are robust but not always fastest.} Adagrad, RMSprop, and Adam adapt to per-coordinate curvature, achieving reliable convergence across diverse problem types without careful step-size tuning. Adam combines momentum and adaptivity and is the dominant method in deep learning, but Nesterov's structured acceleration outperforms it on the highly non-quadratic Rosenbrock. The practical trade-off is: Adam for black-box robustness, Nesterov for well-understood convex problems.

\item \textbf{Derivative-free methods are viable but slower.} Finite differences with small $\delta$ closely approximates exact GD at the cost of $d+1$ function evaluations per step (vs 1 gradient evaluation). Nesterov random search trades gradient quality for 2-evaluation simplicity, at the cost of $O(d)$ slower convergence. Grid search uniquely guarantees global optimum discovery but is only feasible for $d \leq 3$.

\item \textbf{Constraint handling: hard vs soft.} Projected GD enforces feasibility exactly from the first iteration, making it preferable when constraint satisfaction is critical. Penalty methods are simpler to implement but require careful tuning of $\lambda$ --- too small leaves constraints violated, too large destabilises the optimisation. Frank--Wolfe offers a natural constraint-satisfaction guarantee without projection by construction, at the cost of a slower $O(1/k)$ convergence rate.

\item \textbf{Polyak sensitivity.} The Polyak step size achieves the fastest convergence when $f^\star$ is precisely known (Rosenbrock: $f = 0.009$ in 120 iterations), but diverges catastrophically when $f^\star$ is misspecified, as characterised in Proposition~\ref{prop:polyak_diverge}. This fundamental sensitivity limits its practical applicability to problems with known optimal values (e.g.\ certain convex programs where $f^\star$ can be computed by duality).
\end{enumerate}

\subsection{Limitations and Future Work}

All experiments are limited to $d = 2$ dimensions and run for at most 200 iterations. Several phenomena would change at scale:
\begin{itemize}[nosep]
\item \textbf{High dimension ($d \geq 100$):} Newton's $O(d^3)$ cost becomes prohibitive; quasi-Newton methods (L-BFGS) approximate $H^{-1}$ in $O(md)$ where $m \approx 10$--$20$ is the history length. Nesterov's $O(\sqrt{\kappa})$ advantage over GD persists.
\item \textbf{Large data ($m \geq 10^6$):} Full-batch GD and Newton become expensive per step. Mini-batch SGD and Adam become dominant, with the batch size $b$ controlling the variance-cost tradeoff.
\item \textbf{Non-convex problems:} All convergence guarantees are for convex $f$. In practice (deep learning), methods find local minima or saddle-free regions; empirically Adam and Nesterov variants work well despite lacking global convergence guarantees.
\item \textbf{Constraint handling:} Augmented Lagrangian (multiplier method) and ADMM overcome the ill-conditioning introduced by large $\lambda$ in penalty methods by simultaneously updating dual variables, achieving exact constraint satisfaction without requiring $\lambda \to \infty$.
\end{itemize}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
