\begin{abstract}
This report presents a comprehensive comparative study of optimisation algorithms applied to three
benchmark problems: a linear regression quadratic loss~(Benchmark~A), a toy neural network loss
with sinusoidal perturbation~(Benchmark~B), and the Rosenbrock function~(Benchmark~C).  Six
categories of methods are investigated across six questions.

\textbf{Question~1} examines adaptive step-size methods: the Polyak rule, Adagrad, RMSprop, and
the Heavy Ball (Polyak momentum) method.  The Polyak rule achieves the best single-run convergence
on Rosenbrock where $f^\star=0$ is known exactly, but diverges when $f^\star$ is misspecified ---
a fundamental sensitivity identified and explained via the step-size formula.

\textbf{Question~2} studies momentum and stochastic methods: Nesterov acceleration and Adam.
Nesterov achieves the theoretical $O(1/k^2)$ improvement over GD's $O(1/k)$ on the Rosenbrock
valley, while Adam's per-coordinate scaling is highly effective on anisotropic problems.
Mini-batch SGD experiments confirm that smaller batches converge faster per epoch but exhibit
higher variance, and that increased observation noise raises the irreducible loss floor by
$\sigma^2$.

\textbf{Question~3} applies Newton's method with Hessian regularisation, demonstrating quadratic
convergence on near-quadratic benchmarks and showing that exact minimisation of a quadratic
objective requires only one Newton step.  The local second-order Taylor approximation is contrasted
with the first-order (tangent) approximation for $g(x)=x^4$.

\textbf{Question~4} explores derivative-free and finite-difference methods.  Forward finite
differences with step $\delta=0.05$ closely approximate the exact gradient; $\delta=0.8$ degrades
accuracy due to $O(\delta)$ truncation error.  The Nesterov random search requires only two
function evaluations per iteration.  On Rosenbrock, the Nelder--Mead simplex method outperforms
grid search in accuracy per function evaluation.

\textbf{Question~5} compares projected gradient descent and quadratic penalty methods for
constrained optimisation with $x_1\ge0.5$.  Projected GD achieves hard feasibility from the
first iterate; all tested penalty weights ($\lambda\in\{0.15,1.8,4.5\}$) ultimately converge
to the feasible constrained minimum since the unconstrained optimum ($x_1^\star=0.582$) already
lies in the feasible region.  KKT conditions are derived for both the interior and boundary cases,
and the conditioning trade-off of penalty methods ($\kappa\propto\lambda$ for large $\lambda$)
is analysed.

\textbf{Question~6} derives the linear-programming solution over a box constraint set analytically,
then applies the Frank--Wolfe (conditional gradient) algorithm to both interior and boundary
optima, illustrating the algorithm's projection-free nature and $O(1/k)$ convergence rate.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation is the mathematical backbone of machine learning and data analysis: training a
model, fitting a regression, or finding a portfolio allocation all reduce to minimising some
objective function.  This report systematically investigates the behaviour of a broad class
of optimisation algorithms, ranging from simple constant-step gradient descent to second-order
Newton methods, modern adaptive optimisers (Adagrad, Adam), and constrained/projection-free
approaches (Frank--Wolfe).

The experiments are organised around six themes dictated by the CS7DS2 final assignment brief:
\begin{enumerate}[nosep]
\item \textbf{Adaptive step-size methods} (Q1): Polyak step, Adagrad, RMSprop, Heavy Ball.
\item \textbf{Momentum and stochastic methods} (Q2): Nesterov acceleration, Adam, mini-batch SGD.
\item \textbf{Newton's method and local approximation} (Q3): second-order methods, quadratic convergence.
\item \textbf{Derivative-free optimisation} (Q4): finite differences, random search, Nelder--Mead, grid search.
\item \textbf{Constrained optimisation} (Q5): projected gradient descent, penalty methods, KKT conditions.
\item \textbf{Frank--Wolfe algorithm} (Q6): linear-programme oracle, projection-free constrained optimisation.
\end{enumerate}

Three benchmark functions of increasing difficulty are used throughout:
\textbf{A}~(quadratic, $\kappa\approx1$), \textbf{B}~(near-quadratic, $\kappa\approx10$), and
\textbf{C}~(Rosenbrock, $\kappa\approx500$).  The Rosenbrock function serves as the main
discriminator between methods: its narrow, curved valley severely penalises gradient methods
that do not account for local curvature, making it ideal for highlighting the advantages of
momentum, Newton, and adaptive approaches.

\textbf{Relationship between algorithm families:}  Many of the methods studied are closely
related.  Heavy Ball and Nesterov both add a momentum term to gradient descent, but Nesterov's
\emph{lookahead} evaluation at the extrapolated point distinguishes it theoretically and
practically.  Adam can be viewed as RMSprop with an added Heavy Ball momentum term, combined
with bias correction.  The Polyak step can be seen as an optimal per-iteration step computed
from first principles, contingent on knowing $f^\star$.  Newton's method is a limiting case
of quasi-Newton methods (L-BFGS, BFGS), which approximate the Hessian from gradient differences.

All code is implemented in Python~3 with NumPy (version-agnostic, no external optimisation
libraries used), and figures are generated with Matplotlib.  The full implementation is
provided in Appendix~\ref{app:code}.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and $d=2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix},\quad
x^{(i)} \sim \mathcal{N}(0, I_2),\quad
y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)},\quad
\varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2
           = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a \emph{strongly convex quadratic} with constant Hessian $H = \frac{1}{m}X^T X \succ 0$.
The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$.  The smoothness constant
$L = \lambda_{\max}(H)$ and strong convexity constant $\mu = \lambda_{\min}(H)$ determine the
condition number $\kappa_A = L/\mu$.  With $m=1000$ standard normal rows, the law of large
numbers gives $\frac{1}{m}X^TX \approx I_2$, so in practice $\kappa_A \approx 1.0$
(well-conditioned), and a step size $\alpha < 2/L \approx 2$ is stable.  The baseline uses
$\alpha = 0.08 \ll 1/L$, which is conservative but safe.  Because of the observation noise,
the minimum loss is $J^\star \approx 0.4826$, not zero.  Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Quadratic Loss}

\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\; 10(x_2 - 2)]^T$ and the Hessian is
\begin{equation}
H(x) = \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}.
\end{equation}
The diagonal structure means the problem separates into two independent 1-D problems; however,
the curvature ratio between coordinates creates \emph{anisotropy}.  Since
$\sin(x_1)\in[-1,1]$, the Hessian eigenvalues satisfy $h_{11}\in[1,3]$ and $h_{22}=10$,
giving an approximate condition number $\kappa_B \in [10/3,\, 10]$.  The minimum lies at
approximately $(x_1^\star, x_2^\star) \approx (0.582, 2.0)$, obtained numerically by solving
$2(x_1-1)+\cos(x_1)=0$ (root near $x_1\approx0.582$ since
$2(0.582-1)\approx-0.836$ and $\cos(0.582)\approx0.836$), with $f^\star \approx 0.7244$.
The GD stability condition $\alpha \le 2/L = 2/10 = 0.2$ is satisfied by $\alpha=0.06$.
Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$.  The Hessian is
\begin{equation}
H(x) = \begin{bmatrix}
2 + 1200 x_1^2 - 400 x_2 & -400 x_1 \\
-400 x_1 & 200
\end{bmatrix}.
\end{equation}
At the optimum $(1,1)$:
\begin{equation}
H(1,1) = \begin{bmatrix} 2 + 1200 - 400 & -400 \\ -400 & 200 \end{bmatrix}
        = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}.
\end{equation}
The eigenvalues of $H(1,1)$ are $\lambda_{1,2} = 501 \pm \sqrt{501^2 - (802\cdot200 - 400^2)}
= 501 \pm 499.25$, giving $\lambda_1 \approx 1000$ and $\lambda_2 \approx 2$, hence
condition number $\kappa_C \approx 500$.  (The commonly cited value $\kappa\approx2000$ arises
from the Hessian at nearby points; at the exact optimum the conditioning is somewhat milder
though still very large.)  The GD stability condition requires
$\alpha \le 2/\lambda_1 \approx 0.002$, which is why the baseline uses $\alpha = 0.0012$.
Starting point: $x_0 = [-1, 1]^T$.

The Rosenbrock function has two geometrically distinct phases:
\textbf{Phase 1 (descent to valley floor)}: The initial steep descent from $f(-1,1)=4$ to the
parabolic valley $x_2 \approx x_1^2$.  This phase is rapid for all methods.
\textbf{Phase 2 (valley traversal)}: Progress along the valley floor from
$(-1,1)$ towards $(1,1)$.  The valley direction has very low curvature ($\lambda_2 \approx 2$),
while the transverse direction has high curvature ($\lambda_1 \approx 1000$ at the optimum).
The step size is limited by $\lambda_1$ ($\alpha \le 2/1000 = 0.002$), so each step moves
$\alpha \lambda_2 = 0.002 \times 2 = 0.004$ units along the valley --- making Phase 2 very slow
for GD.  Momentum methods build up velocity along the consistent valley direction, while Newton's
Hessian captures the anisotropy directly.  This explains the clear separation between methods
visible in Figure~\ref{fig:summary_rosenbrock}.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

Let $f:\mathbb{R}^d\to\mathbb{R}$ be $L$-smooth (i.e., $\|\nabla f(x) - \nabla f(y)\| \le L\|x-y\|$
for all $x,y$) and $\mu$-strongly convex ($f(y) \ge f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$).
Standard gradient descent with constant step $\alpha\le 1/L$ satisfies
\begin{equation}
f(x_k) - f^\star \;\le\; \left(1 - \frac{\mu}{L}\right)^k \bigl(f(x_0) - f^\star\bigr),
\end{equation}
converging \emph{linearly} at rate $\rho = 1-\mu/L = 1 - 1/\kappa$ per iteration, where
$\kappa=L/\mu$ is the condition number.  On Benchmark~A ($\kappa\approx1$), GD converges in
a few tens of iterations.  On Benchmark~C ($\kappa\approx500$), GD's rate is $\approx1-1/500$
per iteration, requiring hundreds of iterations for a single order-of-magnitude reduction ---
motivating the adaptive and momentum methods studied here.

A larger step $\alpha > 2/L$ causes divergence due to the descent lemma violation.  The
condition $\alpha \le 1/L$ guarantees the \emph{descent lemma} (also called the $L$-smoothness
sufficient decrease condition):
\begin{equation}
f(x_{k+1}) \;\le\; f(x_k) - \alpha\left(1 - \frac{\alpha L}{2}\right)\|\nabla f(x_k)\|^2.
\end{equation}
For $\alpha = 1/L$, this becomes $f(x_{k+1}) \le f(x_k) - \frac{1}{2L}\|\nabla f(x_k)\|^2$,
giving the best guaranteed decrease per step.  Combined with strong convexity
$f(x) - f^\star \le \frac{1}{2\mu}\|\nabla f(x)\|^2$, one derives the linear convergence rate:
\begin{equation}
f(x_{k+1}) - f^\star \;\le\; \left(1 - \frac{\mu}{L}\right)(f(x_k) - f^\star),
\end{equation}
with contraction factor $\rho = 1 - 1/\kappa$.  Each method in this section attempts to
improve upon $\rho$ by adapting the step to local curvature.

\textbf{Adaptive methods as implicit preconditioners.}  The fundamental motivation for adaptive
step sizes is the recognition that gradient descent applies a \emph{scalar} scaling to the
gradient, whereas the ideal update would scale each coordinate (or direction) inversely by its
local curvature.  This ideal is the Newton step, which applies $H_k^{-1}$, the full Hessian
inverse (a $d\times d$ matrix).  Adaptive methods approximate this ideal cheaply:

\begin{itemize}[nosep]
  \item \textbf{Adagrad} approximates $H^{-1}$ by a \emph{diagonal} matrix
    $D_k = \mathrm{diag}(1/\sqrt{G_{k,j}})$, using the cumulative squared gradient as a
    running proxy for curvature.  For a quadratic $f$ with diagonal Hessian $H=\mathrm{diag}(h_j)$,
    after many iterations $G_k \approx k\cdot h_j \cdot \|x^\star\|^2$, giving
    $D_k \approx C/\sqrt{h_j}$ --- matching the scaling of $H^{-1/2}$.
  \item \textbf{RMSprop} makes the same approximation but forgets old curvature information,
    adapting to local curvature near the current point.
  \item \textbf{Adam} combines this with gradient momentum, inheriting properties of both
    the preconditioning (from RMSprop) and the momentum (from Heavy Ball).
\end{itemize}

All diagonal adaptive methods are therefore \emph{diagonal-matrix preconditioned} gradient
descent, in contrast to the full-matrix preconditioning of Newton's method.

\begin{definition}[Polyak Step Size]
Given an estimate $f^\star$ of the optimal value, the Polyak step at $x_k$ is
\begin{equation}
\alpha_k^{\mathrm{P}} = \frac{f(x_k) - f^\star}{\|\nabla f(x_k)\|^2 + \varepsilon}.
\end{equation}
\end{definition}

\begin{theorem}[Polyak Convergence]
If $f$ is convex and $f^\star$ is exact, the Polyak rule satisfies
$\min_{k\le N} f(x_k) - f^\star = O(1/\sqrt{N})$ for convex $f$, and achieves linear convergence
for strongly convex $f$ without requiring knowledge of $L$ or $\mu$.
\end{theorem}

\begin{remark}
When $f^\star$ is misspecified (e.g.\ $f^\star=0$ but the true minimum is $\approx0.48$), as
$\|\nabla f(x_k)\|\to0$ while $f(x_k)-f^\star\to f_{\mathrm{true}}^\star>0$, the step size
$\alpha_k\to\infty$, causing divergence.
\end{remark}

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across
all three benchmarks for 120~iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate sum of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's effective learning rate for coordinate~$j$ is $\alpha_0/\sqrt{\sum_{k} g_{k,j}^2}$.
This \emph{monotonically decreases} with the gradient history, providing large updates for
infrequent features and small updates for frequent ones.  The monotonic decrease can cause
premature stalling on non-stationary objectives.

\begin{proposition}[Adagrad Online Regret Bound]
For an online convex sequence of functions $f_k$ with gradients bounded $\|g_k\|_\infty \le G$,
Adagrad achieves a cumulative regret bound:
\begin{equation}
\sum_{k=1}^K f_k(x_k) - \min_{x^\star} \sum_{k=1}^K f_k(x^\star)
\;\le\; \frac{\|x_0 - x^\star\|_2^2}{2\alpha_0} \sum_{j=1}^d \sqrt{\sum_{k=1}^K g_{k,j}^2}
\;\le\; \frac{\alpha_0 d G \sqrt{K}}{2}.
\end{equation}
The regret is $O(\sqrt{K})$, matching the minimax optimal rate for online convex optimisation,
and scales with the per-coordinate gradient magnitude (sparse features benefit more).
\end{proposition}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop fixes Adagrad's vanishing-rate problem by replacing the cumulative sum with an exponential
moving average (EMA) with decay factor $\beta$.  The effective window size is $1/(1-\beta)$
iterations, so $\beta=0.9$ gives a window of $\approx10$ recent gradients.  The steady-state
effective learning rate for coordinate~$j$ is $\alpha_0/\sqrt{\langle g_j^2\rangle_{1/(1-\beta)}}$,
where $\langle\cdot\rangle$ denotes a weighted average over the recent window.  Note that RMSprop
has no provably convergent regret bound for general online convex problems --- its analysis is
heuristic, though it is highly effective in practice for non-convex deep learning objectives.
Adam (Section~\ref{sec:q2}, Algorithm~\ref{alg:adam}) can be viewed as RMSprop with added
Heavy Ball momentum and bias correction.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{proposition}[Heavy Ball Optimal Rate for Quadratics]
For a quadratic $f$ with smoothness $L$ and strong convexity $\mu$, the Heavy Ball method with
optimal parameters $\alpha^\star = \bigl(\tfrac{2}{\sqrt{L}+\sqrt{\mu}}\bigr)^2$ and
$\beta^\star = \bigl(\tfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\bigr)^2$ achieves
\begin{equation}
\|x_k - x^\star\| \;\le\; \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k\|x_0-x^\star\|,
\end{equation}
improving GD's rate of $(1-1/\kappa)$ to $(1-1/\sqrt{\kappa})$ per iteration.
\end{proposition}

\textbf{Key finding:} The Polyak step size is highly sensitive to the accuracy of $f^\star$.
When $f^\star = 0$ deviates from the true minimum (Benchmarks A and B), the iterates eventually
enter a regime where $f(x_k) \to f^\star_{\mathrm{true}} > 0$ while $\|\nabla f(x_k)\| \to 0$,
causing $\alpha_k = (f(x_k) - 0)/(\|\nabla f(x_k)\|^2 + \varepsilon) \to \infty$.  An
unbounded step size violates the descent lemma, leading to overshoot and oscillation.
This sensitivity is the fundamental weakness of the Polyak rule in practice.

\textbf{Adagrad's coordinate-wise adaptation} provides a notable advantage on Benchmark~C:
the large transverse gradient (magnitude $\sim$hundreds near the start) accumulates rapidly

the flatter valley floor.  This implicit anisotropic preconditioning helps navigate the
banana-shaped valley.

\textbf{RMSprop's limitation on Rosenbrock} stems from its exponential forgetting factor
$\beta=0.9$: with an effective window of $1/(1-0.9)=10$ iterations, it ``forgets'' the
history of large transverse gradients quickly, so it cannot exploit the long-term curvature
difference as effectively as Adagrad.

\subsection{Theoretical Background}

\begin{theorem}[Nesterov Optimal Rate \textnormal{[1]}]
For an $L$-smooth convex function $f$ and the Nesterov accelerated gradient method with the
adaptive momentum schedule $\beta_k = (k-1)/(k+2)$, the following bound holds:
\begin{equation}
f(x_k) - f^\star \;\le\; \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2}.
\end{equation}
This $O(1/k^2)$ rate is \textbf{optimal} among first-order methods for smooth convex
optimisation --- no first-order method can achieve a better worst-case rate (per the
complexity lower bound proved in [1]).
\end{theorem}

\begin{remark}[Heavy Ball vs.\ Nesterov]
The Heavy Ball method (Section~\ref{sec:q1}, Algorithm~\ref{alg:heavyball}) also uses a momentum
term but does \emph{not} evaluate the gradient at the lookahead point.  This subtle difference
has major consequences: Heavy Ball achieves the optimal quadratic rate
$((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1))^k$ on strictly quadratic objectives (Proposition~1 in
Section~\ref{sec:q1}) but fails to achieve $O(1/k^2)$ on general convex problems, and can even
diverge on some non-strongly-convex problems~[8].  Nesterov's lookahead
$\tilde{x}_k = x_k + \beta_k z_k$ enables a ``corrected gradient'' that accounts for where the
iterate is \emph{going}, not just where it is, yielding the universally optimal $O(1/k^2)$ rate.
\end{remark}

Compare with the $O(1/k)$ rate of vanilla gradient descent.  Nesterov's key insight is the
\emph{lookahead}: computing the gradient at the \emph{extrapolated} point $\tilde{x}_k$
rather than $x_k$ allows the method to correct its trajectory before overshooting.

Figure~\ref{fig:nesterov_lookahead} visualises the lookahead mechanism on Benchmark~B and
contrasts Nesterov with Heavy Ball, illustrating why the gradient evaluation point matters.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/nesterov_lookahead_viz.pdf}
\caption{Q2: Nesterov lookahead mechanism on Benchmark~B (12 iterations).  Left: $x_k$
(blue circles) and the lookahead points $\tilde{x}_k = x_k + \beta_k z_k$ (red triangles),
connected by arrows showing the momentum step before gradient evaluation.  The gradient
is evaluated at $\tilde{x}_k$, not $x_k$, providing a ``corrected'' direction that accounts
for where the iterate is heading.  Right: comparison with Heavy Ball (Q1 parameters
$\alpha=0.06$, $\beta=0.90$).  Heavy Ball diverges to $f=4.93$ after 12 iterations because
the momentum overshoots the minimum --- Heavy Ball evaluates the gradient at $x_k$ and then
adds the full accumulated momentum, causing oscillations that grow in amplitude.  Nesterov's
lookahead prevents this: the gradient at $\tilde{x}_k$ ``sees'' the overshoot coming and
applies a corrective force, maintaining stability and achieving $f=0.733$ after 12 iterations.}
\label{fig:nesterov_lookahead}
\end{figure}

\begin{proposition}[Adam Bias Correction]
Without bias correction, the first few Adam iterates are biased towards zero because $m_0=v_0=0$.
The correction factors $(1-\beta_1^t)^{-1}$ and $(1-\beta_2^t)^{-1}$ remove this bias,
ensuring $\hat{m}_1 \approx g_1$ and $\hat{v}_1 \approx g_1^2$ regardless of the momentum
parameters.
\end{proposition}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\; \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead / extrapolation point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Velocity update}
    \State $x_{k+1} \gets x_k + z_{k+1}$ \Comment{Position update}
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at
$\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$, providing a correction to the current
momentum direction.  The adaptive schedule $\beta_k=(k-1)/(k+2)$ increases momentum gradually
from~0, achieving the $O(1/k^2)$ rate on convex functions.  The clamp to $\beta_{\max}$ prevents
the schedule from being too aggressive on non-convex objectives.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\; v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First-moment (gradient) EMA}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second-moment (squared gradient) EMA}
    \State $\hat{m}_t \gets m_t\;/\;(1 - \beta_1^t)$ \Comment{Bias correction}
    \State $\hat{v}_t \gets v_t\;/\;(1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\; \hat{m}_t\;/\;(\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$) with per-coordinate adaptive scaling (via $v_t$), inheriting
advantages of both RMSprop and Heavy Ball.  The effective step size for coordinate~$j$ is bounded:
$|\Delta x_{t,j}|\le \alpha\,(1+\varepsilon^{-1})$.  This bounded-step property makes Adam
robust across diverse problem scales, which partly explains its widespread adoption in deep
learning.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark~A uses learning rate $\alpha = 0.06$, batch sizes
$b \in \{5, 40\}$, 50~epochs, with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1,\ldots,m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

With $m=1000$ samples, batch size $b=5$ gives $200$ gradient steps per epoch, while $b=40$ gives
$25$ steps per epoch.  The stochastic gradient $\hat{g}_{\mathcal{B}} = \frac{1}{b}X_\mathcal{B}^T
(X_\mathcal{B}\theta - y_\mathcal{B})$ is an unbiased estimator of $\nabla J(\theta)$, with
variance $\mathrm{Var}[\hat{g}] = \frac{1}{b}\sigma_{\mathrm{batch}}^2$ where
$\sigma_{\mathrm{batch}}^2$ depends on the data spread.  SGD with constant step size cannot
converge to $J^\star$ but oscillates within a ball of radius $O(\alpha\sigma^2_{\mathrm{batch}}/b)$
around the optimum.  This explains the oscillation visible near the noise floor.
Figure~\ref{fig:q2_sgd_variance} empirically confirms the $1/b$ scaling of gradient variance.

\subsection{Noise Floor Analysis}

\begin{proposition}[SGD Noise Floor]
For strongly convex $f$ with step size $\alpha$ and mini-batch gradient noise variance
$\sigma^2_b = \sigma^2/b$ (where $\sigma^2$ is the per-sample gradient variance), constant
step-size SGD converges to a neighbourhood of the optimum:
\begin{equation}
\limsup_{k\to\infty}\;\mathbb{E}[f(\theta_k)] - f^\star \;\le\; \frac{\alpha L \sigma^2_b}{2\mu}
= \frac{\alpha L \sigma^2}{2\mu b}.
\end{equation}
\end{proposition}

For Benchmark~A: $\sigma^2$ is the noise from the data labels, so $f^\star = J^\star = \sigma^2_{\rm obs}/(2)$
plus contributions from the finite dataset.  With observation noise $\varepsilon^{(i)}\sim\mathcal{N}(0,\sigma^2_{\rm obs})$
and the Bayes-optimal linear predictor fitting $\theta^\star$, the irreducible loss is
$J^\star = \sigma^2_{\rm obs}/2$.  For $\sigma_{\rm obs}=1$: $J^\star\approx 0.4826$; for
$\sigma_{\rm obs}=6$ ($\sigma^2_{\rm obs}=36$): $J^\star\approx 0.4826\times36\approx 17.4$.
The numerical experiments confirm this scaling (the noise floor shifts up by factor~36 in
Figure~\ref{fig:q2_sgd_noisy}).

\subsection{Nesterov vs. Adam: Complementary Strengths}

The experiments reveal a clear pattern: Nesterov outperforms Adam on Rosenbrock ($f=0.479$ vs.
$f=1.578$), while both methods achieve similar accuracy on the quadratic and near-quadratic
benchmarks.  This difference can be explained by the distinct mechanisms of each method:

\begin{itemize}[nosep]
  \item \textbf{Nesterov's advantage on non-linear, ill-conditioned problems:} The momentum
    accumulated by Nesterov points along the valley floor direction, which is consistent across
    many iterations.  The lookahead gradient corrects this direction before overshooting.  Since
    the Rosenbrock valley has a consistent downhill direction (roughly along the curve
    $x_2 = x_1^2$), momentum accumulation is highly effective.

  \item \textbf{Adam's advantage on anisotropic, separable problems:} The per-coordinate scaling
    $\hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$ effectively ``normalises'' the gradient in
    each coordinate, reducing the problem's effective condition number.  For Benchmark~B with
    its diagonal Hessian (condition number $\approx 7$), this provides a near-perfect adaptation.
    However, for Rosenbrock, the off-diagonal Hessian terms ($H_{12} = -400x_1$) represent
    coupling between coordinates --- coupling that coordinate-wise scaling cannot exploit.

  \item \textbf{Adam's second moment on Rosenbrock:} The large gradient in the steep transverse
    direction dominates $v_t$, causing Adam to take very small steps in \emph{both} the steep
    and flat directions.  Unlike Nesterov's momentum (which preferentially builds velocity in
    the consistent low-curvature direction), Adam's normalisation penalises the flat direction
    when the transverse gradient is large --- a fundamental limitation on coupled, anisotropic
    problems.
\end{itemize}

\textbf{Practical recommendation:} Use Adam for coordinate-separable problems (diagonal or near-diagonal
Hessian), especially in deep learning where gradient distributions vary widely across layers.
Use Nesterov for well-structured convex problems with consistent gradient directions.  For
highly coupled, ill-conditioned problems, quasi-Newton methods (L-BFGS) are preferable to both.

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$: using $g'(x) = 4x^3$ and
$g(0.25) = 0.0039$, $g'(0.25) = 0.0625$:
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order (quadratic) approximation:} using $g''(x) = 12x^2$,
$g''(0.25) = 0.75$:
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
           = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises the second-order approximation.  Setting the derivative to zero:
$g'(x_0) + g''(x_0)(x-x_0) = 0$, giving the Newton step
\begin{equation}
x_1 = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\end{equation}
This corresponds to stepping to the stationary point of the local quadratic model.

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Newton's Method with Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction: solve $H_k p_k = g_k$}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Newton's Quadratic Convergence]
\label{thm:newton_quad}
Let $f$ be twice continuously differentiable, with $\nabla^2 f(x^\star) \succ 0$ and
$\|\nabla^2 f(x) - \nabla^2 f(y)\| \le M\|x-y\|$ (Lipschitz Hessian).  If $\|x_0 - x^\star\|$
is sufficiently small, the undamped Newton iterates satisfy
\begin{equation}
\|x_{k+1} - x^\star\| \;\le\; \frac{M}{2\mu}\|x_k - x^\star\|^2,
\end{equation}
where $\mu = \lambda_{\min}(\nabla^2 f(x^\star))$.  This \emph{quadratic (superlinear)} convergence
is the fundamental advantage of Newton's method over first-order methods.
\end{theorem}

\begin{remark}[Affine Invariance]
A key advantage of Newton's method is affine invariance: the Newton step $p_k = H_k^{-1}g_k$ is
identical for any invertible linear reparameterisation $x = Ay$ of the problem.
\textbf{Proof:} Under the change of variables $y = A^{-1}x$, the function becomes
$\tilde{f}(y) = f(Ay)$.  The gradient and Hessian transform as
$\nabla_y \tilde{f}(y) = A^T \nabla f(Ay)$ and $\nabla^2_y \tilde{f}(y) = A^T H(Ay) A$.
The Newton step in $y$-space is
$p_y = -(A^T H A)^{-1} A^T g = -A^{-1} H^{-1} g$,
corresponding to $p_x = A p_y = -H^{-1} g = p_k$ in $x$-space --- identical.
For gradient descent in $y$-space, $p_y = -\alpha A^T g$, corresponding to
$p_x = A(-\alpha A^T g) = -\alpha A A^T g \ne -\alpha g$ unless $A$ is orthogonal.
The condition number of $\tilde{f}$ in $y$-space is $\kappa(\tilde{H}) = \kappa(A^T H A)$,
which can be arbitrarily worse (or better) than $\kappa(H)$, affecting GD's convergence rate.
Newton is thus unaffected by ill-conditioning and affine stretching of the problem geometry.
For Benchmark~A (quadratic), this implies exact convergence in \emph{one step} from any starting
point.
\end{remark}

\begin{remark}[Damped Newton on Non-Quadratic Problems]
For the Rosenbrock function, the undamped Newton step ($\alpha=1$) frequently overshoots
because the quadratic model is only locally accurate in a small neighbourhood of radius
$\approx \|(\nabla^2 f)^{-1}\nabla f\| / M$ where $M$ is the Lipschitz constant of the Hessian.
The Rosenbrock Hessian changes rapidly along the curved valley (the mixed partial $h_{12}=-400x_1$
varies from $400$ to $-400$ as $x_1$ crosses the valley), requiring the damped step $\alpha=0.22$
to maintain the quadratic model accuracy across each Newton iterate.  Backtracking line search
would automate this damping adaptively.
\end{remark}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping $\lambda = 10^{-8}$.

\subsection{Limitations of Newton's Method and Practical Considerations}

Despite its quadratic convergence rate, Newton's method has important limitations that often
prevent its direct use in high-dimensional machine learning settings:

\begin{enumerate}[nosep]
  \item \textbf{Hessian storage and computation ($O(d^2)$ cost):}  For $d$ parameters, the
    Hessian $\nabla^2 f \in \mathbb{R}^{d\times d}$ requires $O(d^2)$ memory.  For modern
    neural networks with $d = 10^7$ parameters, this is $\sim$800~GB --- completely infeasible.
    Explicit gradient descent by contrast stores only the $d$-dimensional gradient.

  \item \textbf{Linear system solve ($O(d^3)$ per step):}  Computing the Newton direction
    $p_k = H_k^{-1}g_k$ requires solving a $d\times d$ linear system, costing $O(d^3)$ via
    Cholesky or LU factorisation.  For $d = 10^4$, this is $10^{12}$ operations per iteration,
    compared to $O(d)$ for gradient descent.

  \item \textbf{Non-convex objectives:}  When $\nabla^2 f(x_k) \not\succ 0$ (e.g., near a
    saddle point or on the non-convex Rosenbrock for large $\|x\|$), the Newton direction may
    point uphill.  Tikhonov regularisation $H_k + \lambda I$ (used in our implementation)
    restores positive definiteness but at the cost of exactness.

  \item \textbf{Global convergence:}  Newton's method is only locally convergent: the quadratic
    rate applies only within a ball of radius $r \sim \mu/M$ around $x^\star$ (where $M$ is
    the Lipschitz constant of $\nabla^2 f$).  Far from the optimum, damping ($\alpha < 1$) or
    globalisation via backtracking line search is required.
\end{enumerate}

\textbf{Practical alternative:} Quasi-Newton methods (L-BFGS, BFGS) approximate $H_k^{-1}$
from the $m$ most recent gradient differences, achieving superlinear convergence
($\|x_{k+1}-x^\star\|/\|x_k-x^\star\|\to0$, though not exactly quadratic) at cost $O(md)$
per step with only $O(md)$ memory.  L-BFGS with $m=10$--$30$ is the de facto standard
second-order method for unconstrained ML problems.

\begin{table}[H]
\centering
\caption{Computational cost comparison for second-order methods ($d$ = dimension).}
\label{tab:second_order_cost}
\begin{tabular}{lccc}
\toprule
\textbf{Method} & \textbf{Memory} & \textbf{Cost/iter} & \textbf{Conv.\ rate} \\
\midrule
Gradient descent & $O(d)$ & $O(d)$ & Linear \\

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
\end{equation}
The approximation error decomposes as
\begin{equation}
\left|\frac{\partial f}{\partial x_i}(x) - \frac{f(x + \delta e_i) - f(x)}{\delta}\right|
\;\le\; \frac{\delta}{2}\left\|\frac{\partial^2 f}{\partial x_i^2}\right\|_\infty
      + \frac{2\varepsilon_{\mathrm{mach}}}{\delta},
\end{equation}
where the first term is the $O(\delta)$ \emph{truncation error} and the second is the
$O(\varepsilon_{\mathrm{mach}}/\delta)$ \emph{roundoff error}.  The optimal step minimising
total error is $\delta^\star = (2\varepsilon_{\mathrm{mach}}/\|f''\|)^{1/2} \approx 10^{-8}$
for double precision.  The assignment tests $\delta = 0.05$ (close to useful) and
$\delta = 0.8$ (truncation-dominated, poor).  This requires $d+1 = 3$ function evaluations per
iteration for $d=2$.

\textbf{Central differences} offer a higher-order alternative:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x - \delta e_i)}{2\delta}.
\end{equation}
The truncation error is $O(\delta^2)$ rather than $O(\delta)$, because the odd-order Taylor
terms cancel in the symmetric difference.  However, central differences require $2d$ function
evaluations per gradient (vs.\ $d+1$ for forward differences), doubling the per-iteration cost.
For $\delta=0.05$, the forward truncation error is $\approx\frac{0.05}{2}\cdot|f''|\approx 0.1$
while the central error is $O(0.05^2) \approx 0.003$ --- a 30$\times$ improvement in gradient
accuracy at 2$\times$ the function evaluation cost.  For $\delta=0.8$, central differences are
essential: the forward truncation error $\sim\frac{0.8}{2}\cdot|f''|\approx 4$ is larger than
typical gradient magnitudes, rendering the gradient direction useless.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order Method)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$; normalise $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{One-sided directional estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates a \emph{directional derivative} along a random unit vector,
using only two function evaluations per iteration regardless of dimension~$d$.  The expected
directional estimate satisfies
\begin{equation}
\mathbb{E}_u[\hat{g}_k] = \frac{1}{d}\nabla f_\delta(x_k),
\end{equation}
where $f_\delta(x) = \mathbb{E}_u[f(x + \delta u)]$ is a smoothed version of $f$.  The method
is therefore an $O(\delta)$-biased gradient estimator: as $\delta\to0$, $\mathbb{E}[\hat{g}_k]
\to \nabla f(x_k)/d$.  Since the estimate is scaled by $1/d$, the effective step size towards
the gradient direction is $\alpha_{\mathrm{eff}} = \alpha/d$, explaining why Nesterov random
search converges more slowly in higher dimensions.

\textbf{Theoretical guarantee:} For $L$-smooth convex $f$ and step size $\alpha = 1/(Ld^2)$,
Nesterov's zeroth-order method requires $O(d^2/\epsilon)$ function evaluations to find an
$\epsilon$-approximate solution, compared to $O(d/\epsilon)$ for gradient methods with exact
gradients.  The extra factor of $d$ reflects the averaging loss from random directional sampling.

Hyperparameters used: step size $\alpha=0.025$, perturbation $\delta=0.08$, 220 iterations.
The FD GD variants use step size $\alpha=0.08$ (not the same as exact GD's $\alpha=0.06$),
chosen to be stable with the less accurate gradient estimates.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and
iteratively transforms it through four operations:
\begin{enumerate}[nosep]
  \item \textbf{Reflection} ($\alpha_r = 1.0$): move the worst vertex through the centroid of
    the remaining $n$ vertices.
  \item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, try further movement.
  \item \textbf{Contraction} ($\rho = 0.5$): if reflection worsened, contract towards the centroid.
  \item \textbf{Shrink} ($\sigma = 0.5$): contract all vertices towards the best, as a last resort.
\end{enumerate}
No gradient information is required; the method operates purely on function values.  The simplex
geometry adapts to the local landscape shape.  Settings: initial simplex step $= 0.35$, 160
iterations.

\begin{remark}[Nelder--Mead Convergence Theory]
Unlike gradient methods, Nelder--Mead has no general convergence guarantee for $d \ge 2$.
In one dimension it converges to a local minimum.  For $d=2$, convergence to a non-stationary
point is possible even in theory (Lagarias et al.\ 1998 showed non-convergence examples for
smooth objectives).  Despite this, Nelder--Mead performs well in practice on low-dimensional,
moderately smooth functions like Benchmark~C, because its simplex geometry naturally adapts to
elongate along the Rosenbrock valley floor and squeeze out of the transverse direction.  The
final simplex diameter provides an empirical convergence certificate: when all simplex vertices
agree to $\varepsilon$, the solution is $\varepsilon$-accurate.
\end{remark}

\textbf{Key insight:} Derivative-free methods are preferable when gradients are unavailable
(black-box functions, non-differentiable objectives, simulation-based optimisation).  For
$d=2$, Nelder--Mead achieves better accuracy than grid search with fewer function evaluations.
For high-dimensional problems, random search scales better than grid search, but the statistical
efficiency decreases as $d$ grows.

\textbf{Method selection guidelines:}
\begin{itemize}[nosep]
  \item \textbf{Gradients available:} Always prefer exact gradient methods (GD, Nesterov, Adam).
    FD approximation adds $O(\delta)$ bias; use only when analytic gradient is unavailable.
  \item \textbf{$d$ small ($d \le 10$), function is smooth:} Nelder--Mead is a strong choice
    for derivative-free optimisation.  It uses local geometric information and adapts its step.
  \item \textbf{$d$ moderate ($10 \le d \le 1000$):} Nesterov random search or evolution
    strategies (CMA-ES).  Grid search is infeasible ($N^d$ evaluations for any grid resolution).
  \item \textbf{$d$ large ($d > 1000$):} Requires gradient information or structured smoothing.
    Zeroth-order methods lose efficiency as the random direction becomes increasingly orthogonal
    to the true gradient in high dimensions ($\cos\theta \sim d^{-1/2}$).
  \item \textbf{Discrete/non-differentiable:} Grid search (exhaustive) or genetic algorithms
    (population-based).
\end{itemize}

\subsection{Problem Setup and KKT Conditions}

Minimise $f(x) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1)$ subject to $x_1 \ge 0.5$, starting from
the infeasible point $x_0 = (0.2, 4.0)$.

\textbf{KKT Conditions.} For this single inequality constraint $g(x) = 0.5 - x_1 \le 0$, the
first-order necessary conditions at a local minimum $x^\star$ are:
\begin{align}
\nabla f(x^\star) - \mu^\star \nabla g(x^\star) &= 0 \quad\Leftrightarrow\quad
    \nabla f(x^\star) + \mu^\star e_1 = 0,\label{eq:kkt1}\\
\mu^\star &\ge 0,\label{eq:kkt2}\\
g(x^\star) &\le 0,\label{eq:kkt3}\\
\mu^\star g(x^\star) &= 0 \quad\text{(complementary slackness)}.\label{eq:kkt4}
\end{align}

\textbf{Case 1 (interior, $x_1^\star > 0.5$):} Complementary slackness gives $\mu^\star = 0$,
and (\ref{eq:kkt1}) reduces to $\nabla f(x^\star) = 0$, identical to the unconstrained minimum.
For Benchmark~B, the unconstrained minimum is at $(0.582, 2.0)$, which satisfies $x_1^\star > 0.5$,
so the constraint is inactive and the constrained and unconstrained minima coincide.

\textbf{Case 2 (boundary, $x_1^\star = 0.5$):} The constraint is active.
From (\ref{eq:kkt1}), $\mu^\star = -(\nabla f)_1|_{x_1=0.5} = -(2(0.5-1)+\cos(0.5)) =
-(−1 + 0.878) = 0.122 > 0$, confirming feasibility of the KKT point.
However, since the unconstrained minimum already lies in the feasible region ($x_1^\star=0.582>0.5$),
the constraint is \emph{inactive} at optimality, and both projected GD and penalty methods should
converge to the unconstrained minimum $(0.582, 2.0)$.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Evaluate $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\; 0.5 - x_1)$ \Comment{Penalised objective}
    \State Compute $\nabla F_{\lambda}(x) = \nabla f(x) - \lambda\, \mathbf{1}[x_1 < 0.5]\, e_1$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$
($\alpha = 0.05$ for $\lambda \le 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$);
unconstrained GD ($\alpha = 0.07$).  All run for 100 iterations.

\textbf{Projected GD} enforces feasibility immediately at every iteration.  This is the
fundamental advantage: feasibility is a hard constraint, not negotiable.  The cost is requiring
a \emph{projection oracle}~$\Pi_\mathcal{X}$, which for simple constraints like $x_1 \ge 0.5$
is a trivial $\max$ operation, but can be computationally expensive for complex constraint sets
(e.g., semidefinite cone, nuclear-norm ball).

\textbf{Penalty methods} trade exact feasibility for algorithmic simplicity: only a modified
gradient is needed, with no projection oracle.  The penalty weight $\lambda$ controls the
trade-off.  Small $\lambda$ under-penalises violations; large $\lambda$ enforces feasibility
but creates a more ill-conditioned penalised objective, requiring smaller step sizes for
stability.  In this experiment, $\lambda=4.5$ requires $\alpha=0.03$ vs.\ $\alpha=0.05$ for
$\lambda\le1.8$, illustrating this trade-off.

\textbf{Theoretical connection:} As $\lambda\to\infty$, the penalty method solution
$x^\star(\lambda)$ converges to the true constrained optimum $x^\star$.  More precisely, for a
convex problem with inactive constraint at optimality (as here), $\|x^\star(\lambda)-x^\star\|
= O(1/\lambda)$.  At each finite $\lambda$, the method solves an unconstrained problem
$F_\lambda$ with an ill-conditioned objective.  In the infeasible region ($x_1 < 0.5$), the
Hessian of $F_\lambda$ has eigenvalues $\{h_{11} + \lambda,\; h_{22}\} = \{1.164 + \lambda,\; 10\}$.
The condition number is $\kappa(F_\lambda) = \max(1.164 + \lambda, 10)/\min(1.164, 10)$.
For $\lambda < 8.84$ (including our tested values $\lambda\in\{0.15, 1.8, 4.5\}$), the largest
eigenvalue is $h_{22}=10$ (dominated by the $x_2$ curvature), giving
$\kappa(F_\lambda)\approx 8.59$ for all tested lambdas.  This explains why the tested penalty
weights do not require dramatically different step sizes.  For large $\lambda > 8.84$,
$\kappa(F_\lambda)\propto\lambda$, and the maximum stable step size $2/L_\lambda\propto 1/\lambda$,
requiring progressively smaller steps.

\textbf{Augmented Lagrangian methods} (not implemented here) address this conditioning issue
by combining penalty terms with explicit Lagrange multiplier updates:
$L_\lambda(x, \mu) = f(x) + \mu g(x) + \frac{\lambda}{2}[\max(0, g(x))]^2$.  This achieves
exact feasibility at finite penalty while maintaining better conditioning than pure penalty methods.

\textbf{Projection-free alternative:} For constraint sets where the LMO is cheap but the
projection $\Pi_\mathcal{X}$ is expensive (e.g., nuclear norm ball, spectrahedra), the
Frank--Wolfe algorithm (Section~\ref{sec:q6}) provides a projection-free alternative with an
$O(1/k)$ convergence rate.  The trade-off between projected GD ($O(1/k^2)$ rate, $O(d)$
projection cost for simplex) and Frank--Wolfe ($O(1/k)$ rate, $O(nd)$ LMO cost for
rank-1 update) depends on the relative cost of projection vs.\ LMO for the specific
constraint set.  For simple box constraints as in Q5--Q6, both costs are $O(d)$ and projected
GD's faster rate is preferable.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \le x_1 \le 5,\; -5 \le x_2 \le 10\}$.
This is a bounded, closed convex polytope (box).

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1, 2]^T$, the minimum over $\mathcal{X}$
is obtained by independently minimising each coordinate:
\begin{equation}
\min_{x \in \mathcal{X}} a^T x
= \min_{0.5 \le x_1 \le 5} x_1 + \min_{-5 \le x_2 \le 10} 2x_2
= 0.5 + 2(-5) = -9.5.
\end{equation}
The optimal solution is
\begin{equation}
x^\star = (0.5,\; -5), \qquad f^\star = -9.5.
\end{equation}

\begin{theorem}[Fundamental Theorem of LP]
The minimum of a linear objective over a bounded convex polytope $\mathcal{X}$ is attained at
a \emph{vertex} (extreme point) of~$\mathcal{X}$.  For the box $\mathcal{X}$, the vertices are
the four corners $\{0.5,5\}\times\{-5,10\}$, and the optimum selects the corner that minimises
$a^Tx$.
\end{theorem}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\; \nabla f(x_k)^T x$ \Comment{Linear Minimisation Oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination (fixed step)}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Frank--Wolfe Convergence Rate]
For an $L$-smooth convex function $f$ on a convex compact set $\mathcal{X}$ with diameter
$D = \max_{x,y\in\mathcal{X}}\|x-y\|$, the Frank--Wolfe algorithm with step-size
$\gamma_k = 2/(k+2)$ satisfies
\begin{equation}
f(x_k) - f^\star \;\le\; \frac{2LD^2}{k+2},
\end{equation}
an $O(1/k)$ convergence rate.  This is weaker than projected gradient descent's
$O(1/k^2)$ rate but avoids the need for a projection oracle.
\end{theorem}

The key advantage of FW is the \emph{linear minimisation oracle (LMO)}: $z_k = \arg\min_{x\in\mathcal{X}} \nabla f(x_k)^T x$.
For box constraints, this decomposes per coordinate in $O(d)$ operations:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \le 0 \end{cases}
\end{equation}
This is far cheaper than a projection onto many constraint sets (e.g., nuclear norm ball,
spectrahedra) where the LMO remains efficient but the projection is costly.

\textbf{Note on fixed-$\beta$ step:} The code implements a fixed mixing parameter
$x_{k+1} = \beta x_k + (1-\beta) z_k$, equivalent to a fixed step-size
$\gamma = 1 - \beta$ towards the LP vertex.  This differs from the optimal $\gamma_k = 2/(k+2)$
schedule, but allows comparison between different fixed strategies.

\textbf{Comparison of step-size strategies:}  For the interior optimum case, the two strategies
are:
\begin{itemize}[nosep]
  \item $\gamma = 1-\beta = 0.10$ (aggressive): fast initial descent but larger oscillation
    once $x_k$ is near $(1,5)$, since each $z_k$ vertex is far from the minimum.
  \item $\gamma = 1-\beta = 0.015$ (conservative): slower initial descent but smaller
    oscillation near the minimum.  Since $x_{k+1} = 0.985 x_k + 0.015 z_k$, the iterate
    ``forgets'' the vertex jumps slowly.
  \item $\gamma_k = 2/(k+2)$ (optimal schedule, not implemented): decays from $2/2=1$ to
    $2/(N+2)$, providing fast initial steps and small steps near the minimum.  This achieves
    the $O(1/k)$ bound with the smallest constant.
\end{itemize}

\textbf{Diameter of the feasible set:} For $\mathcal{X} = [0.5,5]\times[-5,10]$,
$D = \sqrt{(5-0.5)^2 + (10-(-5))^2} = \sqrt{20.25 + 225} = \sqrt{245.25} \approx 15.66$.
The FW convergence bound gives $f(x_{100}) - f^\star \le \frac{2L\cdot245.25}{100+2}$.
For the interior optimum $f(x)=(x_1-1)^2+(x_2-5)^2$, $L=2$, giving
$f(x_{100}) - 0 \le \frac{2\cdot2\cdot245.25}{102} \approx 9.62$ --- a very loose upper bound,
as the actual errors are $\sim$0.005 in 140 iterations.  The looseness reflects the pessimistic
``diameter'' bound (the initial point $x_0=(1,1)$ is close to $x^\star=(1,5)$).

\subsection{Interior vs.\ Boundary Behaviour}

\textbf{Interior optimum:} Frank--Wolfe exhibits a characteristic zig-zag pattern.  The LP
vertex $z_k$ jumps between extreme points of $\mathcal{X}$ at each iteration, and the convex
combination gradually averages these jumps towards the interior.  The general convergence rate
is $O(1/k)$.  Smaller $\beta$ (larger steps towards $z_k$) can be faster initially but introduces
more oscillation near the optimum, as seen in Figure~\ref{fig:q6_fw_conv}.  Note that the KKT
conditions for the interior case (Section~\ref{sec:q5}) give $\mu^\star=0$, confirming that the
gradient of $f$ at the interior minimum is zero --- consistent with FW's convergence to $x^\star$
without hitting the boundary.

\textbf{Boundary optimum:} Frank--Wolfe is particularly well-suited to boundary optima because
$z_k$ frequently selects the vertex closest to the constrained optimum.  The iterate naturally
approaches the boundary without explicit projection.  The residual gap ($f=0.364$ vs.\
$f^\star=0.25$ after 140 iterations) reflects the $O(1/k)$ convergence; a decaying step schedule
$\gamma_k=2/(k+2)$ would reduce this gap.

\textbf{The Frank--Wolfe gap} $g_k = \nabla f(x_k)^T(x_k - z_k)$ serves as a primal convergence
certificate: since $z_k = \arg\min_{z\in\mathcal{X}}\nabla f(x_k)^Tz$ and $x^\star\in\mathcal{X}$:
\begin{equation}
g_k = \nabla f(x_k)^T(x_k - z_k) \ge \nabla f(x_k)^T(x_k - x^\star) \ge f(x_k) - f^\star,
\end{equation}
where the last inequality uses convexity.  Thus $g_k\ge f(x_k)-f^\star\ge0$, and $g_k\to0$
certifies convergence.  This certificate is computable without knowing $f^\star$, which is a
practical advantage over the Polyak step.

\textbf{Vertex oscillation} (visible in Figure~\ref{fig:q6_evolution}) is a characteristic
of FW: since $z_k$ is always a vertex of $\mathcal{X}$, it alternates between nearby vertices
as the gradient direction rotates around the interior minimum.  The iterate $x_k$ smooths this
oscillation by taking only a $1-\beta$ fraction of the step towards each vertex.  The open
problem of FW oscillation has motivated variants such as the Away-Step Frank--Wolfe and
Pairwise Frank--Wolfe, which allow steps away from ``bad'' vertices.

\subsection{Sparse Structure of Frank--Wolfe Iterates}

A distinctive property of the Frank--Wolfe algorithm, distinguishing it from projected gradient
methods, is that its iterates naturally maintain \emph{sparse representations} in terms of the
vertices of $\mathcal{X}$:

\begin{proposition}[Sparse Iterates]
The Frank--Wolfe iterate after $k$ steps is a convex combination of at most $k+1$ vertices of
$\mathcal{X}$:
\begin{equation}
x_k = \sum_{j=0}^{k} \lambda_j^{(k)} v_j,\quad \lambda_j^{(k)} \ge 0,\quad \sum_j \lambda_j^{(k)} = 1,
\end{equation}
where each $v_j$ is a vertex of $\mathcal{X}$ (an atom) and at most $k+1$ atoms are active.
\end{proposition}

This sparsity property has important implications for problems where the feasible set is a
structured polytope.  For example:
\begin{itemize}[nosep]
  \item \textbf{$\ell_1$-ball} ($\|x\|_1 \le 1$): the vertices are $\pm e_i$ (standard basis
    vectors).  Frank--Wolfe naturally produces sparse solutions with at most $k+1$ non-zero
    coordinates after $k$ iterations, recovering the LASSO solution without explicit sparsity
    penalties.
  \item \textbf{Nuclear norm ball} ($\|X\|_* \le 1$): the LMO computes the top singular vector
    pair ($O(nd)$ for rank-$r$ matrices), producing rank-$k$ iterates.  This is far cheaper
    than projecting onto the nuclear norm ball, which requires a full SVD.
  \item \textbf{Spectrahedra} (trace-norm balls in PSD matrices): similarly, the LMO computes
    one eigenvector per step.
\end{itemize}

In our box-constraint experiment, the feasible set has only 4 vertices, and the iterates are
convex combinations of these corners --- explaining the staircase pattern of $z_k$ in
Figure~\ref{fig:q6_evolution}.  For this experiment, projection is cheap ($O(1)$ per coordinate),
so the sparsity advantage of FW is not as critical as in the structured applications above.

\textbf{FW gap as a stopping criterion:} The Frank--Wolfe gap $g_k = \nabla f(x_k)^T(x_k-z_k)
\ge f(x_k) - f^\star$ (derived in Section~\ref{sec:q6}) provides a computable certificate
without knowing $f^\star$.  A practical stopping rule is $g_k \le \varepsilon$, guaranteeing
that $f(x_k) - f^\star \le \varepsilon$.  This is in contrast with gradient descent, where one
must monitor $\|\nabla f(x_k)\|^2 \le 2\mu\varepsilon$ (requiring knowledge of $\mu$), or use
a relative criterion $f(x_k) - f(x_{k-1}) \le \varepsilon$.

\subsection{Key Findings by Algorithm Family}

\textbf{Adaptive step-size methods (Q1):}
The Polyak rule is optimal when $f^\star$ is exactly known, achieving the best Rosenbrock
result among Q1 methods ($f=0.009$).  However, it is impractical in most real-world settings.
Adagrad and Heavy Ball provide robust alternatives that match GD on well-conditioned problems
and outperform it on ill-conditioned Rosenbrock.  RMSprop's exponential averaging prevents
Adagrad's learning-rate stalling but requires tuning of the decay parameter $\beta$.

\textbf{Momentum methods (Q2):}
Nesterov acceleration delivers the theoretical $O(1/k^2)$ improvement over GD's $O(1/k)$,
most visibly on the Rosenbrock benchmark ($f=0.479$ vs.\ GD's $f=3.39$ in 150 iterations).
Adam combines first and second moment estimates, yielding robust performance on anisotropic
problems (Benchmark~B) but underperforming Nesterov on the strongly nonlinear Rosenbrock.
Mini-batch SGD demonstrates that the batch size controls the variance--frequency trade-off:
small batches provide more updates per epoch at higher noise, while large batches give stable
but infrequent updates.

\textbf{Newton's method (Q3):}
Newton converges in one iteration on the quadratic (Benchmark~A) and in $\sim$5 iterations
on the near-quadratic Benchmark~B, demonstrating quadratic convergence.  On Rosenbrock
($\kappa\approx500$ at the optimum), a damped step is required; even so, Newton's 20 iterations
(reaching $f=0.686$) dramatically outperform GD's 80 iterations ($f=3.73$).  The affine
invariance of Newton's method directly explains why it is unaffected by the conditioning that
cripples first-order methods.

\textbf{Derivative-free methods (Q4):}
For gradient availability, finite differences with a well-chosen step ($\delta=0.05$) closely
approximate the exact gradient.  A poor step ($\delta=0.8$) degrades accuracy through truncation
error $O(\delta)$.  Nesterov random search, using only 2 function evaluations per step, is
dimension-scalable but slow.  On the unconstrained Rosenbrock, Nelder--Mead outperforms grid
search in the same evaluation budget by exploiting local geometric information.

\textbf{Constrained optimisation (Q5):}
Projected GD enforces hard feasibility from the first iterate and converges to the constrained
minimum.  Penalty methods are simpler to implement but provide only approximate feasibility;
convergence improves with $\lambda$ at the cost of requiring smaller step sizes.  For the
half-space constraint $x_1\ge0.5$, the projection is $O(1)$ and projected GD is clearly
preferable.

\textbf{Frank--Wolfe (Q6):}
The FW algorithm provides a projection-free approach to constrained optimisation via the LMO.
Its $O(1/k)$ convergence rate (vs.\ $O(1/k^2)$ for projected GD) is the price of replacing
projections with linear minimisations.  FW is most valuable when the LMO is easy (box, simplex,
nuclear norm ball) but the projection is expensive.  The FW gap provides a practical stopping
criterion without knowledge of $f^\star$.

\subsection{Recommendations for Practice}

Based on the experimental results and theoretical analysis in this report, we offer the
following decision framework for algorithm selection:

\begin{enumerate}
\item \textbf{Unconstrained, convex, well-conditioned ($\kappa < 10$):}  Simple GD or
  Nesterov acceleration suffice.  The $\sqrt\kappa$ speedup of Nesterov over GD is modest
  when $\kappa$ is small.  Choose based on implementation simplicity vs.\ extra constant factor.

\item \textbf{Unconstrained, convex, ill-conditioned ($\kappa \ge 100$):}  Use Nesterov
  acceleration (optimal $O(1/k^2)$) or quasi-Newton (L-BFGS, superlinear convergence).
  GD requires $O(\kappa)$ iterations; Nesterov requires $O(\sqrt\kappa)$; Newton/LBFGS
  requires $O(\log\log(1/\varepsilon))$ (essentially constant).

\item \textbf{Stochastic/mini-batch setting:}  Use Adam (per-coordinate adaptive + momentum +
  bias correction) as the default.  It is robust to learning rate tuning across a wide range
  of problem types.  Switch to Nesterov SGD if the problem has strong convex structure and
  small gradient noise.

\item \textbf{Exact optimal value known ($f^\star$):}  The Polyak step rule is the optimal
  adaptive strategy, achieving the best convergence rate without knowing $L$ or $\mu$.
  However, it is sensitive to misspecification --- use only when $f^\star$ is certain.

\item \textbf{Small-scale, high-accuracy, curvature exploitable:}  Newton's method (if $d
  \le 10^3$) or L-BFGS (for $d \le 10^6$).  The quadratic convergence rate dramatically
  outperforms first-order methods near the solution.

\item \textbf{Derivative-free:}  For $d \le 10$, use Nelder--Mead.  For $d \le 1000$,
  use Nesterov random search or CMA-ES.  For $d > 1000$, gradient information is essentially
  mandatory; consider backpropagation through simulation if possible.

\item \textbf{Constrained (simple feasible set):}  Projected GD provides hard feasibility
  from the first iterate at $O(1)$--$O(d)$ projection cost.  Prefer this for box constraints,
  simplex, $\ell_2$-ball.

\item \textbf{Constrained (LP-easy feasible set):}  Frank--Wolfe if the LMO is far cheaper
  than projection (nuclear norm ball: LMO costs one SVD per step vs.\ full SVD for projection;
  spectrahedra: LMO costs one eigenvector per step vs.\ full eigendecomposition for projection).
  Accept the $O(1/k)$ vs.\ $O(1/k^2)$ rate penalty for the per-iteration cost reduction.

\item \textbf{Hard constraints, unknown $f^\star$:}  Augmented Lagrangian for medium-scale
  (combines penalty efficiency with exact feasibility); Interior point for small-scale with
  many smooth constraints.
\end{enumerate}

\textbf{Experimental evidence supporting these recommendations:}  The results in this report
confirm that no single algorithm dominates on all three benchmarks.  On the easiest problem
(Benchmark~A, $\kappa\approx1$), nearly all methods converge comparably.  On Benchmark~B
($\kappa\approx7$), Adam's per-coordinate adaptation shows moderate advantage.  On Benchmark~C
($\kappa\approx500$, strongly non-quadratic), the hierarchy is clear: Newton $\approx$ Nesterov
$\gg$ Adam $>$ Heavy Ball $>$ Adagrad $\approx$ GD $>$ RMSprop, with Polyak (exact $f^\star$)
achieving the best result.  This ordering aligns precisely with the theoretical rates in
Table~\ref{tab:theory_rates}.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z       # gradient evaluated at extrapolated point
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)    # bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Tikhonov Regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))    # ensure positive definiteness
        try:
            p = np.linalg.solve(H_reg, g)       # solve H_reg * p = g
        except np.linalg.LinAlgError:
            p = g                                # fallback to gradient step
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # Linear minimisation oracle (LMO) for box constraint
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z      # convex combination step
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
