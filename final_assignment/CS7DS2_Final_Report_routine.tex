\begin{abstract}
This report presents a comprehensive comparative study of first-order, second-order, and
derivative-free optimisation algorithms applied to three canonical benchmark problems: a linear
regression quadratic loss (Benchmark A, $\kappa \approx 1.1$), a toy neural-network nonlinear
loss with sinusoidal coupling (Benchmark B, $\kappa \approx 6.9$), and the Rosenbrock function
(Benchmark C, $\kappa \approx 2508$).  Six algorithmic families are investigated: (1) adaptive
step-size methods --- Polyak step, Adagrad, RMSprop, and Heavy Ball; (2) momentum and stochastic
methods --- Nesterov acceleration, Adam, and mini-batch SGD; (3) Newton's method with local
quadratic modelling; (4) derivative-free approaches including finite-difference gradient
approximation, Nesterov random search, Nelder--Mead simplex, and grid search; (5) constrained
optimisation via projected gradient descent and penalty methods; and (6) the Frank--Wolfe
conditional gradient algorithm for linear-constrained problems.

Key findings include: (i) the Polyak step diverges when $f^\star$ is misspecified (achieving
$f = 2.72$ vs the true minimum $0.4826$ on Benchmark A) but achieves the best final objective
($f = 0.009$) on Rosenbrock where $f^\star = 0$ is correctly specified; (ii) Nesterov acceleration
achieves a $\sim 7\times$ lower final objective than GD on Rosenbrock in 150 iterations, consistent
with its theoretical $O(1/k^2)$ rate advantage at $\kappa = 2508$ ($\rho_{\rm Nest} = 0.961$ vs
$\rho_{\rm GD} = 0.999$); (iii) Newton's method converges in a single iteration on Benchmark A and
reaches $f = 0.69$ in 20 iterations vs GD's $f = 3.73$ in 80 iterations on Rosenbrock; (iv) the
Nelder--Mead simplex method converges to the \emph{exact} Rosenbrock minimum ($f = 0$) in 160
iterations with $\sim 400$ function evaluations, substantially outperforming grid search
($f = 0.0016$, 3025 evaluations); and (v) projected gradient descent enforces hard constraint
satisfaction from iteration 1, while penalty methods require $\lambda \geq 4.5$ to achieve
feasibility within 10 iterations.  All experiments use \texttt{np.random.seed(42)} for
full reproducibility.
\end{abstract}

\section*{Introduction}
\addcontentsline{toc}{section}{Introduction}
% ============================================================

Optimisation lies at the core of modern machine learning: training a model means minimising a
loss function, and the choice of optimisation algorithm directly affects convergence speed,
solution quality, and computational cost.  This report systematically investigates a broad
spectrum of optimisation methods, from classical first-order gradient descent through
adaptive and momentum-based methods, second-order Newton's method, derivative-free techniques,
and constrained optimisation algorithms.

All methods are evaluated on three benchmark functions of deliberately increasing difficulty:
a well-conditioned quadratic (Benchmark A, $\kappa \approx 1.1$), a moderately anisotropic
nonlinear function (Benchmark B, $\kappa \approx 6.9$), and the notoriously ill-conditioned
Rosenbrock function (Benchmark C, $\kappa \approx 2508$).
This progression allows the report to isolate the specific conditions under which each method's
theoretical advantages become practically significant.  The condition number $\kappa$ plays the
role of a \emph{discriminative signal}: on Benchmark~A, virtually all methods behave similarly;
on Benchmark~C, methods diverge by up to two orders of magnitude in final objective value,
making it the critical test of theoretical claims.  This report uses the benchmark progression
to connect algorithmic theory (convergence rate formulae) to empirical observations
(final objective values and trajectory shapes).

The report is structured as follows:

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.
The benchmarks are chosen to represent a spectrum of difficulty controlled principally by the
condition number $\kappa = \lambda_{\max}/\lambda_{\min}$ of the Hessian, which governs the
ratio between the slowest and fastest directions of curvature.  A large $\kappa$ forces
gradient-based methods to use small step sizes to avoid divergence, slowing convergence.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and two parameters is generated according to
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the normalised mean squared error:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
            = \frac{1}{2}\theta^T H \theta - b^T\theta + c,
\end{equation}
where $H = \frac{1}{m}X^T X$, $b = \frac{1}{m}X^T y$, and $c = \frac{1}{2m}\|y\|^2$.
The gradient is $\nabla J(\theta) = H(\theta - \theta_{\text{OLS}}) = \frac{1}{m}X^T(X\theta - y)$.

Since $X \in \mathbb{R}^{m \times 2}$ with independent $\mathcal{N}(0,1)$ entries and $m = 1000$,
the empirical Hessian $H \approx I_2$ with both eigenvalues close to 1, giving a condition number
$\kappa_A \approx 1$.  This near-isotropic curvature makes Benchmark A the easiest test: any
well-tuned gradient method converges rapidly.  Due to observation noise, the minimum loss is
$J^\star \approx 0.4826$ (not zero), achieved at the OLS solution $\theta_{\text{OLS}} \approx [3.03, 4.02]^T$.
Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Quadratic Loss}

\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are
\begin{equation}
  \nabla f = \begin{bmatrix} 2(x_1 - 1) + \cos(x_1) \\ 10(x_2 - 2) \end{bmatrix}, \qquad
  H(x) = \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}.
\end{equation}
Setting $\nabla f = 0$ gives $x_2^\star = 2$ exactly, and $x_1^\star$ satisfies
$2(x_1^\star - 1) + \cos(x_1^\star) = 0$.  Solving numerically yields $x_1^\star \approx 0.582$,
so the minimum is at approximately $(0.582,\, 2.0)$ with $f^\star \approx 0.7244$.
\emph{Note:} the optimum marker in trajectory figures is placed at $(0.61, 2.0)$, which is an
approximate visual guide; the analytically computed minimum is $(0.582, 2.0)$.

At the minimum, $H^\star = \text{diag}(2 - \sin(0.582),\, 10) \approx \text{diag}(1.45,\, 10)$,
giving condition number $\kappa_B \approx 6.9$.  The $x_2$ direction is approximately 7 times
stiffer than $x_1$, creating moderate anisotropy that challenges fixed-step methods.
Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$.  The Hessian is
\begin{equation}
  H(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the optimum $(1,1)$: $H^\star = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}$
with eigenvalues $\lambda_{\max} \approx 1001.6$ and $\lambda_{\min} \approx 0.4$, giving
$\kappa_C \approx 2508$.  This extreme ill-conditioning, combined with a narrow curved valley
along $x_2 \approx x_1^2$, makes Rosenbrock the most challenging benchmark.  A stable step
size for gradient descent must satisfy $\alpha < 2/\lambda_{\max} \approx 0.002$, which causes
extremely slow progress along the valley direction.
Starting point: $x_0 = [-1, 1]^T$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Algorithm Formulations and Motivation}

Four adaptive methods are compared against a constant step-size gradient descent (GD) baseline
across all three benchmarks for 120 iterations.  The common limitation of constant-step GD is
that the optimal step size $\alpha^\star = 2/(\lambda_{\min} + \lambda_{\max})$ depends on
unknown curvature information.  Adaptive methods attempt to estimate or approximate this
curvature from gradient history.

\begin{algorithm}[H]
\caption{Gradient Descent (Baseline)}
\label{alg:gd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, constant step $\alpha$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} The Polyak step can be derived as the step that
\emph{minimises} the distance $\|x_{k+1} - x^\star\|^2$ subject to $x_{k+1} = x_k - \alpha_k g_k$:
\begin{equation}
  \|x_{k+1} - x^\star\|^2 = \|x_k - x^\star\|^2 - 2\alpha_k g_k^T(x_k - x^\star) + \alpha_k^2 \|g_k\|^2.
\end{equation}
Minimising over $\alpha_k$ and using $g_k^T(x_k - x^\star) \geq f(x_k) - f^\star$ (subgradient
inequality) with the optimal choice:
\begin{equation}
  \alpha_k = \frac{g_k^T(x_k - x^\star)}{\|g_k\|^2} \geq \frac{f(x_k) - f^\star}{\|g_k\|^2},
\end{equation}
the Polyak formula approximates this ideal step using $f(x_k) - f^\star$ as a lower bound.
Under $L$-smoothness, this satisfies $f(x_{k+1}) - f^\star \leq (f(x_k) - f^\star)(1 - 1/(2L))$
(see Lecture notes Week 3b), where $L = \lambda_{\max}$.  The adaptive numerator $f(x_k) - f^\star$
naturally shrinks as the iterate approaches the minimum, giving variable-rate convergence with
no curvature knowledge required.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate cumulative squared gradient}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} Adagrad (Duchi et al., 2011) was designed for
sparse or heterogeneous gradient problems, where different coordinates have very different
gradient magnitudes.  The effective per-coordinate step size
$\alpha_k^{(i)} = \alpha_0 / \sqrt{\sum_{j \leq k} g_j^{(i)^2}}$ provides implicit
\emph{preconditioning}: if coordinate $i$ has consistently large gradients (high curvature),
its step is automatically reduced; if gradients are small (low curvature), the step remains
large.  This diagonal approximation to the inverse Hessian is particularly effective in
natural language processing and recommendation systems where feature gradients span many
orders of magnitude.  However, the cumulative sum $\sum g_j^2$ grows without bound, so the
step monotonically \emph{decreases} and can become negligible before the minimum is reached.
The Adagrad regret bound $R_T \leq O(\sqrt{T}\|\nabla f\|)$ ensures sublinear average regret
in the online learning setting, but for offline minimisation, the vanishing step causes
convergence to stagnate (Reddi et al., 2018).

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$,
  iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$
      \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} RMSprop (Hinton, 2012; unpublished lecture notes)
corrects Adagrad's monotone decay by replacing the cumulative sum with an exponential
moving average of squared gradients:
\begin{equation}
  v_k^{(i)} = \beta\, v_{k-1}^{(i)} + (1-\beta)\, (g_k^{(i)})^2 \approx
  \frac{1}{W}\sum_{j=k-W}^{k} (g_j^{(i)})^2, \quad W \approx \frac{1}{1-\beta}.
\end{equation}
For $\beta = 0.9$, the effective window $W \approx 10$: the step reflects only the last $\sim 10$
gradient observations, allowing it to adapt to changing curvature rather than being permanently
biased by large early gradients.  Unlike Adagrad, RMSprop's step size can \emph{increase} if
gradients become consistently small (e.g., near a flat region), preventing premature stagnation.
This makes RMSprop better suited to non-stationary objectives and long training runs.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} The auxiliary variable $z_k$ accumulates an
exponentially-weighted history of gradients, providing a ``velocity'' that persists across
iterations.  The mechanical analogy is a heavy ball rolling on the loss surface with friction:
$\beta$ is the coefficient of momentum (1 = no friction, 0 = maximum friction), and $\alpha$ is
the force-to-velocity ratio.  For strongly convex quadratics, the optimal parameters are
$\alpha^\star = 4/(\sqrt{\lambda_{\max}} + \sqrt{\lambda_{\min}})^2$ and
$\beta^\star = ((\sqrt{\kappa} - 1)/(\sqrt{\kappa} + 1))^2$, which yields a convergence rate
$\rho = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1) < 1$ -- much faster than GD's rate of
$(\kappa-1)/(\kappa+1)$ when $\kappa \gg 1$ (Week 4a lecture notes).
Plugging in $\kappa = 2508$: $\alpha^\star = 4/(\sqrt{1001.6} + \sqrt{0.4})^2 = 4/(31.65 + 0.632)^2
\approx 4/1041 \approx 0.00384$, and the experiment uses $\alpha = 0.0008$, approximately $4.8\times$
smaller than optimal.  This conservative setting is necessary because the Rosenbrock Hessian
varies across the landscape (unlike the quadratic theory's constant-Hessian assumption), and
using $\alpha^\star$ for the globally worst-case $\lambda_{\max}$ can cause oscillations at
points where the effective Hessian is smaller.

\begin{itemize}
\item \textbf{Convergence speed:}
  When $f^\star$ is known exactly, Polyak converges fastest (Benchmark~C: $f = 0.009$),
  exploiting the exact gap between current loss and optimum to set an optimally-sized step.
  Otherwise, Adagrad and Heavy Ball match or exceed the GD baseline.  On the well-conditioned
  Benchmark~A ($\kappa \approx 1.12$), all methods converge similarly since $\rho \approx 0.057$
  is small for all methods: the high curvature isotropy leaves no room for acceleration.

\item \textbf{Smoothness:}
  RMSprop produces the smoothest convergence curves due to exponential averaging of squared
  gradients.  Heavy Ball shows characteristic overshoot followed by damped oscillation,
  analogous to a second-order damped mechanical system.  The momentum parameter $\beta$
  controls the damping: $\beta < \beta^\star = ((\sqrt\kappa-1)/(\sqrt\kappa+1))^2$
  gives overdamped (monotone) convergence; $\beta > \beta^\star$ gives underdamped oscillation.
  The values $\beta = 0.88, 0.90, 0.86$ in the experiments are empirically tuned near this
  critical value.

\item \textbf{Stability:}
  Constant-step GD is most stable: for any $L$-smooth function, the condition
  $\alpha < 2/L = 2/\lambda_{\max}$ guarantees non-increasing loss.  Polyak is \emph{unstable}
  when $f^\star$ is misspecified.  Adagrad is uniformly stable due to its monotonically
  decreasing step size, but this safety mechanism eventually causes stagnation: on a strongly
  convex function, Adagrad's effective step decays as $\alpha_0/\sqrt{k}$, giving a
  $O(1/\sqrt{k})$ convergence rate that is slower than GD's $O(1/k)$ rate on smooth problems.

\item \textbf{Heavy Ball parameter selection:}
  The optimality of Heavy Ball's $\beta^\star = ((\sqrt\kappa-1)/(\sqrt\kappa+1))^2$ relies on
  knowing $\kappa = \lambda_{\max}/\lambda_{\min}$, which is rarely available in practice.
  The experiments use empirically tuned $\beta \in \{0.86, 0.88, 0.90\}$ that are close to
  but not exactly equal to $\beta^\star$.  For Benchmark C: $\beta^\star = ((50-1)/(50+1))^2
  \approx (49.08/51.08)^2 \approx 0.923$; the experimental $\beta = 0.86$ is below this, causing
  \emph{overdamped} behaviour (slower convergence but no oscillation).  Choosing $\beta > \beta^\star$
  would produce underdamped oscillation --- the so-called ``zig-zag'' problem that Nesterov's
  method avoids by evaluating gradients at the lookahead point.  This fragility of Heavy Ball
  to $\beta$ tuning is a key practical disadvantage compared to Nesterov, which is stable
  for any $\beta_{\max} < 1$ through its decreasing schedule.

\item \textbf{Adagrad vs RMSprop:}
  The key algorithmic difference is how gradient history is aggregated.  Adagrad's cumulative
  sum $G_k = \sum_{j=0}^k g_j^2$ grows without bound, so $\alpha_0/\sqrt{G_k} \to 0$.
  RMSprop's exponential moving average $v_k = \beta v_{k-1} + (1-\beta)g_k^2$ tracks a
  finite window (effective window size $\approx 1/(1-\beta) = 10$ for $\beta = 0.9$),
  preventing the step from vanishing.  RMSprop is strictly preferred for non-stationary
  problems or long training runs.  However, \emph{neither} method has a momentum term: both
  adjust the step size per coordinate but do not accumulate velocity.  This is why Heavy Ball
  outperforms both on Rosenbrock ($f=1.40$ vs Adagrad's $f=2.20$): momentum along the
  consistent valley-floor direction is the key ingredient, not curvature scaling.

\item \textbf{Why Heavy Ball beats Adagrad on Benchmark C despite less curvature information:}
  Adagrad's diagonal scaling effectively reduces the per-coordinate learning rates based on
  gradient magnitudes, but on Rosenbrock the large cross-valley gradients dominate both
  coordinates' accumulators equally, providing no directional discrimination.  Heavy Ball's
  momentum $z_{k+1} = \beta z_k + \alpha g_k$ accumulates gradient history in a \emph{directional}
  sense: if the gradient repeatedly points in the valley-floor direction, $z_k$ grows in that
  direction, amplifying progress.  On Benchmark C, the valley-floor gradient component is
  consistent across iterations, allowing Heavy Ball to build $\sim \alpha/(1-\beta) \approx 5.7\times$
  amplification of the valley-floor step vs the single-iteration GD step.  Adagrad's scalar
  accumulation $G_k^{(i)} = \sum g_k^{(i)^2}$ cannot exploit this directional consistency.

\item \textbf{Practical recommendation:}
  In practice, exact $f^\star$ is rarely known, limiting Polyak's applicability.  RMSprop
  and Adagrad are more robust: RMSprop when training is long; Adagrad for sparse gradient
  problems (NLP/recommendation systems where different features are updated rarely).
\end{itemize}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead / extrapolated point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
The key distinction from Heavy Ball is evaluating the gradient at the \emph{extrapolated
lookahead point} $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$.  This ``look before
you leap'' strategy allows Nesterov to correct its trajectory \emph{before} overshooting,
yielding provably optimal $O(1/k^2)$ convergence on convex functions (vs.\ GD's $O(1/k)$)
and linear convergence on strongly convex functions with a better constant than GD
(Nesterov, 1983; Week 4b lecture notes):
\begin{equation}
  f(x_k) - f^\star \leq \frac{2L \|x_0 - x^\star\|^2}{(k+1)^2}
  \quad \text{(Nesterov)}, \qquad
  f(x_k) - f^\star \leq \frac{L \|x_0 - x^\star\|^2}{2k}
  \quad \text{(GD)}.
\end{equation}
At $\kappa = 2508$, the linear convergence rate for Nesterov on strongly convex functions is
$\rho_{\text{Nest}} = (\sqrt{2508}-1)/(\sqrt{2508}+1) \approx 0.9608$, vs GD's
$\rho_{\text{GD}} = (2508-1)/(2508+1) \approx 0.9992$ --- roughly $49\times$ better
per-iteration error reduction ($1 - 0.9608 \approx 0.0392$ vs $1 - 0.9992 \approx 0.0008$).
Over 150 iterations, the remaining fraction of the initial error is:
$0.9608^{150} \approx 2.5 \times 10^{-3}$ (Nesterov) vs $0.9992^{150} \approx 0.887$ (GD), predicting
that Nesterov reduces error by $\sim 400\times$ while GD reduces it by only $\sim 1.13\times$.
The theoretical prediction of $400\times$ error reduction for Nesterov vs $1.13\times$ for GD
is broadly \emph{qualitatively} consistent with the observed $7\times$ improvement in
final objective ($f = 0.479$ vs $f = 3.39$), but the ratio is lower than predicted.
The discrepancy arises from three factors:
\begin{enumerate}[nosep]
  \item \textbf{Non-quadratic objective:} The theoretical rates hold for strongly convex quadratics.
    Rosenbrock's Hessian varies across the landscape; the effective $\kappa$ experienced during
    the trajectory (from $x_0 = (-1,1)$ to $\sim(0.5, 0.3)$) may be lower than $\kappa^\star = 2508$
    at the minimum.
  \item \textbf{Non-optimal GD step:}  The theoretical GD rate uses $\alpha^\star = 2/(L + \mu) \approx
    0.002$, while the experiment uses $\alpha = 0.0012$ (constrained by numerical stability);
    the true GD rate is somewhat better than the table prediction.
  \item \textbf{Finite iterations:}  At 150 iterations, neither method has entered its
    asymptotic regime.  Nesterov's $O(1/k^2)$ advantage is most pronounced at large $k$;
    at $k = 150$, the quadratic speedup may not yet be fully manifested.
\end{enumerate}
The schedule $\beta_k = \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ starts at zero (pure
gradient step) and grows towards $\beta_{\max}$, ensuring stability while building up momentum.
This warm-up avoids the oscillation that would occur if full momentum were applied from $k=1$.

\noindent\textbf{Connection between the two Nesterov rate results:}
The $O(1/k^2)$ convex rate and the $\rho = (\sqrt\kappa-1)/(\sqrt\kappa+1)$ strongly convex
linear rate describe the \emph{same} algorithm but in different regimes.  For large $k$ on a
strongly convex function, $f(x_k) - f^\star \leq C \rho^k$ where $C$ depends on the initial
distance.  For a convex function with no strong convexity, the algorithm converges polynomially.
The transition between regimes occurs at $k \approx \sqrt\kappa$: below this threshold, the
$O(1/k^2)$ regime dominates; above it, the linear regime dominates.  For $\kappa = 2508$,
the crossover is at $k \approx 50$, suggesting that iterations 1--50 in the experiments are
primarily in the $O(1/k^2)$ phase and iterations 50--150 in the linear phase with
$\rho = 0.9608$.  This is consistent with the faster initial descent seen in
Figure~\ref{fig:q2_fval_C}: the first 50 iterations show super-linear improvement, followed
by geometric decay at rate $\approx 0.9608$ in the later iterations.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$,
  tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$
      \Comment{First moment: exponential moving average of gradients}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$
      \Comment{Second moment: EMA of squared gradients}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$
      \Comment{Bias correction for initialisation at zero}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
Adam (Kingma \& Ba, 2015) combines momentum via $m_t$ with per-coordinate adaptive
scaling via $v_t$, inheriting advantages of both RMSprop and momentum methods.  The effective
step size per coordinate is $\alpha \cdot \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon) \approx
\alpha \cdot \text{sign}(g_t)$ in the limit of large $t$ with consistent gradient directions,
bounding the effective step in $(-\alpha, \alpha)$.  The bias corrections
$(1 - \beta_1^t)^{-1}$ and $(1 - \beta_2^t)^{-1}$ compensate for initialising $m_0 = v_0 = 0$,
which otherwise causes underestimation in early iterations.

\noindent\textbf{Effect of bias correction in early iterations:}
At $t = 1$ with $\beta_1 = 0.82$:\ $\hat{m}_1 = g_1 / (1 - 0.82) = 5.56\, g_1$,
so the effective first step is $5.56\times$ larger than the raw gradient $g_1$, compensating
for the cold start.  At $t = 1$ with $\beta_2 = 0.999$:\ $\hat{v}_1 = g_1^2 / (1 - 0.999)
= 1000\, g_1^2$, so $\sqrt{\hat{v}_1} \approx 31.6\, |g_1|$ --- the denominator scales the
step to $\approx \alpha / 31.6 \cdot \hat{m}_1 / |g_1| = \alpha \cdot 5.56/31.6 \cdot \text{sign}(g_1)
\approx 0.176\,\alpha\,\text{sign}(g_1)$ at $t=1$.  As $t$ grows, the bias correction factors
approach 1 and the effective step approaches $\alpha\,\text{sign}(g_t)$ when the gradient
direction is consistent.  This bounded effective step is what makes Adam robust to step-size
tuning in deep learning: regardless of the gradient magnitude, each coordinate moves at most
$\alpha$ per step.

\noindent\textbf{Why Nesterov outperforms Adam on Rosenbrock:}
Adam's per-coordinate scaling with $\beta_2 = 0.999$ maintains a long memory of squared
gradients: the EMA second moment $v_t$ has effective window size $1/(1-\beta_2) = 1000$ steps,
so gradients from 500+ iterations ago still contribute with weight $\beta_2^{500} \approx 0.61$.
On the curved Rosenbrock valley, the gradient direction rotates significantly as the iterate
moves along $x_2 = x_1^2$ (near $x_1 = -1$, the valley gradient is predominantly in the
$x_1$ direction; near $x_1 = 0.5$, it rotates substantially), so stale gradient magnitudes
from early iterations give a misleading second moment.  The effective step $\alpha/\sqrt{\hat{v}_t}$
is over-shrunk by the large historical $v_t$, slowing convergence.
Nesterov avoids this entirely by using only the \emph{current} lookahead gradient $\nabla f(\tilde{x}_k)$
--- there is no per-coordinate second-moment accumulation.  The result is $f = 0.479$ vs
$f = 1.578$ after 150 iterations ($3.3\times$ better objective).  A smaller $\beta_2 = 0.9$
(effective window 10) would reduce this stale-gradient problem at the cost of higher step-size
variance; but in practice this must be tuned per problem, whereas Nesterov's $O(1/k^2)$
guarantee requires no such tuning.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark~A uses $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs,
with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{epoch $e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1, \ldots, m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$
          \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{SGD Convergence Theory}

For the quadratic loss $J(\theta) = \frac{1}{2m}\|X\theta - y\|^2$ with $\mu$-strongly
convex, $L$-smooth Hessian structure, and stochastic gradient variance $\sigma^2_{\rm sg}$,
fixed-step SGD satisfies the convergence bound (Nguyen et al., 2018):
\begin{equation}
  \mathbb{E}[J(\theta_k)] - J^\star \leq \left(1 - 2\alpha\mu + 2\alpha^2 L\mu\right)^k
  (J(\theta_0) - J^\star) + \frac{\alpha L \sigma^2_{\rm sg}}{2\mu - \alpha L^2/\mu}.
  \label{eq:sgd_bound}
\end{equation}
The first term decays geometrically (linear convergence) with rate $\rho_{\rm sg} = 1 - 2\alpha\mu + 2\alpha^2 L\mu$.
The second term is the \emph{irreducible noise floor}: even after infinite iterations, the
expected loss cannot drop below $\frac{\alpha L \sigma^2_{\rm sg}}{2\mu}$.  This floor is:
\begin{enumerate}[nosep]
  \item \emph{Proportional to $\alpha$}: smaller learning rates give a lower floor.  Setting
    $\alpha \to 0$ achieves exact convergence but infinite iterations.  A \emph{decaying} schedule
    $\alpha_k = \alpha_0 / (k + 1)$ achieves both $\sum_k \alpha_k = \infty$ (sufficient descent)
    and $\sum_k \alpha_k^2 < \infty$ (vanishing noise), guaranteeing convergence to $J^\star$.
  \item \emph{Proportional to $\sigma^2_{\rm sg} \propto \sigma^2_\varepsilon / b$}:
    increasing the batch size $b$ or decreasing label noise $\sigma_\varepsilon$ both lower the floor.
  \item \emph{Inversely proportional to $\mu$}: a more strongly convex loss (steeper bowl)
    can absorb gradient noise more easily, recovering faster.
\end{enumerate}

\noindent\textbf{Practical implication:}  The noise floor explains the \emph{oscillation} near
the minimum seen in Figure~\ref{fig:q2_sgd_batch}: with $\alpha = 0.06$ and $b = 5$, the iterate
reaches the noise floor $\sim \frac{\alpha L \sigma^2_\varepsilon}{b \mu} > 0$ and then
\emph{random-walks} around the minimum rather than converging to it.  Plugging in the experimental
values ($\alpha = 0.06$, $L \approx \lambda_{\max}(H) \approx 1$ on Benchmark~A, $\sigma_\varepsilon^2 = 1$,
$b = 5$, $\mu \approx \lambda_{\min}(H) \approx 1$):
\begin{equation}
  \text{noise floor} = \frac{\alpha L \sigma^2_{\rm sg}}{2\mu}
  = \frac{0.06 \times 1 \times (1/5)}{2 \times 1} = 0.006.
\end{equation}
Adding this to the irreducible label-noise floor $J^\star \approx 0.48$, the expected oscillation
plateau is $\approx 0.48 + 0.006 = 0.486$, consistent with the $b=5$ curve plateauing slightly
above $0.48$ in Figure~\ref{fig:q2_sgd_batch}.  For $b = 40$: noise floor $= 0.06 \times 1
\times (1/40) / 2 = 0.00075$, making the plateau essentially indistinguishable from $J^\star$.
The full-batch GD converges monotonically to the exact minimum because its gradient is exact
($\sigma^2_{\rm sg} = 0$).  In deep learning, this means the training loss \emph{never} reaches
the global minimum under constant learning rates, necessitating learning rate schedules (step
decay, cosine annealing) that reduce $\alpha$ to zero during training.

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0)
       = 0.25^4 + 4 \cdot 0.25^3\,(x - 0.25)
       = 0.0039 + 0.0625(x - 0.25).
\end{equation}
This is the tangent line at $x_0 = 0.25$; it captures only the local slope and provides no
information about curvature or the location of the minimum.

\textbf{Second-order (quadratic) approximation:}
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
       = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}
This parabola is a local quadratic model of $g$ near $x_0$.  The Newton update is obtained by
minimising this quadratic model, setting its derivative to zero:
\begin{equation}
  0 = g'(x_0) + g''(x_0)(x - x_0) \implies x^{\text{Newton}} = x_0 - \frac{g'(x_0)}{g''(x_0)}
    = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\end{equation}
The gradient-descent step would give $x_0 - \alpha g'(x_0) = 0.25 - 0.0625\alpha$, which
moves a fixed distance regardless of curvature.  Newton's step automatically accounts for the
curvature $g''(x_0) = 0.75$: large curvature $\Rightarrow$ smaller step, small curvature
$\Rightarrow$ larger step.

\noindent\textbf{Approximation quality:}  The Taylor remainder bounds quantify how far the
approximations extend.  The second-order remainder is $R_2(x) = g(x) - [g(x_0) + g'(x_0)(x-x_0)
+ \frac{1}{2}g''(x_0)(x-x_0)^2]$.  For $g(x) = x^4$ with $g'''(x) = 24x$ and $g^{(4)}(x) = 24$:
\begin{align}
  |R_1(x)| &= \left|\tfrac{1}{2}g''(\xi)(x-x_0)^2\right| \leq \tfrac{1}{2}|g''|_{\max}\, (x-x_0)^2
    \quad\text{(linear approximation error)}, \\
  |R_2(x)| &= \left|\tfrac{1}{6}g'''(\xi)(x-x_0)^3\right| \leq \tfrac{1}{6}|g'''|_{\max}\, |x-x_0|^3
    \quad\text{(quadratic approximation error)}.
\end{align}
At $|x - 0.25| = 0.1$: $|R_1| \leq 0.375 \times 0.01 = 0.00375$ and
$|R_2| \leq 4 \times 10^{-4}$, confirming the $O(h^2)$ vs $O(h^3)$ improvement from
first to second order.  The quadratic model is thus accurate over a region roughly
proportional to $1/\sqrt{|g'''|} \approx 0.2$ around $x_0 = 0.25$.

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Newton's Method with Hessian Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State Solve $H_k\, p_k = g_k$ for $p_k$ \Comment{Newton direction}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping
$\lambda = 10^{-8}$.  The regularisation $\lambda I$ ensures $H_k$ is positive definite even
when the true Hessian is indefinite (e.g., saddle points on Rosenbrock), preventing the Newton
direction from ascending.

\textbf{Convergence theory:}
Near a strongly convex minimum, Newton's method satisfies the \emph{quadratic convergence}
bound (Nesterov \& Nemirovskii, 1994; Week 6 lecture notes):
\begin{equation}
  \|x_{k+1} - x^\star\| \leq \frac{M}{2\mu}\, \|x_k - x^\star\|^2 \quad
  \text{when } \|x_k - x^\star\| < \frac{2\mu}{M},
\end{equation}
where $\mu = \lambda_{\min}(\nabla^2 f(x^\star))$ is the strong convexity constant, and $M$ is
the Lipschitz constant of the Hessian $\nabla^2 f$.  The condition $\|x_k - x^\star\| < 2\mu/M$
defines the \emph{basin of quadratic convergence}.  Once inside this basin, each iteration
doubles the number of correct digits in $\|x_k - x^\star\|$.  Specifically, for Benchmark~B:
$\mu \approx \lambda_{\min}(H^\star) = 1.45$ and $M \approx |\sin(x_1^\star)|_{\max} \cdot 1 = 0.546$
(Lipschitz constant of $H_{11}(x) = 2 - \sin(x_1)$), giving $C = M/(2\mu) \approx 0.188$ and
basin radius $2\mu/M \approx 5.3$.  The starting point $(−1, 4)$ has $\|x_0 - x^\star\|
\approx \sqrt{(−1 - 0.582)^2 + (4 - 2)^2} \approx 2.6$, within the basin, confirming that
quadratic convergence applies from the first iteration.

In contrast, GD satisfies only $\|x_{k+1} - x^\star\| \leq \rho\, \|x_k - x^\star\|$ (linear
convergence) with $\rho = (\kappa - 1)/(\kappa + 1) = (6.9-1)/(6.9+1) \approx 0.747$ on
Benchmark~B, requiring $\log(1/\varepsilon)/\log(1/0.747) \approx 8$ iterations to reduce
error by $10\times$, vs Newton's $O(\log\log(1/\varepsilon))$ steps (doubly logarithmic).

\textbf{Why damped Newton on Rosenbrock ($\alpha = 0.22$):}
Full Newton steps ($\alpha = 1$) on Rosenbrock overshoot because the Hessian $H(x)$ changes
rapidly along the trajectory: the quadratic model $f(x) \approx f(x_k) + g_k^T d + \frac{1}{2}d^T H_k d$
is only accurate in a small trust region around $x_k$.  A damped step ($\alpha < 1$) ensures
the iterate stays within this region of model accuracy.

\noindent\textbf{Quadratic convergence in practice:}
Table~\ref{tab:q3_final} shows three qualitatively different convergence regimes for Newton's method,
which correspond to the three phases of Newton convergence theory:
\begin{enumerate}[nosep]
  \item \textbf{Global phase (Benchmark C):}  When the initial point is far from the minimum
    (here $\|x_0 - x^\star\| \approx \sqrt{2} \approx 1.41$), the quadratic model may not be
    accurate at the Newton step's destination, so the method operates in a ``descent'' phase
    rather than the super-linear phase.  Damping ($\alpha < 1$) is essential to ensure each step
    reduces $f$.  The convergence is linear in this phase, not quadratic.
  \item \textbf{Super-linear onset (Benchmark B):}  When $\|x_0 - x^\star\|$ is moderate and the
    Hessian is nearly constant (the $\sin$ coupling causes only minor variation), the quadratic
    model is accurate over the full Newton step and the $\|x_k - x^\star\|^2$ reduction is evident
    from the rapidly decreasing update magnitudes seen in Figure~\ref{fig:q3_update}.
  \item \textbf{One-step convergence (Benchmark A):}  The loss is exactly quadratic, so the
    Hessian is constant everywhere.  The quadratic model $f(x) = \frac{1}{2}(x - \theta_{\rm OLS})^T H (x - \theta_{\rm OLS}) + c$
    is globally exact, and the Newton step $x^+ = x - H^{-1}\nabla f(x) = \theta_{\rm OLS}$
    solves the problem in exactly one step regardless of starting point.
\end{enumerate}

\noindent This progression demonstrates why Newton is the gold standard for well-conditioned
locally convex problems, but requires careful step-size management (damping, trust-region, or
line-search) for ill-conditioned or non-convex landscapes such as Rosenbrock.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces the $i$-th partial derivative:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
  \label{eq:fd}
\end{equation}
The total error of this approximation is:
\begin{equation}
  \left|\frac{\partial f}{\partial x_i}(x) - \hat{g}_i\right|
  \leq \underbrace{\frac{\delta}{2}\max_{t} |f''(x + t\delta e_i)|}_{\text{truncation error } O(\delta)}
  + \underbrace{\frac{2\varepsilon_{\text{mach}}}{\delta}}_{\text{rounding error } O(\varepsilon/\delta)},
\end{equation}
which is minimised at $\delta^\star \sim \sqrt{\varepsilon_{\text{machine}}} \approx 10^{-8}$.
Practically, $\delta$ in the range $[10^{-5}, 10^{-3}]$ works well for smooth functions.

The assignment tests two $\delta$ values on Benchmark~B (where $\lambda_{\max} = 10$,
so the Lipschitz constant of $\nabla f$ satisfies $L \leq \lambda_{\max} = 10$):

\begin{itemize}
  \item \textbf{Good:} $\delta = 0.05$ --- truncation error $\leq \delta L / 2 = 0.05 \cdot 10 / 2 = 0.25$.
    For a gradient of magnitude $\|g\| \approx 5$ at the starting point, the \emph{relative}
    error is $\lesssim 0.25/5 = 5\%$.  This is small enough that gradient descent still
    converges reliably towards the minimum.  The FD gradient is $\hat{g}_i = (f(x + 0.05\,e_i) -
    f(x))/0.05$; since $f$ is slowly varying compared to the $\delta$ step, this closely
    tracks the true $\partial f / \partial x_i$.
  \item \textbf{Poor:} $\delta = 0.8$ --- truncation error $\leq 0.8 \cdot 10 / 2 = 4.0$.
    A relative error of $\sim 80\%$ means the finite-difference direction is substantially
    different from the true gradient direction; the algorithm takes steps that largely do not
    correspond to descent.  The $\delta$-step of 0.8 samples the function over a region where
    the gradient direction has changed (the $\sin(x_1)$ coupling in Benchmark~B has period $2\pi$),
    producing an averaged direction that poorly approximates the local gradient.
\end{itemize}

\noindent\textbf{Optimal $\delta$ for Benchmark~B:}  The optimal $\delta^\star$ minimises
the sum of truncation and rounding errors.  Setting $d/d\delta(\delta L/2 + 2\epsilon_m/\delta) = 0$
gives $\delta^\star = 2\sqrt{\epsilon_m / L}$.  For $L = 10$ and machine epsilon $\epsilon_m \approx
10^{-16}$: $\delta^\star = 2\sqrt{10^{-16}/10} = 2 \times 10^{-8}$.  The experiment uses $\delta =
0.05 \gg \delta^\star$, trading numerical precision (not a concern here) for a larger perturbation
that avoids cancellation errors when $f$ values are large.  In practice, $\delta \in [10^{-5}, 10^{-2}]$
is the operational range where both error sources are controlled.

For comparison, a centred finite-difference scheme $[f(x+\delta e_i) - f(x-\delta e_i)]/(2\delta)$
has truncation error $O(\delta^2)$ rather than $O(\delta)$: the odd-order Taylor terms cancel,
so $|{\rm error}| \leq \delta^2 |f'''(\xi)|/6$.  For Benchmark~B with $|f'''(x)| \leq |{\sin}(x_1)|
\leq 1$ for the $x_1$ component, at $\delta = 0.8$: centred error $\leq 0.64/6 \approx 0.11$
vs forward-difference error $\leq 4.0$ --- a $36\times$ improvement.  At $\delta = 0.05$:
centred error $\leq 0.0025/6 \approx 4 \times 10^{-4}$ vs forward error $\leq 0.25$.
The trade-off: centred requires $2d = 4$ evaluations per step vs forward's $d+1 = 3$, a
$33\%$ overhead for $d = 2$ that grows to $2d/(d+1) \to 2\times$ as $d \to \infty$.
In practice, centred differences are always preferred when function evaluation cost is not
prohibitive, since the $O(\delta^2)$ accuracy allows using $\delta \approx 10^{-3}$ instead of
$\delta^\star \approx 10^{-8}$, avoiding numerical cancellation issues.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$; normalise $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
      \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Key property:}  Only \emph{two} function evaluations are required per
iteration, regardless of dimension $d$.  In contrast, forward-difference gradient estimation
requires $d + 1$ evaluations ($n = 2$ evaluations for Benchmark~B, $2 + 1 = 3$).  For
high-dimensional problems ($d \gg 1$), Nesterov random search provides a dimension-independent
cost per step.

\noindent\textbf{Directional derivative estimate:} The code computes
$\hat{g}_k = \frac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
with $u_k$ uniform on $\mathbb{S}^{d-1}$.  For any vector $v$:
\begin{equation}
  \mathbb{E}_{u}[v^T u \cdot u] = \frac{1}{d}\, v, \quad \text{since } \mathbb{E}[u u^T] = \frac{1}{d}I.
\end{equation}
Therefore $\mathbb{E}[\hat{g}_k] \approx \frac{1}{d}\nabla f(x_k)$: the estimator is
\emph{proportional to} (not equal to) the gradient, biased by the factor $1/d$.
In the Nesterov--Spokoiny (2017) framework, adding a factor of $d$ gives an unbiased estimator
of the gradient of the spherically-smoothed function $f_\delta(x) = \mathbb{E}_u[f(x + \delta u)]$:
\begin{equation}
  \mathbb{E}\!\left[\frac{d\,(f(x + \delta u) - f(x))}{\delta}\, u\right]
  = \nabla f_\delta(x) \approx \nabla f(x) + O(\delta^2).
  \label{eq:nrs_unbiased}
\end{equation}
The code's version (without the $d$ factor) is equivalent for optimisation since the step size $\alpha$
absorbs the $1/d$ scaling.  However, the $1/d$ factor means one must use $d \times$ larger step sizes
in high dimensions, which may conflict with stability requirements.  The variance of the estimate grows
with $d$, requiring more iterations for accurate gradient estimation at high dimension.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm (Nelder \& Mead, 1965) maintains a simplex of $n + 1 = 3$ vertices
in $\mathbb{R}^2$ and iteratively transforms it through four operations:
\begin{enumerate}[nosep]
  \item \textbf{Reflection} ($\alpha_r = 1.0$): reflect the worst vertex through the centroid
    of the remaining vertices.
  \item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, try extending further in
    that direction.
  \item \textbf{Contraction} ($\rho = 0.5$): if reflection did not improve, contract towards
    the centroid.
  \item \textbf{Shrink} ($\sigma = 0.5$): if contraction failed, shrink all vertices towards
    the best vertex.
\end{enumerate}
No gradient information is required; the algorithm adapts to the function landscape through
the simplex geometry.  Settings: initial step $= 0.35$, iterations $= 160$.

\noindent\textbf{Convergence rates of each Nelder--Mead operation:}  The four operations have
different roles in convergence.  Reflection + expansion perform coarse optimisation (moving the
simplex towards better regions at $O(1)$ distance); contraction refines the simplex near a
candidate minimum (shrinking diameter by $\sigma = 0.5$ per step, or $O(1/2^k)$ linear
convergence in the contraction phase); shrink is a last resort that reduces all vertex
distances to the best by factor $0.5$.  On smooth unimodal functions, the typical operational
sequence near the optimum is: expansion (found a better direction) $\to$ repeated reflection
(following the valley) $\to$ eventual contraction/shrink as the simplex closes in.  The
overall convergence is approximately linear with rate $\approx 0.5$ per simplex reduction.

\noindent\textbf{Why Nelder--Mead succeeds on Rosenbrock despite having no convergence
guarantee for non-convex functions:}  The Rosenbrock function has a \emph{unique} global
minimum $(1,1)$ and a narrow curved valley $x_2 \approx x_1^2$ with a known shape.
The simplex exploits this geometry through two mechanisms:
\begin{enumerate}[nosep]
  \item \textbf{Elongation:} The simplex stretches along the valley axis via repeated
    reflections in the same direction, effectively approximating the gradient direction
    without computing it.  The simplex ``learns'' the valley orientation through $\sim 100$
    function comparisons.  The initial simplex with step $0.35$ creates vertices at
    $(-1, 1)$, $(-0.65, 1)$, and $(-1, 1.35)$; after the first reflection, the simplex
    is repositioned in the direction of best improvement.
  \item \textbf{Contraction:} Near the minimum, the simplex contracts through shrink and
    inside-contraction steps, achieving super-linear convergence as the simplex diameter
    becomes small relative to the local curvature radius.  This implicit exploitation of
    local quadratic structure is the key to Nelder--Mead's success on smooth unimodal functions.
    When the simplex diameter falls below $\approx 1/\sqrt{L} = 1/\sqrt{1001} \approx 0.03$,
    the local quadratic approximation is accurate and contraction converges at rate $\sigma = 0.5$
    per step towards the exact minimum.
\end{enumerate}
In contrast, grid search finds the best of $55^2 = 3025$ pre-specified points and cannot
adapt to the function landscape: its accuracy is limited by grid resolution $\Delta x \approx 0.074$,
regardless of the function smoothness.  The $\sim 7.5\times$ more function evaluations
(3025 vs 400) combined with $\infty \times$ lower accuracy ($f = 0.0016$ vs $f = 0$)
illustrates the fundamental superiority of adaptive search on smooth problems.

\noindent\textbf{Dimension scaling comparison:}  For $d$ dimensions and target accuracy $\epsilon$,
the required total function evaluations scale as:
\begin{itemize}[nosep]
  \item Exact GD: $O(d + \kappa \log(1/\epsilon))$ -- $d$ for gradient, then $\kappa$-dependent iterations
  \item FD GD (forward): $O((d+1)\kappa \log(1/\epsilon))$ -- $(d+1)$ evaluations per step
  \item Nesterov random search: $O(d\kappa/\epsilon)$ -- 2 evaluations/step but $O(d\kappa/\epsilon)$ steps
  \item Nelder--Mead: $O(\text{poly}(d,1/\epsilon))$ -- exponential in $d$ in theory, practical for $d\leq 20$
  \item Grid search: $O((1/\epsilon)^{d/2})$ -- exponential in $d$ and accuracy
\end{itemize}
For $d = 2$ (as here), FD GD requires 3 evaluations/step vs exact GD's 2 (gradient eval), a modest
$50\%$ overhead; at $d = 100$, FD GD requires $101\times$ the evaluation cost of exact GD.

The key trade-off is between \emph{accuracy} and \emph{gradient availability}:
\begin{itemize}
  \item When exact gradients are available, exact GD (or Newton) is always preferred.
  \item When only function evaluations are available but $d \leq 20$, Nelder--Mead
    provides high accuracy on smooth unimodal problems: here it converges to $f = 0$ (exact
    minimum) with $\sim 400$ evaluations, outperforming both grid search and random search.
  \item For high-dimensional zeroth-order optimisation ($d$ large), Nesterov random search
    requires only 2 function evaluations per step regardless of $d$, but with higher variance;
    gradient estimation via FD requires $d+1$ evaluations, becoming expensive at large $d$.
  \item Grid search provides a \emph{global optimality guarantee within grid resolution} ---
    unique among these methods --- but the cost grows exponentially with $d$, making it
    impractical beyond $d \approx 3$.
\end{itemize}

\noindent\textbf{Unexpected result:}  Nelder--Mead outperforms all other derivative-free
methods on Rosenbrock despite having no convergence guarantee for non-convex problems.
This is because Rosenbrock's minimum is a unique global minimum on the test region, and
the simplex geometry on the $2$-dimensional valley adapts effectively through the four
operations.  The simplex's ability to orient along the valley axis (via stretch/reflection)
provides implicit geometric information that substitutes for gradient information.

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

\subsection{Problem Setup}

Minimise Benchmark~B subject to $x_1 \geq 0.5$, starting from the infeasible point
$x_0 = (0.2,\, 4.0)$.

\begin{remark}[Feasibility of unconstrained minimum]
  The unconstrained minimum of Benchmark~B is at $(x_1^\star, x_2^\star) \approx (0.582, 2.0)$.
  Since $x_1^\star = 0.582 > 0.5$, the constraint $x_1 \geq 0.5$ is \emph{inactive} at the
  optimum: the constrained and unconstrained minima coincide.  Therefore, all methods should
  converge to the same final point $(0.582, 2.0)$ in the limit, but they differ in how quickly
  they enforce feasibility \emph{during} optimisation.  The key distinction is the trajectory
  behaviour, not the final solution.
\end{remark}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$
      \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
Projected GD satisfies $x_k \in \mathcal{X}$ for all $k \geq 0$ (hard constraint guarantee).
The projection $\Pi_{\mathcal{X}}(z) = \arg\min_{x \in \mathcal{X}} \|x - z\|$ for a
half-space $\{x : x_1 \geq 0.5\}$ reduces to $x_1 \leftarrow \max(0.5, x_1)$, costing $O(1)$.
Convergence theory guarantees that projected GD converges on convex problems under
$\alpha < 2/L$ (Week 9a lecture notes), and the rate matches unconstrained GD.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, -x_1 + 0.5)$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
    \Comment{$\nabla F_\lambda(x) = \nabla f(x) - \lambda \mathbf{1}_{x_1 < 0.5}\, e_1$}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
The penalty method solves the unconstrained problem $\min_x F_\lambda(x)$ which approximates
the constrained problem for large $\lambda$.  Formally, if $x^\star_\lambda$ minimises
$F_\lambda$, then $x^\star_\lambda \to x^\star$ (the constrained optimum) as $\lambda \to \infty$.
The violation at $x^\star_\lambda$ satisfies $\max(0, 0.5 - x^\star_{\lambda,1}) \leq c/\lambda$
for some constant $c$, meaning the constraint error decays as $1/\lambda$.

However, large $\lambda$ increases the Lipschitz constant of $\nabla F_\lambda$ in the
infeasible region: the effective Hessian $H_{F_\lambda}(x) = H_f(x) + \lambda\, e_1 e_1^T \cdot
\mathbf{1}_{x_1 < 0.5}$ has eigenvalues approximately $\{\lambda_i(H_f) + \lambda, \lambda_j(H_f)\}$
for $i$ corresponding to $e_1$ and $j \neq i$.  At the starting point $(0.2, 4.0)$ (infeasible),
$H_f \approx \text{diag}(1.45, 10)$, so $H_{F_\lambda} \approx \text{diag}(1.45 + \lambda, 10)$.
The effective condition number in the infeasible region is approximately
\begin{equation}
  \kappa(H_{F_\lambda}) \approx \frac{1.45 + \lambda}{1.45} = 1 + \lambda/1.45.
\end{equation}
For $\lambda = 4.5$: $\kappa_{\rm eff} \approx 4.1$; stable step size $\alpha < 2/(1.45 + 4.5) = 0.33$.
The experiment uses $\alpha = 0.03 \ll 0.33$, indicating conservative safety margin.
An alternative that avoids this ill-conditioning is the \emph{augmented Lagrangian} method:
\begin{equation}
  \mathcal{L}_\lambda(x, \mu) = f(x) + \mu \max(0, 0.5 - x_1) + \frac{\lambda}{2}\max(0, 0.5 - x_1)^2,
\end{equation}
with dual update $\mu_{k+1} \leftarrow \mu_k + \lambda \max(0, 0.5 - x_k)$.  By maintaining a
Lagrange multiplier $\mu$ that tracks the constraint violation, the augmented Lagrangian achieves
exact constraint satisfaction at a \emph{finite} penalty $\lambda$ without increasing $\lambda
\to \infty$, thus avoiding the ill-conditioning problem.

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$
($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$);
unconstrained GD ($\alpha = 0.07$).  All run for 100 iterations.

\textbf{Projected GD} enforces feasibility as a hard constraint from the very first iteration.
The fundamental advantage is that feasibility is non-negotiable: the projection operator ensures
$x_k \in \mathcal{X}$ regardless of the gradient direction.  For the simple half-space
constraint $x_1 \geq 0.5$, the projection costs $O(1)$.  For complex constraints (e.g., the
intersection of multiple half-spaces or a ball), the projection can be expensive or even
NP-hard.

\textbf{Penalty methods} trade exact feasibility for algorithmic simplicity: only a modified
objective and its gradient are needed, requiring no projection oracle.  The trade-off is
parametrised by $\lambda$: small $\lambda$ allows infeasibility but has a better-conditioned
objective; large $\lambda$ enforces feasibility aggressively but requires smaller step sizes
(here $\alpha = 0.03$ for $\lambda = 4.5$) to maintain stability, offsetting some of the
convergence speed advantage.

\noindent\textbf{KKT conditions and optimality characterisation:}
The constrained problem $\min_{x_1 \geq 0.5} f(x)$ has first-order KKT conditions:
\begin{equation}
  \nabla f(x^\star) - \mu^\star e_1 = 0, \quad \mu^\star \geq 0, \quad
  \mu^\star (x_1^\star - 0.5) = 0,
\end{equation}
where $\mu^\star \geq 0$ is the KKT multiplier and $e_1 = (1, 0)^T$.  Since the unconstrained
minimum has $x_1^\star = 0.582 > 0.5$, the constraint is inactive and the complementary
slackness condition $\mu^\star(x_1^\star - 0.5) = 0$ forces $\mu^\star = 0$.  The constrained
KKT conditions therefore reduce to the unconstrained stationarity condition $\nabla f(x^\star) = 0$,
confirming that the constrained and unconstrained minima coincide.

This explains an important feature of the penalty method: as $\lambda \to \infty$, the stationary
point of $F_\lambda(x) = f(x) + \lambda\max(0, 0.5 - x_1)$ satisfies
$\nabla f(x^\star_\lambda) = \lambda \cdot \mathbf{1}_{x_1 < 0.5} \cdot e_1$.
In the limit, this approaches the KKT stationarity condition with $\mu^\star = \lambda \cdot
\mathbf{1}_{x_1 < 0.5}$, but since $x^\star_\lambda \to (0.582, 2.0)$ (feasible), the indicator
eventually equals zero, recovering the unconstrained condition.

\noindent\textbf{Boundary-sliding phase interpretation:}
During the boundary-sliding phase observed in the projected GD trajectory (when $x_1 = 0.5$
and $\partial f/\partial x_1 < 0$), the KKT multiplier is \emph{active}: $\mu^\star > 0$.
Quantitatively, the gradient equilibrium at $x_1 = 0.5$, $x_2 \in (2, 4)$ is:
\begin{equation}
  \nabla f(x) - \mu e_1 = 0 \implies \mu = \frac{\partial f}{\partial x_1}(0.5, x_2)
  = 2(0.5 - 1) + \cos(0.5) = -1 + 0.878 = -0.122.
\end{equation}
Since $\mu < 0$ violates the KKT condition $\mu \geq 0$, the point $(0.5, x_2)$ with $x_2 \neq 2$
is \emph{not} a KKT point --- projected GD is still moving along the boundary towards the
constrained optimum.  The constraint becomes inactive only when the trajectory reaches the
interior neighbourhood of $(0.582, 2.0)$ where $\partial f/\partial x_1 > 0$ and $\mu = 0$.

\textbf{When to choose projected GD vs penalty methods:}
\begin{itemize}[nosep]
  \item Choose \textbf{projected GD} when: (1) the projection has a cheap closed form
    (box, half-space, ball, simplex); (2) hard feasibility is required at every iteration
    (e.g., physical constraints in a control system); (3) the constraint set is well-characterised
    and stable throughout optimisation.
  \item Choose \textbf{penalty methods} when: (1) no efficient projection oracle exists
    (e.g., intersection of many half-spaces, non-convex feasible sets); (2) approximate
    feasibility is acceptable and the constraint tolerance can be controlled by $\lambda$;
    (3) the algorithm is being extended to general inequality/equality constraints, where
    augmented Lagrangian is the natural next step.
  \item Choose \textbf{augmented Lagrangian} when: both exact feasibility and computational
    efficiency are required.  The augmented Lagrangian $\mathcal{L}(x, \mu) = f(x) +
    \mu \max(0, 0.5 - x_1) + \frac{\lambda}{2}\max(0, 0.5 - x_1)^2$ with dual update
    $\mu \leftarrow \mu + \lambda \max(0, 0.5 - x_k)$ achieves exact constraint satisfaction
    at a \emph{finite} (not $\infty$) penalty $\lambda$, avoiding the ill-conditioning of pure
    penalty methods.
\end{itemize}

\section{Question 6: Linear Programmes and Frank--Wolfe Algorithm \hfill [30 marks]}
\label{sec:q6}
% ============================================================

\noindent\textit{Note on connection to Question 5:}  Both Q5 and Q6 deal with constrained
optimisation, but with different constraint structures and algorithmic approaches.
Q5 uses a simple half-space constraint ($x_1 \geq 0.5$) and compares methods that explicitly
enforce or penalise the constraint.  Q6 uses a box constraint with the same $x_1$ lower bound
($0.5 \leq x_1 \leq 5$), but introduces the Frank--Wolfe approach, which enforces constraints
implicitly through convex combinations rather than projection or penalty.  The LP analysis in
this section also demonstrates that for a \emph{linear} objective over the box, the constrained
minimum is at a vertex, providing context for why the LMO always selects a vertex of $\mathcal{X}$.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1, 2]^T$, the objective separates
per coordinate.  Since $a_1 = 1 > 0$, minimising over $x_1 \in [0.5, 5]$ gives $x_1^\star = 0.5$.
Since $a_2 = 2 > 0$, minimising over $x_2 \in [-5, 10]$ gives $x_2^\star = -5$.  Hence:
\begin{equation}
  x^\star = (0.5,\, -5), \qquad f^\star = 0.5 + 2(-5) = -9.5.
\end{equation}
This illustrates the \emph{Fundamental Theorem of Linear Programming}: the optimum of a linear
objective over a bounded convex polytope is attained at a \emph{vertex} (extreme point).
Proof sketch: suppose $x^\star$ is an interior optimum of $a^Tx$ over a polytope $\mathcal{P}$.
Since $a \neq 0$, the gradient $\nabla(a^Tx) = a$ is nonzero and constant, so by moving $x^\star$
in the direction $-a$, the objective $a^Tx^\star$ decreases until $x^\star$ hits a face of $\mathcal{P}$.
Repeating along each face dimension, we reach a vertex (0-dimensional face) with equal or
lower objective.  Therefore no interior point can be uniquely optimal.
The box $\mathcal{X}$ has four vertices $(0.5, -5)$, $(5, -5)$, $(5, 10)$, $(0.5, 10)$; the
LP solution is the vertex that minimises $a^T x = x_1 + 2x_2$, which evaluates to
$\{-9.5, -5, 25, 20.5\}$ respectively, confirming $(0.5, -5)$ with value $-9.5$.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$
      \Comment{Linear Minimisation Oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$
      \Comment{Convex combination: stays in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Key property: Projection-free.}
Since $\mathcal{X}$ is convex and both $x_k, z_k \in \mathcal{X}$, the convex combination
$\beta x_k + (1-\beta) z_k \in \mathcal{X}$ for all $\beta \in [0,1]$, without any projection.
This is the principal advantage over projected gradient descent for complex constraint sets.
Practical examples where Frank--Wolfe's LMO is cheaper than projection:
\begin{itemize}[nosep]
  \item \textbf{Nuclear norm ball} $\{M : \|M\|_* \leq \tau\}$ (used in matrix completion/
    recommender systems): \emph{projection} requires full SVD ($O(\min(m,n)^2\max(m,n))$);
    \emph{LMO} returns the rank-1 outer product of leading left and right singular vectors
    ($O(mn)$ via power iteration).
  \item \textbf{Probability simplex} $\{p \geq 0 : \sum_i p_i = 1\}$ (multinomial distributions):
    \emph{projection} requires sorting ($O(d \log d)$); \emph{LMO} is simply $e_{i^\star}$ where
    $i^\star = \arg\min_i \nabla f_i$ ($O(d)$).
  \item \textbf{Spectrahedron} $\{X \succeq 0 : \text{tr}(X) = 1\}$ (SDPs, Wainwright--Jordan):
    \emph{projection} requires full eigendecomposition; \emph{LMO} requires only the leading
    eigenvector.
\end{itemize}

For box constraints, the LMO decomposes per coordinate (cost $O(d)$):
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if }
  (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
so $z_k$ is always a vertex of $\mathcal{X}$.

\textbf{Convergence rate:} The standard Frank--Wolfe with $\gamma_k = 2/(k+2)$ satisfies
$f(x_k) - f^\star \leq 2L D^2 / (k+2)$, where $L$ is the smoothness constant and $D$ is the
diameter of $\mathcal{X}$.  This gives $O(1/k)$ convergence, matching GD but without a
projection step.  The fixed-$\beta$ variant used here achieves similar convergence but with
different constant factors depending on $\beta$.

\textbf{Frank--Wolfe gap:} A natural convergence certificate is the Frank--Wolfe (FW) gap,
also called the \emph{conditional gradient} or \emph{linear} gap:
\begin{equation}
  \text{gap}_k = \nabla f(x_k)^T (x_k - z_k) \geq 0,
\end{equation}
which upper-bounds the optimality gap: $f(x_k) - f^\star \leq \text{gap}_k$.  The gap equals
zero only at a KKT point (necessary optimality condition for constrained problems), making it
a practical stopping criterion.  Note that the standard FW uses $\gamma_k = 2/(k+2)$ as step
size ($x_{k+1} = (1-\gamma_k)x_k + \gamma_k z_k$, i.e., $\beta = 1-\gamma_k = k/(k+2)$),
giving a step that shrinks with $k$.  The experiments use a \emph{fixed} $\beta$, which is
simpler but does not guarantee the theoretical $O(1/k)$ rate for all $\beta$; for fixed $\beta$,
convergence depends on whether $\beta$ is close enough to 1 that the algorithm can approach
the optimum.

\textbf{Limitation -- zig-zag pattern:}  Because the Frank--Wolfe direction $z_k - x_k$ always
points towards a vertex of $\mathcal{X}$, and the optimal vertex alternates as the gradient
direction changes near an interior optimum, the algorithm exhibits a characteristic zig-zag
pattern.  The ``away-step'' Frank--Wolfe variant addresses this by also moving \emph{away} from
the current worst vertex, enabling faster convergence in practice.

The LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$, and the iterate averages
these jumps.  For an interior optimum with $\beta$ fixed (rather than the optimal
$\gamma_k = 2/(k+2)$), the convergence is $O(1/k)$.  Two competing effects determine the best
$\beta$: smaller $1-\beta$ (larger $\beta$) leads to slower movement per step but less
oscillation near the optimum; larger $1-\beta$ moves faster but overshoots.  The experiments
show $\beta = 0.985$ outperforms $\beta = 0.90$ on this interior problem.

\textbf{Boundary optimum:}
Frank--Wolfe is naturally well-suited to boundary optima because the LP oracle $z_k$ selects
a vertex consistent with the constraint, and the convex combination $\beta x_k + (1-\beta)z_k$
slides the iterate towards the boundary.  For $f(x) = x_1^2 + x_2^2$ over the box, the
gradient $\nabla f = 2x > 0$ (for $x$ in the first quadrant) always points the LMO towards
the lower-left vertex $(0.5, -5)$, providing a consistent descent direction that gradually
pushes $x_1 \to 0.5$.  Unlike projected GD, no projection step is needed.

However, convergence is slower at the boundary (residual gap $0.114$ after 140 iterations
vs $0.0046$ for interior after 180 iterations).  This asymmetry arises because Frank--Wolfe
has no mechanism to ``stay on the boundary'': the convex combination $\beta x_k + (1-\beta)z_k$
with $z_k = (0.5, -5)$ and $x_k$ near $(0.5, 0)$ may pull $x_2$ towards $-5$ rather than
towards 0, creating oscillation in the $x_2$ direction even as $x_1$ approaches its boundary
value.  A line-search variant of Frank--Wolfe that selects $\gamma_k = \arg\min_\gamma
f(\gamma z_k + (1-\gamma) x_k)$ would avoid this and converge in fewer iterations.

\textbf{Summary comparison:}
\begin{center}
\begin{tabular}{lcc}
\toprule
\textbf{Property} & \textbf{Interior optimum} & \textbf{Boundary optimum} \\
\midrule
LMO consistency & Oscillates between vertices & Consistent vertex selection \\
$x_k$ convergence pattern & Zig-zag, damped oscillation & Monotone approach to boundary \\
Final gap (fixed $\beta$) & 0.0046 (180 iters) & 0.114 (140 iters) \\
Projection needed? & No & No \\
\bottomrule
\end{tabular}
\end{center}

The practical implication is that Frank--Wolfe's principal advantage lies in
\emph{avoiding expensive projections}: it is preferred over projected GD when the projection
is costly (e.g., projecting onto a nuclear norm ball requires full SVD; projecting onto the
probability simplex requires sorting) but the LMO is cheap (for many structured constraint
sets, the LP oracle has a closed-form solution: the simplex LMO is just $\arg\min_i c_i$,
and the nuclear norm ball LMO is the rank-1 outer product of leading singular vectors).

\noindent\textbf{Convergence proof sketch for box constraints:}
The standard Frank--Wolfe analysis (Frank \& Wolfe, 1956; Jaggi, 2013) with step
$\gamma_k = 2/(k+2)$ proceeds as follows.  By $L$-smoothness:
\begin{equation}
  f(x_{k+1}) \leq f(x_k) + \gamma_k \nabla f(x_k)^T (z_k - x_k)
  + \frac{L\gamma_k^2}{2}\|z_k - x_k\|^2.
\end{equation}
Using the FW gap definition $\text{gap}_k = \nabla f(x_k)^T(x_k - z_k)$ and the diameter
$D = \max_{x,y \in \mathcal{X}}\|x - y\|$:
\begin{equation}
  f(x_{k+1}) - f^\star \leq (1 - \gamma_k)(f(x_k) - f^\star)
  + \frac{L \gamma_k^2 D^2}{2}.
\end{equation}
Telescoping with $\gamma_k = 2/(k+2)$ gives $f(x_k) - f^\star \leq \frac{2LD^2}{k+2} = O(1/k)$.
For the box $\mathcal{X} = [0.5, 5] \times [-5, 10]$, the diameter is
$D = \sqrt{4.5^2 + 15^2} \approx 15.66$, so the bound predicts
$f(x_{180}) - f^\star \leq 2L \cdot 15.66^2 / 182 \approx 2.69 L$.  For the interior
problem $f(x) = (x_1 - 1)^2 + (x_2 - 5)^2$ with $L = 2$ (since $\nabla^2 f = 2I$),
the predicted bound is $\approx 10.8$, which is a loose upper bound (the actual gap is
$0.0046$); the tightness discrepancy is because the constant $\beta$ step used here
is more aggressive than the decreasing $\gamma_k$ schedule in the analysis.

\noindent\textbf{Affine invariance:}  A key theoretical property of Frank--Wolfe is that its
convergence analysis is \emph{affine invariant}: the $O(1/k)$ rate depends on the curvature
constant $L$ and diameter $D$ of $\mathcal{X}$ in the \emph{current basis}, and these quantities
are invariant under affine transformations (scaling and rotation).  Concretely, if we apply
the affine map $A: x \mapsto Bx + c$ to the feasible set, the Frank--Wolfe iterates on the
transformed problem are exactly the images of the original iterates (since the LMO over $B\mathcal{X}$
equals $B$ applied to the LMO over $\mathcal{X}$).

This contrasts with projected GD: under the same affine transformation, the gradient
$\nabla \tilde{f}(y) = B^{-T}\nabla f(B^{-1}(y - c))$ has a different condition number
$\kappa(\tilde{f}) = \kappa(B^{-T}HB^{-1}) = \sigma_{\max}(B^{-T})^2 \kappa(H) / \sigma_{\min}(B^{-T})^2$,
which depends on the conditioning of $B$.  Projected GD's convergence rate $\rho = (\kappa-1)/(\kappa+1)$
therefore changes under affine transformation; Frank--Wolfe's $O(1/k)$ rate (with constant
$2LD^2$) does not.  This makes Frank--Wolfe theoretically robust to anisotropic feasible sets,
while projected GD is sensitive to the coordinate scaling.

\noindent\textbf{Frank--Wolfe vs Projected GD: a condition number view:}
For the interior optimum problem $f(x) = (x_1-1)^2 + (x_2-5)^2$ over the box
$\mathcal{X} = [0.5, 5] \times [-5, 10]$, the objective has $\kappa = 1$ ($\nabla^2 f = 2I$,
isotropic).  Projected GD at $\alpha = 1/L = 0.5$ would converge in 0 steps (isotropic
quadratic --- single Newton step), while Frank--Wolfe takes $O(1/k)$ iterations.  At $\kappa = 1$,
projected GD is strictly superior.  However, for a strongly anisotropic objective
$f(x) = (x_1-1)^2/\epsilon + (x_2-5)^2$ with $\kappa = 1/\epsilon \gg 1$, projected GD
requires $\rho \approx 1 - 2\epsilon$ per step while Frank--Wolfe's rate is unchanged
(since $L = 1/\epsilon$ but $D^2/L$ is constant for fixed $\mathcal{X}$, and the $O(1/k)$
constant $2LD^2 = 2 \times (1/\epsilon) \times D^2$ grows with $1/\epsilon$).  The crossover
where Frank--Wolfe outperforms projected GD occurs when $\kappa$ exceeds $\approx 1/(1-\beta)$
for the chosen fixed $\beta$.

\section{Summary and Conclusions}
\label{sec:conclusion}
% ============================================================

This report compared six families of optimisation algorithms across three benchmark problems
of increasing difficulty ($\kappa \in \{1.1,\ 6.9,\ 2508\}$).  The unifying theme is that
\emph{algorithm selection is fundamentally guided by the condition number $\kappa$ and the
availability of derivative information}.  The key conclusions are:

\subsection{Convergence Rates and Condition Number Sensitivity}

\begin{table}[H]
\centering
\caption{Theoretical convergence rates of studied methods on convex problems.
$\kappa = L/\mu$ (condition number), $L$ (smoothness constant), $\mu$ (strong convexity).}
\label{tab:convergence_rates}
\begin{tabular}{lcc}
\toprule
\textbf{Method} & \textbf{Convex rate} & \textbf{Strongly convex rate} \\
\midrule
Gradient Descent       & $O(L/k)$ & $O\!\left(\left(\frac{\kappa-1}{\kappa+1}\right)^k\right)$ \\
Polyak step (exact $f^\star$) & $O(L/k)$ & -- \\
Heavy Ball (optimal)   & -- & $O\!\left(\left(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\right)^{2k}\right)$ \\
Nesterov acceleration  & $O(L/k^2)$ & $O\!\left(\left(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\right)^k\right)$ \\
Newton's method        & \multicolumn{2}{c}{Quadratic convergence near minimum} \\
Frank--Wolfe (standard) & $O\!\left(\frac{LD^2}{k+2}\right)$ & -- \\
\bottomrule
\end{tabular}
\end{table}

The experimental results are broadly consistent with these theoretical rates:
\begin{itemize}
  \item On Benchmark~A ($\kappa \approx 1.1$), all first-order methods converge at comparable
    speed: the $\sqrt{\kappa}$ advantage of Nesterov over GD is only $1.05\times$, leaving
    no room for differentiation.
  \item On Benchmark~C ($\kappa \approx 2508$), Nesterov's per-step advantage over GD is
    $\sim 49\times$ (from Table~\ref{tab:q1_rates}: $1-\rho_{\text{GD}} \approx 0.0008$ vs
    $1-\rho_{\text{Nest}} \approx 0.039$), consistent with the observed $7\times$ improvement
    in final objective after 150 iterations (partial credit to the non-quadratic structure
    which limits the exact rate).
  \item Newton's method achieves single-step convergence on Benchmark~A (quadratic: exact 1 step)
    and 5-iteration convergence on Benchmark~B (nearly quadratic: nearly constant Hessian).
    On Rosenbrock (20 vs 80 iterations, $f = 0.686$ vs $f = 3.73$), the $5.4\times$ objective
    improvement with $4\times$ fewer iterations demonstrates that curvature information becomes
    the dominant factor for ill-conditioned problems.  The damped Newton ($\alpha = 0.22$) on
    Rosenbrock operates in the global descent phase; quadratic convergence would only emerge
    near the minimum after approximately 60 total Newton steps.
  \item The Rosenbrock function ($\kappa \approx 2508$) is the most \emph{discriminative}
    benchmark: all methods perform similarly on Benchmark~A, but Rosenbrock separates
    methods by up to two orders of magnitude in final objective value.
\end{itemize}

\subsection{Method-by-Method Summary}

\begin{itemize}
  \item \textbf{Polyak step:} Best when $f^\star$ is exactly known ($f=0.009$ on Benchmark C
    with $f^\star=0$ correctly specified); diverges otherwise ($f=2.72$ on Benchmark A with
    $f^\star=0$ misspecified by $0.48$).  Practically limited but theoretically elegant.
  \item \textbf{Adagrad:} Per-coordinate adaptation is beneficial for sparse or heterogeneous
    gradient problems (NLP, recommendation); monotone step decay $\alpha_0/\sqrt{k}$ causes
    stagnation on long deterministic runs ($f=2.20$ on Benchmark C vs Heavy Ball's $1.40$).
  \item \textbf{RMSprop:} Corrects Adagrad's decay via EMA with window $\approx 1/(1-\beta) = 10$
    observations; the most robust adaptive method for non-stationary objectives, but cannot
    exploit directional momentum ($f=3.12$ on Benchmark C).
  \item \textbf{Heavy Ball:} Effective momentum method on quadratics ($f=1.40$ on Benchmark C,
    $1.5\times$ better than Adagrad); no convergence guarantee on non-convex problems; optimal
    $\beta^\star = ((\sqrt\kappa-1)/(\sqrt\kappa+1))^2 \approx 0.923$ requires knowing $\kappa$.
  \item \textbf{Nesterov:} Theoretically optimal first-order method on convex problems ($O(1/k^2)$
    vs GD's $O(1/k)$); achieves $f=0.479$ on Benchmark C vs GD's $3.39$; lookahead gradient
    prevents oscillation; stable for any $\beta_{\max} < 1$.
  \item \textbf{Adam:} Combines momentum and adaptive scaling; $f=1.578$ on Benchmark C;
    excellent empirical performance in deep learning; no general convergence proof for
    non-convex problems; effective step bounded in $(-\alpha, \alpha)$ per coordinate.
  \item \textbf{Newton:} Achieves quadratic convergence near minimum; 1 step on Benchmark A,
    $\sim5$ steps on Benchmark B, $5.4\times$ objective improvement on Benchmark C with
    $4\times$ fewer iterations; requires $O(d^2)$ Hessian storage and $O(d^3)$ inversion
    per step --- impractical for $d > 10^4$ without low-rank or quasi-Newton approximation.
  \item \textbf{Finite differences:} Provides gradient-like quality with $O(\delta)$ accuracy;
    $\delta$ must be chosen to balance truncation ($O(\delta)$) and rounding ($O(\varepsilon_m/\delta)$)
    errors; optimal $\delta^\star = \sqrt{\varepsilon_m/L} \approx 10^{-8}$ for double precision.
  \item \textbf{Nelder--Mead:} Derivative-free; adapts simplex to local landscape via reflection,
    expansion, contraction; converges to exact Rosenbrock minimum ($f=0$) in 160 iterations,
    $\sim 400$ evaluations; suited to smooth unimodal problems with $d \leq 20$.
  \item \textbf{Projected GD:} Enforces hard constraint satisfaction at every iteration ($0$
    violation from step 1); projection cost $O(1)$ for half-space; requires cheap oracle.
  \item \textbf{Penalty methods:} Require no projection oracle; $\lambda$ controls
    feasibility-objective trade-off ($\lambda = 4.5$ achieves feasibility in $\sim 10$ iterations);
    large $\lambda$ increases effective condition number $\kappa_{\rm eff} = 1 + \lambda/1.45$,
    requiring smaller step sizes.
  \item \textbf{Frank--Wolfe:} Projection-free constrained optimisation; $O(1/k)$ convergence
    ($f \to 0.0046$ in 180 iterations for interior problem); handles interior and boundary optima;
    preferred when LMO is cheap (box: $O(d)$; nuclear norm: $O(mn)$ rank-1 SVD) and projection
    is expensive (nuclear norm: $O(\min(m,n)^2\max(m,n))$ full SVD).
\end{itemize}

\subsection{Practical Guidance}

For practitioners facing a new optimisation problem, the decision flow is:
\begin{enumerate}
  \item \textbf{Estimate $\kappa$ first.}  Run 5--10 GD iterations and observe the convergence
    rate; if the objective stagnates immediately, $\kappa$ is large.  Alternatively, compute or
    estimate $\lambda_{\max}/\lambda_{\min}$ of the Hessian at a representative point.
  \item \textbf{If $\kappa \lesssim 10$:} GD with line search is sufficient.  Nesterov provides
    at most $2\times$ speedup ($(1-0.449)/(1-0.747) \approx 2.2\times$ at $\kappa = 6.9$).
  \item \textbf{If $10 \lesssim \kappa \lesssim 100$:} Nesterov or Adam.  Adam is more robust
    to step-size tuning; Nesterov has stronger theoretical guarantees for convex problems.
  \item \textbf{If $\kappa > 100$:} Newton/quasi-Newton (L-BFGS) for $d$ up to $10^4$;
    for deep learning with $d > 10^6$, use Adam with learning rate decay.  First-order methods
    struggle: at $\kappa = 2508$, GD's $\rho = 0.999$ means $8600+$ iterations to reduce error
    $1000\times$.
  \item \textbf{If gradients are unavailable:} For $d \leq 20$, Nelder--Mead is the first
    choice (converges to exact minimum on smooth unimodal problems with $\sim 400$ evaluations).
    For $d > 20$, use CMA-ES (evolution strategy) or Bayesian optimisation.
  \item \textbf{If constraints exist:} Begin with projected GD (hard feasibility from step 1);
    switch to penalty/AL if projection is expensive; use Frank--Wolfe if the LMO has a
    closed-form solution (box, simplex, nuclear norm ball).
\end{enumerate}

\noindent\textbf{Cross-cutting insight:}
The condition number $\kappa$ is the single most predictive quantity for algorithm selection.
For $\kappa \approx 1$ (isotropic curvature), any first-order method works well and the choice
is largely a matter of implementation convenience.  For $\kappa \approx 10^1$--$10^2$, adaptive
methods (Adagrad, RMSprop, Adam) and momentum methods (Nesterov, Heavy Ball) provide
meaningful advantages.  For $\kappa > 10^3$ (as in Rosenbrock), first-order methods require
curvature information to make progress, motivating the shift to Newton/quasi-Newton methods
or to methods that implicitly build curvature estimates (Adam, L-BFGS).  The experiments
in this report validate this theoretical picture across six algorithmic families.

\label{tab:algo_selection}
\begin{tabular}{p{3.6cm}p{3.0cm}p{4.0cm}p{3.8cm}}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Hessian Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: per-coordinate minimisation over box constraint
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
