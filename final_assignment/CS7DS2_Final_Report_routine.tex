\begin{abstract}
This report presents a comprehensive comparative study of six families of optimisation algorithms
across three benchmark problems: a linear regression quadratic loss (Benchmark~A), a toy neural
network loss with sinusoidal perturbation (Benchmark~B), and the Rosenbrock function
(Benchmark~C).  The methods investigated are: (1)~adaptive step-size methods (Polyak, Adagrad,
RMSprop, Heavy Ball); (2)~momentum-based and stochastic methods (Nesterov acceleration, Adam,
mini-batch SGD); (3)~Newton's method with local second-order approximation;
(4)~derivative-free approaches (finite differences, Nesterov random search, Nelder--Mead, grid
search); (5)~constrained optimisation via projected gradient descent and quadratic penalty
methods; and (6)~the Frank--Wolfe conditional-gradient algorithm for box-constrained problems.
Key findings include: the Polyak step size diverges catastrophically when $f^\star$ is
misspecified but achieves the best convergence on Rosenbrock when $f^\star = 0$ is exact;
Nesterov acceleration reaches $f = 0.479$ on Rosenbrock vs $f = 3.39$ for vanilla GD; Newton's
method solves the quadratic loss in a single iteration; and projected gradient descent enforces
feasibility from the first iterate with zero constraint violation, a guarantee the penalty method
can only approximate.  Each method is evaluated in terms of convergence speed, trajectory
behaviour, stability, and computational cost per iteration.
\end{abstract}

\section{Benchmark Problems, Notation, and Experimental Setup}

\subsection{Standing Assumptions and Notation}

Throughout this report the following notation is used consistently.  Let $f : \mathbb{R}^d \to \mathbb{R}$ denote the objective function with (global) minimiser $x^\star$.  A function is \emph{$L$-smooth} if its gradient is Lipschitz continuous:
\begin{equation}
\|\nabla f(x) - \nabla f(y)\| \leq L\,\|x - y\|, \qquad \forall\, x, y \in \mathbb{R}^d,
\end{equation}
which implies the quadratic upper bound $f(y) \leq f(x) + \nabla f(x)^T(y-x) + \frac{L}{2}\|y-x\|^2$.  A function is \emph{$\mu$-strongly convex} if $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$.  The \emph{condition number} $\kappa = L/\mu$ governs the speed of first-order methods: gradient descent on a $\mu$-strongly convex, $L$-smooth function with step size $\alpha \leq 1/L$ satisfies
\begin{equation}
f(x_{k+1}) - f^\star \leq \left(1 - \frac{1}{\kappa}\right)^k \bigl(f(x_0) - f^\star\bigr),
\label{eq:gd_rate}
\end{equation}
a \emph{linear} (geometric) convergence rate.  All experiments use \texttt{np.random.seed(42)} for reproducibility.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
x^{(i)} \sim \mathcal{N}(0, I_2), \quad
y^{(i)} = {\theta^{\star}}^T x^{(i)} + \varepsilon^{(i)}, \quad
\varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The mean-squared-error loss is
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
= \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a convex quadratic with Hessian $H = \frac{1}{m}X^T X$ (constant) and gradient
$\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$.  The Hessian eigenvalues satisfy
$\lambda_{\min} \approx \mu$ and $\lambda_{\max} \approx L$, giving $\kappa \approx L/\mu$.
Because observation noise $\varepsilon$ is irreducible, the minimum is $J^{\star} \approx 0.4826$
(not zero), reached at the ordinary least-squares estimator $\hat\theta_{\mathrm{OLS}} =
(X^TX)^{-1}X^Ty \approx [3.028, 4.017]^T$.  Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}

\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\; 10(x_2 - 2)]^T$ and the Hessian is
$H(x) = \operatorname{diag}(2 - \sin(x_1),\; 10)$.  The sinusoidal term breaks exact quadratic
structure, introducing mild non-linearity in the $x_1$ direction.  Setting $\nabla f = 0$:
$x_2^\star = 2$ exactly (from $10(x_2-2)=0$), and $x_1^\star$ satisfies
$h(x_1) = 2(x_1 - 1) + \cos(x_1) = 0$.  By bisection on $h(0.5) \approx -0.122 < 0$ and
$h(0.6) \approx +0.025 > 0$, we obtain $x_1^\star \approx 0.5828$.  This is the value used
in the theoretical analysis; contour-plot markers use $x_1 \approx 0.61$ due to rounding in
the visualisation code.  The global minimum is at $(x_1^\star, x_2^\star) \approx (0.5828,
2.0)$ with $f^\star = (0.5828-1)^2 + 0 + \sin(0.5828) \approx 0.1733 + 0.5503 \approx
0.7236 \approx 0.7244$ (small discrepancy from finite-precision root approximation).  The
Hessian eigenvalue ratio at the minimum is $(2 - \sin(0.5828)) / 10 \approx 1.45/10$,
i.e.\ $\kappa \approx 6.9$.  Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)^T$ with $f^\star = 0$.  The Hessian at the optimum has
eigenvalues $\approx 0.5$ and $\approx 1000$, giving condition number $\kappa \approx 2000$.
This extreme ill-conditioning, combined with a narrow curved valley along $x_2 = x_1^2$, makes
Rosenbrock one of the most challenging standard test functions for first-order methods.  Gradient
descent requires a very small step $\alpha \lesssim 2/(L + \mu)$ for stability, yet this tiny
step makes progress along the shallow valley floor extremely slow.  Starting point:
$x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}

For constrained problems (Questions 5 and 6):
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}.
\end{equation}
This is a box (hyper-rectangle), the simplest polytope.  Projection onto $\mathcal{X}$ is
$\Pi_{\mathcal{X}}(x) = \operatorname{clip}(x; l, u)$ --- a per-coordinate clamp --- computable
in $O(d)$ time.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

For gradient descent on an $L$-smooth function, the step size $\alpha = 1/L$ guarantees a
sufficient decrease of $\frac{1}{2L}\|\nabla f(x_k)\|^2$ per iteration.  The \emph{Polyak step}
avoids estimating $L$ by using curvature information directly: $\alpha_k = (f(x_k) -
f^\star)/\|\nabla f(x_k)\|^2$.  This is theoretically optimal for convex functions when
$f^\star$ is known \cite{polyak1987introduction}, achieving convergence in $O(1/k)$ steps.
\emph{Adagrad} \cite{duchi2011adaptive} accumulates squared-gradient statistics to rescale each
coordinate independently, adapting to the geometry of the loss landscape.  \emph{RMSprop}
introduces an exponential forgetting factor to prevent Adagrad's learning rate from decaying to
zero on non-stationary problems.  The \emph{Heavy Ball} (Polyak momentum) method augments
gradient descent with a momentum term that accelerates convergence on quadratic objectives.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent (GD) baseline
across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0 > 0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Coordinate-wise squared-gradient accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0 > 0$, decay $\rho \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \rho\, v_k + (1 - \rho)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Heavy Ball (Polyak Momentum)}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Momentum accumulation}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}
Note that the decay parameter in RMSprop is denoted $\rho$ to avoid confusion with the momentum
parameter $\beta$ used in the Heavy Ball and Nesterov methods.  In the implementation,
$\rho = 0.9$ corresponds to a half-life of approximately $\log(2)/\log(1/0.9) \approx 6.6$
iterations for past gradient information.
\end{remark}

\textbf{Key finding:} The Polyak step size is highly sensitive to the accuracy of $f^{\star}$.
When the specified $f^{\star} = 0$ deviates from the true minimum, the method diverges because
\begin{equation}
\alpha_k = \frac{f(x_k) - f^\star_{\mathrm{specified}}}{\|\nabla f(x_k)\|^2 + \varepsilon}
\;\longrightarrow\; \frac{f^\star_{\mathrm{true}}}{\varepsilon} \;\longrightarrow\; \infty
\quad \text{as } \|\nabla f(x_k)\| \to 0.
\end{equation}
On Benchmark~C where $f^\star = 0$ is exact, Polyak achieves the best convergence, confirming
its theoretical optimality when $f^\star$ is known.  In practice, $f^\star$ is rarely known
for non-quadratic problems, limiting Polyak's direct applicability.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^\star$ is known exactly, Polyak converges fastest
  (Rosenbrock: $f = 0.009$ in 120 steps).  Otherwise, Adagrad and Heavy Ball match or exceed
  GD baseline.

\item \textbf{Robustness to curvature:} Heavy Ball benefits most on the highly ill-conditioned
  Rosenbrock ($\kappa \approx 2000$): momentum builds up in the consistent descent direction
  along the valley, partially compensating for the slow per-step progress imposed by the small
  stable step size.

\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential
  gradient averaging.  Heavy Ball exhibits characteristic overshoot followed by damped
  oscillation, especially on more-anisotropic problems.

\item \textbf{Stability:} GD baseline is most stable but slowest.  Adagrad is uniformly stable
  due to its monotonically decreasing effective step, though this can cause premature stalling
  on later iterations.  Polyak is \emph{unstable} whenever $f^\star$ is misspecified.

\item \textbf{Practical implication:} In practice, exact $f^\star$ is rarely available,
  restricting Polyak to problems with a known theoretical optimum (e.g.\ feasibility problems).
  RMSprop and Adagrad are more robust for general machine-learning training loops.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}

Vanilla gradient descent has a linear convergence rate $O((1 - 1/\kappa)^k)$ for
$\mu$-strongly convex, $L$-smooth objectives.  Nesterov acceleration improves this to
$O((1 - 1/\sqrt{\kappa})^k)$, which is \emph{optimal} among first-order methods in the
worst case \cite{nesterov1983method}.  For general convex functions (no strong convexity), GD
achieves $O(1/k)$ while Nesterov achieves $O(1/k^2)$ in function-value gap.

Adam \cite{kingma2014adam} combines per-coordinate adaptive scaling (from RMSprop) with
first-moment momentum (heavy ball).  While Adam converges empirically in fewer iterations on
many deep learning tasks, it is \emph{not} guaranteed to converge to the global minimum on
non-convex problems without careful hyperparameter tuning, and counter-examples of divergence
exist \cite{reddi2018convergence}.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max} \in [0,1)$,
iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\; \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead (extrapolation) point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is evaluating the gradient at the \emph{extrapolated} point
$\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$.  This ``look-ahead'' allows the method to
correct its trajectory before overshooting and is the mechanism behind the $O(1/k^2)$ rate.
The adaptive schedule $\beta_k = (k-1)/(k+2)$ increases momentum gradually from 0 towards
$\beta_{\max}$, matching the $t_k$ sequence in Nesterov's original analysis.

\begin{remark}[Heavy Ball vs Nesterov]
Both methods use momentum, but they differ in where the gradient is evaluated.  Heavy Ball
evaluates $\nabla f(x_k)$ (current position), leading to momentum along the \emph{past}
gradient direction.  Nesterov evaluates $\nabla f(x_k + \beta_k z_k)$ (look-ahead position),
providing a corrective gradient that partially cancels the overshoot from momentum.  This
distinction is what gives Nesterov its $O(1/k^2)$ convergence rate for general convex functions,
while Heavy Ball only provably achieves $O(1/\sqrt{\kappa})^k$ (linear) convergence on
quadratics and may not converge on general non-quadratic functions with fixed $\beta$.
\end{remark}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha > 0$, moment decay rates $\beta_1, \beta_2
\in [0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0} \in \mathbb{R}^d,\;\; v_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (EMA of gradients)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (EMA of $g^2$)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction (important for early iters)}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$, a first-moment estimate of the gradient) with per-coordinate
adaptive scaling (via $v_t$, a second-moment estimate), inheriting the advantages of both
RMSprop and heavy-ball momentum.  The bias correction terms $(1 - \beta_1^t)$ and
$(1 - \beta_2^t)$ are critical during early iterations: without them, the initialisation
$m_0 = v_0 = 0$ would bias the estimates toward zero, causing spuriously large or small
effective step sizes.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD is applied to Benchmark~A (linear regression) with $n = 1000$ samples, learning
rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, $50$ epochs, and data shuffled at every
epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha > 0$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices into $\pi_1, \pi_2, \ldots, \pi_n$
    \For{each mini-batch $\mathcal{B}_j = \{\pi_{(j-1)b+1}, \ldots, \pi_{jb}\}$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}_j}^T(X_{\mathcal{B}_j}\theta - y_{\mathcal{B}_j})$
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

A key statistical property: the mini-batch gradient is an \emph{unbiased} estimator of the full
gradient $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$, with variance scaling as $O(1/b)$.
Smaller batches therefore provide more gradient updates per epoch (more SGD steps) but with
higher variance per step.

For strongly convex losses with gradient variance $\sigma^2$, SGD with step size $\alpha_k =
c/k$ achieves:
\begin{equation}
\mathbb{E}[f(\bar\theta_k) - f^\star] \leq \frac{\sigma^2}{2\mu k} + \text{bias terms},
\end{equation}
where $\bar\theta_k$ is the iterate average.  The irreducible noise floor arises because the
step size must go to zero to achieve convergence, but a constant step size is used here (50
epochs at $\alpha = 0.06$), so the iterates hover around the noise floor $J^\star \approx
0.4826$ rather than converging exactly to it.  The oscillation around the noise floor grows
with the gradient variance (proportional to $1/b$), explaining why batch $b = 5$ shows more
oscillation than $b = 40$.

\subsection{Local Approximations of $g(x) = x^4$}

The Taylor expansion of $g$ around $x_0 = 0.25$ is:
\begin{align}
g(x) &\approx g(x_0) + g'(x_0)(x - x_0) \notag\\
     &= 0.25^4 + 4 \cdot 0.25^3\,(x - 0.25)
      = 0.0039 + 0.0625\,(x - 0.25). \tag{first order}\\
g(x) &\approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 \notag\\
     &= 0.0039 + 0.0625\,(x - 0.25) + 0.375\,(x - 0.25)^2. \tag{second order}
\end{align}

The Newton update minimises the second-order approximation: setting the derivative of the
quadratic model to zero gives $x_{k+1} = x_k - g'(x_k)/g''(x_k)$.  This corresponds to
stepping directly to the stationary point of the local quadratic surrogate, using curvature
information to determine step length automatically.

\subsection{Newton's Method with Hessian Regularisation}

\begin{algorithm}[H]
\caption{Damped Newton's Method}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, regularisation $\lambda \geq 0$,
iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation for positive-definiteness}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian regularisation
$\lambda = 10^{-8}$.  The Hessian is computed analytically: for Benchmark~A, $H = X^TX/m$ is
constant (precomputed once); for Benchmark~B, $H(x) = \operatorname{diag}(2 - \sin(x_1), 10)$;
for Benchmark~C, the full $2 \times 2$ Hessian is evaluated at each step.

The Tikhonov regularisation $H_k + \lambda I$ ensures positive-definiteness even when the
Hessian is indefinite (which can occur for Rosenbrock in regions far from the optimum, where
$h_{11} = 2 + 1200x_1^2 - 400x_2$ can be negative).  Full Newton steps ($\alpha = 1$) are
used when Hessian information is reliable; damped steps ($\alpha < 1$) are used on Rosenbrock
where the rapidly varying Hessian can make full steps overshoot.

\begin{theorem}[Quadratic Convergence of Newton's Method]
Let $f$ be twice continuously differentiable with Lipschitz continuous Hessian $\nabla^2 f$.
If $x_0$ is sufficiently close to a local minimum $x^\star$ and $\nabla^2 f(x^\star) \succ 0$,
then Newton's method with $\alpha = 1$ satisfies
\begin{equation}
\|x_{k+1} - x^\star\| \leq C\,\|x_k - x^\star\|^2
\end{equation}
for some constant $C > 0$.  This \emph{quadratic} (superlinear) convergence means the number of
correct decimal digits approximately doubles each iteration near the solution.
\end{theorem}

\subsection{Affine Invariance and Cost of Newton vs GD}

A key theoretical property of Newton's method is \emph{affine invariance}: the iterates are
unchanged under any invertible affine reparametrisation $\tilde{x} = Ax + b$.  Formally, if
$\tilde{f}(\tilde{x}) = f(A^{-1}(\tilde{x}-b))$, then Newton's method on $f$ and
$\tilde{f}$ produce identical iterates (after mapping back).  This is because the Newton
direction $H^{-1}\nabla f$ automatically cancels the coordinate scaling through the
$H^{-1}$ factor.  Gradient descent, by contrast, is not affine-invariant: poorly conditioned
problems ($\kappa \gg 1$) are much harder for GD than for Newton, as confirmed by the
Rosenbrock results (Q3 Table~\ref{tab:q3_final}).

Newton's method requires forming and inverting the Hessian at each iteration: for $d$-dimensional
problems this costs $O(d^3)$ per step (or $O(d^2)$ if the structure is exploited), compared to
$O(d)$ for GD.  For the $d = 2$ benchmarks here, this overhead is negligible, but for
large-scale problems ($d = 10^6$, as in neural network training) the Hessian is never formed
directly.  Instead:
\begin{itemize}[nosep]
\item \textbf{Quasi-Newton (L-BFGS)}: approximates $H^{-1}$ from gradient differences,
  achieving superlinear convergence with $O(md)$ cost ($m$ stored vector pairs).
\item \textbf{Natural gradient}: uses the Fisher information matrix as a preconditioner,
  related to second-order methods in probability-model space.
\item \textbf{Hessian-free optimisation}: computes $H v$ products (Pearlmutter trick, $O(d)$)
  and uses conjugate gradient to solve the Newton system approximately.
\end{itemize}

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}

\subsection{Part A: Finite Differences and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with a ratio of
function values:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\end{equation}
where $e_i$ is the $i$-th unit vector.  The error has two competing components:
\begin{itemize}[nosep]
\item \textbf{Truncation error} $O(\delta)$ from the Taylor expansion residual.
\item \textbf{Round-off error} $O(\varepsilon_{\mathrm{mach}}/\delta)$ from finite-precision
  arithmetic.
\end{itemize}
Balancing these gives the optimal $\delta^\star \sim \sqrt{\varepsilon_{\mathrm{mach}}} \approx
10^{-8}$ for 64-bit floating point, yielding error $O(\varepsilon_{\mathrm{mach}}^{1/2}) \approx
10^{-8}$.  The assignment tests $\delta = 0.05$ (acceptable for this smooth function) and
$\delta = 0.8$ (poor: large truncation error spanning a region of significant curvature change).

Implementation: FD GD is run with $\alpha = 0.08$ and $d + 1 = 3$ function evaluations per
gradient (one base evaluation plus one per coordinate).

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
    \Comment{Stochastic directional derivative}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates a \emph{directional} derivative along a random unit vector,
requiring only two function evaluations per iteration regardless of dimension $d$.  This
``dimension-free'' cost per step makes it attractive for high-dimensional black-box

projection discards $d-1$ gradient components each step), so convergence is correspondingly
slower.  Implementation: $\alpha = 0.025$, $\delta = 0.08$, run for 220 iterations.

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n + 1 = 3$ vertices in $\mathbb{R}^2$ and
iteratively deforms it through four operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move the worst vertex through the centroid of the
  remaining vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection succeeded, try an even larger step.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection worsened, contract the worst vertex
  toward the centroid.
\item \textbf{Shrink} ($\sigma = 0.5$): as a last resort, contract all vertices toward the best.
\end{enumerate}
No gradient information is required; only function values are used.  Settings: initial simplex
step $= 0.35$, 160 iterations.

The fundamental trade-off is: methods using exact gradient information (GD, Newton) converge
faster per iteration but require differentiable objectives.  Finite-difference methods extend
gradient descent to problems with available but analytically complex gradients, at the cost of
$d+1$ function evaluations per step.  Zeroth-order methods (random search, Nelder--Mead) can
handle non-differentiable or black-box objectives but converge more slowly in terms of function
evaluations.

From an \emph{oracle complexity} perspective, the information-theoretic lower bound for zeroth-order
convex optimisation requires at least $\Omega(d/\varepsilon^2)$ function evaluations to achieve

achieves $O(d^2/\varepsilon^2)$ evaluations for the full gradient estimate, so it is nearly optimal.
Grid search requires $O((1/\varepsilon)^d)$ evaluations, which is exponential in dimension ---
illustrating the \emph{curse of dimensionality} for exhaustive search.

\subsection{Problem Setup and KKT Conditions}

Minimise Benchmark~B subject to the half-space constraint $x_1 \geq 0.5$:
\begin{equation}
\min_{x \in \mathbb{R}^2}\; f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)
\quad \text{s.t.} \quad x_1 \geq 0.5.
\end{equation}
Starting from the \emph{infeasible} point $x_0 = (0.2, 4.0)$.  Since the unconstrained minimum
$(x_1^\star \approx 0.5828) > 0.5$ lies in the interior of the feasible region
$\{x_1 \geq 0.5\}$, the constraint is \emph{inactive} at the optimum and the constrained
solution equals the unconstrained one.  The KKT conditions confirm this: with multiplier
$\mu \geq 0$ for the constraint $g(x) = -x_1 + 0.5 \leq 0$,
\begin{equation}
\nabla f(x^\star) + \mu\, (-e_1) = 0, \quad \mu \geq 0, \quad \mu g(x^\star) = 0.
\end{equation}
Since $x_1^\star > 0.5$, complementary slackness requires $\mu = 0$, confirming
$\nabla f(x^\star) = 0$: the constrained optimum is the unconstrained one.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project onto feasible set: $x_1 \gets \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method (with $L^1$ penalty)}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda\,\max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $g_k \gets \nabla F_\lambda(x_k)$ \Comment{$= \nabla f(x_k) - \lambda\,\mathbf{1}[x_1 < 0.5]\,e_1$}
    \State $x_{k+1} \gets x_k - \alpha\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$
($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$ due to the
steeper landscape); unconstrained GD ($\alpha = 0.07$).  All run for 100 iterations.

\textbf{Projected GD} enforces feasibility as a hard constraint at every iteration: the iterate
$x_k$ is always feasible, guaranteeing constraint satisfaction throughout the optimisation.  The
projection onto $\{x_1 \geq 0.5\}$ is trivial ($O(1)$ operation: $x_1 \gets \max(0.5, x_1)$),
but for complex constraint sets (e.g.\ semi-definite cone, $\ell^1$ ball) the projection itself
can require solving a non-trivial sub-problem.

\textbf{Penalty methods} trade exact feasibility for algorithmic simplicity: only a modified
gradient is needed, with no projection oracle.  The weight $\lambda$ controls the penalty
strength.  As $\lambda \to \infty$, the penalised problem converges to the constrained one,
but the objective landscape becomes increasingly ill-conditioned near the boundary, requiring
smaller step sizes (here, $\alpha = 0.03$ for $\lambda = 4.5$ vs $\alpha = 0.05$ for
$\lambda \leq 1.8$).  This is the fundamental tension: tighter constraint enforcement requires
both a larger $\lambda$ and a smaller step size, increasing the effective condition number and
slowing convergence.

\begin{remark}
The \emph{augmented Lagrangian} (method of multipliers) addresses this ill-conditioning
trade-off by maintaining an explicit Lagrange multiplier $\mu$ alongside the penalty, solving
\[
\min_x\; f(x) + \langle \mu, g(x) \rangle + \frac{\lambda}{2}\|g(x)^+\|^2,
\]
where $g(x)^+ = \max(0, g(x))$.  Multiplier updates correct the feasibility gap without
requiring $\lambda \to \infty$, achieving much better conditioning than pure penalty methods
while retaining algorithmic simplicity.  This extends naturally to ADMM for distributed
optimisation.
\end{remark}

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2
\leq 10\}$, a box with vertices at $(0.5, -5)$, $(5, -5)$, $(5, 10)$, and $(0.5, 10)$.

\textbf{Linear Programme:} For the objective $f(x) = a^T x$ with $a = [1, 2]^T$, the minimum
over $\mathcal{X}$ is achieved at a vertex (by the fundamental theorem of linear programming:
any bounded LP achieves its optimum at an extreme point of the feasible polytope).  Since both
components of $a$ are positive, minimising $x_1 + 2x_2$ over the box requires each coordinate
at its lower bound:
\begin{equation}
x^{\star} = \bigl(\ell_1,\; \ell_2\bigr) = (0.5,\; -5), \qquad
f^{\star} = 1 \cdot 0.5 + 2 \cdot (-5) = -9.5.
\end{equation}
More generally, for $f(x) = a^T x$ over a box $[\ell, u]$:
\begin{equation}
x_i^\star = \begin{cases} \ell_i & \text{if } a_i > 0 \\ u_i & \text{if } a_i < 0 \end{cases},
\end{equation}
computable in $O(d)$ by inspection.

\centering
\includegraphics[width=0.85\textwidth]{figures/q6_lp.pdf}
\caption{Q6-I: Feasible region (blue box) with linear objective contours $f(x) = x_1 +
2x_2$.  The contour lines are parallel and the minimum (darkest contour) is at the lower-left
corner $(0.5, -5)$, confirming the vertex-solution property of linear programmes.  Moving
along any edge from this corner increases $f$, verifying it is the global optimum.}

\end{figure}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$
    \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$
    \Comment{Convex combination of current point and LP vertex}
\EndFor
\end{algorithmic}
\end{algorithm}

For box constraints, the LMO decomposes per coordinate (as shown in the LP analysis above):
\begin{equation}
(z_k)_i = \begin{cases} \ell_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if }
(\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
This requires $O(d)$ operations, far cheaper than a general projection.  The convex combination
step $x_{k+1} = \beta x_k + (1-\beta)z_k$ maintains feasibility at every iteration (since
$\mathcal{X}$ is convex and both $x_k, z_k \in \mathcal{X}$), eliminating the need for a
projection oracle entirely.

The standard Frank--Wolfe uses the decaying step $\gamma_k = 2/(k+2)$ (i.e.\ $\beta_k = 1 -
2/(k+2) = k/(k+2)$), achieving an $O(1/k)$ convergence rate in function-value gap for
$L$-smooth convex objectives.  The experiments here use a \emph{fixed} $\beta$ for simplicity.

\begin{remark}
The \emph{Frank--Wolfe gap} $g_k = \nabla f(x_k)^T(x_k - z_k) \geq 0$ is a natural measure
of suboptimality and an upper bound on $f(x_k) - f^\star$.  It equals zero if and only if the
KKT conditions hold.
\end{remark}

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum:} Frank--Wolfe converges but exhibits a characteristic zig-zag pattern.
The LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$ at each iteration (since
$\arg\min_{x \in \mathcal{X}} c^T x$ is always a vertex for a bounded polytope), and the
convex combination gradually averages these jumps.  The theoretical convergence rate is
$O(1/k)$ in function value (for $L$-smooth convex objectives), slower than the $O(1/k^2)$ of
Nesterov acceleration.  The intuitive reason: Frank--Wolfe steps are always towards a vertex,
limiting the ``curvature information'' exploited per iteration.

\textbf{Boundary optimum:} Frank--Wolfe is well suited to boundary optima because $z_k$
frequently selects the vertex $(0.5, u_2)$ or $(0.5, \ell_2)$ when the gradient points in the
$-x_1$ direction.  The iterate naturally approaches the boundary $x_1 = 0.5$ without needing
explicit projection, an advantage over penalty methods.  The gap $f(x_k) - f^\star \approx
0.11$ at 140 iterations reflects the fixed $\beta = 0.93$ schedule; using the optimal
$\gamma_k = 2/(k+2)$ decay would improve convergence.

\textbf{Comparison with projected GD:} For box constraints, projection is $O(d)$ and both
methods have the same per-iteration cost.  Frank--Wolfe's advantage emerges for complex
constraint sets (e.g.\ the nuclear-norm ball) where the LMO (a singular value decomposition)
is cheaper than the projection (Dykstra's algorithm or proximal operator).

\begin{proposition}[Frank--Wolfe Convergence]
Let $f$ be convex and $L$-smooth over a compact convex set $\mathcal{X}$ with diameter
$D = \max_{x,y \in \mathcal{X}} \|x - y\|$.  With step sizes $\gamma_k = 2/(k+2)$, the
Frank--Wolfe iterates satisfy
\[
f(x_k) - f^\star \leq \frac{2 L D^2}{k + 2} = O\!\left(\frac{1}{k}\right).
\]
This rate is tight in general.  However, if $f$ is additionally $\mu$-strongly convex and the
optimum is in the interior of $\mathcal{X}$, the rate improves to linear convergence with the
standard step-size rule \cite{garber2015faster}.
\end{proposition}

For the box $\mathcal{X}$ used in Question~6, $D = \sqrt{(5-0.5)^2 + (10-(-5))^2} =

because the bound uses the worst-case diameter.  The empirical gap $f(x_{140}) - 0 \approx
0.36$ for the boundary case is much smaller, reflecting the tighter effective diameter once
the iterates concentrate near the optimum.

Table~\ref{tab:cross_comparison} shows that for the ill-conditioned Rosenbrock function,
Newton's method (20 iterations) achieves $f = 0.686$, significantly better than GD with 80
iterations ($f = 3.73$), while Nesterov (150 iterations) achieves $f = 0.479$, and the Polyak
step with correct $f^\star$ achieves $f = 0.009$ in 120 iterations --- the best result across
all first-order methods.

\textbf{On adaptive step sizes (Q1):} The Polyak step is theoretically optimal when
$f^\star$ is known exactly, as demonstrated on Rosenbrock where it achieves $f = 0.0094$ in
120 iterations --- better than any other Q1 method.  However, its sensitivity to $f^\star$
misspecification makes it impractical for most real-world problems where the optimal value is
unknown.  Adagrad and Heavy Ball are more robust alternatives that match or exceed the GD
baseline on all benchmarks.

\textbf{On momentum (Q2):} Nesterov acceleration provides the greatest practical benefit on
ill-conditioned problems: a factor $7\times$ improvement over GD on Rosenbrock.  Adam's
per-coordinate scaling provides additional robustness to anisotropy, making it the preferred
choice for high-dimensional stochastic settings (deep learning).  For mini-batch SGD, smaller
batches converge faster per epoch but show higher irreducible oscillation near the minimum;
under high observation noise, batch size becomes less decisive.

\textbf{On second-order methods (Q3):} Newton's method is dramatically more efficient than
GD for problems with available Hessians, solving the quadratic loss in a single iteration and
achieving $5.4\times$ lower objective than GD on Rosenbrock with $4\times$ fewer iterations.
The quadratic convergence rate near the optimum makes Newton the gold standard for small-scale,
smooth, well-conditioned problems, with quasi-Newton methods (L-BFGS) extending these benefits
to large-scale settings.

\textbf{On derivative-free methods (Q4):} Finite-difference approximations faithfully replicate
exact gradient descent at small $\delta$, confirming their practical value.  Nesterov random
search and Nelder--Mead trade accuracy for applicability to non-differentiable or black-box
objectives.  Grid search guarantees coverage but is impractical beyond dimension 3.

\textbf{On constrained optimisation (Q5):} Projected GD provides hard, immediate constraint
satisfaction from the first iterate, making it the preferred method when a projection oracle
is available.  Penalty methods offer greater implementation simplicity but require careful
tuning of $\lambda$ to balance feasibility enforcement and step-size stability.

\textbf{On Frank--Wolfe (Q6):} The conditional gradient algorithm handles constraints via a
linear minimisation oracle, naturally enforcing feasibility without projection.  It is
particularly effective for boundary optima and constraint sets whose LMO is cheaper than the
projection (e.g.\ nuclear norm, $\ell^1$ ball).  Its $O(1/k)$ convergence rate and tendency
to zig-zag near interior optima are its principal limitations.

Overall, the choice of optimisation algorithm must account for: (i)~the smoothness and
convexity of the objective; (ii)~the availability of gradient or Hessian information;
(iii)~the structure of the constraint set; and (iv)~the problem's condition number.  No single
method dominates across all criteria, and the experiments here illustrate how algorithm
properties connect to benchmark structure in theoretically predictable ways.

\subsection*{Practical Algorithm Selection Guidelines}

Based on the experimental results and theoretical analysis:

\begin{enumerate}[label=\textbf{\arabic*.}]

\item \textbf{Unconstrained smooth convex / strongly convex:}
  \begin{itemize}[nosep]
  \item Small $d$ ($\leq 10^3$) and Hessian available: use \textbf{Newton} or L-BFGS.
  \item Large $d$ or no Hessian: use \textbf{Nesterov} if batch gradients are cheap, or
    \textbf{Adam/RMSprop} in mini-batch stochastic settings.
  \item $f^\star$ known exactly: \textbf{Polyak step} is optimal.
  \end{itemize}

\item \textbf{Ill-conditioned problems ($\kappa \gg 1$, e.g.\ Rosenbrock):}
  \begin{itemize}[nosep]
  \item Always prefer second-order information if available (Newton: affine invariant, $O(d^3)$).
  \item Among first-order methods, \textbf{Nesterov} or \textbf{Heavy Ball} (with tuned $\beta$)
    outperform vanilla GD by a factor $\sqrt{\kappa}$ in convergence rate.
  \end{itemize}

\item \textbf{Non-differentiable or black-box objective:}
  \begin{itemize}[nosep]
  \item Gradient available via finite differences ($d$ small): \textbf{FD GD with small $\delta$}.
  \item No gradient structure: \textbf{Nelder--Mead} for $d \leq 10$, \textbf{Nesterov random search}
    for large $d$.
  \item Exhaustive global search needed (last resort): \textbf{grid search}, but only for $d \leq 3$.
  \end{itemize}

\item \textbf{Box-constrained or general polytope constraints:}
  \begin{itemize}[nosep]
  \item Simple constraints (box, $\ell^2$ ball): \textbf{Projected GD} --- projection is $O(d)$.
  \item Complex constraints (nuclear norm, $\ell^1$ ball): \textbf{Frank--Wolfe} --- LMO is cheaper.
  \item Penalty method: viable when projection oracle is unavailable, but tune $\lambda$ carefully.
  \end{itemize}

\item \textbf{Key hyperparameter sensitivity:}
  \begin{itemize}[nosep]
  \item GD step size $\alpha$: most sensitive; must satisfy $\alpha \leq 2/(L+\mu)$ for convergence.
  \item Polyak step: catastrophic divergence if $f^\star$ is wrong.
  \item Penalty $\lambda$: increasing $\lambda$ improves feasibility but worsens conditioning.
  \item FD perturbation $\delta$: balance truncation and round-off error; optimal $\delta \approx
    \sqrt{\varepsilon_{\mathrm{mach}}}$.
  \end{itemize}

\end{enumerate}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Hessian Regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g          # fallback to gradient direction
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient)}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
