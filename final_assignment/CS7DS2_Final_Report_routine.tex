\begin{abstract}
This report presents a rigorous comparative study of optimisation algorithms across six problem families, evaluated on three benchmark functions: a quadratic linear regression loss (Benchmark~A, $\kappa \approx 1.12$), a non-quadratic loss with sinusoidal perturbation (Benchmark~B, $\kappa \approx 5$--$8$), and the ill-conditioned Rosenbrock function (Benchmark~C, $\kappa \approx 2508$). The key findings are: \textit{(i)}~The Polyak step size achieves the best Rosenbrock convergence ($f = 0.009$) when $f^{\star}$ is known exactly, but diverges on Benchmarks A and B due to misspecified $f^{\star}$, demonstrating its sensitivity as a convergence oracle; \textit{(ii)}~Nesterov acceleration achieves $O(1/k^2)$ convergence, outperforming GD ($f = 0.479$ vs $3.388$ on Rosenbrock after 150 iterations) with a 7$\times$ observed improvement; the theoretical $\sqrt{\kappa} \approx 50$-fold speedup is only approached asymptotically (150 iterations is pre-asymptotic, and $\alpha = 0.0007$ is 70\% of the optimal $\alpha^{\star} = 1/L \approx 0.001$); \textit{(iii)}~Newton's method converges in one iteration on the quadratic benchmark (exact global model) and achieves $5\times$ better objective than GD on Rosenbrock in one-quarter the iteration budget; \textit{(iv)}~Finite difference approximation with $\delta = 0.05$ (near the truncation-dominated regime) nearly matches exact gradient descent, while $\delta = 0.8$ severely degrades convergence; Nesterov random search incurs a $d$-fold oracle gap; \textit{(v)}~All constrained methods converge to the same optimal point because the constraint $x_1 \geq 0.5$ is inactive at the unconstrained minimum ($x_1^{\star} = 0.582 > 0.5$), with KKT multiplier $\mu^{\star} = 0$; \textit{(vi)}~Frank--Wolfe's fixed-step variant shows the characteristic $O(1/k)$ suboptimality and vertex oscillation; a decaying schedule $\gamma_k = 2/(k+2)$ provides formal convergence guarantees. All results are reproducible via {\tt np.random.seed(42)}.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation underpins virtually every modern machine learning and data analysis pipeline. The choice of optimiser determines not only convergence speed but also robustness to hyperparameter settings, computational cost, and the ability to handle constraints. This report systematically evaluates representative algorithms from six major families on three benchmark functions of increasing difficulty.

\textbf{Scope and course mapping.} Questions 1--2 examine first-order gradient-based methods for unconstrained smooth optimisation, corresponding to weeks 2--4 of the course (gradient descent, Polyak/Adagrad/RMSprop, Heavy Ball, Nesterov, Adam). Question~3 investigates second-order (Newton) methods that exploit curvature information (week 6). Question~4 covers derivative-free approaches when gradient computation is impossible or prohibitively expensive (weeks 8a--8b). Questions 5--6 address constrained optimisation via projection, penalisation, and the Frank--Wolfe conditional gradient method (week 9a--10).

\textbf{Evaluation metrics.} The primary metric is the final objective value $f(x_k)$ after a fixed iteration budget, plotted on a logarithmic scale. Secondary metrics include convergence trajectories in the parameter space (contour plots), effective step-size evolution, and update magnitude norms. Constraint violation (maximum infeasibility) is tracked for Questions 5 and 6.

\textbf{Reproducibility.} All experiments use {\tt numpy} with seed 42. Figures are saved to {\tt figures/} and referenced throughout this report.

\section{Benchmark Problems and Experimental Setup}

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = {\theta^{\star}}^{\!\top} x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^{\top} x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2}\theta^{\top} H \theta - b^{\top}\theta + c,
\end{equation}
where $H = \frac{1}{m}X^{\top}X$, $b = \frac{1}{m}X^{\top}y$, and $c = \frac{1}{2m}\|y\|^2$. The gradient and Hessian are:
\begin{equation}
\nabla J(\theta) = \frac{1}{m}X^{\top}(X\theta - y) = H\theta - b, \qquad \nabla^2 J(\theta) = H \quad (\text{constant}).
\end{equation}
The Hessian eigenvalues are $\lambda_{\min}(H) \approx 0.925$, $\lambda_{\max}(H) \approx 1.033$, giving condition number $\kappa(H) \approx 1.12$. This near-perfect conditioning means all gradient-based methods converge rapidly. The OLS (exact) minimiser is $\hat{\theta} \approx (3.028, 4.017)^{\top}$ with $J^{\star} \approx 0.4826$ (noise floor, non-zero due to $\varepsilon^{(i)}$). Starting point: $\theta_0 = [0,\, 0]^{\top}$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
\label{eq:benchB}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are:
\begin{equation}
\nabla f = \begin{bmatrix}2(x_1 - 1) + \cos(x_1)\\ 10(x_2 - 2)\end{bmatrix}, \qquad
\nabla^2 f = \begin{bmatrix}2 - \sin(x_1) & 0\\ 0 & 10\end{bmatrix}.
\end{equation}
The Hessian eigenvalues lie in $[2 - 1,\; 10] = [1, 10]$, giving condition number $\kappa \approx 5$--$8$ (varying with $x_1$). The unique minimiser satisfies $2(x_1^{\star} - 1) + \cos(x_1^{\star}) = 0$, $x_2^{\star} = 2$, yielding $x^{\star} \approx (0.582, 2.000)^{\top}$ and $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1,\, 4]^{\top}$.

\textbf{Strong convexity verification.} Since $|\sin(x_1)| \leq 1$ for all $x_1 \in \mathbb{R}$, the Hessian satisfies $H_{11}(x) = 2 - \sin(x_1) \geq 2 - 1 = 1 > 0$ everywhere. Combined with $H_{22} = 10 > 0$ and the diagonal structure, $\nabla^2 f(x) \succeq I$ globally. Therefore $f$ is $\mu = 1$-strongly convex and $L = 10$-smooth \emph{everywhere}, making $\kappa = L/\mu = 10$ the global condition number for this benchmark (the local variation $\kappa \approx 5$--$8$ near $x^{\star}$ reflects that $H_{11}(x^{\star}) = 2-\sin(0.582) \approx 1.45 > 1$). This global strong convexity guarantees that all convergence bounds stated in Sections~\ref{sec:q1}--\ref{sec:q2} apply from \emph{any} starting point, not just locally near $x^{\star}$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
\label{eq:benchC}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The gradient is:
\begin{equation}
\nabla f = \begin{bmatrix}-2(1-x_1) - 400x_1(x_2-x_1^2)\\ 200(x_2-x_1^2)\end{bmatrix},
\end{equation}
and the Hessian is $\nabla^2 f = \begin{bmatrix}2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200\end{bmatrix}$.
At the global minimum $(1,1)$, $\nabla^2 f = \begin{bmatrix}802 & -400 \\ -400 & 200\end{bmatrix}$ with $\operatorname{tr} = 1002$, $\det = 802 \times 200 - 400^2 = 400$, giving eigenvalues $\lambda_{1,2} = \frac{1002 \pm \sqrt{1002^2 - 4 \times 400}}{2} = \frac{1002 \pm \sqrt{1\,002\,404}}{2} \approx \frac{1002 \pm 1001.2}{2}$, so $\lambda_1 \approx 0.40$ and $\lambda_2 \approx 1001.6$, giving $\kappa \approx 2508$. Importantly, the condition number \emph{varies along the trajectory}: near the origin $(0,0)$, $\nabla^2 f = \text{diag}(2, 200)$ giving $\kappa = 100$, while at the valley midpoint $(0.5, 0.25)$, $\kappa \approx 401$. The problem becomes harder as we approach the optimum. Geometrically, the valley floor corresponds to $x_2 = x_1^2$: along this curve, the objective is $(1-x_1)^2$, which only decreases as $x_1 \to 1$. Progress requires tiny steps because the valley walls are steep (curvature $\approx 200$--$1200$) while the floor is nearly flat (curvature $\approx 0.4$). This progressive ill-conditioning explains why GD with $\alpha = 0.0012$ barely advances in 120 iterations. Starting point: $x_0 = [-1,\, 1]^{\top}$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent (GD) baseline across all three benchmarks for 120 iterations. The key distinction from fixed-step GD is that each method adjusts $\alpha_k$ dynamically based on gradient history, aiming to remove the need for manual tuning and improve convergence on anisotropic landscapes.

\textbf{Gradient Descent baseline.} Vanilla GD uses $x_{k+1} = x_k - \alpha \nabla f(x_k)$ with constant $\alpha$. For a $\mu$-strongly convex, $L$-smooth function, the step $\alpha^{\star} = 2/(L + \mu)$ minimises the contraction factor: the GD update can be viewed as $x_{k+1} - x^{\star} = (I - \alpha H)(x_k - x^{\star})$ (for quadratic $f$), so $\|I - \alpha H\| = \max_i |1 - \alpha \lambda_i(H)|$ is minimised when $\alpha$ balances the two extremes $|1 - \alpha\mu|$ and $|1 - \alpha L|$, giving $\alpha^{\star} = 2/(L+\mu)$ and optimal rate $(\kappa-1)/(\kappa+1)$. The iterate satisfies:
\begin{equation}
\label{eq:gd_rate}
\|x_{k+1} - x^{\star}\| \leq \frac{\kappa - 1}{\kappa + 1}\,\|x_k - x^{\star}\|, \qquad \kappa = L/\mu,
\end{equation}
equivalently $f(x_k) - f^{\star} \leq \kappa\left(\frac{\kappa-1}{\kappa+1}\right)^{2k}(f(x_0) - f^{\star})$. For Benchmark~A, $\mu \approx 0.925$, $L \approx 1.033$, giving $\alpha^{\star} \approx 1.02$ and convergence rate $(\kappa-1)/(\kappa+1) \approx 0.055$ per iterate on $\|x_k - x^{\star}\|$. However, the implementation uses $\alpha = 0.08 \ll \alpha^{\star}$, giving per-iterate contraction $\rho = \max(|1-0.08\mu|, |1-0.08L|) \approx 0.926$ on $\|x_k - x^{\star}\|$, or $\rho^2 \approx 0.857$ on $(f(x_k) - f^{\star})$. To reduce the relative gap by $10^{-3}$: $0.857^k \leq 10^{-3}$ gives $k \geq 44$ iterations, consistent with the observed $\sim$40 iterations to reach the noise floor at $J^{\star} \approx 0.4826$. For Benchmark~C, $\kappa \approx 2508$, giving $\alpha^{\star} \approx 2/(0.40+1001.6) \approx 0.002$ and rate $\approx 0.9992$, so GD needs $O(10^4)$ iterations to converge.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, estimated optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Adaptive step size from optimality gap}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate cumulative squared gradient}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Velocity accumulation}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\paragraph{Key design differences.} Adagrad~\cite{duchi2011} divides by $\sqrt{\sum_{t=0}^k g_{t,i}^2}$ for each coordinate $i$, giving large steps where gradients have historically been small and small steps where they have been large. This automatically rescales coordinates, effectively implementing a \emph{diagonal preconditioner}: with the preconditioned step $x_{k+1} = x_k - D_k^{-1} \nabla f(x_k)$ where $D_k = \operatorname{diag}(\sqrt{G_k} + \varepsilon)$, the effective Hessian approximation is $D_k$ rather than $I$. An ideal preconditioner would be $D_k = H^{1/2}$ (which Newton's method implicitly uses), but Adagrad's data-driven approximation is available without computing $H$. The downside is that the accumulator $G_k$ only grows, causing the effective step to decay to zero. RMSprop corrects this with exponential forgetting (decay $\beta$), making it suitable for non-stationary problems.

Heavy Ball (Polyak momentum)~\cite{polyak1964} adds a velocity term that accumulates past gradients. For a quadratic $f(x) = \frac{1}{2}x^T H x$ with optimal parameters $(\alpha^*, \beta^*)$, Heavy Ball achieves the same $O(\sqrt{\kappa})$ iteration complexity as Nesterov --- both improve upon GD's $O(\kappa)$ complexity. The optimal parameters for a quadratic with eigenvalues in $[\mu, L]$ are:
\begin{equation}
\alpha^* = \frac{4}{(\sqrt{\mu}+\sqrt{L})^2}, \qquad \beta^* = \left(\frac{\sqrt{L}-\sqrt{\mu}}{\sqrt{L}+\sqrt{\mu}}\right)^2.
\end{equation}
For Benchmark C ($\mu \approx 0.40$, $L \approx 1001.6$): $\alpha^* = 4/(0.632+31.65)^2 \approx 0.0038$ and $\beta^* \approx (31.02/32.28)^2 \approx 0.924$. However, the implementation uses $\alpha = 0.0008 = 0.21\,\alpha^*$ and $\beta = 0.86 \approx \beta^*$. The 5$\times$ underestimate of $\alpha$ is the main reason Heavy Ball achieves $f = 1.40$ rather than the theoretically possible near-Nesterov performance. With $\alpha \approx \alpha^*$, Heavy Ball would converge significantly faster (approaching the $O(\sqrt{\kappa})$ rate). In practice, $\alpha^*$ requires accurate knowledge of $L$, which for Rosenbrock is not globally constant. However, Heavy Ball lacks Nesterov's convergence guarantees for non-quadratic functions, while Nesterov's lookahead provides provable $O(1/k^2)$ convergence (Theorem~\ref{thm:nesterov}).

\paragraph{Key finding: Polyak step size sensitivity.}
The Polyak step size~\cite{polyak1969} can be derived from the optimality condition: if we want $\alpha_k$ such that the one-step descent achieves $f(x_{k+1}) = f^{\star}$ (as if the function were linear), we get $\alpha_k = (f(x_k) - f^{\star})/\|\nabla f(x_k)\|^2$. For a $\mu$-strongly convex function with exact $f^{\star}$, the Polyak step satisfies:
\begin{equation}
f(x_{k+1}) - f^{\star} \leq \left(1 - \frac{\mu}{\|\nabla f(x_k)\|^2/(f(x_k)-f^{\star})}\right)(f(x_k) - f^{\star}),
\end{equation}
and since $\|\nabla f(x_k)\|^2 \leq 2L(f(x_k) - f^{\star})$ (by smoothness), the rate $\leq (1 - \mu/(2L)) = 1 - 1/(2\kappa)$ per step. This matches GD with optimal step. In practice, Polyak achieves faster-than-linear convergence by adapting $\alpha_k$ to the local optimality gap. However, it diverges when $f^{\star}_{\text{specified}} < f^{\star}_{\text{true}}$: if $f^{\star}_{\text{specified}} < f^{\star}_{\text{true}}$, then as $x_k \to x^{\star}$, $\|\nabla f\| \to 0$ while $f(x_k) - f^{\star}_{\text{specified}} \to f^{\star}_{\text{true}} - f^{\star}_{\text{specified}} > 0$, causing $\alpha_k \to \infty$.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest ($f = 0.009$ on Rosenbrock, $375\times$ better than GD). Otherwise, Adagrad and Heavy Ball consistently match or exceed the GD baseline.
\item \textbf{Why RMSprop gives $f = 0.5027$ on Benchmark A (vs.\ others at $0.4826$):} RMSprop's exponential moving average satisfies $v_k \to v_{\infty} = \mathbb{E}[g^2] / (1-\beta) > 0$ as $k \to \infty$ (since gradients don't vanish exactly when $f^{\star} > 0$, i.e., the noise floor is non-zero). This maintains a non-zero effective learning rate $\alpha_0 / \sqrt{v_\infty}$ near the optimum. The iterate then oscillates in a ball of radius $\approx \alpha_0 / (\sqrt{v_\infty} \cdot \mu)$ around $\theta^{\star}$, yielding a final loss above the noise floor by approximately $\frac{1}{2}\mu \cdot (\alpha_0/(\sqrt{v_\infty}\mu))^2 = \alpha_0^2/(2\mu v_\infty)$. By contrast, Adagrad's cumulative sum $G_k = \sum_{t=0}^k g_t^2 \to \infty$ forces the effective step $\alpha_0/\sqrt{G_k} \to 0$, allowing convergence to the exact minimum. This is the fundamental difference: Adagrad's \emph{monotone} (ever-growing) accumulator guarantees eventual convergence while RMSprop's \emph{exponential forgetting} enables continued progress but not exact minimisation.
\item \textbf{Smoothness vs.\ oscillation:} RMSprop produces the smoothest convergence curves due to exponential averaging but requires careful choice of $\alpha_0$. Heavy Ball shows characteristic overshoot followed by damped oscillation. On Rosenbrock, Heavy Ball's momentum ($f = 1.40$) outperforms GD ($f = 3.51$) by building up velocity along the persistent valley-floor direction.
\item \textbf{Stability:} GD is most stable but slowest on ill-conditioned problems. Polyak is provably unstable under $f^{\star}$ misspecification. Adagrad's monotonically decreasing step guarantees convergence but can cause premature stalling on deep neural networks where gradients become very small.
\item \textbf{Heavy Ball vs.\ Nesterov:} On Rosenbrock (Q2), Nesterov ($f = 0.479$) outperforms Heavy Ball ($f = 1.40$) significantly. This is consistent with theory: Nesterov's lookahead provides corrective guidance that prevents momentum overshoot in the curved valley. Heavy Ball, despite its optimal quadratic convergence properties, lacks this correction for nonlinear functions.
\item \textbf{Practical implication:} RMSprop and Adagrad are preferable in practice since exact $f^{\star}$ is rarely known. The Polyak step requires an oracle for $f^{\star}$, limiting it to benchmark functions or problems where a lower bound is available from duality theory.
\end{itemize}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\; \beta_{\max}\right)$ \Comment{Increasing momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead/extrapolation point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Update velocity at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key innovation of Nesterov acceleration~\cite{nesterov1983} over Heavy Ball is the \emph{lookahead}: the gradient is evaluated at the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$. This ``look before you leap'' correction allows the method to anticipate and partially cancel the overshooting caused by momentum. The schedule $\beta_k = (k-1)/(k+2)$ (increasing to $\approx 1$) corresponds to Nesterov's optimal momentum sequence, achieving the provably optimal convergence rate for first-order methods on smooth convex functions:

\begin{theorem}[Nesterov, 1983]
\label{thm:nesterov}
Let $f$ be convex and $L$-smooth. With step $\alpha = 1/L$ and $\beta_k = (k-1)/(k+2)$, the Nesterov method satisfies:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2} = O\!\left(\frac{1}{k^2}\right).
\end{equation}
This is optimal: no first-order method can achieve $O(1/k^{2+\epsilon})$ on all convex smooth functions.
\end{theorem}

\begin{remark}[Nesterov momentum and Chebyshev polynomials]
The Nesterov schedule $\beta_k = (k-1)/(k+2)$ has a deep connection to optimal polynomial approximation. For any first-order method applied to a quadratic $f(x) = \frac{1}{2}x^{\top}Hx$, the error satisfies $x_k - x^{\star} = p_k(H)(x_0 - x^{\star})$ where $p_k$ is a degree-$k$ polynomial with $p_k(0) = 1$. The optimal worst-case reduction is achieved by the \emph{Chebyshev polynomial} $T_k$ scaled to $[\mu, L]$:
\begin{equation}
\min_{p_k: p_k(0)=1} \max_{\lambda \in [\mu,L]} |p_k(\lambda)| = \frac{1}{T_k\!\left(\frac{L+\mu}{L-\mu}\right)}, \quad T_k(t) = \cosh(k \cosh^{-1} t),
\end{equation}
which gives the bound $\|x_k - x^{\star}\| \leq 2\bigl(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\bigr)^k \|x_0 - x^{\star}\|$. The Nesterov algorithm implicitly computes this Chebyshev iteration through its recursive momentum, achieving the information-theoretic lower bound for first-order methods on smooth strongly convex functions.
\end{remark}

\noindent This $O(1/k^2)$ rate improves upon GD's $O(1/k)$ rate on convex functions (and $O(\rho^k)$ linear rate on strongly convex functions, which Nesterov also improves by replacing $\rho$ with $\sqrt{\rho}$). To reach precision $f(x_k) - f^{\star} \leq \varepsilon$: GD needs $k = O(\kappa \log(1/\varepsilon))$ iterations and Nesterov needs $k = O(\sqrt{\kappa} \log(1/\varepsilon))$ iterations. For Benchmark C ($\kappa \approx 2508$), this difference is $\sqrt{2508} \approx 50$: Nesterov needs $50\times$ fewer iterations than GD to achieve the same accuracy.

\paragraph{Why 7$\times$ observed vs 50$\times$ theoretical on Benchmark C.}
Two compounding factors explain why the experimental speedup ($7\times$) falls far short of the asymptotic prediction ($50\times$):
\begin{enumerate}[nosep]
\item \textbf{Pre-asymptotic regime}: The $O(1/k^2)$ vs $O(1/k)$ rate separation is a large-$k$ result. At $k = 150$, both methods are still in a transient regime dominated by the initial geometry rather than the asymptotic convergence law. To observe the full $50\times$ speedup, one would need $k \approx \sqrt{\kappa} \cdot \log(1/\varepsilon) \approx 50 \cdot \log(1/\varepsilon)$ iterations, which for $\varepsilon = 10^{-3}$ is roughly $\sim 345$ iterations.
\item \textbf{Suboptimal step size}: Theorem~\ref{thm:nesterov} requires $\alpha = 1/L$ where $L = \lambda_{\max}(\nabla^2 f)$. For Rosenbrock near $x_0 = (-1, 1)^{\top}$, $H_{11} = 2 + 1200 \times 1 - 400 \times 1 = 802$ and the Hessian eigenvalues span $[L_{\min}, L_{\max}]$ where $L_{\max} \approx 1001$ (as in Table~\ref{tab:q1_gd_rates}), so $\alpha^{\star} = 1/L \approx 0.001$. The implementation uses $\alpha = 0.0007 = 0.70\,\alpha^{\star}$, a 30\% underestimate. This suboptimal step reduces per-step progress and effectively scales the convergence constant in Theorem~\ref{thm:nesterov}.
\end{enumerate}
\noindent Together, these factors explain the 7$\times$ vs 50$\times$ discrepancy without contradicting the theory, which is an asymptotic result with optimal hyperparameters. This highlights the practical importance of step-size tuning for momentum methods.

\paragraph{Nesterov restarts.} A practical technique for accelerating Nesterov on non-convex functions (like Rosenbrock outside the strongly convex neighbourhood) is \emph{gradient restarting}: whenever $\nabla f(\tilde{x}_k)^{\top} (x_k - x_{k-1}) > 0$ (the gradient at the lookahead disagrees with the momentum direction, indicating overshoot), reset the momentum to zero ($z \gets \mathbf{0}$, $\beta_k \gets 0$). Restarts prevent momentum from accumulating in the wrong direction on curved manifolds and can provide superlinear convergence in practice. However, the code does not implement restarts (it uses a fixed $\beta_{\max}$ cap instead), which explains some of the pre-asymptotic underperformance on Rosenbrock.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (exponential mean of gradients)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (exponential mean of $g^2$)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction (important for early iterations)}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam~\cite{kingma2015} combines Nesterov-style momentum (via exponentially averaged $m_t$) with RMSprop-style per-coordinate adaptive scaling (via $v_t$). The bias correction derives from the following: since $m_0 = 0$, expanding the recursive definition gives $m_t = (1-\beta_1)\sum_{j=1}^t \beta_1^{t-j} g_j$. Taking expectations (assuming $\mathbb{E}[g_j] = g$ for all $j$):
\begin{equation}
\mathbb{E}[m_t] = (1 - \beta_1^t)\, g, \quad \text{so} \quad \hat{m}_t = \frac{m_t}{1-\beta_1^t} \implies \mathbb{E}[\hat{m}_t] = g \;\; \text{(unbiased)}.
\end{equation}
Similarly for the second moment: $\mathbb{E}[\hat{v}_t] = \mathbb{E}[g^2]$. This bias correction is critical in early iterations ($t = 1$: $(1 - \beta_1^1) = 1 - \beta_1 = 0.18$--$0.20 \ll 1$ without correction) but becomes negligible for large $t$ as $\beta_1^t \to 0$. With $\beta_1 = 0.80$--$0.82$ and $\beta_2 = 0.999$, Adam provides aggressive momentum while maintaining conservative scaling.

\paragraph{Adam: non-convergence and the AMSGrad fix.} Reddi et al.\ (2018)~\cite{reddi2018} showed that Adam can \emph{fail to converge} even on simple convex functions when $\beta_2$ is close to 1. The issue arises because the exponential moving average in $v_t$ can underestimate the true second moment for infrequently updated coordinates, allowing the effective step $\alpha/\sqrt{\hat{v}_t}$ to remain large even after many iterations when the gradient is small. Their AMSGrad variant fixes this by replacing $\hat{v}_t$ with $\hat{v}_t^{\max} = \max(\hat{v}_{t-1}^{\max}, \hat{v}_t)$, ensuring a non-decreasing denominator. In the deterministic experiments here, this non-convergence issue is not manifested because the benchmark functions are smooth and well-conditioned; Adam converges reliably. However, in stochastic settings with highly non-stationary gradients, the theoretical gap between Adam and convergence guarantees matters.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled at every epoch. The gradient estimate for batch $\mathcal{B}$ of size $b$ is:
\begin{equation}
\hat{g}(\theta) = \frac{1}{b}\sum_{i \in \mathcal{B}} x^{(i)}\!\left(\theta^{\top}x^{(i)} - y^{(i)}\right) = \frac{1}{b}X_{\mathcal{B}}^{\top}(X_{\mathcal{B}}\theta - y_{\mathcal{B}}).
\end{equation}

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$ with $m$ samples, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\sigma$
    \For{$i = 0, b, 2b, \ldots, m-b$}
        \State $\mathcal{B} \gets \{\sigma(i+1), \ldots, \sigma(i+b)\}$
        \State $g \gets \dfrac{1}{b} X_{\mathcal{B}}^{\top}(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

With $m = 1000$ samples, batch $b = 5$ yields $1000/5 = 200$ gradient steps per epoch, while $b = 40$ yields $25$ steps per epoch. The stochastic gradient variance is $\operatorname{Var}[\hat{g}] = O(\sigma^2 / b)$, where $\sigma^2$ is the per-sample gradient variance. The key trade-off is:

\begin{itemize}[nosep]
\item \textbf{Smaller batch ($b=5$)}: $200 \times 1 = 200$ cheap updates/epoch vs.\ $25 \times 8 = 200$ expensive comparisons --- the same computational work but many more, noisier descent steps. Near the optimum, the $O(\sigma^2/b)$ variance dominates, causing persistent oscillation around $\theta^{\star}$.
\item \textbf{Larger batch ($b=40$)}: lower variance ($\sigma^2/40$ vs.\ $\sigma^2/5 = 8\times$ higher), smoother convergence per epoch, but fewer updates. For this well-conditioned problem ($\kappa \approx 1.12$), the per-step progress fully compensates for fewer steps.
\item \textbf{Ultimate noise floor}: both methods converge to the same $J^{\star} \approx 0.4826$ asymptotically, but the oscillation amplitude near the optimum is $O(\alpha \sigma^2/b)$. The oscillation for $b=5$ is $\approx 8\times$ larger than for $b=40$.
\end{itemize}

\paragraph{Polyak--Ruppert averaging.} When a constant learning rate $\alpha$ is used with SGD, the iterate converges not to $\theta^{\star}$ but oscillates in an $O(\alpha \sigma^2 / (\mu b))$-ball around it. The classical remedy is \emph{Polyak--Ruppert (iterate) averaging}: instead of the final iterate $\theta_T$, return $\bar{\theta}_T = \frac{1}{T}\sum_{k=1}^T \theta_k$. This achieves the optimal $O(\sigma^2 / (\mu b T))$ MSE convergence rate (Polyak \& Ruppert 1992), matching the Cram\'er--Rao lower bound for stochastic approximation. For the well-conditioned Benchmark A ($\mu \approx 0.925$), the averaging benefit is small; for ill-conditioned problems with $\mu \ll L$, averaging can dramatically reduce the final error. An alternative is a decaying schedule $\alpha_k = \alpha_0 / \sqrt{k}$, which achieves the same $O(1/\sqrt{T})$ rate without requiring averaging but requires careful choice of $\alpha_0$.

With $b = 40$, only 25 updates per epoch result in smoother but slower convergence. \paragraph{Variance reduction.} A fundamental limitation of SGD is that the stochastic gradient variance $\operatorname{Var}[\hat{g}] = O(\sigma^2/b)$ cannot be driven to zero even as $k \to \infty$, unless the learning rate decays to zero (sacrificing convergence speed). \emph{Variance reduction methods} (SVRG, SAG/SAGA) resolve this: by periodically computing a full gradient $\nabla J(\theta_s)$ at a snapshot $\theta_s$ and using the control variate $\hat{g}_k = g_k - \nabla f_i(\theta_s) + \nabla J(\theta_s)$, they achieve zero variance near the optimum. SVRG achieves linear convergence $O(\rho^k)$ (same as GD) even with $b=1$ stochastic gradients, requiring only one full gradient per $O(m)$ stochastic steps --- optimal for finite-sum problems. While not implemented here, this theoretical connection motivates the use of large-batch training in modern deep learning (reducing variance without full gradient computation).

\subsection{SGD with Increased Noise}

The experiment is repeated with output noise scaled by $\sigma = 6$ (vs.\ original $\sigma = 1$), using $y_{\rm noisy} = X\theta^{\star} + 6\varepsilon$ where $\varepsilon$ is the same noise realisation. The irreducible noise floor (minimum achievable loss at the OLS solution) is:
\begin{equation}
J^{\star}(\sigma) = \frac{1}{2m}\sum_{i=1}^m (\sigma\varepsilon_i)^2 = \sigma^2 \cdot J^{\star}(\sigma=1), \qquad J^{\star}(\sigma=6) \approx 36 \times 0.4826 \approx 17.4.
\end{equation}
The noise floor scales as $\sigma^2$ because the minimum value of $J$ is the variance of the irreducible residuals $\varepsilon_i$. Crucially, the Hessian $H = X^{\top}X/m$ and hence the GD convergence rate are unchanged --- only the convergence target shifts upward.

\subsection{Local Approximations of $g(x) = x^4$}

The Taylor expansion of $g(x) = x^4$ around $x_0 = 0.25$ gives:
\begin{align}
g'(x) &= 4x^3, \quad g''(x) = 12x^2. \notag\\
\text{First-order:}\quad g(x) &\approx g(x_0) + g'(x_0)(x - x_0) = (0.25)^4 + 4(0.25)^3(x - 0.25) \notag\\
&= 0.0039 + 0.0625(x - 0.25). \label{eq:q3_first} \\
\text{Second-order:}\quad g(x) &\approx g(x_0) + g'(x_0)(x-x_0) + \tfrac{1}{2}g''(x_0)(x-x_0)^2 \notag\\
&= 0.0039 + 0.0625(x-0.25) + \tfrac{1}{2}(0.75)(x-0.25)^2 \notag\\
&= 0.0039 + 0.0625(x-0.25) + 0.375(x-0.25)^2. \label{eq:q3_second}
\end{align}

The Newton update minimises the second-order model~\eqref{eq:q3_second}, setting its derivative to zero:
\begin{equation}
0 = g'(x_0) + g''(x_0)(x - x_0) \implies x_{\text{Newton}} = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{4(0.25)^3}{12(0.25)^2} = 0.25 - \frac{0.25}{3} = \frac{1}{6} \approx 0.1667.
\end{equation}

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}

\paragraph{Newton on $g(x) = x^4$: linear convergence due to degenerate Hessian.}
Applying Newton's method repeatedly to $g(x) = x^4$ from $x_0 = 0.25$:
\begin{equation}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)} = x_k - \frac{4x_k^3}{12x_k^2} = x_k - \frac{x_k}{3} = \frac{2}{3}x_k.
\end{equation}
This is exact linear convergence at rate $2/3$: $x_k = (2/3)^k \cdot x_0$, so $x_k \to 0$ but \emph{not} quadratically. This is a degenerate case where the standard quadratic convergence result does \emph{not} apply: $g''(x^{\star}) = g''(0) = 0$, so the Hessian is singular at the optimum. The quadratic convergence theorem requires $\nabla^2 f(x^{\star})$ to be nonsingular (positive definite).

\subsection{Newton's Method on Benchmark Functions}

\begin{algorithm}[H]
\caption{Damped Newton's Method}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, regularisation $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation ensures $H_k \succ 0$}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction via linear system solve}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{$\alpha < 1$ for damping}
\EndFor
\end{algorithmic}
\end{algorithm}

\paragraph{Why does Newton converge in one step on a quadratic?}
For $J(\theta) = \frac{1}{2}\theta^{\top}H\theta - b^{\top}\theta + c$ with constant Hessian $H$, the Newton update with $\alpha = 1$ gives:
\begin{equation}
\theta_{k+1} = \theta_k - H^{-1}\nabla J(\theta_k) = \theta_k - H^{-1}(H\theta_k - b) = H^{-1}b = \theta^{\star}.
\end{equation}
Thus, \emph{one Newton step reaches the exact minimiser from any starting point}, because the second-order Taylor model is exact globally for a quadratic. Geometrically, Newton maps the starting point directly to the bottom of the bowl in one operation, regardless of the bowl's eccentricity.

\paragraph{Why does Newton require damping on Rosenbrock?}
For a step with $\alpha = 1$ (full Newton step), the update direction is $p_k = (\nabla^2 f(x_k))^{-1}\nabla f(x_k)$. On Rosenbrock, $\nabla^2 f$ changes dramatically along the trajectory: $H_{11} = 2 + 1200x_1^2 - 400x_2$ ranges from $\approx 1$ in the valley to $\approx 1202$ near the starting point $x_0 = [-1,1]^{\top}$. A full Newton step from far from the minimum uses curvature information that is only valid locally, causing the step to overshoot the valley or diverge. The damping factor $\alpha = 0.22$ (chosen empirically) reduces the step size to remain within the region where the local quadratic model is a good approximation. An alternative is \emph{line search}: at each iteration, find $\alpha_k$ satisfying Wolfe conditions to ensure sufficient decrease.

\begin{theorem}[Quadratic Convergence of Newton's Method]
\label{thm:newton_quad}
Let $f$ be twice continuously differentiable with Lipschitz continuous Hessian: $\|\nabla^2 f(x) - \nabla^2 f(y)\| \leq M\|x-y\|$ for some $M > 0$. If $\nabla^2 f(x^{\star}) \succ 0$ (positive definite at the minimiser), then there exists $\delta > 0$ such that for any $x_0$ with $\|x_0 - x^{\star}\| < \delta$, Newton's method with step $\alpha = 1$ satisfies:
\begin{equation}
\|x_{k+1} - x^{\star}\| \leq \frac{M}{2\mu}\|x_k - x^{\star}\|^2,
\end{equation}
where $\mu = \lambda_{\min}(\nabla^2 f(x^{\star})) > 0$. This is \emph{quadratic convergence}: the number of correct decimal places doubles each iteration.
\end{theorem}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian regularisation $\lambda = 10^{-8}$.

\paragraph{Local vs.\ global convergence.} Theorem~\ref{thm:newton_quad} guarantees \emph{local} quadratic convergence: the iterate must already be within some radius $\delta$ of $x^{\star}$ for the theorem to apply. From a distant starting point (such as $x_0 = [-1,1]^{\top}$ for Benchmark C), the full Newton step ($\alpha=1$) may diverge or converge to a wrong point, because the second-order model is only locally valid. Damped Newton ($\alpha < 1$) or trust-region Newton provide global convergence: by ensuring sufficient decrease $f(x_{k+1}) < f(x_k)$ at each step, the iterate first descends to a neighbourhood of $x^{\star}$ (Phase 1), then switches to fast local convergence (Phase 2). For Benchmark A (quadratic), Phase 1 is trivially one step since the model is globally exact; for Benchmark C, Phase 1 requires the full 20-iteration budget with $\alpha = 0.22$.

\paragraph{When Newton fails: saddle points and non-convex loss.}
On non-convex functions, Newton's method has a critical failure mode: it converges to \emph{saddle points} as readily as to minima. At a saddle point $x_s$ where $\nabla f(x_s) = 0$ but $\nabla^2 f(x_s)$ is indefinite (some negative eigenvalues), the Newton step $p = H^{-1} g$ has $\|p\| \to 0$ as $g \to 0$ --- the same as at a minimum. With Tikhonov regularisation $\lambda I$, the step at a saddle is $p = (H + \lambda I)^{-1} g$, which still vanishes as $g \to 0$. In contrast, gradient descent provably avoids saddle points: a random perturbation $x \to x + \varepsilon u$ ($u$ uniform on the sphere) moves the iterate off the saddle's flat manifold, after which GD descends along the negative curvature direction. For the 2D benchmarks here, Newton is safe since all benchmarks are designed to have unique minima.

\paragraph{Practical Newton variants.} The $O(d^3)$ cost of the linear solve $H_k p_k = g_k$ is the main barrier to Newton's scalability. \emph{Newton-CG} (truncated Newton) uses conjugate gradient iterations to solve the Newton system approximately: given $H_k p \approx -g_k$ is solved to tolerance $\varepsilon_k = O(\|g_k\|^{1/2})$ (superlinear local convergence is preserved). This reduces per-iteration cost to $O(d^2)$ at most, with early termination near $x_0$ when the CG convergence is slow (indicating poor Hessian conditioning). For large $d$, \emph{L-BFGS} stores only the $m$ most recent gradient difference pairs $\{(s_i, y_i)\}_{i=k-m}^k$ where $s_i = x_{i+1} - x_i$ and $y_i = g_{i+1} - g_i$, satisfying the secant condition $H_k s_{k-1} = y_{k-1}$, with direction computed in $O(md)$ via the two-loop recursion. L-BFGS is the standard method for $d \geq 10^4$. For non-linear least squares specifically, the \emph{Gauss--Newton} approximation replaces the Hessian with $J^{\top}J$ (where $J$ is the Jacobian), ignoring second-order residual terms; this gives a positive-semidefinite approximation that avoids the saddle-point issue while retaining super-linear convergence near the minimum.

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference (FD) approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
\end{equation}
By Taylor's theorem:
\begin{equation}
\hat{g}_i = \frac{\partial f}{\partial x_i}(x) + \underbrace{\frac{\delta}{2}\frac{\partial^2 f}{\partial x_i^2}(x) + O(\delta^2)}_{\text{truncation error}} + \underbrace{O\!\left(\frac{\varepsilon_{\rm mach}}{\delta}\right)}_{\text{round-off error}}.
\end{equation}
The total error $\|\hat{g} - \nabla f\| = O(\delta) + O(\varepsilon_{\rm mach}/\delta)$ is minimised at $\delta^{\star} \approx \sqrt{\varepsilon_{\rm mach}} \approx 10^{-8}$ for IEEE 64-bit arithmetic. For $\delta = 0.05$, the truncation error is moderate, yielding accurate gradients. For $\delta = 0.8$, the truncation error is large, severely degrading gradient quality.

\paragraph{Centered vs.\ forward differences.} The \emph{centered} finite-difference approximation uses both $f(x + \delta e_i)$ and $f(x - \delta e_i)$:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x - \delta e_i)}{2\delta} = \frac{\partial f}{\partial x_i}(x) + \underbrace{\frac{\delta^2}{6}\frac{\partial^3 f}{\partial x_i^3}(x) + O(\delta^4)}_{\text{truncation error}} + O\!\left(\frac{\varepsilon_{\rm mach}}{\delta}\right).
\end{equation}
The truncation error is $O(\delta^2)$ rather than $O(\delta)$, allowing a larger optimal $\delta^{\star} \approx \varepsilon_{\rm mach}^{1/3} \approx 10^{-5.3}$ and lower minimum error $\approx \varepsilon_{\rm mach}^{2/3} \approx 10^{-10.7}$. The cost is $2d$ function evaluations per gradient (vs.\ $d+1$ for forward differences). The code uses forward differences, which is simpler but less accurate. For $\delta = 0.05$, the centered approximation would give error $\approx (0.05)^2 \times M_3/6$ (where $M_3$ is the third derivative magnitude), potentially $\sim 100\times$ smaller than the forward difference error.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Randomised Gradient-Free Method}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method requires only \emph{two} function evaluations per iteration regardless of dimension $d$, making it dimension-independent in cost per step (unlike FD which requires $d+1$ evaluations). The expected value of the gradient estimate is:
\begin{equation}
\mathbb{E}_{u}[\hat{g}_k] = \mathbb{E}_u\!\left[\frac{f(x + \delta u) - f(x)}{\delta} u\right] \approx \mathbb{E}_u\!\left[(\nabla f(x)^{\top} u)\, u\right] = \frac{1}{d}\,\nabla f(x),
\end{equation}
since for $u$ uniformly distributed on the unit sphere, $\mathbb{E}[u u^{\top}] = \frac{1}{d}I$. Thus the estimate is unbiased for $\nabla f$ (up to the $1/d$ scaling factor). However, the \emph{variance} of the estimate is $O(\|\nabla f\|^2)$, comparable to the gradient magnitude itself, meaning the signal-to-noise ratio does not improve with iterations --- unlike FD, which is deterministic given $\delta$. For $d = 2$, the signal from each step is essentially a single noisy directional measurement, requiring many more steps than GD to converge. With $\alpha = 0.025$ and $\delta = 0.08$.

\paragraph{Gaussian smoothing interpretation.} The NRS estimate can be interpreted as the gradient of the Gaussian-smoothed function: $f_\delta(x) = \mathbb{E}_{u \sim \mathcal{N}(0,I)}[f(x + \delta u)]$. The identity $\nabla f_\delta(x) = d \cdot \mathbb{E}_{u}[\hat{g}_k]$ holds (by Stein's lemma), so NRS is actually performing gradient descent on $f_\delta$ rather than $f$. The bias $\|f_\delta - f\| = O(\delta^2)$ is small for small $\delta$. This interpretation connects NRS to zeroth-order optimisation theory and explains why using $\delta = 0.08$ (moderate) rather than $\delta \to 0$ (which would require high-precision function evaluations) is appropriate.

\paragraph{Oracle complexity of zeroth-order methods~\cite{nesterov2013}.} An important insight is that NRS introduces an intrinsic $O(d)$ complexity penalty: since each step only probes one random direction, the effective gradient update is scaled by $1/d$. Formally, for a $\mu$-strongly convex $L$-smooth function, NRS requires $O(d \cdot \kappa / \varepsilon)$ function evaluations to achieve $\mathbb{E}[f(x_k)] - f^{\star} \leq \varepsilon$, compared to $O(\kappa / \varepsilon)$ for gradient descent. This $d$-factor is the \emph{zeroth-order oracle gap}: the price paid for not computing the gradient analytically. Table~\ref{tab:oracle_compare} puts this in perspective:

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm~\cite{nelder1965} maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively deforms it through four operations:

\begin{enumerate}[nosep]
\item \textbf{Reflection} (coefficient $\alpha_r = 1$): move worst vertex $x_w$ through centroid $\bar{x}$ of the other vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x_w)$.
\item \textbf{Expansion} (coefficient $\gamma = 2$): if reflection improved, try further: $x_e = \bar{x} + \gamma(\bar{x} - x_w)$.
\item \textbf{Contraction} (coefficient $\rho = 0.5$): if reflection worsened, contract: $x_c = \bar{x} + \rho(x_r - \bar{x})$ (outside) or $\bar{x} + \rho(x_w - \bar{x})$ (inside).
\item \textbf{Shrink} (coefficient $\sigma = 0.5$): contract all vertices towards the best: $x_i \gets x_1 + \sigma(x_i - x_1)$ for $i = 2, 3$.
\end{enumerate}

Initial simplex: $x_0 = [-1, 1]^{\top}$, step $= 0.35$; iterations $= 160$. In 2D, $n+1 = 3$ vertices. Each iteration uses at most $n = 2$ extra function evaluations (reflection, expansion/contraction), so the total cost is $\leq 320$ function evaluations --- comparable to GD using 160 gradient evaluations.

\begin{remark}
Nelder--Mead converges to the exact Rosenbrock minimum $(1,1)$ ($f = 0$ to machine precision) in 160 iterations despite using zero gradient information. This surprising result is due to the simplex adapting its shape to the curved valley, essentially performing a simplex-based line search along the valley floor. For $d = 2$, Nelder--Mead is known to work well in practice, though it lacks convergence guarantees for $d \geq 3$. The convergence failure for $d \geq 3$ was shown constructively by McKinnon~\cite{mckinnon1998}: there exist smooth strictly convex functions and starting simplices for which Nelder--Mead converges to a non-stationary point. In contrast, for $d = 1$ and $d = 2$, convergence to a stationary point is provable under mild conditions. The practical lesson: Nelder--Mead is a reliable last resort for low-dimensional problems ($d \leq 5$) with expensive, possibly noisy function evaluations.
\end{remark}

\subsection{Problem Setup and KKT Conditions}

Minimise $f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)$ subject to $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2,\, 4.0)^{\top}$.

The constrained problem has the KKT stationarity condition:
\begin{equation}
\nabla f(x^{\star}) - \mu^{\star} e_1 = 0, \quad \mu^{\star}(x_1^{\star} - 0.5) = 0, \quad \mu^{\star} \geq 0,
\end{equation}
where $e_1 = (1, 0)^{\top}$ is the normal to the constraint boundary. The KKT conditions are \emph{necessary} for optimality under a constraint qualification; for a linear constraint $x_1 \geq 0.5$, the \emph{Linear Independence Constraint Qualification} (LICQ) holds trivially (the single constraint gradient $e_1$ is non-zero), so the KKT conditions are both necessary and, combined with convexity of $f$ near $x^{\star}$, sufficient for a constrained local minimum. The unconstrained minimiser of $f$ is $x^{\star}_{\rm unc} \approx (0.582, 2.0)^{\top}$ with $x_1^{\star}_{\rm unc} = 0.582 > 0.5$, so the constraint is \emph{inactive} at the unconstrained solution. Consequently, the constrained minimiser is the same as the unconstrained one: $x^{\star}_{\rm c} = x^{\star}_{\rm unc} \approx (0.582, 2.0)^{\top}$ with $\mu^{\star} = 0$. This makes this problem ideal for testing convergence to the interior of the feasible set.

\paragraph{Second-order sufficient conditions.} To confirm $x^{\star}_{\rm c}$ is a \emph{strict local minimum} of the constrained problem, the second-order KKT conditions require that the Lagrangian Hessian $\nabla^2_{xx} \mathcal{L}(x^{\star}, \mu^{\star}) = \nabla^2 f(x^{\star}) - \mu^{\star} \cdot 0 = \nabla^2 f(x^{\star})$ be positive definite on the tangent space of the active constraints. Since $\mu^{\star} = 0$ (inactive constraint), this reduces to $\nabla^2 f(x^{\star}) \succ 0$, which holds because $\nabla^2 f(x^{\star}) = \text{diag}(2 - \sin(0.582),\; 10) \approx \text{diag}(1.45,\; 10) \succ 0$. Therefore $x^{\star}_{\rm c}$ is a strict local (and by convexity of the quadratic terms, global) minimiser.

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step (may violate constraint)}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{$x_1 \leftarrow \max(0.5,\, x_1)$ for $x_1 \geq 0.5$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Gradient Descent with Quadratic Penalty}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Penalised objective: $F_{\lambda}(x) = f(x) + \lambda\,\max(0,\, 0.5 - x_1)$
    \State Penalised gradient:
    $\nabla F_{\lambda}(x) = \nabla f(x) + \begin{cases} -\lambda\, e_1 & x_1 < 0.5 \\ \mathbf{0} & x_1 \geq 0.5 \end{cases}$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent As $\lambda \to \infty$, the penalty method solution approaches the constrained solution. However, large $\lambda$ creates a stiff (poorly conditioned) penalised problem, requiring smaller step sizes for stability. This is the fundamental limitation of the penalty approach.

\paragraph{PGD convergence rate.} For a $\mu$-strongly convex $L$-smooth $f$ and a closed convex constraint set $\mathcal{X}$, PGD with step $\alpha \in (0, 2/L)$ satisfies the same linear convergence guarantee as unconstrained GD~\cite{boyd2004}:
\begin{equation}
\|x_{k+1} - x^{\star}\| \leq (1 - \alpha\mu)\,\|x_k - x^{\star}\|
\end{equation}
(when $\alpha \leq 1/L$). For Benchmark B with $\mu \approx 1$ and $L \approx 10$, the step $\alpha = 0.08 < 2/10 = 0.2$ is safe, giving rate $\leq 1 - 0.08 \approx 0.92$ per iterate. The projection $\Pi_{\mathcal{X}}(z)_1 = \max(0.5, z_1)$ is non-expansive (does not increase distances to $x^{\star}$), which is why the unconstrained convergence proof carries over to the projected case.

Settings: PGD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ (step $\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\paragraph{Key observation: constraint inactivity.} Since the unconstrained minimiser $x^{\star}_{\rm unc} \approx (0.582, 2.0)^{\top}$ satisfies $x_1^{\star} = 0.582 > 0.5$, the constraint $x_1 \geq 0.5$ is \emph{inactive} at the optimum. Consequently, all five methods converge to the same point: in the neighbourhood of $x^{\star}$, the penalised gradient equals the unconstrained gradient (since $x_1 > 0.5$ there), so the penalty term is irrelevant to the final iterate. The real differentiator is therefore the \emph{path} through infeasible territory and the \emph{speed} of convergence, not the final solution quality.

\paragraph{Projected GD} enforces feasibility as a hard constraint at every iteration through the projection oracle $\Pi_{\mathcal{X}}$. For $\mathcal{X} = \{x : x_1 \geq 0.5\}$, the projection is $\Pi_{\mathcal{X}}(z)_1 = \max(0.5, z_1)$, a trivial $O(1)$ operation. This is the strongest feasibility guarantee possible. For more complex constraint sets (e.g., second-order cone constraints, nuclear norm balls), computing $\Pi_{\mathcal{X}}$ may itself require solving an optimisation problem, making PGD expensive.

\paragraph{Penalty methods} require no projection oracle. The weight $\lambda$ controls feasibility enforcement speed: $\lambda = 0.15$ achieves feasibility at iteration $\approx 13$; $\lambda = 1.8$ and $\lambda = 4.5$ achieve it at iteration $\approx 3$. However, large $\lambda$ creates an ill-conditioned penalised problem --- the effective Lipschitz constant of $F_\lambda$ is $L + \lambda$ in the infeasible region --- requiring a smaller step size $\alpha$ for stability (here, $\alpha = 0.03$ for $\lambda = 4.5$ vs.\ $\alpha = 0.05$ for $\lambda \leq 1.8$), which in turn slows convergence. This explains why $\lambda = 4.5$ converges at a similar speed to $\lambda = 0.15$ despite its stronger feasibility enforcement.

The \emph{augmented Lagrangian} method (Lagrangian + penalty term) addresses this trade-off: by updating the multiplier $\nu \gets \nu + \lambda \cdot \max(0, 0.5 - x_1)$ after each solve, it achieves exact constraint satisfaction at finite $\lambda$ and avoids the ill-conditioning of large $\lambda$.

\paragraph{Contrast: active constraint scenario.}
The results above hold because the constraint $x_1 \geq 0.5$ is \emph{inactive} at the unconstrained minimum ($x_1^{\star} \approx 0.582 > 0.5$). To understand what changes when the constraint is active, consider the modified problem with $x_1 \geq 0.65$ (a tighter bound exceeding $x_1^{\star}$). The constrained minimiser becomes $\tilde{x}^{\star} = (0.65, 2.0)^{\top}$ with $f(\tilde{x}^{\star}) = (0.65-1)^2 + \sin(0.65) \approx 0.730 > 0.7244$. The KKT multiplier satisfies $\mu^{\star} = \nabla_{x_1} f(0.65, 2) = 2(0.65-1) + \cos(0.65) \approx -0.70 + 0.796 = 0.096 > 0$.

For the \emph{linear} penalty $F_\lambda = f + \lambda \max(0, 0.65 - x_1)$ (as implemented in the code), the penalty gradient in the infeasible region ($x_1 < 0.65$) is $\nabla_{x_1} F_\lambda = \nabla_{x_1} f - \lambda$. The critical observation is:
\begin{enumerate}[nosep]
\item \textbf{If $\lambda \geq \mu^{\star} \approx 0.096$}: the penalty term is strong enough to enforce the constraint exactly. At the boundary $x_1 = 0.65$, the left-sided derivative $\nabla_{x_1} f - \lambda = 0.096 - \lambda \leq 0$ (pointing towards feasible region), so the minimum of $F_\lambda$ is at $x_1 = 0.65$ --- violation = 0. This applies to all three penalty values in the experiment ($\lambda \in \{0.15, 1.8, 4.5\}$), which all exceed $\mu^{\star}$.
\item \textbf{If $\lambda < \mu^{\star}$}: the minimum of $F_\lambda$ is in the infeasible region at the point where $\nabla_{x_1} f(x_1) = \lambda$, giving positive violation. For $\lambda = 0.05$: $2(x_1-1)+\cos(x_1) = 0.05$ gives $x_1 \approx 0.57$, violation $\approx 0.08$.
\item \textbf{PGD}: always enforces $x_1 \geq 0.65$ exactly via the projection, regardless of $\mu^{\star}$.
\end{enumerate}
\noindent Note: for a \emph{quadratic} penalty $F_\lambda = f + (\lambda/2)(\max(0, c-x_1))^2$, the violation at the penalty minimum is $\approx \mu^{\star}/\lambda$, giving the familiar $O(1/\lambda)$ convergence to the constrained optimum. The linear penalty behaves differently: any $\lambda \geq \mu^{\star}$ achieves exact constraint satisfaction. The inactive constraint in this experiment ($\mu^{\star} = 0$) thus represents the trivially easy case: any $\lambda > 0$ suffices.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$ (a box/rectangle).

\textbf{Linear Programme.} For $f(x) = a^{\top}x$ with $a = [1,\, 2]^{\top}$, the minimum over $\mathcal{X}$ is attained at a vertex of the box (by the fundamental theorem of linear programming: the minimum of a linear objective over a compact polytope is attained at a vertex~\cite{bertsimas1997}). Since both components of $a$ are positive, minimising $f$ requires taking $x_1$ and $x_2$ to their lower bounds:
\begin{equation}
x^{\star} = \arg\min_{x \in \mathcal{X}} (x_1 + 2x_2) = (0.5,\; -5), \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}

\subsection{Frank--Wolfe Algorithm}

The Frank--Wolfe (FW) or conditional gradient method~\cite{frank1956} replaces the projection step of PGD with a linear minimisation oracle (LMO) over $\mathcal{X}$:

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) with Fixed Step}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^{\top} x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination; $\gamma_k = 1-\beta$ is the step size}
\EndFor
\end{algorithmic}
\end{algorithm}

The parameter $\beta \in (0,1)$ controls the step: $\gamma_k = 1 - \beta$ is the fixed fraction moved towards the LP vertex $z_k$ (equivalently, the step along the Frank--Wolfe direction $d_k = z_k - x_k$). The standard (optimal) FW step schedule is $\gamma_k = 2/(k+2)$ (decreasing), which ensures the $O(1/k)$ convergence guarantee. The fixed-step variant ($\gamma = $ const) is simpler to implement but may not converge if $\gamma$ is too large relative to the curvature. For box constraints, the LMO decomposes per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
This requires only $O(d)$ operations per iteration and no projection oracle, making it advantageous when $\Pi_{\mathcal{X}}$ is expensive but the LMO is cheap.

\paragraph{Sparse iterates.} A key structural property of FW is that iterates maintain a \emph{sparse representation} as convex combinations of $\mathcal{X}$'s vertices. Since each step sets $x_{k+1} = \beta x_k + (1-\beta) z_k$ with $z_k$ a vertex of $\mathcal{X}$, after $k$ iterations $x_k$ lies in the convex hull of at most $k+1$ vertices. For applications where the constraint set is a convex hull of complex objects (e.g., the nuclear norm ball whose vertices are rank-1 matrices, or the transportation polytope whose vertices are permutation matrices), this means FW solutions have bounded structural complexity. In the box constraint setting here, the vertices are the four corners of $\mathcal{X}$ and the representation degenerates, but this property explains FW's popularity in matrix completion and combinatorial optimisation relaxations.

\paragraph{FW gap as a convergence certificate.} The FW duality gap $g_k = \nabla f(x_k)^{\top}(x_k - z_k)$ provides a computable upper bound on the suboptimality: $f(x_k) - f^{\star} \leq g_k$ (by convexity of $f$: $f(z_k) \geq f(x_k) + \nabla f(x_k)^{\top}(z_k - x_k)$, hence $f(x_k) - f^{\star} \leq f(x_k) - f(z_k) \leq \nabla f(x_k)^{\top}(x_k - z_k) = g_k$). When $g_k \approx 0$, the iterate $x_k$ is near-optimal and the gradient direction $-\nabla f(x_k)$ points approximately inward relative to $\mathcal{X}$, meaning no feasible descent is available. This makes $g_k$ a practical stopping criterion. On smooth convex functions, FW converges at rate $O(1/k)$:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2LC^2}{k+2}, \quad C^2 = \max_{x, y \in \mathcal{X}} \|x - y\|^2.
\end{equation}

\subsection{Interior vs.\ Boundary Behaviour: Theoretical Analysis}

\paragraph{Interior optimum.} FW converges but exhibits the characteristic ``zig-zag'' at $O(1/k)$ rate. The LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$ at each iteration; the convex combination averaging reduces these oscillations only slowly. When $x^{\star}$ lies in the interior, the FW gap $g_k = \nabla f(x_k)^{\top}(x_k - z_k) \to 0$ as $x_k \to x^{\star}$, but the oscillations of $z_k$ between distant vertices slow convergence. Projected gradient descent, by contrast, would converge at a linear rate on this strongly convex problem.

\paragraph{Boundary optimum.} FW is better-suited to boundary optima: the LP vertex $z_k$ frequently selects the vertex nearest to $x^{\star}_c$, and the iterate naturally moves towards the constraint boundary without explicit projection. However, the fixed $\beta = 0.93$ does not allow the step to decay, resulting in oscillation around $x^{\star}_c$ and a residual suboptimality gap. The standard decaying schedule $\gamma_k = 2/(k+2)$ would achieve $O(1/k)$ convergence to $x^{\star}_c$ and remove this limitation.

\paragraph{FW vs.\ PGD.} The key trade-off is: FW requires only a cheap LMO (an $O(d)$ operation for boxes) and keeps iterates automatically feasible, but converges at the slower $O(1/k)$ rate and oscillates near the optimum. PGD converges faster (linear rate for smooth strongly convex $f$) but requires a potentially expensive projection oracle. For problems with complex convex constraints (e.g., nuclear norm balls, Birkhoff polytopes), the LMO is often much cheaper than the projection, making FW practically preferable.

\paragraph{Fixed step vs.\ decaying schedule: a quantitative comparison.}
The standard FW convergence rate analysis requires a decreasing step schedule. With $\gamma_k = 2/(k+2)$, one can show by induction~\cite{frank1956} that for an $L$-smooth convex $f$ and diameter $C = \max_{x,y \in \mathcal{X}}\|x-y\|$:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2LC^2}{k+2}.
\end{equation}

\textit{Proof sketch.} Let $h_k = f(x_k) - f^{\star}$. By $L$-smoothness and the FW update $x_{k+1} = x_k + \gamma_k(z_k - x_k)$:
\begin{equation}
h_{k+1} \leq (1 - \gamma_k)\,h_k + \frac{\gamma_k^2}{2}\,LC^2,
\end{equation}
using $g_k \geq h_k$ (from convexity: $f^{\star} \geq f(x_k) + \nabla f(x_k)^{\top}(x^{\star} - x_k) \geq f(x_k) - g_k$). For $k=1$ (with $\gamma_0 = 1$): $h_1 \leq 0 \cdot h_0 + \frac{1}{2}LC^2 = \frac{LC^2}{2} \leq \frac{2LC^2}{3}$ \checkmark. Inductive step: assuming $h_k \leq \frac{2LC^2}{k+2}$,
\[
h_{k+1} \leq \frac{k}{k+2}\cdot\frac{2LC^2}{k+2} + \frac{2LC^2}{(k+2)^2} = \frac{2LC^2(k+1)}{(k+2)^2} \leq \frac{2LC^2}{k+3},
\]
since $(k+1)(k+3) \leq (k+2)^2$ (i.e., $k^2+4k+3 \leq k^2+4k+4$, always true). $\blacksquare$
For the boundary case ($f(x) = x_1^2 + x_2^2$, $\mathcal{X} = [0.5,5]\times[-5,10]$): $L = 2$ (Hessian $= 2I$), $C^2 = (5-0.5)^2 + (10-(-5))^2 = 20.25 + 225 = 245.25$, giving the bound $f(x_k) - f^{\star} \leq 980/(k+2)$. At $k=140$, this gives $f - f^{\star} \leq 6.8$, which is loose (the actual suboptimality is $\approx 0.364 - 0.25 = 0.114$), but the bound confirms $O(1/k)$ convergence. Table~\ref{tab:fw_gap_values} shows the duality gap $g_k = \nabla f(x_k)^{\top}(x_k - z_k)$ at selected iterations for the boundary case, confirming that $g_k$ also provides an upper bound on $f(x_k) - f^{\star}$.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has systematically evaluated six families of optimisation algorithms across three benchmark problems of increasing difficulty. The main findings are:

\paragraph{Q1 -- Adaptive step sizes.} The Polyak step size achieves the best Rosenbrock result ($f = 0.009$, a $375\times$ improvement over GD's $f = 3.514$) when $f^{\star} = 0$ is correctly specified, but diverges on Benchmarks A and B where the true minima are $0.4826$ and $0.7244$ respectively, because the step $\alpha_k = (f - f^{\star}_{\rm specified})/\|\nabla f\|^2 \to \infty$ as $\|\nabla f\| \to 0$ while the numerator remains $\approx 0.48$. Adagrad and Heavy Ball match GD on Benchmarks A/B and outperform it on C. With the suboptimal step $\alpha = 0.08$ (vs.\ optimal $\alpha^{\star} \approx 1.02$ for Benchmark A), GD requires $\sim$75 iterations to reach the noise floor $J^{\star} \approx 0.4826$; the optimal step would achieve this in $\sim$5 iterations, illustrating the importance of step size tuning.

\paragraph{Q2 -- Momentum and stochastic methods.} Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ convergence rate for smooth convex functions, reducing Rosenbrock objective to $f = 0.479$ vs.\ GD's $f = 3.388$ after 150 iterations (a $7\times$ improvement). Theory predicts a $\sqrt{\kappa} = \sqrt{2508} \approx 50\times$ speedup asymptotically; the gap is explained by two factors: (1) 150 iterations is pre-asymptotic (the $O(1/k^2)$ vs $O(1/k)$ separation manifests fully only for $k \gtrsim \sqrt{\kappa} \cdot \log(1/\varepsilon) \approx 345$), and (2) the step $\alpha = 0.0007$ is 70\% of the optimal $\alpha^{\star} = 1/L \approx 0.001$ (see Section~\ref{sec:q2}). The Nesterov momentum schedule $\beta_k = (k-1)/(k+2)$ is connected to Chebyshev polynomial approximation and is information-theoretically optimal. Adam's per-coordinate scaling partially compensates for ill-conditioning but does not accumulate the persistent momentum that Nesterov exploits along the valley floor. Mini-batch SGD on Benchmark A demonstrates that smaller batches ($b=5$: 200 updates/epoch vs.\ $b=40$: 25 updates/epoch) converge faster per epoch, and that increasing observation noise by $6\times$ elevates the convergence plateau by $36\times$ ($\sigma^2$ scaling of the irreducible noise floor).

\paragraph{Q3 -- Newton's method.} Newton's method achieves exact one-step convergence on Benchmark A (the Hessian is constant, so the quadratic model is globally exact) and converges in 3--5 iterations on Benchmark B (near-quadratic structure). The analysis of $g(x) = x^4$ reveals a subtle failure mode: when $g''(x^{\star}) = 0$ at the optimum, the Newton update reduces to $x_{k+1} = (2/3)x_k$, a linear (not quadratic) convergence rate. This violates the hypothesis of Theorem~\ref{thm:newton_quad} ($\nabla^2 f(x^{\star}) \succ 0$ required). On Rosenbrock, damping $\alpha = 0.22$ is essential because the Hessian entries span three orders of magnitude along the trajectory ($H_{11} \in [1, 1202]$), but even with damping, Newton achieves $f = 0.686$ in 20 iterations vs.\ GD's $f = 3.732$ in 80 iterations --- a $5\times$ objective improvement in one-quarter the budget.

\paragraph{Q4 -- Derivative-free methods.} FD gradient approximation with $\delta = 0.05$ nearly matches exact GD on Benchmark B (both reach $f \approx 0.7244$) at the cost of $d+1 = 3$ function evaluations per step instead of 1 exact gradient. With $\delta = 0.8$, the $O(\delta)$ truncation error is $\sim 0.8$ (gradient error $\gg$ true gradient magnitude), severely degrading convergence. The optimal FD step is $\delta^{\star} \approx \sqrt{\varepsilon_{\rm mach}} \approx 10^{-8}$; both experimental $\delta$ values lie in the truncation-dominated regime. Nesterov random search incurs an intrinsic $O(d)$ oracle complexity penalty vs.\ gradient descent. Nelder--Mead achieves $f \approx 0$ on Rosenbrock (machine precision) in 160 iterations with zero gradient information, outperforming damped Newton ($f = 0.686$ in 20 iterations) --- a remarkable result attributable to the simplex's ability to adapt its geometry to the banana-shaped valley. Grid search is the only guaranteed global optimisation approach but scales exponentially: $O(N^d)$ evaluations for a $d$-dimensional $N$-point grid.

\paragraph{Q5 -- Constrained optimisation.} Projected GD enforces feasibility as a hard constraint from the first iteration. Penalty methods converge to the same optimal solution here because the constraint is inactive (the unconstrained optimum $x_1^* = 0.582 > 0.5$ is already feasible). For problems where the constraint \emph{is} active, the penalty method's behaviour depends critically on the penalty type: for a \emph{quadratic} penalty $\frac{\lambda}{2}(\max(0, c - x_1))^2$, the violation scales as $O(1/\lambda)$, so increasing $\lambda$ drives the solution towards the constraint boundary but never reaches it at finite $\lambda$. For the \emph{linear} penalty used in this code ($\lambda \max(0, c - x_1)$), any $\lambda \geq \mu^{\star}$ (the KKT multiplier at the active constrained optimum) achieves \emph{zero} violation exactly, as established in Section~\ref{sec:q5}. The augmented Lagrangian method combines both ideas --- penalty term plus a Lagrange multiplier update --- achieving exact constraint satisfaction at any finite $\lambda$ while avoiding the ill-conditioning of pure large-$\lambda$ penalty methods.

\paragraph{Q6 -- Frank--Wolfe.} Frank--Wolfe maintains feasibility automatically through convex combinations of feasible points (no projection oracle required) and uses an $O(d)$ LMO per iteration. For the interior optimum case, the fixed $\beta = 0.985$ ($\gamma = 0.015$) reaches $f = 0.0046$ vs.\ $\beta = 0.90$ ($\gamma = 0.10$) reaching $f = 0.0089$ --- smaller steps provide more accurate convergence at the cost of slower initial progress. For the boundary case, $f = 0.364$ after 140 iterations (vs.\ $f^{\star} = 0.25$), and the duality gap $g_{140} = 6.97 \approx 980/142 = 6.90$ (theoretical bound), confirming the $O(1/k)$ rate is \emph{tight} for the fixed-step variant. The gap is not a sharp suboptimality certificate here (actual suboptimality is $\approx 0.114$ while $g_{140} \approx 61\times$ larger) due to vertex oscillation: the LMO alternates between $(0.5,-5)$ and $(0.5,10)$ as the $x_2$ coordinate oscillates around the optimum $x_2^{\star}=0$. The decaying schedule $\gamma_k = 2/(k+2)$ provides the formal inductive bound $f(x_k) - f^{\star} \leq 2LC^2/(k+2)$ (proven in Section~\ref{sec:q6}) and would dampen this oscillation. FW's main advantage is for problems with complex constraint sets where the projection is expensive but the LMO is cheap (e.g., nuclear norm balls, Birkhoff polytopes, and large-scale LP relaxations).

\paragraph{Practical recommendations.}
\begin{enumerate}[nosep]
\item For well-conditioned smooth problems: any first-order method works well; Adam is the robust default for noisy/stochastic problems.
\item For ill-conditioned problems with available Hessian: Newton (or L-BFGS quasi-Newton) is preferred. Newton's $O(d^3)$ solve is the bottleneck only for $d \gg 100$; for $d = 2$ (as here), it is negligible.
\item When gradients are unavailable: FD approximation ($\delta \approx \sqrt{\varepsilon_{\rm mach}} \approx 10^{-8}$) if differentiability holds; Nelder--Mead or random search otherwise. Note that for $d \leq 5$, Nelder--Mead is often more practical than random search despite lacking convergence guarantees.
\item For constrained problems: PGD when the projection is cheap; FW when the LMO is cheap; penalty/augmented Lagrangian when neither oracle is available.
\item When $f^{\star}$ is known or reliably estimated: the Polyak step is the simplest and most effective adaptive method, achieving $O(1/k)$ convergence without any smoothness constants.
\end{enumerate}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float); G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x); G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float); v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float); z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z       # evaluate gradient at predicted point
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)  # bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping and Regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))  # Tikhonov regularisation
        try:
            p = np.linalg.solve(H_reg, g)     # Newton direction
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient)}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: minimise linear approximation over box
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z   # step size gamma = 1-beta
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
