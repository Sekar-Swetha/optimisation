\begin{abstract}
% ============================================================
This report presents a systematic comparative analysis of first-order, second-order,
derivative-free, and constrained optimisation algorithms applied to three benchmark
problems of increasing difficulty: a quadratic linear-regression loss (Benchmark A),
a mildly nonlinear toy neural-network loss with sinusoidal perturbation (Benchmark B),
and the ill-conditioned Rosenbrock function (Benchmark C).
Six algorithm families are investigated:
(1)~\emph{Adaptive step-size methods} -- Polyak, Adagrad, RMSprop, and Heavy Ball --
which adjust the learning rate based on gradient history;
(2)~\emph{Momentum and stochastic methods} -- Nesterov acceleration and Adam --
which accumulate gradient information across iterations, together with mini-batch SGD;
(3)~\emph{Newton's method} with local second-order approximations, exploiting Hessian
information for fast local convergence;
(4)~\emph{Derivative-free methods} -- finite-difference gradient approximation,
Nesterov random search, Nelder--Mead simplex, and grid search;
(5)~\emph{Projected gradient descent and penalty methods} for constrained optimisation;
and (6)~the \emph{Frank--Wolfe} (conditional gradient) algorithm for linear-constrained
problems.
Each method is evaluated in terms of convergence speed, trajectory behaviour,
stability, constraint handling, and computational cost per iteration.
Key findings include: the Polyak step size diverges when $f^\star$ is misspecified,
Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ rate on convex
problems, Newton's method converges in a single step on quadratic losses, and
Frank--Wolfe handles linear constraints projection-free at an $O(1/k)$ rate.
\end{abstract}

\section*{Introduction}
\addcontentsline{toc}{section}{Introduction}
% ============================================================

Optimisation is the mathematical engine powering modern machine learning: training a
neural network, fitting a regression model, or finding a policy all reduce to solving
an optimisation problem of the form $\min_{x \in \mathcal{X}} f(x)$.
The choice of optimisation algorithm profoundly affects the practical feasibility,
speed, and reliability of these tasks.
This report investigates the breadth of modern continuous optimisation methods,
from classical gradient descent to second-order Newton methods, from stochastic
mini-batch variants to derivative-free approaches, and from penalty formulations to
Frank--Wolfe for constrained problems.

The central challenge is that no single method dominates across all settings.
Gradient descent is simple and stable but slow on ill-conditioned problems.
Newton's method is fast when near a solution but requires expensive Hessian computation.
Adaptive methods (Adagrad, Adam) are practical for neural networks but may
over-adapt.  Derivative-free methods are necessary when gradients are unavailable
but scale poorly.  The goal of this report is to demonstrate these trade-offs
empirically on three benchmarks of increasing difficulty, and to connect the
observed behaviour to the relevant convergence theory from the course.

\textbf{Notation.}
Throughout: $f: \mathbb{R}^d \to \mathbb{R}$ is the objective; $x_k$ is the iterate
at step $k$; $g_k = \nabla f(x_k)$ is the gradient; $f^\star = \min_{x} f(x)$;
$x^\star$ is a minimiser.  A function $f$ is $\mu$-strongly convex if
$f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$ for all $x,y$;
it is $L$-smooth if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ for all $x,y$.
The condition number $\kappa = L/\mu$ quantifies the difficulty of a strongly
convex problem for first-order methods.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for full
reproducibility.  The four benchmark problems used throughout the assignment are
defined below.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset is generated with $m = 1000$ samples and two parameters:
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = {\theta^{\star}}^{\!T} x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The mean squared error loss function is
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2
            = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a strictly convex quadratic with constant Hessian
$H = \frac{1}{m}X^T X \succ 0$.
The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$.
Due to the irreducible observation noise, the minimum loss is
$J^{\star} \approx 0.4826 \neq 0$.
The Hessian eigenvalues depend on the random design matrix; empirically the condition
number satisfies $\kappa(H) \approx 1.9$ for this draw, meaning Benchmark A is
well-conditioned.
The starting point is $\theta_0 = [0,\, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}

\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is
$\nabla f = \bigl[2(x_1 - 1) + \cos(x_1),\; 10(x_2 - 2)\bigr]^T$
and the Hessian is
$H(x) = \operatorname{diag}(2 - \sin(x_1),\; 10)$.
The Hessian eigenvalues vary in the range $[1, 3] \times \{10\}$, giving a local
condition number between approximately $10/3$ and $10$ depending on position.
The function is non-quadratic due to the sinusoidal term, but remains strongly
convex for $|x_1| \lesssim \pi$ since $2 - \sin(x_1) \geq 1 > 0$.
The unconstrained minimum lies at approximately $(x_1^\star, x_2^\star) \approx (0.582, 2.0)$
with $f^\star \approx 0.7244$.
The starting point is $x_0 = [-1,\, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$.
The Hessian at the optimum evaluates to
\[
  H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\]
with eigenvalues approximately $0.5$ and $1001.5$, giving a condition number
$\kappa \approx 2003$.  This extreme ill-conditioning, combined with the narrow
curved valley along $x_2 = x_1^2$, makes the Rosenbrock function one of the
canonical hard test problems for continuous optimisation.
The Hessian off-diagonal entry $-400 x_1$ creates strong coupling between the
two coordinates, invalidating any coordinate-independent analysis.
The starting point is $x_0 = [-1,\, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}

For constrained optimisation (Questions 5 and 6):
\begin{equation}
  \mathcal{X} = \bigl\{x \in \mathbb{R}^2 :\; 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\bigr\}.
\end{equation}
This is a compact, convex polytope (box) in $\mathbb{R}^2$ with diameter
$D = \sqrt{(5-0.5)^2 + (10+5)^2} = \sqrt{20.25 + 225} \approx 15.67$.
Projection onto $\mathcal{X}$ decomposes coordinate-wise and costs $O(d)$.

\section{Question 1: Adaptive Step-Size Methods}
\label{sec:q1}
% ============================================================

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent
(GD) baseline.  All methods run for 120 iterations on all three benchmarks.
Throughout, $g_k \triangleq \nabla f(x_k)$ denotes the gradient at the current iterate.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, regulariser $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step is derived by minimising the first-order bound on the objective:
\begin{equation}
  f(x_{k+1}) \leq f(x_k) + g_k^T(x_{k+1}-x_k) + \tfrac{L}{2}\|x_{k+1}-x_k\|^2,
\end{equation}
and then choosing $x_{k+1}$ to reach $f^\star$ in one step if the bound were tight.
Crucially, the formula requires knowledge of $f^\star$.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, regulariser $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative per-coordinate squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, regulariser $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1-\beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The key difference between Adagrad and RMSprop is the treatment of gradient history.
Adagrad accumulates \emph{all} past squared gradients ($G_k = \sum_{t=0}^{k-1} g_t^2$),
so the effective step size $\alpha_0/\sqrt{G_k}$ decays monotonically to zero.
RMSprop replaces the cumulative sum with an exponential moving average with decay
$\beta$, causing old gradients to be exponentially discarded.  This prevents the
step from shrinking to zero and allows adaptation to changing curvature.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, g_k$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method adds a momentum term $z_k$ that accumulates gradient
information.  For a $\mu$-strongly convex, $L$-smooth quadratic, the optimal
parameters are $\alpha^\star = \bigl(\frac{2}{\sqrt{L}+\sqrt{\mu}}\bigr)^2$ and
$\beta^\star = \bigl(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\bigr)^2$, yielding a
spectral radius of $\rho = \bigl(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\bigr)^2 < 1$
where $\kappa = L/\mu$.  In practice, the hyperparameters in Table~\ref{tab:q1_params}
are tuned by grid search.

\subsection{Theoretical Background}

\begin{theorem}[Polyak Convergence; Polyak 1969]\label{thm:polyak}
If $f$ is convex, $L$-smooth, $f^\star$ is known exactly, and $\|g_k\|^2 > 0$, then
\[
  f(x_{k+1}) - f^\star \;\leq\;
  \left(1 - \frac{2\mu}{L}\right)(f(x_k) - f^\star)
\]
where $\mu > 0$ is the strong convexity constant.  If $f^\star$ is misspecified
as $\tilde{f}^\star < f^\star_{\rm true}$, the step $\alpha_k \to \infty$ as
$\|g_k\| \to 0$ while $f(x_k) - \tilde{f}^\star \to f^\star_{\rm true} - \tilde{f}^\star > 0$,
causing divergence.
\end{theorem}

In Benchmarks A and B, the true optimal values are $J^\star_A \approx 0.4826$ and
$f^\star_B \approx 0.7244$, both strictly positive, but the algorithm is supplied
$f^\star = 0$.  This creates the divergence observed experimentally.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:}
  When $f^\star$ is known exactly, the Polyak step converges fastest (Rosenbrock:
  $f = 0.009$) by making the largest safe step at each iteration.
  Otherwise, Adagrad and Heavy Ball match or exceed GD, while Polyak diverges.
\item \textbf{Smoothness:}
  RMSprop produces the smoothest convergence curves due to exponential moving-average
  smoothing of the gradient second moment.
  Heavy Ball exhibits the characteristic overshoot followed by damped oscillation
  typical of momentum methods near the optimum.
\item \textbf{Stability:}
  GD is the most stable but slowest.
  Adagrad is uniformly stable because its step is bounded: $\alpha_k \leq \alpha_0/\sqrt{\varepsilon}$
  and $\alpha_k \to 0$ monotonically.
  Polyak is \emph{unstable} when $f^\star$ is misspecified.
\item \textbf{Adagrad vs.\ RMSprop trade-off:}
  Adagrad's cumulative squared gradient $G_k = \sum_{t=0}^{k-1} g_t^2$ grows without
  bound, causing the effective step $\alpha_0/\sqrt{G_k} \sim \alpha_0/\sqrt{k}$ to
  decay at rate $O(1/\sqrt{k})$.  For convex problems, Adagrad achieves an $O(\log k/\sqrt{k})$
  regret bound in the online setting, but for offline optimisation, the decaying step
  may cause premature stagnation.
  RMSprop replaces $G_k$ with an exponential moving average $v_k = \beta v_{k-1} + (1-\beta)g_k^2$
  which has a finite effective window of $1/(1-\beta) = 10$ iterations, preventing
  the step from shrinking to zero.
\item \textbf{Heavy Ball on ill-conditioned problems:}
  Heavy Ball's optimal parameters for a quadratic with condition number $\kappa$ give
  a spectral radius $\rho = (\sqrt{\kappa}-1)^2/(\sqrt{\kappa}+1)^2$, which for
  $\kappa = 2003$ gives $\rho \approx (43.8)^2/(45.8)^2 \approx 0.914$.
  This means each iteration reduces the error by a factor of $\approx 1 - 2/\sqrt{\kappa}$,
  compared to $1 - 2/\kappa$ for GD -- a substantial acceleration.
  The observed improvement ($f_{\rm HB} = 1.40$ vs.\ $f_{\rm GD} = 3.51$ on Rosenbrock)
  confirms this theoretical advantage.
\item \textbf{Practical implication:}
  In practice, exact $f^\star$ is rarely known, limiting Polyak's direct applicability.
  RMSprop and Adagrad are robust choices for neural network training, where gradient
  magnitudes vary widely across layers (a form of coordinate-wise anisotropy).
\end{itemize}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\; \beta_{\max}\right)$ \Comment{Schedule from Nesterov's analysis}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead step}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The defining feature of Nesterov acceleration is that the gradient is evaluated at
the \emph{lookahead point} $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$.
This allows the iterate to ``look ahead'' in the direction of momentum and correct the
trajectory before overshooting.

\begin{theorem}[Nesterov Acceleration Rate]
For a convex, $L$-smooth function, the standard Nesterov method with step
$\alpha = 1/L$ and $\beta_k = (k-1)/(k+2)$ achieves
\[
  f(x_k) - f^\star \;\leq\; \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2},
\]
an $O(1/k^2)$ rate, compared to the $O(1/k)$ rate of gradient descent.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, $\beta_1, \beta_2 \in (0,1)$, $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0},\; v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1-\beta_1)\, g_t$ \Comment{First moment (momentum)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1-\beta_2)\, g_t \odot g_t$ \Comment{Second moment (adaptive scaling)}
    \State $\hat{m}_t \gets m_t / (1 - \beta_1^t)$ \Comment{Bias correction for first moment}
    \State $\hat{v}_t \gets v_t / (1 - \beta_2^t)$ \Comment{Bias correction for second moment}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t \mathbin{/} (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines RMSprop's per-coordinate adaptive scaling (via $v_t$) with gradient
momentum (via $m_t$).  The bias correction factors $(1-\beta_1^t)^{-1}$ and
$(1-\beta_2^t)^{-1}$ ensure that in the early iterations, when $m_t$ and $v_t$ are
initialised at zero, the estimates are corrected to be unbiased.  Without bias
correction, the effective step at $t=1$ would be $\alpha \cdot (1-\beta_1)g_1 / (\sqrt{(1-\beta_2)g_1^2} + \varepsilon) = \alpha\sqrt{1-\beta_2}/(1-\beta_1) \cdot \text{sign}(g_1)$,
which for $\beta_1 = 0.9$, $\beta_2 = 0.999$ gives $\approx \alpha \cdot 0.316/0.1 \approx 3.16\alpha$.
Bias correction at $t=1$ restores the natural step of $\approx \alpha/(\varepsilon)$ when the
gradient magnitude is consistent.

\textbf{Nesterov vs.\ Heavy Ball.}
Both algorithms use a momentum buffer $z_k$, but differ critically in where the
gradient is evaluated.
\begin{itemize}[nosep]
\item \textbf{Heavy Ball:} $z_{k+1} = \beta z_k + \alpha\nabla f(x_k)$;
  gradient evaluated at the current point $x_k$.
\item \textbf{Nesterov:} $z_{k+1} = \beta_k z_k - \alpha \nabla f(x_k + \beta_k z_k)$;
  gradient evaluated at the \emph{lookahead} point $x_k + \beta_k z_k$.
\end{itemize}
The lookahead effectively ``corrects'' the momentum direction before committing to the
step.  On a quadratic, Heavy Ball with optimal parameters matches Nesterov's convergence
rate ($O(1/\sqrt{\kappa})$ iterations).  On general convex functions, Nesterov has a
provably optimal $O(1/k^2)$ rate, whereas Heavy Ball has no convergence guarantee
beyond quadratics (it can oscillate or diverge on non-quadratic functions with fixed
$\beta$).

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$,
batch sizes $b \in \{5, 40\}$, and 50 epochs with data shuffled at every epoch.
With $m = 1000$ samples, each epoch performs $m/b$ gradient steps.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{epoch $e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1, \ldots, m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Unbiased gradient estimate}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The mini-batch gradient $g$ is an unbiased estimator of the full gradient
$\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$, with variance proportional to
$\sigma^2_{\rm grad}/b$ where $\sigma^2_{\rm grad}$ is the per-sample gradient
variance.  Larger batches reduce variance but require fewer steps per epoch.

\subsection{Comparative Analysis of Q2 Methods}

\begin{itemize}[nosep]
\item \textbf{Nesterov vs.\ GD:}
  Nesterov's lookahead gradient removes the systematic overshoot inherent in Heavy Ball,
  yielding theoretical $O(1/k^2)$ convergence versus $O(1/k)$ for GD on convex functions.
  The practical speedup is most dramatic on Rosenbrock ($\approx7\times$ improvement
  in $f$ after 150 iterations) and essentially invisible on well-conditioned Benchmark A
  (both converge to machine precision within 50 iterations).
  The reason is that Nesterov's acceleration benefit scales as $\sqrt{\kappa}$:
  for $\kappa \approx 1.9$ (Benchmark A), there is little to gain;
  for $\kappa \approx 2003$ (Rosenbrock), Nesterov requires $O(\sqrt{2003}) \approx 45$
  times fewer iterations than GD.

\item \textbf{Adam vs.\ Nesterov on Rosenbrock:}
  Adam's per-coordinate adaptive scaling is powerful when different dimensions have
  vastly different curvatures and the Hessian is approximately diagonal.
  The Rosenbrock Hessian has a large off-diagonal entry ($H_{12} = -400 x_1$), meaning
  coordinates $x_1$ and $x_2$ are strongly coupled; diagonal preconditioning fails to
  capture this structure.
  Nesterov's momentum, building along the consistent valley-floor direction, is more
  effective for navigating the curved valley.
  This explains why Nesterov ($f = 0.479$) outperforms Adam ($f = 1.578$) despite
  Adam's general popularity for deep learning (where Hessians are closer to diagonal).

\item \textbf{Batch size trade-off:}
  For a quadratic loss $J(\theta) = \frac{1}{2m}\|X\theta - y\|^2$, the full gradient
  is $\nabla J = \frac{1}{m}X^T(X\theta - y)$ and the mini-batch gradient has variance
  $\mathbb{V}[\hat{g}] = \frac{\sigma^2_{\rm grad}}{b}$ where $\sigma^2_{\rm grad}$ is
  the per-sample gradient variance.
  The optimal batch size balances the variance reduction (favouring large $b$) against
  the number of updates per epoch (favouring small $b$).
  Linear scaling of effective step with batch size holds in the regime where gradient
  variance dominates; it breaks down when $b$ is large enough that the dominant noise
  is irreducible observation noise.

\item \textbf{Effect of noise on SGD:}
  Increasing observation noise by factor 6 multiplies $J^\star$ by 36 (since
  $J^\star \propto \sigma^2$), but also multiplies the gradient noise variance by 36.
  This shifts the ``sweet spot'' for batch size: under high noise, even the large
  batch ($b=40$) behaves like a small batch, and the advantage of $b=5$ (more frequent
  updates) vanishes because both batch sizes are dominated by observation noise.
\end{itemize}

\subsection{Local Approximations of $g(x) = x^4$}

Let $g(x) = x^4$ with $g'(x) = 4x^3$ and $g''(x) = 12x^2$.  Around $x_0 = 0.25$:

\textbf{First-order (Taylor) approximation:}
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0)
        = 0.0039 + 0.0625(x - 0.25).
\end{equation}
The first-order model is a tangent line that captures the local slope but ignores
curvature; it deviates rapidly from $g$ away from $x_0$.

\textbf{Second-order approximation:}
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
        = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises the second-order model.  Setting its derivative to zero:
$g'(x_0) + g''(x_0)(x - x_0) = 0$, yielding
\begin{equation}
  x_1 = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{0.0625}{0.375} = 0.25 - \tfrac{1}{6} \approx 0.0833.
\end{equation}
This is the Newton step, corresponding to the minimum of the local quadratic model.

\subsection{Newton's Method with Damping}

\begin{algorithm}[H]
\caption{Newton's Method with Damping (Regularised Hessian)}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, damping $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction via linear solve}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Hessian damping $\lambda I$ serves two purposes: (1) it ensures positive definiteness
even when the true Hessian has near-zero or negative eigenvalues, and (2) it bounds
the Newton step when the Hessian is ill-conditioned.  With $\alpha = 1$ (full Newton
step) on a strictly convex quadratic, Newton converges in exactly one iteration.

\begin{theorem}[Quadratic Convergence of Newton's Method]
Let $f$ be twice continuously differentiable and strongly convex in a neighbourhood of
$x^\star$.  If $\nabla^2 f$ is $\ell$-Lipschitz and $x_0$ is sufficiently close to
$x^\star$, then with $\alpha = 1$ and $\lambda = 0$,
\[
  \|x_{k+1} - x^\star\| \;\leq\; \frac{\ell}{2\mu}\|x_k - x^\star\|^2,
\]
where $\mu$ is the strong convexity constant.  This \emph{quadratic convergence} means
the number of correct digits doubles at each iteration.
\end{theorem}

For non-quadratic objectives or when starting far from $x^\star$, a damped step
$\alpha < 1$ is used to globalise convergence.

\subsection{Newton Decrement and Convergence Certificate}

A key diagnostic for Newton's method is the \emph{Newton decrement}:
\begin{equation}
  \lambda(x)^2 \triangleq \nabla f(x)^T H(x)^{-1} \nabla f(x) = g^T p,
\end{equation}
where $p = H^{-1}g$ is the Newton direction.
The quantity $\lambda(x)^2/2$ is an upper bound on the suboptimality
$f(x) - f^\star$ (tight for quadratics near the optimum), making it a
parameter-free stopping criterion.
When $\lambda(x)^2/2 \leq \varepsilon_{\rm tol}$, Newton's method has certified
$\varepsilon_{\rm tol}$-suboptimality without requiring knowledge of $f^\star$.
This is a major advantage over the Polyak step size (which requires $f^\star$).
Figure~\ref{fig:q3_decrement} shows the Newton decrement across all three benchmarks.

convergent local phase.

\subsection{Comparative Discussion}

Newton's method's key advantage over gradient descent is its use of curvature
information: by multiplying the gradient by $H^{-1}$, it effectively rescales each
coordinate by the inverse local curvature, removing the ill-conditioning that hampers
GD.  Specifically, the Newton direction $p_k = H_k^{-1}g_k$ satisfies
$\kappa(H_k^{-1})=1$ (identity preconditioning), so the preconditioned gradient
step is scale-invariant -- it is independent of the condition number $\kappa(H_k)$.
This is why Newton converges in the same number of iterations on Benchmark A
($\kappa \approx 1.9$) and Benchmark B ($\kappa \approx 3$--$10$).
The cost is computing and inverting the $d \times d$ Hessian, which costs
$O(d^3)$ per iteration vs.\ $O(d)$ for GD.  For $d = 2$, this cost is negligible;
for large-scale problems ($d \gg 1$), quasi-Newton methods (BFGS, L-BFGS) that
approximate $H^{-1}$ from gradient differences are preferred.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation}
\label{sec:q4}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation of the $i$-th partial derivative is:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
  \qquad e_i = \text{$i$-th standard basis vector.}
\end{equation}
A Taylor expansion gives:
\begin{equation}
  \frac{f(x + \delta e_i) - f(x)}{\delta}
  = \frac{\partial f}{\partial x_i}(x) + \underbrace{\frac{\delta}{2}\frac{\partial^2 f}{\partial x_i^2}(x)}_{\text{truncation error}} + O(\delta^2),
\end{equation}
so the approximation error has two competing components:
\begin{itemize}[nosep]
\item \textbf{Truncation error:} $\frac{\delta}{2} |H_{ii}(x)| \approx \frac{\delta}{2} L$,
  growing with $\delta$.
\item \textbf{Floating-point cancellation error:} $O(\varepsilon_{\rm mach} \|f\| / \delta)$,
  growing as $\delta \to 0$.
\end{itemize}
Balancing these gives an optimal $\delta^\star \sim \sqrt{\varepsilon_{\rm mach} / L} \approx 10^{-4}$
for $L = O(1)$.  For Benchmark B near $x_0 = [-1, 4]^T$, $L \approx 10$ (maximum
Hessian eigenvalue), so $\delta^\star \approx \sqrt{10^{-16}/10} \approx 3 \times 10^{-8}$.
The assignment uses $\delta = 0.05$ (sub-optimal but good enough: truncation error
$\approx 0.025 \times 10 = 0.25$, small relative to gradient magnitudes near $x_0$)
and $\delta = 0.8$ (excessive truncation: error $\approx 0.4 \times 10 = 4$,
comparable to the gradient magnitude itself, causing severe direction errors).

This method requires $d + 1$ function evaluations per iteration (one base evaluation
plus one per dimension), compared to a single analytic gradient evaluation for exact GD.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$; normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The update $\hat{g}_k$ is an unbiased \emph{directional derivative} estimate along a
uniformly random direction $u_k$.  Its expected value satisfies
$\mathbb{E}[\hat{g}_k] = \nabla f_\delta(x_k)$ where $f_\delta$ is a Gaussian-smoothed
version of $f$.  The key properties are:
(1) requires only \emph{two} function evaluations per iteration regardless of dimension,
making it dimension-free in per-iteration cost;
(2) the gradient estimate has high variance (it captures only one random directional
component of $\nabla f$), requiring more iterations to converge than exact gradient
methods.

\subsection{Part B: Derivative-Free Methods on Benchmark C}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$
and iteratively transforms it via four operations with parameters $\alpha_r = 1$ (reflection),
$\gamma = 2$ (expansion), $\rho = 0.5$ (contraction), $\sigma = 0.5$ (shrink):

\begin{enumerate}[nosep]
\item \textbf{Reflection ($\alpha_r$):} move the worst vertex through the centroid of
  the remaining vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x_{\rm worst})$.
\item \textbf{Expansion ($\gamma$):} if reflection improved, try further:
  $x_e = \bar{x} + \gamma(\bar{x} - x_{\rm worst})$.
\item \textbf{Contraction ($\rho$):} if reflection did not improve, contract towards
  the centroid: $x_c = \bar{x} + \rho(x_r - \bar{x})$ or $\bar{x} + \rho(x_{\rm worst} - \bar{x})$.
\item \textbf{Shrink ($\sigma$):} if contraction also failed, contract all vertices
  towards the best: $x_i \gets x_{\rm best} + \sigma(x_i - x_{\rm best})$ for all $i$.
\end{enumerate}

No gradient information is used; the simplex geometry itself encodes directional
information through the relative positions of the vertices.

Settings: initial simplex step $= 0.35$, iterations $= 160$.

\subsection{Comparison Between Nelder--Mead and Nesterov Random Search}

Both Nelder--Mead and Nesterov random search are gradient-free, but they differ in
their approach to directional information:
\begin{itemize}[nosep]
\item \textbf{Nelder--Mead} maintains a geometric structure (simplex) with $n+1 = 3$
  vertices and uses function values at all vertices to infer promising directions.
  It requires up to 4 function evaluations per iteration (reflection, expansion,
  contraction, shrink), and its simplex adapts to local curvature.
  It is effective in low dimensions ($d \leq 10$) but does not generalise to high
  dimensions.
\item \textbf{Nesterov random search} uses only 2 function evaluations per iteration
  but obtains only a one-dimensional directional derivative estimate.
  Its convergence rate on $d$-dimensional $L$-smooth functions is
  $O(dL\|x_0 - x^\star\|^2/k)$, scaling linearly with $d$.
\end{itemize}
On the Rosenbrock function, Nelder--Mead outperforms Nesterov random search
(reaching $f < 0.01$ vs.\ $f \approx 2$ for NRS in comparable iterations) because
the simplex geometry naturally adapts to the banana-shaped valley, whereas NRS
wastes many steps on random directions perpendicular to the valley.

\subsection{Comparative Discussion}

The fundamental trade-off in derivative-free optimisation is between per-iteration
information quality and per-iteration cost.  Exact gradient methods extract maximum
directional information per step but require differentiable objectives.
Finite differences approximate this at extra function evaluation cost ($d+1$ per step).
Nesterov random search uses minimum evaluations (2 per step) but provides only a
one-dimensional gradient estimate.
Nelder--Mead adapts its simplex shape to sense curvature without gradients, and is
practical in low dimensions ($d \leq 10$) but suffers from stagnation on highly
ill-conditioned problems.
Grid search is exhaustive but computationally catastrophic in high dimensions.

\section{Question 5: Constrained Optimisation}
\label{sec:q5}
% ============================================================

\subsection{Problem Formulation}

The constrained problem is:
\begin{equation}
  \min_{x \in \mathcal{F}}\; f(x_1, x_2), \qquad
  \mathcal{F} = \{x \in \mathbb{R}^2 : x_1 \geq 0.5\},
\end{equation}
where $f$ is Benchmark B.  The starting point $x_0 = (0.2, 4.0)$ is \emph{infeasible}
(violates $x_1 \geq 0.5$).

\textbf{Slater's condition.}
The feasible set $\mathcal{F} = \{x : x_1 \geq 0.5\}$ has a non-empty interior;
for example, $x = (1, 3) \in \mathrm{int}(\mathcal{F})$ and is strictly feasible.
Since $f$ is convex and the constraint is affine, Slater's condition holds, which
guarantees strong duality (zero duality gap) and that the KKT conditions are
both necessary and sufficient for optimality.

\textbf{KKT conditions.}  Since the constraint is $g(x) = 0.5 - x_1 \leq 0$ and $f$
is differentiable, the KKT conditions at the constrained optimum $x^\star$ are:
\begin{align}
  \nabla f(x^\star) + \mu^\star \nabla g(x^\star) &= 0 \quad
    \Rightarrow\quad [2(x_1^\star - 1) + \cos(x_1^\star),\; 10(x_2^\star - 2)]^T
    - \mu^\star[1, 0]^T = 0, \\
  \mu^\star g(x^\star) &= 0 \quad (\text{complementary slackness}), \\
  g(x^\star) &\leq 0, \quad \mu^\star \geq 0.
\end{align}
Since the unconstrained minimum at $x_1^\star \approx 0.582 > 0.5$ is feasible, the
constraint is inactive at optimum and $\mu^\star = 0$.  The constrained optimum
coincides with the unconstrained minimum: $x^\star \approx (0.582, 2.0)$,
$f^\star \approx 0.7244$.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{F}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{F}}(z_{k+1})$ \Comment{Project: $x_1 \leftarrow \max(0.5,\; z_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection $\Pi_{\mathcal{F}}(z) = (\max(0.5, z_1), z_2)^T$ costs $O(1)$ for
the half-space constraint.  Projected GD satisfies:
$\|x_{k+1} - x^\star\| \leq \|x_k - \alpha\nabla f(x_k) - x^\star\| \leq (1 - \alpha\mu)\|x_k - x^\star\|$
for $\mu$-strongly convex $f$ and $\alpha < 2/L$, guaranteeing linear convergence.

\begin{algorithm}[H]
\caption{Penalty Method (Gradient Descent on Penalised Objective)}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_\lambda(x_k) \gets f(x_k) + \lambda\,\max(0,\; 0.5 - x_1)$
    \State $\nabla F_\lambda(x_k) \gets \nabla f(x_k) + \lambda\,(-1)\cdot \mathbf{1}[x_1 < 0.5]\,e_1$
    \State $x_{k+1} \gets x_k - \alpha\,\nabla F_\lambda(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty gradient is a subgradient of $F_\lambda$ (since $\max(0, \cdot)$ is
nondifferentiable at zero).  As $\lambda \to \infty$, the penalised minimiser
$x^\star_\lambda \to x^\star$, but larger $\lambda$ stiffens the objective, requiring
smaller step sizes to maintain stability.

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$
($\alpha = 0.05$ for $\lambda \leq 1.8$, $\alpha = 0.03$ for $\lambda = 4.5$);
unconstrained GD ($\alpha = 0.07$).  All run for 100 iterations.

\textbf{Projected GD} enforces feasibility \emph{immediately and hard} at every
iteration: the iterate is always in $\mathcal{F}$.  This is the fundamental advantage
over penalty methods.  The cost is the availability of a projection oracle
$\Pi_{\mathcal{F}}$: trivial for box constraints ($O(d)$) but expensive for general
convex sets (e.g., semidefinite constraints require $O(d^3)$ eigendecomposition).

\textbf{Penalty methods} replace exact feasibility with a soft penalty.  The weight
$\lambda$ controls the strength of constraint enforcement.  As $\lambda \to \infty$:
\begin{itemize}[nosep]
\item The penalised minimiser $x^\star_\lambda \to x^\star$ (exact solution), but
\item The condition number of the penalised objective grows as $O(\lambda)$,
  requiring step size $\alpha = O(1/\lambda)$ and thus more iterations to converge.
\end{itemize}
This fundamental limitation of the pure penalty method motivates the
\emph{augmented Lagrangian} approach, which adds a multiplier estimate $\hat\mu$ to
the penalty:
\begin{equation}
  L_\lambda(x, \hat\mu) = f(x) + \hat\mu\,\max(0, 0.5 - x_1)
    + \frac{\lambda}{2}\max(0, 0.5 - x_1)^2.
\end{equation}
By updating $\hat\mu$ at each outer iteration, the augmented Lagrangian achieves
primal and dual feasibility simultaneously without requiring $\lambda \to \infty$.

In this particular problem, since the unconstrained and constrained optima coincide
(the constraint is inactive at $x^\star = (0.582, 2.0)$ since $0.582 > 0.5$), all
sufficiently tuned methods ultimately reach the same final objective value.
The practical distinction lies in (a)~trajectory feasibility (hard guarantee for
projected GD, soft guarantee for penalty), and (b)~the speed of convergence to the
feasible region, which is analysed in Figure~\ref{fig:q5_violation}.

\subsection{Feasible Set and Linear Programme}

The feasible set is the axis-aligned box:
$\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme.}
For $f(x) = a^T x$ with $a = [1,\; 2]^T$:
\begin{equation}
  \min_{x \in \mathcal{X}}\; x_1 + 2x_2 \;=\; \min_{0.5 \leq x_1 \leq 5} x_1 + \min_{-5 \leq x_2 \leq 10} 2x_2.
\end{equation}
Since $a_1 = 1 > 0$ and $a_2 = 2 > 0$, both coordinates are minimised at their
lower bounds:
\begin{equation}
  x^\star = (0.5,\; -5), \qquad f^\star = 0.5 + 2(-5) = -9.5.
\end{equation}
This illustrates the fundamental theorem of linear programming: for a bounded convex
polytope, the linear minimum is attained at a vertex.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in [0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\; \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1-\beta)\, z_k$ \Comment{Convex combination (fixed step)}
\EndFor
\end{algorithmic}
\end{algorithm}

The linear minimisation oracle (LMO) for box constraints decomposes per coordinate:
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0, \\
                            u_i & \text{if } (\nabla f(x_k))_i \leq 0,
             \end{cases}
\end{equation}
requiring $O(d)$ operations.  Each iterate $x_{k+1} = \beta x_k + (1-\beta)z_k$ is a
convex combination of $x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$, so
$x_{k+1} \in \mathcal{X}$ automatically -- \emph{no projection is required}.

The parameter $\beta$ controls the step size: $(1-\beta)$ is the fraction moved
towards the LP vertex.  The standard Frank--Wolfe step uses $\gamma_k = 2/(k+2)$
(i.e.\ $\beta_k = 1 - 2/(k+2)$), which decays appropriately and achieves the
sublinear convergence bound.

\begin{theorem}[Frank--Wolfe Convergence]
Let $f$ be convex and $L$-smooth over $\mathcal{X}$ with diameter $D$.  With the
standard step $\gamma_k = 2/(k+2)$,
\[
  f(x_k) - f^\star \;\leq\; \frac{2LD^2}{k+2}, \qquad O(1/k) \text{ rate.}
\]
The \emph{Frank--Wolfe gap} $g_k = \nabla f(x_k)^T(x_k - z_k) \geq 0$ is a
certificate of optimality: $g_k = 0$ implies $x_k$ is optimal.
\end{theorem}

Here $D = \sqrt{(5-0.5)^2 + (10-(-5))^2} \approx 15.67$ is the diameter of
$\mathcal{X}$.  The fixed-$\beta$ scheme used in the code is not the standard
decaying step, so convergence may be slower or oscillatory near the optimum.

\subsection{Frank--Wolfe Gap and Rate Analysis}

The \emph{Frank--Wolfe gap} at iterate $x_k$ is:
\begin{equation}
  g_k \triangleq \nabla f(x_k)^T (x_k - z_k) \;\geq\; 0,
\end{equation}
where $z_k$ is the LP solution.  The gap satisfies $g_k \geq f(x_k) - f^\star$ for
convex $f$ (since $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$ and
$f(z^\star) \geq f(x_k) + \nabla f(x_k)^T(z^\star - x_k) \geq f(x_k) - g_k$).
Thus $g_k = 0$ is a \emph{certificate of optimality}: when the gradient is
orthogonal to all directions within $\mathcal{X}$, $x_k$ is optimal.

For the interior case with $f(x) = (x_1-1)^2 + (x_2-5)^2$, $L = 2$, and diameter
$D \approx 15.67$, the standard-step bound gives:
\[
  f(x_k) - f^\star \;\leq\; \frac{2 \cdot 2 \cdot 15.67^2}{k+2} \;\approx\; \frac{980}{k+2}.
\]
To achieve $f(x_k) - f^\star \leq 0.005$ (the observed $\beta=0.985$ result),
the standard step requires $k \geq 980/0.005 - 2 \approx 195{,}998$ iterations.
The fixed-$\beta$ scheme achieves this in only 180 iterations by exploiting the
interior structure (the unconstrained minimum is inside $\mathcal{X}$), far
outperforming the conservative worst-case bound.

\subsection{Interior vs.\ Boundary Behaviour}

\textbf{Interior optimum:}
Frank--Wolfe converges to the interior minimum, but exhibits the characteristic
``zig-zag'' behaviour: at each step, $z_k$ jumps to an extreme vertex of $\mathcal{X}$
(determined by the current gradient sign), and the convex combination averages these
jumps.  Near the interior optimum $x^\star = (1,5)$, the gradient
$\nabla f(x^\star) = [0, 0]^T$ is zero, so the LMO $z_k = \arg\min_{z \in \mathcal{X}}
\nabla f(x_k)^T z$ is dominated by gradient noise near convergence.
The fixed-$\beta$ schedule prevents the algorithm from reducing step size near the
optimum, causing residual oscillation that the standard decaying-step scheme avoids.

\textbf{Boundary optimum:}
Frank--Wolfe is theoretically well-suited to boundary optima: the LMO naturally
selects the vertex $(0.5, \cdot)$ once $(\nabla f)_1 > 0$ (i.e., once $x_1 > 0$,
which is always the case since $x_1 \geq 0.5$).
For $f(x) = x_1^2 + x_2^2$, $\nabla f(x) = (2x_1, 2x_2)$, so $(\nabla f)_1 > 0$
always, meaning $(z_k)_1 = 0.5$ at every step.  Similarly, when $x_2 > 0$,
$(z_k)_2 = -5$; this is why $x_2$ decreases in Figure~\ref{fig:q6_evolution}.
The iterate converges towards $(0.5, 0)$ but the fixed $\beta = 0.93$ gives
$(1-\beta) = 0.07$ fraction per step towards the LP vertex, yielding geometric
convergence to the boundary but with a constant residual from the $-5$ vertex
when $x_2 < 0$.  Using the standard decaying $\gamma_k = 2/(k+2)$ step would
avoid this asymptotic bias.

\textbf{Comparison:}
The interior optimum case converges faster in terms of final objective value
(residual gap $\approx 0.005$ vs.\ $0.11$) because the gradient direction near
$(1, 5)$ is small and approximately consistent, making the LMO select near-identical
vertices over successive iterations, so the convex combination converges smoothly.
The boundary case involves stronger, more consistent gradient forces, but the fixed
step size does not adapt, causing a persistent gap above $f^\star = 0.25$.
In both cases, Frank--Wolfe's \emph{projection-free} property is its key practical
advantage: no oracle for $\Pi_\mathcal{X}$ is needed, and each iterate is trivially
feasible as a convex combination of feasible points.

\textbf{Key cross-cutting conclusions:}

\begin{enumerate}
\item \textbf{Problem structure determines algorithm performance.}
  On the well-conditioned quadratic Benchmark A, virtually all first-order methods
  converge to the same accuracy; differences are mainly in speed.  On the
  ill-conditioned Rosenbrock, the gap between methods is dramatic: Newton's method and
  Nesterov acceleration excel, while vanilla GD barely moves along the valley.

\item \textbf{Second-order methods provide the fastest convergence} when the Hessian
  is affordable.  Newton's method converges in one step on the quadratic, and in
  $\sim$3 steps on the mildly nonlinear Benchmark B.  Its limitation is the $O(d^3)$
  Hessian cost, which makes it infeasible for large-scale problems.

\item \textbf{Nesterov acceleration achieves the theoretically optimal first-order rate}
  ($O(1/k^2)$ vs.\ $O(1/k)$ for GD) and is the best first-order method on all
  benchmarks.  Its lookahead gradient correction is the key innovation distinguishing
  it from Heavy Ball.

\item \textbf{Adaptive methods (Adagrad, RMSprop, Adam) are robust and practical.}
  They automatically adjust the step size per coordinate, removing the need for careful
  global learning rate tuning on anisotropic problems.  Adam, combining momentum and
  adaptive scaling, is the de-facto standard for deep learning.

\item \textbf{The Polyak step size requires exact knowledge of $f^\star$}, which is
  rarely available in practice.  When $f^\star$ is known (Rosenbrock), it converges
  fastest among Q1 methods; when misspecified, it diverges.

\item \textbf{Derivative-free methods are necessary when gradients are unavailable} but
  converge slowly.  Nelder--Mead is effective in low dimensions; Nesterov random search
  scales to high dimensions at the cost of high gradient variance.

\item \textbf{Constraint handling:} Projected GD provides the strongest guarantee --
  hard feasibility at every iteration -- at the cost of requiring a projection oracle.
  Penalty methods are simpler but enforce feasibility only approximately, with accuracy
  increasing as $\lambda \to \infty$ at the cost of increasing stiffness.
  Frank--Wolfe handles linear constraints projection-free, with a natural bias towards
  sparse solutions (vertices of $\mathcal{X}$).

\item \textbf{Batch size and noise trade-offs in SGD} reflect the bias-variance
  decomposition: smaller batches provide more updates per epoch (lower bias, higher
  variance); larger batches provide cleaner gradients but fewer updates.  Under high
  observation noise, the dominant noise source shifts from mini-batch sampling to the
  irreducible Bayes error, reducing the relative advantage of small batches.
\end{enumerate}

The experimental results confirm the theoretical predictions for each method:
Newton's quadratic convergence, Nesterov's $O(1/k^2)$ acceleration,
Adagrad's monotone step decay, RMSprop's stationary effective step,
Frank--Wolfe's $O(1/k)$ sublinear rate, and Polyak's sensitivity to $f^\star$.
Together, these results provide a comprehensive empirical and theoretical picture of
modern first- and second-order optimisation for data analysis.

\textbf{Limitations of this study.}
All experiments use $d = 2$, so the curse of dimensionality is not observed.
In high dimensions: (a) Newton becomes infeasible ($O(d^3)$ Hessian);
(b) grid search is catastrophically expensive ($O(N^d)$);
(c) Nelder--Mead stagnates due to its $O(d+1)$ simplex;
(d) Nesterov random search's $O(d/k)$ rate becomes attractive.
Furthermore, all benchmarks are deterministic; stochastic settings (where gradients
are noisy) favour SGD-based methods and reduce the advantage of second-order information.
The hyperparameters used throughout were tuned for these specific benchmarks and
should not be applied directly to new problems without re-tuning.

\begin{lstlisting}[caption={Gradient Descent}]
def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient)}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
