\begin{abstract}
This report presents a comprehensive comparative study of optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark A), a nonlinear toy neural-network loss with sinusoidal perturbation (Benchmark B), and the ill-conditioned Rosenbrock function (Benchmark C). Six families of methods are investigated: (1)~adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball), (2)~momentum and stochastic methods (Nesterov acceleration, Adam, mini-batch SGD), (3)~Newton's method via second-order local approximation, (4)~derivative-free and derivative-approximation methods (finite differences, Nesterov random search, Nelder--Mead simplex, grid search), (5)~constrained optimisation via projected gradient descent and penalty methods, and (6)~the Frank--Wolfe conditional gradient algorithm for linear-constrained problems. Key findings include: the Polyak step size is highly sensitive to $f^\star$ specification and diverges when $f^\star$ is misspecified; Nesterov's lookahead achieves an $O(1/k^2)$ rate versus GD's $O(1/k)$ on smooth convex problems; Newton's method converges in a single iteration for pure quadratics and exhibits local quadratic convergence; and Frank--Wolfe naturally enforces feasibility through convex combinations at a rate of $O(1/k)$ in the Frank--Wolfe gap. All experiments use fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.
\end{abstract}

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. The starting points and benchmark functions are fixed throughout.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \in \mathbb{R}^2, \quad y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a strictly convex quadratic with constant Hessian $H = \frac{1}{m}X^T X \succ 0$. The exact gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$, and the OLS minimiser is $\theta^{\star}_{\mathrm{OLS}} = (X^TX)^{-1}X^Ty$. Due to observation noise $\sigma=1$, the irreducible minimum is $J^{\star} = \frac{\sigma^2}{2} \approx 0.4826$ rather than zero. The condition number of $H$ depends on the data distribution but is $O(1)$ for standard Gaussian features. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Quadratic Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H(x) = \mathrm{diag}(2 - \sin(x_1),\ 10)$. Since $\sin(x_1) \in [-1,1]$, the smallest Hessian eigenvalue satisfies $\lambda_{\min}(H) \in [1, 3]$ and $\lambda_{\max}(H) = 10$, giving a local condition number ranging from approximately 3.3 to 10. The sinusoidal term breaks the pure-quadratic structure, making this a useful proxy for a shallow neural network loss. The minimum lies at approximately $x^\star \approx (0.582, 2.0)$ with $f^{\star} \approx 0.7244$; here $x_1^\star$ satisfies $2(x_1-1)+\cos(x_1)=0$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian at the optimum is
\begin{equation}
H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues $\lambda_{1,2} = \frac{1002 \pm \sqrt{1002^2 - 4\cdot 400}}{2} \approx 1001.6$ and $0.4$, giving a condition number $\kappa \approx 2504$. This extreme ill-conditioning, combined with a narrow curved valley along $x_2 = x_1^2$, makes the Rosenbrock function one of the most challenging standard test problems for gradient-based methods. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Questions 5 and 6):
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a compact convex polytope (box constraint), for which projection and linear minimisation both decompose independently over coordinates.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}
\label{subsec:q1_theory}

Constant step-size gradient descent $x_{k+1} = x_k - \alpha \nabla f(x_k)$ requires careful selection of $\alpha$: too large causes divergence, too small causes slow convergence. For an $L$-smooth function ($\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$), stability requires $\alpha \leq 1/L$. Adaptive methods remove this global requirement by computing a different effective step size at each iteration.

\textbf{Polyak step size derivation.} From the first-order approximation $f(x - \alpha \nabla f(x)) \approx f(x) - \alpha \|\nabla f(x)\|^2$, choosing $\alpha$ so that the right-hand side equals $f^\star$ gives
\begin{equation}
\alpha_k = \frac{f(x_k) - f^\star}{\|\nabla f(x_k)\|^2 + \varepsilon},
\end{equation}
where $\varepsilon > 0$ prevents division by zero and controls behaviour near the minimum. As shown in the lecture notes, when $f^\star$ is exactly known this rule is derived from requiring $f(x_{k+1}) \approx f^\star$ in one step; it is equivalent to a normalised steepest-descent direction with length proportional to the remaining function value gap. Critically, the quality of the estimate $f^\star$ determines the method's behaviour: using $f^\star < f^\star_{\mathrm{true}}$ (underestimate) leads to conservative steps, while $f^\star > f^\star_{\mathrm{true}}$ (overestimate) causes $f(x_k) - f^\star < 0$, which would produce a negative step size and divergence.

\textbf{Adagrad.} The per-coordinate accumulated gradient sum $G_k \in \mathbb{R}^d$ monotonically increases, causing the effective step $\alpha_0/\sqrt{G_k + \varepsilon}$ to decay to zero over time. This guarantees no oscillation but can slow convergence excessively when the accumulated gradient is large, requiring a correspondingly large base rate $\alpha_0$.

\textbf{RMSprop.} Replaces the accumulation $G_k$ with an exponential moving average $v_k = \beta v_{k-1} + (1-\beta)g_k^2$. For $\beta = 0.9$, the effective memory is approximately $1/(1-\beta) = 10$ iterations, preventing the step size from decaying to zero over long runs. As $\beta \to 0$, RMSprop approaches Adagrad; as $\beta \to 1$, it approaches a constant step.

\textbf{Heavy Ball.} The step $z_{k+1} = \beta z_k + \alpha \nabla f(x_k)$ is a geometric series of past gradients: $z_{k+1} = \sum_{j=0}^{k} \beta^{k-j} \alpha \nabla f(x_j)$. Since $\sum_{j=0}^\infty \beta^j = 1/(1-\beta)$, the effective step size is scaled by a factor of approximately $1/(1-\beta)$ compared to vanilla GD. For $\beta = 0.9$, this gives an effective multiplier of 10$\alpha$ in the direction of consistent past gradients.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\textbf{Key finding:} The Polyak step size is highly sensitive to the accuracy of $f^{\star}$. When the specified $f^{\star} = 0$ deviates from the true minimum (Benchmarks A and B), the method diverges because the step $\alpha_k = f(x_k)/(\|\nabla f(x_k)\|^2 + \varepsilon) \to \infty$ as $\|\nabla f\| \to 0$ while $f(x_k) \to f^{\star}_{\mathrm{true}} > 0$. This is an example of a ``noise floor'' problem: when optimising an empirical risk with irreducible noise, using $f^\star = 0$ is incorrect even if the function has a global minimum of zero in the population sense. A practical remedy is to use an online estimate of $f^\star$ from recent function values, or to place an upper bound on $\alpha_k$.

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest (Rosenbrock: $f = 0.0094$) because each step is optimally sized to close the remaining gap. Otherwise, Adagrad and Heavy Ball match or exceed GD performance.
\item \textbf{Smoothness:} RMSprop produces the smoothest convergence curves due to exponential averaging of gradient magnitudes, which prevents sudden step-size changes. Heavy Ball shows characteristic initial overshoot followed by damped oscillation, arising from the inertia accumulated in $z_k$.
\item \textbf{Stability:} GD baseline is most stable but slowest. Polyak is \emph{unstable} when $f^\star$ is misspecified as a value lower than the true minimum. Adagrad is uniformly stable due to its monotonically decreasing step size, though this guarantee comes at the cost of premature deceleration on long-horizon optimisation.
\item \textbf{Practical implication:} In practice, exact $f^\star$ is rarely known, limiting Polyak's applicability. For machine learning problems with a noise floor (empirical risk minimisation), Adagrad and RMSprop are more robust. Heavy Ball is particularly effective when gradients are persistent in one direction, as on the Rosenbrock valley floor.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}
\label{subsec:q2_theory}

\textbf{Nesterov's optimal rate.} For smooth convex functions with Lipschitz gradient ($L$-smooth), vanilla GD achieves the $O(1/k)$ rate $f(x_k) - f^\star \leq O(L\|x_0 - x^\star\|^2/k)$. Nesterov's method achieves the optimal $O(1/k^2)$ rate $f(x_k) - f^\star \leq O(L\|x_0 - x^\star\|^2/k^2)$ by exploiting the lookahead gradient $\nabla f(x_k + \beta_k z_k)$ evaluated at a predicted future position. The adaptive momentum schedule $\beta_k = (k-1)/(k+2)$ (starting at 0 and increasing towards 1) is precisely what ensures the $O(1/k^2)$ guarantee; a fixed $\beta$ as in Heavy Ball does not carry this theoretical guarantee for general smooth convex functions.

\textbf{Adam as RMSprop + Heavy Ball.} Adam combines: (i) a first-moment estimate $m_t$ that acts as a momentum term (Heavy Ball component), and (ii) a second-moment estimate $v_t$ used for per-coordinate step scaling (RMSprop component). The bias-correction factors $1/(1-\beta_1^t)$ and $1/(1-\beta_2^t)$ correct for the initialisation at zero, which otherwise causes the early estimates to be biased towards zero. This is particularly important in the first few iterations when $\beta_1^t$ and $\beta_2^t$ are still significantly less than 1.

\textbf{Stochastic gradient convergence.} For mini-batch SGD on strongly convex objectives, the convergence rate with step size $\alpha$ is $\mathbb{E}[J(\theta_k) - J^\star] \leq O(e^{-k\alpha\mu} + \alpha\sigma^2)$, where $\mu$ is the strong convexity constant and $\sigma^2$ is the stochastic gradient variance. This reveals a fundamental trade-off: the first term (exponential decay) is controlled by making $\alpha$ large, but the second term (noise floor) increases with $\alpha$. Larger batch sizes reduce $\sigma^2$ (since averaging over $b$ samples reduces variance by $1/b$), enabling larger learning rates and lower final loss.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Momentum update at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$, allowing the method to ``correct'' its direction before applying momentum. Since $\tilde{x}_k \approx x_{k+1}$ when $\alpha \approx 0$, this can be interpreted as a gradient step from a one-step momentum extrapolation of the current position. The adaptive schedule $\beta_k = (k-1)/(k+2) \to 1$ as $k \to \infty$ enables the $O(1/k^2)$ convergence rate.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (momentum)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (RMSprop)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$, \quad $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$ \Comment{Bias correction}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient with variance $\propto 1/b$}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

Each epoch with batch size $b$ performs $m/b$ gradient updates. For $b=5$: 200 updates/epoch; for $b=40$: 25 updates/epoch. The mini-batch gradient $g$ is an unbiased estimator of $\nabla J(\theta)$ with variance $\sigma^2_g = \mathrm{Var}[g] \propto \sigma^2/b$, where $\sigma^2$ is the data noise variance.

\subsection{Local Approximations of $g(x) = x^4$}
\label{subsec:q3_approx}

Around $x_0 = 0.25$, we have $g(x_0) = 0.0039$, $g'(x_0) = 4x_0^3 = 0.0625$, $g''(x_0) = 12x_0^2 = 0.75$.

\textbf{First-order (Taylor) approximation:}
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}
This linear model captures only the local slope. Minimising it gives $x \to -\infty$ (unbounded), so gradient descent alone cannot locate a minimum without a step-size constraint.

\textbf{Second-order approximation:}
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises this local quadratic model by setting its derivative to zero: $g'(x_0) + g''(x_0)(x - x_0) = 0$, yielding
\begin{equation}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)}.
\end{equation}
For $g(x) = x^4$: $x_{k+1} = x_k - \frac{4x_k^3}{12x_k^2} = x_k - \frac{x_k}{3} = \frac{2x_k}{3}$, a contraction with rate $2/3 < 1$. Near the true minimum $x^\star = 0$, Newton's method converges quadratically: $|x_{k+1}| = |2x_k/3| \leq C|x_k|^2$ only holds if the Hessian is well-conditioned near the minimum. For $g = x^4$ the Hessian vanishes at $x^\star = 0$ (degenerate), so the convergence is actually linear with rate $2/3$; quadratic Newton convergence requires $g''(x^\star) \neq 0$ (non-degenerate minimum).

\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}

The second-order approximation (parabola) fits well in a neighbourhood of $x_0$, motivating Newton's method: stepping to the minimum of the local parabola provides a much better estimate of the global minimum direction than a pure gradient step, especially when the function is nearly quadratic.}

\subsection{Newton's Method on Benchmark Problems}

\begin{algorithm}[H]
\caption{Newton's Method with Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \leq 1$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{$\alpha = 1$ is pure Newton; $\alpha < 1$ is damped}
\EndFor
\end{algorithmic}
\end{algorithm}

The damping term $\lambda I$ ensures $H_k$ is positive definite (invertible) even when the true Hessian is ill-conditioned. For $\lambda = 10^{-8}$ as used here, this is negligible for well-conditioned problems but prevents numerical failure. The step factor $\alpha < 1$ (damped Newton) is necessary when the Hessian changes rapidly between $x_k$ and $x_{k+1}$, as on the Rosenbrock function.

\textbf{Newton convergence theory.} For a strongly convex, twice-differentiable function with Lipschitz Hessian (i.e., $\|\nabla^2 f(x) - \nabla^2 f(y)\| \leq M\|x-y\|$), Newton's method with $\alpha = 1$ satisfies \emph{quadratic convergence} in a neighbourhood of $x^\star$:
\begin{equation}
\|x_{k+1} - x^\star\| \leq \frac{M}{2\mu} \|x_k - x^\star\|^2,
\end{equation}
where $\mu > 0$ is the strong convexity constant. This means the number of accurate digits roughly doubles at each iteration, as opposed to the linear convergence $\|x_{k+1} - x^\star\| \leq (1 - \mu/L)\|x_k - x^\star\|$ of gradient descent.

\subsection{Why Newton Outperforms GD}

Newton's method solves the system $H_k p_k = \nabla f(x_k)$ at each iteration, effectively rescaling the gradient by the inverse Hessian. This pre-conditioning:
\begin{enumerate}[nosep]
  \item Removes the dependence on the condition number $\kappa$ from the convergence rate: GD converges at rate $((\kappa-1)/(\kappa+1))^2$ per step, while Newton in the local quadratic-convergence regime converges independently of $\kappa$.
  \item Provides an adaptive step size per direction: large steps in flat directions, small steps in steep directions, automatically without tuning.
  \item Costs $O(d^3)$ per iteration (Hessian inversion) vs.\ $O(d)$ for GD, making it suitable only when $d$ is small or when iterations are very expensive.
\end{enumerate}

\subsection{Part A: Finite Difference Approximation and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\end{equation}
where $e_i$ is the $i$-th standard basis vector. The approximation error has two components:
\begin{equation}
\text{Error} = \underbrace{\frac{\delta}{2} \frac{\partial^2 f}{\partial x_i^2}(x)}_{\text{truncation: } O(\delta)} + \underbrace{\frac{2\varepsilon_{\mathrm{mach}}}{\delta} \|f\|}_{\text{roundoff: } O(\varepsilon_{\mathrm{mach}}/\delta)}.
\end{equation}
Balancing these terms gives the optimal step $\delta^\star = O(\sqrt{\varepsilon_{\mathrm{mach}}}) \approx 10^{-8}$ for double precision. The assignment tests $\delta = 0.05$ (near-optimal for the given function scale: truncation error $\sim$small, roundoff negligible) and $\delta = 0.8$ (excessive truncation: the step spans a region where the second derivative $\partial^2 f/\partial x_i^2$ contributes $O(0.8/2) \cdot \max |f''| \approx O(1)$ error, corrupting the gradient direction). Both use learning rate $\alpha = 0.08$; exact GD uses $\alpha = 0.06$.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha = 0.025$, perturbation $\delta = 0.08$, iterations $N = 220$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Random unit vector}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates a directional derivative along a random direction $u_k$, requiring only \emph{two} function evaluations per iteration regardless of dimension $d$. The expected update direction satisfies $\mathbb{E}[\hat{g}_k | x_k] = \nabla f(x_k) + O(\delta)$, so the method is an unbiased stochastic gradient estimator in the limit $\delta \to 0$. However, the variance of $\hat{g}_k$ is $O(\|\nabla f\|^2/(d))$ per component (the projection onto a random unit vector), making convergence $\sqrt{d}$ times slower per iteration than exact GD in $d$ dimensions. This ``dimension penalty'' is the fundamental cost of avoiding gradient computation.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$, iteratively transforming it through four operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1$): Move the worst vertex $x_w$ through the centroid $\bar{x}$ of the remaining vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x_w)$.
\item \textbf{Expansion} ($\gamma = 2$): If reflection improved, try $x_e = \bar{x} + \gamma(\bar{x} - x_w)$.
\item \textbf{Contraction} ($\rho = 0.5$): If reflection worsened, contract: $x_c = \bar{x} \pm \rho(\cdot - \bar{x})$.
\item \textbf{Shrink} ($\sigma = 0.5$): Contract all vertices towards the best: $x_i \gets x_1 + \sigma(x_i - x_1)$.
\end{enumerate}
No gradient information is required. The method is applicable to non-smooth, noisy, or black-box objectives but has no convergence guarantees in dimensions $d > 1$ in general.

The Nesterov random search has the smallest per-iteration cost (2 function evaluations regardless of $d$), but to achieve $\varepsilon$-accuracy requires $O(d/\varepsilon^2)$ iterations due to the directional projection variance, so the total cost scales linearly with $d$. For the 2D problems here, exact gradient computation is inexpensive, making FD GD with $d+1=3$ evaluations per step the natural derivative approximation choice.

\subsection{Problem Setup and Theory}

Minimise Benchmark B subject to the half-space constraint $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$. Since the unconstrained minimum of $f_B$ is at $(0.582, 2.0)$ and $0.582 > 0.5$, the constraint is \emph{inactive} at the unconstrained solution. However, starting from an infeasible point requires the algorithm to first achieve feasibility.

\textbf{Projected gradient convergence.} For a closed convex constraint set $\mathcal{X}$ and an $L$-smooth, $\mu$-strongly convex objective, projected GD satisfies $f(x_k) - f^\star \leq O(e^{-k\mu/L}(f(x_0) - f^\star))$, i.e., linear convergence, and maintains $x_k \in \mathcal{X}$ at all times.

\textbf{Penalty method analysis.} The penalised objective $F_\lambda(x) = f(x) + \lambda \max(0, 0.5 - x_1)$ has unconstrained minimiser $x^\star(\lambda)$ that satisfies the KKT condition approximately: $\nabla f(x^\star(\lambda)) = \lambda \cdot \mathbf{1}_{x_1 < 0.5} e_1$, with constraint violation $\max(0, 0.5 - x_1^\star(\lambda)) \leq \|\nabla f(x^\star_\mathrm{constrained})\|/\lambda = O(1/\lambda)$. Thus larger $\lambda$ drives the solution closer to the feasible region but also makes the objective less smooth (larger Lipschitz constant), requiring smaller step sizes.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0 = (0.2, 4.0)$, step size $\alpha = 0.08$, iterations 100
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$, where $[\Pi_{\mathcal{X}}(z)]_1 = \max(0.5,\, z_1)$, $[\Pi_{\mathcal{X}}(z)]_2 = z_2$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0 = (0.2, 4.0)$, step size $\alpha$, penalty weight $\lambda$, iterations 100
\For{$k = 0, 1, \ldots, N-1$}
    \State $\nabla F_\lambda(x_k) \gets \nabla f(x_k) - \lambda \cdot \mathbf{1}[x_{k,1} < 0.5]\, e_1$ \Comment{Subgradient of penalty}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_\lambda(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\textbf{Projected GD} enforces feasibility as a hard, non-negotiable constraint at every iteration via the projection operator. \textbf{Penalty methods} require no projection but introduce a soft feasibility enforcement. In the limit $\lambda \to \infty$, the penalty method approaches the constrained solution but requires an infinitesimal step size. Augmented Lagrangian or sequential quadratic programming methods address this by combining penalty with dual variable updates, avoiding this degeneracy.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Fundamental theorem of linear programming.} The optimal solution of a linear objective $f(x) = a^T x$ over a bounded convex polytope $\mathcal{X}$ is always attained at a \emph{vertex} (extreme point) of $\mathcal{X}$. This follows from the fact that $f$ is both convex and concave, so any interior local minimum would require $\nabla f = a = 0$, which contradicts $a \neq 0$. The global minimum is thus achieved at a vertex, and can be found by evaluating $f$ at all $2^d$ vertices for a box constraint or by the simplex algorithm in general.

For $f(x) = a^T x$ with $a = [1, 2]^T$, minimising over $\mathcal{X}$ decomposes per coordinate since both bounds and the objective are separable. Since $a_1 = 1 > 0$ and $a_2 = 2 > 0$, both coordinates prefer their lower bounds:
\begin{equation}
x^{\star} = (0.5,\, -5), \qquad f^{\star} = 1 \cdot 0.5 + 2 \cdot (-5) = -9.5.
\end{equation}

\subsection{Frank--Wolfe Algorithm: Theory and Implementation}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{LP subproblem: linear minimisation oracle}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: stays in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

For the box $\mathcal{X}$, the LP subproblem decomposes per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
requiring only $O(d)$ operations --- no matrix computation needed. This is the defining advantage of Frank--Wolfe over projected gradient descent: the linear oracle replaces the (potentially expensive) projection with a cheap LP.

\textbf{Convergence theory.} The Frank--Wolfe gap (also called the duality gap) at iterate $x_k$ is
\begin{equation}
g_k = \max_{s \in \mathcal{X}} \nabla f(x_k)^T (x_k - s) = \nabla f(x_k)^T(x_k - z_k).
\end{equation}
This quantity $g_k \geq 0$ is a computable certificate of near-optimality: $g_k = 0$ implies $x_k$ is optimal. For smooth convex $f$ with Lipschitz gradient, Frank--Wolfe with the standard step schedule $\gamma_k = 2/(k+2)$ achieves $g_k \leq O(C/k)$, i.e., $O(1/k)$ convergence in the duality gap. The fixed-$\beta$ variant used here (with step size $(1-\beta)$) does not have the $O(1/k)$ guarantee and may converge slower.

\textbf{Key property.} Since $x_{k+1} = \beta x_k + (1-\beta) z_k$ is a convex combination of two feasible points ($x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$), the iterate always remains in $\mathcal{X}$ --- feasibility is maintained for free without any projection step.

\subsection{Interior vs.\ Boundary Behaviour}

\textbf{Interior optimum.} Frank--Wolfe exhibits a characteristic ``zig-zag'' pattern near interior optima because the LP oracle $z_k$ jumps to a vertex of $\mathcal{X}$ that is aligned with the gradient direction, which alternates from step to step. The iterates converge as a weighted average of these vertex jumps, but the convergence is limited to the $O(1/k)$ Frank--Wolfe rate. Smaller $\beta$ (larger steps) amplifies the oscillation but also makes faster initial progress; the optimal $\beta$ balances these effects. For interior optima, projected gradient descent is generally preferred as it can exploit the unconstrained structure once the iterate is in the interior.

\textbf{Boundary optimum.} Frank--Wolfe is better suited to boundary optima: when the unconstrained minimiser lies outside $\mathcal{X}$, the LP vertex $z_k$ consistently selects the closest boundary point (here $x_1 = 0.5$), guiding the iterate towards the constrained optimum without oscillation. The convergence is limited because the fixed $\beta$ schedule does not decay: the standard Frank--Wolfe step schedule $\gamma_k = 2/(k+2)$ would give the $O(1/k)$ duality gap guarantee and improve results.

\textbf{Comparison:} Frank--Wolfe's main advantages over projected GD are: (1) no projection required (only a cheap LP oracle); (2) iterates automatically maintain feasibility as convex combinations of feasible points; (3) the LP oracle can exploit structure of $\mathcal{X}$ (e.g., sparsity). Its main disadvantages are: (1) the $O(1/k)$ rate is slower than projected GD's $O(1/k)$ with the same constant (due to vertex jumping); (2) for interior optima, convergence is slower than unconstrained optimisation.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has investigated six families of optimisation algorithms across three benchmark problems of increasing difficulty.

\textbf{Adaptive step-size methods (Q1):} The Polyak step size is theoretically elegant but brittle in practice --- its performance is entirely contingent on accurate knowledge of $f^\star$. Adagrad provides robust, coordinate-adaptive step sizes but its monotonically decaying effective rate can prematurely stall convergence. RMSprop's exponential forgetting resolves Adagrad's stalling at the cost of an additional hyperparameter $\beta$. Heavy Ball effectively scales the learning rate by $1/(1-\beta)$ in the direction of persistent gradients, making it efficient on functions with consistent gradient directions (e.g., the Rosenbrock valley floor).

\textbf{Momentum methods (Q2):} Nesterov's lookahead gradient evaluation achieves the theoretically optimal $O(1/k^2)$ convergence rate for smooth convex functions, translating to substantial practical advantages on the Rosenbrock function (7$\times$ improvement over GD). Adam (RMSprop + Heavy Ball) offers robustness through combined per-coordinate scaling and momentum, particularly on anisotropic problems, but does not match Nesterov on highly nonlinear problems. Mini-batch SGD's performance is governed by the trade-off between gradient variance (reduced by larger batches) and update frequency (increased by smaller batches).

\textbf{Newton's method (Q3):} Newton's method achieves quadratic local convergence by using second-order information. For the quadratic loss (Q3, Benchmark A), this reduces to \emph{one-step exact convergence}. The method requires computing and inverting the Hessian ($O(d^3)$ cost), making it unsuitable for large-scale problems but extremely powerful for the small-dimensional benchmarks studied here.

\textbf{Derivative-free methods (Q4):} Finite differences with appropriate step size $\delta$ closely replicate exact GD at the cost of $d+1$ function evaluations per step. Excessive $\delta$ corrupts the gradient direction. Nesterov random search avoids gradient computation entirely (2 evaluations/step) but converges slowly in $d$ dimensions. Nelder--Mead adapts its simplex to the landscape without any derivative information, achieving competitive performance in 2D.

\textbf{Constrained optimisation (Q5):} Projected gradient descent enforces feasibility as a hard constraint at every iteration, achieving the same convergence rate as unconstrained GD within the feasible region. Penalty methods provide a simpler implementation but only approach feasibility asymptotically, with a fundamental trade-off between penalty weight and step-size stability.

\textbf{Frank--Wolfe (Q6):} The algorithm maintains feasibility via convex combinations and solves a cheap LP subproblem instead of projecting. It achieves an $O(1/k)$ convergence rate in the duality gap and is particularly well-suited to problems where the optimum lies on the constraint boundary. For interior optima, the vertex-jumping behaviour limits practical convergence speed.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad (per-coordinate accumulation)}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)  # Accumulated squared gradients
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop (exponential moving average of squared gradients)}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)  # Exponential moving average
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)  # Momentum buffer
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum (lookahead gradient)}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)  # Adaptive schedule
        lookahead = x + beta_k * z  # Predicted next position
        g = grad_fn(lookahead)      # Gradient at lookahead
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser (bias-corrected first and second moments)}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g          # First moment
        v_vec = beta2 * v_vec + (1 - beta2) * g**2       # Second moment
        m_hat = m_vec / (1 - beta1**t)                    # Bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Tikhonov regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))  # Ensure positive definiteness
        try:
            p = np.linalg.solve(H_reg, g)     # Newton direction
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient)}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LP oracle: argmin_{z in X} g^T z (decomposable for box)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z  # Convex combination (stays in X)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
