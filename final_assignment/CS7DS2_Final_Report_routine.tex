\begin{abstract}
This report presents a comprehensive comparative study of optimisation algorithms across six question areas for the CS7DS2 Final Assignment. Three benchmark problems are employed: a linear regression quadratic loss (Benchmark A), a perturbed quadratic function modelling toy neural network loss (Benchmark B), and the ill-conditioned Rosenbrock function (Benchmark C). The methods investigated span six categories: (1)~adaptive step-size methods --- Polyak, Adagrad, RMSprop, and Heavy Ball; (2)~momentum-based and stochastic methods --- Nesterov acceleration, Adam, and mini-batch SGD; (3)~Newton's method and local approximations; (4)~derivative-free approaches --- finite differences, Nesterov random search, Nelder--Mead simplex, and grid search; (5)~constrained optimisation via projected gradient descent and penalty methods; and (6)~the Frank--Wolfe conditional gradient algorithm for linear-constrained problems. Each method is evaluated with respect to convergence speed, trajectory behaviour, numerical stability, and computational trade-offs. Key findings include: the Polyak step is highly sensitive to $f^{\star}$ specification; Nesterov momentum achieves the theoretically optimal $O(1/k^2)$ convergence rate; Newton's method converges in one step on quadratic objectives; and Frank--Wolfe converges at $O(1/k)$ without requiring a projection oracle.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation is the backbone of modern machine learning: virtually every model is trained by minimising some loss function. The choice of optimisation algorithm significantly impacts convergence speed, solution quality, and computational cost. This report systematically examines algorithms drawn from six distinct paradigms, evaluated across three canonical benchmark functions of increasing difficulty.

\textbf{Scope.} The six questions address: (Q1) adaptive step-size computation without a fixed learning rate schedule; (Q2) momentum-based acceleration and stochastic variants; (Q3) second-order methods exploiting local curvature via the Hessian; (Q4) gradient-free methods for black-box or non-differentiable objectives; (Q5) constrained optimisation via feasibility enforcement or penalisation; and (Q6) projection-free methods for linearly-constrained convex problems.

\textbf{Benchmarks.} The three benchmark functions are chosen to reflect different curvature properties. Benchmark A (linear regression MSE) is a globally convex quadratic with analytically known minimiser. Benchmark B (perturbed quadratic) introduces mild non-linearity via a sinusoidal term, creating moderate anisotropy with curvature ratio approximately $5\!:\!1$. Benchmark C (Rosenbrock) is a notoriously challenging non-convex function with extreme ill-conditioning ($\kappa \approx 2508$ at the optimum) and a narrow curved valley, serving as a stress test for any first-order method.

\textbf{Implementation.} All experiments use a fixed random seed (\texttt{np.random.seed(42)}) and are implemented in Python with NumPy. Figures are produced with Matplotlib. The complete source code is provided in \texttt{CS7DS2\_Final\_Code\_25336453.py} and reproduced in Appendix~\ref{app:code}.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a convex quadratic with constant Hessian $H = \frac{1}{m}X^T X \succ 0$. The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The unique minimiser is the OLS solution $\theta^{\star}_{\mathrm{OLS}} = (X^TX)^{-1}X^Ty \approx (3.028, 4.017)^T$. Due to the observation noise, the minimum loss is $J^{\star} \approx 0.4826 \neq 0$. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f_B(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f_B = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H = \mathrm{diag}(2 - \sin(x_1),\ 10)$. The diagonal structure means the two coordinates are decoupled, while the non-constant $(1,1)$ entry introduces mild non-convexity. The eigenvalue ratio varies between approximately $1.2\!:\!10$ and $3\!:\!10$, creating moderate anisotropy. The global minimum lies at approximately $(0.582, 2.0)$ with $f^{\star}_B \approx 0.7244$, obtained by solving $2(x_1-1) + \cos(x_1) = 0$ numerically. Starting point: $x_0 = [-1, 4]^T$ (far from the minimum, with $f_B(x_0) \approx 23.16$).

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f_C(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star}_C = 0$. The Hessian at the optimum is
\begin{equation}
H_C(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues $\lambda_{\min} \approx 0.40$ and $\lambda_{\max} \approx 1001.6$, yielding condition number $\kappa \approx 2508$. This extreme ill-conditioning, combined with the narrow curved valley along $x_2 = x_1^2$, renders Rosenbrock one of the most challenging standard test functions for gradient-based methods. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Q5--Q6): $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

A fundamental challenge in gradient descent is choosing the step size $\alpha$. A fixed step size requires knowledge of the Lipschitz constant $L$ of the gradient; too large a step diverges, while too small a step converges very slowly. Adaptive methods overcome this by computing a data-driven step at each iteration.

The \textbf{Polyak step} $\alpha_k = (f(x_k) - f^{\star})/\|\nabla f(x_k)\|^2$ minimises the upper bound on the squared distance to the optimum at each step; for convex functions with known $f^{\star}$, it achieves linear convergence on strongly convex problems without requiring knowledge of the strong convexity constant or the Lipschitz constant separately. However, it requires exact knowledge of $f^{\star}$.

\textbf{Adagrad} accumulates per-coordinate squared-gradient sums, effectively giving coordinates with historically large gradients smaller learning rates. Its per-coordinate update rule achieves a cumulative regret bound of $O(\sqrt{T})$ in online learning, corresponding to $O(1/\sqrt{k})$ average convergence. The accumulated sum grows without bound, causing the effective learning rate to decay to zero --- a desirable property for sparse features but problematic for sustained optimisation.

\textbf{RMSprop} replaces the cumulative sum with an exponential moving average ($\beta = 0.9$), preventing the denominator from growing without bound. This allows the effective step size to adapt to recent curvature rather than the full history.

\textbf{Heavy Ball} (Polyak Momentum) adds a momentum term $\beta z_k$ to the gradient update. For a quadratic with eigenvalues $[\lambda_{\min}, \lambda_{\max}]$ and condition number $\kappa = \lambda_{\max}/\lambda_{\min}$, the optimal parameters are
\begin{equation}
\alpha^{\star} = \frac{4}{(\sqrt{\lambda_{\max}} + \sqrt{\lambda_{\min}})^2}, \qquad \beta^{\star} = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2,
\end{equation}
achieving convergence rate $\rho = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$ per step --- substantially faster than plain GD's rate $(\kappa-1)/(\kappa+1)$.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Polyak sensitivity:} The Polyak step achieves the best result when $f^{\star}$ is known exactly (Rosenbrock: $f = 0.024$, best among all methods). When $f^{\star}$ is misspecified --- as in Benchmark A where $f^{\star}_{\mathrm{true}} \approx 0.483 \gg 0$ --- the method diverges severely ($f = 4.767$). For Benchmark B, misspecification causes oscillation near the true minimum ($f = 0.982$ vs $f^{\star} = 0.724$) rather than full divergence, because the step size grows large but the method does not escape the vicinity of the optimum entirely.

\item \textbf{Adagrad robustness:} Adagrad achieves competitive performance across all benchmarks without requiring knowledge of $f^{\star}$. Its $O(\sqrt{T})$ regret bound ensures reliable, monotonically decreasing effective learning rates. The downside is premature slowdown on non-stationary problems and the Rosenbrock valley (where accumulated past gradients reduce the step to essentially zero before the optimum is reached).

\item \textbf{RMSprop smoothness:} RMSprop produces the smoothest convergence curves due to exponential averaging of squared gradients. However, its final accuracy is slightly worse than GD on Benchmark A ($f = 0.506$ vs $0.483$), suggesting the exponential forgetting may cause small oscillations around the minimum that a simpler method avoids.

\item \textbf{Heavy Ball acceleration:} Heavy Ball provides the best gradient-based improvement on Rosenbrock ($f = 1.400$ vs GD's $3.514$) by accumulating momentum along the consistent direction of the valley floor. On the convex benchmarks (A, B), it matches GD's final accuracy with potentially faster early convergence.

\item \textbf{Practical implication:} In practice, exact $f^{\star}$ is rarely known, limiting Polyak's applicability to settings such as strongly convex problems where a lower bound can be computed. RMSprop and Adam (Q2) are more robust choices for general deep learning optimisation.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}

\textbf{Nesterov Acceleration} achieves the \emph{optimal} $O(1/k^2)$ convergence rate for smooth convex functions among all first-order methods --- a fundamental lower bound established by Nemirovski and Yudin. The key innovation is evaluating the gradient at a \emph{lookahead point} $\tilde{x}_k = x_k + \beta_k z_k$ rather than the current iterate $x_k$. This corrective lookahead allows the method to reduce overshoot that afflicts standard momentum. With the schedule $\beta_k = (k-1)/(k+2)$, the iterate satisfies
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2\|x_0 - x^{\star}\|^2}{\alpha(k+1)^2},
\end{equation}
compared to GD's $O(1/k)$ rate. For Benchmark A (quadratic with $\kappa \approx 2$), the theoretical advantage is modest; for Rosenbrock the difference is dramatic.

\textbf{Adam} combines the first moment estimate (momentum, as in Nesterov) with the second moment estimate (per-coordinate adaptive scaling, as in RMSprop). The bias correction factors $(1-\beta_1^t)$ and $(1-\beta_2^t)$ ensure that the moment estimates are unbiased in early iterations (when the exponential averages are initialised to zero). Adam achieves $O(1/\sqrt{T})$ convergence for smooth convex functions with appropriate diminishing learning rates, and is particularly effective on problems with heterogeneous curvature across coordinates.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. The adaptive momentum $\beta_k = \min((k-1)/(k+2), \beta_{\max})$ increases from 0 towards $\beta_{\max}$, initially behaving like gradient descent and gradually accelerating.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (momentum)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (curvature)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) = (0.25)^4 + 4(0.25)^3(x - 0.25) = 0.00391 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order approximation:}
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.00391 + 0.0625(x - 0.25) + 0.1875(x - 0.25)^2.
\end{equation}

The Newton step minimises the second-order model: setting $g'(x_0) + g''(x_0)(x - x_0) = 0$ gives
$x^+ = x_0 - g'(x_0)/g''(x_0) = 0.25 - 0.0625/0.75 = 0.167.$
This is the Newton update $x_{k+1} = x_k - g'(x_k)/g''(x_k)$ --- a step to the stationary point of the local quadratic model.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}
\caption{Q3: Local approximations of $g(x) = x^4$ at $x_0 = 0.25$. The first-order approximation (tangent line) captures only the local slope and deviates rapidly from the true function. The second-order approximation (parabola) captures local curvature and fits accurately in a neighbourhood of $x_0$. The minimum of the parabola (at $x = 0.167$) provides a better estimate of the function's minimum than a gradient step, which only follows the slope. This motivates Newton's method: each iteration finds the exact minimiser of the local quadratic model, then re-fits the model at the new point.}
\label{fig:q3_approx}
\end{figure}

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Newton's Method with Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The \textbf{Newton direction} $p_k = H_k^{-1}g_k$ is the gradient preconditioned by the inverse Hessian, effectively removing the ill-conditioning introduced by anisotropic curvature. The \textbf{damping} $\lambda I$ regularises the Hessian to ensure positive definiteness even when the Hessian is indefinite far from a local minimum (relevant for the Rosenbrock function). The \textbf{step size} $\alpha < 1$ (damped Newton) ensures global progress when the quadratic model is not globally accurate.

\textbf{Convergence theory.} Near a local minimiser $x^{\star}$ where $\nabla^2 f(x^{\star}) \succ 0$, Newton's method converges \emph{quadratically}:
\begin{equation}
\|x_{k+1} - x^{\star}\| \leq C\|x_k - x^{\star}\|^2,
\end{equation}
for some constant $C$ depending on the Lipschitz constant of $\nabla^2 f$. This means once the iterate is close to $x^{\star}$, the number of accurate digits \emph{doubles} per iteration. For a quadratic function, the Hessian is constant, so Newton takes \emph{exactly one step} to the minimiser with $\alpha = 1$.

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping $\lambda = 10^{-8}$.

\subsection{Complexity and Practical Considerations}

Newton's method requires $O(n^2)$ operations to compute the Hessian and $O(n^3)$ to solve the linear system $H_k p_k = g_k$ (via Cholesky or LU decomposition). For the $n=2$ benchmarks used here, this is trivial, but for modern machine learning problems with $n = 10^6$ to $10^9$ parameters, Newton's method is computationally infeasible. This motivates quasi-Newton methods (BFGS, L-BFGS) which approximate $H^{-1}$ without computing it explicitly. The results here illustrate \emph{why} second-order methods are desirable; practical large-scale implementations require Hessian approximations.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}
% ============================================================

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

When the analytical gradient is unavailable (black-box function, non-differentiable objective, or legacy simulation code), the gradient can be approximated numerically. The forward finite-difference approximation replaces each partial derivative:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \qquad e_i \in \mathbb{R}^n \text{ is the $i$-th unit vector.}
\end{equation}

\textbf{Error analysis.} By Taylor's theorem:
\begin{equation}
f(x + \delta e_i) = f(x) + \delta \frac{\partial f}{\partial x_i}(x) + \frac{\delta^2}{2}\frac{\partial^2 f}{\partial x_i^2}(\xi),
\end{equation}
so the \emph{truncation error} is $O(\delta)$. In floating-point arithmetic, $f(x + \delta e_i) - f(x)$ also incurs \emph{cancellation error} of $O(\varepsilon_{\mathrm{mach}}/\delta)$ when $\delta$ is small. Minimising the total error $O(\delta) + O(\varepsilon_{\mathrm{mach}}/\delta)$ yields the optimal step size
\begin{equation}
\delta^{\star} \approx \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8} \quad \text{(for double precision)}.
\end{equation}
In practice, a larger $\delta \in [10^{-5}, 10^{-3}]$ is often used to reduce sensitivity to function noise. The central difference approximation $[f(x+\delta e_i) - f(x-\delta e_i)]/(2\delta)$ has error $O(\delta^2)$ but requires $2n$ function evaluations per gradient.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates the directional derivative along a random unit vector $u_k$, requiring only \emph{two function evaluations per iteration} regardless of dimension $n$. The expected value of $\hat{g}_k$ (over the random direction) satisfies $\mathbb{E}[\hat{g}_k] = \nabla f(x_k)$ for any dimension, but with variance $O(n)$. The convergence rate is $O(1/\sqrt{k})$, the same as SGD, but with higher per-iteration variance than exact gradient methods. The advantage is extreme: on a $d$-dimensional function, FD requires $d+1$ evaluations per gradient, while Nesterov random search requires only 2.

\subsection{Part B: Derivative-Free Methods on Benchmark C}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four operations:
\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move the worst vertex through the centroid of the remaining $n$ vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, extend further in the same direction.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection worsened, contract between centroid and the best candidate.
\item \textbf{Shrink} ($\sigma = 0.5$): if contraction fails, contract all vertices towards the best vertex.
\end{enumerate}
No gradient information is required --- the simplex explores the function landscape purely through function comparisons. Initial simplex step size: $0.35$, for $160$ iterations.

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

\subsection{Problem Setup}

Minimise Benchmark B, $f_B(x) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1)$, subject to $x_1 \geq 0.5$, starting from the \emph{infeasible} initial point $x_0 = (0.2, 4.0)$.

The unconstrained minimiser of $f_B$ is at $x^{\star} \approx (0.582, 2.0)$, satisfying $x_1^{\star} = 0.582 > 0.5$. Therefore, the constraint $x_1 \geq 0.5$ is \emph{inactive} at the optimum: the constrained and unconstrained solutions coincide. This is a non-trivial setup because while the constraint does not bind at the optimum, the starting point is infeasible, so methods must first recover feasibility and then optimise.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda\, \max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty gradient is $\nabla F_{\lambda}(x) = \nabla f(x) + \lambda\, \partial_x[\max(0, 0.5-x_1)]$, where the subdifferential of the penalty is $-\lambda e_1$ when $x_1 < 0.5$ and $0$ otherwise (a non-smooth term).

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\subsection{Discussion}

Since the unconstrained minimum of $f_B$ at $(0.582, 2.0)$ satisfies $x_1^{\star} \approx 0.582 > 0.5$, the constraint is inactive at the optimum. Consequently, all methods ultimately converge to the same final solution with zero constraint violation. The differences are in the \emph{convergence path} and the handling of the infeasible starting point.

\textbf{Projected GD} enforces feasibility immediately at every iteration via the projection $\Pi_{\mathcal{X}}(x) = (\max(0.5, x_1), x_2)$. This is the fundamental advantage: the iterate is always in the feasible set. The cost is requiring a projection oracle --- trivial for box constraints but potentially expensive for complex constraint sets (e.g., semidefinite programmes require projecting onto the cone of positive semidefinite matrices, costing $O(n^3)$).

\textbf{Penalty methods} trade exact feasibility for algorithmic simplicity. Only a modified gradient is needed; no projection is computed. The weight $\lambda$ controls the trade-off: small $\lambda$ is insufficient to discourage constraint violation, while large $\lambda$ enforces it more aggressively but requires smaller step sizes to maintain stability (the penalised objective has a larger Lipschitz constant near the constraint boundary). In this experiment, the inactive constraint means all penalty values ultimately achieve the same solution.

\textbf{Practical note.} For problems where the constraint \emph{is} active at the optimum (e.g., if the unconstrained minimum were at $x_1 = 0.2 < 0.5$), the penalty method would converge to a slightly infeasible point for any finite $\lambda$. In that case, augmented Lagrangian methods or sequential quadratic programming would be required to achieve exact feasibility with finite penalty.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$ (a box / hyperrectangle).

\textbf{Linear Programme.} For $f(x) = a^T x$ with $a = [1, 2]^T$, minimise $f$ over $\mathcal{X}$. Since $f$ is linear, the unconstrained minimum is $-\infty$; over the bounded feasible set, the minimum is attained at a vertex. For a box, the minimisation decomposes per coordinate:
\begin{equation}
x_i^{\star} = \begin{cases} l_i & \text{if } a_i > 0 \\ u_i & \text{if } a_i < 0 \end{cases}, \qquad \text{yielding} \quad x^{\star} = (0.5, -5), \quad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}
This illustrates the \textbf{fundamental theorem of linear programming}: the optimum of a linear objective over a bounded convex polytope is attained at a vertex (an extreme point).

\subsection{Frank--Wolfe Algorithm: Theory}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{z \in \mathcal{X}}\, \nabla f(x_k)^T z$ \Comment{LP subproblem (linear minimisation oracle)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination update}
\EndFor
\end{algorithmic}
\end{algorithm}

The \textbf{Frank--Wolfe gap} provides a computable convergence certificate:
\begin{equation}
G_k := \nabla f(x_k)^T (x_k - z_k) = \max_{z \in \mathcal{X}} \nabla f(x_k)^T (x_k - z) \geq 0.
\end{equation}
At the optimum $x^{\star}$ of a convex function, $G_k = 0$ (since $\nabla f(x^{\star})^T(x^{\star} - z) \leq 0$ for all feasible $z$). Thus $G_k$ measures progress towards optimality without requiring knowledge of $f^{\star}$.

\textbf{Convergence theorem.} For a smooth convex $f$ (gradient Lipschitz with constant $L$) and using the standard step size $\gamma_k = 2/(k+2)$:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L\,\mathrm{diam}(\mathcal{X})^2}{k+2} = O(1/k).
\end{equation}
The present experiments use a fixed mixing parameter $\beta$ (constant step size) rather than the decaying schedule $\gamma_k = 1 - \beta$, which corresponds to the choice $1-\beta = 2/(k+2)$ only at $k = 0$. The fixed $\beta$ does not provably achieve $O(1/k)$ convergence but is simple to implement.

\textbf{Key advantage.} Frank--Wolfe never requires a projection onto $\mathcal{X}$: iterates are always convex combinations of feasible points (LP vertices), hence automatically feasible. The LP subproblem over a box decomposes per coordinate in $O(d)$ operations.

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum.} Frank--Wolfe exhibits the characteristic $O(1/k)$ ``zig-zagging'' near an interior optimum. Since $z_k$ must be at a vertex of $\mathcal{X}$, the LP subproblem solution oscillates between extreme points as the gradient direction changes sign near the minimum. The iterate $x_k$ converges as an exponentially weighted average of these oscillating vertices. Smaller steps ($\beta = 0.985$, effective step $1-\beta = 0.015$) reduce oscillation near convergence.

\textbf{Boundary optimum.} Frank--Wolfe is well-suited to boundary optima: once the gradient's sign stabilises (indicating which vertex to move towards), the LP vertex $z_k$ consistently selects the constraint-active face. The iterate approaches the boundary naturally without projection. For $f(x) = x_1^2 + x_2^2$, once $x_k$ is near $(0.5, 0)$, the gradient $\nabla f = (2x_1, 2x_2) \approx (1, 0)$, so $z_k = (0.5, \cdot)$ (lower bound for $x_1$). The gap to $f^{\star} = 0.25$ after 140 iterations reflects the slow $O(1/k)$ convergence of the fixed-$\beta$ schedule for boundary optima; the standard diminishing schedule $\gamma_k = 2/(k+2)$ would improve this.

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has demonstrated the comparative behaviour of 14 optimisation algorithms across three benchmark functions of increasing difficulty. The key conclusions are:

\textbf{First-order adaptive methods (Q1).} The Polyak step achieves optimal convergence when $f^{\star}$ is exactly known, but diverges or oscillates when $f^{\star}$ is misspecified. Adagrad and Heavy Ball provide robust alternatives: Adagrad through monotonically decreasing per-coordinate rates, and Heavy Ball through momentum accumulation. RMSprop's exponential forgetting produces smooth trajectories but slightly lower final accuracy on convex problems.

\textbf{Momentum and stochastic methods (Q2).} Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ rate, providing the best gradient-based performance across all benchmarks. On Rosenbrock, Nesterov reduces the objective to $0.479$ vs GD's $3.388$ in 150 iterations --- a 7-fold improvement directly attributable to the accelerated rate. Adam's per-coordinate scaling is most beneficial on problems with heterogeneous curvature across dimensions. Mini-batch SGD demonstrates the variance--efficiency trade-off: smaller batches converge faster per epoch but with more noise, and this advantage disappears when observation noise dominates mini-batch sampling noise.

\textbf{Newton's method (Q3).} Newton's method converges in one step for quadratic objectives and in $O(\log\log(1/\varepsilon))$ steps for smooth strongly convex functions (quadratic convergence). The extreme ill-conditioning of Rosenbrock ($\kappa \approx 2508$) is completely handled by the Hessian inverse in the Newton direction, whereas gradient descent requires step sizes $O(1/L) \approx O(10^{-3})$ for stability. The cost is $O(n^3)$ per iteration, limiting Newton's applicability to small- and medium-scale problems.

\textbf{Derivative-free methods (Q4).} Finite-difference gradient approximation with optimal step size closely tracks exact gradient descent, while large step sizes introduce significant truncation error. Nesterov random search requires only 2 function evaluations per step but converges slowly due to high-variance gradient estimates. For small-dimensional black-box objectives, Nelder--Mead simplex is effective; grid search provides global guarantees at exponential cost in dimension.

\textbf{Constrained optimisation (Q5).} Projected gradient descent provides hard feasibility guarantees at every iteration through the projection oracle, while penalty methods offer algorithmic simplicity at the cost of inexact constraint satisfaction during iterations. When the constraint is inactive at the optimum (as in this experiment), all methods ultimately converge to the same solution; the differences lie in feasibility recovery from the infeasible starting point.

\textbf{Frank--Wolfe (Q6).} The conditional gradient algorithm handles linear constraints without projection, naturally reaching the optimum as a convex combination of vertices. Its $O(1/k)$ convergence rate (with the standard decaying schedule) and $O(d)$ LP subproblem cost make it attractive for large-scale sparse problems. Fixed-$\beta$ schedules cause oscillation near interior optima but can be stabilised by reducing $1-\beta$.

\textbf{Overall recommendation.} For general unconstrained optimisation: use Adam or Nesterov for deep learning (momentum + adaptivity); use L-BFGS (a quasi-Newton method) for small-scale smooth problems. For constrained problems: use projected gradient descent when projections are cheap, Frank--Wolfe when LP subproblems are cheap. For derivative-free objectives: use Nelder--Mead for $d \leq 10$, Nesterov random search or evolutionary methods for large $d$.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Nelder--Mead Simplex}]
def nelder_mead(loss_fn, x0, step, n_iters, alpha_r=1.0, gamma=2.0, rho=0.5, sigma=0.5):
    n = len(x0)
    simplex = np.zeros((n + 1, n))
    simplex[0] = x0.copy()
    for i in range(n):
        simplex[i + 1] = x0.copy()
        simplex[i + 1][i] += step
    f_vals = np.array([loss_fn(v) for v in simplex])
    centroid_hist = [np.mean(simplex, axis=0).copy()]
    f_best_hist = [np.min(f_vals)]
    for _ in range(n_iters):
        order = np.argsort(f_vals)
        simplex = simplex[order]; f_vals = f_vals[order]
        centroid = np.mean(simplex[:-1], axis=0)
        x_r = centroid + alpha_r * (centroid - simplex[-1])
        f_r = loss_fn(x_r)
        if f_vals[0] <= f_r < f_vals[-2]:
            simplex[-1] = x_r; f_vals[-1] = f_r
        elif f_r < f_vals[0]:
            x_e = centroid + gamma * (centroid - simplex[-1])
            f_e = loss_fn(x_e)
            if f_e < f_r: simplex[-1] = x_e; f_vals[-1] = f_e
            else: simplex[-1] = x_r; f_vals[-1] = f_r
        else:
            if f_r < f_vals[-1]:
                x_c = centroid + rho * (x_r - centroid)
                f_c = loss_fn(x_c)
                if f_c <= f_r: simplex[-1] = x_c; f_vals[-1] = f_c
                else:
                    for i in range(1, n+1):
                        simplex[i] = simplex[0]+sigma*(simplex[i]-simplex[0])
                        f_vals[i] = loss_fn(simplex[i])
            else:
                x_c = centroid + rho * (simplex[-1] - centroid)
                f_c = loss_fn(x_c)
                if f_c < f_vals[-1]: simplex[-1] = x_c; f_vals[-1] = f_c
                else:
                    for i in range(1, n+1):
                        simplex[i] = simplex[0]+sigma*(simplex[i]-simplex[0])
                        f_vals[i] = loss_fn(simplex[i])
        centroid_hist.append(np.mean(simplex, axis=0).copy())
        f_best_hist.append(np.min(f_vals))
    return np.array(centroid_hist), np.array(f_best_hist), simplex
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
