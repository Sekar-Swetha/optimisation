\begin{abstract}
This report presents a rigorous comparative study of first-order, second-order, derivative-free, and constrained optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark~A), a sinusoidally-perturbed quadratic (Benchmark~B), and the Rosenbrock function (Benchmark~C). Six algorithmic families are investigated in sequence. \textbf{Question~1} compares adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball): the Polyak step achieves best performance on Rosenbrock ($f = 0.0094$) when $f^\star$ is known, but diverges on A and B due to $f^\star$ misspecification. \textbf{Question~2} shows Nesterov acceleration ($f = 0.479$ on Rosenbrock after 150 iterations) outperforms Adam and standard gradient descent, consistent with the theoretical $O(1/k^2)$ rate for smooth convex functions. \textbf{Question~3} demonstrates Newton's method convergence in a single iteration on the quadratic Benchmark~A and in 20 iterations achieves $f = 0.686$ on Rosenbrock vs GD's $f = 3.732$ in 80 iterations, illustrating second-order convergence. \textbf{Question~4} shows finite-difference gradient descent with $\delta = 0.05$ closely tracks exact gradient descent, while $\delta = 0.8$ fails due to truncation error; Nelder--Mead navigates the Rosenbrock valley derivative-free. \textbf{Question~5} establishes that projected gradient descent achieves hard feasibility from iteration~1, whereas penalty methods require large $\lambda$ at the cost of reduced step-size stability. \textbf{Question~6} analyses the Frank--Wolfe algorithm for linear-constrained problems, demonstrating its $O(1/k)$ convergence rate and natural boundary-seeking behaviour without requiring explicit projection.
\end{abstract}

\section{Notation and Theoretical Preliminaries}
\label{sec:notation}
% ============================================================

Throughout this report the following standard notation is used consistently. Let $f : \mathbb{R}^d \to \mathbb{R}$ be the objective function and $x^\star$ its minimiser.

\begin{itemize}[nosep]
\item $\nabla f(x) \in \mathbb{R}^d$: gradient of $f$ at $x$.
\item $\nabla^2 f(x) \in \mathbb{R}^{d \times d}$: Hessian matrix at $x$.
\item $L$: \emph{Lipschitz constant of the gradient} --- $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ for all $x,y$. Equivalently, $f(y) \leq f(x) + \nabla f(x)^T(y-x) + \tfrac{L}{2}\|y-x\|^2$ ($L$-smooth).
\item $\mu$: \emph{strong-convexity modulus} --- $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \tfrac{\mu}{2}\|y-x\|^2$ for all $x,y$.
\item $\kappa = L/\mu$: \emph{condition number}. Large $\kappa$ signals ill-conditioning and slow GD convergence.
\item $\alpha_k$ or $\alpha$: step size (learning rate).
\item $\odot$: element-wise (Hadamard) product.
\item $\|\cdot\|$: Euclidean norm unless stated otherwise.
\end{itemize}

For $L$-smooth strongly convex problems, gradient descent with step $\alpha = 1/L$ achieves linear convergence: $f(x_k) - f^\star \leq \left(1 - \mu/L\right)^k (f(x_0) - f^\star)$, i.e.\ the error contracts by factor $(1 - 1/\kappa)$ per iteration. The condition number $\kappa$ thus directly governs convergence speed.

A useful weaker condition is the \emph{Polyak--Łojasiewicz (PL) inequality}: $\frac{1}{2}\|\nabla f(x)\|^2 \geq \mu(f(x) - f^\star)$ for all $x$. This holds for any $\mu$-strongly convex function but also for many non-convex functions:
\begin{itemize}[nosep]
\item \textbf{Benchmark A}: the quadratic loss $J(\theta)$ is strongly convex, so the PL condition holds globally with $\mu = \lambda_{\min}(H)$ and the linear convergence rate $O((1-1/\kappa)^k)$ applies from any starting point.
\item \textbf{Benchmark B}: $f$ is strongly convex near the minimum (since $H = \text{diag}(2-\sin(x_1), 10) \succ 0$ in a neighbourhood), so the PL condition holds locally, justifying the observed linear convergence for all methods.
\item \textbf{Benchmark C}: the Rosenbrock function is \emph{not} globally strongly convex, but satisfies the PL condition along the valley floor $\{x_2 = x_1^2\}$ where $f(x_1, x_1^2) = (1-x_1)^2$ is strongly convex in $x_1$. This explains why methods that align with the valley direction (Polyak, Nesterov) converge at an approximately linear rate once on the valley, while methods that don't make slow progress.
\end{itemize}
Under the PL condition, GD with $\alpha = 1/L$ achieves the same linear rate $f(x_k) - f^\star \leq (1 - \mu/L)^k(f(x_0) - f^\star)$ without strong convexity.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility. The three benchmarks span a spectrum of difficulty that mirrors real-world machine learning objectives: Benchmark~A (linear regression) is a prototypical convex quadratic analogous to a 1-layer linear network; Benchmark~B ($f = (x_1-1)^2 + 5(x_2-2)^2 + \sin x_1$) introduces mild non-convexity analogous to shallow networks; Benchmark~C (Rosenbrock) represents the highly ill-conditioned, strongly non-convex loss surfaces found in deep networks.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a \emph{convex quadratic} with constant Hessian $H = \frac{1}{m}X^T X \succ 0$ and gradient $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The Lipschitz constant equals the largest eigenvalue $\lambda_{\max}(H)$ and $\mu = \lambda_{\min}(H)$, so $\kappa = \lambda_{\max}/\lambda_{\min}$. Since the data is i.i.d.\ standard normal, both eigenvalues are close to 1 ($\kappa \approx 1$), making Benchmark~A well-conditioned. Due to observation noise $\varepsilon$, the minimum loss is $J^{\star} \approx 0.4826 > 0$, not zero. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\label{eq:bench_B}
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H = \text{diag}(2 - \sin(x_1),\ 10)$. Along the $x_1$-coordinate the curvature oscillates between $1 \approx 2-\sin(-\pi/2)$ and $3 \approx 2-\sin(\pi/2)$, so $L \approx 10$ and $\mu \approx 1$, giving $\kappa \approx 10$. This moderate ill-conditioning causes anisotropic gradient steps (the $x_2$ component has 5--10$\times$ greater curvature). The minimum lies at approximately $(0.582, 2.0)$ satisfying $2(x_1-1)+\cos(x_1) = 0$ and $x_2 = 2$, with $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\label{eq:bench_C}
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian at the optimum is:
\begin{equation}
\nabla^2 f(1,1) = \begin{bmatrix} 2 + 1200 - 400 & -400 \\ -400 & 200 \end{bmatrix} = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues $\lambda_1 \approx 1002$ (direction across the valley) and $\lambda_2 \approx 0.4$ (direction along the valley floor), giving condition number $\kappa \approx 2004$. The large eigenvalue $\lambda_1 \approx 1002$ forces all gradient-based methods to use very small step sizes ($\alpha < 2/\lambda_1 \approx 0.002$) to remain stable; while the small eigenvalue $\lambda_2 \approx 0.4$ along the valley means each step contributes only $\alpha \lambda_2 \approx 0.0008$ of useful progress towards the minimum --- the ratio $\lambda_1/\lambda_2 = \kappa$ directly explains the slow convergence. This extreme ill-conditioning, combined with the narrow curved valley along $x_2 = x_1^2$, makes the Rosenbrock function one of the most challenging standard test functions and serves as the principal discriminator between methods. The restricted function on the valley floor, $f(x_1, x_1^2) = (1-x_1)^2$, is a simple 1D quadratic in $x_1$ with $\kappa = 1$ --- the challenge is \emph{reaching} the valley floor and then \emph{staying on it} while advancing towards $x_1 = 1$. Starting point: $x_0 = [-1, 1]^T$. Since $x_{0,2} = 1 = (-1)^2 = x_{0,1}^2$, the starting point lies \emph{exactly on the valley floor} $x_2 = x_1^2$. The challenge is therefore not escaping a local basin, but navigating $2$ units along the valley from $x_1 = -1$ to $x_1 = 1$: the gradient at every point on the valley has a large perpendicular component (arising from the $100(x_2 - x_1^2)^2$ term when off-valley) that causes gradient steps to oscillate across the valley rather than advance along it.

\subsection{Expected Algorithm Characteristics per Benchmark}

The three benchmarks serve as discriminating test cases of increasing difficulty:
\begin{itemize}[nosep]
\item \textbf{Benchmark A} ($\kappa \approx 1$): All methods with stable step sizes converge quickly. Adaptive methods provide no advantage. Newton converges in one step (exact quadratic). The noise floor $J^\star \approx 0.48 > 0$ prevents convergence to zero.
\item \textbf{Benchmark B} ($\kappa \approx 10$): Moderate anisotropy means adaptive methods (Adagrad, Adam) begin to outperform plain GD. Newton converges in $\sim$5 steps. The sinusoidal term creates mild non-linearity that dampens Heavy Ball's performance slightly.
\item \textbf{Benchmark C} ($\kappa \approx 2000$): The principal discriminator. Only Polyak (with exact $f^\star$) and Nesterov make significant first-order progress. Newton requires damping but dominates first-order methods. Derivative-free methods (Nelder--Mead) can succeed by adapting their geometry, while random search and FD methods struggle.
\end{itemize}

\section[Question 1: Adaptive Step-Size Methods]{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Framework}

Gradient descent with a fixed step $\alpha \leq 1/L$ decreases the objective by at least $\frac{\alpha}{2}\|\nabla f(x_k)\|^2$ per step. However, selecting $\alpha$ requires knowledge of $L$, and a uniform step size ignores local curvature differences. Adaptive methods address this by adjusting the step size \emph{coordinate-wise} or \emph{globally} based on gradient history, without requiring $L$ explicitly.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Polyak Step Size (Polyak, 1969)}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Minimise first-order model along gradient}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step is derived by minimising the first-order Taylor approximation $f(x_k) + \nabla f(x_k)^T(x - x_k) \approx f^{\star}$, yielding an adaptive step that theoretically contracts $\|x_k - x^{\star}\|$ at the optimal rate when $f^{\star}$ is known exactly and $f$ is convex. Specifically, when $f$ is convex, the Polyak update satisfies:
\begin{equation}
\|x_{k+1} - x^{\star}\|^2 \leq \|x_k - x^{\star}\|^2 - \frac{(f(x_k) - f^{\star})^2}{\|\nabla f(x_k)\|^2}
\label{eq:polyak_descent}
\end{equation}
showing that the squared distance to $x^{\star}$ decreases by at least $(f(x_k) - f^{\star})^2/\|\nabla f\|^2$ at each step. When $f^{\star}$ is misspecified as $\tilde{f}^{\star} < f^{\star}_{\text{true}}$ (as on Benchmarks A and B), the step size $\alpha_k = (f(x_k) - \tilde{f}^{\star})/\|\nabla f\|^2$ does not satisfy \eqref{eq:polyak_descent}, and divergence can occur.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative sum of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's effective per-coordinate step is $\tilde\alpha_k^{(i)} = \alpha_0 / (\sqrt{G_k^{(i)}} + \varepsilon)$, which \emph{decreases monotonically} as squared gradients accumulate. For coordinate $i$, large historical gradients $G_k^{(i)}$ reduce the step, providing natural regularisation for directions with high curvature. Duchi et al.\ (2011) show that Adagrad achieves an $O(\sqrt{T})$ regret bound for online convex optimisation:
\begin{equation}
\sum_{t=1}^T f(x_t) - \min_{x \in \mathcal{X}} \sum_{t=1}^T f(x) \leq \alpha_0 \|x_0 - x^{\star}\|_2 \sqrt{\sum_{t=1}^T \|g_t\|_2^2},
\label{eq:adagrad_regret}
\end{equation}
which is a factor $O(\sqrt{T/d})$ improvement over standard online GD when gradients are sparse (i.e.\ concentrated on a few coordinates, so $\sum_i \|g^{(i)}\| \ll \sqrt{d}\|g\|$). In the offline batch setting with a fixed objective, this translates to an $O(1/\sqrt{k})$ convergence rate for the \emph{running average} $\bar{x}_k = \frac{1}{k}\sum_{t=1}^k x_t$. The downside is that the step size decays to zero regardless of whether it has converged, potentially causing premature stagnation on non-stationary problems or in the late stages of training.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's cumulative sum with an exponential moving average (decay $\beta = 0.9$), preventing the step size from decaying to zero. The exponential moving average has an \emph{effective window} of approximately $1/(1 - \beta) = 10$ past gradient squares (for $\beta = 0.9$): contributions from $t \leq k - 10$ are weighted by $\beta^{10} = 0.35$, so the EMA is dominated by the most recent 10 steps. This is crucial for non-stationary objectives; the effective step $\alpha_0/\sqrt{v_k^{(i)}}$ adapts to \emph{recent} curvature rather than the entire gradient history. Similarly, the Heavy Ball velocity $z_k = \alpha\sum_{j=0}^k \beta^{k-j}\nabla f(x_j)$ has effective memory $1/(1-\beta)$ steps, meaning the momentum term aggregates approximately $1/(1-0.9) = 10$ past gradient directions.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Velocity accumulates past gradients}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method (Polyak, 1964) modifies gradient descent by adding a momentum term. The velocity $z_k = \alpha \sum_{j=0}^{k} \beta^{k-j} \nabla f(x_j)$ is a geometrically-weighted sum of past gradients, damping oscillations in high-curvature directions and amplifying consistent gradient components. For a strongly convex quadratic $f(x) = \frac{1}{2}x^T H x$ with eigenvalues in $[\mu, L]$, the \emph{optimal} Heavy Ball parameters are:
\begin{equation}
\alpha^{\star} = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}, \qquad \beta^{\star} = \left(\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}\right)^2,
\label{eq:hb_optimal}
\end{equation}
achieving the rate $\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k$ --- \emph{identical} to Nesterov's rate. However, this optimality holds only for the exact quadratic case; Heavy Ball with these parameters can diverge on general non-quadratic strongly convex functions (Lessard et al., 2016).

\subsection{Comparative Analysis}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly, Polyak converges fastest by adaptively selecting near-optimal step sizes. Otherwise, Heavy Ball and Adagrad match the GD baseline on well-conditioned problems while outperforming it on ill-conditioned ones. As will be seen in Question~2 (Section~\ref{sec:q2}), the structured momentum of Nesterov's method offers stronger theoretical guarantees than Heavy Ball while retaining similar computational cost.
\item \textbf{Stability:} Adagrad is the most uniformly stable: its monotonically decreasing step guarantees that updates become arbitrarily small, preventing divergence at the cost of irreversible step-size decay. RMSprop's exponential averaging maintains a non-zero effective learning rate indefinitely, making it preferable for non-stationary problems or in the later stages of training.
\item \textbf{Ill-conditioning response:} On Rosenbrock ($\kappa \approx 2000$), all gradient-based methods require tiny steps to avoid overshooting the narrow valley walls. Heavy Ball's momentum provides implicit curvature adaptation by amplifying the valley-floor gradient component. Adagrad's coordinate-wise scaling partially decouples the two curvature directions. However, as shown in Question~3 (Section~\ref{sec:q3}), second-order methods that explicitly use curvature information vastly outperform all these first-order adaptive methods.
\item \textbf{Connection to convergence theory:} GD on a $\mu$-strongly convex, $L$-smooth function with optimal step $\alpha = 2/(\mu+L)$ converges as $((\kappa-1)/(\kappa+1))^k$. For $\kappa \approx 2000$, this gives a rate of $\approx 0.999$ per iteration, requiring $\kappa \log(1/\varepsilon) \approx 2000 \times 7 = 14000$ iterations for $\varepsilon = 10^{-3}$ accuracy --- confirming why 120 iterations achieves little progress on Rosenbrock.
\item \textbf{Practical guidance:} When $f^{\star}$ is unknown (the typical case), RMSprop (Algorithm~\ref{alg:rmsprop}) and Adagrad (Algorithm~\ref{alg:adagrad}) are robust defaults for machine learning applications. Heavy Ball (Algorithm~\ref{alg:heavyball}) can accelerate GD on well-conditioned smooth problems. Nesterov's method (Section~\ref{sec:q2}, Algorithm~\ref{alg:nesterov}) offers a stronger theoretical alternative to Heavy Ball with the same per-iteration cost.
\end{itemize}

\subsection{Theoretical Framework}

Gradient descent on a smooth convex function achieves convergence rate $O(1/k)$. Nesterov~(1983) showed that no first-order method can achieve better than $O(1/k^2)$ on smooth convex functions, and his accelerated method \emph{attains} this optimal rate. Adam combines momentum with adaptive scaling, inheriting advantages of both Nesterov and RMSprop, though its convergence on non-convex problems remains an active research area.

\begin{theorem}[Nesterov, 1983]
\label{thm:nesterov}
For $f$ convex and $L$-smooth, Nesterov's accelerated method with $\beta_k = (k-1)/(k+2)$ and step $\alpha = 1/L$ satisfies:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L\|x_0 - x^{\star}\|^2}{(k+1)^2} = O\!\left(\frac{1}{k^2}\right).
\label{eq:nesterov_rate}
\end{equation}
This rate is \emph{optimal} among all first-order methods for smooth convex optimisation (Nemirovski \& Yudin, 1983).
\end{theorem}

\begin{theorem}[Lower Bound for First-Order Methods, Nemirovski \& Yudin, 1983]
\label{thm:lower_bound}
For any first-order deterministic algorithm (accessing $f$ only through function value and gradient queries) and any $L > 0$ and $R > 0$, there exists an $L$-smooth convex function $f : \mathbb{R}^d \to \mathbb{R}$ with $\|x_0 - x^{\star}\| \leq R$ such that after $k \leq (d-1)/2$ gradient queries the algorithm produces $x_k$ satisfying:
\begin{equation}
f(x_k) - f^{\star} \geq \frac{3L R^2}{32(k+1)^2}.
\label{eq:lower_bound}
\end{equation}
\end{theorem}

The construction proving Theorem~\ref{thm:lower_bound} uses the ``worst-case'' function $f(x) = \frac{L}{8}\left(\sum_{i=1}^{k} (x_i - x_{i+1})^2 + x_1^2\right) - \frac{L R}{2(k+1)^2} e_1^T x$, for which any algorithm restricted to the Krylov subspace $\text{span}\{e_1,\ldots,e_k\}$ after $k$ gradient steps cannot do better than \eqref{eq:lower_bound}. Comparing Theorem~\ref{thm:nesterov} and \eqref{eq:lower_bound}: both have $O(1/(k+1)^2)$ dependence and the same dependence on $L$ and $R$, up to a constant factor. Thus Nesterov's method is \emph{information-theoretically optimal}: no first-order algorithm can achieve a qualitatively faster rate on the worst-case smooth convex problem.

\textbf{Gap between theory and practice.} While Nesterov's rate is optimal in the worst case, it need not be tight on the benchmarks studied here. Benchmark~B ($\kappa \approx 10$) is close to spherically symmetric --- far from the worst-case ``long chain'' construction --- so GD already converges quickly, leaving little room for Nesterov to improve. Benchmark~C (Rosenbrock, non-convex) does not satisfy the convexity assumption, and the $O(1/k^2)$ rate does not directly apply; Nesterov still outperforms GD empirically due to its ability to build momentum along the valley floor, but the convergence rate cannot be bounded by Equation~\eqref{eq:nesterov_rate}.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient Descent}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Momentum schedule increases to $\beta_{\max}$}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead: evaluate gradient at momentum-shifted point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The fundamental distinction from Heavy Ball (Algorithm~\ref{alg:heavyball}) is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This anticipatory gradient evaluation allows the method to \emph{correct} its trajectory before potential overshoot, which is the mechanism behind the improved $O(1/k^2)$ rate. At $k=1$, $\beta_1 = 0$ so the first step reduces to gradient descent; the momentum coefficient increases gradually according to the schedule $\beta_k = (k-1)/(k+2)$, subject to the cap $\beta_{\max}$. For non-convex functions, \emph{momentum restarts} (O'Donoghue \& Candès, 2015) detect when $f(x_{k+1}) > f(x_k)$ (the function increased, indicating the momentum overshot) and reset $z \leftarrow 0$ and $k \leftarrow 1$, restarting the momentum schedule. This adaptively provides Nesterov-like acceleration in convex regions while suppressing overshooting oscillations in non-convex regions, and is the standard practice for Nesterov-based methods on non-convex objectives.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment: exponential average of gradients}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment: exponential average of $g^2$}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction for initialisation at zero}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam (Kingma \& Ba, 2015) combines momentum (first moment $m_t$) with per-coordinate adaptive scaling (second moment $v_t$), analogous to RMSprop but with momentum. The bias corrections $(1 - \beta_1^t)^{-1}$ and $(1 - \beta_2^t)^{-1}$ compensate for the initialisation of $m_0 = v_0 = 0$: in early iterations, the estimates are biased towards zero and the corrections restore unbiased estimates. \emph{Without} momentum ($\beta_1 = 0$), Adam reduces to RMSprop with bias correction, confirming that RMSprop is a special case. The second moment $v_t \approx \mathbb{E}[g_t^2]$ approximates the \emph{diagonal of the Fisher information matrix} $F = \mathbb{E}[\nabla \log p(x|\theta)\, \nabla \log p(x|\theta)^T]$ for probabilistic models; Adam's update $\Delta\theta = -\alpha \hat{m}_t / \sqrt{\hat{v}_t}$ thus approximates the \emph{natural gradient step} $\Delta\theta = -\alpha F^{-1} \nabla\mathcal{L}$ (Amari, 1998) with the diagonal approximation $F \approx \text{diag}(\hat{v}_t)$. The true natural gradient uses the full Fisher matrix and achieves geometry-aware convergence in the space of probability distributions, but is $O(d^3)$ to compute exactly --- motivating Adam's diagonal approximation. Conversely, without adaptive scaling ($v_t \equiv 1$), Adam reduces to gradient descent with exponential moving average (heavy-ball-like momentum). The combination of both components explains why Adam is robust across a wide range of problems: the second moment adapts the effective learning rate per coordinate, while the first moment provides inertia. The bias correction is necessary because $\mathbb{E}[m_t] = (1 - \beta_1^t)\mathbb{E}[\nabla f(x_t)]$ under i.i.d.\ gradients (since $m_t = (1-\beta_1)\sum_{j=1}^t \beta_1^{t-j} g_j$), so dividing by $(1 - \beta_1^t)$ restores an unbiased estimate. Without this correction, early iterations are systematically biased towards zero, causing artificially small updates in the first $O(1/(1-\beta_1))$ steps. Note: Reddi et al.\ (2018) showed that the original Adam convergence proof contains an error and constructed a counterexample where Adam fails to converge. Their fix, \textbf{AMSGrad}, replaces $\hat{v}_t$ with a running maximum $\hat{v}_t^{\max} = \max(\hat{v}_{t-1}^{\max}, \hat{v}_t)$, ensuring the effective learning rate is non-increasing and restoring convergence guarantees.

\subsection{Mini-Batch Stochastic Gradient Descent}
\label{sec:sgd}

Mini-batch SGD on Benchmark~A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with the data re-shuffled at every epoch. Mini-batch SGD is a special case of \emph{stochastic approximation} (Robbins \& Monro, 1951), which provides the general framework for root-finding and optimisation with noisy function evaluations. The Robbins--Monro conditions $\sum_k \alpha_k = \infty$, $\sum_k \alpha_k^2 < \infty$ (e.g.\ $\alpha_k = c/k$) guarantee almost sure convergence but require careful tuning. The mini-batch approach with fixed $\alpha$ relaxes this to convergence to a noise floor, trading theoretical simplicity for practical robustness.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\sigma \in S_{1000}$
    \For{each mini-batch $\mathcal{B} = \{\sigma(j b+1), \ldots, \sigma((j+1)b)\}$}
        \State $g \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Unbiased gradient estimate: $\mathbb{E}[g] = \nabla J(\theta)$}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

Each mini-batch gradient $g = \frac{1}{b}X_\mathcal{B}^T(X_\mathcal{B}\theta - y_\mathcal{B})$ is an \emph{unbiased} estimator of the full gradient: $\mathbb{E}[g] = \nabla J(\theta)$. Its variance scales as $\mathbb{V}[g] \approx \frac{1}{b}\mathbb{V}[g_{\text{single sample}}]$, so halving the batch size doubles gradient variance. This variance has two consequences: (i) faster convergence per epoch (more updates), and (ii) noisier trajectories near the minimum where the true gradient is small but mini-batch gradients are dominated by noise. The asymptotic loss floor $J_\infty(b)$ satisfies $J_\infty(b) \approx J^\star + O(\alpha/b)$ for fixed step size $\alpha$, meaning smaller batches with fixed $\alpha$ cannot converge below a higher noise floor --- a bias-variance trade-off between batch size and step size. More precisely, near the minimum where $\nabla J(\theta) \approx 0$, the iterate satisfies $\mathbb{E}[\|\theta_k - \theta^{\star}\|^2] \to \frac{\alpha}{2\mu}\sigma_b^2$ where $\sigma_b^2 = \mathbb{V}[g_{\text{batch}}] \propto 1/b$: smaller batches require smaller $\alpha$ to achieve the same asymptotic accuracy. A \emph{learning rate schedule} (decaying $\alpha_k \to 0$ at rate $O(1/k)$) resolves this but requires careful tuning. An alternative is \textbf{Polyak--Ruppert averaging}: run SGD with fixed step $\alpha$ and output the \emph{running average} $\bar{\theta}_k = \frac{1}{k}\sum_{t=1}^k \theta_t$ rather than the last iterate. Ruppert (1988) and Polyak \& Juditsky (1992) showed that $\bar{\theta}_k$ achieves the optimal $O(1/k)$ asymptotic variance even with constant $\alpha$, matching the statistical efficiency of the MLE. This requires no step-size decay, making it practically convenient.

A more recent approach is \textbf{variance reduction}: methods such as SVRG (Johnson \& Zhang, 2013) and SAGA (Defazio et al., 2014) achieve a gradient variance that \emph{decreases to zero} as iterates approach the minimum, combining the per-iteration cheap cost of SGD with the linear convergence of full-batch GD.

\textbf{Finite-sum structure.} The machine learning objective has the finite-sum form:
\begin{equation}
\min_\theta \frac{1}{m}\sum_{i=1}^m f_i(\theta), \qquad f_i(\theta) = \tfrac{1}{2}(x_i^T\theta - y_i)^2,
\label{eq:finite_sum}
\end{equation}
where each $f_i$ corresponds to one data point. Full-batch GD evaluates all $m$ component gradients per step. SGD evaluates one at cost $O(1)$, but the critical obstacle to linear convergence is that the gradient variance $\mathbb{V}[g_i] = \mathbb{E}_{i}[\|\nabla f_i(\theta) - \nabla F(\theta)\|^2]$ does not vanish at the optimum: even when $\theta = \theta^\star$ and $\nabla F(\theta^\star) = 0$, individual gradients $\nabla f_i(\theta^\star) \neq 0$ due to data heterogeneity. This persistent variance forces SGD to use a decaying step to converge, sacrificing the $O(1)$ per-step cost advantage.

\textbf{SVRG algorithm.} SVRG eliminates this obstacle by periodically computing a full-gradient \emph{anchor} $\tilde{\mu} = \nabla F(\tilde{\theta})$ at a snapshot $\tilde{\theta}$, used as a control variate to cancel most of the stochastic noise:

\begin{algorithm}[H]
\caption{SVRG (Stochastic Variance Reduced Gradient, Johnson \& Zhang, 2013)}
\label{alg:svrg}
\begin{algorithmic}[1]
\Require Initial $\tilde{\theta}_0$, step $\alpha$, epoch length $m$, outer iterations $S$
\For{$s = 0, 1, \ldots, S-1$}
    \State $\tilde{\mu}^s \gets \frac{1}{m}\sum_{i=1}^m \nabla f_i(\tilde{\theta}^s)$ \Comment{Full gradient: cost $O(m)$ once per epoch}
    \State $\theta_0 \gets \tilde{\theta}^s$
    \For{$k = 0, 1, \ldots, m-1$}
        \State Sample $i_k \sim \text{Uniform}(\{1,\ldots,m\})$
        \State $v_k \gets \nabla f_{i_k}(\theta_k) - \nabla f_{i_k}(\tilde{\theta}^s) + \tilde{\mu}^s$ \Comment{Variance-reduced gradient estimate}
        \State $\theta_{k+1} \gets \theta_k - \alpha\, v_k$
    \EndFor
    \State $\tilde{\theta}^{s+1} \gets \theta_m$
\EndFor
\end{algorithmic}
\end{algorithm}

The estimator $v_k$ is unbiased: $\mathbb{E}_{i_k}[v_k] = \nabla F(\theta_k)$. Its variance obeys $\mathbb{V}[v_k] \leq 2L\|\theta_k - \tilde{\theta}^s\|^2$, which \emph{vanishes} as $\theta_k \to \tilde{\theta}^s \to \theta^\star$ across epochs --- unlike SGD whose variance is bounded below by the data heterogeneity even at $\theta^\star$. This is the mechanism behind linear convergence: the control variate $(\nabla f_{i_k}(\tilde{\theta}^s) - \tilde{\mu}^s)$ subtracts away the component of $\nabla f_{i_k}$ that is independent of the current iterate, leaving only the locally informative signal. The total gradient evaluation cost per epoch is $O(m)$ (full gradient) $+ O(m)$ (inner loop) $= O(2m)$. SVRG achieves $O((m + \kappa) \log(1/\varepsilon))$ total evaluations for $\mu$-strongly convex objectives --- faster than the $O(m\kappa\log(1/\varepsilon))$ cost of SGD and competitive with full-batch GD's $O(m\kappa\log(1/\varepsilon))$ when $m \gg \kappa$, since SVRG replaces the factor $m\kappa$ with $(m+\kappa)$. SAGA (Defazio et al., 2014) achieves the same rate with half the memory overhead by maintaining a table of stored gradients instead of a single snapshot. These methods represent the state-of-the-art for finite-sum optimisation problems common in machine learning, and form the foundation for variance-reduced Adam variants (e.g.\ AdaVAR, SpiderAdam) used in modern deep learning.

\label{fig:q2_sgd_variance}
\end{figure}

\subsection{Continuous-Time ODE Perspective}

The discrete iterations of GD, Heavy Ball, and Nesterov can be understood through their continuous-time limits as step size $\alpha \to 0$:
\begin{itemize}[nosep]
\item \textbf{GD} corresponds to the \emph{gradient flow} ODE: $\dot{x}(t) = -\nabla f(x(t))$, which decreases $f$ monotonically at rate $d f/dt = -\|\nabla f\|^2 \leq 0$.
\item \textbf{Heavy Ball} corresponds to the \emph{damped oscillator}: $\ddot{x} + \gamma \dot{x} = -\nabla f(x)$, where $\gamma = (1-\beta)/\alpha$ is the damping coefficient. This ODE has well-known oscillatory solutions for underdamped systems, explaining the zig-zag behavior on ill-conditioned problems.
\item \textbf{Nesterov} corresponds to the ODE: $\ddot{x} + \frac{3}{t}\dot{x} = -\nabla f(x)$ (Su et al., 2016), with the damping coefficient $3/t \to 0$ as $t \to \infty$. The decreasing damping is precisely what enables the $O(1/k^2)$ rate: unlike the fixed-$\gamma$ Heavy Ball which can resonate, Nesterov's time-varying damping adaptively controls overshooting.
\end{itemize}
This ODE perspective provides geometric intuition: Heavy Ball is a physical system prone to oscillation when γ is small (underdamped), while Nesterov's decreasing damping coefficient drives it toward critical damping asymptotically.

\subsection{Nesterov vs Heavy Ball: Theoretical Comparison}

Both Heavy Ball (Section~\ref{sec:q1}) and Nesterov use a momentum term, but they differ critically in \emph{where} the gradient is evaluated. Heavy Ball evaluates at $x_k$, whereas Nesterov evaluates at the lookahead point $\tilde{x}_k = x_k + \beta_k z_k$. This distinction is not merely implementational: Heavy Ball \emph{cannot} be shown to achieve better than $O(1/k)$ convergence on general smooth convex functions (it can even diverge on pathological examples), while Nesterov's lookahead is precisely what enables the $O(1/k^2)$ rate.

For $\mu$-strongly convex, $L$-smooth functions, the comparison is particularly striking. GD achieves the rate $(1 - \mu/L)^k = (1 - 1/\kappa)^k$. Nesterov achieves $(1 - \sqrt{\mu/L})^k = (1 - 1/\sqrt{\kappa})^k$. For $\kappa = 2000$: GD rate per step $\approx 1 - 0.0005 = 0.9995$; Nesterov rate $\approx 1 - 0.022 = 0.978$. The exponent is improved from $1/\kappa$ to $1/\sqrt{\kappa}$ --- a factor $\sqrt{\kappa} \approx 45$ improvement in convergence speed. Equivalently, GD requires $O(\kappa \log(1/\varepsilon))$ iterations while Nesterov requires $O(\sqrt{\kappa} \log(1/\varepsilon))$ --- see Figure~\ref{fig:gd_vs_nesterov}. This is the precise mathematical sense in which Nesterov is ``optimal'' for strongly convex problems. The experimental results confirm this: on Rosenbrock, Nesterov ($f = 0.479$) substantially outperforms Heavy Ball ($f = 1.400$) under comparable settings, even though Rosenbrock is non-convex.

\subsection{Theoretical Framework}

Newton's method uses \emph{second-order} information to construct a local quadratic model of $f$. For a twice-differentiable function, the second-order Taylor expansion around $x_k$ is:
\begin{equation}
f(x) \approx f(x_k) + \nabla f(x_k)^T(x - x_k) + \tfrac{1}{2}(x - x_k)^T \nabla^2 f(x_k)(x - x_k).
\label{eq:quadratic_model}
\end{equation}
Minimising \eqref{eq:quadratic_model} over $x$ gives the Newton step $x_{k+1} = x_k - [\nabla^2 f(x_k)]^{-1} \nabla f(x_k)$. The \emph{Newton decrement} $\lambda(x_k) = \sqrt{\nabla f(x_k)^T [\nabla^2 f(x_k)]^{-1} \nabla f(x_k)}$ measures the size of the Newton step in the norm induced by the Hessian; it satisfies $f(x_k) - f^{\star} \leq \frac{1}{2}\lambda(x_k)^2$ locally (Boyd \& Vandenberghe, 2004), providing both a natural stopping criterion and a certificate of near-optimality.

\begin{theorem}[Local Quadratic Convergence]
\label{thm:newton}
Let $f$ be twice differentiable, $\nabla^2 f$ be Lipschitz continuous near $x^{\star}$ with constant $M$ (i.e.\ $\|\nabla^2 f(x) - \nabla^2 f(x^{\star})\| \leq M\|x - x^{\star}\|$), and $\nabla^2 f(x^{\star}) \succ 0$ with $\lambda_{\min}(\nabla^2 f(x^{\star})) \geq \mu > 0$. Then Newton's method with unit step ($\alpha = 1$) satisfies, for $x_k$ sufficiently close to $x^{\star}$:
\begin{equation}
\|x_{k+1} - x^{\star}\| \leq \frac{M}{2\mu} \|x_k - x^{\star}\|^2.
\label{eq:newton_quadratic}
\end{equation}
This \emph{quadratic convergence} means the number of correct decimal places roughly doubles at each iteration, in stark contrast to GD's linear convergence.
\end{theorem}

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (linear/tangent) approximation} around $x_0 = 0.25$, where $g'(x_0) = 4x_0^3 = 0.0625$:
\begin{equation}
g_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order (quadratic) approximation}, where $g''(x_0) = 12x_0^2 = 0.75$:
\begin{equation}
g_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises $g_2$: $g_2'(x) = 0$ gives $x^+ = x_0 - g'(x_0)/g''(x_0) = 0.25 - 0.0625/0.75 = 0.167$, a step towards the true minimum at $x^{\star} = 0$. Note that this step is $g'(x_0)/g''(x_0)$ --- precisely the Newton decrement in one dimension. For $g = x^4$, the Newton step overshoots (the quadratic model underestimates $g''$ away from the minimum), but from $x^+ = 0.167$ the process converges: the residual error $e^+ = 0.167$ satisfies $e^+ \approx (M/(2\mu))e_0^2$ with $e_0 = 0.25$, $g''(x^+) = 12(0.167)^2 \approx 0.33$ ($\mu \approx 0.33$), $g'''(x_0) = 24x_0 = 6$ (so $M = 6$), giving the error bound $e^+ \leq \frac{6}{2 \times 0.33} \times 0.25^2 \approx 0.57$ --- a valid but loose bound, consistent with the observed $e^+ = 0.167 < 0.25$.

\subsection{Newton's Method with Damping}

Full Newton steps ($\alpha = 1$) can overshoot far from the minimum where the Lipschitz condition on the Hessian is not satisfied. Damping ($\alpha < 1$) provides global convergence at the cost of slower initial progress. In practice, $\alpha$ is chosen by a \emph{backtracking line search}: starting from $\alpha = 1$, repeatedly set $\alpha \leftarrow \rho \alpha$ (with $\rho \in (0,1)$, typically $\rho = 0.5$) until the \textbf{Armijo sufficient-decrease condition} $f(x - \alpha p) \leq f(x) - c_1 \alpha p^T \nabla f(x)$ is satisfied (with $c_1 \in (0, 1)$, typically $c_1 = 10^{-4}$). The \textbf{Wolfe conditions} additionally require a \emph{curvature condition}: $-p^T \nabla f(x - \alpha p) \leq -c_2 p^T \nabla f(x)$ (with $c_2 \in (c_1, 1)$), ensuring the step is not too short. Together, these guarantee sufficient progress per step while ensuring the step size is large enough to make meaningful progress. The unit step $\alpha = 1$ is accepted as soon as the iterates enter the quadratic convergence regime near the minimum, providing the ``switch'' from damped to full Newton steps.

\begin{algorithm}[H]
\caption{Newton's Method with Hessian Damping and Step-Size Control}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, regularisation $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation ensures $H_k \succ 0$}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction: solve via Cholesky factorisation ($O(d^3)$ once, $O(d^2)$ to solve)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The regularisation $\lambda I$ (with $\lambda = 10^{-8}$) prevents numerical singularity of the Hessian while minimally affecting the Newton direction when $\lambda \ll \lambda_{\min}(H_k)$.

For large $d$ (e.g.\ deep learning with $d \sim 10^7$): the $O(d^3)$ Hessian solve makes exact Newton's method computationally intractable. A ResNet-50 model has $d \approx 2.5 \times 10^7$ parameters, so the Hessian would require $O((2.5 \times 10^7)^3) \approx 10^{22}$ operations per step --- far beyond any foreseeable computational budget. \textbf{Quasi-Newton (BFGS/L-BFGS):} Maintain a rank-2 approximation $B_k \approx H_k^{-1}$ updated from successive gradient differences (BFGS), or store only the $m \sim 10$--$20$ most recent gradient pairs (L-BFGS, $O(md)$ per step). Achieves superlinear convergence on smooth functions.

\textbf{Newton-CG (Hessian-free):} Solve the Newton system $H_k p = g_k$ approximately using the \emph{conjugate gradient} method, which requires only \emph{Hessian-vector products} $H_k v$ rather than the full Hessian. Hessian-vector products can be computed in $O(d)$ time via forward-mode autodiff (R-operator), making each CG iteration $O(d)$. With $k$ CG steps, the total Newton-CG cost is $O(kd)$, achieving nearly quadratic convergence.

\textbf{Trust region Newton:} Rather than constraining the step size $\alpha$, trust region methods constrain the step \emph{size}: $\min_p f(x_k) + g_k^T p + \frac{1}{2}p^T H_k p$ subject to $\|p\| \leq \Delta_k$. The trust radius $\Delta_k$ is expanded/contracted based on the agreement between the quadratic model and the actual function decrease, providing global convergence guarantees without requiring the quadratic model to hold globally.

\section[Question 4: Derivative Approximation and Derivative-Free Optimisation]{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}
% ============================================================

\subsection{Theoretical Framework}

When gradients are unavailable (black-box objectives, simulation-based optimisation, or non-differentiable losses), optimisation must rely on \emph{function evaluations only}. The cost and accuracy trade-off depends critically on the method:

\begin{itemize}[nosep]
\item \textbf{Finite differences} approximate the gradient at a cost of $d+1$ function evaluations (forward differences) or $2d$ (central differences), but scale poorly with dimension $d$.
\item \textbf{Random search} uses $O(1)$ (typically 2) evaluations per step, independent of $d$, at the cost of noisier gradient estimates.
\item \textbf{Nelder--Mead simplex} uses at most $n+1$ evaluations per step and adapts its simplex geometry, with no formal convergence guarantee in general.
\item \textbf{Grid search} is exhaustive and requires $O(N^d)$ evaluations --- exponential in dimension, making it impractical beyond $d \approx 3$.
\end{itemize}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark~B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation of the $i$-th partial derivative is:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \qquad i = 1, \ldots, d.
\label{eq:fd}
\end{equation}
The approximation error decomposes into two competing terms: \emph{truncation error} $O(\delta)$ (from the Taylor remainder $\frac{1}{2}\frac{\partial^2 f}{\partial x_i^2} \delta$) and \emph{floating-point error} $O(\varepsilon_{\text{mach}}/\delta)$ (from subtractive cancellation when $f(x+\delta e_i) \approx f(x)$ for small $\delta$). Setting these equal, $C_1 \delta = C_2\varepsilon_{\text{mach}}/\delta$, gives the optimal step size $\delta^{\star} = \sqrt{C_2/C_1} \cdot \sqrt{\varepsilon_{\text{mach}}}$. For double-precision ($\varepsilon_{\text{mach}} \approx 10^{-16}$), $\delta^{\star} \approx 10^{-8}$. Central differences ($[f(x + \delta e_i) - f(x - \delta e_i)]/(2\delta)$) have $O(\delta^2)$ truncation error, shifting the optimal $\delta^{\star}_{\text{central}} \approx \varepsilon_{\text{mach}}^{1/3} \approx 10^{-5}$ and achieving smaller minimum error $O(\varepsilon_{\text{mach}}^{2/3})$ vs $O(\varepsilon_{\text{mach}}^{1/2})$ for forward differences. The two test values are $\delta = 0.05$ (acceptable, truncation-dominated, error $\approx 10^{-2}$) and $\delta = 0.8$ (poor, severe truncation error $\approx 0.4 \cdot |\partial^2 f/\partial x_i^2|$ that distorts the gradient direction).

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Randomised Gradient-Free Method}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$; normalise $u_k \gets u_k / \|u_k\|$ (uniform on unit sphere)
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The estimator $\hat{g}_k$ is a \emph{directional derivative} along a uniformly random direction, requiring only 2 function evaluations regardless of dimension. In expectation, $\mathbb{E}[\hat{g}_k] = \nabla f_\delta(x_k)$ where $f_\delta(x) = \mathbb{E}_{u \sim \mathcal{N}(0,I)}[f(x + \delta u)]$ is the Gaussian-smoothed (randomised) version of $f$. This smoothing has two effects: (i) $f_\delta$ is differentiable even if $f$ is not (useful for non-smooth objectives); (ii) $\nabla f_\delta(x) \approx \nabla f(x)$ for smooth $f$ with error $O(\delta^2)$, so the estimator is approximately unbiased. The variance of $\hat{g}_k$ is $O(f(x_k)^2/\delta^2)$, so convergence is slow compared to full gradient methods but dimension-free in terms of function evaluations.

\subsection{Part B: Derivative-Free Methods on Benchmark~C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$, iteratively transforming it through four geometric operations without gradient information:

\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move worst vertex through centroid of remaining vertices.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, try to move further.
\item \textbf{Outside/inside contraction} ($\rho = 0.5$): if reflection worsened, contract towards centroid.
\item \textbf{Shrink} ($\sigma = 0.5$): contract all vertices towards the best vertex.
\end{enumerate}

Settings: initial simplex step $= 0.35$, 160 iterations. These standard Nelder--Mead parameters are applied from starting point $x_0 = (-1, 1)$. The primary failure mode in $d > 1$ is \emph{simplex degeneration}: the simplex collapses to a lower-dimensional manifold (all three vertices becoming nearly collinear in $\mathbb{R}^2$), after which neither reflection nor expansion can restore the simplex volume. The shrink step (contracting all vertices towards the best point) can also cause irreversible collapse. In practice, degeneracy detection and periodic restarts are used to mitigate this, but formal convergence guarantees remain elusive for $d \geq 2$.

\subsection{Problem Setup and KKT Conditions}

Minimise $f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)$ (Benchmark~B) subject to the inequality constraint $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$.

The \emph{Karush--Kuhn--Tucker} (KKT) necessary optimality conditions for the constrained problem $\min_x f(x)$ subject to $g(x) = 0.5 - x_1 \leq 0$ are:
\begin{align}
\nabla f(x^{\star}) + \mu^{\star} \nabla g(x^{\star}) &= 0 \label{eq:kkt_stationarity} \\
g(x^{\star}) &\leq 0 \label{eq:kkt_primal} \\
\mu^{\star} &\geq 0 \label{eq:kkt_dual} \\
\mu^{\star} g(x^{\star}) &= 0 \label{eq:kkt_complementarity}
\end{align}
Condition \eqref{eq:kkt_complementarity} (complementary slackness) implies that either the constraint is inactive ($g(x^{\star}) < 0$, $\mu^{\star} = 0$) or active ($g(x^{\star}) = 0$, $\mu^{\star} \geq 0$). Since the unconstrained minimum $(0.582, 2.0)$ satisfies $x_1 = 0.582 > 0.5$, it is \emph{feasible} and the constraint is \emph{inactive}. Thus, $\mu^{\star} = 0$ and the constrained minimum coincides with the unconstrained minimum, as confirmed by the projected GD result. \textbf{Economic interpretation:} the dual variable $\mu^{\star}$ quantifies the sensitivity of the optimal objective to tightening the constraint: $\partial f^{\star}/\partial b = \mu^{\star}$ where $b = 0.5$ is the constraint RHS. Since $\mu^{\star} = 0$, marginally tightening the constraint ($b \to 0.5 + \varepsilon$) would not change $f^{\star}$ --- the constraint is non-binding. If the constraint were active ($\mu^{\star} > 0$), relaxing the constraint by $\varepsilon$ would decrease $f^{\star}$ by $\mu^{\star}\varepsilon$.

\textbf{Constraint qualification.} The KKT conditions are \emph{necessary} (not just sufficient) only when a constraint qualification (CQ) holds at $x^\star$. For a single linear constraint $g(x) = 0.5 - x_1 \leq 0$, the \emph{Linear Independence Constraint Qualification} (LICQ) holds trivially ($\nabla g = [-1, 0]^T \neq 0$ always), guaranteeing that any local minimiser satisfies the KKT conditions \eqref{eq:kkt_stationarity}--\eqref{eq:kkt_complementarity}. For nonlinear constraints, CQs (Slater's condition for convex constraints, MFCQ for general nonlinear) must be verified separately.

\subsection{Methods}

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Standard gradient step (may be infeasible)}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project back: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection $\Pi_{\mathcal{X}}(z) = \arg\min_{x \in \mathcal{X}} \|x - z\|^2$ onto the half-space $\{x : x_1 \geq 0.5\}$ is trivial: $\Pi_{\mathcal{X}}(z) = (\max(0.5, z_1),\ z_2)$. For more complex constraint sets (e.g.\ general polyhedra, semidefinite constraints), computing the projection can be a significant computational burden.

\textbf{Proximal gradient interpretation.} PGD can be interpreted as the \emph{proximal gradient} method applied to $\min_x f(x) + \iota_{\mathcal{X}}(x)$, where $\iota_{\mathcal{X}}$ is the indicator function ($0$ inside $\mathcal{X}$, $+\infty$ outside). The proximal operator of $\iota_{\mathcal{X}}$ is exactly the projection: $\text{prox}_{\alpha \iota_{\mathcal{X}}}(z) = \Pi_{\mathcal{X}}(z)$. This viewpoint unifies PGD with other splitting methods (ISTA, ADMM) and shows that the same $O(1/k)$ convergence rate (and $O(1/k^2)$ with acceleration) applies to all methods of this family.

\textbf{Accelerated proximal gradient (FISTA).} Combining Nesterov's momentum from Section~\ref{sec:q2} with the proximal gradient step gives the \emph{Fast Iterative Shrinkage-Thresholding Algorithm} (FISTA, Beck \& Teboulle, 2009):
\begin{itemize}[nosep]
\item $y_{k+1} = \text{prox}_{\alpha g}(x_k - \alpha \nabla f(x_k))$ \quad (proximal gradient step)
\item $x_{k+1} = y_{k+1} + \frac{k-1}{k+2}(y_{k+1} - y_k)$ \quad (Nesterov momentum)
\end{itemize}
where $g$ is any convex (possibly non-smooth) regulariser. For $g = \iota_{\mathcal{X}}$ (indicator function), FISTA reduces to accelerated projected GD with $O(1/k^2)$ convergence. For $g = \lambda\|\cdot\|_1$ (L1 regularization), FISTA solves LASSO at $O(1/k^2)$ rate, vastly outperforming the unaccelerated ISTA. This directly connects the Nesterov theory of Question~2 to constrained and regularized optimisation.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Add penalty for constraint violation}
    \State $\nabla F_{\lambda}(x)_{[1]} \gets \nabla f(x)_{[1]} - \lambda \cdot \mathbf{1}[x_1 < 0.5]$ \Comment{Subgradient of penalty term}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty term $\lambda \max(0, 0.5 - x_1)$ adds a cost proportional to the constraint violation, shifting the unconstrained minimum of $F_\lambda$ towards feasibility. Theoretically, $x^{\star}(\lambda) \to x^{\star}_{\text{constrained}}$ as $\lambda \to \infty$. However, large $\lambda$ increases the Lipschitz constant of $\nabla F_\lambda$, requiring smaller step sizes for stability.

\textbf{Hyperparameters:} Projected GD ($\alpha = 0.08$, 100 iterations); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ and $\alpha = 0.05$ for $\lambda \leq 1.8$, $\alpha = 0.03$ for $\lambda = 4.5$; Unconstrained GD ($\alpha = 0.07$, 100 iterations).

\textbf{Projected GD} enforces \emph{hard} feasibility at every iteration. This is the fundamental strength: the projection guarantee is exact regardless of the objective gradient. The requirement is a projectable constraint set, which is trivial for box/half-space constraints but can require solving a secondary optimisation problem for general convex sets. For $L$-smooth convex $f$, projected GD with $\alpha = 1/L$ achieves $f(x_k) - f^\star \leq \frac{L\|x_0 - x^\star\|^2}{2k}$ ($O(1/k)$ rate), identical to the unconstrained rate. Since the constraint is inactive at $x^\star$ in this experiment (Benchmark~B's minimum satisfies $x_1 = 0.582 > 0.5$), the projection never activates after the first few steps and projected GD effectively reduces to unconstrained GD with $\mu$-strongly-convex linear convergence $(1 - \mu/L)^k$ once the iterates enter the feasible interior.

\textbf{Penalty methods} encode the constraint \emph{softly}: the parameter $\lambda$ controls the strength. They require only gradient evaluation of $F_\lambda$, making them applicable when projection is expensive. The trade-off: sufficiently large $\lambda$ enforces feasibility but requires smaller step sizes. Specifically, the gradient $\nabla F_\lambda$ has a discontinuity at $x_1 = 0.5$ (the penalty's subgradient is $-\lambda$ for $x_1 < 0.5$, $0$ for $x_1 > 0.5$), which creates a large effective Lipschitz constant near the boundary when $\lambda$ is large. To maintain a descent step size $\alpha < 2/L_\lambda$, $\alpha$ must decrease as $\lambda$ increases --- confirmed by the experimental settings ($\alpha = 0.05$ for $\lambda \leq 1.8$, $\alpha = 0.03$ for $\lambda = 4.5$).

\textbf{Sequential quadratic programming (SQP):} For general nonlinear constraints $g_i(x) \leq 0$, the state-of-the-art approach is SQP, which linearises the constraints and solves a sequence of QP subproblems: $\min_p \frac{1}{2}p^T B_k p + g_k^T p$ subject to $\nabla g_i(x_k)^T p \leq -g_i(x_k)$. The QP can be solved efficiently via active-set or interior-point methods, and the KKT multipliers provide estimates of $\mu^\star$. SQP achieves local superlinear convergence (analogous to Newton) and is the basis for most industrial nonlinear programming solvers (e.g.\ SNOPT, IPOPT).

\textbf{Relationship to logarithmic barrier (interior point):} An alternative to penalty methods for inequality constraints is the \emph{logarithmic barrier}: $F_t(x) = f(x) - \frac{1}{t}\log(-g(x))$ (for $g(x) < 0$). As $t \to \infty$, $x^{\star}(t) \to x^{\star}_{\text{constrained}}$. Unlike the penalty method, the barrier enforces strict feasibility automatically (the $-\log$ term becomes $+\infty$ at the constraint boundary), avoiding any constraint violation. Interior-point methods based on the log barrier achieve polynomial-time complexity for convex problems and are the state-of-the-art for large-scale LP and QP.

\textbf{Relationship to augmented Lagrangian:} A significant limitation of penalty methods is the ill-conditioning at large $\lambda$. The \emph{augmented Lagrangian} method (Hestenes--Powell--Rockafellar) addresses this by maintaining a dual variable $\mu_k$ (Lagrange multiplier estimate):
\begin{equation}
L_\lambda(x, \mu) = f(x) + \mu g(x) + \frac{\lambda}{2} \max(0, g(x))^2.
\end{equation}
Updating $\mu_{k+1} = \mu_k + \lambda g(x_k)$ at each step allows exact constraint satisfaction at moderate $\lambda$, avoiding the conditioning degradation of the pure penalty approach. This makes augmented Lagrangian methods the preferred choice for production constrained optimisation.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$ (a box polytope; see Section~\ref{sec:benchD}).

\textbf{Linear Programme (LP):} Minimise $f(x) = a^T x$ with $a = [1, 2]^T$ over $\mathcal{X}$. Since $f$ is linear and $\mathcal{X}$ is a bounded polytope, the fundamental theorem of linear programming guarantees the minimum is attained at a \emph{vertex} of $\mathcal{X}$. For a box, the vertices are the $2^d = 4$ corners. Since both components of $a$ are positive, the minimum is at the component-wise lower bound:
\begin{equation}
x^{\star} = (0.5,\, -5), \qquad f^{\star} = 1 \cdot 0.5 + 2 \cdot (-5) = -9.5.
\end{equation}

The parallel contour lines decrease towards the lower-left, and the minimum is achieved at the corner $(0.5, -5)$. \subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) Algorithm}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{z \in \mathcal{X}}\, \nabla f(x_k)^T z$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: $x_{k+1} \in \mathcal{X}$ automatically}
\EndFor
\end{algorithmic}
\end{algorithm}

\textbf{Key property:} Since $x_k, z_k \in \mathcal{X}$ (a convex set), $x_{k+1} = \beta x_k + (1-\beta) z_k \in \mathcal{X}$ for any $\beta \in [0,1]$. Frank--Wolfe thus maintains feasibility \emph{implicitly without any projection}.

\textbf{Linear Minimisation Oracle:} For the box $\mathcal{X} = \prod_i [l_i, u_i]$, the LP subproblem $\min_{z \in \mathcal{X}} \nabla f(x)^T z$ decouples per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\label{eq:fw_oracle}
\end{equation}
This requires $O(d)$ operations per iteration, which is the same cost as a gradient evaluation. For complex constraint sets (e.g.\ nuclear norm ball, flow polytopes), this oracle can be solved in closed form or by efficient specialised algorithms, making Frank--Wolfe preferable to projected gradient descent. Note the connection to \emph{coordinate descent}: the LMO on the $\ell_1$ ball selects coordinate $i^\star = \arg\max_i |\nabla f(x)_i|$ and places all weight there, which is a greedy single-coordinate update. Coordinate descent algorithms (cyclically updating one coordinate at a time) are closely related to this principle and are the standard solvers for LASSO-type problems (e.g.\ GLMNET, scikit-learn's \texttt{lasso\_cd}).

\begin{theorem}[Frank--Wolfe Convergence, $O(1/k)$]
\label{thm:fw}
For $f$ convex and $L$-smooth, Frank--Wolfe with step size $\gamma_k = 2/(k+2)$ satisfies:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L \cdot D^2}{k+2}, \quad D = \text{diam}(\mathcal{X}) = \max_{x,y \in \mathcal{X}} \|x-y\|.
\label{eq:fw_rate}
\end{equation}
\end{theorem}

For our box $\mathcal{X} = [0.5, 5] \times [-5, 10]$: the diameter is $D = \|(5, 10) - (0.5, -5)\| = \|(4.5, 15)\| = \sqrt{20.25 + 225} \approx 15.66$. For the interior optimum ($L = 2$), Theorem~\ref{thm:fw} gives the bound after $k = 180$ iterations as $f(x_k) - f^\star \leq \frac{2 \cdot 2 \cdot 245.25}{182} \approx 5.4$, while the actual gap is $0.005$ --- confirming the bound is very conservative (it accounts for worst-case starting points far from the optimum).

\textbf{Frank--Wolfe vs Projected GD:} Both methods achieve the same $O(1/k)$ convergence rate for smooth convex problems. The key distinctions are: (1) projected GD can be accelerated to $O(1/k^2)$ via Nesterov's technique while standard FW cannot; (2) the LMO in FW costs $O(d)$ for box constraints (same as a gradient step), whereas projection onto general convex sets can cost $O(d^2)$ or more; (3) FW naturally produces sparse iterates (convex combinations of vertices) while PGD does not. Thus FW is preferred for high-dimensional problems with special constraint structure (sparsity, flow polytopes), while PGD is preferred for simple constraints where projection is cheap and acceleration matters.

\textbf{Frank--Wolfe gap and duality.} The quantity $h(x) = \nabla f(x)^T(x - z^{\star}(x))$ where $z^{\star}(x) = \arg\min_{z \in \mathcal{X}} \nabla f(x)^T z$ is the \emph{Frank--Wolfe gap}. By first-order convexity, $f(z^{\star}(x)) \geq f(x) + \nabla f(x)^T(z^{\star}(x) - x)$, which rearranges to $\nabla f(x)^T(x - z^{\star}(x)) \leq f(x) - f(z^{\star}(x)) \leq f(x) - f^{\star}$, so $h(x) \geq f(x) - f^{\star}$. Thus the FW gap is a \emph{computable certificate}: when $h(x_k) < \varepsilon$, we are guaranteed $f(x_k) - f^{\star} < \varepsilon$ without knowing $f^{\star}$. For the LP case ($f$ linear), $h(x) = \nabla f^T(x - z^{\star})$ equals the LP duality gap, connecting FW directly to LP duality theory. Figure~\ref{fig:q6_fw_gap} verifies that $h(x_k) \geq f(x_k) - f^{\star}$ holds at every iteration and that the gap tracks the actual suboptimality closely.

\subsection{Interior vs Boundary Optimum: Theoretical Comparison}

\textbf{Interior optimum:} Frank--Wolfe converges at rate $O(1/k)$ (sublinear), exhibiting the characteristic zig-zag as the LMO alternates between opposing vertices. Near the optimum, the gradient $\nabla f(x^{\star}) \to 0$ but the LMO still selects a vertex (not the interior point), causing systematic oscillation. The fixed $\beta$ schedule does not allow the step to decay, resulting in residual oscillation. The theoretically optimal decaying schedule $\gamma_k = 2/(k+2)$ would eventually enforce smaller moves and reduce oscillation.

\textbf{Boundary optimum:} Frank--Wolfe is well-suited to boundary optima by its LP oracle structure: since $\partial f/\partial x_1 = 2x_1 > 0$ for all $x_1 \geq 0.5$, the LMO always selects $z_1 = l_1 = 0.5$, driving $x_1$ monotonically towards the constraint boundary. For $x_2$, the gradient is $\partial f/\partial x_2 = 2x_2$, so the LMO selects $z_2 = -5$ when $x_2 > 0$ and $z_2 = +10$ when $x_2 \leq 0$. This causes oscillation around $x_2 = 0$: once $x_2$ reaches near zero, the LMO alternates between $z_2 = -5$ (when $x_2 > 0$) and $z_2 = 10$ (when $x_2 \leq 0$), creating persistent oscillation. The final value $x_2 = -0.337$ reflects this oscillation rather than the true minimum $x_2 = 0$. The standard decaying step size $\gamma_k = 2/(k+2) \to 0$ would eventually suppress this oscillation, but fixed $\beta$ does not.

\textbf{Sparse solutions and LASSO.} A key advantage of Frank--Wolfe over projected gradient descent is that its iterates are always convex combinations of at most $k+1$ vertices after $k$ iterations. For problems with sparsity-inducing constraints (e.g.\ the $\ell_1$-ball $\{x : \|x\|_1 \leq \tau\}$), the LMO $\min_{z:\|z\|_1 \leq \tau} \nabla f(x)^T z$ selects a vertex $z = \pm\tau e_{i^\star}$ where $i^\star = \arg\max_i |\nabla f(x)_i|$ (the coordinate with largest gradient magnitude). Frank--Wolfe thus naturally produces \emph{sparse} iterates: after $k$ steps, $x_k$ has at most $k$ non-zero entries. This is directly applicable to the LASSO problem $\min_{\|\theta\|_1 \leq \tau} \|X\theta - y\|^2$, where FW provides a principled projection-free solver. Projected gradient descent does not share this sparsity property: projecting onto the $\ell_1$-ball via soft-thresholding produces dense iterates in general.

\textbf{Standard vs fixed step size:} The theoretical $O(1/k)$ rate requires the decaying schedule $\gamma_k = 2/(k+2)$ (rather than fixed $\beta$). With fixed $\beta$, the effective mixing coefficient $1 - \beta$ is constant, meaning the influence of the current LMO solution does not diminish over time. This causes persistent oscillation near the optimum, as observed in Figure~\ref{fig:q6_fw_conv}. Using the decaying schedule would improve convergence near the minimum, at the cost of slightly more complex implementation.

\textbf{Optimality of the $O(1/k)$ rate:} The standard Frank--Wolfe rate $O(1/k)$ is \emph{optimal} for the class of methods that access $f$ only through linear function queries (i.e.\ gradient evaluations without curvature information). Any algorithm in this class requires $\Omega(1/k)$ steps to guarantee $f(x_k) - f^\star \leq \varepsilon$ in the worst case. This is consistent with the rate being achievable but not improvable without stronger oracle information. Projected GD also achieves $O(1/k)$ but can be accelerated to $O(1/k^2)$ via Nesterov's technique, which uses the same gradient oracle but with \emph{momentum} --- extra state beyond what a single-query method uses.

\textbf{Linear convergence via away-steps:} The standard Frank--Wolfe achieves only $O(1/k)$ even for strongly convex $f$ on a polytope. The \emph{away-step} variant (Guelat \& Marcotte, 1986; Lacoste-Julien \& Jaggi, 2015) augments each step with an option to \emph{increase} the weight on a vertex $s_k \in \mathcal{S}_k$ (the active set), enabling the iterates to ``back away'' from poorly positioned vertices. This breaks the zig-zag pattern and achieves \emph{linear} convergence rate $(1 - \mu/LC^2)^k$ where $C$ is the pyramidal width of $\mathcal{X}$ --- a significant improvement for strongly convex problems at the cost of maintaining the active set.

\subsection{Key Themes}

\textbf{Condition number dominates convergence.} On well-conditioned problems ($\kappa \approx 1$, Benchmark~A), nearly all methods converge quickly and differences are small. On the extremely ill-conditioned Rosenbrock ($\kappa \approx 2000$), the spread in final objective values across methods spans three orders of magnitude, illustrating how critical curvature information is.

\textbf{Information order vs per-iteration cost.} First-order methods (GD, momentum, adaptive) require $O(d)$ work per iteration. Newton's method requires $O(d^3)$ for the Hessian solve but converges quadratically --- making it the overall winner in terms of iterations-to-solution when the Hessian is available and $d$ is moderate. Derivative-free methods (FD, Nelder--Mead, grid search) trade gradient accuracy for flexibility at higher per-iteration cost.

\textbf{Problem structure matters.} Nesterov's $O(1/k^2)$ rate assumes convexity; it substantially outperforms GD on Rosenbrock but the function's severe non-convexity means neither can be guaranteed to converge to the global minimum. Newton's method, despite exploiting full second-order information, reaches only $(0.183, 0.020)$ after 20 iterations on Rosenbrock --- far from the global minimum at $(1,1)$ --- because the initial point lies in the regime where the Hessian is poorly conditioned for large-step Newton. More fundamentally, non-convex functions have \emph{saddle points} (where the gradient is zero but the Hessian has both positive and negative eigenvalues) and \emph{local minima} that all gradient-based methods may converge to. On Rosenbrock, the saddle point at approximately $(-0.32, 0.10)$ can temporarily slow trajectories. Stochastic perturbations (SGD noise) and random restarts are common heuristics for escaping saddle points in practice.

\textbf{Constraints as a challenge.} The transition from unconstrained to constrained optimisation introduces feasibility management. Projected GD elegantly handles this via the projection, while penalty methods offer a gradient-free route to constraint enforcement at the cost of conditioning. Frank--Wolfe's projection-free approach is most natural for LP-structured constraint sets.

\textbf{Hyperparameter sensitivity.} A cross-cutting observation is that all methods exhibit significant sensitivity to step-size selection, particularly on ill-conditioned problems. On Rosenbrock ($\kappa \approx 2000$): (i) GD requires $\alpha < 2/L \approx 0.002$ for stability; too large a step causes divergence, too small gives negligible progress. (ii) Heavy Ball is even more sensitive --- the theoretically optimal $\beta = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1) \approx 0.956$ for the quadratic case would give better convergence than the tuned $\beta = 0.86$, but this requires knowing $\kappa$. (iii) Newton's damped step $\alpha = 0.22$ is a conservative choice that sacrifices initial speed for stability; backtracking line search would adaptively find a better step at runtime. This hyperparameter sensitivity reinforces the value of methods with built-in step-size adaptation (Adam, Polyak step, backtracking Newton).

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report has provided a rigorous comparative study of optimisation algorithms spanning six methodological categories, with consistent empirical evaluation across three benchmark problems and theoretical analysis grounding each experimental observation.

\textbf{Q1 (Adaptive step sizes):} The Polyak step achieves optimal performance on Rosenbrock ($f = 0.0094$, best among all first-order methods tested) when $f^{\star}$ is known exactly, but diverges catastrophically when $f^{\star}$ is misspecified --- a critical practical limitation. Adagrad and Heavy Ball are robust alternatives with complementary strengths: Adagrad provides guaranteed monotone step decay and $O(\sqrt{T})$ regret, while Heavy Ball accelerates through momentum at the risk of oscillation.

\textbf{Q2 (Momentum methods):} Nesterov acceleration ($f = 0.479$ on Rosenbrock) achieves the optimal first-order rate $O(1/k^2)$, which for $\kappa = 2000$ requires $O(\sqrt{\kappa}) \approx 45\times$ fewer iterations than GD. The key mechanism --- gradient evaluation at the lookahead point $\tilde x_k = x_k + \beta_k z_k$ --- provides the corrective signal that enables the improved rate over Heavy Ball. Mini-batch SGD variance scales as $1/b$; variance-reduction methods (SVRG, SAGA) achieve linear convergence at mini-batch cost by periodically recomputing a full gradient. Adam approximates the diagonal Fisher information matrix, providing a practical approximation to the natural gradient.

\textbf{Q3 (Newton's method):} Second-order methods dominate first-order on all benchmarks. Newton achieves the exact solution in one step on the quadratic Benchmark~A (quadratic convergence is exact for quadratics), converges in $\sim$5 steps on Benchmark~B, and reaches $f = 0.686$ on Rosenbrock in 20 iterations vs GD's $f = 3.73$ in 80 iterations. The damped Newton step ($\alpha = 0.22$) is essential for global convergence; Armijo backtracking line search provides an adaptive alternative. For large-scale problems, Newton-CG (Hessian-free via Hessian-vector products) and trust-region methods extend Newton's convergence properties to $d \sim 10^7$ settings.

\textbf{Q4 (Derivative-free):} FD gradient descent with $\delta = 0.05$ closely approximates exact GD, confirming the $O(\delta)$ truncation error bound; $\delta = 0.8$ causes severe distortion. Random search is uniquely scalable in high dimensions ($O(1)$ function evaluations per step) but converges slowly. Nelder--Mead navigates the Rosenbrock valley effectively without gradient information by adapting its simplex geometry.

\textbf{Q5 (Constrained optimisation):} Projected GD enforces hard feasibility from iteration~1 at negligible cost for simple constraints. Penalty methods provide a gradient-only alternative but require careful $\lambda$ tuning; the augmented Lagrangian resolves the ill-conditioning that limits pure penalty methods.

\textbf{Q6 (Frank--Wolfe):} The conditional gradient algorithm naturally maintains feasibility via convex combinations and produces sparse iterates for polyhedral constraints (e.g.\ LASSO $\ell_1$-ball), as each LMO step selects a vertex. The FW gap $h(x_k) \geq f(x_k) - f^\star$ provides a computable certificate without knowing $f^\star$. The $O(1/k)$ rate is optimal for the linear-oracle class; away-step FW achieves linear convergence for strongly convex $f$ on polytopes.

\textbf{Unifying framework --- mirror descent.} Many of the algorithms studied can be viewed as instances of \emph{mirror descent} (Nemirovski \& Yudin, 1983): $x_{k+1} = \arg\min_{x \in \mathcal{X}} \{\alpha \nabla f(x_k)^T x + D_\phi(x, x_k)\}$, where $D_\phi(x, y) = \phi(x) - \phi(y) - \nabla\phi(y)^T(x-y)$ is the Bregman divergence of a strongly convex mirror map $\phi$. With $\phi(x) = \frac{1}{2}\|x\|^2$ (squared Euclidean norm), mirror descent reduces to projected GD. Adagrad corresponds to a data-dependent mirror map $\phi_k(x) = \frac{1}{2}x^T G_k^{1/2} x$ (Bregman with diagonal metric). Frank--Wolfe can also be interpreted as mirror descent with a linear mirror map over the simplex. This unified view explains why all these methods achieve $O(1/k)$ convergence --- they all solve the same class of optimisation subproblem, differing only in the choice of $D_\phi$.

\textbf{Cross-cutting theme:} The condition number $\kappa$ is the single most predictive factor for algorithm difficulty. On Benchmark~A ($\kappa \approx 1$), nearly all methods converge within their iteration budgets. On Rosenbrock ($\kappa \approx 2000$), the spread in final objective values spans three orders of magnitude across methods. Algorithm selection should be guided by the estimated condition number: for $\kappa \ll 100$, simple GD or momentum suffices; for $\kappa \gg 100$, second-order methods or specialised adaptive methods become essential.

\textbf{Practical algorithm selection guide:}
\begin{itemize}[nosep]
\item \emph{Well-conditioned smooth problem, gradient available}: GD or Nesterov. Adam as robust default in ML.
\item \emph{Ill-conditioned smooth problem, $d$ small}: Newton with backtracking line search for maximum efficiency.
\item \emph{Ill-conditioned smooth problem, $d$ large}: L-BFGS (quasi-Newton) or Nesterov with restarts.
\item \emph{Gradient unavailable, $d$ small ($\leq 10$)}: Nelder--Mead or Bayesian optimisation.
\item \emph{Gradient unavailable, $d$ large}: Nesterov random search or evolutionary strategies.
\item \emph{Constrained problem, simple constraints}: Projected GD (hard feasibility, $O(1/k)$ convergence).
\item \emph{Constrained problem, LP-structured constraints, sparsity needed}: Frank--Wolfe conditional gradient.
\item \emph{Constrained problem, complex constraints, projection expensive}: Penalty method or augmented Lagrangian.
\end{itemize}

Future work could investigate adaptive Newton--Krylov methods that approximate the Hessian-vector product without forming the full Hessian, enabling second-order convergence in high-dimensional settings, and extend the Frank--Wolfe analysis to non-convex objectives using the FW gap as a stationarity measure.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball (Polyak Momentum)}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z  # Evaluate gradient at look-ahead point
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)  # Bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damped Step and Tikhonov Regularisation}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))  # Tikhonov regularisation
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g  # Fall back to gradient direction
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe (Conditional Gradient)}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: select vertex minimising g^T z over box
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
