\begin{abstract}
This report presents a comprehensive comparative study of optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark A, condition number $\kappa \approx 1$), a toy neural network loss with sinusoidal perturbation (Benchmark B, $\kappa \approx 7$), and the Rosenbrock function (Benchmark C, $\kappa \approx 2504$). Twelve algorithms across six categories are investigated and evaluated on convergence speed, trajectory behaviour, stability, and computational trade-offs: (1) adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball), (2) momentum-based and stochastic methods (Nesterov acceleration, Adam, mini-batch SGD), (3) Newton's method with local second-order approximations, (4) derivative-free approaches (finite differences, Nesterov random search, Nelder--Mead, grid search), (5) constrained optimisation via projected gradient descent and penalty methods, and (6) the Frank--Wolfe conditional gradient algorithm.

Key quantitative findings: Newton's method converges in a single step on the quadratic Benchmark A (vs.\ 80 GD iterations for comparable accuracy); Nesterov acceleration reduces the Rosenbrock objective from $3.39$ (GD) to $0.48$ in 150 iterations ($7\times$ improvement); the Polyak step size with misspecified $f^\star = 0$ diverges to $f \approx 4.77$ on Benchmark A while achieving the best convergence ($f = 0.024$) when $f^\star$ is exact on Benchmark C; finite-difference gradients with $\delta = 0.05$ closely track exact GD while $\delta = 0.8$ (beyond the optimal $\delta \approx \sqrt{\varepsilon_{\rm mach}} \approx 10^{-8}$) fails completely; and projected gradient descent enforces feasibility from the first iteration whereas penalty methods require large $\lambda$ (with consequent ill-conditioning) for comparable constraint satisfaction.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Iterative optimisation algorithms underpin virtually all of modern machine learning and data analysis. From fitting a linear regression model to training deep neural networks, the choice of optimisation algorithm -- and its hyperparameters -- determines both the quality of the solution found and the computational cost of finding it. This report systematically investigates six families of algorithms spanning first-order gradient methods, second-order Newton methods, derivative-free strategies, and constrained optimisation techniques, evaluating each on three test problems of increasing difficulty.

The central challenge addressed in this study is that no single method dominates across all settings: well-conditioned convex problems favour simple gradient descent or Newton's method; ill-conditioned problems benefit from adaptive step-size schemes or momentum; derivative-free methods trade gradient information for black-box applicability; and constrained problems require either projection oracles or penalty formulations. Understanding when and why each method succeeds is the primary analytical goal.

All experiments use \texttt{np.random.seed(42)} for reproducibility and are implemented in Python using NumPy. Figures are generated via Matplotlib.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \in \mathbb{R}^2 \sim \mathcal{N}(0,I), \quad
  y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
            = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a \emph{strongly convex quadratic} with constant Hessian $H = \frac{1}{m}X^T X \succ 0$. The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. Due to observation noise, the minimum loss is $J^{\star} \approx 0.4826$ (not zero). Starting point: $\theta_0 = [0, 0]^T$.

With $m = 1000$ i.i.d.\ standard-normal rows, the law of large numbers gives $H \approx I_2$, so the Lipschitz constant $L = \lambda_{\max}(H) \approx 1$ and the strong convexity parameter $\mu = \lambda_{\min}(H) \approx 1$, yielding condition number $\kappa = L/\mu \approx 1$. GD with $\alpha = 0.08$ is well within the stability bound $\alpha < 2/L \approx 2$, and converges at a near-optimal rate for this near-isotropic Hessian. Benchmark A is the most tractable of the three.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is:
\begin{equation}
  H(x) = \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}.
\end{equation}
The eigenvalues are $\lambda_1(x_1) = 2 - \sin(x_1) \in [1, 3]$ and $\lambda_2 = 10$, giving a condition number $\kappa(H) = 10 / (2 - \sin(x_1)) \in [3.3, 10]$ that varies with $x_1$. At the minimum $x_1^\star \approx 0.582$ where $\sin(0.582) \approx 0.549$, we obtain $L = \lambda_{\max} = 10$, $\mu = \lambda_{\min} \approx 1.451$, and $\kappa \approx 6.9$. The contour ellipses are elongated along $x_1$ (flatter curvature $\approx 1.45$) and compressed along $x_2$ (steeper curvature $10$). GD stability requires $\alpha < 2/L = 0.2$; the used $\alpha = 0.06$ satisfies this. The minimum lies at approximately $(0.582, 2.0)$ with $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian at the optimum $(1,1)$ is:
\begin{equation}
  H(1,1) = \begin{bmatrix} 2 + 1200(1)^2 - 400(1) & -400 \\ -400 & 200 \end{bmatrix}
         = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues approximately $0.4$ and $1001.6$, giving $\kappa \approx 2504$. For GD to remain stable, the step size must satisfy $\alpha < 2/\lambda_{\max} \approx 0.002$. With such a tiny step, GD's linear convergence rate is $\rho = (1 - 2\alpha\mu L/(\mu+L)^2) \approx 1 - 4 \times 10^{-4}$, meaning the error halves only every $\sim 1730$ iterations.

The Rosenbrock function has two distinct challenges: (1) \emph{fast convergence to the valley floor} --- the valley $x_2 = x_1^2$ is quickly reached from any starting point, since the gradient component perpendicular to the valley is large; and (2) \emph{slow progress along the valley floor} --- once in the valley, the gradient component along the valley direction is tiny (proportional to $1-x_1$), and the extreme curvature ratio $\kappa \approx 2504$ between valley-perpendicular and valley-parallel directions forces tiny step sizes. This two-phase behavior (fast then slow) is characteristic of Rosenbrock and is clearly visible in the contour trajectory plots. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}

For constrained problems (Questions 5--6): $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\subsection{Notation Summary}

Throughout this report, $\nabla f(x)$ denotes the gradient and $\nabla^2 f(x)$ the Hessian. The effective step size for Adagrad at coordinate $i$ is $\alpha_k^{(i)} = \alpha_0 / (\sqrt{G_k^{(i)}} + \varepsilon)$. The symbol $\odot$ denotes element-wise (Hadamard) product. Loss is always evaluated at the current (post-step) iterate unless stated otherwise.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}

\subsection{Algorithm Formulations}

Four adaptive step-size methods are compared against a constant step-size gradient descent (GD) baseline across all three benchmarks for 120 iterations.

\begin{proposition}[GD convergence for strongly convex functions]
Let $f$ be $\mu$-strongly convex and $L$-smooth ($\|\nabla^2 f(x)\| \leq L$ everywhere). Then GD with step size $\alpha \in (0, 2/(L+\mu))$ satisfies:
\begin{equation}
  \|x_k - x^\star\|^2 \leq \left(\frac{\kappa - 1}{\kappa + 1}\right)^{2k} \|x_0 - x^\star\|^2, \quad \kappa = L/\mu,
\end{equation}
achieved at the optimal step $\alpha^\star = 2/(\mu + L)$. The stability condition $\alpha < 2/L$ is necessary: larger steps cause divergence.
\end{proposition}

For Benchmark A ($\kappa \approx 1$), the rate $((\kappa-1)/(\kappa+1))^{2k} \approx 0$ for all $k \geq 1$: GD converges in very few iterations regardless of step size. For Benchmark C ($\kappa \approx 2504$), the rate is $\approx (1 - 8 \times 10^{-4})^k$: requiring $\approx 8650$ iterations to reduce error by $1/e$. This explains why all first-order methods struggle on Rosenbrock. Adaptive step-size methods aim to overcome this bottleneck by using curvature information to implicitly precompute an approximation to $H^{-1}$.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step is motivated by the inequality $f(x_k) - f^\star \leq \nabla f(x_k)^T(x_k - x^\star) \leq \|g_k\| \cdot \|x_k - x^\star\|$ (by Cauchy--Schwarz). Setting $\alpha_k = (f(x_k)-f^\star)/\|g_k\|^2$ gives the steepest descent step in the direction that reduces the ``optimality gap'' the most. When $f^\star$ is known exactly and $f$ is convex, the Polyak step achieves the optimal $O(1/k)$ rate for non-smooth problems.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Accumulate squared gradients per coordinate}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad adapts the learning rate inversely to the historical gradient magnitude. Coordinates that receive large, frequent gradients are penalised (smaller step), while rarely-updated coordinates retain a larger effective rate. The effective step at coordinate $i$ after $k$ iterations is $\alpha_0 / \sqrt{\sum_{t=1}^k g_t^{(i)2}}$, which decays monotonically as $O(1/\sqrt{k})$.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop addresses Adagrad's diminishing step-size problem by replacing the cumulative sum with an exponentially-weighted moving average. The decay $\beta$ controls the memory length: only the most recent $\sim 1/(1-\beta)$ gradient observations contribute substantially, preventing the effective step size from collapsing to zero on non-stationary problems.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta \in (0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

Heavy Ball (Polyak Momentum) accumulates a velocity vector $z_k$ using an exponential moving average of past gradients. The steady-state update can be written as $x_{k+1} - x_k \approx -\frac{\alpha}{1-\beta} \nabla f(x_k)$, effectively multiplying the gradient step by $1/(1-\beta)$. With $\beta = 0.9$ this gives a $10\times$ amplification, enabling faster descent at the cost of potential oscillation on ill-conditioned problems.

For a $\mu$-strongly convex, $L$-smooth quadratic, the theoretically optimal Heavy Ball parameters are:
\begin{equation}
  \alpha^\star = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}, \qquad \beta^\star = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2,
\end{equation}
yielding the accelerated linear rate $\rho_{\rm HB} = (\sqrt{\kappa}-1)^2/(\sqrt{\kappa}+1)^2$. For Rosenbrock with $\kappa \approx 2504$ ($L \approx 1001.6$, $\mu \approx 0.4$): $\beta^\star \approx (\sqrt{2504}-1)^2/(\sqrt{2504}+1)^2 \approx (49/51)^2 \approx 0.923$, and $\alpha^\star = 4/(\sqrt{L}+\sqrt{\mu})^2 = 4/(\sqrt{1001.6}+\sqrt{0.4})^2 \approx 4/(31.65+0.63)^2 \approx 4/1041 \approx 0.0038$. The used values ($\alpha = 0.0008$, $\beta = 0.86$) are conservative approximations (roughly $\alpha^*/5$, $\beta^*/0.93$) that trade some convergence speed for stability on the non-quadratic landscape.

\paragraph{Why does RMSprop converge to a higher value on Benchmark A?}
RMSprop's exponential moving average of squared gradients $v_k \gets 0.9 v_{k-1} + 0.1 g_k^2$ can ``over-adapt'': near the minimum where gradients are small, $v_k$ is dominated by the exponentially decayed history of larger earlier gradients, keeping the effective step size artificially small and preventing the method from fully converging to the minimum. This effect is especially pronounced on Benchmark A where the Hessian is nearly isotropic and per-coordinate adaptation provides no benefit, while the stale exponential average causes the method to settle at $f \approx 0.506$ rather than $0.4826$.

\textbf{Key finding:} The Polyak step size is exquisitely sensitive to the accuracy of $f^{\star}$. When the specified $f^{\star} = 0$ deviates from the true minimum, the step size $\alpha_k = (f(x_k) - 0)/(\|\nabla f(x_k)\|^2 + \varepsilon)$ grows without bound as $\|\nabla f\| \to 0$ while $f(x_k) \to f_{\mathrm{true}}^\star > 0$. This causes the iterates to leave the neighbourhood of the optimum, a failure mode unique to methods that use function-value information (see Table~\ref{tab:q1_final} for numerical evidence). On Benchmark C where $f^{\star} = 0$ is exact, Polyak achieves the best convergence among all five methods ($f = 0.024$ vs.\ GD $f = 3.514$), confirming that its theoretical advantages are realised only when $f^\star$ is precisely known.

\subsection{Comparative Analysis and Discussion}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^{\star}$ is known exactly (Rosenbrock), Polyak converges fastest ($f = 0.024$). Otherwise, Adagrad and Heavy Ball match the GD baseline on well-conditioned problems and outperform it on ill-conditioned ones.

\item \textbf{Monotone decay vs.\ oscillation:} Adagrad guarantees monotonically decreasing effective step sizes, making it inherently stable but prone to premature stalling on non-stationary problems. Heavy Ball can exhibit damped oscillation near the minimum but ultimately converges on strongly convex objectives.

\item \textbf{Stability:} GD baseline is most robust but slowest. Polyak is \emph{unstable} when $f^{\star}$ is misspecified --- this is its fundamental limitation in practice, since exact $f^\star$ is rarely known. RMSprop is the most practically stable adaptive method, balancing adaptivity with memory.

\item \textbf{Computational cost:} All methods have the same per-iteration cost of $O(d)$ gradient evaluations plus $O(d)$ auxiliary operations, where $d = 2$ in these experiments. Adagrad and RMSprop add $O(d)$ storage for accumulated second moments.

\item \textbf{Effect of condition number:} The results confirm that adaptive methods provide greater benefit as $\kappa$ increases. On Benchmark A ($\kappa \approx 1$), all methods perform equivalently. On Benchmark C ($\kappa \approx 2504$), Heavy Ball reduces the final objective by $2.5\times$ relative to GD, demonstrating that momentum effectively decouples convergence speed from the condition number.
\end{itemize}

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}

\subsection{Algorithm Formulations}

Having established in Question~\ref{sec:q1} that Adagrad and Heavy Ball can improve upon standard GD by adapting step sizes or using momentum, this section investigates two more theoretically grounded acceleration strategies: Nesterov's optimal first-order method and Adam, which combines both ideas.

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max} \in (0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead / extrapolated point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The key distinction from Heavy Ball (Algorithm~\ref{alg:heavyball}) is the \emph{lookahead}: the gradient is evaluated at the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$. This ``corrective look-ahead'' allows Nesterov momentum to anticipate its overshoot and adjust accordingly. The adaptive schedule $\beta_k = (k-1)/(k+2)$ ensures that $\sum_{k=1}^\infty (1-\beta_k) < \infty$, which is the key condition for the classical $O(1/k^2)$ convergence guarantee:

\begin{theorem}[Nesterov, 1983]
For an $L$-smooth convex function $f$, the Nesterov accelerated gradient method with $\alpha = 1/L$ satisfies:
\begin{equation}
  f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2}.
\end{equation}
This rate is optimal among all first-order methods for smooth convex optimisation.
\end{theorem}

The schedule implemented here caps $\beta_k$ at $\beta_{\max}$ for practical stability, ensuring the momentum parameter does not approach 1 too aggressively on non-convex problems like Rosenbrock.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{Biased first moment estimate}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Biased second moment estimate}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction (important in early iterations)}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \dfrac{\alpha\, \hat{m}_t}{\sqrt{\hat{v}_t} + \varepsilon}$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$, analogous to RMSprop's first moment) with per-coordinate adaptive scaling (via $v_t$, analogous to RMSprop's second moment). The bias-correction terms $(1-\beta_j^t)^{-1}$ prevent the early iterates from being unduly biased toward zero (since $m_0 = v_0 = 0$), which is especially important when $\beta_2 = 0.999$ and convergence is slow. Empirically, Adam requires less hyperparameter tuning than Nesterov while matching or exceeding its performance on many practical tasks.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, and 50 epochs, with data randomly shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1,\ldots,m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \dfrac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Mini-batch gradient}
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}
Each epoch with batch size $b = 5$ performs $m/b = 200$ parameter updates, while $b = 40$ performs only 25. The mini-batch gradient estimator is unbiased:
\begin{equation}
  \mathbb{E}[\hat{g}_\mathcal{B}] = \nabla J(\theta), \quad
  \mathrm{Var}[\hat{g}_\mathcal{B}] = \frac{\sigma^2_{\rm data}}{b} \cdot \Sigma_X,
\end{equation}
where $\sigma^2_{\rm data}$ is the observation noise variance and $\Sigma_X = X^T X/m$ is the data covariance. Smaller batches increase variance by factor $40/5 = 8\times$, explaining the greater oscillation near the minimum. For $\mu$-strongly convex objectives with mini-batch gradient variance $\sigma^2$, constant step-size SGD converges to a neighbourhood of size $\Theta(\alpha\sigma^2/\mu)$; convergence to the exact minimum requires a decaying step size $\alpha_k \to 0$ (not used here).
\end{remark}

\subsection{Discussion: Nesterov vs.\ Adam}

The results on Rosenbrock ($f = 0.479$ for Nesterov vs.\ $1.579$ for Adam) reveal a fundamental difference in assumptions. Nesterov's scalar momentum accumulates a \emph{single} velocity vector aligned with the dominant descent direction, effectively building kinetic energy along the valley floor. Adam's per-coordinate scaling $1/\sqrt{\hat{v}_t}$ applies \emph{different} effective step sizes to $x_1$ and $x_2$, which is beneficial when the Hessian is approximately diagonal and the coordinates are largely decoupled. However, the Rosenbrock function has a strongly non-diagonal Hessian with off-diagonal terms $h_{12} = -400x_1$, indicating strong coupling between coordinates. Adam's coordinate-wise treatment cannot capture this coupling, whereas Nesterov's scalar momentum (through the accumulated velocity) can align itself with the correlated descent direction.

This distinction has a practical implication: in deep learning with batch normalisation (which whitens layer inputs, making the effective Hessian more diagonal), Adam is typically preferred. For problems with strong coordinate coupling or known geometric structure, Nesterov or L-BFGS (quasi-Newton) methods are more appropriate.

\begin{remark}[Adam convergence subtleties]
Standard Adam does not always converge to the global optimum even on simple convex problems. Reddi et al.\ (2018) showed that Adam can diverge on certain online convex optimisation problems due to non-monotone effective step sizes: a large gradient at step $t$ inflates $v_t$, reducing the effective step at step $t+1$ even if subsequent gradients are small. The fix, AMSGrad, replaces $\hat{v}_t$ with a monotonically non-decreasing maximum $\hat{v}_t^{\max} = \max(\hat{v}_{t-1}^{\max}, \hat{v}_t)$, restoring convergence guarantees. In the deterministic full-batch setting used here, Adam's performance is reliable because the gradient signal is consistent; stochastic training (where this issue manifests) is not tested. The empirical success of Adam in practice (especially for neural network training) is attributed to its ability to adapt to gradient scale differences across layers rather than its theoretical convergence rate.
\end{remark}

\subsection{Local Approximations of $g(x) = x^4$}

The first-order methods studied in Questions~\ref{sec:q1} and~\ref{sec:q2} use only gradient information ($O(d)$ per iteration) and achieve at best $O(1/k^2)$ rates. This section investigates second-order Newton methods, which use Hessian information to achieve much faster (quadratic) convergence. To motivate Newton's method, we first examine how Taylor expansions provide local models of a function. Consider $g(x) = x^4$ as a simple scalar example.

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) = (0.25)^4 + 4(0.25)^3\,(x - 0.25)
          = 0.00391 + 0.0625(x - 0.25).
\end{equation}

\textbf{Second-order approximation:}
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
          = 0.00391 + 0.0625(x - 0.25) + \tfrac{1}{2}(12 \times 0.25^2)(x - 0.25)^2.
\end{equation}
Here $g'(x_0) = 4x_0^3 = 0.0625$ and $g''(x_0) = 12x_0^2 = 0.75$, so:
\begin{equation}
  g(x) \approx 0.00391 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The Newton update minimises the local quadratic model: setting $\frac{d}{dx}[g'(x_0)(x-x_0) + \frac{1}{2}g''(x_0)(x-x_0)^2] = 0$ gives the Newton step $x_1 = x_0 - g'(x_0)/g''(x_0) = 0.25 - 0.0625/0.75 = 0.1667$.

\subsection{Newton's Method with Damping}

\begin{algorithm}[H]
\caption{Damped Newton's Method}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0,1]$, damping $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov regularisation ensures $H_k \succ 0$}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction: minimiser of local quadratic}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$ \Comment{Damped Newton step}
\EndFor
\end{algorithmic}
\end{algorithm}

The Newton direction $p_k = H_k^{-1} g_k$ is the solution to the linear system $H_k p = g_k$, obtained via \texttt{np.linalg.solve} for stability. Damping $\lambda = 10^{-8}$ prevents numerical issues when the Hessian is near-singular. The step size $\alpha < 1$ (``damped Newton'') is necessary on non-convex problems like Rosenbrock where the Hessian changes rapidly and the full Newton step might overshoot.

\begin{proposition}[Quadratic convergence of Newton's method]
Let $f$ be twice differentiable with $L$-Lipschitz Hessian. If $x_0$ is sufficiently close to a local minimum $x^\star$ with $\nabla^2 f(x^\star) \succ 0$, then Newton's method with $\alpha = 1$ satisfies:
\begin{equation}
  \|x_{k+1} - x^\star\| \leq C\|x_k - x^\star\|^2,
\end{equation}
for some constant $C > 0$ (quadratic convergence). This means the number of correct digits doubles at each iteration.
\end{proposition}

Settings: GD uses 80 iterations; Newton uses 20 iterations with $\lambda = 10^{-8}$.

\subsection{Theoretical Discussion: Newton vs.\ Gradient Descent}

The fundamental advantage of Newton's method is \emph{affine invariance}: the Newton direction $p_k = H^{-1}\nabla f(x)$ is unchanged by any invertible affine coordinate transformation, making Newton immune to the condition number. For GD, the convergence rate depends on $\kappa = L/\mu$ through $\rho = (\kappa-1)/(\kappa+1)$; for Rosenbrock with $\kappa \approx 2504$, $\rho \approx 0.9992$, meaning the error decreases by only $0.08\%$ per iteration. Newton's quadratic convergence near the minimum means the error \emph{squares} at each step, which is dramatically faster.

\paragraph{Newton Decrement.}
A principled stopping criterion for Newton's method is the \emph{Newton decrement}:
\begin{equation}
  \lambda(x) = \sqrt{\nabla f(x)^T \bigl[\nabla^2 f(x)\bigr]^{-1} \nabla f(x)}.
\end{equation}
The Newton decrement satisfies:
\begin{itemize}[nosep]
  \item $f(x) - f(x - [\nabla^2 f(x)]^{-1}\nabla f(x)) \approx \lambda(x)^2/2$ (expected decrease of full Newton step);
  \item For self-concordant functions: $f(x) - f^\star \leq \lambda(x)^2/2 - \ln(1-\lambda(x)^2/2)$ (gap upper bound);
  \item For $\mu$-strongly convex $f$: $f(x) - f^\star \leq \lambda(x)^2/(2\mu)$.
\end{itemize}
When $\lambda(x)^2 < 2\varepsilon$, one can stop with an $\varepsilon$-suboptimality guarantee. This \emph{self-certifying} property is a key advantage over GD, which requires knowledge of global $L$ and $\mu$ to estimate when to stop.

\paragraph{Cost comparison and quasi-Newton methods.}
Newton pays $O(d^2)$ for Hessian construction and $O(d^3)$ for the linear solve per iteration, making it impractical for large $d$ (e.g., deep neural networks with $d \sim 10^8$ parameters). Quasi-Newton methods such as L-BFGS maintain an \emph{implicit} approximate inverse Hessian $B_k \approx H_k^{-1}$ built from the history of gradient differences:
\begin{equation}
  s_k = x_{k+1} - x_k, \quad y_k = \nabla f(x_{k+1}) - \nabla f(x_k), \quad B_{k+1}s_k = y_k.
\end{equation}
L-BFGS stores the most recent $m$ pairs $(s_k, y_k)$ and applies the Hessian approximation implicitly in $O(md)$ time, achieving super-linear (near-quadratic) convergence at $O(md)$ storage --- the practical choice for medium-scale smooth optimisation ($d \leq 10^6$).

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \quad i = 1,\ldots,d.
\end{equation}
The total error decomposes as:
\begin{equation}
  \left|\frac{f(x+\delta e_i) - f(x)}{\delta} - \frac{\partial f}{\partial x_i}(x)\right|
  \leq \underbrace{\frac{\delta}{2}\left|\frac{\partial^2 f}{\partial x_i^2}(x)\right|}_{\text{truncation error: }O(\delta)} + \underbrace{\frac{2\varepsilon_{\text{mach}}}{\delta}}_{\text{roundoff error: }O(\varepsilon_{\text{mach}}/\delta)},
\end{equation}
where $\varepsilon_{\text{mach}} \approx 10^{-16}$ for double-precision. The optimal $\delta$ balances these: $\delta_{\text{opt}} \sim \sqrt{\varepsilon_{\text{mach}}} \approx 10^{-8}$, giving total error $O(\varepsilon_{\text{mach}}^{1/2}) \approx 10^{-8}$.

An improved alternative is the \emph{central finite difference}:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x+\delta e_i) - f(x-\delta e_i)}{2\delta},
\end{equation}
which has $O(\delta^2)$ truncation error (the odd symmetry cancels the first-order term), requiring $\delta_{\text{opt}} \sim \varepsilon_{\text{mach}}^{1/3} \approx 5 \times 10^{-6}$ for optimal accuracy $\approx 10^{-11}$. This method was not used here but would provide better gradient estimates at the same evaluation cost ($d+1$ evaluations total, needing $2d$ per gradient call but one can reuse $f(x)$).

In the experiment, $\delta = 0.05$ gives truncation error $\sim 0.025 \times |f_{x_ix_i}| \approx 0.05 \ll |\nabla f|$ near the starting point, so gradient direction is accurate. At $\delta = 0.8$, truncation error $\sim 0.8$, which exceeds $|\nabla f|$ near the optimum, rendering the gradient estimate unreliable. The FD method requires $d+1 = 3$ function evaluations per gradient.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order Gradient Estimate)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$, normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform on unit sphere}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Randomised directional derivative}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The gradient estimator $\hat{g}_k$ is an unbiased estimate of $\nabla f_\delta(x_k)$ where $f_\delta(x) = \mathbb{E}_{u \sim \text{Unif}(\mathcal{S}^{d-1})}[f(x+\delta u)]$ is the Gaussian-smoothed surrogate. Specifically:
\begin{equation}
  \mathbb{E}[\hat{g}_k] = \frac{d}{\delta}\,\mathbb{E}_u[f(x+\delta u) u]  = \nabla f_\delta(x_k).
\end{equation}
Crucially, this estimator requires only \textbf{two} function evaluations per iteration regardless of $d$, in contrast to forward FD which requires $d+1$. This makes Nesterov random search \emph{dimension-free} in per-step oracle cost.

The price is \emph{high variance}: the estimator uses a single random direction, so $\mathrm{Var}[\hat{g}_k] \sim d \|\nabla f(x_k)\|^2 / \delta^2$ (grows with $d$). Consequently, for smooth convex $f$, the zeroth-order oracle complexity is $O(d/\varepsilon)$ function evaluations to achieve $\varepsilon$-accuracy, compared to $O(1/\varepsilon)$ for first-order methods (gradient descent). The factor of $d$ is the unavoidable \emph{dimension overhead} of not using gradient information.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm (Nelder \& Mead, 1965) is a direct-search method that requires no gradient information. It maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four operations:
\begin{enumerate}[nosep]
  \item \textbf{Reflection} ($\alpha_r = 1.0$): move worst vertex $x_{\text{worst}}$ through centroid $\bar{x}$ of the remaining vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x_{\text{worst}})$.
  \item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, try $x_e = \bar{x} + \gamma(\bar{x} - x_{\text{worst}})$.
  \item \textbf{Contraction} ($\rho = 0.5$): if reflection worsened, contract toward centroid.
  \item \textbf{Shrink} ($\sigma = 0.5$): if contraction fails, contract all vertices toward the best.
\end{enumerate}
No gradient information is required. Initial simplex step size: $0.35$. Iterations: 160.

\begin{remark}[Nelder--Mead convergence properties]
Unlike the deterministic methods studied elsewhere in this report, Nelder--Mead has limited theoretical convergence guarantees. It is known to converge to the minimum for one-dimensional problems, but counter-examples exist in $d \geq 2$ where it stagnates at non-stationary points. In practice, it performs well on smooth, low-dimensional, unimodal problems (such as Rosenbrock in $\mathbb{R}^2$) and is popular in engineering applications where gradient information is unavailable. Its convergence on Rosenbrock (see Figure~\ref{fig:q4_nm}) reflects the adaptive geometry of the simplex, which elongates along the valley direction.
\end{remark}

\subsection{Problem Formulation}

Minimise $f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)$ (Benchmark B, studied in its unconstrained form in Sections~\ref{sec:q1}--\ref{sec:q4}) subject to:
\begin{equation}
  x_1 \geq 0.5, \quad x \in \mathcal{F} = \{x \in \mathbb{R}^2 : x_1 \geq 0.5\},
\end{equation}
starting from the infeasible point $x_0 = (0.2, 4.0)$.

The unconstrained minimiser $(x_1^\star, x_2^\star) \approx (0.582, 2.0)$ satisfies $x_1^\star = 0.582 > 0.5$, so it lies \emph{inside} the feasible region. Consequently, the constrained and unconstrained optima coincide, and the constraint is inactive at the solution. This makes the problem an ideal test of whether constrained methods can find the correct interior solution without unnecessarily deflecting from the unconstrained path.

\subsection{KKT Conditions}

The Lagrangian of the constrained problem is:
\begin{equation}
  \mathcal{L}(x, \mu) = f(x) - \mu(x_1 - 0.5), \quad \mu \geq 0.
\end{equation}
The KKT first-order necessary conditions at the constrained optimum $x^\star$ are:
\begin{align}
  \nabla_x \mathcal{L}(x^\star, \mu^\star) &= \nabla f(x^\star) - \mu^\star e_1 = 0, \\
  \mu^\star (x_1^\star - 0.5) &= 0 \quad \text{(complementary slackness)}, \\
  x_1^\star &\geq 0.5, \quad \mu^\star \geq 0.
\end{align}
Since $x_1^\star \approx 0.582 > 0.5$, complementary slackness forces $\mu^\star = 0$, confirming the constraint is inactive at the optimum.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, projection $\Pi_{\mathcal{F}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{F}}(z_{k+1})$ \Comment{Project: $\Pi_{\mathcal{F}}(z) = (\max(0.5, z_1), z_2)$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection onto $\{x_1 \geq 0.5\}$ is the element-wise operation $\Pi_{\mathcal{F}}(z)_1 = \max(0.5, z_1)$, a $O(1)$ operation.

\begin{theorem}[Projected Gradient Descent convergence]
Let $f$ be $\mu$-strongly convex and $L$-smooth over a closed convex feasible set $\mathcal{F}$. PGD with step size $\alpha \in (0, 1/L]$ satisfies:
\begin{equation}
  \|x_k - x^\star\|^2 \leq (1 - \alpha\mu)^k \|x_0 - x^\star\|^2.
\end{equation}
For $L$-smooth convex $f$ (without strong convexity), PGD converges at rate $O(L\|x_0-x^\star\|^2/k)$.
\end{theorem}

The key insight is that the projection step does not increase the distance to any feasible point, including $x^\star$:
\begin{equation}
  \|\Pi_\mathcal{F}(z) - x^\star\|^2 \leq \|z - x^\star\|^2 \quad \forall x^\star \in \mathcal{F},
\end{equation}
a consequence of the Hilbert projection theorem (non-expansivity of orthogonal projection onto convex sets). This non-expansivity is what allows the standard GD convergence proof to carry through with projection.

\begin{algorithm}[H]
\caption{Penalty Method (Gradient Descent on Penalised Objective)}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty gradient is:
\begin{equation}
  \nabla F_\lambda(x) = \nabla f(x) + \lambda\, \partial[\max(0, 0.5 - x_1)]\, e_1
  = \nabla f(x) - \lambda\, \mathbf{1}[x_1 < 0.5]\, e_1.
\end{equation}
As $\lambda \to \infty$, minimisers of $F_\lambda$ converge to minimisers of $f$ over $\mathcal{F}$, but larger $\lambda$ introduces ill-conditioning requiring smaller step sizes.

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\subsection{Dual Variables and Complementary Slackness}

The dual perspective provides additional insight into the constrained optimum. The Lagrange dual of the constrained problem is:
\begin{equation}
  \max_{\mu \geq 0} \min_{x} \mathcal{L}(x, \mu) = \max_{\mu \geq 0} \left[\min_{x} f(x) - \mu(x_1 - 0.5)\right].
\end{equation}
Since the constraint is inactive at the optimum ($x_1^\star = 0.582 > 0.5$), the dual optimal multiplier $\mu^\star = 0$. This means the dual problem is degenerate: the constrained and unconstrained optima coincide, and any $\mu \geq 0$ satisfying $\partial_x \mathcal{L}(x^\star, \mu^\star) = 0$ must have $\mu^\star = 0$. The projected GD trajectory confirms this: after the initial projection from $x_1 = 0.2$ to $x_1 = 0.5$, the iterate moves interior to the feasible region and no further projections are needed.

\subsection{Comparative Discussion}

\textbf{Projected Gradient Descent} enforces feasibility \emph{immediately} at every iteration: it is a hard constraint method. The key advantage is that feasibility is guaranteed regardless of the step size or objective value. The projection cost for $x_1 \geq 0.5$ is $O(1)$ (a single max operation), but for complex constraint sets (e.g., semidefinite constraints, nuclear norm balls), the projection may require solving a separate optimisation problem at each step.

\textbf{Penalty methods} are simpler to implement (only a modified objective is needed) but trade exact feasibility for a soft constraint. The $\lambda$ parameter controls the trade-off:
\begin{itemize}[nosep]
  \item Small $\lambda$: fast convergence but persistent violation --- the unconstrained optimum of $F_\lambda$ may be infeasible.
  \item Large $\lambda$: near-exact feasibility but severe ill-conditioning of $F_\lambda$ requires small step sizes (stability: $\alpha \propto 1/(\lambda + L)$).
\end{itemize}
An \emph{augmented Lagrangian} method (not implemented here) combines the benefits by augmenting the Lagrangian with a quadratic penalty term. For the constraint $x_1 \geq 0.5$ (equivalently, $c(x) = 0.5 - x_1 \leq 0$):
\begin{equation}
  \mathcal{L}_\rho(x, \mu) = f(x) + \mu\, c(x) + \frac{\rho}{2}\max(0,\, c(x))^2,
  \quad c(x) = 0.5 - x_1,
\end{equation}
with the multiplier update $\mu \leftarrow \max\!\bigl(0,\, \mu + \rho\, c(x^{(t)})\bigr)$ after each inner minimisation step $x^{(t)}$. When the constraint is violated ($c(x)>0$), $\mu$ increases, strengthening the penalty; when feasible, $\mu$ is clipped to 0 (complementary slackness). This allows a moderate fixed $\rho$ (avoiding ill-conditioning) while the dual variable $\mu$ converges to $\mu^\star = 0$ for our inactive constraint, combining the simplicity of penalty methods with the theoretical guarantees of dual methods.

\paragraph{Condition number analysis.}
The condition number of the penalised Hessian $\nabla^2 F_\lambda$ relates to $\lambda$ as:
\begin{equation}
  \kappa(\nabla^2 F_\lambda) \approx \frac{L + \lambda}{\mu} \quad \text{(in the infeasible region)},
\end{equation}
where $L \approx 10$ and $\mu \approx 1.45$ for Benchmark B. At $\lambda = 4.5$: $\kappa \approx 14.5/1.45 \approx 10$; at $\lambda = 1.8$: $\kappa \approx 8.2$. Both are manageable, but for very large $\lambda$ (e.g., $\lambda = 100$), $\kappa \approx 76$, requiring $\alpha \approx 0.0015$ for stability, making convergence very slow. This quantifies the ill-conditioning trade-off of penalty methods.

\subsection{Feasible Set and Linear Programme}

Question~\ref{sec:q5} addressed inequality constraints using projection and penalty methods. This section studies an alternative approach — the Frank--Wolfe algorithm — that handles constraints through a linear minimisation oracle rather than projection. We first analyse the feasible set structure via linear programming.

The feasible set is the box $\mathcal{X} = [0.5, 5] \times [-5, 10]$ (Benchmark D from Section~\ref{sec:benchmarks}). A linear programme (LP) minimises a linear objective over this box:
\begin{equation}
  \min_{x \in \mathcal{X}} f(x) = a^T x = x_1 + 2x_2, \quad a = [1, 2]^T.
\end{equation}
Since the objective is linear and $\mathcal{X}$ is a bounded convex polytope (box), the fundamental theorem of linear programming states that the optimum is attained at a vertex (extreme point). Both components of $a$ are positive, so the optimum is at the lower bounds:
\begin{equation}
  x^{\star} = (0.5,\, -5), \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}

\subsection{Frank--Wolfe Algorithm (Conditional Gradient)}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial feasible point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: $x_{k+1} \in \mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

For the box $\mathcal{X}$, the LMO decomposes per coordinate:
\begin{equation}
  (z_k)_i = \begin{cases} \ell_i & \text{if } (\nabla f(x_k))_i > 0, \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0, \end{cases}
\end{equation}
where $[\ell_i, u_i]$ are the $i$-th coordinate bounds. This costs $O(d)$ per iteration --- no projection is needed, only a sign check. The key property is that $x_{k+1}$ is always a convex combination of feasible points, hence automatically feasible.

\begin{theorem}[Frank--Wolfe convergence, $O(1/k)$ rate]
For an $L$-smooth convex function $f$ over a compact convex set $\mathcal{X}$ with diameter $D = \max_{x,y \in \mathcal{X}}\|x-y\|$, the Frank--Wolfe algorithm with step sizes $\gamma_k = 2/(k+2)$ (i.e., $\beta_k = k/(k+2)$) satisfies:
\begin{equation}
  f(x_k) - f^\star \leq \frac{2LD^2}{k+2}.
\end{equation}
This $O(1/k)$ rate is slower than projected gradient descent's $O(1/k^2)$ (for convex $f$), but Frank--Wolfe avoids the projection step entirely.
\end{theorem}

In the implementation, a fixed $\beta$ is used (rather than the optimal decaying schedule), which means the theoretical $O(1/k)$ rate is not guaranteed.

\subsection{Interior vs.\ Boundary Behaviour and Limitations}

\paragraph{Frank--Wolfe gap as a stopping criterion.}
A natural stopping criterion for Frank--Wolfe is the \emph{Frank--Wolfe gap} (also called the duality gap):
\begin{equation}
  \Phi_k = \nabla f(x_k)^T(x_k - z_k) = \max_{z \in \mathcal{X}} \nabla f(x_k)^T(x_k - z).
\end{equation}
By convexity, $f(x_k) - f^\star \leq \Phi_k$, so $\Phi_k$ provides an upper bound on the suboptimality. When $\Phi_k \leq \varepsilon$, the current iterate is $\varepsilon$-optimal. This requires no knowledge of $f^\star$, making it a self-certifying stopping criterion analogous to the Newton decrement. In the interior-optimum experiment, $\Phi_k$ shrinks as $x_k \to x^\star$ because $z_k$ approaches $x_k$ from the boundary, giving a small directional derivative product.

\paragraph{Interior optimum analysis.}
Frank--Wolfe converges but exhibits the characteristic ``zig-zag'' pattern. The LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$ at each iteration, and the convex combination gradually averages these jumps. With fixed $\beta$, the iterate converges at a geometric rate $O(\beta^k)$, but the zig-zag persists because $z_k$ always selects a boundary vertex, never the interior optimum. The suboptimality $f = 0.0089$ (resp.\ 0.0046) vs.\ $f^\star = 0$ reflects the residual gap after 180 iterations with fixed $\beta$.

\paragraph{Boundary optimum analysis.}
Frank--Wolfe is theoretically well-suited to boundary optima: $z_k$ consistently selects the corner nearest the constrained optimum, and iterates naturally approach the boundary without projection. However, the residual gap $f = 0.364$ vs.\ $f^\star = 0.25$ after 140 iterations illustrates the $O(1/k)$ convergence rate's practical slowness with fixed $\beta$. Replacing the fixed $\beta$ with the optimal schedule $\gamma_k = 2/(k+2)$ (equivalent to $\beta_k = k/(k+2)$) would recover the theoretical $O(1/k)$ rate guarantee.

\paragraph{Sparsity and structural bias of Frank--Wolfe.}
A fundamental structural property of Frank--Wolfe is that after $k$ iterations, the iterate $x_k$ is a \emph{convex combination of at most $k+1$ extreme points} (``atoms'') of $\mathcal{X}$:
\begin{equation}
  x_k = \sum_{j=0}^{k} \lambda_j^{(k)} z_j, \quad \lambda_j^{(k)} \geq 0, \quad \sum_j \lambda_j^{(k)} = 1,
\end{equation}
where each $z_j$ is a vertex of $\mathcal{X}$. For a box, this means at most $k+1$ distinct vertices are combined. This ``atom sparsity'' is highly desirable in applications such as matrix completion (where atoms are rank-1 matrices), compressed sensing (where atoms are standard basis vectors), and low-rank approximation. In contrast, projected GD iterates have no such structural guarantee.

\paragraph{Comparison with projected gradient descent.}
PGD converges at rate $O(1/k^2)$ for smooth convex objectives (vs.\ $O(1/k)$ for Frank--Wolfe), and is faster per iteration when the projection is cheap (as here, $O(1)$). Frank--Wolfe's advantage is in settings where: (a) $\mathcal{X}$ is complex but has an efficient LP oracle (e.g., nuclear norm ball via SVD: $O(d^2)$ LP vs.\ $O(d^3)$ projection), or (b) sparse/low-rank solutions are desired (the sparsity structure is automatically inherited).

\section{Conclusion}
\label{sec:conclusion}
% ============================================================

This report evaluated six families of optimisation algorithms on three benchmark problems of increasing difficulty. The key findings are organised below.

\subsection{Method-by-Method Summary}

\paragraph{Adaptive step-size methods (Q1).}
Adagrad and Heavy Ball reliably match or exceed gradient descent performance without parameter sensitivity. Heavy Ball's momentum is particularly effective on ill-conditioned problems (Rosenbrock: $f = 1.40$ vs.\ GD $f = 3.51$). RMSprop's exponential forgetting stabilises the step size but requires careful tuning of the decay $\beta$. The Polyak step size is theoretically elegant but critically depends on an accurate $f^\star$: misspecification by even $\varepsilon_{\text{true}}$ causes pathological divergence as the iterate approaches the true optimum.

\paragraph{Momentum and stochastic methods (Q2).}
Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ rate for smooth convex problems and demonstrates the largest practical improvement on Rosenbrock ($f = 0.479$ vs.\ GD $f = 3.388$). Adam combines momentum with coordinate-wise adaptation, making it versatile across problem types at the cost of additional hyperparameters ($\beta_1, \beta_2, \varepsilon$). Mini-batch SGD with small batches converges faster per epoch due to more frequent updates, but at the cost of higher gradient variance; the optimal batch size balances these effects.

\paragraph{Newton's method (Q3).}
Newton's method converges in a single iteration on quadratic objectives and in $O(\log\log 1/\varepsilon)$ iterations near a strongly convex minimum (quadratic convergence). Its primary limitations are the $O(d^3)$ cost per iteration for Hessian inversion and the need for damping ($\alpha < 1$) in non-convex regions. For $d = 2$, Newton is overwhelmingly preferred over first-order methods.

\paragraph{Derivative-free methods (Q4).}
Finite-difference gradients with small $\delta$ closely approximate exact gradients at the same $O(d)$ evaluation cost. The step size $\delta$ must balance truncation error ($O(\delta)$) and roundoff error ($O(\varepsilon_{\text{mach}}/\delta)$), with $\delta \approx \sqrt{\varepsilon_{\text{mach}}} \approx 10^{-8}$ being theoretically optimal. Nesterov random search uses only 2 function evaluations per step (dimension-independent), making it suitable for very high-dimensional black-box problems at the cost of slow per-step progress. Nelder--Mead and grid search are practical only for $d \leq 4$.

\paragraph{Constrained optimisation (Q5).}
Projected gradient descent enforces feasibility as a hard constraint from the first iteration, with the same convergence guarantees as unconstrained GD when the projection is cheap. Penalty methods are simpler to implement but require $\lambda \to \infty$ for exact feasibility, introducing ill-conditioning. For the test problem, both methods converge to the correct solution $(0.582, 2.0)$; the advantage of PGD is its immediate and guaranteed feasibility.

\paragraph{Frank--Wolfe algorithm (Q6).}
Frank--Wolfe avoids projections by replacing them with a linear minimisation oracle, making it practical for constraint sets with efficient LP solvers (e.g., spectrahedra, nuclear norm balls). Its $O(1/k)$ convergence rate is slower than projected GD's $O(1/k^2)$, and fixed $\beta$ schedules introduce oscillation. Frank--Wolfe is best suited to boundary optima and sparse solutions (it naturally selects vertices).

The broader lesson from these experiments is that effective optimisation requires matching the algorithm to the problem structure: the condition number, the availability of gradient or Hessian information, the constraint geometry, and the trade-off between per-iteration cost and convergence rate. No single method dominates across all dimensions.

\begin{remark}[Condition number as the key diagnostic]
The single most important property to assess before choosing an optimisation algorithm is the condition number $\kappa$ of the objective Hessian at the minimiser. The experimental results confirm three regimes:
\begin{itemize}[nosep]
  \item $\kappa \approx 1$ (Benchmark A): all first-order methods converge at comparable speed; choose by simplicity (GD) or per-iteration cost.
  \item $\kappa \approx 1$--$100$ (Benchmark B): momentum methods (Nesterov, Heavy Ball) provide meaningful speedup; Newton converges in $\ll 10$ steps.
  \item $\kappa \gg 100$ (Benchmark C): first-order methods require $O(\sqrt{\kappa})$ to $O(\kappa)$ more iterations than Newton; Nesterov and Polyak (with exact $f^\star$) are essential.
\end{itemize}
Estimating $\kappa$ can be done cheaply via the ratio of successive gradient magnitudes (power-iteration estimate) or by running a few steps of GD and observing the convergence rate.
\end{remark}

\subsection{Limitations and Future Directions}

Several limitations of the present study should be acknowledged:

\begin{enumerate}[nosep]
  \item \textbf{Low dimensionality:} All benchmarks use $d = 2$. In high dimensions ($d \geq 100$), the relative performance of methods changes significantly: Newton's $O(d^3)$ cost becomes prohibitive, Nesterov random search's $O(d/\varepsilon)$ overhead grows, and Adam's coordinate-wise scaling becomes more beneficial.

  \item \textbf{Fixed iteration budgets:} Results are compared after fixed iteration counts (80--220), not after equal computational effort. Some methods (Newton, with $d=2$) have lower per-step cost than others (FD GD), and wall-clock comparisons would yield different conclusions.

  \item \textbf{Hyperparameter sensitivity:} The hyperparameters reported (Tables~\ref{tab:q1_params}--\ref{tab:q3_params}) were tuned manually for each benchmark. Automated methods (e.g., line search, learning rate schedules, Bayesian optimisation over hyperparameters) could potentially improve all results.

  \item \textbf{Convergence to local vs.\ global minima:} Rosenbrock is unimodal; the experiments do not test global optimisation. For multimodal problems, derivative-free methods (Nelder--Mead, genetic algorithms, simulated annealing) or stochastic methods may be preferred for their ability to escape local minima.

  \item \textbf{Stochastic Adam:} The Adam experiments use full-batch gradients. Adam's advantage over Nesterov is most pronounced in the \emph{stochastic} setting (mini-batch training), where coordinate-wise variance reduction is more impactful.
\end{enumerate}

Future directions include: (a) extending to constrained Newton methods (e.g., interior point) for Q5, (b) comparing augmented Lagrangian vs.\ penalty in Q5, (c) implementing the optimal Frank--Wolfe line search (away-step Frank--Wolfe) for faster convergence, and (d) evaluating these methods on a real-world machine learning dataset to assess practical performance beyond toy benchmarks.

This study confirms that algorithm selection is not merely a technical detail but a fundamental aspect of applied optimisation: the correct choice can reduce computation by orders of magnitude (Newton's $1$ vs.\ GD's $80$ iterations on Benchmark A) while an incorrect choice (Polyak with misspecified $f^\star$) can cause complete failure.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z        # extrapolated point
        g = grad_fn(lookahead)             # gradient at lookahead
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)   # bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))   # Tikhonov regularisation
        try:
            p = np.linalg.solve(H_reg, g)       # solve H p = g
        except np.linalg.LinAlgError:
            p = g                                # fallback to GD direction
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # Linear minimisation oracle: select vertex minimising g^T z
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                      for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z    # convex combination
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
