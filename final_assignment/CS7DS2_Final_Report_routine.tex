\begin{abstract}
This report presents a comprehensive comparative study of first-order, second-order, and
derivative-free optimisation algorithms applied to three canonical benchmark problems: a linear
regression quadratic loss (Benchmark A), a toy neural-network nonlinear loss with sinusoidal
coupling (Benchmark B), and the Rosenbrock function (Benchmark C).  Six algorithmic families
are investigated: (1) adaptive step-size methods -- Polyak step, Adagrad, RMSprop, and Heavy
Ball; (2) momentum and stochastic methods -- Nesterov acceleration, Adam, and mini-batch SGD;
(3) Newton's method with local quadratic modelling; (4) derivative-free approaches including
finite-difference gradient approximation, Nesterov random search, Nelder--Mead simplex, and grid
search; (5) constrained optimisation via projected gradient descent and penalty methods; and
(6) the Frank--Wolfe conditional gradient algorithm for linear-constrained problems.

Key findings include: (i) the Polyak step diverges on problems where $f^\star$ is misspecified but
achieves best-in-class convergence on Rosenbrock where $f^\star = 0$ is exact; (ii) Nesterov
acceleration achieves an $O(1/k^2)$ convergence rate that substantially outperforms GD's $O(1/k)$
rate on the ill-conditioned Rosenbrock function; (iii) Newton's method converges in a single
iteration on the quadratic Benchmark A, demonstrating quadratic convergence; (iv) finite-difference
approximation quality is critically sensitive to the perturbation size $\delta$; and (v) projected
gradient descent enforces hard constraint satisfaction from the first iteration, while penalty
methods require tuning $\lambda$ to balance objective quality and constraint satisfaction speed.
All experiments use \texttt{np.random.seed(42)} for full reproducibility.
\end{abstract}

Optimisation lies at the core of modern machine learning: training a model means minimising a
loss function, and the choice of optimisation algorithm directly affects convergence speed,
solution quality, and computational cost.  This report systematically investigates a broad
spectrum of optimisation methods, from classical first-order gradient descent through
adaptive and momentum-based methods, second-order Newton's method, derivative-free techniques,
and constrained optimisation algorithms.

All methods are evaluated on three benchmark functions of deliberately increasing difficulty:
a well-conditioned quadratic (Benchmark A), a moderately anisotropic nonlinear function
(Benchmark B), and the notoriously ill-conditioned Rosenbrock function (Benchmark C).
This progression allows the report to isolate the specific conditions under which each method's
theoretical advantages become practically significant.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.
The benchmarks are chosen to represent a spectrum of difficulty controlled principally by the
condition number $\kappa = \lambda_{\max}/\lambda_{\min}$ of the Hessian, which governs the
ratio between the slowest and fastest directions of curvature.  A large $\kappa$ forces
gradient-based methods to use small step sizes to avoid divergence, slowing convergence.

\subsection{Benchmark A: Linear Regression Quadratic Loss}

A synthetic dataset with $m = 1000$ samples and two parameters is generated according to
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the normalised mean squared error:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2
            = \frac{1}{2}\theta^T H \theta - b^T\theta + c,
\end{equation}
where $H = \frac{1}{m}X^T X$, $b = \frac{1}{m}X^T y$, and $c = \frac{1}{2m}\|y\|^2$.
The gradient is $\nabla J(\theta) = H(\theta - \theta_{\text{OLS}}) = \frac{1}{m}X^T(X\theta - y)$.

Since $X \in \mathbb{R}^{m \times 2}$ with independent $\mathcal{N}(0,1)$ entries and $m = 1000$,
the empirical Hessian $H \approx I_2$ with both eigenvalues close to 1, giving a condition number
$\kappa_A \approx 1$.  This near-isotropic curvature makes Benchmark A the easiest test: any
well-tuned gradient method converges rapidly.  Due to observation noise, the minimum loss is
$J^\star \approx 0.4826$ (not zero), achieved at the OLS solution $\theta_{\text{OLS}} \approx [3.03, 4.02]^T$.
Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Quadratic Loss}

\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient and Hessian are
\begin{equation}
  \nabla f = \begin{bmatrix} 2(x_1 - 1) + \cos(x_1) \\ 10(x_2 - 2) \end{bmatrix}, \qquad
  H(x) = \begin{bmatrix} 2 - \sin(x_1) & 0 \\ 0 & 10 \end{bmatrix}.
\end{equation}
Setting $\nabla f = 0$ gives $x_2^\star = 2$ exactly, and $x_1^\star$ satisfies
$2(x_1^\star - 1) + \cos(x_1^\star) = 0$.  Solving numerically yields $x_1^\star \approx 0.582$,
so the minimum is at approximately $(0.582,\, 2.0)$ with $f^\star \approx 0.7244$.
\emph{Note:} the optimum marker in trajectory figures is placed at $(0.61, 2.0)$, which is an
approximate visual guide; the analytically computed minimum is $(0.582, 2.0)$.

At the minimum, $H^\star = \text{diag}(2 - \sin(0.582),\, 10) \approx \text{diag}(1.45,\, 10)$,
giving condition number $\kappa_B \approx 6.9$.  The $x_2$ direction is approximately 7 times
stiffer than $x_1$, creating moderate anisotropy that challenges fixed-step methods.
Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}

\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$.  The Hessian is
\begin{equation}
  H(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the optimum $(1,1)$: $H^\star = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix}$
with eigenvalues $\lambda_{\max} \approx 1001.6$ and $\lambda_{\min} \approx 0.4$, giving
$\kappa_C \approx 2508$.  This extreme ill-conditioning, combined with a narrow curved valley
along $x_2 \approx x_1^2$, makes Rosenbrock the most challenging benchmark.  A stable step
size for gradient descent must satisfy $\alpha < 2/\lambda_{\max} \approx 0.002$, which causes
extremely slow progress along the valley direction.
Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}

For constrained problems: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\
-5 \leq x_2 \leq 10\}$.

\subsection{Algorithm Formulations and Motivation}

Four adaptive methods are compared against a constant step-size gradient descent (GD) baseline
across all three benchmarks for 120 iterations.  The common limitation of constant-step GD is
that the optimal step size $\alpha^\star = 2/(\lambda_{\min} + \lambda_{\max})$ depends on
unknown curvature information.  Adaptive methods attempt to estimate or approximate this
curvature from gradient history.

\begin{algorithm}[H]
\caption{Gradient Descent (Baseline)}
\label{alg:gd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, constant step $\alpha$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} For a convex function with $f^\star$ known exactly,
the Polyak step provably satisfies $f(x_{k+1}) - f^\star \leq (f(x_k) - f^\star)(1 - 1/(2L))$
under $L$-smoothness (see Lecture notes Week 3b), where $L = \lambda_{\max}$.  The adaptive
numerator $f(x_k) - f^\star$ naturally shrinks as the iterate approaches the minimum, giving
variable-rate convergence with no curvature knowledge required.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate cumulative squared gradient}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} Adagrad was introduced by Duchi et al.\ (2011) to
perform better adaptation for sparse or heterogeneous gradients.  The effective per-coordinate
step size $\alpha_k^{(i)} = \alpha_0 / \sqrt{\sum_{j \leq k} g_j^{(i)^2}}$ monotonically
\emph{decreases}, which is beneficial early on (large gradients reduce the step) but harmful
later (the step can become negligibly small before reaching the minimum).

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$,
  iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$
      \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} RMSprop (Hinton, 2012) corrects Adagrad's monotone
decay by replacing cumulative with exponential averaging ($\beta = 0.9$ here).  The effective
step $\alpha_0 / \sqrt{v_k}$ reflects recent gradient magnitudes rather than all historical
gradients, allowing the step size to recover if curvature decreases.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:} The auxiliary variable $z_k$ accumulates an
exponentially-weighted history of gradients, providing a ``velocity'' that persists across
iterations.  For strongly convex quadratics, the optimal parameters are
$\alpha^\star = 4/(\sqrt{\lambda_{\max}} + \sqrt{\lambda_{\min}})^2$ and
$\beta^\star = ((\sqrt{\kappa} - 1)/(\sqrt{\kappa} + 1))^2$, which yields a convergence rate
$\rho = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1) < 1$ -- much faster than GD's rate of
$(\kappa-1)/(\kappa+1)$ when $\kappa \gg 1$ (Week 4a lecture notes).

\item \textbf{Convergence speed:}
  When $f^\star$ is known exactly, Polyak converges fastest (Benchmark~C: $f = 0.009$),
  exploiting the exact gap between current loss and optimum to set an optimally-sized step.
  Otherwise, Adagrad and Heavy Ball match or exceed the GD baseline.  On the well-conditioned
  Benchmark~A ($\kappa \approx 1.12$), all methods converge similarly since $\rho \approx 0.057$
  is small for all methods: the high curvature isotropy leaves no room for acceleration.

\item \textbf{Smoothness:}
  RMSprop produces the smoothest convergence curves due to exponential averaging of squared
  gradients.  Heavy Ball shows characteristic overshoot followed by damped oscillation,
  analogous to a second-order damped mechanical system.  The momentum parameter $\beta$
  controls the damping: $\beta < \beta^\star = ((\sqrt\kappa-1)/(\sqrt\kappa+1))^2$
  gives overdamped (monotone) convergence; $\beta > \beta^\star$ gives underdamped oscillation.
  The values $\beta = 0.88, 0.90, 0.86$ in the experiments are empirically tuned near this
  critical value.

\item \textbf{Stability:}
  Constant-step GD is most stable: for any $L$-smooth function, the condition
  $\alpha < 2/L = 2/\lambda_{\max}$ guarantees non-increasing loss.  Polyak is \emph{unstable}
  when $f^\star$ is misspecified.  Adagrad is uniformly stable due to its monotonically
  decreasing step size, but this safety mechanism eventually causes stagnation: on a strongly
  convex function, Adagrad's effective step decays as $\alpha_0/\sqrt{k}$, giving a
  $O(1/\sqrt{k})$ convergence rate that is slower than GD's $O(1/k)$ rate on smooth problems.

\item \textbf{Adagrad vs RMSprop:}
  The key algorithmic difference is how gradient history is aggregated.  Adagrad's cumulative
  sum $G_k = \sum_{j=0}^k g_j^2$ grows without bound, so $\alpha_0/\sqrt{G_k} \to 0$.
  RMSprop's exponential moving average $v_k = \beta v_{k-1} + (1-\beta)g_k^2$ tracks a
  finite window (effective window size $\approx 1/(1-\beta) = 10$ for $\beta = 0.9$),
  preventing the step from vanishing.  RMSprop is strictly preferred for non-stationary
  problems or long training runs.

\item \textbf{Practical recommendation:}
  In practice, exact $f^\star$ is rarely known, limiting Polyak's applicability.  RMSprop
  and Adagrad are more robust: RMSprop when training is long; Adagrad for sparse gradient
  problems (NLP/recommendation systems where different features are updated rarely).
\end{itemize}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead / extrapolated point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
The key distinction from Heavy Ball is evaluating the gradient at the \emph{extrapolated
lookahead point} $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$.  This ``look before
you leap'' strategy allows Nesterov to correct its trajectory \emph{before} overshooting,
yielding provably optimal $O(1/k^2)$ convergence on convex functions (vs.\ GD's $O(1/k)$)
and linear convergence on strongly convex functions with a better constant than GD
(Nesterov, 1983; Week 4b lecture notes):
\begin{equation}
  f(x_k) - f^\star \leq \frac{2L \|x_0 - x^\star\|^2}{(k+1)^2}
  \quad \text{(Nesterov)}, \qquad
  f(x_k) - f^\star \leq \frac{L \|x_0 - x^\star\|^2}{2k}
  \quad \text{(GD)}.
\end{equation}
At $\kappa = 2508$, the linear convergence rate for Nesterov on strongly convex functions is
$\rho_{\text{Nest}} = (\sqrt{2508}-1)/(\sqrt{2508}+1) \approx 0.9684$, vs GD's
$\rho_{\text{GD}} = (2508-1)/(2508+1) \approx 0.9992$ --- roughly $25\times$ better
per-iteration error reduction ($1 - 0.9684 \approx 0.0316$ vs $1 - 0.9992 \approx 0.0008$).
Over 150 iterations, the remaining fraction of the initial error is:
$0.9684^{150} \approx 0.0076$ (Nesterov) vs $0.9992^{150} \approx 0.887$ (GD), predicting
that Nesterov reduces error by $\sim 130\times$ while GD reduces it by only $\sim 1.13\times$.
This theoretical prediction is broadly consistent with the observed $7\times$ improvement in
final objective ($0.479$ vs $3.39$), with the discrepancy explained by the Rosenbrock's
non-quadratic nature (the theoretical rates apply to strongly convex quadratics).  The schedule $\beta_k = \min\!\left(\frac{k-1}{k+2},
\beta_{\max}\right)$ starts at zero (pure gradient step) and grows towards $\beta_{\max}$,
ensuring stability while building up momentum.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$,
  tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$
      \Comment{First moment: exponential moving average of gradients}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$
      \Comment{Second moment: EMA of squared gradients}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$
      \Comment{Bias correction for initialisation at zero}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
Adam (Kingma \& Ba, 2015) combines momentum via $m_t$ with per-coordinate adaptive
scaling via $v_t$, inheriting advantages of both RMSprop and momentum methods.  The effective
step size per coordinate is $\alpha \cdot \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon) \approx
\alpha \cdot \text{sign}(g_t)$ in the limit of large $t$ with consistent gradient directions,
bounding the effective step in $(-\alpha, \alpha)$.  The bias corrections
$(1 - \beta_1^t)^{-1}$ and $(1 - \beta_2^t)^{-1}$ compensate for initialising $m_0 = v_0 = 0$,
which otherwise causes underestimation in early iterations.

\begin{algorithm}[H]

\label{alg:sgd}
\begin{algorithmic}[1]

\EndFor
\end{algorithmic}

\subsection{Local Approximations of $g(x) = x^4$}

\textbf{First-order (Taylor) approximation} around $x_0 = 0.25$:
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0)
       = 0.25^4 + 4 \cdot 0.25^3\,(x - 0.25)
       = 0.0039 + 0.0625(x - 0.25).
\end{equation}
This is the tangent line at $x_0 = 0.25$; it captures only the local slope and provides no
information about curvature or the location of the minimum.

\textbf{Second-order (quadratic) approximation:}
\begin{equation}
  g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
       = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}
This parabola is a local quadratic model of $g$ near $x_0$.  The Newton update is obtained by
minimising this quadratic model, setting its derivative to zero:
\begin{equation}
  0 = g'(x_0) + g''(x_0)(x - x_0) \implies x^{\text{Newton}} = x_0 - \frac{g'(x_0)}{g''(x_0)}
    = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\end{equation}
The gradient-descent step would give $x_0 - \alpha g'(x_0) = 0.25 - 0.0625\alpha$, which
moves a fixed distance regardless of curvature.  Newton's step automatically accounts for the
curvature $g''(x_0) = 0.75$: large curvature $\Rightarrow$ smaller step, small curvature
$\Rightarrow$ larger step.

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Newton's Method with Hessian Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State Solve $H_k\, p_k = g_k$ for $p_k$ \Comment{Newton direction}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping
$\lambda = 10^{-8}$.  The regularisation $\lambda I$ ensures $H_k$ is positive definite even
when the true Hessian is indefinite (e.g., saddle points on Rosenbrock), preventing the Newton
direction from ascending.

\textbf{Convergence theory:}
Near a strongly convex minimum, Newton's method satisfies the \emph{quadratic convergence}
bound:
\begin{equation}
  \|x_{k+1} - x^\star\| \leq C\, \|x_k - x^\star\|^2
\end{equation}
for some constant $C$ depending on the Lipschitz constant of $\nabla^2 f$.  This means that
once $\|x_k - x^\star\|$ is sufficiently small, the error is halved \emph{in the number of
decimal digits} at each iteration.  In contrast, GD satisfies only
$\|x_{k+1} - x^\star\| \leq \rho\, \|x_k - x^\star\|$ (linear convergence) with
$\rho = (\kappa - 1)/(\kappa + 1)$.

the iterate stays within this region of model accuracy.

\section{Question 4: Derivative Approximation and Derivative-Free Optimisation \hfill [30 marks]}
\label{sec:q4}
% ============================================================

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces the $i$-th partial derivative:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}.
  \label{eq:fd}
\end{equation}
The total error of this approximation is:
\begin{equation}
  \left|\frac{\partial f}{\partial x_i}(x) - \hat{g}_i\right|
  \leq \underbrace{\frac{\delta}{2}\max_{t} |f''(x + t\delta e_i)|}_{\text{truncation error } O(\delta)}
  + \underbrace{\frac{2\varepsilon_{\text{mach}}}{\delta}}_{\text{rounding error } O(\varepsilon/\delta)},
\end{equation}
which is minimised at $\delta^\star \sim \sqrt{\varepsilon_{\text{machine}}} \approx 10^{-8}$.
Practically, $\delta$ in the range $[10^{-5}, 10^{-3}]$ works well for smooth functions.

The assignment tests two $\delta$ values on Benchmark~B (where $\lambda_{\max} = 10$,
so the Lipschitz constant of $\nabla f$ satisfies $L_2 \leq \lambda_{\max} = 10$):

\begin{itemize}
  \item \textbf{Good:} $\delta = 0.05$ --- truncation error $\leq \delta L_2 / 2 = 0.05 \cdot 10 / 2 = 0.25$.
    For a gradient of magnitude $\|g\| \approx 5$ at the starting point, the \emph{relative}
    error is $\lesssim 0.25/5 = 5\%$.  This is small enough that gradient descent still
    converges reliably towards the minimum.
  \item \textbf{Poor:} $\delta = 0.8$ --- truncation error $\leq 0.8 \cdot 10 / 2 = 4.0$.
    A relative error of $\sim 80\%$ means the finite-difference direction is substantially
    different from the true gradient direction; the algorithm takes steps that largely do not
    correspond to descent.  This explains why FD GD with $\delta = 0.8$ fails to converge.
\end{itemize}
For comparison, a centred finite-difference scheme $[f(x+\delta e_i) - f(x-\delta e_i)]/(2\delta)$
has truncation error $O(\delta^2)$ rather than $O(\delta)$, so $\delta = 0.8$ would give error
$\leq \delta^2 L_3/6 \approx 0.05$ (assuming $L_3 \approx 0.5$) --- substantially better.  The
forward-difference scheme requires only $d+1 = 3$ function evaluations per step vs $2d = 4$
for centred, making it more economical in high dimensions.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$; normalise $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
      \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Key property:}  Only \emph{two} function evaluations are required per
iteration, regardless of dimension $d$.  In contrast, forward-difference gradient estimation
requires $d + 1$ evaluations ($n = 2$ evaluations for Benchmark~B, $2 + 1 = 3$).  For
high-dimensional problems ($d \gg 1$), Nesterov random search provides a dimension-independent
cost per step.  The random direction $u_k$ provides an unbiased estimate of the gradient
direction in expectation:
\begin{equation}
  \mathbb{E}\!\left[\hat{g}_k\right] = \frac{1}{\delta}\mathbb{E}\!\left[(f(x_k + \delta u_k) - f(x_k))u_k\right]
  \approx \nabla f(x_k).
\end{equation}
The variance of this estimate is $O(1/d)$ times larger than a full gradient estimate with the
same FE count, explaining the slower convergence.

\subsection{Part B: Derivative-Free Methods (Benchmark C)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm (Nelder \& Mead, 1965) maintains a simplex of $n + 1 = 3$ vertices
in $\mathbb{R}^2$ and iteratively transforms it through four operations:
\begin{enumerate}[nosep]
  \item \textbf{Reflection} ($\alpha_r = 1.0$): reflect the worst vertex through the centroid
    of the remaining vertices.
  \item \textbf{Expansion} ($\gamma = 2.0$): if reflection improved, try extending further in
    that direction.
  \item \textbf{Contraction} ($\rho = 0.5$): if reflection did not improve, contract towards
    the centroid.
  \item \textbf{Shrink} ($\sigma = 0.5$): if contraction failed, shrink all vertices towards
    the best vertex.
\end{enumerate}
No gradient information is required; the algorithm adapts to the function landscape through
the simplex geometry.  Settings: initial step $= 0.35$, iterations $= 160$.

\subsection{Problem Setup}

Minimise Benchmark~B subject to $x_1 \geq 0.5$, starting from the infeasible point
$x_0 = (0.2,\, 4.0)$.

\begin{remark}[Feasibility of unconstrained minimum]
  The unconstrained minimum of Benchmark~B is at $(x_1^\star, x_2^\star) \approx (0.582, 2.0)$.
  Since $x_1^\star = 0.582 > 0.5$, the constraint $x_1 \geq 0.5$ is \emph{inactive} at the
  optimum: the constrained and unconstrained minima coincide.  Therefore, all methods should
  converge to the same final point $(0.582, 2.0)$ in the limit, but they differ in how quickly
  they enforce feasibility \emph{during} optimisation.  The key distinction is the trajectory
  behaviour, not the final solution.
\end{remark}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$
      \Comment{Project: $x_1 \leftarrow \max(0.5,\, x_1)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
Projected GD satisfies $x_k \in \mathcal{X}$ for all $k \geq 0$ (hard constraint guarantee).
The projection $\Pi_{\mathcal{X}}(z) = \arg\min_{x \in \mathcal{X}} \|x - z\|$ for a
half-space $\{x : x_1 \geq 0.5\}$ reduces to $x_1 \leftarrow \max(0.5, x_1)$, costing $O(1)$.
Convergence theory guarantees that projected GD converges on convex problems under
$\alpha < 2/L$ (Week 9a lecture notes), and the rate matches unconstrained GD.

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty weight $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, -x_1 + 0.5)$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_{\lambda}(x_k)$
    \Comment{$\nabla F_\lambda(x) = \nabla f(x) - \lambda \mathbf{1}_{x_1 < 0.5}\, e_1$}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Theoretical motivation:}
The penalty method solves the unconstrained problem $\min_x F_\lambda(x)$ which approximates
the constrained problem for large $\lambda$.  Formally, if $x^\star_\lambda$ minimises
$F_\lambda$, then $x^\star_\lambda \to x^\star$ (the constrained optimum) as $\lambda \to \infty$.
The violation at $x^\star_\lambda$ satisfies $\max(0, 0.5 - x^\star_{\lambda,1}) \leq c/\lambda$
for some constant $c$, meaning the constraint error decays as $1/\lambda$.

However, large $\lambda$ increases the Lipschitz constant of $\nabla F_\lambda$ in the
infeasible region: the effective ``stiffness'' in the $x_1$ direction becomes
$\lambda_{\max}(H_{F_\lambda}) \approx \lambda$ when $x_1 < 0.5$, requiring step sizes
$\alpha < 2/\lambda$ for stability there.  This explains the required step size reduction:
$\alpha = 0.03 < 2/\lambda = 2/4.5 = 0.44$ for $\lambda = 4.5$.  An alternative that avoids
this ill-conditioning is the \emph{augmented Lagrangian} method, which introduces a Lagrange
multiplier $\mu$ alongside the penalty term and updates $\mu \leftarrow \mu + \lambda\, c(x)$
at each outer iteration, achieving exact constraint satisfaction at finite $\lambda$.

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$
($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$);
unconstrained GD ($\alpha = 0.07$).  All run for 100 iterations.

\section{Question 6: Linear Programmes and Frank--Wolfe Algorithm \hfill [30 marks]}
\label{sec:q6}
% ============================================================

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1, 2]^T$, the objective separates
per coordinate.  Since $a_1 = 1 > 0$, minimising over $x_1 \in [0.5, 5]$ gives $x_1^\star = 0.5$.
Since $a_2 = 2 > 0$, minimising over $x_2 \in [-5, 10]$ gives $x_2^\star = -5$.  Hence:
\begin{equation}
  x^\star = (0.5,\, -5), \qquad f^\star = 0.5 + 2(-5) = -9.5.
\end{equation}
This illustrates the \emph{Fundamental Theorem of Linear Programming}: the optimum of a linear
objective over a bounded convex polytope is attained at a \emph{vertex} (extreme point).
The box $\mathcal{X}$ has four vertices $(0.5, -5)$, $(5, -5)$, $(5, 10)$, $(0.5, 10)$; the
LP solution is the vertex that minimises $a^T x$.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q6_lp.pdf}
\caption{Q6-I: Feasible region $\mathcal{X}$ (blue box) and linear objective contours
$f(x) = x_1 + 2x_2$ (labelled).  The contour lines are parallel (constant gradient direction),
and decreasing $f$ moves towards the lower-left.  The minimum $f^\star = -9.5$ is attained at
the lower-left vertex $(0.5, -5)$.  This example motivates the Frank--Wolfe LP oracle: to
minimise a linear function over $\mathcal{X}$, one simply identifies the vertex towards which
the gradient points.}
\label{fig:q6_lp}
\end{figure}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$
      \Comment{Linear Minimisation Oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$
      \Comment{Convex combination: stays in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

\noindent\textbf{Key property: Projection-free.}
Since $\mathcal{X}$ is convex and both $x_k, z_k \in \mathcal{X}$, the convex combination
$\beta x_k + (1-\beta) z_k \in \mathcal{X}$ for all $\beta \in [0,1]$, without any projection.
This is the principal advantage over projected gradient descent for complex constraint sets
(e.g., the nuclear norm ball, the simplex) where the projection oracle is expensive.

For box constraints, the LMO decomposes per coordinate (cost $O(d)$):
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if }
  (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
so $z_k$ is always a vertex of $\mathcal{X}$.

\textbf{Convergence rate:} The standard Frank--Wolfe with $\gamma_k = 2/(k+2)$ satisfies
$f(x_k) - f^\star \leq 2L D^2 / (k+2)$, where $L$ is the smoothness constant and $D$ is the
diameter of $\mathcal{X}$.  This gives $O(1/k)$ convergence, matching GD but without a
projection step.  The fixed-$\beta$ variant used here achieves similar convergence but with
different constant factors depending on $\beta$.

\textbf{Frank--Wolfe gap:} A natural convergence certificate is the Frank--Wolfe (FW) gap
\begin{equation}
  \text{gap}_k = \nabla f(x_k)^T (x_k - z_k) \geq 0,
\end{equation}
which upper-bounds the optimality gap: $f(x_k) - f^\star \leq \text{gap}_k$.  The gap equals
zero only at a KKT point (necessary optimality condition for constrained problems), making it
a practical stopping criterion.  Note that the standard FW uses $\gamma_k = 2/(k+2)$ as step
size ($x_{k+1} = (1-\gamma_k)x_k + \gamma_k z_k$, i.e., $\beta = 1-\gamma_k = k/(k+2)$),
giving a step that shrinks with $k$.  The experiments use a \emph{fixed} $\beta$, which is
simpler but does not guarantee the theoretical $O(1/k)$ rate for all $\beta$; for fixed $\beta$,
convergence depends on whether $\beta$ is close enough to 1 that the algorithm can approach
the optimum.

\textbf{Limitation -- zig-zag pattern:}  Because the Frank--Wolfe direction $z_k - x_k$ always
points towards a vertex of $\mathcal{X}$, and the optimal vertex alternates as the gradient
direction changes near an interior optimum, the algorithm exhibits a characteristic zig-zag
pattern.  The ``away-step'' Frank--Wolfe variant addresses this by also moving \emph{away} from
the current worst vertex, enabling faster convergence in practice.

\subsection{Interior Optimum: $f(x) = (x_1 - 1)^2 + (x_2 - 5)^2$}

The unconstrained minimum $(1, 5)$ lies \emph{inside} $\mathcal{X}$ (since $0.5 \leq 1 \leq 5$
and $-5 \leq 5 \leq 10$).  Two mixing parameters are tested: $\beta = 0.90$ (step size
$1-\beta = 0.10$ towards LMO vertex) and $\beta = 0.985$ (step size $0.015$).

\subsection{Interior vs Boundary Behaviour}

\textbf{Interior optimum:}
Frank--Wolfe converges to the interior optimum but with characteristic oscillation.
The LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$, and the iterate averages
these jumps.  For an interior optimum with $\beta$ fixed (rather than the optimal
$\gamma_k = 2/(k+2)$), the convergence is $O(1/k)$.  Two competing effects determine the best
$\beta$: smaller $1-\beta$ (larger $\beta$) leads to slower movement per step but less
oscillation near the optimum; larger $1-\beta$ moves faster but overshoots.  The experiments
show $\beta = 0.985$ outperforms $\beta = 0.90$ on this interior problem.

\textbf{Boundary optimum:}
Frank--Wolfe is naturally well-suited to boundary optima because the LP oracle $z_k$ selects
a vertex consistent with the constraint, and the convex combination $\beta x_k + (1-\beta)z_k$
slides the iterate towards the boundary.  For $f(x) = x_1^2 + x_2^2$ over the box, the
gradient $\nabla f = 2x > 0$ (for $x$ in the first quadrant) always points the LMO towards
the lower-left vertex $(0.5, -5)$, providing a consistent descent direction that gradually
pushes $x_1 \to 0.5$.  Unlike projected GD, no projection step is needed.

However, convergence is slower at the boundary (residual gap $0.114$ after 140 iterations
vs $0.0046$ for interior after 180 iterations).  This asymmetry arises because Frank--Wolfe
has no mechanism to ``stay on the boundary'': the convex combination $\beta x_k + (1-\beta)z_k$
with $z_k = (0.5, -5)$ and $x_k$ near $(0.5, 0)$ may pull $x_2$ towards $-5$ rather than
towards 0, creating oscillation in the $x_2$ direction even as $x_1$ approaches its boundary
value.  A line-search variant of Frank--Wolfe that selects $\gamma_k = \arg\min_\gamma
f(\gamma z_k + (1-\gamma) x_k)$ would avoid this and converge in fewer iterations.

\begin{center}
\begin{tabular}{lcc}
\toprule

\midrule

\bottomrule

\end{center}

The practical implication is that Frank--Wolfe's principal advantage lies in
\emph{avoiding expensive projections}: it is preferred over projected GD when the projection
is costly (e.g., projecting onto a nuclear norm ball requires full SVD; projecting onto the
probability simplex requires sorting) but the LMO is cheap (for many structured constraint
sets, the LP oracle has a closed-form solution: the simplex LMO is just $\arg\min_i c_i$,
and the nuclear norm ball LMO is the rank-1 outer product of leading singular vectors).

\section{Summary and Conclusions}
\label{sec:conclusion}
% ============================================================

This report compared six families of optimisation algorithms across three benchmark problems
of increasing difficulty ($\kappa \in \{1.1,\ 6.9,\ 2508\}$).  The key conclusions are:

\subsection{Convergence Rates and Condition Number Sensitivity}

\begin{table}[H]
\centering
\caption{Theoretical convergence rates of studied methods on convex problems.
$\kappa = L/\mu$ (condition number), $L$ (smoothness constant), $\mu$ (strong convexity).}
\label{tab:convergence_rates}
\begin{tabular}{lcc}
\toprule
\textbf{Method} & \textbf{Convex rate} & \textbf{Strongly convex rate} \\
\midrule
Gradient Descent       & $O(L/k)$ & $O\!\left(\left(\frac{\kappa-1}{\kappa+1}\right)^k\right)$ \\
Polyak step (exact $f^\star$) & $O(L/k)$ & -- \\
Heavy Ball (optimal)   & -- & $O\!\left(\left(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\right)^{2k}\right)$ \\
Nesterov acceleration  & $O(L/k^2)$ & $O\!\left(\left(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\right)^k\right)$ \\
Newton's method        & \multicolumn{2}{c}{Quadratic convergence near minimum} \\
Frank--Wolfe (standard) & $O\!\left(\frac{LD^2}{k+2}\right)$ & -- \\
\bottomrule
\end{tabular}

The experimental results are broadly consistent with these theoretical rates:
\begin{itemize}
  \item On Benchmark~A ($\kappa \approx 1.1$), all first-order methods converge at comparable
    speed: the $\sqrt{\kappa}$ advantage of Nesterov over GD is only $1.05\times$, leaving
    no room for differentiation.
  \item On Benchmark~C ($\kappa \approx 2508$), Nesterov's per-step advantage over GD is
    $\sim 25\times$ (from Table~\ref{tab:q1_rates}: $1-\rho_{\text{GD}} \approx 0.0008$ vs
    $1-\rho_{\text{Nest}} \approx 0.032$), consistent with the observed $7\times$ improvement
    in final objective after 150 iterations (partial credit to the non-quadratic structure
    which limits the exact rate).
  \item Newton's method achieves single-step convergence on Benchmark~A and reaches $f = 0.686$
    on Rosenbrock in 20 iterations vs GD's $f = 3.73$ in 80 iterations, demonstrating that
    curvature information is the dominant factor for ill-conditioned problems.
  \item The Rosenbrock function ($\kappa \approx 2508$) is the most \emph{discriminative}
    benchmark: all methods perform similarly on Benchmark~A, but Rosenbrock separates
    methods by up to two orders of magnitude in final objective value.
\end{itemize}

\subsection{Method-by-Method Summary}

\begin{itemize}
  \item \textbf{Polyak step:} Best when $f^\star$ is exactly known; diverges otherwise.
    Practically limited but theoretically elegant.
  \item \textbf{Adagrad:} Per-coordinate adaptation is beneficial for sparse or heterogeneous
    problems; monotone step decay causes stagnation on long runs.
  \item \textbf{RMSprop:} Corrects Adagrad's decay via exponential averaging; the most robust
    adaptive method in practice.
  \item \textbf{Heavy Ball:} Effective momentum method on quadratics; no convergence guarantee
    on non-convex problems; momentum parameter $\beta$ requires tuning.
  \item \textbf{Nesterov:} Theoretically optimal first-order method on convex problems;
    lookahead gradient prevents oscillation.  Best choice for ill-conditioned convex problems.
  \item \textbf{Adam:} Combines momentum and adaptive scaling; excellent empirical performance
    across benchmarks; no general convergence proof for non-convex problems.
  \item \textbf{Newton:} Achieves quadratic convergence but requires Hessian computation
    ($O(d^2)$ storage, $O(d^3)$ inversion); impractical for large $d$ without approximation.
  \item \textbf{Finite differences:} Provides gradient-like quality with $O(\delta)$ accuracy;
    $\delta$ must be chosen carefully to balance truncation and rounding error.
  \item \textbf{Nelder--Mead:} Derivative-free; adapts simplex to local landscape; suited to
    smooth low-dimensional problems where gradient computation is unavailable.
  \item \textbf{Projected GD:} Enforces hard constraint satisfaction at every iteration;
    requires cheap projection oracle; preferred when constraints are simple.
  \item \textbf{Penalty methods:} Require no projection oracle; $\lambda$ controls
    feasibility-objective trade-off; large $\lambda$ introduces ill-conditioning.
  \item \textbf{Frank--Wolfe:} Projection-free constrained optimisation; natural for structured
    constraint sets; $O(1/k)$ convergence; handles interior and boundary optima.
\end{itemize}

\subsection{Practical Guidance}

For practitioners facing a new optimisation problem:
\begin{enumerate}
  \item If the problem is a quadratic (e.g., linear regression, ridge regression):
    use Newton (one step) or conjugate gradient.
  \item If the problem is smooth, convex, and ill-conditioned: use Nesterov or
    quasi-Newton methods (L-BFGS).
  \item If the problem is high-dimensional and non-convex (deep learning): use Adam
    or RMSprop with mini-batch SGD.
  \item If gradients are unavailable and $d \leq 20$: use Nelder--Mead.
  \item If gradients are unavailable and $d$ is large: use Nesterov random search
    or evolutionary strategies.
  \item If the problem has constraints: use projected GD for simple constraints
    (e.g., box, half-space), penalty/augmented Lagrangian for general inequality constraints,
    Frank--Wolfe for structured sets with a cheap linear minimisation oracle.
\end{enumerate}

\noindent\textbf{Cross-cutting insight:}
The condition number $\kappa$ is the single most predictive quantity for algorithm selection.
For $\kappa \approx 1$ (isotropic curvature), any first-order method works well and the choice
is largely a matter of implementation convenience.  For $\kappa \approx 10^1$--$10^2$, adaptive
methods (Adagrad, RMSprop, Adam) and momentum methods (Nesterov, Heavy Ball) provide
meaningful advantages.  For $\kappa > 10^3$ (as in Rosenbrock), first-order methods require
curvature information to make progress, motivating the shift to Newton/quasi-Newton methods
or to methods that implicitly build curvature estimates (Adam, L-BFGS).  The experiments
in this report validate this theoretical picture across six algorithmic families.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Hessian Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: per-coordinate minimisation over box constraint
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
