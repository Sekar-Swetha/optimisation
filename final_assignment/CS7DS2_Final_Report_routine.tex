\begin{abstract}
This report presents a comprehensive comparative study of seventeen optimisation algorithms
across six categories, applied to three benchmark problems spanning condition numbers
$\kappa \in \{1.12,\,3.52\text{--}6.90,\,2508\}$: a convex quadratic linear regression
loss (Benchmark~A), a near-quadratic toy neural network loss with sinusoidal perturbation
(Benchmark~B), and the highly ill-conditioned Rosenbrock function (Benchmark~C,
$\kappa \approx 2508$). The methods investigated are: \textbf{(Q1)} adaptive step-size
methods (Polyak step, Adagrad, RMSprop, Heavy Ball); \textbf{(Q2)} momentum and stochastic
methods (Nesterov acceleration, Adam, mini-batch SGD); \textbf{(Q3)} Newton's method;
\textbf{(Q4)} derivative-free approaches (finite differences, Nesterov random search,
Nelder--Mead simplex, grid search); \textbf{(Q5)} projected gradient descent and
penalty methods; \textbf{(Q6)} the Frank--Wolfe conditional gradient algorithm.

Each method is analysed for convergence speed, stability, theoretical guarantees, and
computational trade-offs, with formal convergence theorems provided for key algorithms.
Key quantitative findings: \emph{Newton's method} solves the quadratic loss exactly in
$k = 1$ step; \emph{Nesterov acceleration} reduces the Rosenbrock final value from GD's
$f = 3.39$ to $f = 0.48$ ($7\times$ improvement); \emph{Nelder--Mead} locates the
Rosenbrock global minimum $(1,1)$ with $f = 0$ in 160 function evaluations;
\emph{Polyak step} diverges exponentially under $f^\star$ misspecification
($\alpha_k \to \infty$ when $\hat{f}^\star > f^\star$); and \emph{Frank--Wolfe}
maintains feasibility intrinsically via LP oracle solutions without requiring projection.
The report demonstrates that no single method dominates: algorithm selection must match
problem structure (conditioning, available information, constraints) to achieve
practical efficiency.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Gradient-based and derivative-free optimisation algorithms are the computational
foundation of modern data analysis and machine learning. The choice of algorithm
determines not only how fast a model trains, but whether it converges at all on
ill-conditioned problems, noisy data, or constrained feasible sets.

This report investigates all six categories of algorithms studied in CS7DS2 through
a unified empirical framework. Three benchmarks of increasing difficulty serve as a
controlled test bed: a near-isotropic quadratic (Benchmark~A, $\kappa \approx 1.12$)
where any reasonable method succeeds; a mildly anisotropic neural network loss
(Benchmark~B, $\kappa \in [3.52, 6.90]$) where adaptive methods offer tangible gains;
and the pathological Rosenbrock function (Benchmark~C, $\kappa \approx 2508$) that
exposes fundamental differences in how first-order, second-order, and momentum methods
handle ill-conditioning. Questions~5 and~6 additionally study a constrained box polytope
(Benchmark~D) for projected gradient descent, penalty methods, and the Frank--Wolfe algorithm.

For each category the report provides:
\begin{enumerate}[nosep]
\item a precise algorithmic description with pseudocode;
\item a formal convergence theorem (where applicable) with proof sketch or citation;
\item quantitative experimental results with figures;
\item a comparative analysis explaining \emph{why} each method performs as it does in
  terms of its underlying theoretical properties.
\end{enumerate}

All implementations are from scratch in NumPy \cite{harris2020array} with no external
optimisation libraries, ensuring full transparency and reproducibility.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}
% ============================================================

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) to ensure full
reproducibility. Each algorithm is implemented from scratch in NumPy; no external
optimisation libraries are used.

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated as follows:
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The mean squared error loss is:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2
            = \frac{1}{2m}\|X\theta - y\|^2.
  \label{eq:loss_A}
\end{equation}
The loss is a strictly convex quadratic with constant Hessian $H = \frac{1}{m}X^TX \succ 0$.
The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$.
Because the training targets contain irreducible noise $\varepsilon^{(i)} \sim \mathcal{N}(0,1)$,
the ordinary least-squares minimiser is $\hat\theta = (X^TX)^{-1}X^Ty \approx (3.028,\,4.017)^T$,
and the minimum loss is $J^\star \approx 0.4826 \neq 0$.
The Hessian eigenvalues are $\mu \approx 0.925$ and $L \approx 1.033$, giving condition number
$\kappa(H) \approx 1.12$ --- an almost isotropic problem. This explains why gradient descent
converges rapidly on Benchmark~A with no special tuning.
\textbf{Starting point:} $\theta_0 = (0, 0)^T$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
  \label{eq:loss_B}
\end{equation}
The gradient is
$\nabla f = \bigl[2(x_1 - 1) + \cos(x_1),\; 10(x_2 - 2)\bigr]^T$
and the Hessian is $H = \operatorname{diag}(2 - \sin(x_1),\, 10)$.
The minimum occurs at $x^\star \approx (0.5824, 2.0)$ where
the stationarity condition $2(x_1^\star - 1) + \cos(x_1^\star) = 0$ is satisfied,
yielding $f^\star \approx 0.7244$.
The Hessian $H = \operatorname{diag}(2 - \sin(x_1),\, 10)$ has
$\kappa(H) = 10\,/\,(2 - \sin(x_1))$, which evaluates to $\kappa \approx 3.52$
at the starting point $x_0 = (-1, 4)^T$ (where $\sin(-1) \approx -0.841$,
so the smaller eigenvalue is $2 - (-0.841) = 2.841$) and $\kappa \approx 6.90$
at the optimum (where $\sin(0.5824) \approx 0.550$, giving eigenvalue
$2 - 0.550 = 1.450$), creating moderate-to-significant anisotropy.
\textbf{Starting point:} $x_0 = (-1, 4)^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
  \label{eq:loss_C}
\end{equation}
The global minimum is at $x^\star = (1, 1)^T$ with $f^\star = 0$.
The gradient is
\begin{equation}
  \nabla f(x) = \begin{bmatrix}
    -2(1-x_1) - 400 x_1(x_2 - x_1^2) \\
    200(x_2 - x_1^2)
  \end{bmatrix},
\end{equation}
and the Hessian is
\begin{equation}
  H(x) = \begin{bmatrix}
    2 + 1200 x_1^2 - 400 x_2 & -400 x_1 \\
    -400 x_1 & 200
  \end{bmatrix}.
\end{equation}
At $x^\star = (1,1)$, $H = \begin{bmatrix}802 & -400 \\ -400 & 200\end{bmatrix}$
(since $2 + 1200(1)^2 - 400(1) = 802$), with eigenvalues approximately $0.399$ and $1001.6$,
giving $\kappa \approx 2508$. This extreme ill-conditioning, combined with the narrow
curved valley defined by $x_2 = x_1^2$, makes Rosenbrock one of the most widely-used
hard test functions for iterative optimisation methods. Notably, the condition number at the starting point $(-1, 1)$ is essentially the same
($\kappa \approx 2508$), since $H(-1,1) = \begin{bmatrix}802 & 400 \\ 400 & 200\end{bmatrix}$
has the same eigenvalues.
The starting point lies on the valley floor ($x_2 = (-1)^2 = 1 = x_1^2$),
so $\nabla f(-1,1) = (-4, 0)^T$ (computed as: $g_1 = -2(1-(-1)) - 400(-1)(1-1) = -4$;
$g_2 = 200(1 - 1) = 0$): the initial gradient points purely in the $x_1$ direction.
This means all algorithms take their first step correctly toward the minimum ($x_1$ increases),
but must then navigate the curved valley to reach $(1,1)$, which requires the step
in the $x_2$ direction to track $x_2 = x_1^2$ --- a highly nonlinear constraint that
creates the characteristic ``banana'' shape of the Rosenbrock landscape.

\textbf{Starting point:} $x_0 = (-1, 1)^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained experiments (Questions~5 and~6):
$\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$,
a bounded box polytope. The diameter of $\mathcal{X}$ is:
\[
  C_\mathcal{X} = \max_{x, y \in \mathcal{X}}\|x - y\|
  = \sqrt{(5 - 0.5)^2 + (10 - (-5))^2} = \sqrt{20.25 + 225} = \sqrt{245.25} \approx 15.66,
\]
which appears in the Frank--Wolfe convergence bound in Section~\ref{sec:q6}.
The Benchmark~B unconstrained minimum $x^\star \approx (0.5824, 2.0)$ lies in the
\emph{interior} of $\mathcal{X}$, making the Q5 inequality constraint ($x_1 \geq 0.5$)
inactive and the Q6 box constraint inactive in the $x_2$ direction.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Motivation and Theoretical Background}

A fundamental challenge in gradient descent is selecting an appropriate step size.
A constant step $\alpha$ requires $\alpha \leq 2/L$ for convergence on $L$-smooth functions
\cite{nesterov2004convex}, yet too small a step yields slow convergence.
Adaptive methods remove this dilemma by \emph{automatically} scaling the step size
based on observed gradient information. The Polyak step and Adagrad were covered in
Week~3b of the course; Heavy Ball in Week~4a.

Four adaptive methods are compared against a constant-step gradient descent baseline
across all three benchmarks for 120 iterations.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Gradient Descent (Baseline)}
\label{alg:gd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
  \State $x_{k+1} \gets x_k - \alpha\,\nabla f(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Polyak Step Size \cite{polyak1969minimization}}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step is theoretically optimal for convex functions when $f^\star$ is known
exactly: it minimises the worst-case distance to the optimum at each step.

\begin{algorithm}[H]
\caption{Adagrad \cite{duchi2011adaptive}}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0 > 0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate sum of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad adapts the step size \emph{per coordinate}: coordinates that have received
large cumulative gradients get smaller effective steps. The denominator
$\sqrt{G_k} + \varepsilon$ is computed element-wise. Because $G_k$ is monotonically
non-decreasing, the effective learning rate $\alpha_0/(\sqrt{G_k}+\varepsilon)$
\emph{can only decrease}, which can cause premature stagnation on non-stationary problems.

\begin{algorithm}[H]
\caption{RMSprop \cite{tieleman2012lecture}}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0 > 0$, decay $\beta \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exp.\ moving average of squared gradients}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop replaces Adagrad's running sum with an \emph{exponential moving average}
controlled by $\beta$ (typically $0.9$). Recent gradients receive weight
$(1-\beta)\beta^j$ at lag $j$, so the effective window is $\approx 1/(1-\beta)$ steps.
This prevents indefinite accumulation and allows the step size to recover when curvature decreases.

\begin{algorithm}[H]
\caption{Heavy Ball (Polyak Momentum) \cite{polyak1964methods}}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The momentum term $z_k$ accumulates a weighted history of past gradients.
When gradients are consistently aligned (e.g.\ along a valley floor), the
accumulated momentum amplifies the effective step, accelerating convergence.
The update can be written as
$x_{k+1} = x_k - \alpha\sum_{j=0}^{k} \beta^{k-j}\nabla f(x_j)$,
showing that the step is a geometrically weighted sum of all past gradients.

\subsection{Theoretical Analysis and Comparative Discussion}

\begin{theorem}[Adagrad Convergence \cite{duchi2011adaptive}]
\label{thm:adagrad}
For a convex, $G$-Lipschitz function with $\|\nabla f(x)\| \leq G$ for all $x$,
Adagrad with base rate $\alpha_0$ achieves after $T$ steps:
\[
  \min_{k \leq T} f(x_k) - f^\star
  \;\leq\;
  \frac{\|x_0 - x^\star\|^2}{2\alpha_0 \sqrt{T}}
  + \frac{\alpha_0 G \sqrt{d}}{\sqrt{T}},
\]
which gives an overall $O(1/\sqrt{T})$ rate. For smooth ($L$-smooth) functions in
the noiseless case, Adagrad achieves $O(\log T / \sqrt{T})$, interpolating towards
$O(1/T)$ as the problem becomes well-conditioned. The key advantage over constant-step
GD is that Adagrad automatically tunes the step size per coordinate: dimensions with
sparse gradients retain larger steps, beneficial in problems with heterogeneous features.
\end{theorem}

\begin{theorem}[Polyak Step Convergence]
\label{thm:polyak}
Let $f$ be convex with $f^\star$ known exactly. If $f$ is $L$-smooth
and satisfies the Polyak--\L{}ojasiewicz (PL) condition with constant $\mu > 0$,
i.e.\ $\|\nabla f(x)\|^2 \geq 2\mu(f(x) - f^\star)$ for all $x$, then the
Polyak step achieves
\[
  f(x_{k+1}) - f^\star \leq \left(1 - \frac{\mu}{L}\right)(f(x_k) - f^\star),
\]
i.e.\ linear convergence at a rate independent of the condition number \cite{polyak1969minimization}.
\end{theorem}

\begin{remark}
Benchmark~A satisfies the PL condition (it is strongly convex), which is why the Polyak
step would converge rapidly if $f^\star = 0.4826$ were used instead of $0$.
Benchmark~C also satisfies a local PL condition near the optimum, allowing fast convergence
when $f^\star = 0$ is correctly specified.
\end{remark}

\textbf{Key findings:}
\begin{itemize}[nosep]
\item \textbf{Polyak step:} Theoretically optimal when $f^\star$ is known exactly.
  Practically dangerous when $f^\star$ is misspecified, as the step diverges.
  The sensitivity arises because $\alpha_k \propto (f(x_k) - f^\star)/\|\nabla f(x_k)\|^2$:
  a non-zero numerator combined with a vanishing denominator gives $\alpha_k \to \infty$.

\item \textbf{Adagrad:} Uniformly stable due to monotonically decreasing step size.
  Performs on par with GD on well-conditioned problems (Benchmarks A, B). On the
  ill-conditioned Rosenbrock, the per-coordinate scaling provides some benefit, though
  the step decay limits long-run progress.

\item \textbf{RMSprop:} The exponential moving average addresses Adagrad's step
  stagnation. However, tuning $\alpha_0$ on Rosenbrock is difficult because the
  required rate is very small; with $\alpha_0 = 0.0035$ it matches GD performance.

\item \textbf{Heavy Ball:} Momentum accumulation along the valley floor yields
  significant improvement on Rosenbrock ($f = 1.40$ vs.\ GD $f = 3.51$), at the
  cost of overshoot on well-conditioned problems.

\item \textbf{Practical recommendation:} When $f^\star$ is unknown, RMSprop or
  Adagrad are safer adaptive choices. When momentum is desired without curvature
  information, Heavy Ball provides meaningful acceleration at near-zero additional cost.
\end{itemize}

\subsubsection*{Practical Tuning Guidance}

The hyperparameters in Table~\ref{tab:q1_params} were selected to ensure stable
convergence on each benchmark. The following principles guided the choices:
\begin{itemize}[nosep]
\item \textbf{GD step size:} Must satisfy $\alpha < 2/L$ for convergence.
  Benchmark A: $L \approx 1.03$, so $\alpha = 0.08 \ll 2/1.03 \approx 1.94$ (conservative).
  Benchmark C: $L(x_0) \approx 1002$ at start, requiring $\alpha < 2/1002 \approx 0.002$,
  hence $\alpha = 0.0012$.
\item \textbf{Adagrad $\alpha_0$:} A larger base rate works because the effective step
  $\alpha_0/\sqrt{G_k}$ shrinks automatically; $\alpha_0 = 1.8$ for Benchmark A
  accounts for the large initial gradient norms.
\item \textbf{RMSprop:} The base rate $\alpha_0 = 0.0035$ for Benchmark C reflects
  the need for stability on the highly curved Rosenbrock surface, where even the
  RMSprop denominator cannot fully compensate for the extreme condition number.
\end{itemize}

\begin{proposition}[Heavy Ball on Quadratics]
For a quadratic $f(x) = \frac{1}{2}x^T H x - b^T x$ with eigenvalues
$\mu \leq \lambda_i \leq L$, the optimal Heavy Ball parameters are
$\alpha^* = \frac{4}{(\sqrt{L}+\sqrt{\mu})^2}$ and
$\beta^* = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2$,
achieving convergence rate $\rho^* = \frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}$,
which matches Nesterov's optimal rate on strongly convex functions \cite{polyak1964methods}.
\end{proposition}

\begin{remark}
For Benchmark~A with $\mu \approx 0.925$, $L \approx 1.033$, $\kappa \approx 1.12$:
\begin{align*}
  \alpha^\star &= \frac{4}{(\sqrt{1.033}+\sqrt{0.925})^2}
               = \frac{4}{(1.016+0.962)^2}
               = \frac{4}{3.912} \approx 0.96 \\
  \beta^\star  &= \left(\frac{\sqrt{1.12}-1}{\sqrt{1.12}+1}\right)^2
               = \left(\frac{0.058}{2.058}\right)^2 \approx 0.00079 \\
  \rho^\star   &= \frac{\sqrt{1.12}-1}{\sqrt{1.12}+1} \approx 0.058
\end{align*}
The extremely small $\beta^\star$ confirms that for near-isotropic problems ($\kappa \approx 1$),
momentum provides almost no benefit. For Benchmark~C (Rosenbrock, local $\kappa \approx 2508$
at the minimiser), the theoretical optimum would be
$\beta^\star = \bigl((\sqrt{2508}-1)/(\sqrt{2508}+1)\bigr)^2 \approx (0.969)^2 \approx 0.940$,
with $\rho^\star \approx 0.969$ per step --- still far slower than the $\sqrt{\kappa}$-free
rate achievable with Nesterov. The experimentally used $\beta = 0.86$ is conservative
to avoid overshoot on the highly nonlinear Rosenbrock valley.
The key challenge in practice is that the optimal $\beta^*$ depends on the (global/local)
spectral gap of $H$, which is generally unknown.
\end{remark}

\subsection{Motivation and Theoretical Background}

Classical gradient descent on a $\mu$-strongly convex, $L$-smooth function
achieves a linear convergence rate of $(1 - \mu/L)^k$, which is slow when
$\kappa = L/\mu$ is large. Nesterov's acceleration \cite{nesterov1983method} achieves the
\emph{optimal} rate $(1 - \sqrt{\mu/L})^k$ for smooth strongly convex functions,
reducing the effective condition number from $\kappa$ to $\sqrt{\kappa}$
(covered in Week~4b of the course). Adam and mini-batch SGD were introduced in Week~5.
The speedup is most pronounced for large $\kappa$: on Benchmark~C ($\kappa \approx 2508$),
the GD rate is $(1 - 1/2508)^k \approx e^{-k/2508}$ while Nesterov achieves
$(1 - 1/\sqrt{2508})^k \approx e^{-k/50}$, a $50\times$ improvement in convergence speed.
This theoretical factor-of-$\sqrt{\kappa}$ acceleration is clearly visible in Figure~\ref{fig:q2_fval_C}.
Figure~\ref{fig:conv_rates} shows the three convergence rates as a function of $\kappa$,
confirming the growing advantage of Nesterov over GD for large condition numbers.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/convergence_rates_comparison.pdf}
\caption{Theoretical convergence rates (left) and required iterations to reduce error by $10^6$
(right) as a function of condition number $\kappa$ for GD, Heavy Ball (with optimal parameters),
and Nesterov. The vertical lines mark Benchmarks~A ($\kappa \approx 1.12$) and~C ($\kappa \approx 2508$).
At large $\kappa$: GD requires $O(\kappa)$ iterations, Heavy Ball $O(\sqrt{\kappa})$, and Nesterov

to reduce the error by $10^6\times$ (i.e.\ $50\times$ faster as predicted by theory).}

\end{figure}

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Accelerated Gradient \cite{nesterov1983method}}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max} \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Momentum update}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The defining feature of Nesterov's method is the \emph{lookahead}: the gradient is
evaluated at the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than at
$x_k$. This anticipatory correction prevents the overshoot that afflicts the Heavy Ball
method and enables the $O(1/k^2)$ convergence rate on general convex functions
\cite{nesterov1983method}. The schedule $\beta_k = (k-1)/(k+2)$ was derived by
Nesterov to guarantee this optimal rate; the cap $\beta_{\max}$ prevents instability
in early iterations.

\begin{theorem}[Nesterov Convergence Rate]
Let $f$ be convex and $L$-smooth. With step size $\alpha = 1/L$ and the momentum
schedule $\beta_k = (k-1)/(k+2)$, Nesterov's method satisfies
\[
  f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2},
\]
achieving the optimal $O(1/k^2)$ convergence rate for first-order methods on smooth
convex functions \cite{nesterov1983method}. On Benchmark~C with $\|x_0 - x^\star\| \approx 2$
and $L \approx 1002$, this gives $f(x_{150}) - f^\star \leq 2 \cdot 1002 \cdot 4 / 151^2 \approx 351$,
a loose bound; the actual result ($f = 0.479$) reflects local acceleration near the minimum
rather than the global worst-case bound.
\end{theorem}

\begin{algorithm}[H]
\caption{Adam Optimiser \cite{kingma2015adam}}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha > 0$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First-moment (mean) estimate}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second-moment (variance) estimate}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction (counters zero initialisation)}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines the momentum of Heavy Ball (via the exponential moving average $m_t$)
with the per-coordinate adaptive scaling of RMSprop (via $v_t$).
The bias-correction factors $(1 - \beta_1^t)^{-1}$ and $(1-\beta_2^t)^{-1}$
correct for the fact that $m_0 = v_0 = 0$ biases the early estimates towards zero.
The effective learning rate per coordinate is approximately
$\alpha / \sqrt{v_t + \varepsilon} \in [\alpha/\sqrt{G_k} ,\, \alpha/\varepsilon]$,
bounded away from zero, which prevents the premature stagnation of Adagrad.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD is applied to Benchmark~A with learning rate $\alpha = 0.06$,
batch sizes $b \in \{5, 40\}$, and $E = 50$ epochs. The data is
reshuffled at the start of each epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1,\ldots,m\}$
    \For{each mini-batch $\mathcal{B} \subset \{1,\ldots,m\}$ of size $b$}
        \State $\hat{g} \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$
        \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, \hat{g}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[SGD Variance]
The stochastic gradient $\hat{g}$ is an \emph{unbiased} estimate of the full gradient:
$\mathbb{E}[\hat{g}] = \nabla J(\theta)$. Its variance can be decomposed as:
\[
  \operatorname{Var}[\hat{g}] = \frac{1}{b}\operatorname{Var}_{i}[g^{(i)}(\theta)],
\]
where $g^{(i)} = (X_i\theta - y_i) X_i^T / m$ is the per-sample gradient,
and the variance decreases linearly with batch size $b$. This means:
\begin{itemize}[nosep]
\item Larger batches ($b = 40$) produce lower-variance gradient estimates (smoother convergence)
  but perform fewer updates per epoch ($m/b = 25$ steps vs.\ $200$ steps for $b=5$).
\item Smaller batches ($b = 5$) perform more updates per epoch with higher gradient noise.
\end{itemize}
The fundamental limit is the \emph{noise floor}: as $\theta \to \hat\theta$, the gradient
$\nabla J(\hat\theta) = 0$ but the stochastic gradient $\hat{g}(\hat\theta) \neq 0$
(since individual samples deviate from the mean), causing oscillation of magnitude
$O(\sigma^2/b)$ around the minimum \cite{bottou2018optimization}.
This irreducible noise is a fundamental feature of stochastic optimisation that can only
be reduced by decreasing the learning rate (at the cost of slower convergence) or
increasing the batch size (at the cost of fewer updates per unit of computation).
\end{remark}

\subsection{Comparison of Nesterov and Adam}

Nesterov acceleration and Adam represent complementary approaches to improving over
vanilla gradient descent:

\begin{remark}[Adam convergence]
Adam does not have a tight $O(1/k)$ convergence guarantee for smooth convex functions
in general. Reddi et al.~\cite{reddi2018convergence} showed that the original Adam update can
\emph{diverge} on convex problems and proposed AMSGrad as a fix. In practice, Adam
converges reliably when gradients are noisy and heterogeneous but its theoretical
guarantees remain weaker than those of Nesterov. The effective per-coordinate
learning rate $\alpha_k^{(i)} = \alpha / (\sqrt{\hat{v}_t^{(i)}} + \varepsilon)$
is bounded in $[\alpha/\sqrt{G_k}, \alpha/\varepsilon]$, preventing the indefinite
decay of Adagrad while retaining scale invariance.
\end{remark}

\begin{itemize}[nosep]
\item \textbf{Nesterov} exploits the temporal structure of the optimisation trajectory:
  it looks ahead in the momentum direction before computing the gradient.
  This yields the theoretically optimal $O(1/k^2)$ rate for smooth convex functions,
  but does not adapt to per-coordinate curvature.

\item \textbf{Adam} exploits the per-coordinate structure of the gradient through
  adaptive scaling. It is better suited to problems with highly heterogeneous curvature
  across coordinates, but lacks the global acceleration guarantee of Nesterov.

\item On \textbf{Benchmark~C} (Rosenbrock), Nesterov outperforms Adam ($0.479$ vs $1.578$)
  because the dominant challenge is the ill-conditioned valley geometry, where
  directional momentum is more valuable than per-coordinate scaling.
  Adam's per-coordinate scaling cannot account for the off-diagonal curvature
  ($H_{12} = -400 x_1 \neq 0$) that makes valley traversal difficult.

\item The bias parameters $\beta_1 = 0.80$--$0.82$ (lower than the default $0.9$)
  reduce the momentum contribution, which improves stability on the Rosenbrock
  surface where large momentum would cause overshooting across the valley.

\item In practice, Adam is preferred for stochastic settings (deep learning) where
  unbiased gradient estimates are noisy and per-coordinate tuning is critical.
  Nesterov is preferred for deterministic settings with known smoothness constants.
\end{itemize}

\subsection{Local Approximations of $g(x) = x^4$}

Newton's method is motivated by the idea of minimising a local quadratic model of $f$
at each iteration (introduced in Week~6a; quasi-Newton methods and L-BFGS in Week~6b).
To illustrate the local approximation principle, consider $g(x) = x^4$ at $x_0 = 0.25$.

The function values at the expansion point are:
$g(0.25) = 0.25^4 = 0.00391$,
$g'(0.25) = 4 \times 0.25^3 = 0.0625$,
$g''(0.25) = 12 \times 0.25^2 = 0.750$.

\textbf{First-order (linear) approximation:}
\begin{equation}
  \hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0)
               = 0.00391 + 0.0625(x - 0.25).
  \label{eq:first_order}
\end{equation}

\textbf{Second-order (quadratic) approximation:}
\begin{equation}
  \hat{g}_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2
               = 0.00391 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
  \label{eq:second_order}
\end{equation}

The Newton update step minimises $\hat{g}_2(x)$ by setting its derivative to zero:
\begin{equation}
  \frac{d\hat{g}_2}{dx} = g'(x_0) + g''(x_0)(x - x_0) = 0
  \implies
  x_1 = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{0.0625}{0.750} = 0.167.
  \label{eq:newton_step_1d}
\end{equation}

This step moves towards the minimum of the local quadratic model, which is a better
approximation of the function's minimum than a simple gradient step.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{figures/q3_approximation.pdf}
\caption{Q3: Local approximations of $g(x) = x^4$ at $x_0 = 0.25$ (marked with circle).
The first-order tangent line (blue dashed) diverges rapidly from the true function for
$|x - x_0| > 0.1$. The second-order parabola (red dash-dot) fits well in a neighbourhood
of $x_0$ and its minimum provides a much better estimate of the function's minimiser
than a gradient step alone. This motivates Newton's method: iteratively minimising the
quadratic model to take larger, more accurately directed steps.}
\label{fig:q3_approx}
\end{figure}

\subsection{Newton's Method with Damping}

In $\mathbb{R}^d$, Newton's method replaces the scalar update \eqref{eq:newton_step_1d}
with the solution of a linear system:
\begin{equation}
  x_{k+1} = x_k - \alpha\, H_k^{-1}\, \nabla f(x_k),
  \label{eq:newton_update}
\end{equation}
where $H_k = \nabla^2 f(x_k)$ is the Hessian at $x_k$, and $\alpha$ is a damping
factor (step size). The pure Newton step ($\alpha = 1$) may overshoot when the
Hessian changes rapidly; damping ($\alpha < 1$) improves global behaviour at the cost
of slower convergence.

\begin{algorithm}[H]
\caption{Newton's Method with Regularised Hessian}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, Hessian regularisation $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Regularised Hessian (ensures positive definiteness)}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Hessian regularisation $\lambda I$ ensures positive definiteness of $H_k + \lambda I$
when the Hessian has small or negative eigenvalues (e.g.\ near saddle points or with
numerical noise). With $\lambda = 10^{-8}$ in these experiments, regularisation is
purely for numerical stability and does not materially affect convergence.

\begin{theorem}[Newton: Exact Convergence on Quadratics]
\label{thm:newton_quadratic}
For a quadratic $J(\theta) = \frac{1}{2m}\|X\theta - y\|^2$ with constant Hessian
$H = \frac{1}{m}X^TX \succ 0$ and minimiser $\hat\theta = H^{-1} \frac{1}{m}X^Ty$,
Newton's method with full step $\alpha = 1$ satisfies $\theta_1 = \hat\theta$ for any
starting point $\theta_0$. \emph{Proof:}
$\nabla J(\theta) = H(\theta - \hat\theta)$, so
$\theta_1 = \theta_0 - H^{-1}\nabla J(\theta_0) = \theta_0 - H^{-1}H(\theta_0 - \hat\theta) = \hat\theta$.
$\square$
\end{theorem}

\begin{theorem}[Newton Quadratic Convergence Near Optima]
Let $f$ be twice continuously differentiable with Lipschitz-continuous Hessian.
If $\alpha = 1$ (full Newton step) and the iterate $x_k$ is sufficiently close
to a local minimum $x^\star$ with $\nabla^2 f(x^\star) \succ 0$, then Newton's
method converges quadratically:
\[
  \|x_{k+1} - x^\star\| \leq C\,\|x_k - x^\star\|^2
\]
for some constant $C > 0$ depending on the local Lipschitz constant of $\nabla^2 f$
\cite{nocedal2006numerical}. For non-quadratic $f$, this rate holds only in a
neighbourhood of $x^\star$ (local convergence); from far away, damping $\alpha < 1$
is required for global convergence.
\end{theorem}

\subsection{Analysis: Why Newton Outperforms GD}

The fundamental reason Newton's method outperforms gradient descent is that it
\emph{accounts for curvature}. Consider the update directions:
\begin{itemize}[nosep]
\item GD moves in the direction $-\nabla f$, which is perpendicular to the level curves.
  On anisotropic functions, this direction can be far from the direction of steepest
  descent towards the minimum.
\item Newton moves in $-H^{-1}\nabla f$, which whitens the gradient by the inverse
  Hessian. For a quadratic $f(x) = \frac{1}{2}x^T H x - b^T x$, this gives the exact
  minimiser in one step regardless of the condition number $\kappa(H)$.
\end{itemize}

The cost is computing and inverting the $d \times d$ Hessian at each step: $O(d^3)$
operations versus $O(d)$ for gradient descent. For large-scale machine learning with
millions of parameters, this cost is prohibitive, motivating quasi-Newton methods
(L-BFGS) that approximate $H^{-1}$ using rank-2 updates.

\textbf{Quasi-Newton perspective.} The L-BFGS method (Limited-memory Broyden--Fletcher--Goldfarb--Shanno)
maintains an approximation $B_k \approx H_k^{-1}$ using the most recent $m$ gradient
difference pairs $\{s_k, y_k\}$ where $s_k = x_{k+1} - x_k$ and $y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$:
\begin{equation}
  B_{k+1} = B_k + \frac{s_k s_k^T}{y_k^T s_k} - \frac{B_k y_k y_k^T B_k}{y_k^T B_k y_k}.
  \label{eq:bfgs_update}
\end{equation}
This rank-2 update satisfies the secant condition $B_{k+1} y_k = s_k$ and requires only
$O(md)$ storage and $O(md)$ computation per iteration rather than $O(d^2)$ and $O(d^3)$
for exact Newton, making quasi-Newton methods the practical choice for problems with
$d = 10^3$--$10^6$.

\textbf{Connection to lecture material.}
The Newton method as applied here directly implements the second-order update from the
course \emph{Newton and quasi-Newton Methods} (Week 6), demonstrating that for
well-behaved smooth functions, accounting for curvature dramatically reduces the
number of iterations required compared to first-order methods.

\subsection{Part 1: Finite Difference Gradient Approximation (Benchmark B)}

When analytical gradients are unavailable, they can be approximated via finite differences
(covered in Week~8a). Nelder--Mead and random search methods were discussed in Week~8b.
The forward finite-difference approximation of the $i$-th partial derivative is:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}
  = \frac{\partial f}{\partial x_i}(x) + \underbrace{O(\delta)}_{\text{truncation error}}
  + \underbrace{O(\varepsilon_{\rm mach}/\delta)}_{\text{roundoff error}},
  \label{eq:fd_error}
\end{equation}
where $e_i$ is the $i$-th standard basis vector and $\delta$ is the perturbation size.

The total error in the finite-difference approximation \eqref{eq:fd_error} has two
competing contributions. More precisely, expanding by Taylor's theorem:
\[
  f(x + \delta e_i) = f(x) + \delta\frac{\partial f}{\partial x_i}(x) + \frac{\delta^2}{2}\frac{\partial^2 f}{\partial x_i^2}(\xi) + O(\delta^3),
\]
so the truncation error of the forward difference is $\frac{\delta}{2}|\partial^2 f/\partial x_i^2|$,
which is first-order in $\delta$. The centred difference
$[f(x + \delta e_i) - f(x - \delta e_i)]/(2\delta)$ reduces this to $O(\delta^2)$,
at the cost of an extra function evaluation per coordinate.

For the forward difference:
\begin{itemize}[nosep]
\item \textbf{Truncation error:} $\approx \frac{\delta}{2}|\partial^2 f/\partial x_i^2|$.
\item \textbf{Roundoff error:} $\approx \varepsilon_{\rm mach}\,|f(x)|/\delta$
  (cancellation in the difference $f(x+\delta e_i) - f(x)$).
\end{itemize}
Minimising the total error gives $\delta^\star \approx \sqrt{2\varepsilon_{\rm mach}\,|f(x)|/|\partial^2 f/\partial x_i^2|}$.
For functions of order unity, $\delta^\star \approx \sqrt{\varepsilon_{\rm mach}} \approx 1.5 \times 10^{-8}$.
The experiment uses $\delta_{\rm good} = 0.05$ (near-optimal for Benchmark B's scale)
and $\delta_{\rm poor} = 0.8$ (too large: truncation error $\approx 0.4|\partial^2 f/\partial x_i^2|$,
which for Benchmark B is $O(4)$, completely dominating the gradient signal).

\subsection{Part 2: Nesterov Random Search (Benchmark B)}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order Method)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$; normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$
    \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The estimator $\hat{g}_k$ is a scaled directional derivative:
$\hat{g}_k \approx (u_k^T \nabla f(x_k))\, u_k = \Pi_{u_k}\nabla f(x_k)$,
the projection of the gradient onto the random direction $u_k$.
Its expected value (over random $u_k$) is a smoothed gradient \cite{nesterov2017random}:
\[
  \mathbb{E}[\hat{g}_k] = \frac{1}{d}\nabla f_\delta(x_k) \approx \frac{1}{d}\nabla f(x_k),
\]
so the method converges in the direction of the true gradient on average, but with
variance scaling as $d$: on a 2D problem the variance is $2\times$ that of the full
gradient, but in high dimensions ($d = 1000$) the variance is $1000\times$ higher.
The method requires only 2 function evaluations per step regardless of $d$,
making it attractive when $d$ is large but gradient computation is unavailable
(e.g.\ black-box simulation models).

\begin{theorem}[Nesterov Random Search Convergence \cite{nesterov2017random}]
\label{thm:nrs}
For a convex $L$-smooth function with $\mu$-strongly convex component,
Nesterov random search with step size $\alpha = d / (2L d) = 1/(2L)$ satisfies
in expectation:
\[
  \mathbb{E}[f(x_k)] - f^\star \leq \left(1 - \frac{\mu}{dL}\right)^k (f(x_0) - f^\star).
\]
The dimension factor $d$ in the denominator replaces the $\kappa = L/\mu$ factor
of GD with $d\kappa$, explaining the significantly slower convergence observed
on Benchmark~B ($d=2$, already $2\times$ slower than exact-gradient GD).
\end{theorem}

\subsection{Part 3: Nelder--Mead Simplex Method (Benchmark C)}

The Nelder--Mead algorithm \cite{nelder1965simplex} maintains a simplex of $n+1 = 3$
vertices in $\mathbb{R}^n$ and iteratively deforms it through four geometric operations,
requiring no gradient evaluations:

\begin{enumerate}[nosep]
\item \textbf{Reflection} ($\alpha_r = 1.0$): move the worst vertex through the centroid of the
  remaining $n$ vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x_{\rm worst})$.
\item \textbf{Expansion} ($\gamma = 2.0$): if reflection strictly improves, try further:
  $x_e = \bar{x} + \gamma(\bar{x} - x_{\rm worst})$.
\item \textbf{Contraction} ($\rho = 0.5$): if reflection does not improve, contract:
  $x_c = \bar{x} + \rho(\cdot - \bar{x})$ (inside or outside).
\item \textbf{Shrink} ($\sigma = 0.5$): if contraction fails, shrink all vertices towards
  the best.
\end{enumerate}

Settings: initial simplex step $= 0.35$, $N = 160$ iterations, with default
Nelder--Mead parameters: reflection $\alpha_r = 1.0$, expansion $\gamma = 2.0$,
contraction $\rho = 0.5$, shrink $\sigma = 0.5$ \cite{nelder1965simplex}.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/q4_nelder_mead_C.pdf}
\caption{Q4B: Nelder--Mead on Benchmark C (160 iterations, step $= 0.35$).
Left: the simplex centroid trajectory navigates the curved Rosenbrock valley without
any gradient information; the simplex adapts geometrically through reflection, expansion,
contraction, and shrink operations. Right: the best objective value decreases from

Nelder--Mead achieves $f = 0$ in 160 iterations (320 function evaluations at 2~FE per
non-shrink step), which is competitive with gradient-based methods at far lower information
cost. The key to its success on Rosenbrock is the \emph{adaptive simplex geometry}: the
simplex elongates along the valley direction, effectively learning the local curvature
without computing any derivatives. This geometry-adaptation provides the equivalent of
momentum in gradient methods --- the simplex ``remembers'' the productive direction and
exploits it in subsequent steps.

However, Nelder--Mead is not convergence-guaranteed in general: there exist counterexamples
where it stagnates on non-convex functions in $d \geq 4$ dimensions, and the method does
not have a formal convergence rate. Its practical success on Rosenbrock is largely due to
the unimodality and smooth geometry of the function in $d = 2$.

\subsection{Problem Setup}

Projected gradient descent and penalty methods for constrained optimisation were
introduced in Week~9a and Week~9b of the course, respectively.

We minimise Benchmark~B subject to the half-space constraint $x_1 \geq 0.5$:
\begin{equation}
  \min_{x \in \mathbb{R}^2} f(x) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1)
  \quad \text{subject to} \quad x_1 \geq 0.5.
  \label{eq:q5_problem}
\end{equation}
The unconstrained minimum is at $x^\star_{\rm unconstrained} \approx (0.582, 2.0)$,
which satisfies $x_1 > 0.5$ and is therefore also the \emph{constrained} minimum:
$x^\star = (0.582, 2.0)$, $f^\star \approx 0.7244$.
Starting point: $x_0 = (0.2, 4.0)^T$, which is \emph{infeasible} ($0.2 < 0.5$).

\subsection{Algorithm Formulations}

\subsubsection{Projected Gradient Descent}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1})$ \Comment{Project onto feasible set}
\EndFor
\end{algorithmic}
\end{algorithm}

For the constraint $x_1 \geq 0.5$, the projection is elementwise:
\begin{equation}
  \Pi_{\mathcal{X}}(z) = \begin{bmatrix}\max(0.5,\; z_1) \\ z_2\end{bmatrix}.
  \label{eq:proj_q5}
\end{equation}
This is a $O(1)$ operation for the box-like constraint used here. For general
constraint sets, computing the projection can require solving a quadratic
programme, which may itself be expensive.

\begin{theorem}[Projected Gradient Descent Convergence \cite{bertsekas1999nonlinear}]
For a convex, $L$-smooth $f$ and closed convex set $\mathcal{X}$, projected gradient
descent with step size $\alpha \leq 1/L$ satisfies
\[
  f(x_k) - f^\star \leq \frac{\|x_0 - x^\star\|^2}{2\alpha k}.
\]
The projection ensures $x_k \in \mathcal{X}$ for all $k \geq 1$, providing \emph{strict feasibility}
at every iteration.
\end{theorem}

\subsubsection{Penalty Method}

\begin{algorithm}[H]
\caption{Gradient Descent on Penalised Objective}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x_k) \gets f(x_k) + \lambda\, \max(0,\; 0.5 - x_1)$
    \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla_x F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

where the penalised gradient is:
\begin{equation}
  \nabla F_\lambda(x) = \nabla f(x) + \lambda\, \nabla_x \max(0,\; 0.5 - x_1)
  = \nabla f(x) - \lambda\, \mathbf{1}[x_1 < 0.5]\, e_1.
  \label{eq:penalty_grad}
\end{equation}
The penalty term $\lambda \max(0, 0.5 - x_1)$ adds a cost proportional to the
constraint violation. As $\lambda \to \infty$, the constrained problem
\eqref{eq:q5_problem} is recovered asymptotically, but finite $\lambda$ admits
residual violations and may require smaller step sizes for stability.

\begin{remark}[Why large $\lambda$ requires smaller step size]
The penalised objective $F_\lambda$ has Lipschitz constant of its gradient:
\[
  L_\lambda = L_f + \lambda \cdot L_c,
\]
where $L_f$ is the smoothness constant of $f$ and $L_c$ is the Lipschitz constant
of $\nabla c(x) = \nabla\max(0, 0.5 - x_1)$. Since $\nabla c$ is discontinuous at
$x_1 = 0.5$, the penalty function is not smooth --- the gradient of $F_\lambda$ has
a jump of magnitude $\lambda$ at the constraint boundary. For stability, gradient
descent requires step size $\alpha \leq 1/(L_f + \lambda)$, explaining why
$\lambda = 4.5$ uses $\alpha = 0.03$ while $\lambda = 1.8$ uses $\alpha = 0.05$.
\end{remark}

\textbf{KKT conditions.} At the constrained optimum $x^\star$, the
Karush--Kuhn--Tucker (KKT) conditions for \eqref{eq:q5_problem} are:
\[
  \nabla f(x^\star) + \mu^\star (-e_1) = 0, \quad
  \mu^\star (x_1^\star - 0.5) = 0, \quad
  \mu^\star \geq 0, \quad x_1^\star \geq 0.5.
\]
Since the unconstrained minimum $x_1^\star = 0.582 > 0.5$ lies in the interior,
the constraint is inactive ($x_1^\star - 0.5 > 0$), the complementary slackness
condition forces $\mu^\star = 0$, and the KKT conditions reduce to $\nabla f(x^\star) = 0$.
This is why the constrained and unconstrained minima coincide in this experiment.

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$
($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$ to
maintain stability on the more steeply penalised objective); unconstrained GD ($\alpha = 0.07$);
all run for 100 iterations.

\subsection{Comparative Analysis}

\textbf{Projected Gradient Descent} maintains strict feasibility $x_k \in \mathcal{X}$
at every iteration by construction. The projection onto $\{x : x_1 \geq 0.5\}$ is a
simple $\max$ operation. When the constraint is \emph{inactive} (unconstrained optimum
interior, as here), PGD converges to the unconstrained minimum with the standard GD rate,
since the projection is applied but leaves the iterate unchanged once $x_1 \geq 0.5$.
When the constraint is \emph{active} (unconstrained optimum outside $\mathcal{X}$),
PGD slides along the constraint boundary, converging to the constrained KKT point where
$\nabla f(x^\star)^T (x - x^\star) \geq 0$ for all $x \in \mathcal{X}$
(the optimality condition for a constrained minimum). The disadvantage is that the
projection oracle must be computationally tractable; for general convex sets
(e.g.\ nuclear norm balls, positive semidefinite cones, intersection of halfspaces),
projection may require solving a convex programme at each step.

\textbf{Penalty methods} replace the constrained problem with an unconstrained
penalised surrogate $F_\lambda = f + \lambda\, c(x)$. The weight $\lambda$ controls
the feasibility--optimality trade-off:
\begin{itemize}[nosep]
\item \emph{Active constraint} ($x^\star_{\text{unc}} \notin \mathcal{X}$): small $\lambda$ yields
  large residual violation; large $\lambda$ approaches the constrained minimum but
  increases $L_\lambda = L_f + \lambda L_c$, requiring $\alpha \leq 1/L_\lambda$.
\item \emph{Inactive constraint} ($x^\star_{\text{unc}} \in \mathcal{X}$, as in this experiment):
  $\nabla f$ already drives iterates into the feasible set, so even small $\lambda$ achieves
  exact feasibility at the optimum. The choice of $\lambda$ only affects the
  transient path from the infeasible starting point.
\end{itemize}
In the limit $\lambda \to \infty$, the penalty method recovers the exact constrained
solution for active constraints but becomes increasingly ill-conditioned. A practical alternative is the
\emph{augmented Lagrangian} method, which combines the penalty term with a Lagrange
multiplier estimate to maintain well-conditioning while achieving exact feasibility
at finite $\lambda$ \cite{bertsekas1999nonlinear}.

\subsection{Feasible Set and Linear Programme}

The feasible set is the box polytope:
$\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\; -5 \leq x_2 \leq 10\}$.

\textbf{Linear Programme.} For the linear objective $f(x) = a^T x$ with $a = (1, 2)^T$,
the minimum over $\mathcal{X}$ is found by solving:
\begin{equation}
  \min_{x \in \mathcal{X}}\; x_1 + 2x_2
  = \min_{0.5 \leq x_1 \leq 5}\; x_1 + \min_{-5 \leq x_2 \leq 10}\; 2x_2
  = 0.5 + 2(-5) = -9.5.
  \label{eq:lp_sol}
\end{equation}
Since both components of $a$ are positive, the minimum is attained at the lower bounds
of each coordinate:
\begin{equation}
  x^{\star}_{\rm LP} = (0.5,\; -5)^T, \qquad f^{\star}_{\rm LP} = -9.5.
  \label{eq:lp_opt}
\end{equation}
This illustrates the \emph{fundamental theorem of linear programming}: the minimum of
a linear objective over a bounded convex polytope is always attained at a vertex.

\subsection{Frank--Wolfe (Conditional Gradient) Algorithm}

The Frank--Wolfe algorithm \cite{frank1956algorithm} (also called the conditional gradient
method; covered in Week~10a of the course) is designed for minimising a differentiable
function over a convex compact set without an explicit projection oracle.
Instead, each iteration requires solving a \emph{linear minimisation oracle} (LMO) over $\mathcal{X}$.

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient) \cite{frank1956algorithm}}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial feasible point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{s \in \mathcal{X}}\, \nabla f(x_k)^T s$
    \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$
    \Comment{Convex combination (stays in $\mathcal{X}$)}
\EndFor
\end{algorithmic}
\end{algorithm}

For the box constraint $\mathcal{X}$, the LMO decomposes per coordinate:
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
  \quad i = 1, \ldots, d.
  \label{eq:lmo_box}
\end{equation}
This requires only $O(d)$ operations, compared to $O(d)$ for computing the projection
onto a box. The key advantage of Frank--Wolfe is that \emph{iterates are always feasible}
by design: since $x_k \in \mathcal{X}$ and $z_k \in \mathcal{X}$, their convex
combination $\beta x_k + (1-\beta) z_k \in \mathcal{X}$.

\begin{theorem}[Frank--Wolfe Convergence \cite{jaggi2013revisiting}]
Let $f$ be convex and $L$-smooth. Frank--Wolfe with the standard step size schedule
$\gamma_k = 2/(k+2)$ (i.e.\ $\beta = 1 - \gamma_k$) satisfies
\[
  f(x_k) - f^\star \leq \frac{2LC^2_f}{k+2},
\]
where $C_f = \operatorname{diam}(\mathcal{X}) = \sup_{x,y \in \mathcal{X}}\|x-y\|$ is
the diameter of the feasible set. For the box
$\mathcal{X} = [0.5, 5] \times [-5, 10]$, we have
$C_f = \sqrt{(5-0.5)^2 + (10-(-5))^2} = \sqrt{245.25} \approx 15.66$.
With $L = 2$ (Hessian of $(x_1-1)^2 + (x_2-5)^2$) and $k = 180$,
the bound evaluates to $2 \cdot 2 \cdot 15.66^2 / 182 \approx 5.39$.
The actual performance ($f = 0.0046$ for $\beta = 0.985$) is far below this worst-case bound,
since the bound uses the global diameter while the algorithm converges locally.
\end{theorem}

\begin{remark}
The fixed $\beta$ schedule used in the experiments is equivalent to a constant
$\gamma = 1 - \beta$ rather than the optimal decaying schedule $\gamma_k = 2/(k+2)$.
A constant step size does not guarantee convergence to the exact minimum; it introduces
a ``zig-zag'' oscillation as $z_k$ switches between vertices of $\mathcal{X}$.
\end{remark}

\subsection{Interior vs.\ Boundary Behaviour and Frank--Wolfe Gap}

A key diagnostic for Frank--Wolfe is the \emph{duality gap}:
\begin{equation}
  g_k = \nabla f(x_k)^T (x_k - z_k) \geq f(x_k) - f^\star,
  \label{eq:fw_gap}
\end{equation}
which provides a computable upper bound on the suboptimality $f(x_k) - f^\star$.
When $g_k \approx 0$, the method has approximately satisfied the first-order
optimality conditions for the constrained problem.

\textbf{Interior optimum behaviour:} As $x_k \to (1, 5)$, the gradient
$\nabla f(x_k) \to 0$, so $z_k$ switches unpredictably between vertices
as the gradient direction changes sign. This causes the ``zig-zag'' oscillation
of $z_k$ visible in Figure~\ref{fig:q6_evolution}. The iterate $x_k$ nonetheless
converges because each convex combination moves it closer to the interior minimum.

\textbf{Boundary optimum behaviour:} When the constrained minimum lies on the
boundary, $z_k$ consistently selects the same vertex (or a small set of nearby
vertices) near $x^\star$, providing more stable progress. Frank--Wolfe is
particularly well-suited to boundary optima because the LMO naturally generates
boundary points.

\textbf{Residual gap:} The boundary case converges to $f = 0.364 > f^\star = 0.25$
after 140 iterations because the fixed $\beta = 0.93$ step size does not decay.
Using the standard schedule $\gamma_k = 2/(k+2)$ would guarantee $O(1/k)$
convergence to $f^\star$. This is a fundamental limitation of constant-step
Frank--Wolfe relative to projected gradient descent, which achieves exact convergence
with constant step size on strongly convex functions.

\textbf{Variants and improvements.} The standard Frank--Wolfe suffers from
\emph{zig-zagging} between support vertices, which can slow practical convergence.
The \emph{away-step Frank--Wolfe} \cite{jaggi2013revisiting} adds a step that moves
\emph{away from} a current active vertex:
$x_{k+1} = x_k + \gamma(x_k - v_k)$ where $v_k = \arg\max_{v \in \mathcal{V}}
\nabla f(x_k)^T v$ and $\mathcal{V}$ is the set of active vertices.
This modification achieves linear convergence on strongly convex objectives,
matching projected gradient descent, at the cost of maintaining an active set.

\textbf{Connection to the LP:} The LP subproblem $\min_{s \in \mathcal{X}} \nabla f(x_k)^T s$
solved at each Frank--Wolfe iteration is exactly the same type of problem as the
LP in Section~\ref{sec:q6}.1: minimise a linear function over the feasible set.
For the box $\mathcal{X}$, the solution is the vertex \eqref{eq:lmo_box},
and the LP value $\nabla f(x_k)^T z_k$ provides the lower bound contribution
in the duality gap \eqref{eq:fw_gap}.

The following principal findings emerge. Figure~\ref{fig:summary_bar} provides a
visual comparison of final objective values across methods and benchmarks.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/summary_bar_chart.pdf}
\caption{Summary: Final objective values for all Q1--Q3 methods on Benchmarks~B and~C after
their respective iteration budgets. Left: Benchmark~B (note Polyak capped at $4.0$; actual
final value $= 24.1$, showing divergence). Right: Benchmark~C (Rosenbrock), showing the
dramatic range from Newton ($f = 0.69$, green) and Nesterov ($f = 0.48$) to GD ($f = 3.51$).
The contrast highlights how second-order information (Newton) and momentum acceleration
(Nesterov) are transformative for ill-conditioned problems.}
\label{fig:summary_bar}
\end{figure}

\textbf{Adaptive step-size methods (Q1):} The Polyak step achieves the best convergence
when $f^\star$ is known exactly (Rosenbrock: $f = 0.009$), but \emph{diverges} under
$f^\star$ misspecification. In practice, where $f^\star$ is rarely known, Adagrad and
Heavy Ball provide reliable convergence across all benchmarks without this sensitivity.

\textbf{Momentum and stochastic methods (Q2):} Nesterov acceleration achieves the
theoretically optimal $O(1/k^2)$ convergence rate and outperforms all other first-order
methods on the ill-conditioned Rosenbrock function ($f = 0.479$ vs.\ GD $f = 3.388$).
Adam's per-coordinate scaling is more effective in noisy/stochastic settings; mini-batch
SGD shows that smaller batches converge faster in epoch count but exhibit higher variance
near the minimum, and that increasing observation noise by $6\times$ raises the loss
floor by $36\times$.

\textbf{Newton's method (Q3):} Newton's method solves quadratic problems in a single
step (Benchmark~A: exact convergence at $k=1$) and achieves the fastest convergence
on all benchmarks using only 20 iterations vs.\ GD's 80. Its quadratic convergence
rate makes it the method of choice when Hessian computations are affordable and the
function is smooth. The cost---$O(d^3)$ per iteration---limits applicability to
low-dimensional problems.

\textbf{Derivative-free methods (Q4):} Good finite-difference approximations
($\delta = 0.05$) essentially recover exact-gradient performance, while poor choices
($\delta = 0.8$) substantially degrade convergence. Nesterov random search provides
a dimension-free zeroth-order method but converges slowly. Nelder--Mead adapts its
simplex geometry to navigate the Rosenbrock valley without any gradient information.
Grid search is the only method that guarantees finding the global optimum, but
its $O(N^d)$ cost renders it impractical beyond 2--3 dimensions.

\textbf{Constrained optimisation (Q5):} Projected gradient descent enforces
feasibility as a hard guarantee from iteration 1, at the cost of requiring a
projection oracle. Penalty methods trade exact feasibility for simplicity.
Crucially, when the constraint is \emph{inactive} (unconstrained optimum in the
interior of the feasible set, as in this experiment), all penalty methods
converge to the constrained minimum with zero violation regardless of $\lambda$,
because $\nabla f$ drives the iterate to a feasible point without any penalty
assistance. The penalty magnitude $\lambda$ affects only the transient convergence
speed from an infeasible starting point, not the final solution quality.

\textbf{Frank--Wolfe (Q6):} The conditional gradient algorithm maintains feasibility
without explicit projection by taking convex combinations with LP oracle solutions.
Its $O(1/k)$ convergence rate (slower than projected gradient descent's $O(1/k)$
on strongly convex objectives) is the cost of avoiding projection. For linear-constrained
problems where the LMO is cheap (e.g.\ box constraints, simplex), Frank--Wolfe is
a practical and theoretically elegant alternative to projected methods.

The overarching lesson is that no single method dominates across all problem types.
The key selection criteria are:
\begin{enumerate}[nosep]
\item \textbf{Available information:} Gradient available $\to$ first-order methods;
  Hessian affordable $\to$ Newton/quasi-Newton; only function values $\to$
  Nelder--Mead or random search.
\item \textbf{Problem conditioning:} Well-conditioned ($\kappa \approx 1$) $\to$
  any first-order method suffices; ill-conditioned ($\kappa \gg 1$) $\to$
  Nesterov or Newton dramatically outperform vanilla GD.
\item \textbf{Constraints:} Simple projectable set $\to$ projected GD;
  complex set but cheap LP oracle $\to$ Frank--Wolfe; simple constraint $\to$ penalty.
\item \textbf{Stochastic setting:} Noisy gradients $\to$ Adam or SGD with learning
  rate schedule; deterministic $\to$ Nesterov or Newton.
\end{enumerate}

The experiments demonstrate these trade-offs concretely: Benchmark~A (isotropic,
$\kappa \approx 1.12$) is solved efficiently by all methods; Benchmark~B (moderate
anisotropy, $\kappa \approx 3$--$7$) benefits from adaptive or momentum methods;
Benchmark~C (severely ill-conditioned, $\kappa \approx 2508$) requires either
momentum acceleration or second-order information for efficient convergence.

Understanding these theoretical guarantees and failure modes---as systematically
explored in this report---is essential for principled algorithm selection in
data analysis and machine learning applications.

\begin{lstlisting}[caption={Gradient Descent}]
def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Accelerated Gradient}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)  # Adaptive momentum
        lookahead = x + beta_k * z                   # Extrapolated point
        g = grad_fn(lookahead)                        # Gradient at lookahead
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)   # Bias-corrected first moment
        v_hat = v_vec / (1 - beta2**t)   # Bias-corrected second moment
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Regularised Hessian}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))         # Regularisation
        try:
            p = np.linalg.solve(H_reg, g)             # Solve linear system
        except np.linalg.LinAlgError:
            p = g                                      # Fallback to gradient
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

\begin{lstlisting}[caption={Frank--Wolfe Algorithm}]
def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: minimise g^T s over box
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                      for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z  # Convex combination
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
\end{lstlisting}
