\begin{abstract}
This report presents a systematic comparative study of first-order and second-order optimisation algorithms applied to three benchmark problems of increasing difficulty: a convex quadratic loss (Benchmark A), a mildly nonlinear loss with sinusoidal perturbation (Benchmark B), and the highly ill-conditioned Rosenbrock function (Benchmark C). Six families of methods are investigated: (1)~adaptive step-size rules including Polyak, Adagrad, RMSprop, and Heavy Ball; (2)~accelerated and adaptive methods including Nesterov acceleration and Adam, together with mini-batch SGD; (3)~Newton's method exploiting second-order curvature; (4)~derivative-free approaches including finite-difference gradient descent, Nesterov random search, Nelder--Mead, and grid search; (5)~constrained optimisation via projected gradient descent and penalty methods; and (6)~the Frank--Wolfe conditional gradient algorithm for linearly-constrained problems. Key findings include: the Polyak step size diverges when $f^\star$ is misspecified, achieving best performance only on Rosenbrock where $f^\star = 0$ exactly; Nesterov acceleration achieves the theoretically optimal $O(1/k^2)$ convergence rate on convex problems; Newton's method solves the quadratic benchmark in a single step (due to the exactness of its quadratic model on quadratics) and exhibits quadratic local convergence on smooth problems; and Frank--Wolfe's $O(1/k)$ rate is confirmed with the Frank--Wolfe gap serving as a computable upper bound on the duality gap.
\end{abstract}

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and two parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The loss function is the mean squared error:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\label{eq:loss_A}
\end{equation}
This is a strongly convex quadratic with constant Hessian $H = \frac{1}{m}X^T X \succ 0$. The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The Hessian's eigenvalues determine the Lipschitz constant $L = \lambda_{\max}(H)$ and strong convexity parameter $\mu = \lambda_{\min}(H)$; here $\kappa = L/\mu \approx 1.8$, making Benchmark~A the most well-conditioned problem. Due to observation noise $\varepsilon^{(i)} \sim \mathcal{N}(0,1)$, the irreducible minimum is $J^\star \approx 0.4826 \neq 0$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\label{eq:loss_B}
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H(x) = \operatorname{diag}(2 - \sin(x_1),\ 10)$. The condition number at the minimum is $\kappa \approx 10/(2-\sin(0.5823)) \approx 6.9$. The minimum satisfies $2(x_1^\star - 1) + \cos(x_1^\star) = 0$ (numerically: $x_1^\star \approx 0.5823$) and $x_2^\star = 2$, giving $x^\star \approx (0.582, 2.0)$ and $f^\star = f(x^\star) \approx 0.7232$. In practice, methods run for a finite number of iterations converge to reported values $\approx 0.7244$, reflecting that the iterates approach but do not exactly reach $x^\star$. The Lipschitz constant is $L = \lambda_{\max}(H) = 10$, giving stability requirement $\alpha < 1/L = 0.1$; all applied step sizes satisfy this. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\label{eq:loss_C}
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$. The Hessian at the optimum is:
\begin{equation}
H(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues $\lambda_1 \approx 0.5$ and $\lambda_2 \approx 1001.5$, giving condition number $\kappa \approx 2003$. This extreme ill-conditioning, combined with a narrow curved valley along $x_2 = x_1^2$, makes Rosenbrock the most challenging benchmark. Two separate difficulties arise: (i)~\emph{descent phase} from $x_0 = (-1,1)$ to the valley floor requires navigating steep transverse gradients ($\partial^2 f/\partial x_2^2 = 200$); (ii)~\emph{valley traversal} along $x_2 \approx x_1^2$ requires small careful steps in the nearly-flat longitudinal direction ($\lambda_1 \approx 0.5$). The maximal stable step for gradient descent is $\alpha < 2/(\lambda_1 + \lambda_2) \approx 2 \times 10^{-3}$ at the optimum. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained optimisation (Questions 5--6):
\begin{equation}
\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}.
\end{equation}
This is a compact convex polytope (a box), enabling efficient projections and linear minimisation oracles required by projected gradient descent and Frank--Wolfe respectively.

\subsection{Algorithm Formulations and Theoretical Background}

Four adaptive step-size methods are compared against constant-step gradient descent across all three benchmarks for 120 iterations. The fundamental motivation is that a fixed step size $\alpha < 1/L$ is required for GD convergence ($L$ is the gradient Lipschitz constant), but estimating $L$ is costly and the resulting step may be far too conservative. The GD baseline step sizes are:
\begin{itemize}[nosep]
\item Benchmark A: $\alpha = 0.08$. At the starting point $H = \frac{1}{m}X^TX$ has $\lambda_{\max} \approx 1.2$, giving $1/L \approx 0.83$. The chosen $\alpha = 0.08 \approx 0.1/L$ is $\sim$10$\times$ conservative.
\item Benchmark B: $\alpha = 0.06$. $L = \lambda_{\max}(H(x)) = 10$, so $1/L = 0.1$. The chosen $\alpha = 0.06 = 0.6/L$ is reasonably aggressive.
\item Benchmark C: $\alpha = 0.0012$. At $x_0 = (-1, 1)$, the Hessian has $\lambda_{\max} \approx 1002$, giving $1/L \approx 0.001$. The chosen $\alpha = 0.0012 \approx 1.2/L$ is just barely stable.
\end{itemize}
Adaptive methods adjust $\alpha_k$ automatically to the local geometry, accelerating convergence without requiring knowledge of $L$.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step size is theoretically optimal for convex functions when $f^\star$ is known: it minimises the distance to the optimum along the gradient direction. Formally, for convex $f$ with the Polyak step:
\begin{equation}
\|x_{k+1} - x^\star\|^2 = \|x_k - \alpha_k g_k - x^\star\|^2 = \|x_k - x^\star\|^2 - 2\alpha_k g_k^T(x_k - x^\star) + \alpha_k^2\|g_k\|^2.
\label{eq:polyak_descent}
\end{equation}
By convexity, $g_k^T(x_k - x^\star) \geq f(x_k) - f^\star$. Substituting $\alpha_k = (f(x_k)-f^\star)/\|g_k\|^2$ and simplifying:
$\|x_{k+1}-x^\star\|^2 \leq \|x_k-x^\star\|^2 - (f(x_k)-f^\star)^2/\|g_k\|^2$. This shows the distance is non-increasing, and sums over $k$ give $\sum_k (f(x_k)-f^\star)^2/\|g_k\|^2 \leq \|x_0 - x^\star\|^2 < \infty$, implying $f(x_k) - f^\star \to 0$. The regulariser $\varepsilon$ prevents division by zero when $\|\nabla f\| \approx 0$.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon$, iterations $N$
\State $G_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Per-coordinate squared-gradient accumulation}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad scales the learning rate by the inverse square root of the sum of squared past gradients. Coordinates with large cumulative gradients receive smaller effective rates (stabilising large-gradient directions) while infrequently-updated coordinates maintain larger rates. The effective rate is monotonically decreasing: $\text{eff\_}\alpha_{k,i} = \alpha_0/\sqrt{\sum_{t=1}^k g_{t,i}^2} \sim \alpha_0/\sqrt{k}$ in the worst case, which guarantees convergence but causes premature slowdown on stationary problems.

\textbf{Adagrad convergence rate derivation.} For $L$-smooth convex $f$ with global gradient bound $\|g_k\|_\infty \leq G$, the Adagrad regret bound gives:
\begin{equation}
\frac{1}{K}\sum_{k=0}^{K-1} f(x_k) - f^\star \leq \frac{\|x_0 - x^\star\|_2}{\sqrt{K}} \cdot \frac{G\sqrt{d}}{\alpha_0} + O(1/K),
\label{eq:adagrad_rate}
\end{equation}
which is $O(1/\sqrt{K})$. The key quantity $\frac{G\sqrt{d}}{\alpha_0}$ determines the convergence speed: small $\alpha_0$ (overly conservative) gives slow $O(1/\sqrt{K})$ convergence, while large $\alpha_0$ causes instability. In the diagonal preconditioning interpretation, Adagrad approximates the inverse-Hessian preconditioner $H^{-1}$ by its diagonal $\text{diag}(\alpha_0/\sqrt{G_{k,i}})$, which is exact when the Hessian is diagonal (as for Benchmark~A and B) but fails to capture off-diagonal curvature (as on Rosenbrock).

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop corrects Adagrad's vanishing step-size problem by replacing the full history with an exponentially-weighted moving average (parameter $\beta = 0.9$). Recent gradients receive weight $(1-\beta) = 0.1$ while the effective window spans roughly $1/(1-\beta) = 10$ iterations, allowing the step size to recover when curvature decreases.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, momentum $\beta$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

Heavy Ball accumulates gradient momentum: $z_k$ is a weighted sum of all past gradients with geometric decay $\beta^j$. For a strongly convex quadratic with condition number $\kappa$, the optimal parameters $\alpha^\star = 4/(\sqrt{L} + \sqrt{\mu})^2$ and $\beta^\star = \left((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\right)^2$ give convergence rate $\rho^\star = \left((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)\right)^2$, versus $\rho_{\rm GD} = (\kappa-1)/(\kappa+1)$ for gradient descent --- a significant improvement for large $\kappa$.

\textbf{Derivation sketch.} In the eigenbasis of the Hessian $H$, coordinate $i$ satisfies the linear recurrence $x_{k+1,i} = (1+\beta - \alpha\lambda_i)x_{k,i} - \beta x_{k-1,i}$, with characteristic roots $r_{1,2} = \frac{(1+\beta-\alpha\lambda_i) \pm \sqrt{(1+\beta-\alpha\lambda_i)^2 - 4\beta}}{2}$. The convergence rate is $\max_i |r_1(\lambda_i)|$ (spectral radius). Minimising this over $\lambda_i \in [\mu, L]$ gives the optimal $(\alpha^\star, \beta^\star)$ above (Polyak, 1964). For $\kappa = 2000$: $\rho^\star = ((44.7-1)/(44.7+1))^2 \approx 0.914$, versus $\rho_{\rm GD} = 0.999$. The theoretical Heavy Ball error after 120 steps satisfies $\|e_{120}\| \lesssim 0.914^{120} \approx 2\times10^{-5}$ vs GD's $\|e_{120}\| \lesssim 0.999^{120} \approx 0.887$, a $44000\times$ difference.

\begin{remark}[Theory--practice gap on non-quadratics]
The Heavy Ball analysis assumes a fixed quadratic Hessian. On Rosenbrock, the condition number varies along the path ($\kappa \approx 2500$ at $x_0=(-1,1)$ vs $\kappa \approx 2000$ at $x^\star=(1,1)$), and the method must navigate a curved valley rather than a fixed ellipsoidal contour. The actual result ($f=1.40$ vs theoretical $\to 0$) reflects this gap. Nesterov momentum, by contrast, has convergence guarantees for general smooth convex functions (not just quadratics), explaining its superior performance ($f=0.479$) on Benchmark~C.
\end{remark}

\begin{remark}[Polyak Divergence Mechanism]
When the true minimum satisfies $f_{\rm true}^\star > 0$ but we specify $f^\star = 0$, the Polyak step $\alpha_k = (f(x_k) - 0)/\|\nabla f(x_k)\|^2$ can grow unboundedly. As $x_k \to x_{\rm true}^\star$, $\|\nabla f(x_k)\| \to 0$ while $f(x_k) \to f_{\rm true}^\star > 0$. For Benchmark~A, $\|\nabla J(\theta_k)\| \sim O((\kappa-1)/(\kappa+1))^k \to 0$ while $J(\theta_k) - 0 \to 0.4826$, so $\alpha_k \approx 0.4826/\|\nabla J\|^2 \to \infty$. This large step overshoots the minimum, producing oscillations (final $f = 2.72$, well above $f_{\rm true}^\star$). By contrast, on Benchmark~C where $f^\star = 0$ is correct, both the numerator and denominator shrink together as $x_k \to x^\star$, and $\alpha_k \to$ a finite positive limit, giving convergence.
\end{remark}

Adagrad's monotone decay also yields smooth curves but can slow prematurely. \textbf{Stability}: Across all 15 method-benchmark combinations, GD baseline is most uniformly stable (never diverges, predictable behaviour), at the cost of slowest convergence. Polyak is unstable when $f^\star$ is misspecified (Benchmarks A, B), but optimally stable when $f^\star$ is exact (Benchmark C).

This gives $5.4\times$ more iterations for GD to achieve the same reduction per step. All methods struggle but Heavy Ball's momentum provides the most consistent first-order improvement without requiring Hessian information.

\subsection{Algorithm Formulations and Theoretical Background}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\dfrac{k-1}{k+2},\ \beta_{\max}\right)$
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The critical distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This allows Nesterov's method to ``look ahead'' in the momentum direction and correct before overshooting. The schedule $\beta_k = (k-1)/(k+2)$ grows from $0$ to $\beta_{\max}$, achieving Nesterov's celebrated $O(1/k^2)$ convergence rate on convex functions (versus $O(1/k)$ for gradient descent):

\begin{proposition}[Nesterov convergence rate]
For $L$-smooth convex $f$ and $\alpha = 1/L$, the Nesterov sequence satisfies $f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2}$, achieving the optimal first-order convergence rate (Nesterov 1983).
\end{proposition}

\textbf{Proof sketch (estimate sequences).} Nesterov's proof maintains a sequence of quadratic lower bounds $\phi_k(x) = \phi_0^\star + \frac{\gamma_k}{2}\|x - v_k\|^2$ (the ``estimate sequence'') satisfying two invariants: (i)~$\phi_k^\star \leq f(x_k)$ (the lower bound tracks the iterates); (ii)~$\phi_k(x) \leq (1-\lambda_k)f(x) + \lambda_k f(x^\star)$ with $\lambda_k \leq C/k^2$. Combining: $f(x_k) \geq \phi_k^\star \geq \phi_k(x^\star) \geq f(x^\star) + (1-\lambda_k)(f(x^\star)-f(x)) + 0$ ... actually what is shown is $f(x_k) - f^\star \leq \frac{\gamma_k}{2}\|v_0 - x^\star\|^2$ with $\gamma_k = \frac{4}{\alpha(k+1)^2}$, giving the $1/k^2$ rate. The schedule $\beta_k = (k-1)/(k+2)$ is precisely what maintains these invariants. Heavy Ball does not use estimate sequences and consequently has no $O(1/k^2)$ guarantee on non-quadratic $f$.

The practical consequence in terms of iterations to achieve $f(x_k) - f^\star \leq \varepsilon$:
\begin{itemize}[nosep]
\item \emph{General convex $f$}: GD requires $O(L\|x_0 - x^\star\|^2 / \varepsilon)$ iterations; Nesterov requires $O\!\left(\sqrt{L\|x_0 - x^\star\|^2 / \varepsilon}\right)$ --- a quadratic speedup.
\item \emph{Strongly convex $f$ (condition number $\kappa = L/\mu$)}: GD requires $O(\kappa\log(1/\varepsilon))$ iterations; Nesterov requires $O(\sqrt{\kappa}\log(1/\varepsilon))$ --- a factor-$\sqrt{\kappa}$ speedup.
\end{itemize}
For Benchmark~A with $\kappa \approx 1.8$, the improvement is modest ($\sqrt{1.8} \approx 1.3\times$). For Benchmark~C with $\kappa \approx 2000$, the theoretical speedup is $\sqrt{2000} \approx 45\times$, consistent with the observed $\sim 7\times$ improvement at 150 iterations (the full speedup would be realised asymptotically).

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (uncentred variance)}
    \State $\hat{m}_t \gets m_t / (1 - \beta_1^t)$ \Comment{Bias correction: counteracts zero initialisation}
    \State $\hat{v}_t \gets v_t / (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam combines momentum (via $m_t$, estimating $\mathbb{E}[g_t]$) with per-coordinate adaptive scaling (via $v_t$, estimating $\mathbb{E}[g_t^2]$). The bias corrections ensure $\hat{m}_1 = g_1$ and $\hat{v}_1 = g_1^2$ at $t=1$ regardless of zero initialisation. The effective step size for coordinate $i$ is $\alpha/\sqrt{\hat{v}_{t,i}}$. The choice $\beta_2 = 0.999$ (effective window $\approx 1000$ steps) means $v_t$ accumulates a long-horizon estimate of gradient magnitude; this is appropriate for deterministic settings (as here) where the gradient varies smoothly and long memory provides a stable denominator estimate. In stochastic settings, a smaller $\beta_2$ (shorter window) would better track non-stationary gradient statistics.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD on Benchmark~A uses $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled at every epoch. At each step, the mini-batch gradient estimator is:
\begin{equation}
\tilde{g}(\theta; \mathcal{B}) = \frac{1}{b} X_\mathcal{B}^T(X_\mathcal{B}\theta - y_\mathcal{B}) = \nabla J(\theta) + \underbrace{\xi_k}_{\text{stochastic noise}},
\end{equation}
where $\mathbb{E}[\xi_k] = 0$ and $\mathbb{E}[\|\xi_k\|^2] = \sigma_g^2/b$ with per-sample gradient variance:
\begin{equation}
\sigma_g^2 = \frac{1}{m}\sum_{i=1}^m \left\|\nabla J_i(\theta) - \nabla J(\theta)\right\|^2, \quad \nabla J_i(\theta) = \left(\theta^T x^{(i)} - y^{(i)}\right) x^{(i)}, \quad \nabla J(\theta) = \frac{1}{m}\sum_{i=1}^m \nabla J_i(\theta).
\end{equation}
The mini-batch gradient is the average over the batch: $\tilde{g} = (1/b)\sum_{i\in\mathcal{B}}\nabla J_i(\theta)$, with $\mathbb{E}[\tilde{g}] = \nabla J(\theta)$ (unbiased). When observation noise scales by factor $c$ ($y^{(i)} = \theta^{\star T}x^{(i)} + c\varepsilon^{(i)}$), the residuals $r_i = \theta^T x^{(i)} - y^{(i)}$ at the optimum satisfy $r_i \approx -c\varepsilon^{(i)}$, so $\sigma_g^2 \propto c^2\sigma_\varepsilon^2 \|x\|^2$. The mini-batch variance is $c^2\sigma_\varepsilon^2/b$, scaling quadratically with $c$. This explains the high-noise experiment: with $c=6$, the gradient noise increases by $c^2 = 36\times$, causing proportionally larger oscillations near the minimum.

The two key trade-offs are: (1)~\emph{Updates per epoch}: $b=5$ gives $m/b = 200$ gradient steps per epoch, while $b=40$ gives only 25; (2)~\emph{Gradient noise}: $\text{Var}[\tilde{g}] = \sigma_g^2/b$, so $b=5$ has $40/5 = 8\times$ higher variance than $b=40$. These effects compete: more noisy updates (small $b$) converge faster per epoch but oscillate more near the minimum.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute indices $\{1, \ldots, m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $g \gets \frac{1}{b} X_\mathcal{B}^T(X_\mathcal{B}\theta - y_\mathcal{B})$
        \State $\theta \gets \theta - \alpha\, g$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Comparative Analysis: Nesterov vs Adam vs GD}

\paragraph{Convergence, smoothness, and stability.}

\textbf{Convergence speed} (Table~\ref{tab:q2_final}): On Benchmarks~A and B, all three methods (GD, Nesterov, Adam) reach the same final value; the difference is speed in early iterations. Nesterov reaches the noise floor $\approx 20$\% faster than GD on Benchmark~A and $\approx 30$\% faster on Benchmark~B. On Benchmark~C the gap is dramatic: Nesterov's $f = 0.479$ vs GD's $f = 3.388$ at 150 iterations ($7\times$ better). Adam falls between: $f = 1.579$ on Benchmark~C, benefiting from per-coordinate normalisation of the $6.9:1$ curvature ratio but unable to exploit the off-diagonal valley structure.

\textbf{Nesterov vs Heavy Ball (key distinction):} Both use momentum, but differ critically: Heavy Ball evaluates the gradient at $x_k$ (current point), while Nesterov evaluates at $\tilde{x}_k = x_k + \beta_k z_k$ (lookahead point ahead of momentum). This lookahead allows Nesterov to correct before overshooting: the gradient at $\tilde{x}_k$ provides ``warning'' of impending overshoot that GD and Heavy Ball miss. Theoretically, this is what lifts Nesterov from $O(1/k)$ to $O(1/k^2)$ for general convex $f$ and from $O((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1))^k$ convergence rate for strongly convex $f$. Heavy Ball achieves the same strongly-convex rate with optimal $(\alpha^\star, \beta^\star)$ tuning, but fails on non-quadratic problems (no $O(1/k^2)$ guarantee).

\textbf{Adam's coordinate-wise normalisation}: Adam divides each coordinate's gradient by its RMS, effectively rescaling each direction independently. This handles axis-aligned anisotropy (Benchmarks A, B) well but fails for off-diagonal curvature (Rosenbrock). The bias correction ($\hat{m}_t = m_t/(1-\beta_1^t)$) is crucial in early iterations: without it, the first step would be $\alpha \cdot g_1 \cdot \beta_1$ (underestimating the gradient by $\beta_1$), slowing convergence in the first $\sim 1/(1-\beta_1) = 5$ iterations.

\textbf{Stability}: Nesterov's growing $\beta_k$ schedule (from 0 to $\beta_{\rm max}$) provides automatic warm-up, avoiding early oscillations from large momentum. Adam's bias correction provides the same function in the variance estimator. Neither method requires $f^\star$ knowledge (unlike Polyak), making both suitable for real optimisation without prior knowledge of the optimum value.

\subsection{Local Approximations of $g(x) = x^4$}

At $x_0 = 0.25$: $g(x_0) = 0.25^4 = 3.906 \times 10^{-3}$, $g'(x_0) = 4 \times 0.25^3 = 0.0625$, $g''(x_0) = 12 \times 0.25^2 = 0.75$.

\textbf{First-order (linear) approximation:}
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) = 3.906 \times 10^{-3} + 0.0625\,(x - 0.25).
\end{equation}

\textbf{Second-order (quadratic) approximation:}
\begin{equation}
g(x) \approx g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 3.906 \times 10^{-3} + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

\textbf{Newton update derivation:} Minimising the second-order approximation with respect to $x$:
\begin{equation}
\frac{d}{dx}\left[g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x-x_0)^2\right] = g'(x_0) + g''(x_0)(x - x_0) = 0
\end{equation}
\begin{equation}
\Rightarrow x^+ = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.1667.
\label{eq:newton_1d_update}
\end{equation}
This is the one-dimensional Newton step: instead of stepping along the negative gradient with a fixed size, we step to the minimum of the local quadratic model. The step is automatically scaled by $1/g''(x_0)$: when curvature is high (large $g''$), the step is small to avoid overshooting; when curvature is low, the step is larger.

\textbf{Full Newton iteration on $g(x) = x^4$:} Applying Newton's update formula generally,
\begin{equation}
x_{k+1} = x_k - \frac{g'(x_k)}{g''(x_k)} = x_k - \frac{4x_k^3}{12x_k^2} = x_k - \frac{x_k}{3} = \frac{2}{3}x_k.
\label{eq:newton_x4_recurrence}
\end{equation}
This gives the closed-form sequence $x_k = (2/3)^k x_0$, converging to $x^\star = 0$ geometrically (linearly) at rate $\rho = 2/3$ regardless of starting point. Each iteration reduces the function value by the factor $(x_{k+1}/x_k)^4 = (2/3)^4 = 16/81 \approx 0.20$, so the objective decreases by about $80\%$ per step.

\begin{remark}[Degenerate Hessian and Loss of Quadratic Convergence]
Standard Newton's method converges \emph{quadratically} near $x^\star$ when $g''(x^\star) > 0$. For $g(x) = x^4$, however, $g''(x^\star) = g''(0) = 12 \cdot 0^2 = 0$ --- the Hessian vanishes at the minimum (a degenerate or flat minimiser). The quadratic convergence proof requires dividing by $g''(x^\star)$, which fails when $g''(x^\star) = 0$. The consequence is \emph{linear} convergence at rate $2/3$ (Eq.~\ref{eq:newton_x4_recurrence}), not quadratic. This contrasts with Newton on the 2D benchmarks, where $\nabla^2 f(x^\star) \succ 0$ everywhere, giving genuine quadratic convergence (Section~\ref{sec:q3}).
\end{remark}

\subsection{Newton's Method}

Generalising the one-dimensional derivation above (Eq.~\ref{eq:newton_1d_update} was derived by minimising the second-order model) to $\mathbb{R}^d$: the Newton update minimises the local quadratic model $q_k(x) = f(x_k) + \nabla f(x_k)^T(x-x_k) + \frac{1}{2}(x-x_k)^T H_k (x-x_k)$, giving:
\begin{equation}
x_{k+1} = x_k - \alpha \left[\nabla^2 f(x_k)\right]^{-1} \nabla f(x_k),
\end{equation}
where the damping parameter $\alpha \in (0, 1]$ is required when the Hessian approximation quality degrades far from the minimum (as on Rosenbrock, where $H$ changes rapidly along the valley). The Hessian is regularised as $H_k + \lambda I$ with $\lambda = 10^{-8}$ to ensure positive definiteness and numerical stability of the linear solve $H_k p_k = g_k$.

\begin{algorithm}[H]
\caption{Newton's Method with Hessian Damping}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, damping $\lambda$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping $\lambda = 10^{-8}$.

The starting point $x_0 = (-1, 4)$ has $\|x_0 - x^\star\| = \|(-1-0.582,\; 4-2)\| = \sqrt{1.582^2 + 4} \approx 2.55 < r$, confirming Newton's rapid convergence. For Benchmark~C (Rosenbrock), $\mu \approx 0.5$ and the Rosenbrock Hessian varies rapidly (large $M$), giving a small basin, consistent with the requirement for a damped step $\alpha = 0.22 < 1$.

The cost per step, however, is higher for Newton: $O(d^3)$ for Hessian inversion vs $O(d)$ for a gradient step, making Newton only practical for small $d$.

\subsection{Part A: Finite Difference and Nesterov Random Search on Benchmark B}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference approximation replaces each partial derivative with:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \quad i = 1, \ldots, d.
\end{equation}
By Taylor expansion: $f(x + \delta e_i) = f(x) + \delta \frac{\partial f}{\partial x_i} + \frac{\delta^2}{2}\frac{\partial^2 f}{\partial x_i^2} + O(\delta^3)$, so the error is:
\begin{equation}
\left|\frac{f(x + \delta e_i) - f(x)}{\delta} - \frac{\partial f}{\partial x_i}(x)\right| = \frac{\delta}{2}\left|\frac{\partial^2 f}{\partial x_i^2}(x)\right| + O(\delta^2).
\end{equation}
The truncation error is $O(\delta)$ and grows with $\delta$. In finite precision, there is also a \emph{cancellation error} $O(\varepsilon_{\rm machine}/\delta)$ from computing the difference of nearly-equal floating-point numbers. The optimal $\delta$ balances these: $\delta^\star \sim \sqrt{\varepsilon_{\rm machine}} \approx 10^{-8}$. The assignment tests $\delta = 0.05$ (good: truncation $O(\delta)$ is manageable) and $\delta = 0.8$ (poor: truncation error dominates). Both use $\alpha = 0.08$, 120 iterations.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$; normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

This zeroth-order method estimates a \emph{directional derivative} along a uniformly-random unit vector $u_k$. The estimator satisfies $\mathbb{E}[\hat{g}_k] \approx \frac{1}{d}\nabla f(x_k)$ (up to $O(\delta)$ approximation error): formally, $\mathbb{E}_{u \sim \mathcal{U}(\mathbb{S}^{d-1})}[(\nabla f(x)^T u) u] = \frac{1}{d}\nabla f(x)$. This means on average the method moves in the true gradient direction, but scaled by $1/d$ --- in high dimensions this requires $d$ times more steps to achieve the same progress as a gradient step. The method requires only \emph{two} function evaluations per iteration regardless of dimension $d$: one at $x_k$ and one at $x_k + \delta u_k$.

Settings: $\alpha = 0.025$, $\delta = 0.08$, 220 iterations; exact GD baseline with $\alpha = 0.06$.

\textbf{Convergence rate.} For $L$-smooth convex $f$ with radius $R = \|x_0 - x^\star\|$, Nesterov random search achieves $\mathbb{E}[f(x_K)] - f^\star \leq \varepsilon$ using at most $O(dLR^2/\varepsilon)$ function evaluations (Nesterov \& Spokoiny, 2017). Finite-difference GD requires $O(LR^2/\varepsilon)$ gradient evaluations, each costing $d+1$ function evaluations, giving $O(d\cdot LR^2/\varepsilon)$ total --- the same asymptotic cost. The practical distinction is memory and implementation: Nesterov RS needs only two function evaluations per iteration regardless of $d$, while FD-GD needs $d+1$ evaluations in a synchronised batch (or sequential pass). For $d=2$ the methods are nearly equivalent; the advantage of Nesterov RS grows only for large $d$ where evaluating all coordinates in series becomes expensive.

\subsection{Part B: Derivative-Free Methods on Benchmark C}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$, iteratively transforming it via four operations applied to the \emph{worst} vertex $x_w$ relative to the centroid $\bar{x}$ of the other $n$ vertices:
\begin{align}
\text{Reflection:}& \quad x_r = \bar{x} + \alpha_r(\bar{x} - x_w), \quad \alpha_r = 1 \\
\text{Expansion:}& \quad x_e = \bar{x} + \gamma(\bar{x} - x_w), \quad \gamma = 2 \\
\text{Contraction:}& \quad x_c = \bar{x} + \rho(\cdot - \bar{x}), \quad \rho = 0.5 \\
\text{Shrink:}& \quad x_i \gets x_{\rm best} + \sigma(x_i - x_{\rm best}), \quad \sigma = 0.5
\end{align}
No gradient information is required. The simplex adapts its shape to the local landscape: elongating in productive directions and contracting when progress stalls.

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

\subsection{Problem Setup}

Minimise Benchmark~B subject to $x_1 \geq 0.5$, starting from the \emph{infeasible} initial point $x_0 = (0.2, 4.0)$:
\begin{equation}
\min_{x \in \mathbb{R}^2}\ f(x) \quad \text{subject to} \quad x_1 \geq 0.5.
\end{equation}
The KKT conditions for this inequality-constrained problem are:
\begin{equation}
\nabla f(x^\star) - \mu^\star e_1 = 0, \quad \mu^\star(x_1^\star - 0.5) = 0, \quad \mu^\star \geq 0, \quad x_1^\star \geq 0.5,
\end{equation}
where $e_1 = [1, 0]^T$ and $\mu^\star$ is the Lagrange multiplier. Since the unconstrained minimum $x^\star \approx (0.582, 2.0)$ already satisfies $x_1^\star = 0.582 > 0.5$, the constraint is \emph{inactive} at the optimum, implying $\mu^\star = 0$. Thus the constrained and unconstrained optima coincide, and the challenge is purely about handling the infeasible starting point.

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1}) = \left[\max(0.5,\, z_1^+),\, z_2^+\right]$ \Comment{Project onto $x_1 \geq 0.5$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, penalty $\lambda$, iterations $N$
\State Define $F_\lambda(x) = f(x) + \lambda\max(0,\, 0.5 - x_1)$ \Comment{Penalised objective}
\For{$k = 0, 1, \ldots, N-1$}
    \State $\nabla F_\lambda(x) = \nabla f(x) - \lambda \mathbf{1}[x_1 < 0.5]\, e_1$ \Comment{Gradient of penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_\lambda(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

For the penalty gradient, noting that $\partial_x[\lambda \max(0, 0.5 - x_1)] = -\lambda \mathbf{1}[x_1 < 0.5] e_1$ (subgradient when $x_1 = 0.5$), the penalty gradient is:
\begin{equation}
\nabla F_\lambda(x) = \nabla f(x) - \lambda \mathbf{1}[x_1 < 0.5]\, e_1, \quad e_1 = [1, 0]^T.
\end{equation}

Settings: Projected GD ($\alpha = 0.08$); Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$, $\alpha = 0.03$ for $\lambda = 4.5$); Unconstrained GD ($\alpha = 0.07$). All methods run for 100 iterations.

\textbf{Step-size constraint for penalty methods:} When an iterate lies just below the boundary ($x_1 = 0.5^-$), the penalty gradient has magnitude $\lambda$ (pushing $x_1$ upward); just above the boundary ($x_1 = 0.5^+$), the penalty vanishes. A gradient step of size $\alpha$ from $x_1 = 0.5 - \varepsilon$ lands at approximately $x_1 + \alpha\lambda$ (ignoring the small $\partial f/\partial x_1 \approx -0.12$ contribution). To avoid overshooting past the constrained optimum $x_1^\star \approx 0.582$, we need:
\begin{equation}
0.5 + \alpha\lambda \lesssim x_1^\star \quad\Rightarrow\quad \alpha \lesssim \frac{x_1^\star - 0.5}{\lambda} \approx \frac{0.082}{\lambda}.
\label{eq:penalty_step_bound}
\end{equation}
For $\lambda = 4.5$: $\alpha \lesssim 0.082/4.5 \approx 0.018$. The code uses $\alpha = 0.03$, which is slightly larger but acceptable since the true gradient contribution is not zero and the condition is conservative. For $\lambda = 1.8$: $\alpha \lesssim 0.082/1.8 \approx 0.046$, consistent with $\alpha = 0.05$. This explains the step-size reduction for large $\lambda$: not a stability condition on $\nabla f$ alone, but a constraint on the penalty overshoot magnitude.

\textbf{Projected GD} enforces feasibility \emph{exactly} at every iteration via the projection operator. For this problem, the projection $\Pi_{\mathcal{X}}(x) = \max(0.5, x_1)$ is trivial ($O(1)$ operation). The fundamental advantage is that feasibility is a hard constraint: no iterate ever violates it, which is critical in applications where infeasible points are inadmissible (e.g., physical constraints, probability simplex).

\textbf{Penalty methods} trade exact feasibility for algorithmic simplicity: only a modified gradient is needed, with no projection oracle. The weight $\lambda$ controls the trade-off:
\begin{itemize}[nosep]
\item Small $\lambda$ (0.15): weak penalty; the objective gradient dominates, and feasibility is only weakly enforced.
\item Large $\lambda$ (4.5): strong penalty; effectively enforces feasibility but requires a reduced step size ($\alpha = 0.03$ vs $0.05$) to prevent oscillation caused by the non-smooth penalty term's large effective gradient.
\end{itemize}
The penalty method converges to the true constrained optimum as $\lambda \to \infty$, but large $\lambda$ creates ill-conditioning in the penalised objective: the condition number of $\nabla^2 F_\lambda$ scales as $\kappa(F_\lambda) \approx \kappa(f) + O(\lambda)$ in the infeasible region. The \emph{Augmented Lagrangian} method (not implemented here) addresses this by defining:
\begin{equation}
\mathcal{L}_\lambda(x, \mu) = f(x) - \mu\,(x_1 - 0.5) + \tfrac{\lambda}{2}\max(0, 0.5-x_1)^2,
\end{equation}
and alternating between minimising $\mathcal{L}_\lambda$ over $x$ (with $\mu$ fixed) and updating $\mu^{t+1} = \max(0,\; \mu^t - \lambda\,(x_1^{t+1} - 0.5))$. The multiplier update drives $\mu^t \to \mu^\star$ (the true KKT multiplier, which is $\mu^\star = 0$ here since the constraint is inactive), achieving exact constraint satisfaction at a fixed $\lambda$ and avoiding the ill-conditioning of the pure penalty approach.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$, a compact convex box.

\textbf{Linear Programme:} For $f(x) = a^Tx$ with $a = [1, 2]^T$, the minimum over $\mathcal{X}$ is obtained by minimising each coordinate independently (since the feasible set is a box and the objective is linear):
\begin{equation}
x_i^\star = \begin{cases} \ell_i & \text{if } a_i > 0 \\ u_i & \text{if } a_i < 0 \end{cases} \quad \Rightarrow \quad x^\star = (0.5,\, -5), \quad f^\star = 0.5 + 2(-5) = -9.5.
\end{equation}
This illustrates the \textbf{fundamental theorem of linear programming}: the optimum of a linear objective over a bounded convex polytope is always attained at a vertex (extreme point). By LP strong duality, the dual problem is:
\begin{equation}
\max_{\mu \geq 0}\; \{-\mu^T b : A^T\mu + \nu = a\}, \quad \text{where } Ax \leq b \text{ encodes the box constraints},
\end{equation}
and strong duality gives zero duality gap at optimality. For our box constraints, the dual variables $\mu_1 = 1$ (shadow price of $x_1 \geq 0.5$) and $\mu_4 = 2$ (shadow price of $x_2 \geq -5$) represent the marginal value of relaxing each bound: reducing the lower bound on $x_1$ by $\delta$ decreases $f^\star$ by $\mu_1\delta = \delta$. The LP oracle structure (LMO) in Frank--Wolfe exploits this same coordinate-decomposability: the LMO for a box is equivalent to solving one 1D LP per coordinate, each requiring $O(1)$ operations.

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial feasible $x_0 \in \mathcal{X}$, mixing parameter $\beta$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination: stay in $\mathcal{X}$}
\EndFor
\end{algorithmic}
\end{algorithm}

For the box constraint $\mathcal{X}$, the LMO decomposes per coordinate:
\begin{equation}
(z_k)_i = \begin{cases} \ell_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}, \quad i = 1, 2,
\end{equation}
requiring $O(d)$ operations --- much cheaper than a general-purpose projection. Every iterate $x_k$ is a convex combination of $x_0$ and LP vertices in $\mathcal{X}$, so \emph{feasibility is maintained automatically} without any projection.

With step size $\gamma_k = (1-\beta)$ (constant here), the convergence rate for $L$-smooth convex $f$ satisfies:
\begin{equation}
f(x_k) - f^\star \leq \frac{2LD^2}{k+2},
\label{eq:fw_rate}
\end{equation}
where $D = \operatorname{diam}(\mathcal{X}) = \|(5-0.5, 10-(-5))\|_2 = \sqrt{4.5^2 + 15^2} \approx 15.66$ is the diameter of $\mathcal{X}$. For the interior objective $f(x) = (x_1-1)^2 + (x_2-5)^2$ with $L = 2$ (Hessian eigenvalue), Eq.~(\ref{eq:fw_rate}) gives $f(x_k) - f^\star \leq 2 \cdot 2 \cdot 15.66^2/(k+2) \approx 980/(k+2)$. While this bound is loose (the actual convergence is faster due to the interior optimum), it confirms the $O(1/k)$ rate. This $O(1/k)$ rate is slower than projected gradient descent's $O(e^{-\mu k / L})$ linear rate, representing the price paid for replacing the projection with the cheaper LMO.

\subsection{Interior Optimum: $f(x) = (x_1-1)^2 + (x_2-5)^2$}

\textbf{Interior optimum ($\beta = 0.90$ and $0.985$):} Frank--Wolfe converges but exhibits the characteristic ``zig-zag'' oscillation: near the interior minimum, $z_k$ alternates between opposing vertices of $\mathcal{X}$ (e.g.\ $(0.5, -5)$ and $(5, 10)$) as the gradient direction oscillates. The convex average damps these jumps at rate $O(1/k)$ rather than $O(1/k^2)$.

\textbf{Frank--Wolfe gap computation.} Define the \emph{Frank--Wolfe gap} $g_k = \nabla f(x_k)^T(x_k - z_k)$. For $L$-smooth convex $f$, this satisfies $f(x_k) - f^\star \leq g_k$ (duality gap bound). Example at $x = (1, 3)$: $\nabla f = [2(1-1),\, 2(3-5)] = [0,\, -4]$; since $\partial f/\partial x_2 = -4 < 0$, the LMO selects $z_2 = 10$ (upper bound); since $\partial f/\partial x_1 = 0$, $z_1$ is indeterminate (any value in $\{0.5, 5\}$ achieves the minimum of $0 \cdot z_1$). Taking $z = (5, 10)$: $g = [0,\,-4]^T([1,3] - [5,10]) = [0,\,-4]^T[-4,\,-7] = 28$. The true gap is $f(1,3) - f^\star = 4 - 0 = 4$. The FW gap 28 is a valid but loose upper bound at this point far from the optimum. As $x_k \to x^\star = (1,5)$, $\nabla f(x_k) \to [0,0]$, so $g_k = \nabla f(x_k)^T(x_k - z_k) \to 0$ regardless of $z_k$, confirming convergence.

Comparing $\beta$ values: conservative steps ($\beta = 0.985$) produce less oscillation and a lower final value ($f = 0.0046$) than aggressive steps ($\beta = 0.90$, $f = 0.0089$) after 180 iterations.

\textbf{Boundary optimum ($\beta = 0.93$):} Frank--Wolfe is well-suited to boundary optima. The LMO $z_k$ consistently selects the vertex $(0.5, \cdot)$ nearest the constrained optimum $(0.5, 0)$, pulling $x_k$ towards the boundary without explicit projection. The final value $f = 0.3637$ (after 140 iterations) remains above $f^\star = 0.25$, because the fixed step size $(1-\beta) = 0.07$ does not decay and causes residual oscillation. Using $\gamma_k = 2/(k+2)$ (satisfying $\sum_k \gamma_k = \infty$, $\sum_k \gamma_k^2 < \infty$) would guarantee convergence to $f^\star$; this is a fundamental limitation of the fixed-$\beta$ implementation.

\textbf{Comparison with projected GD (Q5):} Projected GD achieves zero constraint violation at every step and converges linearly. Frank--Wolfe is preferred when: (1)~the projection is expensive to compute (e.g., nuclear norm ball requires singular value decomposition), but (2)~linear minimisation over $\mathcal{X}$ is tractable. For box constraints, projection and LMO have equal cost, but Frank--Wolfe's projection-free nature becomes decisive for complex polytopes arising in machine learning (e.g., flow polytopes in structured prediction).

\section{Summary and Conclusions}
\label{sec:conclusions}
% ============================================================

\subsection{Synthesis}

The six questions in this assignment collectively trace the progression from simple gradient descent to increasingly sophisticated optimisation methods, each addressing a fundamental limitation of the previous:

\begin{enumerate}[nosep]
\item \textbf{Q1 (Adaptive step sizes):} Fixed-step GD requires knowing $L$; adaptive methods (Adagrad, RMSprop, Polyak) eliminate this at the cost of either monotone decay (Adagrad) or $f^\star$ knowledge (Polyak).
\item \textbf{Q2 (Acceleration and stochasticity):} Adaptive steps still suffer $O(1/k)$ rates; Nesterov acceleration achieves the optimal $O(1/k^2)$ without tuning $f^\star$. Mini-batch SGD introduces a noise-iteration count trade-off.
\item \textbf{Q3 (Second-order methods):} Both adaptive and accelerated methods remain first-order; Newton's method uses the Hessian to account for curvature exactly, achieving one-step quadratic convergence (on quadratics) and quadratic rate (locally) for general smooth objectives.
\item \textbf{Q4 (Derivative-free):} Newton's method requires two derivatives; Nelder--Mead and Nesterov RS drop all derivative requirements, at the cost of slower $O(d/\varepsilon)$ rates and increased function evaluations.
\item \textbf{Q5 (Constrained optimisation):} Unconstrained methods ignore feasibility; projected GD and penalty methods handle inequality constraints, with the projection offering exact feasibility and the penalty offering gradient-only simplicity.
\item \textbf{Q6 (Frank--Wolfe):} Projection can be expensive for complex polytopes; Frank--Wolfe replaces it with a linear oracle, enabling projection-free optimisation over flow polytopes and other structured sets at the cost of an $O(1/k)$ convergence rate.
\end{enumerate}

The central lesson across all six questions is that algorithm performance is strongly problem-dependent. No single method dominates: Polyak is optimal on Rosenbrock but catastrophic on benchmarks with $f_{\rm true}^\star > 0$; Newton is fastest per iteration but scales as $O(d^3)$; Frank--Wolfe is projection-free but restricted to $O(1/k)$. Practical algorithm selection requires matching method properties to problem structure.

\subsection{Key Findings}

\begin{enumerate}[nosep]
\item \textbf{Well-conditioned problems (Benchmark A, $\kappa \approx 1.8$):} All gradient-based methods converge efficiently to $J^\star \approx 0.4826$ (the irreducible noise floor). Newton achieves this in exactly one iteration (affine invariance). Mini-batch SGD with $b=5$ reaches $J^\star$ in $\sim$10 epochs vs $\sim$20 for $b=40$, confirming the update-count advantage of smaller batches.

\item \textbf{Moderately ill-conditioned problems (Benchmark B, $\kappa \approx 6.9$):} Per-coordinate methods (Adagrad, Adam) normalise the $6.9:1$ curvature mismatch between $x_1$ and $x_2$. All methods except Polyak (which diverges due to $f^\star$ misspecification) converge to $f^\star \approx 0.7232$ within 150 iterations. Newton converges in $\sim$5 steps.

\item \textbf{Severely ill-conditioned problems (Benchmark C, $\kappa \approx 2000$):} Performance diverges dramatically. After 120 iterations: GD ($f=3.51$), Heavy Ball ($f=1.40$), Adagrad ($f=2.20$), Polyak ($f=0.009$). After 150 iterations: GD ($f=3.39$), Nesterov ($f=0.48$), Adam ($f=1.58$). Newton in just 20 iterations: $f=0.69$. The lesson: at $\kappa=2000$, first-order methods with constant step sizes can barely progress; curvature exploitation (Newton) or momentum-based acceleration (Nesterov) is essential.

\item \textbf{Constraint handling (Q5):} The constraint $x_1 \geq 0.5$ is non-binding at the unconstrained minimum $(x_1^\star \approx 0.582 > 0.5)$, so all methods ultimately converge to the same point. The difference is \emph{how they handle the infeasible starting point}: projected GD is immediately feasible (hard constraint), penalty methods with large $\lambda$ become feasible within 10 iterations, while $\lambda = 0.15$ never enforces strict feasibility.

\item \textbf{Derivative-free methods (Q4):} Good finite-difference ($\delta = 0.05$) achieves near-identical convergence to exact gradient descent. Nelder--Mead navigates Rosenbrock without gradients, achieving steady progress along the valley. Grid search guarantees global coverage but is limited to the grid resolution ($\Delta \approx 0.074$).
\end{enumerate}

\subsection{Limitations and Scope}

The experiments in this report are conducted on 2-dimensional benchmark problems (or on linear regression with 2 parameters), which limits the conclusions in important ways:
\begin{itemize}[nosep]
\item \emph{Dimensionality}: Newton's $O(d^3)$ Hessian inversion cost becomes prohibitive for large $d$ (e.g., neural networks with millions of parameters). Quasi-Newton methods (L-BFGS) address this at $O(md)$ per step.
\item \emph{Stochasticity}: The full-gradient implementations in Q1--Q3 do not reflect real machine learning training where only mini-batch gradients are available. Adam and RMSprop retain their advantage in the stochastic setting.
\item \emph{Hyperparameter sensitivity}: All hyperparameters were tuned for these specific benchmarks. Performance could differ significantly with suboptimal hyperparameters, especially for Polyak (requires exact $f^\star$) and Heavy Ball (requires careful $\alpha$/$\beta$ tuning).
\item \emph{Nonconvexity}: Rosenbrock is the only nonconvex benchmark, and it has a unique global minimum. Deep learning objectives have multiple local minima and saddle points, where the relative performance of methods could differ substantially.
\end{itemize}

\subsection{Practical Recommendations}

For machine learning applications: (1)~Adam or RMSprop are the practical defaults for neural network training due to robustness to hyperparameter choice and adaptivity to gradient scale; (2)~Nesterov momentum is preferred when convergence rate matters and a good learning rate can be identified; (3)~Newton's method and quasi-Newton methods (L-BFGS) are preferred for small-scale problems ($d \lesssim 10^4$) where Hessian computation or approximation is affordable; (4)~For constrained problems with simple constraints (box, probability simplex), projected gradient descent is efficient; for complex polytopes arising in structured prediction, Frank--Wolfe provides a scalable alternative; (5)~Derivative-free methods should be reserved for problems with non-differentiable, discontinuous, or black-box objectives where gradient computation is impossible.

    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

\begin{lstlisting}[caption={Adagrad and RMSprop}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

\begin{lstlisting}[caption={Heavy Ball and Nesterov Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # Linear minimisation oracle for box constraints
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                      for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
