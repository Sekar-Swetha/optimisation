\begin{abstract}
This report presents a comprehensive comparative study of six families of optimisation algorithms applied to three benchmark problems: a linear regression quadratic loss (Benchmark A), a toy neural network loss with sinusoidal perturbation (Benchmark B), and the Rosenbrock function (Benchmark C). The families investigated are: (i)~adaptive step-size methods (Polyak, Adagrad, RMSprop, Heavy Ball); (ii)~momentum and stochastic methods (Nesterov acceleration, Adam, mini-batch SGD); (iii)~Newton's method with second-order local approximations; (iv)~derivative-free approaches (finite differences, Nesterov random search, Nelder--Mead, grid search); (v)~constrained optimisation via projected gradient descent and penalty methods; and (vi)~the Frank--Wolfe algorithm for linearly constrained problems. Each method is evaluated in terms of convergence speed, trajectory behaviour, stability, and computational trade-offs. Theoretical convergence rates are stated where applicable and empirically verified. The experiments reveal that problem structure---convexity, curvature, constraint geometry---critically determines which algorithm class is most suitable.
\end{abstract}

\section{Notation and Preliminaries}
\label{sec:notation}
% ============================================================

We adopt the following notation throughout. Let $f : \mathbb{R}^d \to \mathbb{R}$ be the objective function, $x^{\star}$ the (or a) minimiser, and $f^{\star} = f(x^{\star})$. The gradient is $\nabla f(x) \in \mathbb{R}^d$ and the Hessian $\nabla^2 f(x) \in \mathbb{R}^{d \times d}$. For a sequence $\{x_k\}$, $k$ indexes the iteration. The symbol $\odot$ denotes element-wise (Hadamard) multiplication. $\|{\cdot}\|$ denotes the Euclidean norm unless otherwise stated. The projection onto a convex set $\mathcal{X}$ is $\Pi_{\mathcal{X}}(x) = \arg\min_{z \in \mathcal{X}} \|x - z\|$.

\begin{definition}[Smoothness and Strong Convexity]
A differentiable function $f$ is $L$-\emph{smooth} if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|$ for all $x, y$. It is $\mu$-\emph{strongly convex} if $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$ for all $x, y$. The \emph{condition number} is $\kappa = L/\mu$.
\end{definition}

All experiments use \texttt{np.random.seed(42)} for reproducibility.

\section{Benchmark Problems and Experimental Setup}
\label{sec:benchmarks}

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ parameters is generated:
\begin{equation}
\theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad x^{(i)} \sim \mathcal{N}(0, I_2), \quad y^{(i)} = \theta^{\star T} x^{(i)} + \varepsilon^{(i)}, \quad \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The mean squared error loss is:
\begin{equation}
J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left(\theta^T x^{(i)} - y^{(i)}\right)^2 = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a convex quadratic with constant Hessian $H = \frac{1}{m}X^T X \succ 0$. The gradient is $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The unique minimiser is $\theta^{\star}_{\text{OLS}} = (X^TX)^{-1}X^Ty \approx (3.028, 4.017)$ (perturbed from true $\theta^{\star}$ due to finite noise). Due to irreducible observation noise $\varepsilon$, the minimum loss is $J^{\star} = \frac{1}{2m}\|(\text{I} - X(X^TX)^{-1}X^T)y\|^2 \approx 0.4826$, not zero. Starting point: $\theta_0 = [0, 0]^T$.

\subsection{Benchmark B: Toy Neural Network Quadratic Loss}
\begin{equation}
f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H(x) = \text{diag}(2 - \sin(x_1),\ 10)$. The function is not quadratic due to the $\sin(x_1)$ perturbation, which creates moderate nonlinearity. The Hessian diagonal entry $H_{11} = 2 - \sin(x_1) \in [1, 3]$ (since $\sin(x_1) \in [-1, 1]$), giving a condition number $\kappa \in [10/3, 10]$, representing moderate anisotropy. The minimum satisfies $2(x_1-1) + \cos(x_1) = 0$, i.e., $x_1 \approx 0.582$, and $x_2 = 2.0$, giving $f^{\star} \approx 0.7244$. Starting point: $x_0 = [-1, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^{\star} = 0$. The Hessian is:
\begin{equation}
\nabla^2 f(x) = \begin{bmatrix} 2 + 1200x_1^2 - 400x_2 & -400x_1 \\ -400x_1 & 200 \end{bmatrix}.
\end{equation}
At the optimum, the eigenvalues are approximately $0.5$ and $1000$, giving condition number $\kappa \approx 2000$. This extreme ill-conditioning, combined with the narrow curved valley $\{x : x_2 = x_1^2\}$, makes the Rosenbrock function a canonical challenge for optimisation algorithms: methods must navigate rapid descent to the valley floor before slowly progressing along the highly curved valley. Starting point: $x_0 = [-1, 1]^T$.

\subsection{Benchmark D: Constrained Feasible Set}
For constrained problems (Questions 5 and 6): $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$, an axis-aligned box polytope.

\section{Question 1: Adaptive Step-Size Methods \hfill [30 marks]}
\label{sec:q1}
% ============================================================

\subsection{Theoretical Background}

Standard gradient descent with constant step size $\alpha$ satisfies $x_{k+1} = x_k - \alpha \nabla f(x_k)$ and converges at rate $O(1/k)$ for $L$-smooth convex functions when $\alpha \leq 1/L$, and at linear rate $O(\rho^k)$ with $\rho = 1 - \mu/L$ for $\mu$-strongly convex functions. The fundamental limitation is that a single global step size cannot adapt to varying local curvature. The adaptive methods below address this by computing per-coordinate or per-iteration step sizes automatically.

\subsection{Algorithm Formulations}

Four adaptive methods are compared against a constant step-size gradient descent baseline across all three benchmarks for 120 iterations.

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Adaptive step towards optimum}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The Polyak step size is derived from minimising an upper bound on $\|x_{k+1} - x^{\star}\|^2$. For a convex function with known $f^{\star}$, this yields the \emph{theoretically optimal} single step: $\alpha_k = (f(x_k) - f^{\star})/\|\nabla f(x_k)\|^2$. The regularisation term $\varepsilon$ prevents division by zero. The convergence guarantee is $\min_{j \leq k} f(x_j) - f^{\star} \leq O(1/\sqrt{k})$ for general convex functions.

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0 > 0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative squared gradient per coordinate}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

Adagrad's key insight is that coordinates with historically large gradients receive smaller steps (beneficial for dense features), while infrequently updated coordinates receive larger steps. The per-coordinate effective step is $\alpha_k^{(i)} = \alpha_0/(\sqrt{G_k^{(i)}} + \varepsilon)$, which is a monotonically decreasing function of $k$ --- a potential drawback for non-stationary problems.

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

RMSprop addresses Adagrad's monotone decay issue by replacing the cumulative sum with an \emph{exponential moving average} (EMA) of squared gradients. The decay factor $\beta = 0.9$ means old gradient information is down-weighted exponentially, allowing the effective step size to adapt to recent curvature. This makes RMSprop suitable for non-stationary and stochastic settings.

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Momentum accumulation}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The Heavy Ball method augments gradient descent with a momentum term $z_k$, which accumulates a weighted history of past gradients. The physical analogy is a ball rolling down a surface with friction coefficient $(1-\beta)$. For strongly convex quadratics, the optimal parameters $\alpha^* = 4/(\sqrt{L}+\sqrt{\mu})^2$ and $\beta^* = ((\sqrt{\kappa}-1)/(\sqrt{\kappa}+1))^2$ achieve the optimal convergence rate $O(\rho_{\text{HB}}^k)$ with $\rho_{\text{HB}} = (\sqrt{\kappa}-1)/(\sqrt{\kappa}+1)$, which is substantially better than GD's $\rho_{\text{GD}} = ({\kappa}-1)/({\kappa}+1)$.

\subsection{Comparative Analysis and Theoretical Interpretation}

\begin{itemize}[nosep]
\item \textbf{Polyak step size:} Theoretically optimal when $f^{\star}$ is exactly known, achieving $\min_{j \leq k} f(x_j) - f^{\star} \leq \|x_0 - x^{\star}\|/(2\sqrt{k+1})$ for $L$-smooth convex $f$. However, it is highly sensitive to $f^{\star}$ misspecification: when $f^{\star}_{\text{specified}} < f^{\star}_{\text{true}}$, the step size does not vanish at the true minimum, causing persistent oscillations or divergence. This limits its practical applicability, since $f^{\star}$ is rarely known exactly.

\item \textbf{Adagrad:} Accumulates squared gradients cumulatively ($G_k = \sum_{j=0}^k g_j^2$), which monotonically decreases the effective step. This guarantees convergence but can lead to premature learning rate decay on long-horizon problems. It is most effective in sparse gradient settings (not present here, but the motivation in the ML context).

\item \textbf{RMSprop:} Replaces cumulative accumulation with EMA, preventing step size from decaying to zero. More robust to non-stationarity than Adagrad. However, its convergence guarantees are empirical rather than universal; it can oscillate near optima if $\alpha_0$ is not tuned appropriately.

\item \textbf{Heavy Ball:} Accelerates convergence by adding momentum $z_k$, which builds up in the consistent gradient direction and damps oscillations in noisy directions. For quadratics, achieves $O(\rho_{\text{HB}}^k)$ with $\rho_{\text{HB}} \ll \rho_{\text{GD}}$ when optimally tuned. For non-convex problems (Rosenbrock), momentum helps escape the slow valley traversal but does not guarantee the optimal acceleration.

\item \textbf{GD baseline:} Most stable but slowest. The step size must be $\alpha \leq 1/L$ for convergence, where $L$ is the global Lipschitz constant of $\nabla f$, which for Rosenbrock is $L \approx 1200$ at $x_0 = (-1, 1)$, necessitating the tiny $\alpha = 0.0012$.
\end{itemize}

\textbf{Key finding:} The suitability of adaptive step-size methods depends critically on problem structure. Polyak is uniquely suited to problems where the optimal value is exactly known. Adagrad and RMSprop require tuning of $\alpha_0$, but are robust once set. Heavy Ball provides significant acceleration for ill-conditioned convex problems.

\section{Question 2: Momentum and Stochastic Methods \hfill [30 marks]}
\label{sec:q2}
% ============================================================

\subsection{Theoretical Background}

The classical result that gradient descent achieves only $O(1/k)$ convergence on smooth convex functions is tight in the black-box oracle model. Nesterov's acceleration breaks this lower bound by exploiting the function's gradient \emph{history} through a carefully designed momentum schedule, achieving the optimal $O(1/k^2)$ rate. Adam combines Nesterov-style momentum with RMSprop-style per-coordinate scaling, making it the de facto standard optimiser in deep learning.

\subsection{Algorithm Formulations}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Acceleration}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max}$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Increasing momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead (extrapolation) point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Velocity update at lookahead}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

The critical distinction from Heavy Ball is the \emph{lookahead}: the gradient is evaluated at the extrapolated point $\tilde{x}_k = x_k + \beta_k z_k$ rather than at $x_k$. This correction allows Nesterov to anticipate and partially undo overshoots before they occur. The adaptive schedule $\beta_k = (k-1)/(k+2)$ is derived from Nesterov's estimate sequence analysis and achieves the provably optimal $O(1/k^2)$ convergence rate for $L$-smooth convex functions:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2L \|x_0 - x^{\star}\|^2}{(k+1)^2}.
\end{equation}
This quadratic rate improvement over GD's $O(1/k)$ is \emph{not} merely heuristic but is information-theoretically optimal.

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon$, iterations $N$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment (mean of gradient)}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment (variance of gradient)}
    \State $\hat{m}_t \gets m_t\, /\, (1 - \beta_1^t)$ \Comment{Bias correction for cold-start}
    \State $\hat{v}_t \gets v_t\, /\, (1 - \beta_2^t)$
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t\, /\, (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

Adam maintains EMA estimates of both the first moment (gradient) and second moment (squared gradient). The bias corrections $1/(1-\beta_j^t)$ are essential in early iterations: without them, $m_1 = (1-\beta_1)g_1$ would severely underestimate the true gradient mean. The effective per-coordinate update is $\alpha \hat{m}_t^{(i)} / (\sqrt{\hat{v}_t^{(i)}} + \varepsilon)$, which is approximately $\alpha \cdot \text{sign}(g_t^{(i)})$ when signal-to-noise is high, making Adam's effective step size bounded in $[\alpha/(\sqrt{\hat{v}} + \varepsilon),\ \alpha/\varepsilon]$.

\subsection{Mini-Batch Stochastic Gradient Descent}
\label{subsec:sgd}

Mini-batch SGD on Benchmark A uses learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, with data shuffled at every epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute data indices $\{1, \ldots, m\}$
    \For{each mini-batch $\mathcal{B}$ of size $b$ (disjoint partition)}
        \State $g_{\mathcal{B}} \gets \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}})$ \Comment{Stochastic gradient estimate}
        \State $\theta \gets \theta - \alpha\, g_{\mathcal{B}}$
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

The stochastic gradient $g_{\mathcal{B}}$ is an unbiased estimate of the full gradient: $\mathbb{E}[g_{\mathcal{B}}] = \nabla J(\theta)$. The variance is $\text{Var}(g_{\mathcal{B}}) \propto \sigma^2 / b$, where $\sigma^2$ is the per-sample gradient variance. Thus, smaller batches introduce more noise but more frequent updates per epoch.

\subsection{Discussion: Nesterov vs Adam vs SGD}

\begin{itemize}[nosep]
\item \textbf{Nesterov acceleration} provides provably optimal rates for smooth convex problems and works well in practice when the gradient is inexpensive (deterministic setting). Its advantage over Adam on Rosenbrock arises because the simple momentum-based estimate of the descent direction is more stable than Adam's per-coordinate scaling when the curvature varies rapidly along the trajectory.

\item \textbf{Adam} excels in deep learning settings where (a) gradients are stochastic, (b) different parameters have very different scales, and (c) sparse updates are common. In the deterministic, low-dimensional benchmarks here, its per-coordinate scaling is less necessary, and the additional hyperparameters introduce tuning overhead.

\item \textbf{Mini-batch SGD} introduces a fundamental trade-off: smaller batches provide more updates per epoch but noisier gradients. The optimal batch size depends on the ratio of computation cost to gradient noise, and in practice is determined empirically or via learning rate schedulers.
\end{itemize}

\subsection{Local Taylor Approximations of $g(x) = x^4$}

At $x_0 = 0.25$, the function values are $g(x_0) = 0.25^4 = 0.0039$, $g'(x_0) = 4 \times 0.25^3 = 0.0625$, $g''(x_0) = 12 \times 0.25^2 = 0.75$.

\textbf{First-order (tangent line) approximation:}
\begin{equation}
\hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0) = 0.0039 + 0.0625(x - 0.25).
\end{equation}
This is a linear model that matches $g$ in value and slope at $x_0$ but ignores curvature. The minimiser of $\hat{g}_1$ is undefined (linear functions have no minimum), so gradient descent takes a fixed-size step $x_1 = x_0 - \alpha g'(x_0)$.

\textbf{Second-order (parabolic) approximation:}
\begin{equation}
\hat{g}_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2 = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}
The Newton step minimises $\hat{g}_2$: setting $\hat{g}_2'(x) = 0$ gives $x_1 = x_0 - g'(x_0)/g''(x_0) = 0.25 - 0.0625/0.75 = 0.25 - 0.0833 = 0.1667$. This is a better estimate of the true minimiser (which is at $x^{\star} = 0$) than a fixed-size gradient step would give.

\subsection{Newton's Method: Algorithm and Convergence Theory}

\begin{algorithm}[H]
\caption{Newton's Method with Damping (Hessian Regularisation)}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, damping $\lambda \geq 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Tikhonov-regularised Hessian}
    \State $p_k \gets H_k^{-1}\, g_k$ \Comment{Newton direction (solve linear system)}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Quadratic Convergence of Newton's Method]
Let $f$ be twice continuously differentiable, $\nabla^2 f$ be $M$-Lipschitz continuous (i.e.\ $\|\nabla^2 f(x) - \nabla^2 f(y)\| \leq M\|x - y\|$), and $\nabla^2 f(x^{\star}) \succ 0$ at a local minimiser $x^{\star}$. Then for $\alpha = 1$ (full Newton step) and $x_0$ sufficiently close to $x^{\star}$:
\begin{equation}
\|x_{k+1} - x^{\star}\| \leq \frac{M}{2\mu}\, \|x_k - x^{\star}\|^2,
\end{equation}
where $\mu$ is the smallest eigenvalue of $\nabla^2 f(x^{\star})$. This is \emph{quadratic convergence}: the number of correct digits roughly doubles at each iteration.
\end{theorem}

For Benchmark A (quadratic loss), $\nabla^2 f = H = \text{const}$, so the Newton step with $\alpha = 1$ is \emph{exact} in one step:
\begin{equation}
\theta_{k+1} = \theta_k - H^{-1}\nabla J(\theta_k) = \theta_k - H^{-1} H(\theta_k - \theta_{\text{OLS}}) = \theta_{\text{OLS}}.
\end{equation}
This ``one-step'' property for quadratics is the ideal case for Newton's method. The damping $\lambda = 10^{-8}$ regularises the Hessian without noticeably affecting the solution.

Settings: GD uses 80 iterations; Newton uses 20 iterations with Hessian damping $\lambda = 10^{-8}$.

\subsection{Newton's Method: Limitations and Practical Considerations}

\begin{itemize}[nosep]
\item \textbf{Cost per iteration:} Newton requires computing and inverting $\nabla^2 f(x_k) \in \mathbb{R}^{d \times d}$, costing $O(d^2)$ for the Hessian and $O(d^3)$ for the solve (or $O(d^3)$ total). For large $d$ (e.g., deep neural networks with $d \sim 10^9$), this is prohibitive. Quasi-Newton methods (L-BFGS) approximate the inverse Hessian using gradient differences, costing $O(md)$ per step for $m$ stored vectors.

\item \textbf{Non-convexity:} Near saddle points, $\nabla^2 f$ is indefinite, and the Newton direction may not be a descent direction. The Hessian regularisation ($+\lambda I$) addresses this by shifting eigenvalues to be positive, at the cost of reduced Newton step quality.

\item \textbf{Radius of convergence:} Quadratic convergence is only guaranteed sufficiently close to $x^{\star}$. The damped Newton method (with $\alpha < 1$) extends the basin of attraction at the cost of slower initial convergence.
\end{itemize}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

When the analytical gradient is unavailable, it can be approximated using finite differences. The forward finite-difference approximation of partial derivative $i$ is:
\begin{equation}
\frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta},
\label{eq:fd}
\end{equation}
where $e_i$ is the $i$-th unit vector and $\delta > 0$ is the step size. The approximation error decomposes as:
\begin{equation}
\left|\frac{\partial f}{\partial x_i}(x) - \frac{f(x + \delta e_i) - f(x)}{\delta}\right| \leq \underbrace{\frac{M\delta}{2}}_{\text{truncation}} + \underbrace{\frac{2\varepsilon_{\text{machine}}}{\delta}}_{\text{round-off}},
\end{equation}
where $M = \max |\partial^2 f/\partial x_i^2|$ and $\varepsilon_{\text{machine}} \approx 10^{-16}$. The optimal $\delta$ balances both errors: $\delta^{\star} = 2\sqrt{\varepsilon_{\text{machine}}/M} \approx 10^{-8}$ for $M \sim 1$. The experiments test $\delta = 0.05$ (good approximation, close to optimal for the problem scale) and $\delta = 0.8$ (poor approximation, truncation error dominates). Cost: $d + 1 = 3$ function evaluations per gradient estimate.

\subsubsection{Nesterov Random Search (Zeroth-Order Gradient Estimation)}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I)$, then normalise: $u_k \gets u_k / \|u_k\|$ \Comment{Uniform direction on sphere}
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

The key property is $\mathbb{E}[\hat{g}_k] = \nabla f_\delta(x_k)$, where $f_\delta(x) = \mathbb{E}_{u \sim \mathcal{N}(0,I)}[f(x + \delta u)]$ is the Gaussian-smoothed version of $f$. For small $\delta$, $f_\delta \approx f$. The variance of $\hat{g}_k$ scales as $O(L^2/\delta^2)$ in the worst case, meaning more iterations are required to compensate for the gradient noise. Crucially, the method uses only \textbf{2 function evaluations} per iteration regardless of dimension $d$, making it asymptotically cheaper per iteration than finite differences ($O(d)$ evaluations).

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

The Nelder--Mead algorithm maintains a simplex of $n+1 = 3$ vertices in $\mathbb{R}^2$ and iteratively transforms it through four geometric operations:

\begin{enumerate}[nosep]
\item \textbf{Reflection ($\alpha_r = 1.0$):} Move the worst vertex $x^{(n+1)}$ through the centroid $\bar{x}$ of the remaining vertices: $x_r = \bar{x} + \alpha_r(\bar{x} - x^{(n+1)})$.
\item \textbf{Expansion ($\gamma = 2.0$):} If reflection gives the best point ever, extend further: $x_e = \bar{x} + \gamma(\bar{x} - x^{(n+1)})$.
\item \textbf{Contraction ($\rho = 0.5$):} If reflection worsened, contract towards centroid.
\item \textbf{Shrink ($\sigma = 0.5$):} If contraction fails, contract all vertices towards the best vertex.
\end{enumerate}

Settings: initial simplex step $= 0.35$, 160 iterations. No gradient information is required --- only function evaluations ($\leq 3$ per iteration on average). The simplex geometry adapts to the local loss landscape, eventually contracting around the minimum.

The key insight is the fundamental tension between cost and accuracy in derivative-free optimisation. Nesterov random search is \emph{dimension-independent} in cost per iteration but has high gradient variance, requiring many iterations. Grid search is globally optimal but exponential in cost. Nelder--Mead is practical for small $d$ and is the method of choice in many scientific computing contexts (e.g., \texttt{scipy.optimize.minimize} default).

\section{Question 5: Constrained Optimisation \hfill [30 marks]}
\label{sec:q5}
% ============================================================

\subsection{Problem Setup and Theoretical Background}

Minimise $f(x_1, x_2) = (x_1-1)^2 + 5(x_2-2)^2 + \sin(x_1)$ (Benchmark B) subject to $x_1 \geq 0.5$. The feasible set is the half-space $\mathcal{X} = \{x : x_1 \geq 0.5\}$. The starting point $x_0 = (0.2, 4.0)$ is infeasible.

The optimality condition for constrained problems is given by the KKT conditions. For this problem, the Lagrangian is $\mathcal{L}(x, \lambda) = f(x) - \lambda(x_1 - 0.5)$ with $\lambda \geq 0$. The KKT conditions require:
\begin{equation}
\nabla f(x^{\star}) = \lambda e_1, \quad \lambda(x_1^{\star} - 0.5) = 0, \quad \lambda \geq 0, \quad x_1^{\star} \geq 0.5.
\end{equation}
Since the unconstrained minimiser of $f$ is at $x_1 \approx 0.582 > 0.5$, the constraint is \emph{inactive} at the optimum, $\lambda^{\star} = 0$, and the constrained minimiser coincides with the unconstrained one at $(0.582, 2.0)$.

\subsection{Projected Gradient Descent}

\begin{algorithm}[H]
\caption{Projected Gradient Descent}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1}) = ({\max(0.5, z_{k+1,1})},\; z_{k+1,2})$ \Comment{Project: clip $x_1$}
\EndFor
\end{algorithmic}
\end{algorithm}

The projection onto $\mathcal{X} = \{x : x_1 \geq 0.5\}$ is trivial: $\Pi_{\mathcal{X}}(z) = (\max(0.5, z_1), z_2)$. This is a $O(1)$ operation. For general convex constraint sets, projection may require solving a quadratic programme.

\begin{proposition}[Convergence of Projected GD]
For $L$-smooth, $\mu$-strongly convex $f$ and $\alpha \in (0, 1/L)$, projected GD converges as $\|x_k - x^{\star}\|^2 \leq (1 - \mu\alpha)^k \|x_0 - x^{\star}\|^2$, i.e., at the same linear rate as unconstrained GD.
\end{proposition}

\subsection{Penalty Method}

\begin{algorithm}[H]
\caption{Quadratic Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, penalty weight $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $F_{\lambda}(x) \gets f(x) + \lambda \max(0,\, -x_1 + 0.5)$ \Comment{Penalised objective}
    \State $x_{k+1} \gets x_k - \alpha\, \nabla_x F_{\lambda}(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

The penalty gradient is $\nabla F_\lambda(x) = \nabla f(x) - \lambda \mathbf{1}[x_1 < 0.5] e_1$, where $e_1 = (1,0)^T$. For fixed $\lambda$, the penalty method converges to the minimiser of $F_\lambda(x)$, which is a \emph{biased} approximation of $x^{\star}$. The penalty bias vanishes as $\lambda \to \infty$: the minimiser $x^{\star}(\lambda) \to x^{\star}$ as $\lambda \to \infty$, but larger $\lambda$ requires smaller step sizes to maintain stability (because the penalty term makes $F_\lambda$ less smooth near the constraint boundary).

Settings: Projected GD ($\alpha = 0.08$), Penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\subsection{Projected GD vs Penalty Methods: Key Comparison}

\textbf{Projected Gradient Descent} enforces feasibility as a hard constraint at every iteration via the projection step. This is the fundamental advantage: feasibility is guaranteed regardless of step size or number of iterations. The projection onto simple constraint sets (box, halfspace, simplex) is computationally trivial. For general convex sets, the projection requires solving a QP, which can be expensive.

\textbf{Penalty methods} avoid the projection oracle entirely, requiring only gradient descent on a modified objective. The trade-off is that feasibility is only \emph{approximately} enforced for finite $\lambda$. Increasing $\lambda$ reduces the feasibility error but requires reducing $\alpha$ to control the increasingly large Lipschitz constant of $\nabla F_\lambda$ near the constraint boundary (the penalty creates a sharp kink in $F_\lambda$ at $x_1 = 0.5$).

A practical improvement is the \emph{augmented Lagrangian} (ALM) method, which adds a Lagrange multiplier update $\lambda_{k+1} = \lambda_k + \rho \cdot \text{violation}(x_k)$, gradually increasing $\lambda$ and achieving $\lambda \to \lambda^{\star}$ in the limit, recovering exact feasibility without the conditioning issues of purely increasing $\lambda$.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$ (a box, or bounded polytope).

\textbf{Linear Programme:} For $f(x) = a^T x$ with $a = [1, 2]^T$, the minimum over $\mathcal{X}$ is obtained by independently minimising each coordinate. Since both components of $a$ are positive, the optimum is at the lower bounds:
\begin{equation}
x^{\star} = \arg\min_{x \in \mathcal{X}} (x_1 + 2x_2) = (0.5,\, -5), \qquad f^{\star} = 0.5 + 2(-5) = -9.5.
\end{equation}

\begin{theorem}[Fundamental Theorem of Linear Programming]
The minimum of a linear objective $f(x) = c^Tx$ over a non-empty bounded polytope $\mathcal{X}$ is always attained at a vertex (extreme point) of $\mathcal{X}$.
\end{theorem}

This theorem is illustrated directly: the feasible box has four vertices $\{(0.5, -5), (0.5, 10), (5, -5), (5, 10)\}$, and the LP minimum is at the vertex $(0.5, -5)$ as predicted.

\subsection{Frank--Wolfe Algorithm (Conditional Gradient)}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{x \in \mathcal{X}}\, \nabla f(x_k)^T x$ \Comment{Linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination (fixed mixing)}
\EndFor
\end{algorithmic}
\end{algorithm}

The Frank--Wolfe algorithm replaces the projection step of projected gradient descent with a \emph{linear minimisation oracle} (LMO): minimise a linear surrogate $\nabla f(x_k)^T x$ over $\mathcal{X}$. For box constraints, the LMO decomposes per coordinate in $O(d)$:
\begin{equation}
(z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
Since each iterate $x_{k+1} = \beta x_k + (1-\beta) z_k$ is a convex combination of two feasible points ($x_k, z_k \in \mathcal{X}$), \emph{feasibility is maintained automatically} without any projection. This is the key advantage of Frank--Wolfe for constraint sets where LMO is cheap but projection is expensive (e.g., spectrahedra, nuclear norm balls in matrix problems).

\begin{proposition}[Frank--Wolfe Convergence]
For $L$-smooth convex $f$ and the step size rule $\gamma_k = 2/(k+2)$ (standard FW), the Frank--Wolfe algorithm satisfies:
\begin{equation}
f(x_k) - f^{\star} \leq \frac{2LC^2}{k+2},
\end{equation}
where $C = \max_{x,y \in \mathcal{X}}\|x - y\|$ is the diameter of $\mathcal{X}$. This is an $O(1/k)$ convergence rate, slower than projected gradient descent's $O(\rho^k)$ linear rate for strongly convex problems, but without requiring a projection oracle.
\end{proposition}

The fixed-$\beta$ implementation used here corresponds to a constant step size $\gamma = 1 - \beta$ rather than the decaying $2/(k+2)$ schedule, which explains why the method does not converge to arbitrary precision in the results below.

\subsection{Interior vs Boundary Behaviour and Algorithm Analysis}

\textbf{Interior optimum:} Frank--Wolfe exhibits characteristic zig-zagging because the LP vertex $z_k$ jumps between extreme points of $\mathcal{X}$. The convex combination $x_{k+1} = \beta x_k + (1-\beta) z_k$ gradually averages these jumps. The theoretical $O(1/k)$ rate (with the standard $\gamma_k = 2/(k+2)$ schedule) is slow compared to projected GD's linear rate for strongly convex problems. However, for the interior case where $(1, 5) \in \text{int}(\mathcal{X})$, the gap closes rapidly since $z_k$ frequently selects the vertex closest to the gradient direction.

\textbf{Boundary optimum:} Frank--Wolfe is well-suited to boundary optima because the LMO selects the vertex most aligned with $-\nabla f(x_k)$, which for the boundary case increasingly points towards the constraint boundary. The residual gap ($f = 0.364$ vs $f^{\star} = 0.25$) is due to the fixed-$\beta$ step not decaying: using $\gamma_k = 2/(k+2)$ would close the gap as $k \to \infty$.

\textbf{Comparison with projected GD:}
\begin{itemize}[nosep]
\item Frank--Wolfe requires \emph{no projection oracle}: the only geometric computation is the LMO (linear minimisation), which is trivial for polytopes.
\item Frank--Wolfe produces \emph{sparse iterates}: $x_{k+1}$ is a convex combination of at most $k+1$ vertices, which can be beneficial for nuclear norm and other structured constraint sets.
\item Projected GD converges faster (linear rate for strongly convex $f$) but requires $O(d^2)$ projection for general polytopes vs $O(d)$ for the LMO.
\item The $O(1/k)$ rate of Frank--Wolfe is a fundamental limitation: for strongly convex $f$, it cannot achieve linear convergence with the standard step schedule.
\end{itemize}

\subsection{Key Lessons}

\begin{enumerate}
\item \textbf{Convexity determines the landscape of guarantees.} For strongly convex quadratic problems (Benchmark A), even GD converges linearly and Newton's method terminates in one step. As problems become more nonlinear and ill-conditioned (Rosenbrock), the choice of algorithm becomes increasingly critical.

\item \textbf{Adaptive step sizes improve robustness but require tuning.} Polyak step is theoretically optimal when $f^{\star}$ is known but catastrophically fails otherwise. Adagrad and RMSprop provide practical robustness by adapting to the local gradient scale. Heavy Ball and Nesterov provide acceleration without coordinate-wise adaptation.

\item \textbf{Second-order information is transformative but expensive.} Newton's method reduces the quadratic loss to one step and achieves dramatic acceleration on near-quadratic problems. The $O(d^3)$ cost per iteration limits it to small-dimensional problems; quasi-Newton methods (not investigated here) provide a practical compromise.

\item \textbf{Derivative-free methods enable optimisation without gradient access, at a cost.} Finite differences with small $\delta$ nearly replicate exact gradient descent, but require $d+1$ function evaluations. Zeroth-order methods like Nesterov random search are dimension-independent in cost but have high variance. Nelder--Mead and grid search are practical for small-dimensional problems.

\item \textbf{Constraint handling fundamentally alters algorithm design.} Projected GD enforces feasibility exactly at every step, while penalty methods approximate it. The Frank--Wolfe algorithm handles linear constraints without projection, at the cost of a slower convergence rate.

\item \textbf{Problem structure should guide algorithm choice.} No single method dominates across all settings. Practitioners should consider convexity, dimensionality, gradient access, constraint geometry, and computational budget when selecting an optimisation algorithm.
\end{enumerate}

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad and RMSprop}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2                            # Cumulative squared gradient
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)

def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2    # EMA of squared gradient
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball and Nesterov Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g            # Momentum update
        x = x - z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)   # Increasing schedule
        lookahead = x + beta_k * z          # Extrapolation point
        g = grad_fn(lookahead)              # Gradient at lookahead
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g        # First moment
        v_vec = beta2 * v_vec + (1 - beta2) * g**2     # Second moment
        m_hat = m_vec / (1 - beta1**t)                  # Bias correction
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)

def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))           # Regularisation
        try:
            p = np.linalg.solve(H_reg, g)               # Newton direction
        except np.linalg.LinAlgError:
            p = g                                        # Fall back to GD
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)

def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        # LMO: per-coordinate minimisation over box
        z = np.array([bounds[i][0] if g[i] > 0 else bounds[i][1]
                       for i in range(len(g))])
        z_hist.append(z.copy())
        x = beta * x + (1 - beta) * z                  # Convex combination
        x_hist.append(x.copy()); f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(z_hist)
