\begin{abstract}
This report presents a systematic comparative study of first-order, second-order, and derivative-free optimisation algorithms applied to three canonical benchmark problems: a linear regression quadratic loss (Benchmark A, $\kappa \approx 1.12$), a mildly non-quadratic toy neural-network loss with sinusoidal perturbation (Benchmark B, $\kappa \approx 3.5$--$6.9$), and the ill-conditioned Rosenbrock function (Benchmark C, $\kappa \approx 2508$). Six families of methods are investigated: (1) \emph{adaptive step-size} methods (Polyak, Adagrad, RMSprop, Heavy Ball); (2) \emph{momentum and stochastic} methods (Nesterov acceleration, Adam, mini-batch SGD); (3) \emph{Newton's method} with local second-order approximations; (4) \emph{derivative-free} methods (forward finite differences, Nesterov random search, Nelder--Mead simplex, grid search); (5) \emph{constrained optimisation} via projected gradient descent and penalty methods; and (6) \emph{linear programmes and the Frank--Wolfe conditional-gradient algorithm}. Each family is evaluated in terms of convergence speed, trajectory behaviour, algorithmic stability, and computational complexity. The report includes proof sketches for key convergence theorems (GD linear convergence, Nesterov $O(1/k^2)$ via Lyapunov argument, Newton quadratic convergence, Frank--Wolfe $O(1/k)$ via descent lemma), exact numerical results for all benchmark runs, and 45 figures covering convergence curves, trajectory plots, and theoretical vs empirical rate comparisons. The main finding is that the condition number $\kappa$ is the primary predictor of method performance: GD requires $O(\kappa \log(1/\varepsilon))$ iterations, Nesterov and Heavy Ball $O(\sqrt{\kappa}\log(1/\varepsilon))$, and Newton $O(\log\log(1/\varepsilon))$ independent of $\kappa$. Polyak's step achieves $O(1/k)$ without knowing $L$ or $\mu$ but requires exact $f^\star$, Frank--Wolfe replaces projection with a cheaper linear minimisation oracle at the cost of not improving from $O(1/k)$ for strongly convex objectives, and Nelder--Mead achieves essentially machine-zero on Rosenbrock in 160 iterations with no gradient information.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% ============================================================

Optimisation lies at the heart of machine learning and data analysis: training a neural network, fitting a regression model, or selecting a policy all reduce to minimising an objective function over a parameter space. The choice of optimisation algorithm has profound consequences for both the quality of the solution and the computational cost of obtaining it.

This report investigates six families of optimisation algorithms, systematically applied across three benchmarks that represent increasing levels of difficulty. Benchmark A (linear regression) is a strongly convex quadratic whose condition number depends on the data covariance $H = \frac{1}{m}X^TX$. Benchmark B introduces mild non-quadratic behaviour via a sinusoidal term, creating a landscape that is close to convex but not exactly so. Benchmark C, the Rosenbrock function, is a classic stress test: a non-convex function with a narrow curved valley whose condition number near the minimum is approximately $\kappa \approx 2000$, exposing the limitations of methods that cannot exploit second-order curvature.

The experiments are designed to answer several key questions:
\begin{itemize}[nosep]
  \item How sensitive is the Polyak step size to the accuracy of $f^\star$?
  \item Can momentum methods (Nesterov, Adam) overcome the ill-conditioning of Rosenbrock?
  \item How many Newton steps are needed to match 80 gradient steps, and what does this reveal about per-iteration cost?
  \item What is the accuracy ceiling of derivative-free methods compared to gradient-based methods?
  \item How does the penalty parameter $\lambda$ trade off feasibility and objective quality in penalty methods?
  \item When does Frank--Wolfe converge to the interior optimum vs the boundary optimum, and what is the role of the mixing parameter $\beta$?
\end{itemize}

The three benchmarks span a carefully chosen range of problem properties:
\begin{itemize}[nosep]
  \item \textbf{Benchmark A} ($\kappa \approx 1.12$, strongly convex): a well-conditioned linear regression quadratic where all gradient methods converge quickly and Newton solves the system in one step. This benchmark provides ground-truth validation of convergence theory.
  \item \textbf{Benchmark B} ($\kappa \approx 3.5$--$6.9$, mildly non-quadratic): a near-convex problem with a sinusoidal perturbation creating a varying-curvature landscape. Coordinate-wise adaptation (Adam) provides a clear advantage here.
  \item \textbf{Benchmark C} ($\kappa \approx 2508$, non-convex): the Rosenbrock function, a classic optimisation test case with extreme ill-conditioning that exposes the fundamental limitations of first-order methods without curvature adaptation.
\end{itemize}

The main finding of this report is that \emph{curvature information, whether explicit (Newton), implicit via momentum (Nesterov), or adaptive via coordinate scaling (Adam), is essential for efficiently solving ill-conditioned problems}. Methods that do not account for curvature (GD, Adagrad, RMSprop) converge slowly on Benchmark C, while Nesterov and Polyak (with correct $f^\star$) achieve qualitatively faster convergence. Newton's method, at the cost of $O(d^3)$ per iteration, achieves quadratic convergence that no first-order method can match.

All experiments use a fixed random seed (\texttt{np.random.seed(42)}) for reproducibility.

\section{Notation and Conventions}
\label{sec:notation}
% ============================================================

Throughout this report, the following notation is used consistently:

\begin{itemize}[nosep]
  \item $f: \mathbb{R}^d \to \mathbb{R}$ --- the objective function to be minimised.
  \item $f^\star = \min_{x \in \mathcal{X}} f(x)$ --- the optimal value; $x^\star$ --- an optimal point.
  \item $\nabla f(x) \in \mathbb{R}^d$ --- the gradient of $f$ at $x$; $\nabla^2 f(x) \in \mathbb{R}^{d \times d}$ --- the Hessian.
  \item $\mu$ --- strong convexity constant ($f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$).
  \item $L$ --- gradient Lipschitz constant ($\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$).
  \item $\kappa = L/\mu$ --- condition number ($\kappa = 1$ for isotropic quadratics, $\kappa \gg 1$ for ill-conditioned problems).
  \item $\odot$ --- elementwise (Hadamard) product; $\sqrt{\cdot}$ applied to a vector means elementwise square root.
  \item $\alpha$ or $\alpha_k$ --- step size (learning rate) at iteration $k$; $\beta, \beta_k$ --- momentum parameter.
  \item $\mathcal{X} \subseteq \mathbb{R}^d$ --- feasible set; $\Pi_{\mathcal{X}}$ --- Euclidean projection onto $\mathcal{X}$.
  \item $x_0$ --- initial iterate; $N$ or $n$ --- total number of iterations.
  \item \textbf{Bench.\ A/B/C} refers to the linear regression, toy neural network, and Rosenbrock benchmarks, respectively.
  \item $e_i$ --- $i$-th standard basis vector in $\mathbb{R}^d$.
  \item $I_d$ --- $d \times d$ identity matrix.
\end{itemize}

\subsection{Benchmark A: Linear Regression Quadratic Loss}
A synthetic dataset with $m = 1000$ samples and $d = 2$ features is generated:
\begin{equation}
  \theta^{\star} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}, \quad
  x^{(i)} \sim \mathcal{N}(0, I_2), \quad
  y^{(i)} = (\theta^{\star})^T x^{(i)} + \varepsilon^{(i)}, \quad
  \varepsilon^{(i)} \sim \mathcal{N}(0, 1).
\end{equation}
The mean-squared-error loss is:
\begin{equation}
  J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \bigl(\theta^T x^{(i)} - y^{(i)}\bigr)^2
            = \frac{1}{2m}\|X\theta - y\|^2.
\end{equation}
This is a \emph{strongly convex quadratic} with constant Hessian $H = \frac{1}{m}X^T X \succ 0$ and gradient $\nabla J(\theta) = \frac{1}{m}X^T(X\theta - y)$. The strong convexity constant is $\mu = \lambda_{\min}(H)$ and the gradient Lipschitz constant is $L = \lambda_{\max}(H)$. With the given random seed, numerical computation yields:
\begin{equation}
  \mu \approx 0.9247, \quad L \approx 1.0325, \quad \kappa = L/\mu \approx 1.117.
\end{equation}
This near-unit condition number means Benchmark A is \emph{extremely well-conditioned}: GD with any step $\alpha \in (0, 2/(L+\mu)) = (0, 1.022)$ converges at rate $\rho \leq (\kappa-1)/(\kappa+1) \approx 0.055$ per iteration. Because the labels contain observation noise, the minimum loss is $J^{\star} = \frac{1}{2m}\|y - X\theta_{\mathrm{OLS}}\|^2 \approx 0.4826 > 0$. Starting point: $\theta_0 = [0,\, 0]^T$; initial loss $J(\theta_0) \approx 13.11$.

\subsection{Benchmark B: Toy Neural Network Loss}
\begin{equation}
  f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1).
\end{equation}
The gradient is $\nabla f = [2(x_1 - 1) + \cos(x_1),\ 10(x_2 - 2)]^T$ and the Hessian is $H(x) = \mathrm{diag}(2 - \sin(x_1),\ 10)$. The diagonal Hessian has eigenvalues $\lambda_1(x) = 2 - \sin(x_1) \in [1, 3]$ and $\lambda_2 = 10$ (constant). The condition number therefore varies: $\kappa(x) = 10 / (2-\sin(x_1)) \in [10/3, 10]$. At the starting point $x_0 = [-1, 4]^T$: $\kappa \approx 3.52$ (since $2 - \sin(-1) \approx 2.841$). At the minimiser: $\kappa \approx 6.89$ (since $2 - \sin(0.5815) \approx 1.451$). The unique minimiser satisfies $x_2^\star = 2$ and $2(x_1^\star - 1) + \cos(x_1^\star) = 0$, yielding $x_1^\star \approx 0.5815$ (solved numerically) and $f^\star \approx 0.7244$. Starting point: $x_0 = [-1,\, 4]^T$.

\subsection{Benchmark C: Rosenbrock Function}
\begin{equation}
  f(x_1, x_2) = (1 - x_1)^2 + 100(x_2 - x_1^2)^2.
\end{equation}
The global minimum is at $(1, 1)$ with $f^\star = 0$. The Hessian at the optimum is:
\begin{equation}
  \nabla^2 f(1,1) = \begin{bmatrix} 802 & -400 \\ -400 & 200 \end{bmatrix},
\end{equation}
with eigenvalues $\lambda_1 \approx 0.399$ and $\lambda_2 \approx 1001.6$, giving condition number $\kappa \approx 2508$. Remarkably, the eigenvalues at the starting point $x_0 = (-1, 1)$ are identical (since both $H(1,1)$ and $H(-1,1)$ have the same characteristic polynomial due to the symmetry of the squared off-diagonal term), confirming that this extreme ill-conditioning permeates the entire trajectory. The consequence for GD is stark: Theorem \ref{thm:gd_conv} requires $\alpha \leq 2/(L+\mu) \approx 2/1001.6 \approx 0.002$ for stability, and the resulting convergence rate is $\rho \approx (\kappa-1)/(\kappa+1) \approx 0.9992$ --- barely progressing each step. In contrast, Newton's method reduces the effective condition number to 1 by transforming the step via the Hessian inverse, achieving superlinear convergence. Starting point: $x_0 = [-1,\, 1]^T$; initial loss $f(x_0) = 4.0$.

\subsection{Algorithm Formulations and Theoretical Background}

Four adaptive step-size methods are compared against a constant step-size gradient descent (GD) baseline. The central motivation is that the optimal fixed step size $\alpha^\star = 2/(L + \mu)$ for strongly convex problems requires knowledge of $L$ and $\mu$, which are often unavailable. Adaptive methods remove this requirement at the cost of additional per-iteration computation.

\begin{definition}[Lipschitz Gradient]
A differentiable function $f$ has an $L$-Lipschitz gradient if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|$ for all $x, y$. This is equivalent to $f(y) \leq f(x) + \nabla f(x)^T(y-x) + \frac{L}{2}\|y-x\|^2$.
\end{definition}

\begin{theorem}[GD Convergence for Strongly Convex Functions]
\label{thm:gd_conv}
If $f$ is $\mu$-strongly convex with $L$-Lipschitz gradient, GD with step size $\alpha \in (0, 2/(L+\mu))$ satisfies:
\begin{equation}
  f(x_k) - f^\star \leq \left(1 - \frac{2\alpha \mu L}{\mu + L}\right)^k (f(x_0) - f^\star).
\end{equation}
The optimal contraction factor $\rho^\star = \frac{\kappa - 1}{\kappa + 1}$ (where $\kappa = L/\mu$) is achieved at $\alpha^\star = 2/(L+\mu)$.
\end{theorem}

\begin{algorithm}[H]
\caption{Polyak Step Size}
\label{alg:polyak}
\begin{algorithmic}[1]
\Require Initial point $x_0$, optimal value $f^{\star}$, tolerance $\varepsilon > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $\alpha_k \gets \dfrac{f(x_k) - f^{\star}}{\|g_k\|^2 + \varepsilon}$ \Comment{Step proportional to suboptimality}
    \State $x_{k+1} \gets x_k - \alpha_k\, g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[Polyak Convergence]
When $f^\star$ is exact and $f$ is convex with $L$-Lipschitz gradient, the Polyak step satisfies $f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{k}$ [1], an $O(1/k)$ rate without requiring knowledge of $L$ or $\mu$. When $f^\star$ is underestimated (set too low), $\alpha_k = (f(x_k) - f^\star_{\text{incorrect}})/\|g_k\|^2$ inflates the step size as $f(x_k) \to f^\star_{\text{true}} > f^\star_{\text{incorrect}}$, causing divergence.
\end{remark}

\begin{algorithm}[H]
\caption{Adagrad}
\label{alg:adagrad}
\begin{algorithmic}[1]
\Require Initial point $x_0$, base learning rate $\alpha_0$, tolerance $\varepsilon > 0$, iterations $N$
\State $G_0 \gets \mathbf{0} \in \mathbb{R}^d$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $G_{k+1} \gets G_k + g_k \odot g_k$ \Comment{Cumulative per-coordinate squared gradient}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{G_{k+1}} + \varepsilon} \odot g_k$ \Comment{Coordinate-wise scaling}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[Adagrad Properties]
Adagrad implicitly performs a change of metric: the effective step in direction $i$ is $\alpha_0 / \sqrt{\sum_{j \leq k} g_{j,i}^2}$. Coordinates with consistently large gradients receive smaller steps (automatic regularisation). The monotonically non-increasing step can cause premature stagnation on non-stationary or non-convex problems. For sparse gradients, infrequent large updates in rare coordinates are preserved.
\end{remark}

\begin{algorithm}[H]
\caption{RMSprop}
\label{alg:rmsprop}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha_0$, decay $\beta \in (0,1)$, tolerance $\varepsilon > 0$, iterations $N$
\State $v_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $v_{k+1} \gets \beta\, v_k + (1 - \beta)\, g_k \odot g_k$ \Comment{Exponential moving average of $g^2$}
    \State $x_{k+1} \gets x_k - \dfrac{\alpha_0}{\sqrt{v_{k+1}} + \varepsilon} \odot g_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[RMSprop vs Adagrad]
RMSprop addresses Adagrad's diminishing step-size problem by replacing cumulative squared gradients with an exponential moving average (EMA) with forgetting factor $\beta$. The effective window over which past gradients contribute is approximately $1/(1-\beta)$ steps. With $\beta = 0.9$ (used here), roughly the last 10 gradient observations influence the current step. This allows the step size to recover when gradients decrease.
\end{remark}

\begin{algorithm}[H]
\caption{Polyak Momentum / Heavy Ball}
\label{alg:heavyball}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, momentum $\beta \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets \beta\, z_k + \alpha\, \nabla f(x_k)$ \Comment{Velocity update (exponential averaging)}
    \State $x_{k+1} \gets x_k - z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[Heavy Ball Optimal Convergence]
For $\mu$-strongly convex, $L$-smooth quadratic functions, Heavy Ball with optimal parameters $\alpha^\star = 4/(\sqrt{L}+\sqrt{\mu})^2$ and $\beta^\star = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2$ achieves the optimal linear convergence rate $\rho^\star = \frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}$, compared to GD's $\rho_{\mathrm{GD}} = \frac{\kappa-1}{\kappa+1}$. For large $\kappa$, $\rho^\star \approx 1 - 2/\sqrt{\kappa}$ versus $\rho_{\mathrm{GD}} \approx 1 - 2/\kappa$, a qualitative speedup. However, this optimality holds \emph{only for quadratics}; on non-quadratic functions Heavy Ball can exhibit oscillations or even divergence.
\end{remark}

\begin{remark}[Heavy Ball Parameter Selection]
\label{rem:hb_params}
For Heavy Ball on a $\mu$-strongly convex, $L$-smooth quadratic, the \emph{theoretically optimal} parameters are:
\begin{equation}
  \alpha^\star_\mathrm{HB} = \frac{4}{(\sqrt{L}+\sqrt{\mu})^2}, \qquad \beta^\star_\mathrm{HB} = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2.
\end{equation}
For Benchmark A ($\kappa \approx 1.12$): $\alpha^\star_\mathrm{HB} \approx 0.97$, $\beta^\star_\mathrm{HB} \approx 0.003$ (almost no momentum needed). For Benchmark C ($\kappa \approx 2508$): $\alpha^\star_\mathrm{HB} \approx 0.004$, $\beta^\star_\mathrm{HB} \approx (49/51)^2 \approx 0.923$. The used values $\alpha = 0.0008$, $\beta = 0.86$ are conservative: they ensure stability on the non-quadratic Rosenbrock at the cost of not reaching the theoretical optimum for quadratics. On non-quadratic objectives, the optimal Heavy Ball parameters are unknown (they depend on the unknown local curvature), so the conservative choice is justified. This is a fundamental limitation: Heavy Ball's $O(\sqrt{\kappa})$ speedup is proven \emph{only for quadratics}; on general smooth functions, Heavy Ball can exhibit limit cycles or divergence with the optimal quadratic parameters.

\textbf{Non-quadratic stability region:} For a general smooth function, the Heavy Ball iteration $x_{k+1} = x_k - \alpha \nabla f(x_k) + \beta(x_k - x_{k-1})$ can be analysed locally by linearising around the optimum. The characteristic polynomial of the linearised update is $\lambda^2 - (1+\beta - \alpha L_{\rm local})\lambda + \beta = 0$ (where $L_{\rm local}$ is the local Hessian eigenvalue). Stability requires $|\lambda| < 1$ for all roots, which gives:
\begin{equation}
  \alpha < \frac{2(1+\beta)}{L_{\rm local}}, \qquad \beta < 1.
\end{equation}
For the Rosenbrock function, $L_{\rm local}$ can range from $0.399$ (minimum eigenvalue) to $\approx 1002$ (maximum eigenvalue) along the trajectory. With $\beta = 0.86$: the step constraint becomes $\alpha < 2\times1.86/1002 \approx 0.0037$, which the chosen $\alpha = 0.0008$ satisfies comfortably. If one used the theoretically optimal $\alpha^\star_\mathrm{HB} = 0.004$ for the quadratic approximation, it would lie \emph{outside} the stability region $0.0037$ in the high-curvature transverse direction, causing the oscillations observed when using more aggressive step sizes. The asymmetry between the curvature directions ($L_{\min}/L_{\max} = 1/2508$) means any fixed step size that respects the transverse stability bound $\alpha < 0.0037$ will make very slow progress in the longitudinal direction ($L_{\min} = 0.399$), where the optimal step would be $2\times1.86/0.399 \approx 9.3$ --- three orders of magnitude larger.
\end{remark}

\label{fig:ada_rms_theory}

The formal step-size formulae for the two methods are:
\begin{align}
  \text{Adagrad:} \quad \alpha_k^{(i)} &= \frac{\alpha_0}{\sqrt{G_{k,i} + \varepsilon}}, \qquad G_{k,i} = \sum_{j=1}^k g_{j,i}^2, \\
  \text{RMSprop:} \quad \alpha_k^{(i)} &= \frac{\alpha_0}{\sqrt{v_{k,i} + \varepsilon}}, \qquad v_{k,i} = \beta v_{k-1,i} + (1-\beta) g_{k,i}^2.
\end{align}
For a sequence of constant gradients $|g_i| = c$, Adagrad gives $G_{k,i} = kc^2$ and $\alpha_k^{(i)} = \alpha_0/(c\sqrt{k})$, an $O(1/\sqrt{k})$ decay. RMSprop gives $v_{k,i} \to c^2$ (geometric series: $v_k = (1-\beta^k)c^2$) and $\alpha_k^{(i)} \to \alpha_0/c$, a \emph{constant} effective step. This fundamental difference explains why Adagrad eventually stagnates on long training runs while RMSprop (and Adam, which uses the same second-moment mechanism) remains effective.

The RMSprop EMA has an effective memory window of $\tau = 1/(1-\beta)$ iterations. For $\beta = 0.9$, $\tau = 10$; the weight assigned to a gradient from $m$ steps ago is $(1-\beta)\beta^m$, which decays to half its initial value at $m = \tau\log 2 \approx 6.9$ steps. This ``forgiving'' mechanism allows RMSprop to respond to changes in gradient magnitude, making it more suitable for non-stationary objectives (e.g., deep networks during later stages of training where the effective curvature changes).

\subsection{Comparative Analysis and Discussion}

\begin{itemize}[nosep]
\item \textbf{Convergence speed:} When $f^\star$ is known exactly (Benchmark C), Polyak converges fastest ($f = 0.009$ in 120 iterations). For benchmarks where $f^\star > 0$, Adagrad and Heavy Ball match GD on simple quadratics and significantly outperform GD on the ill-conditioned Rosenbrock. The theoretical Polyak guarantee is $f(x_k) - f^\star \leq 2L\|x_0-x^\star\|^2/k$ for convex objectives --- an $O(1/k)$ rate with the constant $2L\|x_0 - x^\star\|^2$ rather than the $O(\rho^k)$ linear rate of GD, which can be much slower when $\rho \approx 1$.

\item \textbf{Polyak divergence mechanism (detailed):} Let $f^\star_{\mathrm{true}} = 0.4826$ for Benchmark A. With the misspecified $f^\star_{\mathrm{incorrect}} = 0$, the Polyak step becomes:
\begin{equation}
  \alpha_k = \frac{f(x_k)}{\|g_k\|^2 + \varepsilon}.
\end{equation}
As $x_k \to x^\star_{\mathrm{OLS}}$: $f(x_k) \to 0.4826 > 0$ while $\|g_k\| \to 0$ (the gradient vanishes at the minimum). Therefore $\alpha_k \to 0.4826 / \varepsilon = 0.4826/10^{-4} = 4826$. A step size of 4826 in a problem where the stability bound is $\alpha < 2/L \approx 1.93$ causes massive overshoot and divergence. The regularisation $\varepsilon = 10^{-4}$ prevents literal division-by-zero but does not prevent the instability.

\item \textbf{Stability vs adaptation:} GD baseline is most stable but relies on manual step-size tuning. Adagrad is uniformly stable (monotonically decreasing step guarantees convergence for convex problems via the $O(1/k)$ step-size schedule) but may stagnate on non-stationary objectives as steps shrink to near-zero. Heavy Ball can oscillate near the minimum but generally converges within the stability region $\alpha < (1-\beta)^2/L$.

\item \textbf{Adagrad vs RMSprop trade-off:} Adagrad accumulates all past squared gradients ($G_k = \sum_{j=0}^{k} g_j^2$), so the effective step decays as $O(1/\sqrt{k})$ for constant gradients. RMSprop's EMA ($v_k = \beta v_{k-1} + (1-\beta)g_k^2$) ``forgets'' old gradients with time constant $1/(1-\beta) = 10$ steps (for $\beta=0.9$), stabilising the effective step size in stationary regions. This makes RMSprop better suited to non-stationary objectives but gives it a potential advantage in steady-state convergence near a minimum, as seen in Benchmark A where RMSprop achieves $f = 0.5027$ (slightly above $f^\star = 0.4826$) due to non-zero oscillation rather than stagnation.

\item \textbf{Computational cost:} All adaptive methods require $O(d)$ extra storage (for $G$ or $v$) and $O(d)$ extra arithmetic per iteration. For the 2D problems here this is negligible. In large-scale deep learning with $d = 10^8$ parameters, this doubles the memory requirement, but this overhead is universally accepted given the convergence benefits.
\end{itemize}

\subsection{Algorithm Formulations and Theoretical Background}

\begin{algorithm}[H]
\caption{Nesterov Momentum / Accelerated Gradient Descent}
\label{alg:nesterov}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, max momentum $\beta_{\max} \in [0,1)$, iterations $N$
\State $z_0 \gets \mathbf{0}$
\For{$k = 1, 2, \ldots, N$}
    \State $\beta_k \gets \min\!\left(\frac{k-1}{k+2},\ \beta_{\max}\right)$ \Comment{Adaptive momentum schedule}
    \State $\tilde{x}_k \gets x_k + \beta_k\, z_k$ \Comment{Lookahead (extrapolation) point}
    \State $z_{k+1} \gets \beta_k\, z_k - \alpha\, \nabla f(\tilde{x}_k)$ \Comment{Velocity update using lookahead gradient}
    \State $x_{k+1} \gets x_k + z_{k+1}$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Nesterov Acceleration]
\label{thm:nesterov}
For a convex function $f$ with $L$-Lipschitz gradient, Nesterov's accelerated gradient descent with $\alpha = 1/L$ and $\beta_k = (k-1)/(k+2)$ satisfies:
\begin{equation}
  f(x_k) - f^\star \leq \frac{2L\|x_0 - x^\star\|^2}{(k+1)^2},
\end{equation}
i.e., an $O(1/k^2)$ rate versus GD's $O(1/k)$ rate. This is \emph{optimal} for first-order methods in the worst case over smooth convex functions.
\end{theorem}

\begin{remark}[Nesterov Lookahead vs Heavy Ball]
The key innovation of Nesterov momentum over Heavy Ball is the \emph{lookahead}: the gradient is evaluated at $\tilde{x}_k = x_k + \beta_k z_k$ rather than $x_k$. This ``corrected'' gradient is more informative about the direction of the minimum, enabling the algorithm to correct its trajectory before overshooting. Specifically, the lookahead point is ahead of the current iterate in the direction of accumulated momentum, so the gradient computed there reveals whether the momentum direction is still productive or about to overshoot.

The momentum schedule $\beta_k = \min((k-1)/(k+2), \beta_{\max})$ is adaptive: $\beta_1 = 0$, $\beta_2 = 1/4$, $\beta_3 = 2/5$, \ldots, $\beta_k \to 1$ as $k \to \infty$. This gradual warm-up prevents the instability that Heavy Ball exhibits when starting with large momentum. The capping at $\beta_{\max}$ (values 0.90--0.92 in the experiments) prevents excessive momentum in the nonlinear setting where the full schedule might cause oscillations.

The relationship between the two algorithms can be made explicit: in Heavy Ball, $z_{k+1} = \beta z_k + \alpha \nabla f(x_k)$ and $x_{k+1} = x_k - z_{k+1}$, while in Nesterov, the gradient is evaluated one lookahead step ahead. Both are instances of the general \emph{inertial gradient flow} framework, but Nesterov's correction term is what enables the $O(1/k^2)$ rate.
\end{remark}

\begin{algorithm}[H]
\caption{Adam Optimiser}
\label{alg:adam}
\begin{algorithmic}[1]
\Require Initial point $x_0$, learning rate $\alpha > 0$, moments $\beta_1, \beta_2 \in (0,1)$, tolerance $\varepsilon > 0$
\State $m_0 \gets \mathbf{0},\ v_0 \gets \mathbf{0}$
\For{$t = 1, 2, \ldots, N$}
    \State $g_t \gets \nabla f(x_t)$
    \State $m_t \gets \beta_1\, m_{t-1} + (1 - \beta_1)\, g_t$ \Comment{First moment: exponential gradient average}
    \State $v_t \gets \beta_2\, v_{t-1} + (1 - \beta_2)\, g_t \odot g_t$ \Comment{Second moment: exponential squared-gradient average}
    \State $\hat{m}_t \gets m_t / (1 - \beta_1^t)$, \quad $\hat{v}_t \gets v_t / (1 - \beta_2^t)$ \Comment{Bias correction}
    \State $x_{t+1} \gets x_t - \alpha\, \hat{m}_t / (\sqrt{\hat{v}_t} + \varepsilon)$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[Adam: Motivation and Properties]
Adam combines first-moment momentum (as in Heavy Ball) with per-coordinate adaptive scaling (as in RMSprop). Three key design choices distinguish Adam:

\textbf{(1) Bias correction:} At $t=1$, $m_1 = (1-\beta_1)g_1$ is $(1-\beta_1)$-scaled; the correction $\hat{m}_1 = m_1/(1-\beta_1) = g_1$ recovers the true gradient. Without correction, Adam would take very small steps early in training. The correction is critical primarily in early iterations; for large $t$, $1-\beta_1^t \approx 1$ and the correction becomes negligible.

\textbf{(2) $\beta_2 = 0.999$ (slow second-moment decay):} This gives a ``memory'' of $1/(1-0.999) = 1000$ past squared gradients for the second moment, providing a very stable estimate of the gradient's second moment even for noisy gradients. This makes Adam robust to noisy mini-batch estimates.

\textbf{(3) Approximate invariance to gradient scaling:} When gradients have consistent sign and magnitude in coordinate $i$, $\hat{m}_{t,i} \approx \text{sign}(g_i) \times \sqrt{\hat{v}_{t,i}}$, so the update $\alpha \hat{m}_{t,i}/(\sqrt{\hat{v}_{t,i}}+\varepsilon) \approx \pm\alpha$. This makes Adam's effective step size approximately $\pm\alpha$ per coordinate, independent of the gradient magnitude, conferring robustness across coordinates with very different gradient scales.

The limitation revealed by Benchmark C is that Adam's per-coordinate normalisation, while powerful for decoupled curvature, cannot account for \emph{cross-coordinate curvature}. The Rosenbrock Hessian $[[802, -400], [-400, 200]]$ has large off-diagonal terms; coordinate-wise scaling cannot exploit this structure, whereas Newton's inverse-Hessian step can.

\textbf{Preconditioner interpretation:} Adam's update $x_{t+1} = x_t - \alpha \hat{m}_t/\sqrt{\hat{v}_t}$ is equivalent to a gradient step with the diagonal preconditioner $D_t = \mathrm{diag}(1/\sqrt{\hat{v}_t})$: $x_{t+1} \approx x_t - \alpha D_t \hat{m}_t$. In the limit $\hat{v}_t \to \mathbb{E}[g_t^2] = [H_{11}^2, H_{22}^2]^T$ (for a quadratic with diagonal $H$), the preconditioner $D_t \to \mathrm{diag}(1/H_{11}, 1/H_{22}) = H^{-1}$ exactly --- recovering Newton's step! This is why Adam is so effective on Benchmark B (where $H$ is diagonal): it recovers the Newton step asymptotically. On Benchmark C, the diagonal approximation to $H^{-1}$ misses the off-diagonal coupling ($H^{-1}_{12} \neq 0$), leaving residual ill-conditioning that momentum alone cannot overcome.
\end{remark}

\subsection{Why the $\beta_k = (k-1)/(k+2)$ Schedule Achieves $O(1/k^2)$}

The momentum schedule $\beta_k = (k-1)/(k+2)$ is not arbitrary. We sketch Nesterov's Lyapunov argument. Define the \emph{energy} functional:
\begin{equation}
  E_k = \frac{k(k+1)}{2}\bigl(f(x_k) - f^\star\bigr) + \frac{k^2}{2}\|v_k - x^\star\|^2,
\end{equation}
where $v_k$ is the auxiliary sequence (the ``speed'' iterate) satisfying $v_{k+1} = v_k - \frac{1}{\mu_k}\nabla f(x_k)$ for a suitable coefficient $\mu_k$. The $O(1/k^2)$ rate follows from showing $E_{k+1} \leq E_k$ for all $k$:

\begin{proposition}[Lyapunov Decrease]
\label{prop:lyapunov}
If $f$ is convex with $L$-Lipschitz gradient and the step size $\alpha = 1/L$, then with $\beta_k = (k-1)/(k+2)$ the Lyapunov functional satisfies $E_{k+1} \leq E_k$. Dividing by $k(k+1)/2$ and rearranging:
\begin{equation}
  f(x_k) - f^\star \leq \frac{2E_0}{k(k+1)} = \frac{2[L\|x_0 - x^\star\|^2]}{k(k+1)} = O(1/k^2).
\end{equation}
\end{proposition}

The key step in the proof is the identity $(k+1)^2\langle \nabla f(x_k), x^\star - v_{k+1}\rangle + k^2\langle \nabla f(x_k), x^\star - v_k \rangle = -k(k+1)(f(x_{k+1})-f^\star) + \ldots$, which cancels when using the specific momentum ratio $(k-1)/(k+2)$ and the quadratic upper bound from $L$-smoothness. The specific ratio $(k-1)/(k+2)$ ensures that the coefficient of $E_k$ in $E_{k+1} - E_k$ is non-positive.

The capping at $\beta_{\max}$ (e.g., $0.90$ for Benchmarks A and C, $0.92$ for B) prevents the schedule from approaching 1 too quickly in the nonlinear setting. Without the cap, $\beta_k \to 1$ would produce excessive momentum that destabilises the algorithm on non-convex or strongly nonlinear objectives. The cap trades some of the theoretical $O(1/k^2)$ rate for improved numerical stability.

\label{fig:momentum_comparison}
\end{figure}

The lookahead mechanism can be understood as an \emph{implicit prediction-correction} step. Heavy Ball's velocity at iteration $k$ is $z_{k+1} = \beta z_k - \alpha\nabla f(x_k)$, which corrects the current position using the current gradient. Nesterov first predicts where the iterate will be after applying the current momentum ($\tilde{x}_k = x_k + \beta_k z_k$), then evaluates the gradient \emph{there} before deciding on the full update. The lookahead gradient $\nabla f(\tilde{x}_k)$ is a better approximation to the ``committed'' gradient direction, allowing the algorithm to apply brakes when the momentum overshoots. This one-step lookahead --- mathematically $\nabla f(x_k + \beta_k z_k)$ vs $\nabla f(x_k)$ --- is the sole algorithmic difference between Heavy Ball and Nesterov, yet it produces a qualitatively different convergence theory: $O(\rho^{k/2})$ vs $O(1/k^2)$ for smooth convex objectives.

\subsection{Mini-Batch Stochastic Gradient Descent}

Mini-batch SGD is evaluated on Benchmark A with learning rate $\alpha = 0.06$, batch sizes $b \in \{5, 40\}$, 50 epochs, and data shuffled at each epoch. The gradient estimator for batch $\mathcal{B}$ of size $b$ is:
\begin{equation}
  g_{\mathcal{B}}(\theta) = \frac{1}{b} \sum_{i \in \mathcal{B}} x^{(i)}\bigl(\theta^T x^{(i)} - y^{(i)}\bigr) = \frac{1}{b} X_{\mathcal{B}}^T(X_{\mathcal{B}}\theta - y_{\mathcal{B}}).
\end{equation}
This is an \emph{unbiased} estimate of the full gradient: $\mathbb{E}_{\mathcal{B}}[g_{\mathcal{B}}(\theta)] = \nabla J(\theta)$. The variance of the mini-batch gradient estimator scales as:
\begin{equation}
  \mathrm{Var}[g_{\mathcal{B},i}(\theta)] = \frac{\sigma_i^2}{b}, \qquad \text{where } \sigma_i^2 = \mathrm{Var}\bigl[(X^T(X\theta - y))_i\bigr] / m^2
\end{equation}
is the per-sample variance. Larger batches reduce gradient noise by factor $1/b$, giving more accurate update directions at the cost of more computation per epoch.

\begin{algorithm}[H]
\caption{Mini-Batch SGD}
\label{alg:sgd}
\begin{algorithmic}[1]
\Require Data $(X, y)$, initial $\theta_0$, learning rate $\alpha$, batch size $b$, epochs $E$
\For{$e = 1, 2, \ldots, E$}
    \State Randomly permute the $m$ sample indices into $\lfloor m/b \rfloor$ mini-batches
    \For{each mini-batch $\mathcal{B}$ of size $b$}
        \State $\theta \gets \theta - \alpha\, g_{\mathcal{B}}(\theta)$ \Comment{Stochastic gradient step}
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{SGD Convergence Theory: Batch Size vs Learning Rate Trade-off}

\begin{theorem}[SGD Convergence on Strongly Convex Functions]
\label{thm:sgd_conv}
For $\mu$-strongly convex, $L$-smooth $f$ with mini-batch gradient variance $\sigma_b^2 = \sigma^2/b$, SGD with decaying step sizes $\alpha_k = \alpha_0/(k+1)$ satisfies:
\begin{equation}
  \mathbb{E}[f(\bar{\theta}_T) - f^\star] \leq \frac{\max(2\alpha_0 L \sigma_b^2, \alpha_0^2 \sigma_b^2)}{\mu \alpha_0 T} + O(1/T^2),
\end{equation}
where $\bar{\theta}_T = \frac{1}{T}\sum_{k=0}^{T-1}\theta_k$ is the Cesàro average. With \emph{constant} step size $\alpha$, SGD converges to a \emph{noise floor} $\mathbb{E}[J(\theta_\infty)] - J^\star \approx \frac{L \alpha \sigma_b^2}{2\mu} = \frac{L \alpha \sigma^2}{2\mu b}$.
\end{theorem}

This theorem has two important implications for the experiments. First, the noise floor \emph{decreases linearly with batch size} $b$: doubling $b$ halves the noise floor at the same step size $\alpha$, consistent with Figure \ref{fig:q2_sgd_batch}. Second, the noise floor is proportional to $\alpha$: reducing the step size reduces oscillation near the minimum. The optimal batch size balances gradient computation cost vs noise: for $b = 5$, 200 gradient steps per epoch but high noise; for $b = 40$, 25 steps per epoch but lower noise. The total gradient computation per epoch is the same ($m = 1000$ samples), but the mini-batch accumulation creates a variance-vs-frequency trade-off.

The \emph{linear scaling rule} (Goyal et al., 2017) follows directly: the noise floor $L\alpha\sigma^2/(2\mu b)$ is constant when $\alpha/b$ is constant. Thus increasing $b$ by factor $\rho$ allows increasing $\alpha$ by $\rho$ while maintaining the same noise floor. This explains why large-batch training (modern deep learning often uses $b = 256$--$8192$) requires proportionally larger learning rates.

\textbf{Variance decomposition:} The total estimation error of the mini-batch gradient can be decomposed as:
\begin{equation}
  \mathbb{E}\|\hat{g}_\mathcal{B} - \nabla J(\theta)\|^2 = \underbrace{\frac{\sigma_g^2}{b}}_{\text{mini-batch sampling variance}} + \underbrace{0}_{\text{bias (unbiased estimator)}},
\end{equation}
where $\sigma_g^2 = \frac{1}{m}\sum_{i=1}^m\|\nabla J_i(\theta) - \nabla J(\theta)\|^2$ is the \emph{per-sample gradient variance}. For the linear regression objective, $\nabla J_i(\theta) = x^{(i)}({\theta^T x^{(i)} - y^{(i)}})$ and $\sigma_g^2$ depends on the data distribution. The noise floor $L\alpha\sigma_g^2/(2\mu b)$ can be viewed as the gradient variance $\sigma_g^2/b$ times the GD step size sensitivity $L\alpha/(2\mu) = \alpha/(2\mu/L) = \alpha/(2/\kappa)$: ill-conditioned problems ($\kappa \gg 1$) amplify gradient noise, requiring even smaller learning rates or larger batches to control oscillations.

For Benchmark A with $m = 1000$, $b = 5$: the effective noise amplification is $\kappa/(2b) = 1.12/10 \approx 0.11$ --- modest because $\kappa$ is small. For a hypothetical Rosenbrock SGD ($\kappa \approx 2508$, $b=5$): amplification $\approx 250.8$, meaning gradient noise is amplified by $\sim 250\times$ per step, making mini-batch SGD completely ineffective without aggressive step-size reduction. This explains why SGD is not applied to Benchmark C: the high condition number makes the noise floor unacceptably large at any reasonable batch size and learning rate.

Nesterov acceleration provides the most significant improvement over GD on ill-conditioned problems, consistent with its theoretical $O(1/k^2)$ rate (Theorem \ref{thm:nesterov}). The observed improvement (Nesterov at $f=0.48$ vs GD at $f=3.39$ after 150 iterations) is consistent with this theoretical speedup, though Rosenbrock's non-quadratic structure prevents the full $\sqrt{\kappa}$ improvement from being realised.

Adam's coordinate-wise adaptation is beneficial for problems with \emph{decoupled} heterogeneous curvature across coordinates (Benchmark B) but does not help on Rosenbrock, where the challenge is \emph{coupled} cross-coordinate curvature (the off-diagonal Hessian term $-400x_1$ couples the two coordinates). Mini-batch SGD is the only method in this question that trades gradient accuracy for computational efficiency, a trade-off especially relevant in large-scale machine learning where the full gradient is expensive to compute.

\textbf{Nesterov vs Adam: regime analysis.} The two methods occupy distinct regimes of the exploration-exploitation trade-off in optimisation:

\begin{enumerate}[nosep]
\item \textbf{Strongly convex, well-conditioned} (Benchmark A, $\kappa=1.12$): Both Nesterov and Adam converge to $f^\star$ in $\sim 30$ iterations. The low condition number means momentum helps only marginally; the main advantage of both methods over GD is the ability to use somewhat larger effective step sizes without instability. No meaningful separation.

\item \textbf{Non-quadratic, moderate curvature anisotropy} (Benchmark B, $\kappa \in [3.5, 6.9]$): Adam holds a slight advantage from its coordinate-wise scaling ($H$ is diagonal for Benchmark B). The per-coordinate step effectively precomputes the direction-dependent learning rate, matching the curvature in each direction. Nesterov's global momentum is direction-agnostic and converges more slowly in the $x_1$ direction (lower curvature) relative to Adam's explicit $x_1$-scaling.

\item \textbf{Highly non-convex, extreme coupled curvature} (Benchmark C, $\kappa=2508$): Nesterov decisively outperforms Adam. The Rosenbrock Hessian $H = [[802, -400], [-400, 200]]$ has off-diagonal coupling: the $(1,2)$ entry $-400x_1$ links the two coordinates. Adam's diagonal preconditioner $D_t = \mathrm{diag}(1/\sqrt{\hat{v}_t})$ sets step sizes based on per-coordinate gradient magnitudes but cannot capture the $x_1$-$x_2$ interaction. Nesterov's momentum vector $z_k$ is a $d$-dimensional quantity that \emph{can} accumulate displacement in a non-axis-aligned direction (the valley floor direction of Rosenbrock), partially compensating for the cross-coordinate coupling. The final values after 150 iterations ($f_\mathrm{Nesterov} = 0.479$ vs $f_\mathrm{Adam} = 1.578$) confirm a $3.3\times$ Nesterov advantage in objective value.
\end{enumerate}

This regime analysis suggests a practical rule: use Adam for problems with heterogeneous but decoupled coordinate scales (common in deep learning with diverse parameter groups); use Nesterov (or Polyak) for problems with strongly coupled cross-coordinate curvature and known or estimated $f^\star$.

\subsection{Local Approximations of $g(x) = x^4$}

For a smooth function $g: \mathbb{R} \to \mathbb{R}$, the Taylor expansion around $x_0$ gives:
\begin{align}
  \text{First-order:} \quad & \hat{g}_1(x) = g(x_0) + g'(x_0)(x - x_0), \\
  \text{Second-order:} \quad & \hat{g}_2(x) = g(x_0) + g'(x_0)(x - x_0) + \tfrac{1}{2}g''(x_0)(x - x_0)^2.
\end{align}

For $g(x) = x^4$ at $x_0 = 0.25$: $g(0.25) = 0.0039$, $g'(0.25) = 4(0.25)^3 = 0.0625$, $g''(0.25) = 12(0.25)^2 = 0.75$:
\begin{equation}
  \hat{g}_1(x) = 0.0039 + 0.0625(x - 0.25),
\end{equation}
\begin{equation}
  \hat{g}_2(x) = 0.0039 + 0.0625(x - 0.25) + 0.375(x - 0.25)^2.
\end{equation}

The \emph{Newton step} minimises $\hat{g}_2$: setting $d\hat{g}_2/dx = 0$ gives:
\begin{equation}
  x_1 = x_0 - \frac{g'(x_0)}{g''(x_0)} = 0.25 - \frac{0.0625}{0.75} = 0.25 - 0.0833 = 0.167.
\end{equation}
The true minimum of $g(x) = x^4$ is at $x = 0$; Newton overshoots from $x_0 = 0.25$ to $x_1 = 0.167 > 0$. This illustrates that Newton's method for $g(x) = x^4$ converges to $x=0$ but not in one step, since $g$ is not quadratic. For higher-order functions, multiple Newton steps are needed; the convergence is superlinear ($|x_{k+1}| \leq C|x_k|^2$ near the zero of $g'$, which is $x = 0$) but not finite.

Applying one more Newton step from $x_1 = 0.167$: $g'(0.167) = 4(0.167)^3 \approx 0.0186$, $g''(0.167) = 12(0.167)^2 \approx 0.334$, so $x_2 = 0.167 - 0.0186/0.334 \approx 0.111$. The pattern is $x_k = (2/3)^k x_0 / 2^{k-1}$... more precisely, the Newton iterates follow $x_{k+1} = x_k(1 - 1/3) = (2/3)x_k$ (for the stationary point of $x^4$, which has $g'(x)/g''(x) = x/3$), converging linearly (not quadratically) from away from $x=0$ since $x=0$ is a non-generic minimum where $g''(0) = 0$.

\subsection{Newton's Method}

\begin{algorithm}[H]
\caption{Newton's Method with Regularisation (Damped Newton)}
\label{alg:newton}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha \in (0, 1]$, regularisation $\lambda > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $g_k \gets \nabla f(x_k)$
    \State $H_k \gets \nabla^2 f(x_k) + \lambda I$ \Comment{Regularised Hessian ensures positive definiteness}
    \State Solve $H_k\, p_k = g_k$ for the Newton direction $p_k$ \Comment{$p_k = H_k^{-1}g_k$}
    \State $x_{k+1} \gets x_k - \alpha\, p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Quadratic Convergence of Newton's Method]
\label{thm:newton}
Let $f$ be twice continuously differentiable with $\rho$-Lipschitz Hessian in a neighbourhood of a local minimum $x^\star$ where $\nabla^2 f(x^\star) \succ 0$. For $x_0$ sufficiently close to $x^\star$ and $\alpha = 1$, Newton's method satisfies:
\begin{equation}
  \|x_{k+1} - x^\star\| \leq \frac{\rho}{2\mu}\|x_k - x^\star\|^2,
\end{equation}
where $\mu = \lambda_{\min}(\nabla^2 f(x^\star))$. This \emph{quadratic convergence} means the number of accurate digits roughly doubles each iteration.
\end{theorem}

\begin{remark}[Proof Sketch: Quadratic Convergence]
\label{rem:newton_proof}
Let $e_k = x_k - x^\star$. The Newton update gives $e_{k+1} = e_k - \nabla^2 f(x_k)^{-1}\nabla f(x_k)$. By the mean-value theorem, $\nabla f(x_k) = \nabla f(x^\star) + \nabla^2 f(x^\star) e_k + O(\|e_k\|^2)$. Since $\nabla f(x^\star) = 0$:
\begin{equation}
  e_{k+1} = e_k - \nabla^2 f(x_k)^{-1}\bigl[\nabla^2 f(x^\star) e_k + O(\|e_k\|^2)\bigr].
\end{equation}
Writing $\nabla^2 f(x_k) = \nabla^2 f(x^\star) + O(\rho\|e_k\|)$ (by the Lipschitz-Hessian assumption) and inverting to first order: $\nabla^2 f(x_k)^{-1} = \nabla^2 f(x^\star)^{-1} + O(\rho\|e_k\|/\mu^2)$. Substituting:
\begin{equation}
  e_{k+1} = e_k - \nabla^2 f(x^\star)^{-1}\nabla^2 f(x^\star) e_k + O(\rho\|e_k\|^2/\mu) = O\!\left(\frac{\rho}{\mu}\|e_k\|^2\right).
\end{equation}
The leading term cancels exactly, leaving a second-order remainder. The contraction constant $\rho/(2\mu)$ involves the ratio of Hessian Lipschitz constant $\rho$ to the minimum eigenvalue $\mu$ at the solution. For problems with nearly-constant Hessian (e.g., Benchmark A, where $H$ is constant), $\rho = 0$ and convergence is exactly quadratic (in fact, one-step for quadratics). For Rosenbrock, $\rho$ is large (highly varying Hessian), requiring the damped step $\alpha < 1$ to maintain the basin of attraction.

\textbf{Explicit constants for Benchmark C:} The third-order tensor $T = \nabla^3 f$ at $(1,1)$ has Frobenius norm $\|T\|_F = \sqrt{2400^2 + 3\times 400^2} \approx 2498$, giving Hessian Lipschitz constant $\rho \leq 2498$. With $\mu = 0.399$ (minimum Hessian eigenvalue at the optimum), the contraction constant from Theorem~\ref{thm:newton} is $\rho/(2\mu) \approx 3128$. Since the initial distance $\|e_0\| = \|x_0 - x^\star\| = 2.0$, we get $\rho/(2\mu)\|e_0\| \approx 6256 \gg 1$, confirming that $x_0 = (-1,1)$ is far outside the quadratic convergence basin. The damped step $\alpha = 0.22$ addresses this: while the full Newton step gives $f(x_0 - p_0) = 1600$ (catastrophically bad), the damped step $\alpha = 0.10$ gives $f = 3.40$ (slight improvement from $f_0 = 4.0$). Only after several iterations does the iterate enter the neighbourhood where $\rho/(2\mu)\|e_k\| < 1$, after which quadratic convergence activates.
\end{remark}

\begin{remark}[Full Newton Step on Quadratics]
\label{rem:ols_remark}
For a quadratic $f(\theta) = \frac{1}{2}\theta^T H \theta - b^T \theta + c$ with constant Hessian $H$, the Newton step $p = H^{-1}\nabla f(\theta_k) = H^{-1}(H\theta_k - b) = \theta_k - H^{-1}b = \theta_k - \theta^\star$ and thus $x_{k+1} = \theta_k - \alpha(\theta_k - \theta^\star)$. With $\alpha = 1$: $x_1 = \theta^\star$ in exactly one step, regardless of dimension or condition number. This is the fundamental advantage of second-order methods on quadratic objectives.
\end{remark}

\subsection{Per-Iteration Cost and Break-Even Analysis}

Newton's method requires $O(d^3)$ per iteration (Hessian computation $O(d^2)$ + LU factorisation $O(d^3)$), compared to $O(md)$ for the full-gradient GD iteration (a matrix-vector product). For the $d=2$ benchmarks here, both costs are negligible. However, the convergence-speed advantage quantifies the trade-off:

\begin{itemize}[nosep]
  \item \textbf{Benchmark A:} Newton achieves the minimum in 1 step vs GD's $\approx 123$ steps for $10^{-3}$ sub-optimality (at $\alpha = 0.08$). The Newton iteration costs $O(d^3) = O(8)$ vs GD's $O(md) = O(2000)$ per step. Net computation: Newton is $123 \times (2000/8) \approx 30{,}000\times$ cheaper.
  \item \textbf{Benchmark C:} Newton achieves $f = 0.69$ in 20 iterations vs GD achieving $f = 3.73$ in 80 iterations. For the same 80 iterations, Newton would achieve near-optimality; for comparable accuracy, GD would require $> 10{,}000$ iterations.
\end{itemize}

For high-dimensional problems (neural networks with $d \gg 10^6$ parameters), Newton's $O(d^3)$ cost is infeasible. This motivates: (a) \emph{quasi-Newton} methods (L-BFGS, BFGS) that maintain low-rank Hessian approximations; (b) \emph{Gauss--Newton} approximations for least-squares objectives; (c) \emph{natural gradient} methods that use the Fisher information matrix as a curvature proxy. The 2D experiments here serve as proof-of-concept for the convergence-quality gain that motivates this entire research area.

\subsection{Convergence on Benchmark A: Verification of Quadratic Convergence}

For a quadratic $J(\theta) = \frac{1}{2}\theta^T H \theta - b^T\theta + c$ with $b = \frac{1}{m}X^Ty$ and $c = \frac{1}{2m}\|y\|^2$, the Newton update is:
\begin{align}
  p_k &= H_{\mathrm{reg}}^{-1} \nabla J(\theta_k) = (H + \lambda I)^{-1}(H\theta_k - b), \\
  \theta_{k+1} &= \theta_k - \alpha p_k = \theta_k - \alpha (H + \lambda I)^{-1}(H\theta_k - b).
\end{align}
With $\alpha = 1$ and $\lambda \approx 0$ (the regularisation $\lambda = 10^{-8}$ is negligible): $\theta_1 = \theta_k - H^{-1}(H\theta_k - b) = H^{-1}b = \theta_{\mathrm{OLS}}$. This is the OLS solution in one step, confirming the theoretical prediction. The reported $J = 0.4826$ after one Newton step equals the irreducible noise-floor loss $J^\star = \frac{1}{2m}\|y - X\theta_{\mathrm{OLS}}\|^2$.

\subsection{Connection to Non-Convex Settings}

The Rosenbrock function is technically non-convex (the Hessian has a very small but positive minimum eigenvalue of $\approx 0.399$ at the optimum but may be indefinite away from it, as shown in Figure~\ref{fig:rosen_hessian}b). Newton's method with damping ($\alpha = 0.22$) handles this by:
\begin{enumerate}[nosep]
  \item The regularisation $H_k + \lambda I$ (with $\lambda = 10^{-8}$) ensures the effective Hessian is positive definite, making the Newton direction a descent direction.
  \item The step $\alpha = 0.22 < 1$ ensures the objective decreases at each step even when the local quadratic model is not globally valid.
\end{enumerate}
This is essentially the \emph{trust region} approach: taking a fraction of the full Newton step keeps the iterate within the basin of the local quadratic model's validity. The globally convergent variant would use line search to find the optimal $\alpha$ at each step, but the fixed damped step is sufficient for these benchmarks.

\begin{remark}[Polyak--\L ojasiewicz Condition and Non-Convex Convergence]
A weaker condition than strong convexity that still guarantees linear GD convergence is the \emph{Polyak--\L ojasiewicz (PL) condition}: $\|\nabla f(x)\|^2 \geq 2\mu(f(x) - f^\star)$ for all $x$. If $f$ satisfies PL, GD with $\alpha = 1/L$ achieves $f(x_k) - f^\star \leq (1 - \mu/L)^k (f(x_0) - f^\star)$, an $O(\rho^k)$ rate. The Rosenbrock function \emph{does not} satisfy PL globally: near the saddle point at $(-1, 1)$, the gradient can be small while the function value is large (relative to $f^\star = 0$). This explains why GD fails dramatically on Rosenbrock: once trapped near the valley entrance, both the gradient and the objective value are small but the distance to the minimum $(1,1)$ is large.

Formally, the Polyak--\L ojasiewicz condition sits strictly between (strong) convexity and general smoothness in the function hierarchy. Every $\mu$-strongly convex function satisfies PL with the same $\mu$ (by the suboptimality characterisation of strong convexity: $f(x) - f^\star \leq \frac{1}{2\mu}\|\nabla f(x)\|^2$), but not conversely. In fact, PL holds for all functions of the form $f(x) = h(Ax)$ where $h$ is strongly convex and the composition retains the gradient lower bound structure --- a class that includes over-parameterised linear networks and certain shallow neural networks in the interpolating regime.

The relationship between PL, strong convexity, and the quadratic growth condition $f(x) - f^\star \geq (\mu/2)\|x - x^\star\|^2$ can be summarised as:
\begin{equation}
  \text{Strong convexity} \Rightarrow \text{PL condition} \Rightarrow \text{Quadratic growth}
\end{equation}
(with neither implication reversible in general). Newton's quadratic convergence in Theorem~\ref{thm:newton} holds under strong convexity (positive definite Hessian at $x^\star$), which for Rosenbrock requires the damped/trust-region approach since the global PL condition is violated.
\end{remark}

\subsection{Part A: Finite Difference and Nesterov Random Search (Benchmark B)}

\subsubsection{Finite Difference Gradient Approximation}

The forward finite-difference (FFD) approximation of the $i$-th partial derivative is:
\begin{equation}
  \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \delta e_i) - f(x)}{\delta}, \qquad e_i = \text{$i$-th standard basis vector.}
\end{equation}

\begin{theorem}[Finite Difference Error]
For $f \in C^2$, the FFD error satisfies:
\begin{equation}
  \left|\frac{\partial f}{\partial x_i}(x) - \frac{f(x + \delta e_i) - f(x)}{\delta}\right|
  \leq \underbrace{\frac{\delta}{2}\max\left|\frac{\partial^2 f}{\partial x_i^2}\right|}_{\text{truncation error}} + \underbrace{\frac{2\varepsilon_{\mathrm{mach}}}{\delta}}_{\text{round-off error}}.
\end{equation}
Minimising over $\delta$ gives the optimal perturbation $\delta^\star \sim \sqrt{\varepsilon_{\mathrm{mach}}} \approx 10^{-8}$ (for double precision). Practical values must also ensure that $\delta \ll$ the scale of function variation.
\end{theorem}

\begin{remark}[Centered vs Forward Finite Differences]
The \emph{centered} finite difference $\frac{f(x + \delta e_i) - f(x - \delta e_i)}{2\delta}$ achieves $O(\delta^2)$ truncation error (using the $C^3$ Taylor expansion, the first-order terms cancel). For $f \in C^3$: error $\leq \frac{\delta^2}{6}\max|f'''_{iii}|$. This is dramatically better than the forward difference $O(\delta)$ error for the same $\delta$. The trade-off is cost: centered differences require $2d$ function evaluations per gradient estimate (vs $d+1$ for forward), a factor of $\approx 2$ overhead in high dimensions. For the experiments here, forward differences are used as specified in the assignment, but centered differences would achieve the same accuracy at $\delta = \sqrt{0.05} \approx 0.22$ --- reducing the sensitivity to $\delta$ selection.
\end{remark}

For Benchmark B, the maximum second derivative is $\max|f_{x_1 x_1}| = \max|2 - \sin(x_1)| \leq 3$ and $f_{x_2 x_2} = 10$ (constant). The FD truncation error in the $x_2$ direction is thus $\leq (\delta/2) \times 10 = 5\delta$. For $\delta = 0.05$: error $\leq 0.25$ (small relative to typical $|\partial f/\partial x_2| \approx 10|x_2 - 2|$). For $\delta = 0.8$: error $\leq 4.0$ in the $x_2$ direction, comparable to the gradient magnitude early in the optimisation, completely corrupting the gradient estimate.

The optimal $\delta$ for Benchmark B balances truncation error $\leq 5\delta$ against round-off error $\leq 2\varepsilon_{\mathrm{mach}}/\delta$: setting $5\delta = 2\varepsilon_{\mathrm{mach}}/\delta$ gives $\delta^\star = \sqrt{2\varepsilon_{\mathrm{mach}}/5} \approx 2\times10^{-8}$ for double precision. In practice, $\delta = 0.05$ is chosen as a pragmatic balance between the theoretical optimum and finite-precision effects; the key constraint is that $\delta$ must be small enough to avoid large truncation error but not so small that round-off dominates.

\subsubsection{Nesterov Random Search}

\begin{algorithm}[H]
\caption{Nesterov Random Search (Zeroth-Order Method)}
\label{alg:nrs}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, perturbation $\delta > 0$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sample $u_k \sim \mathcal{N}(0, I_d)$, normalise: $u_k \gets u_k / \|u_k\|$
    \State $\hat{g}_k \gets \dfrac{f(x_k + \delta u_k) - f(x_k)}{\delta}\, u_k$ \Comment{Directional derivative estimate}
    \State $x_{k+1} \gets x_k - \alpha\, \hat{g}_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[NRS as Gradient Estimator]
The NRS estimator satisfies $\mathbb{E}_{u}[\hat{g}_k] = \frac{1}{d}\nabla f_\delta(x_k)$ where $f_\delta(x) = \mathbb{E}_u[f(x + \delta u)]$ is a Gaussian-smoothed version of $f$. For small $\delta$, $f_\delta \approx f + O(\delta^2)$. The estimator is unbiased for the smoothed function's gradient but introduces $O(\delta)$ bias in the original gradient. Crucially, only \emph{two} function evaluations are needed per iteration regardless of dimension $d$, making NRS asymptotically cheaper than FFD ($d+1$ evaluations) in high dimensions. The cost is high variance: only one random direction is sampled per step.

\textbf{Convergence rate of NRS:} For a smooth convex $f$ with $L$-Lipschitz gradient, the expected convergence of NRS satisfies (Nesterov and Spokoiny, 2017):
\begin{equation}
  \mathbb{E}[f(x_k)] - f^\star \leq \frac{L d^2 \|x_0 - x^\star\|^2}{2k},
\end{equation}
i.e., an $O(d^2/k)$ rate. The extra $d^2$ factor arises from two sources: a factor of $d$ from the estimator variance (projecting the gradient onto a single random direction loses $d-1$ dimensions of information) and a factor of $d$ from the smoothing. This means NRS requires $O(d^2 \kappa \log(1/\varepsilon))$ function evaluations to achieve $\varepsilon$-accuracy on a strongly convex function, vs $O(\kappa \log(1/\varepsilon))$ for exact GD and $O(d \kappa \log(1/\varepsilon))$ for FD GD.

For Benchmark B with $d = 2$: NRS requires $4\times$ more evaluations than exact GD to achieve the same accuracy. At 220 iterations $\times$ 2 evaluations = 440 total evaluations for NRS vs 120 iterations $\times$ 1 evaluation = 120 for exact GD --- a $3.7\times$ ratio, consistent with the $d^2 = 4$ prediction (accounting for the fact that the 220 vs 120 iteration difference already partly reflects the slower rate). For $d = 100$: the evaluation ratio would be $d^2 = 10{,}000\times$, completely dominating --- NRS is not competitive with FD GD in moderate dimensions unless gradient computation is fundamentally unavailable.
\end{remark}

\subsection{Part B: Derivative-Free Methods on Benchmark C (Rosenbrock)}

\subsubsection{Nelder--Mead Simplex Method}

\begin{algorithm}[H]
\caption{Nelder--Mead Simplex (for $d = 2$)}
\label{alg:nm}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step $s$, parameters $\alpha_r=1, \gamma=2, \rho=0.5, \sigma=0.5$, iterations $N$
\State Initialise simplex: $\{v_0, v_1, v_2\}$ with $v_0 = x_0$, $v_j = x_0 + s e_j$ for $j=1,2$
\For{$k = 0, 1, \ldots, N-1$}
    \State Sort vertices: $f(v_0) \leq f(v_1) \leq f(v_2)$ \Comment{$v_0$ is best, $v_2$ is worst}
    \State Compute centroid $c = (v_0 + v_1)/2$
    \State $x_r \gets c + \alpha_r(c - v_2)$ (reflect worst through centroid)
    \If{$f(v_0) \leq f(x_r) < f(v_1)$} replace $v_2 \gets x_r$
    \ElsIf{$f(x_r) < f(v_0)$} expand: $x_e = c + \gamma(c-v_2)$; accept $\min(x_r, x_e)$
    \ElsIf{$f(x_r) < f(v_2)$} outside contraction: $x_c = c + \rho(x_r - c)$
    \Else{} inside contraction: $x_c = c + \rho(v_2 - c)$; if fail, shrink all vertices
    \EndIf
\EndFor
\end{algorithmic}
\end{algorithm}

Settings: initial simplex step $= 0.35$, iterations $= 160$. The Nelder--Mead parameters $(\alpha_r, \gamma, \rho, \sigma) = (1.0, 2.0, 0.5, 0.5)$ are the standard Lagarias et al.~(1998) defaults.

The four simplex operations serve distinct geometric purposes: \textbf{reflection} ($\alpha_r = 1$) moves the worst vertex through the centroid of the remaining vertices, probing the opposite side of the simplex; \textbf{expansion} ($\gamma = 2$) doubles the reflection step if it improved significantly, accelerating descent in productive directions; \textbf{contraction} ($\rho = 0.5$) shrinks the worst vertex towards the centroid when reflection fails, reducing simplex size near a valley; and \textbf{shrink} ($\sigma = 0.5$) collapses all vertices towards the best, reserved for cases where contraction also fails. This adaptive geometry allows the simplex to elongate along ridges and contract near flat regions, approximating the local topology without gradient information.

\begin{remark}[Curse of Dimensionality for Grid Search]
To maintain resolution $\Delta x = 0.075$ in $d$ dimensions, grid search requires $N^d = (1/\Delta x)^d \approx 13.3^d$ evaluations. For the 2D case here: $13.3^2 \approx 177$ points would suffice (the experiment uses $55^2 = 3025$ for better resolution). For $d = 10$: $13.3^{10} \approx 4 \times 10^{11}$ evaluations. For $d = 100$: the universe does not contain enough particles to represent the number of evaluations. This exponential scaling is the \emph{curse of dimensionality}, which makes grid search impractical for any real-world optimisation problem with $d \geq 4$.

By contrast, gradient descent converges in $O(\kappa \log(1/\varepsilon))$ evaluations regardless of $d$ (for strongly convex problems), while Nesterov random search uses $O(d/\varepsilon)$ evaluations but these are function evaluations only. The dimension-agnostic nature of gradient methods (at the cost of requiring $\nabla f$) is their most fundamental advantage over grid search.
\end{remark}

\textbf{Key trade-off:} Methods that do not use gradient information pay a convergence-rate penalty. Specifically:
\begin{itemize}[nosep]
\item FD gradient descent with good $\delta$ achieves the same convergence rate as exact GD asymptotically, but with $d+1$ function evaluations per step rather than one. \subsection{Problem Setup and KKT Conditions}

Minimise Benchmark B subject to $x_1 \geq 0.5$, starting from the infeasible point $x_0 = (0.2, 4.0)$:
\begin{equation}
  \min_{x \in \mathbb{R}^2}\; f(x_1, x_2) = (x_1 - 1)^2 + 5(x_2 - 2)^2 + \sin(x_1) \quad \text{s.t.}\quad x_1 \geq 0.5.
\end{equation}

Since the unconstrained minimum $x^\star \approx (0.5815, 2.0)$ satisfies $x_1^\star > 0.5$, the constraint is \emph{inactive} at the unconstrained minimum. The constrained and unconstrained optima coincide, and by the KKT conditions the Lagrange multiplier $\mu^\star = 0$ (complementary slackness is satisfied with strict feasibility).

\begin{remark}[Inactive vs Active Constraints: A Thought Experiment]
\label{rem:active_constraint}
If the constraint had instead been $x_1 \geq 1.0$ (a tighter bound), the unconstrained minimum $x_1^\star \approx 0.5815 < 1.0$ would be infeasible. The constrained minimum would then lie at $x_1 = 1.0$ (the constraint becomes \emph{active}): minimising over $x_2$ gives $x_2^\star = 2.0$ from the unconstrained $x_2$ equation. At this point, $\nabla f(1.0, 2.0) = [2(0) + \cos(1), 0]^T = [\cos(1), 0]^T \approx [0.54, 0]^T \neq 0$. The KKT condition $\nabla f(x^\star) + \mu^\star(-e_1) = 0$ gives $\mu^\star = \cos(1) \approx 0.54 > 0$ (active constraint with positive multiplier, as required). In this scenario, penalty methods would produce $x_1 < 1.0$ unless $\lambda$ is sufficiently large, and PGD would converge to $(1.0, 2.0)$ directly. The practical significance: for our actual constraint $x_1 \geq 0.5$, all methods find the same solution as unconstrained GD; the distinction between methods only matters when the constraint is active.
\end{remark}

\begin{remark}[KKT Conditions]
For this problem, $x^*$ is the constrained optimum if and only if there exists $\mu \geq 0$ such that:
\begin{align}
  \nabla f(x^*) + \mu \nabla g(x^*) &= 0, \quad g(x) = 0.5 - x_1 \leq 0, \\
  \mu g(x^*) &= 0 \quad \text{(complementary slackness)}, \\
  g(x^*) &\leq 0 \quad \text{(primal feasibility)}.
\end{align}
Since $x^*_1 \approx 0.5815 > 0.5$, we have $g(x^*) < 0$, hence $\mu^* = 0$ and the KKT conditions reduce to $\nabla f(x^*) = 0$.
\end{remark}

\begin{algorithm}[H]
\caption{Projected Gradient Descent (PGD)}
\label{alg:pgd}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, projection $\Pi_{\mathcal{X}}$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_{k+1} \gets x_k - \alpha\, \nabla f(x_k)$ \Comment{Unconstrained gradient step}
    \State $x_{k+1} \gets \Pi_{\mathcal{X}}(z_{k+1}) = \max(0.5, z_{k+1,1})\, e_1 + z_{k+1,2}\, e_2$ \Comment{Clip $x_1$ to $[0.5, \infty)$}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Quadratic Penalty Method}
\label{alg:penalty}
\begin{algorithmic}[1]
\Require Initial point $x_0$, step size $\alpha > 0$, penalty weight $\lambda > 0$, iterations $N$
\State Define penalised objective: $F_\lambda(x) = f(x) + \lambda \max(0,\, 0.5 - x_1)$
\For{$k = 0, 1, \ldots, N-1$}
    \State Compute $\nabla F_\lambda(x_k)$: gradient of $f$ plus $-\lambda e_1$ if $x_1 < 0.5$, else $\nabla f$
    \State $x_{k+1} \gets x_k - \alpha\, \nabla F_\lambda(x_k)$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{remark}[Penalty Method Convergence]
As $\lambda \to \infty$, the minimiser of $F_\lambda$ converges to the constrained minimiser. However, large $\lambda$ causes the Hessian of $F_\lambda$ to be ill-conditioned in the infeasible region, requiring smaller step sizes for stability. The step size must satisfy $\alpha < 2/(L + \lambda)$ for convergence in the active-constraint region, explaining why $\alpha$ is reduced from $0.05$ to $0.03$ when $\lambda$ increases from $1.8$ to $4.5$.
\end{remark}

\begin{theorem}[PGD Convergence Rate]
\label{thm:pgd}
For $\mu$-strongly convex, $L$-smooth $f$ over a convex compact set $\mathcal{X}$, projected GD with step $\alpha = 1/L$ satisfies:
\begin{equation}
  \|x_{k+1} - x^\star\|^2 \leq \left(1 - \frac{\mu}{L}\right)^k \|x_0 - x^\star\|^2.
\end{equation}
The contraction factor $\rho = 1 - \mu/L = 1 - 1/\kappa$ is the same as unconstrained GD. The key step uses the non-expansiveness of projection: $\|\Pi_\mathcal{X}(u) - \Pi_\mathcal{X}(v)\| \leq \|u - v\|$, which ensures the projection does not increase distances.
\end{theorem}

For Benchmark B with PGD step $\alpha = 0.08 \approx 1/L = 1/10 = 0.1$ (conservative), the effective rate is approximately $\rho \approx 1 - 0.08 \times \mu \approx 1 - 0.08 \times (2-\sin(x_1)) \approx 0.84$ early in the optimisation. The convergence to $f^\star \approx 0.7244$ within 100 iterations is consistent with this rate: $0.84^{100} \approx 5\times10^{-8}$, so PGD should converge to machine precision well within the budget.

Settings: PGD ($\alpha = 0.08$), penalty with $\lambda \in \{0.15, 1.8, 4.5\}$ ($\alpha = 0.05$ for $\lambda \leq 1.8$; $\alpha = 0.03$ for $\lambda = 4.5$), unconstrained GD ($\alpha = 0.07$). All run for 100 iterations.

\subsection{Comparative Discussion}

\textbf{Projected GD} enforces feasibility as a hard constraint at every iteration. The projection onto the half-space $\{x : x_1 \geq 0.5\}$ is simply $\Pi_{\mathcal{X}}(x) = (\max(0.5, x_1), x_2)$, a $O(1)$ operation. For this simple constraint, PGD is the gold standard: it is both feasible and optimal. For complex constraint sets where projections are expensive ($O(d^2)$ or worse), penalty methods may be preferred.

\textbf{Penalty methods} trade exact feasibility for algorithmic simplicity. The minimiser of $F_\lambda(x) = f(x) + \lambda\max(0, 0.5-x_1)$ satisfies the perturbed KKT condition $\nabla f(x^\star_\lambda) = \lambda e_1$ (when $x^\star_{\lambda,1} < 0.5$), so the residual violation at the penalised minimiser satisfies $\max(0, 0.5-x_{1,\lambda}^\star) \propto 1/\lambda$. For $\lambda = 0.15$, the observed violation $\approx 0.09$ reflects this: the penalty gradient $\lambda = 0.15$ is much smaller than the objective gradient $|\partial f/\partial x_1| \approx 2|x_1 - 1| \approx 1.2$ at the infeasible point, so the penalty pulls the iterate towards feasibility only weakly. For $\lambda = 4.5$, the penalty gradient dominates, strongly enforcing $x_1 \geq 0.5$. The required step size must satisfy $\alpha < 2/\lambda_{\max}(\nabla^2 F_\lambda)$; since the penalty $\lambda\max(0, g)$ is linear (not quadratic) in $g(x) = 0.5-x_1$, the Hessian of $F_\lambda$ is identical to that of $f$ away from the boundary. However, the gradient jump at $x_1 = 0.5$ (the penalty gradient switches from $-\lambda$ to $0$) effectively acts as a steep potential wall, requiring smaller $\alpha$ to prevent overshooting.

\textbf{Practical implications}: Since the unconstrained minimum of Benchmark B is already feasible ($x_1^\star \approx 0.5815 > 0.5$), the constraint is inactive and the KKT multiplier is $\mu^\star = 0$. This explains why both PGD and large-$\lambda$ penalty methods converge to the same point as unconstrained GD. For problems where the unconstrained minimum is infeasible, the constrained minimum lies on the constraint boundary, the multiplier $\mu^\star > 0$ is non-zero, and the methods would give genuinely different solutions.

\textbf{Penalty vs Augmented Lagrangian:} The penalty method used here adds $\lambda \max(0, g(x))$ to the objective. An alternative is the \emph{augmented Lagrangian method} (ALM / ADMM family), which includes both a Lagrange multiplier estimate $\nu$ and a quadratic penalty:
\begin{equation}
  L_\lambda(x, \nu) = f(x) - \nu g(x) + \frac{\lambda}{2}\max(0, g(x))^2,
\end{equation}
where the multiplier is updated as $\nu_{k+1} = \nu_k - \lambda \max(0, g(x_k))$ at each outer iteration. This has two key advantages over pure penalty:
\begin{itemize}[nosep]
  \item \textbf{Exact feasibility at lower $\lambda$:} The multiplier update compensates for constraint violation, achieving near-exact feasibility even for moderate $\lambda$ (avoiding the ill-conditioning that requires $\lambda \to \infty$).
  \item \textbf{Better conditioning:} The Hessian of $L_\lambda$ equals that of $f$ (plus $\lambda$ only when $g(x) > 0$), so the step size requirement $\alpha < 2/\lambda_{\max}(\nabla^2 L_\lambda)$ does not tighten as aggressively as for the pure penalty.
\end{itemize}
The experiments confirm the pure penalty limitation: the step size must decrease as $\lambda$ increases ($\alpha = 0.05$ for $\lambda \leq 1.8$, $\alpha = 0.03$ for $\lambda = 4.5$), reflecting $\lambda_{\max}(F_\lambda) \approx L_{\max} + \lambda \cdot \mathbf{1}_{g(x)<0}$ in the infeasible region. For the problem here, with the unconstrained optimum already feasible, neither ALM nor pure penalty has a structural advantage. However, for problems where $x_1^\star < 0.5$ (an infeasible unconstrained minimum), the pure penalty with $\lambda = 0.15$ would completely fail to find the constrained minimum, while ALM would succeed through the multiplier update.

\textbf{Computational summary:}
\begin{itemize}[nosep]
\item \textbf{PGD}: $O(1)$ projection + gradient per step, exact feasibility, requires projection oracle.
\item \textbf{Penalty ($\lambda$ small)}: gradient only, approximate feasibility, no projection needed.
\item \textbf{Penalty ($\lambda$ large)}: gradient only, near-exact feasibility, but requires smaller step.
\item \textbf{Augmented Lagrangian}: iterative multiplier update, best balance of feasibility and conditioning.
\end{itemize}

\subsection{Penalty Method Conditioning Analysis}

A key limitation of pure quadratic penalty methods is that the condition number of the augmented objective $F_\lambda(x) = f(x) + (\lambda/2)\|g(x)\|^2$ grows with $\lambda$, making gradient descent increasingly ill-conditioned. For the half-space constraint $g(x) = 0.5 - x_1$ with quadratic penalty $(\lambda/2)\max(0,g)^2$, the Hessian of $F_\lambda$ at a point where $x_1 < 0.5$ (infeasible) is:
\begin{equation}
  \nabla^2 F_\lambda(x) = \nabla^2 f(x) + \lambda\, e_1 e_1^T,
\end{equation}
where $e_1 = [1, 0]^T$. The eigenvalues of $\nabla^2 f$ at the constrained optimum are approximately $[2\cos(x_1^\star), 4] \approx [1.66, 4]$. Adding $\lambda$ to the $(1,1)$ entry gives eigenvalues approximately $[1.66 + \lambda, 4]$, so:
\begin{equation}
  \kappa(F_\lambda) = \frac{\max(\lambda_{\max})}{\min(\lambda_{\min})} \approx \frac{1.66 + \lambda}{4} \cdot \frac{4}{1.66} \approx 1 + \frac{\lambda}{1.66},
\end{equation}
and the maximum stable step size satisfies $\alpha < 2/(1.66 + \lambda)$. For $\lambda = 4.5$, $\alpha < 2/6.16 \approx 0.32$ (reasonable); for $\lambda = 100$, $\alpha < 2/101.66 \approx 0.02$ (restrictive). This explains the observed need to reduce $\alpha$ as $\lambda$ increases, and is the primary motivation for the augmented Lagrangian, which can achieve feasibility at lower $\lambda$ without the associated ill-conditioning.

\subsection{Feasible Set and Linear Programme}

Feasible set: $\mathcal{X} = \{x \in \mathbb{R}^2 : 0.5 \leq x_1 \leq 5,\ -5 \leq x_2 \leq 10\}$, a bounded box polytope.

\textbf{Linear Programme:} Minimise $f(x) = a^T x = x_1 + 2x_2$ over $\mathcal{X}$, with $a = [1, 2]^T$.

\begin{proposition}[Fundamental Theorem of Linear Programming]
The minimum of a linear function over a bounded polytope $\mathcal{X}$ is attained at a vertex of $\mathcal{X}$.
\end{proposition}

Since both components of $a$ are positive, each coordinate is minimised at its lower bound independently:
\begin{equation}
  x^\star = (0.5,\, -5), \qquad f^\star = 0.5 + 2 \times (-5) = -9.5.
\end{equation}
For a box $\mathcal{X} = [l_1, u_1] \times [l_2, u_2]$, the LP solution for $\min a^T x$ is:
\begin{equation}
  x^\star_i = \begin{cases} l_i & \text{if } a_i > 0 \\ u_i & \text{if } a_i < 0 \end{cases}
\end{equation}
This $O(d)$ LP solution per iteration replaces the potentially expensive projection step. For comparison: projection onto a general polytope (intersection of $m$ halfspaces) requires solving a QP, which costs $O(m \cdot d)$ to $O(d^3)$ depending on the method. The LP subproblem over a box costs only $O(d)$ --- a dramatic simplification. This is why Frank--Wolfe is particularly attractive for \emph{structured} constraint sets where the LP is cheap: simplices, nuclear norm balls, spectrahedra, and flow polytopes all have efficient LP oracles.

\begin{remark}[Connection to the Simplex Method]
The LP subproblem solved at each Frank--Wolfe step is itself a special case of linear programming over the same feasible polytope $\mathcal{X}$. The Simplex Method solves this LP by moving along edges of $\mathcal{X}$ between adjacent vertices until optimality is certified. For the box constraint here, the LP solution is trivial (component-wise comparison), but for general polytopes (flow polytopes, combinatorial polytopes in network optimisation), efficient LP solvers can be substituted as the LMO oracle. This separates the FW algorithm's convergence analysis from the specific LP oracle, allowing the two components to be improved independently. Frank--Wolfe with a specialised LP oracle for matrix trace-norm constraints, for instance, enables state-of-the-art algorithms for matrix completion.
\end{remark}

\subsection{Frank--Wolfe Algorithm}

\begin{algorithm}[H]
\caption{Frank--Wolfe (Conditional Gradient Method)}
\label{alg:fw}
\begin{algorithmic}[1]
\Require Initial point $x_0 \in \mathcal{X}$, mixing parameter $\beta \in (0,1)$, iterations $N$
\For{$k = 0, 1, \ldots, N-1$}
    \State $z_k \gets \arg\min_{z \in \mathcal{X}}\, \nabla f(x_k)^T z$ \Comment{LP: linear minimisation oracle (LMO)}
    \State $x_{k+1} \gets \beta\, x_k + (1 - \beta)\, z_k$ \Comment{Convex combination step towards LMO solution}
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Frank--Wolfe Convergence Rate]
\label{thm:fw_conv}
For a convex differentiable $f$ with $L$-Lipschitz gradient over a convex compact set $\mathcal{X}$ with diameter $D = \max_{x,y \in \mathcal{X}}\|x-y\|$, the Frank--Wolfe algorithm with step size $\gamma_k = 2/(k+2)$ satisfies:
\begin{equation}
  f(x_k) - f^\star \leq \frac{2LD^2}{k+2}, \qquad k \geq 1.
\end{equation}
This $O(1/k)$ rate is slower than projected gradient descent's $O(1/k^2)$ for strongly convex objectives, but Frank--Wolfe does not require a projection oracle, replacing it with the cheaper LMO.
\end{theorem}

\begin{remark}[Frank--Wolfe Duality Gap]
The \emph{Frank--Wolfe gap} at iteration $k$ is:
\begin{equation}
  g_k = \nabla f(x_k)^T(x_k - z_k) \geq 0,
\end{equation}
where $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z$. Since $f$ is convex, the first-order condition gives:
\begin{equation}
  f^\star = f(x^\star) \geq f(x_k) + \nabla f(x_k)^T(x^\star - x_k) \geq f(x_k) + \min_{z \in \mathcal{X}} \nabla f(x_k)^T(z - x_k) = f(x_k) - g_k,
\end{equation}
establishing $g_k \geq f(x_k) - f^\star$. This gap is a \emph{computable} upper bound on suboptimality (unlike $f(x_k) - f^\star$ itself, which requires $f^\star$). At the starting point $x_0 = (1,1)$ for Case II, we compute: $\nabla f(x_0) = [0, -8]^T$, $z_0 = (5, 10)$ (LMO solution), and:
\begin{equation}
  g_0 = [0, -8]^T \cdot [(1,1) - (5,10)] = [0, -8]^T \cdot [-4, -9] = 0 + 72 = 72.
\end{equation}
The true suboptimality is $f(x_0) - f^\star = 16 - 0 = 16 < 72 = g_0$: the gap is valid but overestimates the suboptimality by a factor of 4.5. This looseness is characteristic of FW: the first-order lower bound $f(z) \geq f(x) + \nabla f(x)^T(z-x)$ used in the derivation is not tight when $z$ is far from $x$. The gap is used as a stopping criterion: when $g_k < \varepsilon$, the iterate is $\varepsilon$-optimal.
\end{remark}

For box constraints, the LMO reduces to coordinate-wise comparison:
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } (\nabla f(x_k))_i > 0 \\ u_i & \text{if } (\nabla f(x_k))_i \leq 0 \end{cases}
\end{equation}
requiring $O(d)$ operations, compared to $O(d)$ to $O(d^2)$ for projection onto general polytopes.

\begin{remark}[Proof Sketch: Frank--Wolfe $O(1/k)$ Rate]
Using the descent lemma and the definition of $z_k$ from the LMO, with step size $\gamma_k = 2/(k+2)$:
\begin{align}
  f(x_{k+1}) &\leq f(x_k) + \nabla f(x_k)^T(x_{k+1} - x_k) + \frac{L}{2}\|x_{k+1}-x_k\|^2 \\
  &= f(x_k) + \gamma_k \nabla f(x_k)^T(z_k - x_k) + \frac{L\gamma_k^2}{2}\|z_k - x_k\|^2 \\
  &\leq f(x_k) + \gamma_k \nabla f(x_k)^T(x^\star - x_k) + \frac{L\gamma_k^2 D^2}{2},
\end{align}
where the last inequality uses $z_k = \arg\min_{z \in \mathcal{X}} \nabla f(x_k)^T z \leq \nabla f(x_k)^T x^\star$ and $\|z_k - x_k\| \leq D$. By convexity, $\nabla f(x_k)^T(x^\star - x_k) \leq f(x^\star) - f(x_k) = f^\star - f(x_k)$. Subtracting $f^\star$ from both sides and setting $h_k = f(x_k) - f^\star$:
\begin{equation}
  h_{k+1} \leq (1 - \gamma_k) h_k + \frac{L\gamma_k^2 D^2}{2}.
\end{equation}
With $\gamma_k = 2/(k+2)$, substituting and applying induction yields $h_k \leq 2LD^2/(k+2)$, the stated $O(1/k)$ bound. The key step is that FW bounds the \emph{decrease in objective} in terms of the duality gap $g_k = \nabla f(x_k)^T(x_k - z_k)$, rather than requiring a projection step.
\end{remark}

\subsection{Interior vs Boundary Behaviour: Comparative Analysis}

\textbf{Interior optimum (Case II):} Frank--Wolfe exhibits a characteristic zig-zag pattern as $z_k$ oscillates between extreme points of $\mathcal{X}$. The mechanism is as follows: at iteration $k$, the gradient $\nabla f(x_k)$ determines which vertex of $\mathcal{X}$ is selected by the LMO. When $x_k$ is near the interior optimum $(1,5)$, the gradient $(2(x_{k,1}-1), 2(x_{k,2}-5))$ alternates sign in the $x_2$ component, causing $z_k$ to jump between $(0.5, 10)$ (when $\partial f/\partial x_2 < 0$) and $(0.5, -5)$ (when $\partial f/\partial x_2 > 0$). With $\beta = 0.90$ (larger step towards $z_k$), this oscillation is amplified, causing $x_k$ to overshoot past the optimum. With $\beta = 0.985$ (smaller step), the iterate moves less aggressively towards each vertex, allowing the averaging effect to dominate and produce smoother convergence. This is the \emph{zig-zag phenomenon} of Frank--Wolfe.

The standard Frank--Wolfe $O(1/k)$ theorem uses the decaying schedule $\gamma_k = 2/(k+2) \to 0$. Fixed $\beta$ does not satisfy this: with $\beta = 0.90$, the step size is constant at $1-\beta = 0.10$ regardless of $k$, violating the decay requirement. For $\beta = 0.985$, the step size $0.015$ is smaller but also constant, and neither value achieves the theoretical $O(1/k)$ guarantee. Using the schedule $\gamma_k = 2/(k+2)$ would achieve the $O(LR^2/k)$ bound where $R = \max_{x,y \in \mathcal{X}}\|x-y\| = \|(4.5, 15)\| \approx 15.7$ and $L = 2$ (gradient Lipschitz constant for the quadratic objective), giving $f(x_k) - f^\star \leq 494/k$, predicting suboptimality $\approx 2.7$ at $k=180$.

\textbf{Boundary optimum (Case III):} Frank--Wolfe is particularly well-suited to boundary optima: the gradient $2x$ at any $x \in \mathcal{X}$ has positive components, so the LMO consistently selects the vertex $(0.5, -5)$ (at the lower bounds), pulling the iterate towards the boundary. The iterate converges to $(0.5, -0.337)$ after 140 iterations, with $f = 0.364 > f^\star = 0.25$. The residual gap arises because the $x_2$ component has not yet converged: $-0.337 \neq 0$. Using more iterations would further reduce $f$; the theoretical guarantee gives convergence as $k \to \infty$.

\textbf{Projection-free advantage:} Frank--Wolfe's core advantage is the LMO oracle replacing projections. For structured constraint sets (nuclear norm balls, simplex, flow polytopes), the LMO can be solved efficiently in problem-specific ways, enabling Frank--Wolfe to scale to high-dimensional constrained problems where projection would be prohibitively expensive.

\subsection{Frank--Wolfe vs Projected Gradient Descent: Theoretical Comparison}

Both FW and PGD solve the same constrained problem $\min_{x \in \mathcal{X}} f(x)$, but with fundamentally different sub-problems at each iteration:

A crucial distinction is that FW does \emph{not} improve from $O(1/k)$ to $O(\rho^k)$ linear convergence for strongly convex objectives --- unlike PGD, which achieves linear convergence. This is because FW's step direction always targets a vertex of $\mathcal{X}$, so the zig-zag oscillation prevents the gradient-norm-to-zero convergence that underlies linear convergence for PGD. The trade-off is clearest for highly structured constraints: nuclear norm balls arise in matrix completion and low-rank regression, where FW's $O(d^2)$ leading-singular-vector subproblem dominates PGD's $O(d^3)$ full SVD projection. In that setting, FW's $O(1/k)$ rate at $O(d^2)$ cost can outperform PGD's linear rate at $O(d^3)$ cost for moderate dimensions.

For the box constraints in this experiment ($O(d)$ cost for both), PGD is theoretically superior for strongly convex objectives. The choice of FW here is illustrative: it demonstrates the algorithm's properties (duality gap, zig-zag, vertex convergence) in a setting where both methods are equally cheap per step.

\textbf{Quantitative zig-zag analysis:} The zig-zag phenomenon admits a precise characterisation for the interior-optimum case (Case II, $f(x) = (x_1-1)^2 + (x_2-5)^2$). At each iteration $k$, the LMO for coordinate $i$ selects:
\begin{equation}
  (z_k)_i = \begin{cases} l_i & \text{if } \frac{\partial f}{\partial x_i}(x_k) > 0 \\ u_i & \text{if } \frac{\partial f}{\partial x_i}(x_k) < 0 \end{cases}
\end{equation}
For coordinate 2, $\frac{\partial f}{\partial x_2}(x_k) = 2(x_{k,2} - 5)$ changes sign when $x_{k,2}$ crosses the optimum $x_{2}^\star = 5$. With fixed step $(1-\beta)$, the iterate $x_{k+1,2} = \beta x_{k,2} + (1-\beta) (z_k)_2$ where $(z_k)_2 \in \{-5, 10\}$. When $x_{k,2} > 5$ (gradient positive, LMO selects $z_{k,2} = -5$):
\begin{equation}
  x_{k+1,2} = \beta x_{k,2} + (1-\beta)(-5) = \beta(x_{k,2} - 5) - 5(1-\beta) + 5\beta = \beta x_{k,2} - 5 + 5\beta.
\end{equation}
The sign of $(x_{k+1,2} - 5)$ is the same as that of $\beta(x_{k,2} - 5) - 10(1-\beta)$. For $\beta = 0.90$ and $x_{k,2} \approx 5.1$ (close to optimum), $\beta(x_{k,2}-5) \approx 0.09 < 10 \times 0.10 = 1.0$, so $x_{k+1,2} - 5 < 0$: the iterate crosses the optimum, triggering a sign change and an LMO switch from $-5$ to $+10$. This perpetuates the zig-zag: at each step, the iterate overshoots the optimum and the LMO switches between extremes of the box. The oscillation amplitude decays as $\beta^k$ (from the geometric damping in the update), but for large $\beta$ this decay is slow. For $\beta = 0.985$: $\beta^{50} \approx 0.47$, so after 50 steps the oscillation has halved; for $\beta = 0.90$: $\beta^{50} \approx 0.0052$, oscillation has nearly vanished but the iterate is less accurate due to large early overshoots.

\subsection{Key Lessons}

\begin{enumerate}
\item \textbf{Curvature matters most on ill-conditioned problems.} Newton's method with 20 iterations outperforms GD with 80 iterations on Rosenbrock by $5\times$ in objective value, and converges in 1 step on the quadratic. The cost in Hessian computation is justified when the condition number $\kappa$ is large.

\item \textbf{The Polyak step is theoretically optimal but oracle-sensitive.} Its $O(1/k)$ guarantee without knowing $L$ or $\mu$ is compelling, but exact knowledge of $f^\star$ is its Achilles heel. A practical remedy is to use a running estimate of $f^\star$ or combine Polyak with a backtracking mechanism.

\item \textbf{Nesterov acceleration achieves qualitative speedup.} The $O(1/k^2)$ vs $O(1/k)$ rate difference materialises visibly on Rosenbrock ($f = 0.479$ vs $3.39$ for GD after 150 steps). This motivates the widespread use of Nesterov-style momentum in modern deep learning optimisers.

\item \textbf{Adam and coordinate-wise scaling excel on heterogeneous curvature.} For problems with decoupled coordinate curvature (e.g., Benchmark B), Adam's per-coordinate adaptation effectively preconditiones the problem. The advantage diminishes for strongly coupled curvature (Rosenbrock), where full second-order information is needed.

\item \textbf{Derivative-free methods pay a convergence-rate penalty.} FD gradient descent closely tracks exact GD with appropriate $\delta$, but good $\delta$ requires problem knowledge. Nesterov random search converges slowly but requires only 2 function evaluations per step, a practical advantage in very high dimensions or black-box settings.

\item \textbf{Penalty vs projection trade-off.} Projected GD enforces constraints exactly at every step but requires a projection oracle. Penalty methods require only a modified gradient and achieve approximate feasibility for large $\lambda$; the required step size decreases as $\lambda$ increases, creating a computational trade-off.

\item \textbf{Frank--Wolfe avoids projections at the cost of $O(1/k)$ convergence.} The LMO is cheap for structured sets (boxes, simplices) and the algorithm naturally handles boundary optima. For strongly convex objectives inside the feasible set, projected gradient descent is faster; Frank--Wolfe is preferred when projections are expensive.
\end{enumerate}

Zeroth-order methods (NRS, Nelder--Mead) pay an explicit $d$-dependent factor over their gradient-based counterparts. The three benchmarks in this report were deliberately chosen to highlight different positions in this hierarchy: Benchmark A (small $\kappa$) is easy for all gradient methods; Benchmark B (moderate $\kappa$) reveals the benefit of coordinate-wise adaptation; Benchmark C (large $\kappa \approx 2508$) starkly separates methods by their ability to deal with ill-conditioning.

\subsection{Unified Mathematical Framework}

All algorithms studied in this report can be viewed through a single unifying lens: each is a \emph{gradient preconditioner} that modifies the gradient update $x_{k+1} = x_k - \alpha P_k \nabla f(x_k)$ for some preconditioner matrix $P_k$:

\begin{table}[H]
\centering
\caption{All algorithms as gradient preconditioners $x_{k+1} = x_k - \alpha P_k \nabla f(x_k)$ or generalisations.}
\label{tab:preconditioners}
\begin{tabular}{lp{5.5cm}p{5cm}}
\toprule
\textbf{Algorithm} & \textbf{Preconditioner $P_k$} & \textbf{Interpretation} \\
\midrule
GD & $I$ (identity) & No preconditioning \\
Newton & $[\nabla^2 f(x_k)]^{-1}$ & Full curvature inverse \\
Heavy Ball & $I$ (with momentum state) & Inertial iteration, $\kappa$ improvement for quadratics \\
Nesterov & $I$ (with lookahead gradient) & Accelerated via extrapolated point \\
Adagrad & $\mathrm{diag}(G_k)^{-1/2}$, $G_{k,i} = \sum_j g_{j,i}^2$ & Diagonal, cumulative curvature estimate \\
RMSprop & $\mathrm{diag}(v_k)^{-1/2}$, $v_k$ = EMA of $g_k^2$ & Diagonal, exponential curvature estimate \\
Adam & $\mathrm{diag}(\hat{v}_t)^{-1/2}$ applied to $\hat{m}_t$ & Diagonal preconditioner + momentum \\
L-BFGS & Low-rank approx.\ of $[\nabla^2 f]^{-1}$ & Between GD and Newton \\
\midrule
PGD & $I$ + projection onto $\mathcal{X}$ & Constrained GD via projection \\
Frank--Wolfe & LMO oracle (no matrix) & Projection-free, $O(1/k)$ rate \\
NRS / Nelder--Mead & None (zeroth-order) & Gradient-free, $d$-factor penalty \\
\bottomrule
\end{tabular}
\end{table}

This framework immediately reveals why Newton dominates: for strongly convex $f$, the ideal preconditioner is $[\nabla^2 f(x_k)]^{-1}$ (equating all effective step sizes across directions), and Newton's method is the only first/second-order method that achieves this exactly. Adam and RMSprop approximate this with the \emph{diagonal} of the Hessian, which is exact for problems with diagonal $H$ (like Benchmark B) but misses off-diagonal coupling (like Benchmark C). Heavy Ball and Nesterov use $P_k = I$ but compensate through momentum accumulation, effectively averaging past gradients to approximate the inverse Hessian implicitly over multiple steps.

From this perspective, the history of optimisation for machine learning can be read as a progression: GD (no preconditioning) $\to$ Adagrad/RMSprop (diagonal preconditioning) $\to$ Adam (diagonal + momentum) $\to$ K-FAC/Shampoo (block-diagonal) $\to$ Newton/L-BFGS (full inverse Hessian). Each step trades computational cost for better curvature information, with the optimal choice depending on $d$, the cost of Hessian computation, and the degree of cross-coordinate coupling in the problem.

def gradient_descent(grad_fn, loss_fn, x0, alpha, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        x = x - alpha * grad_fn(x)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Polyak Step Size}]
def polyak_step(grad_fn, loss_fn, x0, f_star, eps, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        alpha_k = (loss_fn(x) - f_star) / (np.dot(g, g) + eps)
        alpha_hist.append(alpha_k)
        x = x - alpha_k * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adagrad}]
def adagrad(grad_fn, loss_fn, x0, alpha0, eps, n_iters):
    x = x0.copy().astype(float)
    G = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        G += g**2
        eff_alpha = alpha0 / (np.sqrt(G) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={RMSprop}]
def rmsprop(grad_fn, loss_fn, x0, alpha0, beta, eps, n_iters):
    x = x0.copy().astype(float)
    v = np.zeros_like(x)
    x_hist, f_hist, alpha_hist = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        v = beta * v + (1 - beta) * g**2
        eff_alpha = alpha0 / (np.sqrt(v) + eps)
        alpha_hist.append(np.mean(eff_alpha))
        x = x - eff_alpha * g
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(alpha_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Heavy Ball / Polyak Momentum}]
def heavy_ball(grad_fn, loss_fn, x0, alpha, beta, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for _ in range(n_iters):
        g = grad_fn(x)
        z = beta * z + alpha * g
        x = x - z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Nesterov Momentum}]
def nesterov_momentum(grad_fn, loss_fn, x0, alpha, beta_max, n_iters):
    x = x0.copy().astype(float)
    z = np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for k in range(1, n_iters + 1):
        beta_k = min((k - 1) / (k + 2), beta_max)
        lookahead = x + beta_k * z
        g = grad_fn(lookahead)
        z = beta_k * z - alpha * g
        x = x + z
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Adam Optimiser}]
def adam_optimiser(grad_fn, loss_fn, x0, alpha, beta1, beta2, eps, n_iters):
    x = x0.copy().astype(float)
    m_vec, v_vec = np.zeros_like(x), np.zeros_like(x)
    x_hist, f_hist = [x.copy()], [loss_fn(x)]
    for t in range(1, n_iters + 1):
        g = grad_fn(x)
        m_vec = beta1 * m_vec + (1 - beta1) * g
        v_vec = beta2 * v_vec + (1 - beta2) * g**2
        m_hat = m_vec / (1 - beta1**t)
        v_hat = v_vec / (1 - beta2**t)
        x = x - alpha * m_hat / (np.sqrt(v_hat) + eps)
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist)
\end{lstlisting}

\begin{lstlisting}[caption={Newton's Method with Damping}]
def newtons_method(grad_fn, hess_fn, loss_fn, x0, alpha, n_iters, damping=1e-8):
    x = x0.copy().astype(float)
    x_hist, f_hist, update_norms = [x.copy()], [loss_fn(x)], []
    for _ in range(n_iters):
        g = grad_fn(x)
        H = hess_fn(x) if callable(hess_fn) else hess_fn
        H_reg = H + damping * np.eye(len(x))
        try:
            p = np.linalg.solve(H_reg, g)
        except np.linalg.LinAlgError:
            p = g
        update_norms.append(np.linalg.norm(alpha * p))
        x = x - alpha * p
        x_hist.append(x.copy())
        f_hist.append(loss_fn(x))
    return np.array(x_hist), np.array(f_hist), np.array(update_norms)
\end{lstlisting}

def frank_wolfe(grad_fn, loss_fn, x0, bounds, beta, n_iters):
    x = x0.copy().astype(float)
    x_hist, f_hist, z_hist = [x.copy()], [loss_fn(x)], []
